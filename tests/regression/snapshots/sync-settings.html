配置指南

坚果云 WebDAV（应用密码） 登录坚果云网页版 → 账户信息 → 安全选项 → 第三方应用管理 → 添加应用密码（不能填登录密码）；先在坚果云新建同步文件夹（或用「我的坚果云」），地址填 https://dav.jianguoyun.com/dav/我的坚果云/。
Nextcloud WebDAV 地址填 https://你的域名/remote.php/dav/files/你的用户名/Fuyu/（请勿使用旧版 /remote.php/webdav）；开启两步验证时请在「设置 → 安全 → 设备与会话」中生成专用应用密码。
群晖 Synology WebDAV 在套件中心安装启用 WebDAV Server（默认 HTTPS 5006、局域网 HTTP 5005），确认账号有对应共享文件夹读写权限与 WebDAV 应用权限，地址填 https://NAS地址:5006/共享文件夹/Fuyu/。
OneDrive / iCloud Drive 在网盘里新建一个文件夹（如 Sync/Fuyu），在各台电脑上都选中它即可；按需下载的占位文件会在同步时自动拉取。
坚果云桌面同步盘 若已安装坚果云桌面客户端，也可直接用「同步文件夹」方式在 Windows 与 Mac 上选中同一个本地同步目录。
Syncthing 局域网/跨网同步 共享同一个文件夹给多台设备，浮屿会自动忽略 .sync-conflict 与临时文件，按条无锁合并。
NAS / SMB 局域网共享 挂载群晖或飞牛等 SMB 共享目录后选中；外出未挂载共享盘时会自动跳过当轮同步，回来后继续。

多台电脑之间只需指向同一个 WebDAV 目录、云盘同步目录或局域网共享目录即可协同工作。
