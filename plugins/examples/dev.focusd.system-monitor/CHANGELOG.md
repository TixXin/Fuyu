# 更新记录

## 1.2.2

- 打开监控页更快出数字：读程序列表从逐个进程取 CPU 时间（几百个进程要 2 秒多，打开页面时还会连读两次）改成一次 WMI 查询（约 0.1 秒）。程序列表从打开后 6 秒左右缩到 2 秒左右；每 3 秒读程序时页面也不再顿一下。

## 1.2.1

- 修复：监控页刚打开、还没加载好时插件就开始发读数，开着「后台记录曲线」时读数会抢在记录的曲线前面。现在页面加载好之后才发读数，记录的曲线先到。

## 1.2.0

- 任何显卡都有 GPU 占用：读 Windows 自带的 GPU 计数器（和任务管理器的数字一致），AMD、Intel 也有，不再只认 NVIDIA。GPU 下面多一排引擎条：3D、复制、视频解码、视频编码。计数器读一次要 0.3–1 秒，放在后台线程里每 2 秒读一次，只在监控页打开时读，不拖慢每秒的刷新。
- CPU 下面是每个核心，GPU 下面是它的引擎，一一对应。核心很多（32 个以上）时竖条间距变窄，不会挤出页面。完全读不到 GPU 的电脑，CPU 占满这一行。
- 浅色岛屿底色上也能看清：岛屿 0.3.4 起把墨色告诉不套卡片的页面，图表颜色也换成在浅底上看得清的深一档。
- 修复：程序图标存进了页面状态，看过的程序一多就超过岛屿给页面的 64 KB，曲线历史也跟着存不下。现在图标只在页面打开期间保留，插件自己缓存，再打开时重新发过去。
- 打开页面后程序列表 1 秒左右就出来（以前要等 3 秒），等待时显示占位行，不会跳动。读程序路径只读排在前面的几个，不再每 3 秒对所有进程读一遍。
- 曲线刚打开时至少按一分钟铺开，不再只在最右边一小段。鼠标停在 CPU、GPU、网速上显示最近 5 分钟的平均和最高。
- 内存一行加上百分比；占用超过整机 20% 的程序数字变红。
- 程序一栏右上角加了「打开任务管理器」按钮。

## 1.1.0

- 监控页重新排版：不再套卡片，直接画在岛上；岛在这一页变宽（760px），左边是 CPU、GPU、每个核心、内存、网速，右边是最占 CPU 或内存的 6 个程序，不再出现滚动条。需要 FocuSD Island 0.3.4 或更新，旧版岛屿照旧显示窄页面。
- 程序带上自己的图标（每个程序只读一次）；系统进程这类读不到图标的显示首字母。
- CPU、GPU、内存各有一个小圆环；显存、显卡功耗和电池放在一行，电脑上没有的就不显示。

## 1.0.3

- 新设置「后台记录曲线」（默认关）：监控页关着时也每秒读一次 CPU、GPU 和网速，打开页面时曲线带着最近五分钟，不再只有打开之后的数据。开着时插件一直运行（约 80 MB 的 PowerShell 进程）。
- 曲线从一分钟加长到五分钟（每秒一个点）。

## 1.0.2

- 修复：监控页只偶尔刷新，「程序」一栏一直是空的。插件等岛屿消息时的超时在 Windows PowerShell 5.1 上不生效，两次消息之间读数就停住了（issue #12）。现在每秒刷新一次，程序列表每 3 秒更新。
