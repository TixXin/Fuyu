# 天气

岛上多一个「天气」页：所选城市的当前天气、今天逐小时和未来 7 天。收起条上也可以显示天气和温度，一小时内要下雨时在岛上提醒。

## 怎么用

- 安装并启用后，到 **设置 → 插件扩展 → 天气 → 设置**，在「城市」里填城市名，例如「杭州」「London」。同名城市在逗号后加省、州或国家区分，例如「Springfield, Illinois」。插件设置页的「位置」一栏写着实际找到的地方和经纬度，不对就换个写法。
- 岛上的「天气」页：现在的天气、体感、湿度和风速，未来 24 小时（降水概率 20% 以上时标出），未来 7 天的最低、最高温度。面板宽时 7 天排在右边，窄时排在下面，放不下就上下滚动。右上角的按钮立即刷新。
- 勾选「收起条显示天气和温度」后，收起条上多一列，例如「多云 18°」，悬停看体感温度，点击打开天气页。可以在 **外观 → 收起条上的项目** 里调位置。默认不勾。
- 勾选「一小时内要下雨时提醒」后，接下来一小时内预报有雨时岛上提示一次，大约几点开始下。同一场雨只提醒一次，3 小时内不重复。默认不勾。
- 温度单位可以选摄氏度或华氏度。

## 联网和隐私

- 不读系统定位。城市留空时插件不联网。
- 数据来自 [Open-Meteo](https://open-meteo.com/)（免费，不需要账号和密钥，数据按 CC BY 4.0 授权）。插件发给它的只有城市名（查经纬度用，结果会记住，换城市或换界面语言时才再查一次）和经纬度。
- 每 30 分钟最多刷新一次（「刷新间隔」可以调到 180 分钟；开了下雨提醒时固定 30 分钟），点刷新按钮时立即刷新。联网失败时继续显示上次的结果，并写出更新时间和原因。

## 开销

- 两个都不勾：只在打开天气页时联网，页面关掉一分钟后插件自己停下。
- 勾了收起条显示：一直运行（插件卡片上会写原因），按刷新间隔发一个很小的请求。
- 只勾了下雨提醒：每 30 分钟启动一次查预报，查完一分钟后停下。
- 运行时是一个 Windows 自带的 PowerShell 进程，运行时约 60 MB 内存，大部分是 PowerShell 本身。
