# 更新记录 · Changelog

## 1.1.0

有了设置：可以每天定时写入，同一天再写会替换上一份，不再越叠越多。

- **同一天再次写入时替换上一份**（默认开）：原来每点一次就在笔记末尾多一份。现在替换今天上一份摘要；那一份被你在笔记里改过时，新的写在后面，你改的内容不动。
- **每天定时自动写入**（默认关，22:00）：到点时浮屿没开着，当天晚些时候启动后补写。
- 新设置：写入范围（只写未完成 / 未完成 + 已完成数 / 全部）、条目格式（列表 / 复选框 `- [ ]`）、全部完成时也写一句（默认开）、写完在岛上弹出提示（默认开）。改了马上生效。
- 设置里的预览直接显示将要写进笔记的内容，跟着设置变。
- 「写入摘要」命令接上了：在插件详情里点「运行」或给它设快捷键就能写。
- 过了零点自动换到新的一天；读不到待办时有中英文提示。
- 岛上的提示服务变成可选：没有它也照样写入，只是不弹提示。
- 写进笔记的文字和界面一样跟随界面语言。
- 名字统一成「待办摘要 / To-do digest」，说明改成一句话。
- 原来没有设置项，升级后全部取默认值。
- 图标换成和浮屿设置一致的风格：浅底色加同色线条。

Settings at last: write on a schedule, and writing again on the same day replaces the earlier digest instead of piling up.

- **Writing again on the same day replaces the earlier digest** (on by default): before, every click added another copy to the end of the note. If you edited the earlier digest in the note, the new one goes below it and your edits stay.
- **Write automatically every day** (off by default, 22:00). If Fuyu is not running at that time, it writes when it starts later the same day.
- New settings: what to write (open only, open + done count, or all), item style (list or `- [ ]` checkbox), a line when everything is done (on), and a notification on the island after writing (on). Changes apply right away.
- The preview in the settings shows exactly what will go into the note and follows the settings.
- The "Write to-do digest" command now works: run it from the plugin's details or give it a shortcut.
- It moves on to the new day after midnight, and says so in Chinese or English when it can't read your to-dos.
- Island notifications are now optional: without them the digest is still written, just without a notification.
- The text written into the note follows the interface language, like the settings.
- The name is now "To-do digest" everywhere and the description is one sentence.
- 1.0.0 had no settings, so everything starts at the defaults.
- New icon in the same style as Fuyu's settings: a tinted tile with a line glyph in the same color.
