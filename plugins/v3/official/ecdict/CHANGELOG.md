# 更新记录 · Changelog

## 1.0.1

改名「离线词典」，说明改成一句话讲用处。

- 插件名和翻译服务里的名字从「ECDICT 离线词典」改成「离线词典」；ECDICT 是词库的名字，写在说明和致谢里。
- 插件说明改成一句话讲能做什么，主分类改为「工具」。
- 查词功能和词库没有变化。
- 图标换成和浮屿设置一致的风格：浅底色加同色线条。
- 市场页补上截图：在快捷翻译里查单词、变形词还原和中文反查。
- 补了搜索关键词，在市场里搜「查词」「字典」「英汉」也能找到。

Renamed to "Offline dictionary", with a one-line description.

- The plugin and its entry in the translation service list are now called "Offline dictionary" instead of "ECDICT Offline Dictionary"; ECDICT, the name of the word list, stays in the description and credits.
- The description now says in one line what it does, and the main category is Utilities.
- Lookups and the word list are unchanged.
- New icon in the same style as Fuyu's settings: a tinted tile with a line glyph in the same color.
- The market page gets screenshots: a word lookup in Quick translate, an inflected form, and a Chinese-to-English lookup.
- Search keywords added, so "translation" or "word lookup" find it in the market.
