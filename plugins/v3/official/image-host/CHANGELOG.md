# 更新记录 · Changelog

## 1.0.0

首个版本。截图卡片和截图历史上多一个「上传图床」：把截图传到你自己的 S3 兼容存储（Cloudflare R2、Amazon S3、阿里云 OSS、腾讯云 COS 或本机的 MinIO），并复制链接或 Markdown。密钥存在系统凭据里。

First release. Screenshot cards and the screenshot history get an Upload button: it sends the screenshot to your own S3-compatible storage (Cloudflare R2, Amazon S3, Alibaba Cloud OSS, Tencent Cloud COS or MinIO on this computer) and copies the link or Markdown. The keys are kept in the system credential store.
