# 更新记录 · Changelog

## 1.1.0

有了设置，岛上更清爽，不再一点就完成。

- **点待办不再直接完成**：原来点一下就标为完成、没法撤销，容易误点。现在默认只看不改；想在岛上勾掉待办，到 设置 → 插件 → 待办进度环 打开「点待办勾选完成」，打开后点完几秒内可以撤销。
- 新设置：统计范围（今天 / 今天加逾期）、列出几条待办（只显示圆环 / 3 / 5 / 8，默认 3）、全部完成后圆环变完成色（默认开）、收起条显示（默认开）和样式（圆环 + 3/7 / 只圆环 / 剩 4 条）。改了马上生效。
- 岛页去掉刷新按钮（待办一变就会更新）和与百分比重复的「X / N 已完成」，默认列 3 条。
- 过了零点自动换到新的一天；读不到待办、没能标为完成时有中英文提示。
- 岛的页头有了中英文标题；点收起条打开待办进度环页（需要浮屿支持）。

More settings, a cleaner island page, and no more ticking a todo by accident.

- **Clicking a todo no longer finishes it straight away**: it used to mark it done with no undo, which was easy to hit by mistake. The page is now read-only by default; to tick todos off on the island, turn on "Click a todo to mark it done" in Settings → Plugins → Todo Progress Ring, and you can undo for a few seconds after each click.
- New settings: count today or today + overdue, how many todos to list (ring only, 3, 5 or 8; 3 by default), the done color when everything is done (on), and whether and how the ring shows on the collapsed bar (ring + 3/7, ring only, or "4 left"). Changes apply right away.
- The island page drops the refresh button (it updates as soon as todos change) and the "X / N done" line that repeated the percentage, and lists 3 todos by default.
- It moves on to the new day after midnight, and says so in Chinese or English when it can't read your todos or mark one done.
- The island header has a title in Chinese and English; clicking the collapsed bar opens the Todo Progress Ring page (when Fuyu supports it).
