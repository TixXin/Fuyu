# 上游 fly-island 近期改动里值得借鉴的

> 日期：2026-11-18。问题：上游仓库 flyl1u/fly-island 最近的 PR 和改动里，有哪些值得我们借鉴。范围：上游 `main` 在 2026-11-05 到 2026-11-19 之间的约 100 个提交（`gh api repos/flyl1u/fly-island/commits`），合入的 PR #55、开着的 PR #69；逐条读提交的改动，再在本仓库的 `src/`、`src-tauri/src/`、`packages/`、`docs/` 里查我们有没有。插件系统的对比见 [upstream-plugin-system.md](upstream-plugin-system.md)（2026-11-16），这里只写那之后的新东西。

## 结论

上游这两周主要在打磨日常体验：通知、贴边、游戏模式、歌词源、Agent 状态的边界情况。下面这些地方，我们已经有，而且做得更全，不用再跟：
- **媒体 CPU**：D52、D98。
- **办公 IM 提醒**：C102，我们有 Toast 监听，还支持 macOS。
- **卸载时清理钩子**：B74。
- **下载镜像**、**旧名清理**（D81）、**逐字歌词填充**。
- **自绘月历**、**待办保存路径**、**微信唤回不弹登录框**。

**值得做（按收益排序）**

**可以考虑（小改或要先定方向）**

- 鼠标停在岛上时保持通知不消失，收起条上的通知正文可以拖选（1ce83a97）。C109 只覆盖了面板和邮件。
- 验证码自动复制（74143d7a），要能关，而且这次写入不进剪贴板历史（C109）。
- 自动安装更新失败后退避重试，并提示「更新失败，点击重试」（3da82c8c）。
- 重新评估已结束会话默认藏起来是否合适（PR #55）。上游把三家结束时机不一样讲得很清楚：Codex 要空闲 30 分钟才发 SessionEnd。我们是 `agentHideClosed`，默认开。
- 通用 API 余额插件（PR #69 第 3 节）：供应商模板、密钥存进系统凭据、按账户设低余额线。适合做成 v3 插件的样板。
- 收起态的圆角单独设置（ab73d9ef），记住上次打开的页面并在重启后恢复（bcb7da2b，要加 localStorage key）。
- 剪贴板全选不包含收藏（d9779b4e），待办页可设一次显示几条（68894050），已开始的任务各自计时（e48c8ec0）。
- 收起空闲时居中显示时钟和日期（PR #69 第 2 节）：更适合做成插件往收起条上的贡献，不必内置（E37）。
- 桌面实时模糊（7d639493）：用 DXGI 桌面复制采集岛后面的画面再模糊。这是真正透出后面窗口的唯一路线，实测占用约 0.3% 单核，但要新写约 700 行平台代码，而且和 `docs/design/island.md`「不透出桌面、只透壁纸」的决定冲突，要用户先定方向（C87、C89、C97）。

**不借鉴**

- 网易云进度插件自动安装（fc9b4326）：往网易云目录放 DLL，容易被安全软件拦截，也有信任风险。我们用 InfLink-rs 的 BetterNCM 插件。
- 内置 Google gtx / MyMemory 免密钥翻译（6746d913）：已经定了不内置逆向接口（C110）。
- 插件规范改成「改造小岛源码、靠 PR 合进去」（3e6ae116、a07d3659）：上游退回了源码级扩展，和我们的 v3 路线相反。
- 欢迎待办（4011f3c4）：我们有完整的新手引导窗口。
- 露边高度可调、模糊下限改为 30、剪贴板标签行的图标加文字、播放器顺序归档、待办结束前响三声：用处小，或者和我们的设计不同。

**另外两点**

- 上游用 `release-features.json` 做发布功能开关，编译期一处关掉插件和验证码（70d739f9）。这个「单一来源」的做法可以参考，我们现在有 `FUYU_PLUGINS_V3=0`。
- 上游 office-im 用来认企业微信、钉钉、飞书窗口的类名表（`WeWorkWindow`、`StandardFrame_DingTalk`、`Feishu.exe`），可以拿来核对我们的 `im_sources/specs.rs`。
