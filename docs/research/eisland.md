# eIsland：值得借鉴的功能

> 日期：2026-11-14。问题：同类项目 eIsland 还有什么值得我们学习和增加的功能。范围：[JNTMTMTM/eIsland](https://github.com/JNTMTMTM/eIsland) 的 README、GitHub Releases（60 个版本）、`docs/CHANGE_LOG.md` 里约 1800 条 feat 提交、源码目录结构，粗看了 SMTC 时间线的代码；没装软件实测。相关任务：D55（歌词卡住）；据此新建 C73–C80、D57、D58、E37（见下面各条）。

## 结论

eIsland（344 star，GPLv3 加署名附加条款，2026-03 创建，27.0.2 刚从 Electron 迁到 Tauri；数字为 2026-11-14 查询）走的是「岛上装满小工具」的路子：天气、倒数日、闹钟、世界时钟、计算器、工具箱、小游戏、壁纸市场、内置 AI 聊天，还有账号体系和 Pro 付费。我们走的是「把桌面上正在发生的事放到岛上」（Agent、消息、音乐、剪贴板、截图），重心不同，不必跟着堆工具。

值得借鉴的按优先级：

1. **歌词的细节**（推算时钟在 D55；其余是 C73、C74、C75）
   - 每个媒体会话一个推算时钟，播放器时间线没更新时从自己上次的位置接着推，暂停时停住并暂停歌词动画（已写进 D55）。
   - 前奏（第一句之前）显示歌名或音符，而不是提前显示第一句歌词。我们现在前奏时显示待办，可以加这个选项。
   - 专辑封面取主色，给歌词、波形、光晕上色。
   - 更多歌词来源：lrclib（开放接口，适合英文歌）、Apple Music 的 TTML 逐字、汽水音乐。
2. **悬停「窥视」层**（C76）：它有闲置、悬停、展开、全展开四层。光标停在岛上先出一个比收起条大一点的预览（歌词、时间、天气轮换），滚轮再往深处走。我们是悬停直接展开面板，可以考虑在中间加一层轻量预览，或支持滚轮切页。
3. **闲置时变淡、整体透明度**（C77）：可调岛的透明度，一段时间没操作自动降低透明度，闲置时鼠标穿透。我们已有贴边收起，这是另一种「不挡视线」的方式。
4. **休息提醒**（C78）：久坐、护眼提醒，可自定义图标和间隔，到点在岛上提醒。和我们已有的计时器（C58）放在一起。
5. **链接识别和收藏**（C79）：剪贴板里出现链接时岛上弹一条，一键收藏；有收藏页、黑名单和识别规则。可以作为剪贴板的一项功能。
6. **国内更新镜像**（D57）：它把安装包同时放在腾讯云 COS、阿里云 OSS、Cloudflare R2 和 GitHub，更新弹窗显示当前更新源。我们只走 GitHub，国内用户下载慢、插件下载也失败过（D53），值得加一个国内镜像源。
7. **升级前备份**（D58）：大版本升级前自动备份数据并校验，出问题能回滚。
8. **语音输入**（C80）：语音转文字，结果一键存成备忘或待办。
9. **倒数日、闹钟、世界时钟**：适合做成插件放进市场，不内置（E37）。

不建议照搬：账号体系和 Pro 付费、内置 AI 聊天（我们的方向是接已有的 Agent）、小游戏、股票、壁纸市场和视频壁纸、格式转换 / 压缩 / 多线程下载这类工具箱（真要做就做成插件）。

许可：两边都是 GPLv3，但 eIsland 附加了必须保留作者署名的条款。只借思路，不搬代码；真要用它的代码，按它的 LICENSE 保留署名。

### 它有、我们没有的（摘自更新记录）

- 界面：悬停预览层，滚轮切换标签页；整体透明度、闲置自动变淡、闲置鼠标穿透；动画速度可调；「一键锁定 UI」和位置校准；自定义时钟字体和渐变色；全展开页的布局顺序可调。
- 音乐：封面主色光晕和波形颜色；前奏时显示歌名或音符；Apple Music、汽水音乐、MoeKoe、lrclib 歌词源；切换播放源的弹窗；音乐服务账号登录；YouTube Music 白名单。
- 提醒：休息提醒（自定义图标、总览卡片）、闹钟（铃声）、倒数日（自定义背景图）、公告系统；音量分级（总体、音效、闹钟）。
- 工具：链接识别和收藏、世界时钟、计算器（含函数图像）、工具箱（图片和视频格式转换、压缩、音视频轨道提取、多线程下载、JSON / Base64、IP 查询、TOTP）、相册小组件、本地文件搜索、2048 和五子棋。
- AI：内置聊天（多模型、Ollama 本地模型、附件、记忆、37 个操作岛和系统的工具、中危操作需用户授权）、语音输入。
- 发布：国内对象存储镜像加 GitHub 的多更新源；从 Electron 迁到 Tauri 的迁移助手，升级前备份；命令行工具（TUI）可以查看和删除已保存的数据。

### 歌词时间线（和 D55 相关）

`plugins/windows/eisland-windows-smtc-helper/src/SmtcController.cs` 里的 `TimelineClock`：记下播放器上次发布的（位置、开始、结束、更新时间）。下次采样时，发布内容没变就从自己上次算出的位置按速率接着推；变了才用新的发布值重新推算。暂停和停止时不外推。采样结果带 `SampledAtMs` 交给前端。我们在 `src-tauri/src/media_control/session.rs` 的 `read_timeline` 只做了「从发布值推到现在」那一步。
