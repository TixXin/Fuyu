# 股票小组件与桌面盯盘 UI 调研及自选股重设计方案

> 日期：2026-11-26。问题：浮屿展开态是宽矮横条（约 800×240），现有单列自选股列表中间留白过大、纵向只能放 3.5 条；主流股票小组件与桌面看盘工具是怎么布局的，浮屿自选股应该怎么重新设计？范围：Apple Stocks（macOS / iOS 桌面小组件）、Raycast / macOS 菜单栏股票工具、TradingView / Robinhood、富途牛牛 / 同花顺 / 东方财富迷你看盘、iOS Dynamic Island Live Activity，以及浮屿内置「系统监控」宽屏布局参考。

## 结论

1. **核心问题诊断**：浮屿展开岛是典型的 **宽矮横屏容器（宽高比 > 3:1）**。手机端常用的「单列纵向自选列表」拉宽到 800px 后，名称贴最左、价格贴最右，中间出现约 500px 空白，且纵向只能露出 3～4 只股票；全宽示例横幅又吃掉一行高度，信息密度和视觉平衡都偏弱。
2. **主流竞品的共同规律**：
   - **Sparkline（无坐标轴微型分时折线 + 渐变填充 + 昨收虚线）** 是股票小组件最具辨识度的视觉锚点（Apple Stocks、TradingView、Robinhood、富途牛牛全部采用）。
   - **宽屏空间必须横向分栏**：不能把单列无限拉宽。宽度 ≥ 520px 时，业界最成熟的是 **「左主图详情 + 右紧凑自选列表」（Master-Detail）**，或者 **「多列行情卡片网格」**。
   - **数字严格等宽（`tabular-nums`）**，次级信息（今开/最高/最低/昨收）只放焦点股票卡，列表只保留名称、代码、微型走势与涨跌幅胶囊。
   - **示例提示与工具按钮融入紧凑顶栏**，不单独占一条全宽 Banner。
3. **浮屿 `@fuyu/stock` 重设计方案（已按方案 A 落地）**：
   - 采用对标 **Apple Stocks macOS + 富途牛牛迷你看盘 + 浮屿系统监控** 的 **左图右表 Master-Detail 分时看板**（宽度 < 520px 时通过 CSS Container Query 自动切换上下堆叠）。
   - **左侧（~54%）焦点分时卡**：选中股票的大号等宽现价、涨跌额与涨跌幅胶囊 + **真实分时折线渐变面积图 + 昨收虚线基准线** + 极简四格日内指标（`今开` / `最高` / `最低` / `昨收`）。
   - **右侧（~46%）高密度自选清单**：顶栏浓缩「状态点 + 涨跌计数 `↑/↓` + 示例自定义小胶囊 + 刷新/设置图标」，下方紧凑列表一屏直接展示 **5～6 只股票**，每行带微型走势线、现价与涨跌幅胶囊；点击任意一只立刻切换左侧分时详情。
   - **数据源零鉴权升级**：行情批量接口顺手读取 `今开 / 最高 / 最低 / 昨收`（东方财富 `f15~f18` 与腾讯 `qt.gtimg.cn` 同一次请求即可返回），分时走势双源接入腾讯 `web.ifzq.gtimg.cn`（A 股、港股、美股、指数均实测 200）与东方财富 `push2.eastmoney.com/api/qt/stock/trends2/get` 自动兜底。

## 竞品 UI 调研对比

| 参考产品 | 适用容器比例 | 核心布局结构 | 视觉亮点与可借鉴之处 | 对浮屿宽矮岛的启发 |
|---|---|---|---|---|
| **Apple Stocks（macOS / iOS 桌面小组件）** | 中号 2×1（横条）、大号 2×2 | 行内三段式：`[代码/简称] — [无轴 Sparkline] — [等宽现价 + 涨跌胶囊]`；支持「显示更多详情」紧凑模式 | 去掉坐标轴与杂乱网格，用 1.5–2pt 折线 + 柔和红绿渐变面积表达日内走势；等宽数字纵向对齐 | **Sparkline + 昨收虚线 + 柔和渐变**最适合小空间，一眼扫出日内强弱 |
| **富途牛牛 / 同花顺 / 东方财富（桌面迷你看盘）** | 280×160 单股卡片 / 360×240 多股看板 / 细条悬浮条 | 顶部股票名+价格，中间大面积分时折线（价格线 + 昨收基准线），底部单行极简指标（今开/最高/最低/成交量） | 深色暗夜底降低盯盘疲劳；红涨绿跌采用现代低饱和金融色（避免纯红纯绿刺眼）；点击或悬停渐进披露详情 | 焦点卡底部用单行 4 格展示 `今开 / 最高 / 最低 / 昨收`，极省高度又有专业感 |
| **Raycast / macOS Menu Bar Ticker（含 TradingView / Robinhood 风格）** | 菜单栏胶囊 + 下拉浮层 | 菜单栏只留 `[简称 现价 涨跌幅]`；浮层顶部聚合状态/快捷操作，列表卡片内嵌微型走势线 | 极克制用色（除涨跌外全中性灰白），深炭底高对比字体，操作按钮图标化收进角落 | 去掉多余装饰与全宽提示条，把「示例 · 自定义」浓缩成顶栏小胶囊 |
| **iOS Dynamic Island（Stock Live Activity）** | 灵动岛收起态双翼 + 展开态横条 | 收起态左右分翼（左简称、右现价/涨跌）；展开态左上标的、右上大号等宽价格、下方走势与日内极值 | `monospacedDigit` 防止数字跳动抖动，收起态极简克制不塞第二行 | 浮屿收起条继续克制，展开态充分利用横向双栏 |
| **浮屿内置「系统监控」** | 浮屿标准宽矮展开岛（~800×240） | **左半区指标+面积折线图，右半区紧凑排行列表** | 完全贴合浮屿岛壳比例，视觉重心在左、交互列表在右，零大片死黑留白 | 最贴合浮屿基因的布局范式，股票页采用同款左图右表骨架最和谐 |

## 三种候选重设计方向对比

### 方案 A：左图右表 Master-Detail 分时看板（推荐 · 已优先落地）

```text
┌────────────────────────────────────────────────────────────────────────────┐
│  ┌────────────────────────────────────┐  ● 交易中 · 19:42  ↑2 ↓3  [示例›] ↻ ⚙ │
│  │ 上证指数  SH 000001                │  ┌──────────────────────────────┐  │
│  │ 3475.46  -1.01  [ -0.03% ]         │  │▌上证指数   ╱╲_   3475.46 -0.03%│  │
│  │   ╱╲    /\                         │  │ 贵州茅台   ╲_╱   1465.19 -0.65%│  │
│  │ ─/──\──/──\───────── 昨收 3476.47  │  │ 腾讯控股   _╱‾   344.20  +2.02%│  │
│  │ 3469.65                   3497.81  │  │ 苹果       ─╱‾   355.58  +0.43%│  │
│  │ 今开 3490  最高 3497  最低 3469  昨收 │  │ 英伟达     ──╱   186.20  +0.00%│  │
│  └────────────────────────────────────┘  └──────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────────┘
```

- **优点**：彻底消灭中间 500px 空白；左侧有真实分时图 + 日内四维指标，右侧一屏直接看全 5～6 只自选股且支持点击切换左侧分时；宽屏像专业金融看板，窄屏（< 520px）自动上下堆叠。
- **取舍**：比纯文字列表多了一次轻量的分时数据请求（仅在交易时段或切换选中标的时按需拉取并缓存，休市不重复请求）。

### 方案 B：多列紧凑行情瓷砖网格（2×3 / 3×2 Grid）

- **结构**：去掉大详情卡，整个 800×240 区域铺成 3 列 × 2 行共 6 张小卡片，每张卡内含名称、现价、涨跌幅胶囊和一条极简迷你走势线。
- **优点**：同时平权展示 6 只股票，无需点击切换。
- **不足**：缺少放大看分时与今开/高低/昨收的焦点区域，当自选只有 1～3 只时网格仍有明显空洞。

### 方案 C：单列三段式（左名称 + 中宽 Sparkline + 右价格）

- **结构**：保留现有纵向列表，把中间空出来的 500px 填成拉长的水平分时折线。
- **不足**：在 240px 高度限制下依然只能显示 3～4 行，且每条折线被拉得过扁过长，比例不如左图右表均衡。
