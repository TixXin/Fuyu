## O que é isto?

Fuyu (浮屿, «ilhota flutuante») é uma ilha flutuante leve, sem bordas e sempre por cima das outras janelas. Ela fica recolhida no topo da tela, se abre quando você precisa e se recolhe sozinha quando você termina. O que você usa no dia a dia está na ilha, então não precisa trocar de janela só para dar uma olhada.

A aparência, o tamanho, o jeito de recolher, os atalhos e cada função são ajustados na janela de Configurações, e o app se atualiza sozinho. Todos os seus dados ficam no seu computador.

## Consumo de recursos

Recolhida, ociosa e sem música (configuração padrão, sem plugins):

| | Medido |
|---|---|
| CPU | Cerca de **10%** de um núcleo (cerca de 0,5% do total num computador de 20 núcleos) |
| Memória | Cerca de **16 MB** para o Fuyu em si |
| A página de Agentes atualizando a lista de sessões a cada segundo | **0,1%** de um núcleo |
| Cada plugin de PowerShell instalado | Cerca de **60 MB** a mais |

Como foi medido e os dados completos: [idle-usage.md](../investigations/idle-usage.md) (em chinês).

## Primeiros passos

1. **Baixe e instale**: baixe o instalador em [Releases](https://github.com/TixXin/fuyu/releases/latest).
   - **Windows**: baixe o `_x64-setup.exe`. Os instaladores não têm assinatura de código; se o SmartScreen mostrar um aviso, escolha «Mais informações → Executar assim mesmo».
   - **macOS**: na [lista de releases](https://github.com/TixXin/fuyu/releases), baixe o `_aarch64.dmg` da versão mais recente que o tenha (se a última versão estável não tiver, procure na versão de teste logo acima dela) e arraste o Fuyu para Aplicativos. Na primeira vez, abra Ajustes do Sistema → Privacidade e Segurança e clique em «Abrir Mesmo Assim»; o passo a passo está no [guia de instalação no Mac](https://fuyu.ing/#mac-install).
2. **Abra a ilha**: passe o ponteiro sobre a ilha no topo da tela para abri-la; o botão de engrenagem ou o ícone na bandeja do sistema (no Mac, o ícone na barra de menus) abre as Configurações. No Mac, o guia de boas-vindas ajuda você a ativar as permissões do sistema necessárias.
3. **Configure uma vez**: e-mail, tradução e agentes de IA precisam ser configurados uma vez nas Configurações. Veja [e-mail](../features/mail.md), [agentes de IA](../features/agent-status-hooks.md), [notificações do QQ](../features/qq-notifications.md), [avisos do WeChat](../features/wechat-reminders.md) e [alertas no celular](../features/cc-connect.md) (em chinês).

> [!NOTE]
> Funciona no Windows 10 / 11 e no macOS 15 ou posterior (Apple silicon). No Mac há algumas diferenças em relação ao Windows: QQ e WeChat mostram só o número de mensagens não lidas, não o conteúdo, e o controle de mídia e o brilho usam interfaces privadas do sistema. Em [platforms.md](../architecture/platforms.md) está a situação de cada função nas duas plataformas (em chinês).

## Plugins

Se falta algo na ilha, você mesmo pode adicionar. Um plugin é uma pasta: um manifesto e um programa que a ilha inicia (um script de PowerShell, um exe ou um script de Node.js). Os plugins só enviam dados; a ilha desenha as páginas, a barra recolhida e as configurações a partir de modelos, então eles combinam com o resto da ilha.

```sh
npm create fuyu-plugin@latest
```

- **Instale um pronto**: em Configurações → Loja de plugins na ilha, ou dê antes uma olhada na [loja de plugins do site](https://fuyu.ing/plugins/).
- **Crie o seu**: o [início rápido](../plugins/quickstart.md) leva você do zero a um plugin funcionando em cerca de uma hora; a [documentação de plugins](../plugins/README.md) cobre todo o resto (ambos em chinês).
- **Compartilhe**: publique na [loja de plugins](https://github.com/TixXin/fuyu-plugins) ou use só no seu computador; os passos estão em [publicar](../plugins/publish.md) (em chinês).

## Compilar a partir do código-fonte

- **Windows**: você precisa de Windows 10/11, Node.js, pnpm, Rust, Visual Studio C++ Build Tools e WebView2 Runtime.
- **macOS**: você precisa de macOS 15 ou posterior, das ferramentas de linha de comando do Xcode (`xcode-select --install`), Node.js, pnpm e Rust.

```sh
git clone https://github.com/TixXin/fuyu.git
cd fuyu
pnpm install
pnpm tauri dev      # modo de desenvolvimento
pnpm tauri build    # gerar os instaladores
```

Tecnologias: Tauri 2, React 19 + TypeScript e Rust. Os lançamentos e as atualizações dentro do app estão descritos em [docs/features/updater.md](../features/updater.md) (em chinês).

## Como contribuir

<a href="https://fuyu.ing/logo/"><img src="../assets/logo-placeholder.svg" alt="Um espaço vazio com borda pontilhada: o Fuyu ainda procura um logo" width="88" height="88" align="right"></a>

O Fuyu é feito por todos nós, e tem lugar para você:

- **Relate problemas e ideias**: abra uma [issue](https://github.com/TixXin/fuyu/issues) e conte o que está atrapalhando ou o que você gostaria de ter.
- **Mude código, documentação ou traduções**: abra um pull request. O [CONTRIBUTING.md](../../CONTRIBUTING.md) explica como fazer e quais verificações rodar antes; o [AGENTS.md](../../AGENTS.md) explica como o código está organizado (em chinês).
- **Crie um plugin**: não precisa mexer na ilha; quando estiver pronto, publique na [loja de plugins](https://github.com/TixXin/fuyu-plugins).
- **Desenhe um logo**: o Fuyu ainda não tem um logo oficial e a [chamada](https://fuyu.ing/logo/) continua aberta; o espaço vazio à direita está esperando por ele.
