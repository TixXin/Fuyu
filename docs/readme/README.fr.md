## Qu'est-ce que c'est ?

Fuyu (浮屿, « îlot flottant ») est une île flottante légère, sans bordure et toujours au premier plan. Elle reste repliée en haut de l'écran, se déploie quand vous en avez besoin et se replie d'elle-même ensuite. Ce que vous utilisez tous les jours est sur l'île : plus besoin de changer de fenêtre juste pour jeter un coup d'œil.

## Consommation de ressources

Repliée, au repos et sans musique (réglages par défaut, sans plugins) :

| | Mesuré |
|---|---|
| CPU | Environ **10 %** d'un cœur (environ 0,5 % du total sur une machine à 20 cœurs) |
| Mémoire | Environ **16 Mo** pour Fuyu lui-même |
| La page Agents qui actualise la liste des sessions chaque seconde | **0,1 %** d'un cœur |
| Chaque plugin PowerShell installé | Environ **60 Mo** de plus |

Méthode de mesure et données complètes : [idle-usage.md](../investigations/idle-usage.md) (en chinois).

## Premiers pas

1. **Téléchargez et installez** : récupérez l'installateur sur la page [Releases](https://github.com/TixXin/fuyu/releases/latest).
   - **Windows** : téléchargez le `_x64-setup.exe`. Les installateurs ne sont pas signés ; si SmartScreen affiche un avertissement, choisissez « Informations complémentaires → Exécuter quand même ».
   - **macOS** : dans la [liste des releases](https://github.com/TixXin/fuyu/releases), téléchargez le `_aarch64.dmg` de la version la plus récente qui en contient un (si la dernière version stable n'en a pas, cherchez-le dans la version de test située au-dessus) et faites glisser Fuyu dans Applications. Au premier lancement, ouvrez Réglages Système → Confidentialité et sécurité et cliquez sur « Ouvrir quand même » ; les étapes détaillées sont dans le [guide d'installation sur Mac](https://fuyu.ing/#mac-install).
2. **Déployez l'île** : survolez l'île en haut de l'écran avec le pointeur pour la déployer ; le bouton en forme d'engrenage ou l'icône de la zone de notification (sur Mac, l'icône de la barre des menus) ouvre les Paramètres. Sur Mac, le guide de bienvenue vous aide à activer les autorisations système nécessaires.
3. **Configurez une seule fois** : l'e-mail, la traduction et les agents IA doivent être configurés une fois dans les Paramètres. Voir [e-mail](../features/mail.md), [agents IA](../features/agent-status-hooks.md), [notifications QQ](../features/qq-notifications.md), [rappels WeChat](../features/wechat-reminders.md) et [alertes sur le téléphone](../features/cc-connect.md) (en chinois).

> [!NOTE]
> Fonctionne sous Windows 10 / 11 et macOS 15 ou ultérieur (Apple silicon). Sur Mac, il y a quelques différences avec Windows : QQ et WeChat n'affichent que le nombre de messages non lus, pas leur contenu, et le contrôle multimédia et la luminosité passent par des interfaces privées du système. [platforms.md](../architecture/platforms.md) indique l'état de chaque fonction sur les deux plateformes (en chinois).

## Plugins

S'il manque quelque chose à l'île, vous pouvez l'ajouter vous-même. Un plugin est un dossier : un manifeste et un programme que l'île lance (un script PowerShell, un exe ou un script Node.js). Les plugins n'envoient que des données ; l'île dessine les pages, la barre repliée et les réglages à partir de modèles, si bien qu'ils ont le même style que le reste de l'île.

```sh
npm create fuyu-plugin@latest
```

- **Installez-en un tout prêt** : depuis Paramètres → Marché de plugins dans l'île, ou jetez d'abord un œil au [marché de plugins du site web](https://fuyu.ing/plugins/).
- **Écrivez le vôtre** : le [démarrage rapide](../plugins/quickstart.md) vous mène de zéro à un plugin fonctionnel en une heure environ ; la [documentation des plugins](../plugins/README.md) couvre tout le reste (en chinois).
- **Partagez-le** : publiez-le sur le [marché de plugins](https://github.com/TixXin/fuyu-plugins) ou gardez-le pour votre propre ordinateur ; les étapes sont dans [publier](../plugins/publish.md) (en chinois).

## Compiler depuis les sources

- **Windows** : il faut Windows 10/11, Node.js, pnpm, Rust, Visual Studio C++ Build Tools et WebView2 Runtime.
- **macOS** : il faut macOS 15 ou ultérieur, les outils de ligne de commande Xcode (`xcode-select --install`), Node.js, pnpm et Rust.

```sh
git clone https://github.com/TixXin/fuyu.git
cd fuyu
pnpm install
pnpm tauri dev      # mode développement
pnpm tauri build    # générer les installateurs
```

Technologies : Tauri 2, React 19 + TypeScript et Rust. Les versions et les mises à jour intégrées à l'app sont décrites dans [docs/features/updater.md](../features/updater.md) (en chinois).

## Contribuer

<a href="https://fuyu.ing/logo/"><img src="../assets/logo-placeholder.svg" alt="Un emplacement vide au contour en pointillés : Fuyu cherche encore un logo" width="88" height="88" align="right"></a>

Fuyu se construit à plusieurs, et il y a une place pour vous :

- **Signalez des problèmes et des idées** : ouvrez une [issue](https://github.com/TixXin/fuyu/issues) et dites-nous ce qui vous gêne ou ce que vous aimeriez avoir.
- **Modifiez le code, la documentation ou les traductions** : ouvrez une pull request. [CONTRIBUTING.md](../../CONTRIBUTING.md) explique comment faire et quelles vérifications lancer avant ; [AGENTS.md](../../AGENTS.md) explique comment le code est organisé (en chinois).
- **Écrivez un plugin** : pas besoin de toucher à l'île ; une fois prêt, publiez-le sur le [marché de plugins](https://github.com/TixXin/fuyu-plugins).
- **Dessinez un logo** : Fuyu n'a pas encore de logo officiel et l'[appel à propositions](https://fuyu.ing/logo/) reste ouvert ; l'emplacement vide à droite l'attend.
