## Was ist das?

Fuyu (浮屿, „schwebende Insel“) ist eine leichte, rahmenlose Insel, die immer über allen anderen Fenstern schwebt. Sie bleibt eingeklappt oben am Bildschirm, klappt auf, wenn du sie brauchst, und zieht sich danach von selbst wieder ein. Was du jeden Tag brauchst, steckt in der Insel, also musst du nicht für einen kurzen Blick das Fenster wechseln.

Aussehen, Größe, Einklappverhalten, Tastenkürzel und jede einzelne Funktion stellst du im Einstellungsfenster ein, und die App aktualisiert sich selbst. Alle deine Daten bleiben auf deinem Rechner.

## Ressourcenverbrauch

Eingeklappt, im Leerlauf und ohne Musik (Standardeinstellungen, keine Plugins):

| | Gemessen |
|---|---|
| CPU | Etwa **10 %** eines Kerns (etwa 0,5 % insgesamt auf einem Rechner mit 20 Kernen) |
| Arbeitsspeicher | Etwa **16 MB** für Fuyu selbst |
| Agenten-Seite, die die Sitzungsliste jede Sekunde aktualisiert | **0,1 %** eines Kerns |
| Jedes installierte PowerShell-Plugin | Etwa **60 MB** zusätzlich |

Wie gemessen wurde und alle Daten: [idle-usage.md](../investigations/idle-usage.md) (auf Chinesisch).

## Erste Schritte

1. **Herunterladen und installieren**: Lade den Installer unter [Releases](https://github.com/TixXin/fuyu/releases/latest) herunter.
   - **Windows**: Lade die `_x64-setup.exe` herunter. Die Installer sind nicht codesigniert; wenn SmartScreen eine Warnung zeigt, wähle „Weitere Informationen → Trotzdem ausführen“.
   - **macOS**: Lade in der [Release-Liste](https://github.com/TixXin/fuyu/releases) die `_aarch64.dmg` der neuesten Version herunter, die eine hat (fehlt sie bei der letzten stabilen Version, findest du sie bei der Testversion darüber), und zieh Fuyu in den Ordner Programme. Öffne beim ersten Mal Systemeinstellungen → Datenschutz & Sicherheit und klick auf „Dennoch öffnen“; die einzelnen Schritte stehen in der [Installationsanleitung für den Mac](https://fuyu.ing/#mac-install).
2. **Insel aufklappen**: Fahr mit dem Mauszeiger über die Insel oben am Bildschirm, um sie aufzuklappen; das Zahnrad oder das Symbol im Infobereich der Taskleiste (auf dem Mac das Symbol in der Menüleiste) öffnet die Einstellungen. Auf dem Mac führt dich die Einführung durch die nötigen Systemberechtigungen.
3. **Einmal einrichten**: E-Mail, Übersetzung und KI-Agenten musst du einmalig in den Einstellungen einrichten. Siehe [E-Mail](../features/mail.md), [KI-Agenten](../features/agent-status-hooks.md), [QQ-Benachrichtigungen](../features/qq-notifications.md) und [WeChat-Hinweise](../features/wechat-reminders.md) (auf Chinesisch).

> [!NOTE]
> Läuft unter Windows 10 / 11 und macOS 15 oder neuer (Apple Silicon). Auf dem Mac gibt es ein paar Unterschiede zu Windows: QQ und WeChat zeigen nur die Zahl der ungelesenen Nachrichten, nicht deren Inhalt, und Mediensteuerung und Helligkeit nutzen private Systemschnittstellen. In [platforms.md](../architecture/platforms.md) steht der Stand jeder Funktion auf beiden Plattformen (auf Chinesisch).

## Plugins

Fehlt der Insel etwas, kannst du es selbst ergänzen. Ein Plugin ist ein Ordner: ein Manifest und ein Programm, das die Insel startet (ein PowerShell-Skript, eine exe oder ein Node.js-Skript). Plugins liefern nur Daten; Seiten, die eingeklappte Leiste und die Einstellungen zeichnet die Insel anhand von Vorlagen, deshalb sehen sie aus wie der Rest der Insel.

```sh
npm create fuyu-plugin@latest
```

- **Ein fertiges installieren**: über Einstellungen → Plugin-Marktplatz in der Insel, oder schau dich vorher im [Plugin-Marktplatz auf der Website](https://fuyu.ing/plugins/) um.
- **Ein eigenes schreiben**: Der [Schnellstart](../plugins/quickstart.md) bringt dich in etwa einer Stunde von null zu einem laufenden Plugin; die [Plugin-Dokumentation](../plugins/README.md) deckt alles Weitere ab (beide auf Chinesisch).
- **Teilen**: Veröffentliche es im [Plugin-Marktplatz](https://github.com/TixXin/fuyu-plugins) oder nutze es nur auf deinem Rechner; die Schritte stehen unter [Veröffentlichen](../plugins/publish.md) (auf Chinesisch).

## Aus dem Quellcode bauen

- **Windows**: Du brauchst Windows 10/11, Node.js, pnpm, Rust, die Visual Studio C++ Build Tools und die WebView2 Runtime.
- **macOS**: Du brauchst macOS 15 oder neuer, die Xcode-Befehlszeilentools (`xcode-select --install`), Node.js, pnpm und Rust.

```sh
git clone https://github.com/TixXin/fuyu.git
cd fuyu
pnpm install
pnpm tauri dev      # Entwicklungsmodus
pnpm tauri build    # Installer erstellen
```

Technik: Tauri 2, React 19 + TypeScript und Rust. Versionen und Updates in der App sind in [docs/features/updater.md](../features/updater.md) beschrieben (auf Chinesisch).
