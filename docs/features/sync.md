# 跨设备同步

浮屿支持在多台 Windows / macOS 设备之间同步常用数据与配置，无需官方云账号。可在 **设置 → 同步** 中启用并管理。同步契约与文件布局细则见 [contracts.md](../architecture/contracts.md)「跨设备同步引擎」，历史规划见 [cross-device-sync-plan.md](../architecture/history/cross-device-sync-plan.md)。

## 同步方式

- **共享文件夹**：选择一个本地同步文件夹（如 iCloud Drive、OneDrive、Dropbox、坚果云或 Syncthing 同步目录），每台设备只在 `fuyu-sync/devices/<deviceId>/` 下写入自己的状态文件，避免多机互相覆盖。
- **WebDAV**：填写兼容 WebDAV 的服务地址、用户名与密码（支持先测试连接），密码存入系统凭据管理器 / macOS 钥匙串（`com.tixxin.fuyu.sync` / `webdav-password`），不写入明文配置文件。
- **局域网直连**（C96）：同一个网络里的两台电脑直接互传，不经过网盘或服务器，见下一节。

## 局域网直连

- **配对**：两台都在「同步方式」里选「局域网」并启用。一台点「显示配对码」（6 位数字，2 分钟有效，输错 5 次作废），另一台填它的地址（同网段的浮屿会出现在「附近的浮屿」里，可一键填入；也可手填 `IP` 或 `IP:端口`，默认端口 47321）和配对码。双方用 SPAKE2 以配对码交换密钥，再互相确认对方证书指纹和设备 id，两边都对上才记下对方；配对码本身不在网络上传，偷听也无法离线猜。
- **传输**：每台第一次启用时生成一张自签 Ed25519 证书，私钥存凭据管理器 / 钥匙串（`com.tixxin.fuyu.sync` / `lan-identity`）。之后的连接都是双向 TLS 1.3，两边只认配对表里的证书指纹。对端只能读本机自己那一份设备目录，不能写本机任何东西。
- **同步**：每台把自己的数据写在本机的 `sync-lan/`，每轮开始时从在线的已配对设备取它们自己的那一份到 `sync-lan-cache/`，然后照常合并；对方不在线时用上次取到的。本机写了新数据会通知对方立即同步，配对的设备在局域网上出现时也会立即同步一轮，平时每 5 分钟一轮。局域网直连本身已加密，不再提供端到端加密。
- **剪贴板互传**（默认关，两台都要打开）：本机复制的文字发到已配对的设备，进对方的剪贴板历史，来源显示为发送方的设备名，不写进对方的系统剪贴板。只发文字（最多 1 MB）；带系统隐私标记、像密码或密钥的、来自远程桌面或其他设备的都不发，对方也不收像密钥的内容。
- **系统提示**：Windows 第一次监听时会弹防火墙提示，要点「允许」并勾选专用网络；网络被设成「公用」或路由器开了 AP 隔离时连不上。Mac 第一次连接会询问是否允许访问本地网络（`NSLocalNetworkUsageDescription`、`NSBonjourServices: _fuyu._tcp`），拒绝后到「系统设置 → 隐私与安全性 → 本地网络」打开；这个权限只有签名的正式包才会弹（G1.12）。
- **关闭**：换成别的同步方式或停止同步时，端口和局域网广播一起关掉。移除一台已配对设备时，它的缓存也一起删掉。

## 同步内容与合并规则

- **默认开启类别**：待办与每日笔记（`todos`）、常用短语（`snippets`）、链接书签（`links`）、通用设置（`settings`，按 `settings_whitelist.json` 筛选，剔除屏幕尺寸与本机快捷键等设备相关字段）、样式预设（`presets`）。
- **可选类别与分组**：剪贴板文字收藏（`clipFavorites`，默认关闭，且严格排除隐私、打码与密钥内容）；设置中还支持按可选组开关同步（翻译服务商、截图设置、Agent 音效/推送、邮箱账号不含密钥、岛屿布局、更新通道）。
- **市场插件名单**：已安装的第三方市场插件列表与非密钥配置（`fuyu-market-plugins`）随设置同步；在新设备上不会静默自动安装或改写配置，而是在插件页提示用户一键确认装回。
- **冲突与安全防线**：按条目以混合逻辑时钟（HLC）后写者赢，删除留 90 天墓碑；每日笔记双端并发修改时保留两端文本并用分隔线拼接；当远端触发大比例删除或远端被清空时，同步会暂停并要求用户在界面显式确认，防止误删扩散。

## 端到端加密（可选）

- 可为同步目录启用端到端加密：设置口令后生成随机 32 字节数据密钥，以 Argon2id 派生密钥并包裹数据密钥写入 `meta.json`，全部远端设备文件以 XChaCha20-Poly1305 加密。
- 同时生成 `FUYU-` 格式恢复密钥（支持一键复制不进剪贴板历史，或保存到下载目录），新设备输入口令或恢复密钥即可解锁；本地数据密钥保存在系统凭据管理器 / 钥匙串中。

## 实现位置

- Rust 同步引擎、WebDAV 客户端与加密模块：`src-tauri/src/sync/`；局域网直连在 `src-tauri/src/sync/lan/`（身份与配对 `identity.rs`、`pairing.rs`、`peers.rs`，传输 `tls.rs`、`wire.rs`、`server.rs`、`client.rs`，发现 `discovery.rs`，同步后端 `store.rs`，剪贴板 `clip.rs`）。
- 前端设置页与状态接口：`src/features/sync/`。
