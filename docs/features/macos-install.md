# 在 Mac 上安装浮屿

这份教程写给第一次在 Mac 上装浮屿的人，照着一步步做就行，大约 3 分钟。

浮屿的 Mac 版还没有经过苹果的付费认证，所以**第一次打开**时系统会拦一下，需要你手动点一次「仍要打开」。这是正常现象，只需要做这一次，之后打开和更新都不会再拦。

## 开始之前：确认你的 Mac 能装

点屏幕左上角的苹果图标 → 「关于本机」，看两行：

- **芯片**：写着 Apple M1、M2、M3、M4 这类就可以。写着 Intel 的 Mac 装不了。
- **macOS**：版本号要是 15 或更高。低于 15 的话，先在「系统设置 → 通用 → 软件更新」里升级系统。

## 第 1 步：下载安装包

1. 打开[浮屿的下载页](https://github.com/TixXin/fuyu/releases)。
2. 页面从上到下是一个个版本，最新的在最上面。找到最上面那个版本，点开它下面的「Assets」。
3. 在列表里找名字以 `_aarch64.dmg` 结尾的文件，例如 `Fuyu_0.3.8_aarch64.dmg`，点它下载。
4. 如果最上面那个版本的列表里没有 `.dmg` 文件，就往下看下一个版本。

浏览器问「是否允许下载」时点「允许」。下载好的文件在「下载」文件夹里。

## 第 2 步：把浮屿放进「应用程序」

1. 双击刚下载的 `.dmg` 文件，会弹出一个小窗口，里面有 Fuyu 的图标和一个「应用程序」文件夹。
2. 按住 Fuyu 的图标，拖到旁边的「应用程序」文件夹上再松手。
3. 等复制完成，关掉这个小窗口。

## 第 3 步：第一次打开，让系统放行

这一步最容易卡住，按顺序做：

1. 打开「访达」，点左边的「应用程序」，找到 Fuyu，双击它。
2. 系统会弹出提示，说无法验证这个应用。点「完成」。**不要点「移到废纸篓」。**
3. 点屏幕左上角的苹果图标 → 「系统设置」→ 左边的「隐私与安全性」。
4. 把右边的页面一直往下拉到底，会看到一行「已阻止打开 Fuyu」，点它旁边的「仍要打开」。
5. 按提示输入你的开机密码，或者用指纹确认。
6. 回到「应用程序」，再双击一次 Fuyu，在弹窗里点「打开」。

做完以后，屏幕顶部正中会出现一座黑色的小岛，浮屿就装好了。以后直接双击就能打开。

## 第 4 步：跟着引导开权限

第一次打开时，浮屿会带你走一遍新手引导，其中有一步「给浮屿开几个权限」。它会按你选的功能列出要开的权限，点「去允许」，在系统设置里把 Fuyu 旁边的开关打开就行。

| 权限 | 不开的话哪些功能用不了 |
|---|---|
| 辅助功能 | 从剪贴板历史贴回原来的窗口、划词翻译、QQ 和微信的未读数 |
| 屏幕录制 | 截图、贴图、长截图。打开开关后要重开一次浮屿才生效，引导里有「重开浮屿」按钮 |
| 自动化 | 点 AI 会话跳到终端里对应的标签页。第一次用到时系统会自己问，点「允许」 |

权限可以先不开，以后在浮屿的「设置 → 通用 → 系统权限」里随时补上。

## 怎么用

- 把鼠标移到屏幕顶部的小岛上，它会展开；移开后自己收回去。
- 屏幕右上角的菜单栏里有浮屿的小图标，点它可以打开设置或退出。

## 遇到问题

**在「隐私与安全性」里找不到「仍要打开」**
这个按钮只在你刚尝试打开过 Fuyu 之后才出现，大约保留一小时。回到「应用程序」再双击一次 Fuyu，点「完成」，然后马上回系统设置里找。

**不小心点了「移到废纸篓」**
没关系，从第 2 步重新拖一次就行；安装包还在「下载」文件夹里。

**下载页里找不到 `.dmg` 文件**
往下多看一两个版本。有的版本只有 Windows 的安装包（`.exe`、`.msi`），Mac 的安装包名字里带 `aarch64.dmg`。

**打开后没看到小岛**
小岛在屏幕顶部正中。有刘海的 Mac 上，它贴着刘海。如果在用全屏应用，先退出全屏看看。

**以后更新会不会又被拦**
不会。浮屿会自己检查更新（设置 → 关于），更新装好后不用再点「仍要打开」，已经开过的权限也都保留。

## 卸载

先退出浮屿（点菜单栏里的浮屿图标 → 退出），再把「应用程序」里的 Fuyu 拖进废纸篓。

你的待办、笔记等数据存在个人文件夹下一个叫 `.fuyu` 的隐藏文件夹里。想连数据一起删掉：打开「访达」，按 Command + Shift + G，输入 `~/.fuyu` 回车，把这个文件夹拖进废纸篓。

## 给熟悉终端的人

把 Fuyu 拖进「应用程序」之后，可以用下面这一行代替第 3 步：

```bash
xattr -dr com.apple.quarantine /Applications/Fuyu.app
```

macOS 15 起，按住 Control 点「打开」已经不能跳过放行。Mac 版用的是浮屿自己的签名证书，权限授权跟着这个证书走，所以更新后会保留。
