# 在 Mac 上安装浮屿

适用于 macOS 15 及以上、Apple 芯片（M 系列）的 Mac。Intel Mac 不支持（决定 M3）。

浮屿的 Mac 版目前没有苹果开发者账号的签名和公证，用的是浮屿自己的证书，所以**第一次打开**要手动放行一次；之后应用内自动更新照常，不用再放行。

## 安装

1. 从 [Releases](https://github.com/TixXin/fuyu/releases/latest) 下载 `Fuyu_<版本>_aarch64.dmg`。
2. 打开 dmg，把「Fuyu」拖进「应用程序」。
3. 在「应用程序」里双击 Fuyu。系统会提示「无法验证开发者」，点「完成」（不要点「移到废纸篓」）。
4. 打开「系统设置 → 隐私与安全性」，拉到最下面，在「已阻止打开 Fuyu」旁点「仍要打开」，按提示输入登录密码。
5. 再打开一次 Fuyu，弹窗里点「打开」。以后就能直接打开了。

macOS 15 起，按住 Control 点「打开」已经不能跳过这一步。

会用终端的话，也可以在拖进「应用程序」后运行下面这一行代替第 3–5 步：

```bash
xattr -dr com.apple.quarantine /Applications/Fuyu.app
```

## 第一次使用：系统权限

新手引导里有一步「给浮屿开几个权限」，按你选的功能列出要开的权限；以后也能在「设置 → 通用 → 系统权限」里看到每项是否已允许、一键打开系统设置的对应页。

| 权限 | 用在哪 | 说明 |
|---|---|---|
| 辅助功能 | 剪贴板贴回原来的窗口、划词翻译、QQ / 微信未读数 | 打开开关就生效 |
| 屏幕录制 | 截图、贴图、长截图 | 打开开关后要**重开浮屿**才生效，引导和设置里有「重开浮屿」按钮 |
| 自动化 | 点 AI 会话切到 Terminal / iTerm2 的对应标签页；系统媒体服务不可用时控制 Apple Music / Spotify | 第一次用到时系统会问 |

这些授权跟着浮屿的签名证书走，更新后会保留。

## 更新

浮屿会自己检查更新（设置 → 关于）。更新包由浮屿自己下载和校验，装好后不用再「仍要打开」。

## 卸载

退出浮屿后，把「应用程序」里的 Fuyu 拖进废纸篓。数据在 `~/.fuyu`，不想保留就一起删掉。
