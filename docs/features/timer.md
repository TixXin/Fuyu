# 计时器

> 任务：[C58](/docs/tasks/C/C58.md)，issue #228。内置插件 `focusd.timer`，默认关闭，在 **设置 → 插件扩展** 里打开。

「10 分钟后提醒我」这种临时计时，以及秒表。番茄钟示例插件（`plugins/examples/dev.focusd.pomodoro`）是给插件开发者看的示例，和它并存、互不影响。

## 怎么用

- 打开插件后岛上多一个「计时器」页（头部的计时器图标，`Alt+数字` 也能切过去）。
- 全局快捷键 `Ctrl+Alt+K`（插件命令「新建计时」，可在插件详情里改）：展开岛、打开计时器页，光标落在输入框。
- 输入时长按 Enter 开始倒计时。认得的写法：`10`（不写单位按分钟）、`2.5`、`10m`、`1h30m`、`90s`、`1:30`（分:秒）、`1:00:00`（时:分:秒）、`10 分钟`、`1小时30分`、`45秒`。最短 1 秒，最长 24 小时，读不懂时输入框下面提示。
- 输入框旁的秒表按钮开一个秒表。
- 最多同时 12 个计时，每个可以暂停、继续、取消。

## 收起条

有计时在走时，收起条右侧出现一个小块：显示最近到点的那个倒计时的剩余时间；没有在走的倒计时就显示正在走的秒表。点它打开计时器页。项目 id 是 `timer`，可以在 外观 → 收起条 里换位置或隐藏。

## 到点

- 岛上提示「10:00 的计时到了」（几个同时到点时写还有几个），响一声（插件设置「到点响一声」，默认开，用 Agent 提示音里的「完成」）。
- 提示上有「再加 5 分钟」和「知道了」；计时器页里到点的那一行也一样。
- 关掉岛屿再打开，倒计时按到点的实际时间接着走；关着的时候已经到点的，打开后马上提醒。

## 数据

计时存在 `localStorage` 的 `fuyu-timers`（只在本机，不进设置备份）。逻辑在 `src/features/timer/timers.ts`（纯函数，单元测试 `tests/unit/timer.test.mjs`），状态和提醒在 `store.ts`，回归页 `tests/regression/timer.tsx`。
