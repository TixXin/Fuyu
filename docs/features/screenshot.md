# 截图

浮屿内置的区域截图：冻结屏幕、选区或选中窗口、标注，然后复制、保存、贴到屏幕上、识别文字、翻译，或者从岛上发给 Agent。默认关着，在「设置 → 功能 → 截图」打开。分步计划和设计取舍见 [screenshot-plan.md](../architecture/screenshot-plan.md)，任务是 [C41](../tasks/C/C41.md)。

## 怎么打开

- 快捷键（默认，可以改或关掉）：

  | 快捷键 | 做什么 |
  |---|---|
  | `Ctrl+Shift+1` | 截图：选好区域后出现标注工具栏 |
  | `Ctrl+Shift+2` | 截图并复制：松开鼠标就复制，不出工具栏 |
  | `Ctrl+Shift+3` | 截图并识别文字：文字复制到剪贴板，岛上显示 |
  | `Ctrl+Shift+4` | 截图并翻译：识别后交给快捷翻译 |
  | `Ctrl+Shift+5` | 长截图：选好要滚动的区域，按空格或控制条上的 ▶ 开始往下滚并拼成一张长图，也可以自己滚；控制条可以暂停、保存、完成或取消 |
  | `Ctrl+Shift+7` | 截取鼠标所在的整个显示器 |
  | （不设） | 隐藏或显示所有贴图，全局可用 |

  `Ctrl+Shift+数字` 时，右侧小键盘的数字也可以（要开着 NumLock）。
- 「按 PrintScreen 截图」打开后，单独按 PrintScreen 打开浮屿的截图；`Alt+PrintScreen` 等组合键仍归 Windows。
- 托盘菜单的「截图」。
- 岛展开后右上角的剪刀按钮：岛先收起，再开始截图。

## 截图时

- 屏幕先冻结；鼠标下的窗口和控件自动高亮，单击选中，滚轮换到外层或内层；也可以拖动选区，拖边角调整。
- 放大镜显示坐标、选区尺寸和颜色，按 `C` 复制颜色值。
- 工具栏：矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克、序号，撤销 / 重做；然后是复制、保存、贴图、识别文字、翻译、取消。
- 长截图：工具栏里方框加剪刀（下边虚线）的按钮（或 `Ctrl+Shift+5`）。截图界面不退：选区外照样压暗、选区四边的辅助线和虚线框都在，框里换成实时的页面；截图层对截屏隐身、对鼠标穿透，只有选区旁的控制条能点。开始后不自动滚：控制条提示按空格或 ▶ 开始，等待时自己在框里滚动也照样拼上。开始后浮屿在选区中间往下滚，每屏等画面停稳再按重叠部分拼接，固定在顶部、底部的栏只留一份；每次挪得太少就自动加大步长，接不上就往回滚一点并减半步长。控制条上有实时高度和屏数、最新拼上的那一截预览、2 万像素的进度条，以及开始 / 暂停 / 继续（空格）、取消（`Esc`）、保存（`Ctrl+S`）、完成并复制（`Enter`）。暂停时可以自己在框里滚动，浮屿照样拼上；滚到底会自动停下等你点完成。长图像复制一样进剪贴板和截图历史，标注不会带进长图。
- 自动打码：工具栏的眼睛按钮先识别选区里的文字，把邮箱、手机号（含 +86 和国际号码）、IPv4 / IPv6 地址和密钥（`sk-`、`ghp_`、`AKIA` 这类前缀，JWT，`password: `、`密码：` 这类标签后面的值，32 位以上大小写字母和数字混合的长串）各盖一块马赛克。不用标注工具时点一块就取消它，`Ctrl+Z` 从最后一块往前撤。识别全在本机（Windows 自带的文字识别），认不出的文字不会被打码，发出去前自己再看一眼。
- 键盘：`Enter` 复制，`Ctrl+S` 保存，`T` 贴图，`Esc` 取消，`Ctrl+Z` / `Ctrl+Y` 撤销 / 重做。

## 截完之后

- **复制**：同时放进位图、PNG 和文件引用，聊天软件、画图、Word、终端都能贴；剪贴板历史里记成一张图片。
- **保存**：写到「保存位置」（完整路径，例如 `D:\截图`），留空就是「图片 › 浮屿截图」；文件名带时间。
- **贴图**：置顶的小窗，可拖动，滚轮缩放，`Ctrl+滚轮` 调透明度，右键菜单里有复制、保存、鼠标穿透、关闭；在贴图或岛上按 `T` 隐藏 / 显示所有贴图。
- **岛上的截图提示**：复制或保存后，收起的岛条上像音量、耳机提示那样显示缩略图和「截图已复制」，右边是三个按钮（默认 3 秒，可设 3–30 秒或不显示，鼠标停在上面不收起）：拖到别的应用、放进文件中转、发给 Agent。只有一个本机会话时直接发给它，多个时选一个：切到会话的终端，贴进带引号的 PNG 路径（Claude Code 在 Windows 上读剪贴板位图不可靠，路径一直可靠）。

## 截图历史

复制、保存、贴到屏幕上的截图都会留一份，在岛上的「截图历史」页（截图模块开着时出现在页面按钮里）：新的在前，点一下复制，拖出去当文件用，鼠标停上去有「贴到屏幕上」和「删除」。最多 100 张，保留天数在设置里选（1、7、30、90 天，默认 7 天）。

## 设置

「设置 → 功能 → 截图」：模块开关；每个快捷键可以重新录、恢复默认或关掉，和浮屿其他快捷键撞了会当场提示，被别的程序占用或写法不对的会在那一行标出来；「按 PrintScreen 截图」；显示辅助线；保存位置；岛上的截图卡片停留时间。所有快捷键也在「设置 → 快捷键」里。

已知会撞的：Excel 的 `Ctrl+Shift+1`–`6` 是数字格式，个别输入法用 `Ctrl+Shift+数字` 切方案；遇到时在设置里换掉。

## 数据

截图只在本机。复制、保存、贴图的截图各存一份 PNG 在家目录的 `screenshots/`（截图历史），只留最近 100 张、设置的天数内的，启动时清理；冻结的画面只在内存里。不上传、不进日志。设置在 `localStorage` 的 `fuyu-screenshot-settings`（会进设置备份）。见 [data-storage.md](../architecture/data-storage.md) 和 [contracts.md](../architecture/contracts.md)。
