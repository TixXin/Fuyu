每一档在应用里是什么

档做法估计 GPU 开销（岛这么大）应用里能做到吗
1A 静态几层固定渐变 + 主题色光斑，和现在的思路一样，只是颜色更饱满无只在展开收起时重绘能，Win / Mac 一样
1B 慢流动4 团径向渐变色块，只用 transform 慢慢漂（19–31 秒一个来回）很低合成器移动图层，不重绘能，推荐作默认
1C 极光 + 油膜边1B + 沿边转动的虹彩细边（@property 角度 + conic-gradient）+ 一道缓慢扫过的光泽低每帧重绘 1.5px 的边和光泽层能
1D 着色器WebGL 噪声流体（domain warp），限 30 fps中每个岛一个 GPU 上下文，GPU 不再空闲能，但不建议作默认；掉上下文时退回 1B
2A 磨砂透出半透明底 + backdrop-filter: blur saturate低网页里是这一块的模糊；原生材质时由系统付Windows 不能（材质铺满整个舞台窗口，见调研 §2）；Mac 要自己加 effect view
2B + 边缘折射2A + SVG feDisplacementMap 位移图（按岛的形状算）+ 红绿蓝三通道错开的色散中–高背后一变或尺寸一变整块重算不能：只能折射岛自己的内容；Mac 的 WKWebView 不支持
2C + 高光与液体形变2B + 跟鼠标的镜面高光和边缘亮线 + 展开收起时弹簧回弹中–高形变时每帧重算位移图高光和形变能（不依赖背后）；透出和折射不能

推荐

  • 做方向 1，默认 1B「慢流动」，颜色跟主题色，可选跟封面；1C 作为更花的一档。1A 留给「减少动态效果」和游戏免打扰时的静止画面。
  • 从方向 2 只拿不依赖背后的部分叠上去：跟鼠标的镜面高光、边缘亮线、展开收起的弹簧回弹（2C 里打开看）。
  • 「真透出桌面」不在本任务做：Windows 原生材质铺满整个透明舞台，当初就是因此关掉的；Mac 可以单独开个实验任务试 NSVisualEffectView / macOS 26 的系统液态玻璃。
  • 贴边收起、游戏免打扰、窗口隐藏、减少动态效果时一律暂停（停在当前帧，不跳），点上面的「状态」看效果。
