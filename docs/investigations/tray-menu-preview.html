托盘 / 菜单栏卡片：三版内容挑一版

左键点托盘图标弹浮屿自己的卡片，右键弹原生精简菜单（显示 / 隐藏岛屿、设置、退出）。深浅色跟系统，强调色跟浮屿的主题色。计划见 docs/investigations/tray-menu-plan.md。

A 入口型常用功能一眼都在、最接近参考图，点一下就到；代价是卡片最高，歌、会议、Agent 这些状态还得回岛上看。
B 状态型不展开岛就能看正在放的歌、下一个会议、Agent 在跑几个并顺手操作；代价是高度随情况变，功能按钮少，剪贴板只能靠快捷键。
C 精简型最小最快，和现在的原生菜单最像，只多一排按钮，做起来和维护都最省；代价是比原生菜单多不了多少东西。
