Alt 拖拽 / 改尺寸提示预览

先点一下页面让它拿到键盘，然后按住 Alt 把鼠标移到岛屿上（也可以点"模拟按住 Alt"）。展开面板的左边、右边、下边和两个下角可以拖动改尺寸，收起的岛屿只有左右两边能改宽度，其余地方是移动。默认是悬浮展开：不按 Alt 移上去 300ms 后展开；按住 Alt 移上去不会展开。

午饭

要点

  • 线条画在离边框 4px 的同心轮廓上，落在 12px 的拖动热区里：看到线的地方就是能拖的地方。顶边不能拖，所以没有线。
  • 改宽度时岛屿保持居中，拖一边、两边一起动，所以光标那一侧全亮，另一侧半亮。拖下角时同样，另一个下角半亮。
  • 下角的 L 形线条沿圆角走，并向两边各延伸 10px。预览里整个下角（圆角半径范围内的热区）都算"同时改宽高"；现在 Rust 只认角上 12×12 的小方块，大部分圆弧会被判成只改宽度，实现时要一起放大。
  • 左下角用 nesw-resize 光标，右下角用 nwse-resize。现在两个角都是 nwse-resize，左下角的方向是反的。
  • 拖动时线条保持高亮，岛屿下方显示当前尺寸。松开 Alt 不会中断正在进行的拖动。
  • 悬浮展开：按住 Alt 移上去、或在等待展开时按下 Alt，这一次都不展开；松开 Alt 也不展开，要移出再移回来才重新计时。展开的面板在按住 Alt 时不会收起。
