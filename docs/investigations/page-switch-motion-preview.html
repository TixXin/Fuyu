换页动效：面板、设置窗口、设置页的标签

三处换页现在各管各的：岛的面板只淡入（240ms）；设置窗口换页时整页各块一个接一个上移 6px 淡入；设置页的标签下划线直接跳过去，侧栏高亮条原地从短拉长。下面先是一个仿真的设置窗口，打开在 行为 → 展开，新的「切换动效」一组就在那里，改它会同时改这页所有演示；点侧栏、点标签就是实际效果。再往下是岛的面板实景，和所有效果并排轮播的一面墙。

4. 我的推荐

用户定的（2026-11-23）：都按推荐来，之后又把面板的默认也改成幕布（下表第一行的涟漪留作可选项）。会让文字跟着动的五种没有放进设置。

位置推荐为什么
岛的面板涟漪从点的那个页签或箭头扩散出去，一眼就知道「新页是从这里打开的」；文字不动，只是被一个圆形遮罩露出来。键盘、滑动翻页时从那一侧扩散，和箭头的方向一致。时长 280ms，比开合动画短，不拖沓。
设置窗口换页幕布（竖向）侧栏是竖的，往下点的页从下往上拉开、往上点的从上往下，边上一道强调色的亮线带出方向；文字不动，比现在「每块上移 6px、一块接一块」更利落，也顺手把现在违反规矩的上移去掉。
设置页的标签幕布（横向）+ 下划线伸缩下划线先伸到新标签、再把尾巴收过去（毛毛虫式），新内容同方向拉开。标签就在内容正上方，方向感最强。
侧栏高亮伸缩和标签下划线同一个手感：高亮块先拉长覆盖到新的一项，再收过去。
默认值都按上面推荐另外在下拉里放「轮播」（每次换一种，和小组件出场的默认一样）给喜欢新鲜感的人，不做默认：设置窗口里反复换页时风格一直变，会显得乱。

5. 细节

  • 连续快速翻页：上一段动画没播完又翻页时，立刻把上一段跳到结尾，从当前页开始播新的，不排队、不叠加。按住箭头（之前定的只翻一页）和滑动不会触发连播。
  • 方向：按页的先后算，往后翻是「下一个」方向。循环翻页从最后一页跳到第一页时按「往后」算，不反过来走一大圈。「跟着方向」关掉时，有方向的效果都从中间开始（幕布从中间往两边拉开，涟漪从中心扩散）。
  • 和开合动画分开：面板刚展开时不播换页动效，由开合动画负责；收起时也不播。只在面板已经打开、换到另一页时播。
  • 页面大小不一样时：有的页面板高度不同，外壳的高度过渡照旧，和换页动效同时跑；遮罩类效果按新页的大小算，不会露出空白。
  • 设置的搜索结果跳转：从搜索框点进某一项时，跳过去不播动效，直接定位、高亮那一行，免得等动画。
  • 减少动画：系统开了「减少动态效果」时，所有效果都换成淡入，下划线和高亮块直接跳。
  • 性能：遮罩（clip-path）、透明度和整页的位移都能交给合成器，不重排；「像素溶解」用一层 12×8 的小方块盖住再揭开，最多 96 个元素，动完就删。面板展开的性能约束（expansion-performance.md）只管开合那一下，换页不在里面。
  • 插件页、Fuyu 页：整页作为一块参与，不管页面里面怎么排；Fuyu 页自己的小组件出场动效只在面板刚展开时播，换页进来时不再叠一遍（否则两套动画打架）。要不要换页进来也播，由你定。
  • 设置项放哪：设置 → 行为 → 展开，「开合动画」「小组件出场」下面新加一组「切换动效」：面板换页、设置窗口换页、标签和侧栏、速度、跟着方向。每个下拉右边带一个小缩略图，选中就演一遍，点「试一下」再演。
