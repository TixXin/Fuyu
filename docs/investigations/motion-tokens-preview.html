动效档位前后对比（D85.4 第一段：src/windows/）

每一行左边是现在写死的曲线和时长，右边是并进档位后的样子，两边同时开始。点「全部重播」或单行的「重播」反复看，「慢放 4 倍」看清曲线差别。档位：曲线 --motion-ease (0.2, 0.8, 0.2, 1)、--motion-ease-out (0.22, 1, 0.36, 1)、--motion-ease-in-out (0.45, 0, 0.55, 1)；时长 120 / 160 / 240 / 420ms。

这一段共 35 个 CSS 文件、2 个 TS 文件。没动的：岛外壳开合（--island-motion-*，含玻璃的 bloom 和液态展开、侧栏淡出）、1s 以上的循环（呼吸、玻璃色块漂移）只换了曲线不换时长、匀速的 linear、新手引导里星星的回弹 (0.2, 0.9, 0.3, 1.5)（没有文字的装饰，留着并记进门禁白名单；要去掉回弹就说）。剪贴板预览的退场本来要并进 160ms，但 Rust 侧固定等 150ms 就隐藏窗口，所以落在 120ms。
