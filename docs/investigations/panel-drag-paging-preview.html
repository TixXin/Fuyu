① 边缘换页：停住翻页，甩过去立刻翻

  • 拖到左右边缘会亮起一道光，圆环开始转，转满就翻一页。停住不动就每隔一段时间再翻一页。
  • 快甩：快速甩到边上，跳过等待直接翻。只是路过边缘的话停留时间不够，不会误翻。
  • 探头：圆环转的时候，下一页先露出一条边，转满时再顺着滑过去。没翻成的话就弹回原处。
  • 最后一页往右停，圆环里会变成 ＋，转满就多出一页空白页，放进去就是新的一页。没放进去的话，松手后自动收掉。
  • 热区延伸到岛外面：甩出岛也算。真岛上要给窗口加 setPointerCapture，鼠标出了窗口还能收到移动事件。

② 页码点在拖动时变成缩略图

  • 平时只有几个页码点（当前页是长条），点一下就跳页。
  • 拿起组件后，页码点展开成各页的缩略图，用色块画出每页的排布，最后多一个 ＋ 新页。
  • 拖到缩略图上停一下就跳到那页（缩略图底下的进度条走满）；直接松手则把组件放进那一页（排满时挤走那页最后一个），当前页不动，提示条里有「撤销」和「去看看」。
  • 放进去会把别的组件挤到下一页时，缩略图上被挤走的那块变成橙色，提示条也会写出它会被挤到第几页。
  • 放在「上方」时，拖动期间页签栏让出位置给缩略图（页签和完成按钮淡出），松手后恢复；放在「下方」时，缩略图在底栏中间。

③ 全景、暂存架、键盘和滚轮

  • 全景：拖到顶部的页签栏上停住（缩略图在上方时停在「全部」上），或者按空格，所有页面摊开成小图，可以直接放进任意一页。手里的组件缩成一个小胶囊，不会挡住小图。
  • 暂存架：放到底栏的「暂存」里，就可以两手空空地慢慢翻页，翻到了再拖出来。退出编辑时，暂存的组件会排回末尾。
  • 拖动时滚轮、← → 翻页，数字键直接跳到第 N 页，Esc 取消，组件飞回原处。
  • 底下那条提示条一直跟着你的动作，告诉你松手后会发生什么，这比任何动画都更能让人放心。

要你定的事

1. 缩略图放上面还是下面？上面离手更近，是「拖到上方切换页面」的直觉位置，但拖动时要暂时占掉页签栏；Mac 刘海模式下顶部中间可能被刘海挡住，要在真岛上看。下面不和任何东西抢位置，但离板子远一点。我倾向上方，刘海模式自动改到下方。
2. 停留时长默认多少？预览默认 450ms，连续翻页 800ms。太短容易误翻，太长让人觉得「卡住了」。
3. 全景和暂存架要不要？页数多（4 页以上）时它们才值钱。我的建议是第一批做 ①②，③ 先不做，看实际用的时候页数多不多。
4. 「新建一页」要改数据格式。现在网格模式只存顺序，排的时候按列从前往后填，后面的小组件会回填前面的空位，所以存不下「这一页从这里开始」。预览里给组件加了一个「分页符」标记（brk）来实现。真做要在 CustomPanel 的条目上加一个可选字段，旧数据没有这个字段时照现在的方式排：这属于 localStorage 数据格式变化，要写进 contracts.md。不想改格式的话，可以只保留「翻到已有页面」，去掉 ＋ 新页。

落到代码上的前提

  • 拖动时补偿滚动：useBoxDrag 的 dx 只算了鼠标的位移。要在拖动开始时记下 scrollLeft，之后每帧加上滚动的变化量，否则一翻页，组件就和鼠标错开。预览里把拿起的卡片放到一个固定定位的浮层上，天然不受滚动影响，真做也可以这么改。
  • 编辑时也要分页：stripGeometry 里 paged = grid && !editing，一进编辑就变成连续的长条。要改成编辑时也按页对齐，再画出页的分界线（预览里每页之间的竖虚线）。
  • 从组件库拖进来的新组件（incoming）也要走同一套边缘换页和缩略图。
  • 自由模式本来就没有页，边缘换页改成匀速连续滚动，缩略图不出现。
