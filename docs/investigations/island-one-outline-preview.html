岛屿画成一条轮廓

左边是现在的拼法：方圆角矩形本体（inset box-shadow 加一圈 refraction 边框）+ 盒子外面的 ::before / ::after 两块反向弧，接缝靠盖条和裁剪补。右边是一条轮廓：整块外形是一条 CSS shape() 路径，填充、玻璃、流动色块都裁在它里面；描边是同一条路径和它往里缩 1px 的路径用 evenodd 相减得到的环，所以从侧边顺着反向弧一直走到屏幕顶，在弧尖渐隐。路径里只引用 --W --H --f --rt --rb 这几个注册变量，展开收起和贴顶/悬空切换都由 CSS 过渡驱动，没有 JS 逐帧计算。左边只复刻了贴顶和刘海，侧边、底边现在也是同样的拼法。

这个浏览器不支持 clip-path: shape()，右边画不出来。请用 Edge 或 Chrome 135 以上版本打开。

现在：拼起来的 本体 + 两块反向弧

现在的侧边、底边、药丸也是拼的，这里只复刻贴顶和刘海。

一条轮廓 clip-path: shape()

看什么现在一条轮廓
液态玻璃，贴顶，放大 4 倍本体左右的竖线一直通到屏幕顶，弧上的描边另起一条，在交界处错开、断开同一条 1px 描边从侧边转进反向弧，越往上越淡，到屏幕顶消失
经典，透明度调到 60顶边和弧的交界处透出盖条（docs/design/island.md 记过的已知问题）填充只有一层，没有盖条
贴顶 ↔ 悬空药丸反向弧整块淡出，顶角另外长出来反向弧收成上圆角，路径连续变形
流动色块、模糊反向弧里只有底色（background: inherit），没有色块和模糊色块和背景模糊一直铺到弧尖

已定（用户确认 2026-11-17）：贴顶、侧边、底边、刘海、药丸和经典、液态玻璃全部换成一条轮廓，拼接用的伪元素删掉；贴顶时描边顺着反向弧走、在弧尖渐隐，屏幕顶边那一条不画；不支持 shape() 的旧 Mac WebView 用 @supports 退回现在的拼法。
