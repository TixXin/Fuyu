市场卡片和详情页

每个插件一页，深色、浅色、中文、英文各一份，由 fuyu-plugin preview 画。卡片封面就是清单里第一张截图放在主色浅底上，只露出顶上一段。

在新标签页打开这一页右边空白？12 份预览页一共 10 MB 左右，没进仓库，按下面的命令重新生成。

重新生成

在仓库根目录跑，每个插件一条（<名字> 换成插件文件夹名）：

node packages/plugin-cli/bin/fuyu-plugin.mjs preview plugins/v3/official/<名字> --out docs/investigations/official-plugins-listing-preview/<名字>.html

和真的市场差在哪

  1. 卡片按默认大小的设置窗口里的宽度画；包的大小、更新日期、点赞数、权限清单、命令列表、更新记录页签只有真市场有。
  2. 外面那层岛是照默认外观画的；翻译窗口、设置页、岛上提示和换歌卡片那几张是用浮屿的真组件截的，数据来自插件自己的代码或示例，没有在真岛上截。
  3. 「待设置」的标记在插件页（已安装的那一页）上，这里看不到；它的测试在 tests/unit/e66-weather、e66-github-issues、e66-countdown。
