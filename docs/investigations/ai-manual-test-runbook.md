# 真机实测交给 AI：分组与执行方案

> 日期：2026-11-27。起因：用户定了「不管是什么测试都完全交给 AI 来做」。`pnpm tasks` 里「需要你本人」的 43 条改由 AI 在两台真机上做，结果写回各任务文件。相关：[roadmap-plan.md](../architecture/roadmap-plan.md) 阶段 0。

## 两台机器怎么操作

| 机器 | 通路 | 能做什么 | 现在的阻碍 |
|---|---|---|---|
| Mac（MacBook Air M4，有刘海，只有内置屏） | 本机 computer-use：截图、点击、键盘 | 全部界面操作 | 会占用屏幕；主工作区同时有多个会话在跑开发版，测试前要错开 |
| Windows（`tixxin-computer`，Win11 26300） | Tailscale `ssh winrel`：命令行直接跑；界面操作经计划任务进用户桌面会话（截图、UI Automation、模拟键鼠） | 安装卸载、命令行、日志、CPU 采样、界面操作 | 现在只有一块虚拟显示器在出图，截图全白；实体屏要开着，或远程桌面连着 |
| Windows 上的反重力 CLI（可选） | SSH 拉起 `agy -p`，跑长时间、可脚本化的测试（10 分钟 CPU 采样、回归页、`cargo test`），省本会话的额度 | 命令行类测试 | Windows 上还没装 `agy` CLI、没登录；它同样要放进桌面会话里跑才看得到界面 |

## 43 条怎么分

### 一、AI 在 Mac 上做（17 条）

A13、A11（Mac 部分）、B82（Mac）、C101.5（Mac）、C137.5（Mac 刘海、深浅色）、C145（Mac 部分）、D113（Mac 权限）、E66.14（Mac）、E77.8.3（Mac）、G1.3、G1.6、G1.7、G1.8、G1.9、G1.11、G1.29–G1.33（5 条一起）、E36 剩下的闲置内存测量。

### 二、AI 在 Windows 上做（20 条）

| 类别 | 任务 |
|---|---|
| 纯命令行，现在就能做 | B74（钩子移除、NSIS 重装、卸载清理）、B92（状态栏转存额度）、D5（装旧版走一遍自动更新）、D102（10 分钟 CPU / 线程采样）、E64.3 后台部分、C116 第 1 条（`im_notification_probe`） |
| 要界面 | A11、A19、B60、B82、C101.5、C108、C129、C135.3、C137.5、C145、D104、D113、E64.3、E66.14、E77.8.3 |

D104 里的「睡眠唤醒」改成只测「锁屏 / 解锁」：远程让电脑睡下去后没法保证能叫醒。

### 三、要你出一次材料或授权（5 条）

AI 不代输密码、不以你的身份给别人发消息，所以下面几条要你做一步，其余全由 AI 做。

| 任务 | 要你做的那一步 |
|---|---|
| C112 真实邮箱与 QQ 通知 | 同意 AI 用你的一个邮箱给自己发几封测试邮件（含验证码样式）；QQ 部分要有人给你发一条消息 |
| C115 坚果云、Nextcloud / 群晖 WebDAV | 你在两台电脑的同步设置里各填一次应用密码，之后的测试 AI 做 |
| C116 七个聊天软件的真实消息 | 在每个已登录的软件里让别人（或你的小号）发一条消息；AI 盯着岛看结果 |
| C113 同步文件夹跨设备 | 选一个两台电脑都能访问的同步盘（iCloud / OneDrive / 坚果云 / SMB 共享），告诉 AI 用哪个 |
| A6 某位用户 VS Code 环境的日志 | 这是别人电脑上的问题，AI 复现不了，建议改成「找那位用户要日志」或关掉 |

### 四、不是测试，只能你做（4 条，不算进实测）

D42（换微信群二维码，要你的微信扫）、D114（收款方式和打赏名单）、G1.12（Apple 开发者账号，要付款）、D116 最后一条（微软商店 Partner Center 账号）。

## 执行顺序

1. **Windows 命令行类**（不等任何人）：B74、B92、D5、D102、C116 第 1 条。B74 和 D5 会卸载、重装 Windows 上的浮屿，开始前先备份 `%USERPROFILE%\.fuyu` 和应用数据目录。
2. **Windows 界面类**：等实体屏出图后做。
3. **Mac 界面类**：挑主工作区没有开发版在跑的时候做，或者用正式版测。
4. **第三组**：等你的那一步做完再测。

每条测完在任务文件里写结果（过 / 不过、现象、日志几行、截图存本机路径），过了的按 `fuyu-task` 流程收尾；不过的另开任务修。
