岛屿与面板改尺寸：四合一

A 拉环、B 捏边、C 调整大小模式、D 角落旋钮放在同一个岛上，各管一块地方、共用一套反馈：拖任何一处，正在变的边都会亮，顶上出刻度，经过档位会吸一下，拖出范围有橡皮筋。上面一块是展开的面板，下面一块是折叠的岛，都能直接拖。可以在下面关掉某一项，看少了它会怎样；打开「显示热区」能看到每一块谁管。

开启

四个怎么一起用（冲突和优先级）

  1. 各占一块：拉环在底边正中，旋钮在两个下角，捏边只管左右两边和底边的其余部分（离角 26px 起，底边避开中间的拉环）。几块不重叠，鼠标在哪就是谁。
  2. 先出现再能拖：拉环、旋钮平时看不见，鼠标进到底部 40px、角落 70px 才淡入；捏边要在边上停 180ms 才亮起、才能拖，停之前的点击照常传给下面的按钮，这一条专门治旧版的误触。
  3. 拉环自由、旋钮整档：拉环和捏边经过档位轻吸（±10px），可以停在任何尺寸；旋钮拖动时浮出「紧凑 / 标准 / 宽大 / 满屏」轮廓，28px 以内整档吸住，适合一下子换一档。
  4. 调整模式是兜底：右键「调整大小…」或长按半秒进入。进去后拉环、旋钮、捏边都收起，换成五个圆点和档位条，方向键每次 10px（Shift 40px），Enter 或「完成」退出，Esc 撤销这次的改动。不会拖、或用触控板不方便的人走这条路。
  5. 双击复原：双击拉环或旋钮回到「标准」，双击折叠岛两端的小拉环回到默认宽度。
  6. 同一套反馈：正在变的那条边全亮、对侧半亮；宽度变时顶上出刻度，高度变时右边出刻度；尺寸标签在岛下面，碰到档位跳一下并写出档位名。
  7. 折叠岛：两端靠近时出现小拉环（A），贴着两端停一下也能捏（B），拖动时浮出各档宽度的虚线胶囊（D 的轮廓），右键同样能进调整模式（C）。
