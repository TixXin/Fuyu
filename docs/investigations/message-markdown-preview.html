消息卡片显示 Markdown（C143 / #1085）

左边是现在的样子，右边是打算改成的样子。卡片样式按岛上消息页的真实尺寸和颜色仿的，不是截图。

先核对了代码：
  • 即时通讯卡片正文已经有 white-space: pre-wrap，换行本来就保留。所以截图里「挤成一段」更像是聊天软件发系统通知时已经把表格压平了，岛这边没有再丢换行（issue 回复里那句说错了，会更正）。
  • 后端把正文截到 1000 字（src-tauri/src/im_sources/state.rs），20 行的表格会被截掉后半张。
  • 现有 Markdown 组件会把 _x_、*x* 当斜体，snake_case_name 这种也会被误伤。卡片里打算不认斜体，只认表格、加粗、链接、代码、标题、列表。

1. 原文带 Markdown：机器人发的榜单

只有原文里还留着 |---|、** 这些符号时才可能这样显示。右边：表格有行列，宽了就在卡片里横向滚动；超过 12 行先折起来，点「展开」看全部。第二行的 _斜体_ 故意留着下划线：这是不认斜体的代价，换来普通消息不被误伤。

2. 原文被压平，但还有换行

现在已经能按行显示；改后只多一件事：网址能点开。表格还原不了。

3. 原文被压平成一整段

截图里的情况。岛上没有任何依据分行分列，改前改后一样，只有链接能点。这种情况要请聊天软件那边保留格式，或者用插件直接接机器人消息。

4. 普通聊天里带 * _ # 的文字

必须和现在一模一样，不能被当成格式。判断规则见最后一节。

5. 横幅、到达面板、收起条的一行预览

这些地方只有一行，不渲染格式；改后去掉 Markdown 符号，表格只留第一行文字。验证码按钮照常。

6. 自己贴一段试试

左边输入原文，右边按改后的规则显示，下面写着判断结果。

什么时候按 Markdown 显示（满足一条就算）：
  • 有表格：一行带 |，下一行是 |---|---| 这样的分隔行
  • 有成对的 **加粗**，或者 [文字](https://…) 链接，或者 ``` 代码块
  • 至少三行，且有两处以上是 # 标题 或 - 列表
都不满足就按纯文本显示（保留换行，网址能点）。复制按钮始终复制原文。
