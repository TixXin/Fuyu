Agent 页额度：换个摆法

现在的样子是一张对齐表格：每家一行、按列对齐。家数一多，四五行就把会话挤下去了，Cursor 的额度被推到最右边的列，积分和余额又是另一种写法，看着很乱。下面五种摆法用的都是你截图里的真实数据，岛的宽度也和截图一样。顶部可以切换数据，看看家数多或少时各是什么样子。

不管选哪种都会一起修的：Cursor 的窗口名显示成了 month、cursorAuto，要改成「本月」「Auto」（用量环那边早就有这两个名字，Agent 页漏用了）；WorkBuddy 的积分是小数，要按用量环的写法保留一位、加单位；已过时的数据（截图里 Codex 行尾的黄色时钟）统一成一个小标记，不单独占一列。
