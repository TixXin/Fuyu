针对现在 800×320 宽岛里只有一条输入框 + 一行小字、底下大片黑屏 的问题，下面给出四套完整可交互的 redesign 方案。 四套方案里的倒计时、秒表、输入框解析（10、10m、1h30m、90s、1:30）、预设一键启动、暂停/加时/到点提醒都能直接点着试，上方工具栏可随时切换 空态 / 单计时 / 多计时 / 响铃 以及 深浅主题 / 宽窄尺寸。

横向空间浪费默认面板 800×320 是横向画布，现在只放了 1 条 30px 输入框，85% 面积全黑。
每次都要敲键盘常用 5 分、15 分、25 分在 Fuyu 面板小组件里都有一键预设，计时器主页面反而没有。
缺少时间感与反馈没有进度环 / 进度条，也没有「预计几点结束」的锚点；运行 1 个计时器时也只是一条细行。
秒表与休息提醒太隐蔽秒表缩在最右侧无文字图标里；同一模块里的「休息提醒」完全藏在设置窗口中。
A

左右双栏：速启台 + 实时舞台

推荐 · 零服务改动

顺着 800×320 宽岛自然分成左右两块：左侧固定负责「输入 + 6 格常用预设 + 秒表」，右侧专心展示当前计时（空态显示可调表盘，1 个计时用大圆环聚焦，多个自动切进度条列表）。

亮点

  • 空态不再空：左侧 6 格常用预设一键开跑，右侧是带 -1分 / +1分 微调和预计结束时间的待机表盘；在左边打字时，右边表盘会实时预览解析出的时长。
  • 单计时最有仪式感：只跑 1 个计时器时自动切「大圆环 + 预计到点 + +1分 / +5分」，不用盯着一行小字看。
  • 多计时不打架：开到第 2 个以上自动切回带底边进度条的紧凑列表，到点响铃自动置顶并高亮。
  • 快捷键习惯不变：全局快捷键打开依然直接聚焦左上角输入框，敲 10 + Enter 立刻开跑。

实现成本

  • 完全复用现有 timers/v1：零后端、零宿主协议改动，纯前端 TimerPanel 重构。

试试看：点左侧任意预设，或在输入框里敲 90s 看右侧实时预览；切上方场景看单计时 / 多计时 / 响铃态。

B

双模式大表盘：倒计时 / 秒表

像独立计时器仪器：顶栏切换「倒计时 / 秒表」并保留右侧快捷输入；空态居中展示可步进的 时 : 分 : 秒 滚轮大数字，秒表模式自带独立大表盘与分段计次。

亮点

  • 超强第一眼聚焦：大号等宽数字（48px）居中，无论空态还是运行态，一展开岛就有很强的视觉重心。
  • 主副队列联动：同时开多个计时器时，左侧保持大表盘聚焦当前选中的一条，右侧是队列栏，点哪条就把哪条切上主舞台。
  • 秒表体验完整：切到秒表标签后有 0.1 秒精度大字和右侧「计次」记录表，适合计时测速。

实现成本

  • 倒计时部分零服务改动；秒表计次可先存前端内存（随秒表清除），不改宿主。

试试看：点数字上下的箭头调时长，或切到「秒表」标签体验计次功能；切「多个 + 秒表」场景点右侧队列切换主舞台。

C

速启卡片网格：磁贴工坊

延续 Fuyu 自定义面板的卡片网格气质：空态是 3×2 六张常用时长磁贴，点一下原地变身带背景进度填充的实时卡片；剩余空位继续保留速启卡，随时一键多开。

亮点

  • 多计时器并排最爽：同时开 2–6 个倒计时 / 秒表时，每个卡片用整张底色当进度条，余光一扫就能看清所有进度。
  • 从不半空：运行 1–5 个计时器时，后面格位自动补齐常用预设磁贴，整个岛的视觉密度始终均衡。
  • 和 Fuyu 主面板风格最统一：圆角卡片、等宽大数字、角落微操作按钮，像原生长出来的兄弟页。

实现成本

  • 完全复用现有 timers/v1：零后端、零协议改动；超过 6 个时网格自动纵向滚动。

试试看：在「空态」连点两三张预设卡，看它们变成带进度填充的实时卡片并自然排布。

D

时间中枢：倒计时 + 休息提醒

把同属 timer 模块但目前藏在设置里的「休息提醒（久坐 / 护眼 / 喝水）」搬到右侧常驻，让计时器页在不开倒计时的时候也有活生生的实时进度。

亮点

  • 把隐藏能力亮出来：很多用户不知道 Fuyu 自带久坐 / 护眼提醒（离开 5 分钟自动暂停），搬进计时器页右侧能随时看到「还剩几分钟该起身」、一键开关或提前重置。
  • 左侧依然利落：输入框 + 单行快捷预设条 + 最近使用记录，运行态同样支持单计时大卡和多计时进度列表。

实现成本

  • 需小幅扩展前端状态：把 useBreakReminders.ts 内部 progress.current 暴露成可订阅的 store（约 20 行改动），就能实时同步进度与手动重置。

试试看：点右侧「休息提醒」开关或单条的重置按钮，同时在左侧启动任意倒计时。
