Agent 通知重设计：三套方案

C137 · issue #991 · 2026-11-19 · 只是预览，不改实现。上面的开关对整页生效（第 6、9 节另有固定组合的并排）。图标是示意色块，不是正式品牌图标。
第二版（2026-11-19，按用户意见）：橙色只给「等你确认」，只用在状态字和图标的环上；「允许」等主按钮用强调色 --color-accent；「等你回复」换成安静的灰蓝（强调色系、降饱和）；出错仍是红色。Agent 的最后一条消息尽量显示全：等你回复、完成、出错时 A / C 给 4 行、B 给 6 行，超出在卡片里滚动（底部渐隐提示还有），悬停展开全文；按 Markdown 显示列表、代码块和行内代码；运行中的命令换行显示 2～3 行。模型、用时、「你：」都收进悬停卡片。

0 · 现状

  • 第一行塞了五样：状态点、「项目 · 标题」、模型胶囊、已运行时长、提供方图标，标题只剩挤剩下的宽度，被截成「Fuyu ·［任…」。
  • 「项目 ·」前缀吃掉标题：AI 标题已经说清是什么，前面再拼项目名，最先被截掉的反而是标题本身。
  • 状态不是主角：「运行中 / 等你确认」只靠一个 8px 的点区分，离远了看不出要不要管。
  • 第二行「你：…」是你自己刚说的话，通知里重复给你看用处小，却占一整行。
  • 多会话：一次只弹一个，其余的看不出有几个在排队。
  • 审批是另一张卡片（结构、标题行都不一样），从通知切过去时整块跳变。

三套方案一句话

A · 精简两行

保留现在的行结构，砍到「谁 + 在干嘛」两行

第一行只放图标（带状态角标）、标题、状态字；第二行只放正在做的一件事。模型、时长、「你：」全进悬停卡片。

改动最小，和 Agent 页的会话行一脉相承。

本质还是一行列表，状态依旧不够醒目；多会话只看到「+2」。

B · 状态优先

大字写「现在要你做什么」，标题降为副标题

左边是带状态环的大图标，右边第一行是状态句（「等你确认 · Bash」），第二行是会话标题，第三块是正文；多会话叠成卡片堆。

一眼看懂要不要管，标题独占一行不再被挤；审批和通知同一结构。

比现在高约 14px；状态句和标题分两行，信息总量不减。

C · 两翼 + 下拉

平时只占两翼，需要你时才往下长

左翼是会话图标（叠放、带状态环），右翼是状态字；运行中不展开，等你确认 / 回复、出错、完成才往下长出正文和按钮。

最安静，Mac 刘海和 Windows 最一致，像 iPhone 灵动岛。

运行中看不到在跑什么命令；Windows 上两翼中间只放得下很短的标题。

外壳宽高用 --motion-slow + --motion-ease-out 示意（真岛走「开合动画」预设，≤560ms）；文字只淡入淡出，不位移不缩放：淡出 --motion-fast、淡入 --motion-base；更新时外壳高度变化用 --motion-medium；变成等你确认时状态标记脉冲两下（无文字的装饰层）；底下 2px 的细条是停留倒计时，鼠标停在岛上就停住。勾上顶上「模拟减少动画」看减少动画时的样子：外壳直接跳，文字照旧淡入淡出，循环停下。

9 · 窄宽度、中英文

固定 280px，左右分别是中文和英文，用「等你确认」和「等你回复」举例。规则：A 窄于 340 去掉快捷键字、窄于 300 把「到终端」收起；B 窄于 300 按钮只剩 ✕ >_ ✓ 图标；C 窄时中间标题先让位。

推荐

推荐 B（状态优先）为主体，借 C 的两条：Mac 刘海用两翼标题带；开始新一轮不弹出。

  • 现在的问题根子是第一行塞了五样东西、谁都不是主角。B 让「现在要你做什么」成为最大的字，标题降到第二行独占整行，模型、用时、「你：」进悬停卡，剩下的高度都给 Agent 的消息：平时 6 行，按 Markdown 显示，超出在卡片里滚动，悬停展开全文。
  • 审批、等你回复、出错、完成都是同一个结构（图标 + 状态句 + 标题 + 正文 + 按钮），从运行中变成等你确认时只是状态句换色、按钮那行长出来，不再整张卡片跳变。
  • 叠放的边能看出后面还有几个、什么状态，比 A 的「+2」直观，又不像 C 那样把运行中的信息全藏起来。
  • A 改动最小；C 在 Mac 刘海上最自然但两翼占掉一行，消息比 B 少两行，Windows 上也太空。

  • 元信息（原问题 4）：模型、用时、「你：」收进悬停卡片，把空间让给消息正文。

还要你定的问题（每条带推荐）

  1. 选哪套：A 精简两行、B 状态优先、C 两翼加下拉，或组合。推荐：B 为主体，Mac 刘海用 C 的两翼标题带，开始新一轮按 C 的做法不弹。
  2. 开始新一轮还弹不弹：现在每开一轮都展开 5 秒。推荐：不弹，只在收起条上显示标题几秒，需要你的时候（等你确认、等你回复、出错、完成）才弹。
  3. 停留多久：等你回复、出错是「留到你看过」（悬停过或切到那个窗口）还是定时收起？推荐：等你确认和等你回复留到处理或看过，出错留到看过，完成仍按设置的 5 秒；鼠标停在岛上一律暂停。
  4. 点通知去哪：现在点了打开 Agent 页。推荐：点本体直接切到会话所在的终端 / 编辑器窗口，右上角留一个小「↗」打开 Agent 页。
  5. 多个会话怎么叠：叠放露边（B）、一次一条加「+n」（A）、左翼图标堆（C）。推荐：B 的叠放露边，最紧急的在前，悬停展开成列表。
  6. 审批按钮：顺序「拒绝 / 到终端 / 允许」，「允许」在最右并用强调色填满；「始终允许」仍放在点开命令后的展开区里。推荐：就这样。
