# 设置页体验审计：还有哪些页值得像「刘海」那样改

2026-11-22。用户看过刘海设置（C168）和岛屿布局改 tab 之后，想知道还有哪些设置页也该这样改，先要一份清单再挑。

**怎么看的**：读了每页的组件代码和 `src/windows/settings/searchIndex.json`（每页有哪些行、说明、选项）。没有跑回归页、没有截图；窄窗口是否挤是按代码推断的（`SettingsChoice` 不换行、`settings-row__control` 不收缩），标了「待看」的要上真窗口确认。岛屿布局三个 tab（收起的岛 / 展开的面板 / 显示与刘海）和刘海组正在别的会话里改，不在这份清单里。

预览页：[settings-ux-audit-preview.html](settings-ux-audit-preview.html)，7 项各有「现在 / 改后」，改后能点。

## 定稿方案（2026-11-22）

用户看过预览页后说「可以，开始做」，预览页上「要你定」的几处按推荐定：原「桌面提醒」tab 改名「通知的样子」，事件总表单独做第一个 tab；「最小化按钮」放进贴边隐藏页的「露出」组；日历先打开「日历」tab；同步格子的说明缩成一行；剪贴板行名可以缩短。下面是各项共同守的规则和每项的细节，分头做的会话照这一节做，和下面「逐项」部分冲突时以这一节为准。

### 各项都守的

- **只换界面，不动存储**：不改任何 `localStorage` key、字段名、取值和默认值，不改 Tauri 命令。旧页名（`agentAlerts`、`sounds`、`agentPush`、`calendar`、`calendarSources`、`behaviorTuck`、`generalSync`、`clipboardHistory`…）照旧能打开，落在原来那块内容所在的 tab。
- **新页名只有两个**：`agentNoticeLook`（通知的样子 / Notice look）和 `calendarAlerts`（提醒 / Reminders）。它们在 `settingsCategories.ts` 和 i18n 的 `categories.ts` 里由统筹会话先登记好，做这两项的会话只在各自功能的 `plugin/settings.tsx` 里挂页面，不再改那两个文件。
- **缩略图条用共用组件** `src/components/settings/SettingsThumbStrip.tsx`（统筹会话先建好）：一排按钮，`role="group"` + `aria-pressed`，键盘 Tab 能到，悬停或聚焦的那格和选中的那格 `live`（只有这时缩略图才动），选中项的一句话说明写在条下面，窄窗口横向滚动。不各写一份。
- **动效**：缩略图、预览只在悬停 / 聚焦 / 点「试一下」时动，没指着的停着；系统开了减少动态效果时停在静止的样子。时长和曲线用 `--motion-*` token，写动效前加载 `fuyu-motion` skill。预览和演示只在设置窗口里演，不写设置、不让真岛动（已有的「在真岛上试一下」除外）。
- **文案**：中英文都写，中文短、直白；行名缩短时，旧行名要还能在设置搜索里搜到（写进说明或 `keywords`）。窄窗口（580 宽；760 以下侧栏收起）里不溢出：表格列头换成图标、缩略图条横向滚动、分段选择放不下时换行。
- **平台**：Mac 上本来就隐藏或换文案的行（Win+V、PrtSc、托盘 / 菜单栏、贴到终端的说明）照旧。
- **设置搜索索引**：分头做的会话**不跑** `pnpm settings:index`、不提交 `searchIndex.json`，最后由统筹会话统一重生成一次；在那之前 `settings-search` 回归页挂是预期的，汇报里写一句就行。
- **回归页**：改到哪页，更新哪页的快照（`pnpm test:regression <页名> --update-snapshots`），mock 跟着改，提交说明里写为什么变。提交前照规则跑 `pnpm test:changed`。
- **文档**：Agent 那项的决定写进 `docs/design/agent.md`；其余各项的决定写进自己的任务文件 `## 备注`，`docs/design/settings.md` 由统筹会话最后统一补。
- **提交**：功能提交正文写行为变化，末尾 `Release note:` / `Release note (en):` 两行；不推、不 land，提交号交回统筹会话。

- **事件总表**：最上面是 B87 的预览（`NoticePreviewStage`，行为不变），下面一张表，行是事件，列是岛上 / 声音 / 手机：

  | 事件 | 岛上 | 声音 | 手机 |

  | 等你确认或回答 | `agentAlertWaiting` | `approval`、`question` 两个小开关 | `waiting` |
  | 完成 | `agentAlertCompleted` | `complete` | `completed` |
  | 出错 | `agentAlertFailed` | `error` | `failed` |
  | 开始新一轮 | `agentAlertStarted`（原来的四选一下拉，缩窄） | `start` | — |
  | 发出消息 | — | `ack` | — |
  | 上下文快满 | — | `compact` | — |
  | 闲置等你 | — | `idle` | — |
  | 额度快用完 | 额度提醒线（`AgentQuotaAlertSettings` 那个下拉） | `quotaLow` | — |
  | 额度已刷新 | 「跟上一行」 | `quotaReset` | — |

  点行的空白处选中这件事、预览演它（现有的 `onSelect`）；声音格带试听。声音或推送总开关关着时，那一列变灰、不能点，列头写「没开 · 打开」链接去对应 tab；开着时列头写当前音量 / 通道和「设置 ›」。窄窗口（表宽 < 560px）列头换成图标（显示器、喇叭、手机）。做之前对一遍 `previewEvents.ts` 和三处原来的行，保证每个原来的开关在表里或别的 tab 里恰好出现一次。
- **通知的样子**：最上面同一块预览；然后「停留多久」组（完成的通知几秒后关、出错的通知、等你回复的通知、没处理时再提醒，这几个原来挂在事件行上的下拉搬到这里）；然后原来的 `NoticeLookGroups`（通知样式、Mac 刘海、正文行数、Markdown、滚动条、行为、审批按钮、恢复默认）。
- **声音**：只留总开关、音量、音效包、什么时候不响、导入音效包；10 行事件删掉，换一行说明加链接「每件事响不响在事件总表里改 ›」。**推送**同样删掉三行事件，留通道、服务器、Key、离开多久才推、发送测试、cc-connect。
- 额度提醒线从原来单独的「用量额度」组搬进表里，那一组去掉。

### 2. 行为 › 贴边隐藏（`behaviorTuck`）

- 原来顶上的静态示意（`tuck-intro`）换成实时预览：一段屏幕顶边加收起的岛，按 `tuckStyle` 画露边 / 细线 / 隐身；隐身时画记号（无 / 小圆点 / 光晕，颜色，呼吸）。「试一下」演鼠标碰顶边、岛滑出来、再收回去，只在预览里演。
- 露出样式、隐身记号各一条 `SettingsThumbStrip`（3 格；记号那条只在贴边隐身时出现）。提示颜色和自选颜色合成一行色块（白色描边、跟随岛色、自选，自选点开取色），呼吸开关留着，记号是「无」时这两行不显示。
- 「闲置时贴边隐藏」开关和「闲置多久」照旧；四个「不收起」（待办、Agent、音乐、消息）合成一行多选胶囊（`SettingsMultiChoice`），不再收在细调里；细调只留「鼠标移开后再次隐藏」和等待。
- 「最小化按钮」挪进「露出」组的最后一行。
- 新文案写进 `expand.ts`，不动 `layout.ts`（别的会话正在改它）。

### 3. 日历（`calendar`）

- 两个 tab：**日历**（`calendar`，`calendarSources` 也到这里）、**提醒**（`calendarAlerts`，新）。
- 日历 tab：页头，已添加的日历放第一组，然后「日历面板」（默认视图、每周起始日、月历周数、折叠全天日程），然后「哪些日程不算」（隐藏已拒绝、空闲不参与倒计时、以时间开头的待办并入日程）。日历的快捷键那一组位置不变。
- 提醒 tab：最上面一块演示，一座收起的小岛按当前「收起条显示格式」和「显示会议标题」显示一场示例会议（会议名、几分钟后、加入按钮），「演示强提醒」演横幅弹出（强提醒关着时按钮灰掉并说明）；格式从下拉换成 3 格 `SettingsThumbStrip`，缩略图就是三种收起条；然后「小岛倒计时」（提前多久、范围、开始后保留）、「会前强提醒」（开关和提前量合成一行、调休和放假前一晚、加入时暂停媒体），「自定义视频会议域名」收进细调。
- 「收起条显示格式」的中文说明照英文补全（说时间、标题和剩余分钟数）。

### 4. 通用 › 跨设备同步（`generalSync`）

- **没设置时**（没选文件夹、也没配 WebDAV）：只显示三步引导：选同步方式、选文件夹或填 WebDAV、要不要端到端加密；当前步骤描边，做完的打勾。同步内容、可选同步、设备都不显示，换成一句「设好后在这里选同步什么」。
- **设好后**：状态卡在最上面（状态、上次同步、设备数、文件夹或地址、是否加密、立即同步、更换），然后「同步什么」两列勾选格子（窄窗口一列）：勾选框、名字、一行说明（放不下省略，完整说明在悬停提示里）、状态徽标；有错误时错误信息整行显示在格子下面。然后加密那一组、「可选同步」整组收进细调（标题写「已开 N 项」）、设备、帮助。
- 同步的开关逻辑（`toggleCategory`、`toggleOptionalGroup`、确认删除）不动。

### 5. 剪贴板（统筹会话自己做）

- 打开与粘贴：「粘贴与显示」拆成「粘贴」（自动粘贴、收藏置顶、岛上的复制卡片）、「贴到终端」（图片贴成文件路径、多行命令合成一行）、「隐私与性能」（共享屏幕时隐藏、读取链接标题和图标、启动时预先准备窗口）。
- 记录与链接：隐私组的「清空时删掉刚记下的那条」「打码的自动删除」「允许本地接口读取」进细调；书签的两个网站名单和导入导出书签进书签组的细调；「容量与清理」「导入导出」整组折起来，折叠标题写当前值。

### 6. 行为 › 展开与收起的动效（`behavior`，和第 2 项同一个会话）

- 「动画曲线」11 种做成 `SettingsThumbStrip`，每格一个小岛，`live` 时用真参数（`islandMotionVariables`、`islandMotionTiming`）开合一次；原来的预览框留在条上面当大预览；每种曲线一句话说明（新文案，中英文），原来那段长说明去掉。
- 「弹动幅度」只在选了「弹开」时显示，改叫「弹开的回弹」。
- 「悬停效果」7 种同样做成一条，`live` 时演那种悬停；每种一句话说明。
- 「小组件出场动效」保留下拉，说明缩成一句。

### 7. 外观 › 材质与圆角（统筹会话自己做）

- 「不透明度」「整体不透明度」并排成「透明度」一组的两张小卡，各带一个小预览（只淡底色 / 连字一起淡）。
- 液态玻璃「风格」做成 4 格 `SettingsThumbStrip`，`live` 时才流动。
- 「颜色来源」和颜色 1 / 2 / 3 合成一行：分段选择加三个色块；不是「自定义」时色块显示当前取到的颜色、不能点。

| 记号 | 做法 | 现成的例子 |
|---|---|---|
| **合组** | 一堆互相关联的开关合成一组：最上面实时预览（用真组件画），样式用缩略图条，共用的颜色只放一处，冷门项收进「细调」 | 刘海（`sections/notch/`，C168） |

## 1. AI Agent › 提醒：三个 tab 的事件合成一张表

**页面**：侧栏「AI Agent › 提醒」，`agentAlerts`（桌面提醒）、`sounds`（声音）、`agentPush`（推送与机器人）。

**现在的问题**
- 同一类事件分三处开：
  - 桌面提醒：「等待你确认或回答时」「会话完成时」「会话出错时」「开始新一轮时」（`ReminderEventRows.tsx`，行上已经有一个试听按钮，借的是声音那边的音效）。
  - 声音：会话开始、任务完成、任务出错、需要审批、需要回答、发出消息、上下文快满、闲置等你、额度快用完、额度已刷新，10 行，每行「试听」加开关（`SoundSettingsSection.tsx`，`AGENT_SOUND_EVENTS`）。
  - 推送：「等你确认或回答时」「完成一轮时」「出错时」（`AgentPushSettings.tsx`，`AGENT_PUSH_EVENTS`）。
- 用户想知道「Agent 跑完时我会收到什么」，要翻三个 tab 拼起来；三处的事件名也不一样（「会话完成时」「任务完成」「完成一轮时」说的是同一件事）。
- 额度也分两处：桌面提醒里的「额度提醒」线，声音里的「额度快用完 / 已刷新」。

**建议**（参照「合组」和 B87 的演示）
- 「提醒」的第一个 tab 改成总表：每行一个事件，三列「岛上 / 声音 / 手机」，格子是开关；声音格带试听，点行的空白处照旧让上面的预览演这一条（B87 已有）。没有的组合（比如「发出消息」没有岛上提醒和推送）画成灰的「—」。
- 事件名统一成一套：等你确认、等你回答、完成、出错、开始、发出消息、上下文快满、闲置等你、额度快用完、额度已刷新。
- 原来三个 tab 只留各自渠道的配置：桌面提醒留通知的样子和行为、审批按钮；声音留总开关、音量、音效包、什么时候不响；推送留通道、服务器、Key、离开多久才推、发送测试。
- 窄窗口（低于 760px）时三列开关放得下（每格 40px 左右），事件名可以换行。

**工作量**：中到大。要新写一个表格组件，三处的开关改成从表里读写；B87 的预览联动要接到表上；回归页 `settings-agent-*` 和设置搜索的行都要跟着改（改完跑 `pnpm settings:index`）。

**风险**：存储不变：岛上的在 `IslandSettings`（`agentAlertWaiting` 等），声音在 `fuyu-agent-sounds` 的 `events`，推送在 `fuyu-agent-push` 的 `events`，表只是换个地方读写。旧的设置搜索结果会指向总表，旧页名 `sounds`、`agentPush` 照旧能打开。

## 2. 行为 › 贴边隐藏：做成刘海那样的一组

**页面**：侧栏「行为」› 贴边隐藏，`behaviorTuck`，16 行。

**现在的问题**
- 顶部 `tuck-intro` 是两个静态小岛中间一个箭头，和下面的选项没有关系，改了也不变。
- 「露出样式」（标准露边 / 极简细线 / 贴边隐身）是文字分段选择，说明里才写「露出的厚度」；选了贴边隐身后又冒出「隐身提示」（无 / 小圆点 / 光晕）、「提示颜色」（白色描边 / 跟随岛色 / 自选）、「自选颜色」、「提示呼吸」四行（`TuckHintRows.tsx`），都看不到样子。
- 「有正在进行的待办 / Agent 在等你 / 音乐播放中 / 有未读消息时不收起」四个开关意思一样，只是条件不同，已经收在「细调」里，但仍是四行长说明。

**建议**（参照「合组」）
- 顶部换成实时预览：屏幕上沿加收起的岛，按当前露出样式画；贴边隐身时画出提示记号（圆点或光晕、颜色、呼吸）；带一个「试一下」让它从收起到露出演一遍，只在预览里演。
