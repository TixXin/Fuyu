# 设置页体验审计：还有哪些页值得像「刘海」那样改

2026-11-22。用户看过刘海设置（C168）和岛屿布局改 tab 之后，想知道还有哪些设置页也该这样改，先要一份清单再挑。

**怎么看的**：读了每页的组件代码和 `src/windows/settings/searchIndex.json`（每页有哪些行、说明、选项）。没有跑回归页、没有截图；窄窗口是否挤是按代码推断的（`SettingsChoice` 不换行、`settings-row__control` 不收缩），标了「待看」的要上真窗口确认。岛屿布局三个 tab（收起的岛 / 展开的面板 / 显示与刘海）和刘海组正在别的会话里改，不在这份清单里。

预览页：[settings-ux-audit-preview.html](settings-ux-audit-preview.html)，7 项各有「现在 / 改后」，改后能点。

## 参照的几种做法

| 记号 | 做法 | 现成的例子 |
|---|---|---|
| **合组** | 一堆互相关联的开关合成一组：最上面实时预览（用真组件画），样式用缩略图条，共用的颜色只放一处，冷门项收进「细调」 | 刘海（`sections/notch/`，C168） |
| **演示** | 预览框里把这一页管的东西演一遍，可以「再演示一次」「在真岛上试一下」 | Agent 桌面提醒（B87/B88）、消息 › 提醒方式（D111） |
| **分 tab** | 一个侧栏入口下用 `SettingsTabs` 分几个 tab，在 `settingsCategories.ts` 的 `tabs: [...]` 里登记 | 通用、行为、待办、剪贴板、Agent 各组 |
| **细调** | 不常改的行收进 `SettingsAdvanced` 折叠 | 贴边隐藏的「不收起」四项、液态玻璃的模糊 / 饱和度 / 噪点 |

## 总表（按收益排序）

| # | 页面 | 主要问题 | 建议 | 工作量 | 风险 |

下面逐项说。

## 1. AI Agent › 提醒：三个 tab 的事件合成一张表

**页面**：侧栏「AI Agent › 提醒」，`agentAlerts`（桌面提醒）、`sounds`（声音）、`agentPush`（推送与机器人）。

**现在的问题**
- 同一类事件分三处开：
  - 桌面提醒：「等待你确认或回答时」「会话完成时」「会话出错时」「开始新一轮时」（`ReminderEventRows.tsx`，行上已经有一个试听按钮，借的是声音那边的音效）。
  - 声音：会话开始、任务完成、任务出错、需要审批、需要回答、发出消息、上下文快满、闲置等你、额度快用完、额度已刷新，10 行，每行「试听」加开关（`SoundSettingsSection.tsx`，`AGENT_SOUND_EVENTS`）。
  - 推送：「等你确认或回答时」「完成一轮时」「出错时」（`AgentPushSettings.tsx`，`AGENT_PUSH_EVENTS`）。
- 用户想知道「Agent 跑完时我会收到什么」，要翻三个 tab 拼起来；三处的事件名也不一样（「会话完成时」「任务完成」「完成一轮时」说的是同一件事）。
- 额度也分两处：桌面提醒里的「额度提醒」线，声音里的「额度快用完 / 已刷新」。

**建议**（参照「合组」和 B87 的演示）
- 「提醒」的第一个 tab 改成总表：每行一个事件，三列「岛上 / 声音 / 手机」，格子是开关；声音格带试听，点行的空白处照旧让上面的预览演这一条（B87 已有）。没有的组合（比如「发出消息」没有岛上提醒和推送）画成灰的「—」。
- 事件名统一成一套：等你确认、等你回答、完成、出错、开始、发出消息、上下文快满、闲置等你、额度快用完、额度已刷新。
- 原来三个 tab 只留各自渠道的配置：桌面提醒留通知的样子和行为、审批按钮；声音留总开关、音量、音效包、什么时候不响；推送留通道、服务器、Key、离开多久才推、发送测试。
- 窄窗口（低于 760px）时三列开关放得下（每格 40px 左右），事件名可以换行。

**工作量**：中到大。要新写一个表格组件，三处的开关改成从表里读写；B87 的预览联动要接到表上；回归页 `settings-agent-*` 和设置搜索的行都要跟着改（改完跑 `pnpm settings:index`）。

**风险**：存储不变：岛上的在 `IslandSettings`（`agentAlertWaiting` 等），声音在 `fuyu-agent-sounds` 的 `events`，推送在 `fuyu-agent-push` 的 `events`，表只是换个地方读写。旧的设置搜索结果会指向总表，旧页名 `sounds`、`agentPush` 照旧能打开。

## 2. 行为 › 贴边隐藏：做成刘海那样的一组

**页面**：侧栏「行为」› 贴边隐藏，`behaviorTuck`，16 行。

**现在的问题**
- 顶部 `tuck-intro` 是两个静态小岛中间一个箭头，和下面的选项没有关系，改了也不变。
- 「露出样式」（标准露边 / 极简细线 / 贴边隐身）是文字分段选择，说明里才写「露出的厚度」；选了贴边隐身后又冒出「隐身提示」（无 / 小圆点 / 光晕）、「提示颜色」（白色描边 / 跟随岛色 / 自选）、「自选颜色」、「提示呼吸」四行（`TuckHintRows.tsx`），都看不到样子。
- 「有正在进行的待办 / Agent 在等你 / 音乐播放中 / 有未读消息时不收起」四个开关意思一样，只是条件不同，已经收在「细调」里，但仍是四行长说明。

**建议**（参照「合组」）
- 顶部换成实时预览：屏幕上沿加收起的岛，按当前露出样式画；贴边隐身时画出提示记号（圆点或光晕、颜色、呼吸）；带一个「试一下」让它从收起到露出演一遍，只在预览里演。
- 露出样式做成三格缩略图，隐身提示做成三格缩略图（只在贴边隐身时出现），提示颜色用色块（白、岛色、自选），和刘海的色块一样。
- 四个「不收起」合成一行多选胶囊「这些时候不收起：待办 / Agent / 音乐 / 消息」（`SettingsMultiChoice` 现成），说明合成一句。注意音乐页也有「音乐播放中不收起」，两边是同一个开关，要一起认。
- 「最小化按钮」和这页关系不大，可以留在原处，不进预览。

**工作量**：中。预览用现有的 `IslandGlyph` 和贴边收起的样式画；缩略图条可以照 `NotchStyleStrip` 写。

**风险**：低。设置键（`tuckStyle`、`autoTuckHold*` 等）不变；四个开关合成一行时，设置搜索里四行要变成一行，跑 `pnpm settings:index`。

## 3. 日历：分两个 tab，提醒加演示

**页面**：侧栏「功能 › 日历」，`calendar`，18 行，没有 tab（2026-11-17 定的「行数少保持单页」，现在多了强提醒、节假日、过滤规则，已经不少）。

**现在的问题**
- 页面从上到下是：小岛倒计时 5 行、会前强提醒 5 行、面板与过滤 7 行，最后才是「已添加的日历」。第一次打开的人最先要做的是添加日历，却得滚到底。
- 「收起条显示格式」是下拉，选项写成示例文字（「标题 · 10 分钟后」「14:00 标题 · 10m」「紧凑（仅图标与时间）」）；「显示会议标题」「开始后保留时长」也影响收起条长什么样，但看不到。
- 中英文说明不一致：「收起条显示格式」中文是「选择收起条展示会议时间与标题的详略方式」，英文多说了剩余分钟数。

**建议**（参照「分 tab」和消息页的「演示」）
- 分两个 tab：**日历**（已添加的日历放最上面，下面是面板与过滤规则）、**提醒**（小岛倒计时、会前强提醒、节假日前一晚、加入会议）。侧栏点「日历」先到「日历」tab。
- 「提醒」tab 顶上放一块演示：一座收起的小岛按当前格式显示一场「10 分钟后」的示例会议，关掉「显示会议标题」时立刻变成「会议」；「再演示一次」演强提醒横幅弹出；「在真岛上试一下」可以后做。
- 「收起条显示格式」从下拉换成三格缩略图（就是三种收起条的样子）。

**工作量**：中。分 tab 是登记一个新页名（比如 `calendarAlerts`）加把 `sections.add` 的 category 改掉；演示要单独写一个小组件，收起条的倒计时组件能复用多少要看 `MeetingLine.tsx`。

**风险**：中。新增页名要进 `settingsCategories.ts`、i18n 的 tabs 和 keywords、回归页；`calendar` 和别名 `calendarSources` 要继续打开「日历」tab（岛上和概览的链接用它们）。设置存在 `IslandSettings`（`calendarRemindMinutes`、`calendarShowTitle`）和 `fuyu-calendar-prefs`，都不动。

## 4. 通用 › 跨设备同步：没设置时只给引导

**页面**：侧栏「通用」› 跨设备同步，`generalSync`，16 行（加上 WebDAV、加密、设备列表、帮助，实际更长）。

**现在的问题**
- `SyncSettingsPage.tsx` 不分有没有设置，一律依次摊开：状态、通道、同步内容（6 个开关）、可选同步（7 个开关）、设备、帮助。还没选文件夹时，13 个开关开了也不起作用。
- 可选同步 7 行默认全关，每行一句「默认关闭：……」的两行说明，读完要很久。
- 同步内容每行右边有状态徽标（正常 / 待确认 / 出错），这是有用的，要保留。

**建议**（参照「细调」，加一个引导）
- 没选文件夹时：只显示三步「选通道（同步文件夹 / WebDAV）→ 选文件夹或填地址 → 要不要端到端加密」，同步内容先灰着折起来，写一句「设好后在这里选同步什么」。
- 设好之后：状态卡在最上面；同步内容做成两列勾选格子（图标、名字、状态徽标），说明放进悬停提示或展开；可选同步整组收进「细调」，标题后面写「已开 N 项」。

**工作量**：中。主要是 `SyncSettingsPage` 的排版和一个格子组件；开关的逻辑（`toggleCategory`、`toggleOptionalGroup`）不动。

**风险**：低。不改同步的存储和后端；回归页里同步页的快照要更新。

## 5. 剪贴板：重新分组，冷门项收进细调

**页面**：侧栏「功能 › 剪贴板」，`clipboard`（打开与粘贴，13 行）和 `clipboardHistory`（记录与链接，21 行）。

**现在的问题**
- 「记录与链接」21 行，四组：记录什么、隐私与过滤（6 行）、容量与清理、链接书签（6 行，含两个域名名单和导入导出书签）、导入导出。链接书签原来是单独的 tab，后来在 `dfa719767`（合并稀疏的子 tab）并进来了。
- 「打开与粘贴」的「粘贴与显示」一组 8 个开关管的是四类事：粘贴（收藏置顶、自动粘贴）、终端（贴文件路径、多行合一行）、隐私（共享屏幕时隐藏）、性能和联网（预先准备窗口、读取链接标题）、岛上的复制卡片。

**建议**（参照「细调」，不加新 tab，免得和「合并稀疏子 tab」那次的决定冲突）
- 「粘贴与显示」拆成三组：**粘贴**（自动粘贴、收藏置顶、岛上的复制卡片）、**终端**（两行）、**隐私与性能**（共享屏幕时隐藏、预先准备窗口、读取链接标题）。
- 「记录与链接」：容量与清理整组、导入导出整组收进「细调」；书签的「这些网站不提示」「只提示这些网站」和导入导出书签收进书签组的细调，组里只留「复制链接时提示」「识别哪些链接」。

**工作量**：小到中。主要是挪行和包 `SettingsAdvanced`。

**风险**：低。设置键不变；设置搜索的分组名会变，跑 `pnpm settings:index`。

## 6. 行为 › 展开与收起：动效用缩略图代替长说明

**页面**：侧栏「行为」› 展开与收起，`behavior`，13 行，「开合动画」组。

**现在的问题**
- 「动画曲线」11 种（弹开、轻快、弹簧……）、「悬停效果」7 种、「小组件出场动效」几种，都是下拉；每一行的说明把每个选项都描述一遍（设置搜索里这几行的说明有好几百字）。
- 已经有小预览（`IslandMotionRow` 的播放按钮、`IslandHoverRow` 的「移上来试试」），但要先在下拉里选、再看预览，比对两种曲线很慢。
- 「弹动幅度」只对「弹开」有用，其他曲线时是灰的一整行。

**建议**（参照「合组」的缩略图条）
- 动画曲线做成缩略图条：每格一个小岛，鼠标或键盘移上去就用这种曲线开合一次，没选中的停着（和刘海缩略图一样省电）；当前曲线的一句话说明写在条下面。
- 悬停效果同样做成一条，移上去就是试的那一下。
- 「弹动幅度」收到「弹开」那一格下面，只在选了弹开时出现。

**工作量**：中。动效的参数和播放逻辑都在（`islandMotionVariables`、`islandMotionTiming`），主要是排版；要守 `docs/design/motion.md` 和减少动画的规则（加载 `fuyu-motion`）。

**风险**：低。设置键不变。

## 7. 外观 › 材质与圆角：剩下的两处文字选项

**页面**：侧栏「外观」› 材质与圆角，`themeStyle`，31 行，全站最长。2026-11-17 第 2 轮已经把液态玻璃分成三组、加了吸顶预览和细调，大头已经做了。

**还剩的问题**
- 「风格」（静态 / 慢流动 / 极光 / 着色器）是文字分段选择，英文四个选项合起来约 53 个字符，窄窗口下可能挤（待看）。
- 「颜色来源」选「自定义」后多出「颜色 1 / 2 / 3」三行，每行一个色块。
- 「不透明度」和「整体不透明度」两行容易混，说明里才分得清。

**建议**
- 风格做成四格缩略图，移上去才动。
- 三个颜色合成一行三个色块，和刘海的 `NotchSwatches` 一样。
- 两个不透明度合成一组「透明度」，标题下一句话说明「底色 / 整个岛」，或者把「整体不透明度」收进细调。

**工作量**：小到中。

**风险**：低。

## 小问题（顺手改）

- Agent 桌面提醒「点通知」：中文说明只有「另一个去处放在右上角的小按钮」，英文先说了两个去处；「多个会话同时来」中文少了「叠起来时露出后面的边」。中文照英文补全。
- 日历「收起条显示格式」的中英文说明不一致，见上面第 3 项。

## 不值得改的页

- **概览、关于（四个 tab）、插件、插件市场、运行诊断**：都是最近专门设计过的页，不是开关列表。
- **通用 › 启动与托盘、数据与备份；本机接口**：各 4–5 行，够短。
- **外观 › 主题与配色**：C119、C31、C33 改过，已有选择卡、预览和色块。
- **外观 › 位置与尺寸**：12 行，已有位置示意图；「岛的形态」和刘海的关系等岛屿布局那个会话做完再看。
- **快捷键三个 tab**：按键录入和速查表，形式合适。
- **待办三个 tab**：C140.2 刚按排法 A 改过。
- **音乐三个 tab**：歌词样式已经有实时预览，歌词来源是开关加路径，形式合适。
- **翻译、文件中转、语音输入、计时与提醒两个 tab**：各 1–7 行。
- **截图、录屏**：各 6–10 行，分组清楚；「快捷键说明的位置」可以做成四角点选，收益小。
- **消息两个 tab**：D111 刚按预览页改过，有演示。
- **Agent › 钩子与代理、连接与扩展、审批**：B67 和 11-17 改过，行数少。
- **Agent › 状态灯与标题、会话列表、用量与会话环**：11-17 已经做了缩略图选择卡。
- **SSH 远程**：主机列表，不是开关页。
- **岛屿布局三个 tab、刘海**：别的会话正在改，不在这次范围。
