面板编辑态预览 · 第 3 版

点右上角的布局图标进入编辑；也可以在组件或空白处按住半秒，按住组件时会直接拿起它开始拖。Esc 或点岛外面退出。页面里的改动不会保存，点「重置」回到初始状态。

方面做法
进入 / 退出右上角是只有图标的圆按钮：平时是布局图标，编辑时原地变成蓝底的 ✓，悬停显示「调整布局 / 完成调整」，读屏也能读出来。按住组件半秒直接拿起它开始拖（像手机桌面）；按住空白处只进编辑。按住时指针处有一圈进度环，按住期间移动超过 6px 就取消，留给拖岛。退出：完成、Esc、点岛外面；真岛上岛失焦时也退出（现在就是这样）。
动效顺序组件不缩小，整个岛同时长高、加宽（默认高 +96px、宽 +80px，左右各 40px，420ms）：多出来的高度放底部组件栏，多出来的宽度让一行能多放组件，也让组件栏少滚动；岛长完再开始抖，避免两种动作叠在一起发晃。组件标签从下往上淡入。退出时立刻停抖，岛再收回原来的大小。所有时长和曲线都用现有的 --motion-* 档位。
抖动转 ±0.9°，一个来回 135ms，每个组件起始相位不同。鼠标放上去、键盘聚焦到某个组件时它停止抖动，方便点小按钮。正在拖的那个不抖。系统开了「减少动画」时完全不抖，排序和增删也不做位移动画。
标签条盖在卡片底部，用半透明加模糊，不加高卡片。这样进出编辑不会让整页重新排版，自由模式下也不会和下面的组件重叠。代价是底部约 30px 内容暂时被盖住。
拖动排序网格模式下拖动时其他组件实时让位，用 FLIP 动画平滑移动；松手后被拖的组件弹回空位。拖到滚动区上下边缘时自动滚动。
从组件栏添加点一下加到末尾，并滚到它的位置，带弹出动画。拖到上面时面板里先出现一个虚线占位，指到哪里占位就到哪里，拖回组件栏就取消。鼠标停在组件栏的某个组件上会浮出它的样子，加之前就能看到。
删除鼠标移到组件上（或用键盘聚焦），右上角浮出一个 × 关闭按钮，压在卡片边角外面一点，悬停时变红。平时不显示，画面更干净。点 × 后组件缩小消失，回到底部组件栏；岛底部出现「已移除 · 撤销」，4 秒后消失。不做二次确认，因为能撤销。
尺寸网格模式在底部标签条最右边显示 1×1 / 2×1，点一下换尺寸。自由模式不显示尺寸，改成右下角的拉伸手柄，按 8px 吸附。
自由模式背景出现点阵，拖到任意位置吸附到格子，最后动过的组件放到最上层。从网格切过来时保持原来的位置，切回网格时按从上到下、从左到右的顺序重排。
组件栏按「内置」「插件」分组，横向滚动，左右两边渐隐，滚轮可以直接横向滚。没启用的插件组件带锁并置灰，悬停说明原因。已经加进面板的组件不显示在栏里。
保存每次改动立刻保存，右侧提示短暂变成绿色的「已保存」，不需要「保存」按钮。
键盘和读屏编辑时组件可以用 Tab 聚焦：←→ 移动（自由模式四个方向都能移），Enter 换尺寸，Delete 删除；组件栏的组件按 Enter 添加。每次移动、添加、删除都会读出来。
空面板平时显示模板（工作台 / 娱乐）。编辑时换成虚线框「把下面的组件拖到这里」，拖进来时框变亮。
窄岛、英文、浅色窄岛下右侧提示隐藏，组件栏照样横向滚动；英文文案更长，标签条里的名字会截断成省略号。浅色主题全部走变量，不写死颜色。
实时组件番茄钟在编辑时照常走秒，验证抖动时内容刷新不卡。

还要你定的

  • 标签条：盖在卡片底部（本页做法，不改布局），还是像 Nook X 那样放在卡片下面（整页会变高，自由模式要另想办法）？
  • 自由模式重叠：本页允许组件叠在一起，最后动过的在上面。现在的实现是什么规则要再对一下；要不要改成碰到就把别的组件推开？
  • 岛往哪边长：本页是往下长高、向两边对称加宽。岛贴近屏幕左右边缘时，加宽要改成只往一侧长。岛贴在屏幕顶部时只能往下；如果用户把岛放在屏幕底部，要改成往上长，否则会超出屏幕。真岛上这一步要改 Rust 侧的窗口尺寸，并且展开态、贴边收起时都要考虑。
  • 按住组件就进编辑：在真岛上，按住组件可能和组件自己的操作冲突（例如歌词拖动、番茄钟长按）。可以只在组件的空白处生效，或者只允许按住空白处进入。
