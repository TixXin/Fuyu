岛屿布局预览

配合 island-layout-plan.md 看。这一页是示意，样子和尺寸以做的时候的设计为准。三部分用的是同一份数据：在第二部分岛上改的面板，第三部分的编辑器里会跟着变，反过来也一样。

一、收起条：入口收拢到「岛屿布局」

同一件事（显示不显示、放哪、长什么样）现在有 6 个入口。改后只在「岛屿布局」里改，右键菜单和岛上编辑模式是它的快捷方式，改的是同一份数据。

入口现在管什么改后
外观 → 收起条上的项目左右、顺序、隐藏、小面板搬到 岛屿布局 → 收起条，加上文字位和样式
右键收起的岛勾选显示 / 隐藏保留；底部「排列…」打开岛屿布局
插件详情「显示在岛上」显示 / 隐藏开关
AI Agent 页状态灯样式、会话环样式样式选项
待办页、音乐页、插件设置「剩余 N 个待办」、歌词 / Agent 标题二选一、中心图案、用量环选哪些 Agent岛上样式
外观 → 收起条「+N」开关、刘海两侧最宽搬到 岛屿布局 → 收起条

被划掉的地方都换成一行只读链接，见下面「原位置」两张卡片。插件总开关不动：它管的是功能开不开，不是岛上的事。

二、自定义面板：岛上的样子和编辑模式

顶部页面栏多出用户建的面板（这里是「工作台」）。点右上角「编辑」进入编辑模式：组件晃动，拖动移动组件，不拖岛，「−」删除，底部「+ 添加组件」。右上角切「网格 / 自由」：网格按 120 的格子对齐、压到就往下挤；自由按 8px 吸附，能拉伸右下角改大小。组件按自己拿到的大小排版，拉宽拉高会换成更完整的样子。

三、展开页面：设置里的面板编辑器

左边是全部页面（内置、插件、自定义），能排序、隐藏（隐藏不关功能）。中间是按实际大小画的面板，能拖、能删。右边是组件库：点一个尺寸加到面板里，点「条」加到收起条上（看第一部分的预览）。没有某个尺寸的组件就没有那个按钮。

新建时可以选模板：空白、工作台、娱乐
