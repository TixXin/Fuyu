面板左右翻页箭头 + 方向键展开 / 收起

展开面板的左右两边各放一个半透明箭头，鼠标放上去才完全显示，点了切到上一页 / 下一页；← → 也能切页。收起的岛上按 ↓ 或 回车展开，面板里按 ↑ 或 Esc 收起。下面的演示能真的用鼠标和键盘操作：先点一下桌面或岛，当成岛拿到了键盘焦点（右下角会显示），再按方向键。右下角的记录会写出每次按键做了什么、为什么。

方案对比（上面的开关就是这些）

箭头长什么样

A 只有箭头推荐

只画一个 ‹ ›，没有底；鼠标放上去才出现浅色圆角底。最轻，不跟内容抢眼，深浅色都干净。点击区 28×64，比看上去大。

B 圆形玻璃按钮

30px 的半透明圆，带细边和模糊。最像「可以点的按钮」，一眼就懂；但常驻在面板上比较显眼，内容贴边时会压住一点。

C 贴边竖条

整条左 / 右边都是点击区，悬停时从边缘亮起一道渐变。最好点（像翻书摸页边），但内容区左右各让出 30px 的空间里的点击会被它接走。

平时看得见多少

① 一直半透明

面板打开就看得见（约 25%），你说的就是这个。好找；代价是常驻两个淡淡的符号。

② 鼠标进面板才淡淡出现推荐

只用键盘或鼠标在别处时完全干净，鼠标一进面板就淡出两个箭头，放到箭头上全亮。比 ① 安静，又不难发现。

③ 靠近那一边才出现

鼠标离左边或右边 80px 以内，那一边的箭头才淡淡出现。最干净，但第一次用的人不知道有箭头。

切页时怎么动

只淡入 + 箭头推一下推荐

新页面照现在的 240ms 淡入，不位移；被点 / 按的那个箭头往那边推 4px 再回来（箭头没有文字，可以动），页签底下的高亮滑到新页签。方向感来自箭头和页签，文字不动。

只淡入

和现在点页签一模一样，没有任何方向提示。

内容轻推 8px违反规矩

新页面从切换方向那边挪进来 8px 同时淡入，方向感最强。但会让文字位移、最后一帧可能落到不同像素行发虚，违反 motion.md「文字不动位置」和「不从旁边滑入」，选它要你明确点头。

键盘规则（按我推荐的写）

按键在哪做什么不做的情况
↓ 回车收起的岛展开，打开上次的页面岛没有键盘焦点时按不到（见下面「焦点」）；收起态里有按钮拿着焦点时回车先给那个按钮
← →展开的面板上一页 / 下一页，顺序和页签、Ctrl+Tab 一致光标在输入框、文本框里；焦点在自己处理方向键的控件上（日历月视图、下拉、滑块、Agent 会话列表）；输入法正在组词；按着 Ctrl / Alt / Shift / Win；弹出页（详情、设置小页）开着；正在调整布局
↑展开的面板收起同上；内容往下滚过时先回到顶部，在顶部再按才收起（可选）
Esc展开的面板收起（现在就有）由里往外一层层退：先关下拉 / 弹出页 / 退出编辑，最后才收起
按住 ← →展开的面板只翻一页，松开再按才翻下一页（可选连翻）防止手一抖滑过好几页、每页都触发加载

需要你拍板的细节

  • 焦点（最关键）：现在点收起的岛不抢键盘焦点，面板收起时还会把焦点还给原来的窗口（这是之前你定的，免得打断正在打字的程序）。所以「在岛上按 ↓ / 回车」只有岛手上有焦点时才按得到：拖过岛、托盘点开、或开了「悬停时接管键盘」、光标停在岛上的时候。推荐保持现状，不为了 ↓ 键去抢焦点；顺带让「悬停时接管键盘」在收起的岛上也生效，开了它的人光标停在岛上按 ↓ 就能展开。另一种做法是「用 ↑ / Esc 收起后焦点在岛上留着，点别处才还」，代价是收起后打字会打进岛里。演示里点「别的窗口」就是焦点被还走的样子。
  • 箭头放在面板里面还是外面：推荐里面（压在内容区两侧的留白上）。放外面不挡内容，但岛的原生窗口要左右各加宽 40px，而且鼠标移到箭头上时已经离开了岛的形状，悬停展开模式下会被当成「移开了」开始倒数收起，要另外处理。
  • 到头时：推荐循环（最后一页往右回到第一页），和现在的 Ctrl+Tab 一样，箭头永远两个都在。也可以选「到头停住」：那一边的箭头变得很淡、点不了，按方向键时它闪一下表示到头了。
  • Fuyu 页面自己也分页时（网格模式的组件超过一页）：推荐箭头和 ← → 只换岛的页面，组件的内页继续用滚轮和页码点翻。另一种是先翻完内页再跳到下一个页面，更连贯，但同一个按键有时翻内页、有时换页面，不好预测。
  • 只有一个页面时两个箭头都不显示；页签放不下、收进「更多」里的页面也按顺序翻到。
  • 竖着的侧边岛：面板窄，箭头会压到内容，推荐侧边形态不显示箭头，← → 照常能用。
  • 收起的岛有焦点时，右边淡淡显示「↓ 展开」（演示里有）：只在岛真的拿着焦点时出现，告诉人现在按 ↓ 有用；没有焦点时不显示，免得按了没反应。要不要？
  • 箭头在面板里面时，内容区左右各多留 22px，箭头不压内容（演示里就是这样）；代价是每页横向少 44px。
  • 键盘翻页时屏幕上的箭头闪一下（默认开）：顺便告诉只用键盘的人「这里还有箭头可以点」。
  • 悬停箭头时显示要去的页面名（停 300ms 才出，默认开）：知道点了会到哪，不用盯着页签。
  • 设置：在 设置 → 页面切换 里加两个开关「面板两侧显示翻页箭头」「方向键翻页和展开收起」，默认都开？还是箭头默认关、先给想要的人打开？
  • 其他照规矩办的：箭头只做透明度和底色的过渡（120 / 160ms），不缩放；减少动画时不推箭头；箭头是按钮、带「上一页：日历」这样的无障碍名称，但不进 Tab 顺序（键盘本来就有 ← →）；中英文文案都有；浅色主题下箭头用深色。
