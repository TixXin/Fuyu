# 官方插件完善：审查结果和计划（E66）

组长：`[任务] 官方插件完善`（总控 `Fuyu-[总控] 插件开发`）。2026-11-19 起草，用户同意后派会话。标准见 [official-quality.md](../plugins/official-quality.md)，总预览见 [official-plugins-preview.html](official-plugins-preview.html)。

审查方法：三个只读子代理逐个读 `plugins/v3/official/<名字>/` 的源码、清单和 README，有第 2 版的对照 `git show 59ac01a0^:plugins/examples/dev.focusd.<名字>/`，再对照同类软件。系统监控（E64）、世界时钟（E65）另有计划，ecdict 没有界面不审。

## 所有插件都有的问题

- **岛页没写 `title`**：页头的标题只能回落到 `fuyu.displayName`（E60.5 已支持 `title`）。
- **命令没接上**：7 个插件只在清单里声明了命令，代码里没有 `ctx.commands.register`，设置里的「运行」按钮和快捷键都不起作用（E60.6 查出）：now-playing `show`、weather `refresh`、github-issues `refresh`、launcher `rescan`、alarm `dismiss`、todo-digest `write-digest`、pomodoro `start` / `stop`。
- **语言来源不一致**：界面用 `navigator.language`，宿主的通知和写进笔记的文字用 `Intl` 的系统语言，两边可能不一样，也不跟浮屿的界面语言设置。要平台给插件一个「浮屿界面语言」（见「要平台做的」）。
- **收起项没写 `opens`**，点了没反应（E60.9 合入后补）；宽度照旧写 `width`，等 E60.8。
- **设置要点「保存」**（github-issues、now-playing、weather）：改成改了就生效。
- **没有 `CHANGELOG.md`**，版本都是 1.0.0。
- 描述写的是内部实现或罗列功能（「监听待办变化」「大小写不敏感子串」），要改成一句话说用途。

**老用户的设置不变**：下面「默认改成关」的项，只对新装的用户生效；已经保存过的设置照读。

## 每个插件

### 番茄钟 pomodoro（大）
- 现状：岛页大号时间、进度条、开始/停止，空闲时列出 5 条待办单选；收起条只在运行时显示剩余时间；**没有设置分节，时长写死 25 分钟**（第 2 版能改，这是退步）。
- 要补：设置分节；专注时长（25）、短休息（5）、长休息（15）、几轮后长休息（4）；**休息阶段**和**暂停 / 继续**（`timers/v1` 已有 pause / resume）；到点后自动开始休息 / 下一轮（都关）；提示音（关）；每日目标轮数（0 = 不设）；通知上的「再来一轮 / 休息一下」按钮（第 2 版有）。
- 岛上收起来：待办列表折成一行「选一条待办 ›」，点开才出（设置里可以默认展开）。
- 其他：过零点待办列表不刷新；描述去掉「25 分钟」。

### 待办进度环 todo-ring（小到中）
- 现状：岛页圆环 + 「X / N 已完成」+ 4 条待办，**点一下待办就直接完成、没有撤销**；收起条小圆环 + `3/7`；没有设置。
- 要补：设置分节；显示几条待办（3，0 = 只显示圆环）；点待办勾选完成（**默认关**，防误触）；统计范围（今天 / 今天加逾期）；收起条样式（圆环 + 数字 / 只圆环 / 剩余 N 条）；全部完成后圆环变完成色（开，第 2 版有）。
- 岛上收起来：刷新按钮（事件已经实时）、和百分比重复的「X / N 已完成」一行。
- 其他：过零点不刷新；错误信息没翻译。

### 倒数日 countdown（中到大）
- 现状：岛页大卡片 + 添加表单 + 全部日期列表，每行四个小按钮（置顶 / 设背景图 / 去背景 / 删除）；收起条图标 + `12天`；设置只有「在收起条显示天数」。
- 要补：**日期管理搬进设置**（增删、编辑、排序、置顶、背景图），岛页只留卡片和最多 5 行；类型「倒数 / 纪念日（第 N 天）」；每年重复（生日、纪念日）；当天提醒（开）、提前 N 天提醒（关）；过期的显示方式（已过 N 天 / 隐藏 / 变灰）；收起条显示哪一项、样式。
- 岛上收起来：添加表单、每行按钮、卡片上的日期、收起条的图标。
- 其他：英文名 Countdown 容易被当成计时器，建议改 **Day Counter**（id 不变）；背景图随快照每分钟广播，改成按需取；超过 50 条静默丢弃。

### 闹钟 alarm（中）
- 现状：岛页一大块添加表单（时间、备注、铃声、试听、7 个星期按钮）+ 闹钟列表；收起条常驻下一次闹钟；设置只有默认铃声和收起条开关。**已有闹钟不能编辑**。
- 要补：编辑闹钟；贪睡时长（5 分钟，现在写死）；响铃多久自动停（30 秒）；音量（70%）；渐强（关）；时间格式（跟随系统）；一周起始日（跟随系统）；错过的闹钟开机后补报（开）；单次闹钟响过后自动删除或保留。
- 岛上收起来：收起条平时**默认不显示**，只在响铃时显示（设置里可常驻）；表单只留「时间 + 备注 + 添加」，重复和铃声折成一行点开再改；试听挪进设置。
- 其他：贪睡状态重启就丢；`dismiss` 命令没接上。

### 应用启动台 launcher（中）
- 现状：岛页搜索框 + 「重新扫描」，下面最多 500 个应用全列出，每行带文件夹和「最近 · N 次」；设置只有两个按钮。
- 要补：空搜索时显示「最近使用」（8 个）还是全部；启动后岛自动收起（开）；排除的应用；额外扫描的文件夹；显示文件夹 / 次数徽标（都关）；自动重新扫描间隔；最近记录开关和上限；**新命令「打开启动台」**，可以绑快捷键。
- 岛上收起来：空搜索时的全部应用列表、文件夹名、次数徽标、底部按键提示、「重新扫描」按钮（挪进设置）。
- 不在这一轮做：Windows 商店应用（UWP）、真图标，工作量大，另开任务。
- 其他：同名不同路径的应用被去重吞掉；描述改成给用户看的话。

### 待办摘要 todo-digest（小到中）
- 现状：没有岛页和收起条；设置里有今日统计、「写入摘要」按钮和 5 条预览；没有设置项。
- 要补：每天定时自动写入（关，默认 22:00）；写入范围（只未完成 / 加已完成数 / 全部）；条目格式（列表 / 复选框）；**重复写入时替换当天上一份**（默认替换，现在会一直追加）；全部完成时也写一句（开）；写完弹通知（开）。
- 岛上：保持什么都不放。
- 其他：过零点不刷新；`messages/v1` 应改成可选依赖。

### GitHub Issue github-issues（中）
- 现状：岛页筛选框 + 刷新按钮，按仓库分组，每个仓库最多 30 条，每条带作者和日期；设置有仓库（文本框）、刷新间隔、新 issue 提醒。
- 要补：仓库改成列表（添加、删除、校验）；每个仓库显示几条（10，多的折叠）；排序（最近更新）；按标签筛选；是否显示 PR（关）；每行显示作者（关）、更新时间（开，改成「3 天前」）、评论数（开）；打开岛页时立即刷新（开）；收起条显示未关闭总数（关）。
- 岛上收起来：作者和绝对日期、常驻的筛选框（多于约 10 条才出）。
- 不在这一轮做：第 2 版有的 GitHub 登录（私有仓库、更高限额），要平台的密钥存储，另开任务。
- 其他：名字中英不一致（「GitHub Issue」/「GitHub issues」），统一成「GitHub Issue」/「GitHub Issues」；仓库改名（301）显示加载失败。

### 正在播放 now-playing（小）
- 现状：没有岛页和收起条，只有设置里的「换歌时自动提示」（默认关）和「立即显示」按钮；开了以后每 2.5 秒轮询一次。
- **要用户定**：岛自带音乐页和收起条，这个插件只是「换歌时弹一下」。建议改名「**换歌提示** / Track change notice」，定位成通知插件，不做第二个音乐页。
- 要补：提示停留时长（6 秒）；显示内容（歌名 + 歌手）；显示控制键（开）；只对某些音乐软件提示；岛展开时不弹（开）；连切歌只提示最后一首（开）。
- 其他：去掉常驻轮询，只靠事件；暂停状态可能被误报成播放；英文「Show now playing now」。

### 天气 weather（大，可拆两步）
- 现状：岛页城市 + 刷新按钮、大字温度、体感·湿度·风速、6 小时、7 天；收起条「多云 18°」**默认开**；下雨提醒**默认开**；设置有城市、温度单位、刷新间隔等 5 项。
- 默认值：**收起条默认关**（打开后默认「图标 + 温度」）、**下雨提醒默认关**（第 2 版两项都默认关）。
- 要补（第一步）：风速单位（km/h / m/s / mph / 级）；时间格式（跟随系统）；岛页显示项勾选（体感开，湿度、风速关，降水概率开）；逐小时格数（6 / 12 / 24）；收起条样式；「更新于 14:30」和离线时「显示的是上次的结果」；下雨提醒的提前量和静默时段；7 天带周几。
- 第二步（可以放到下一轮）：城市搜索后从候选里选（防同名城市选错，第 2 版有核对行）；极端天气提醒。

## 要平台做的（插件系统总控 2026-11-19 已定接口，平台在做）

1. **界面语言 `ctx.locale`**（修复组长做）：`ctx.locale.current`（`"zh-CN"` / `"en"`，跟浮屿设置里的界面语言）、`ctx.locale.onChange(fn)`、`ctx.locale.pick({ "zh-CN": …, en: … })`，客户端和宿主两边都有。接口出来前，各插件包一层 `currentLocale()`，暂时把 `navigator.language` 映射成 `zh-CN` / `en`，以后只改这一处；**不读浮屿的 `fuyu-*` localStorage**。
2. **打开自己的设置 `ctx.settings.open()`**（插件页组长做）：不带参数，打开设置窗口并定位到本插件详情的「设置」标签。接口出来前，空状态里不放按钮，写一句「在 设置 → 插件 → <名字> 里填写……」。
3. 已在排的：E60.9（警告色、深浅标记、收起项 `opens`）、E60.8（收起条宽度）。
