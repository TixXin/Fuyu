静默会话与「隐藏会话」增强设计预览

解决 agy-title 等工具在随机临时目录反复跑一次性会话刷满 Agent 列表的问题：在现有「隐藏会话」和会话行 ⋯ 菜单基础上，补齐 环境变量静默启动、目录通配符、「隐藏类似会话…」面板 与可选的 系统临时目录开关。

文案对照：
示例系统：

岛上 Agent 页：规则生效前后对比 & 行菜单「隐藏类似会话…」

左边是刷屏现场与点开某条 agy-title-xxxx 的 ⋯ 菜单和「隐藏类似会话…」建议小面板（可直接勾选并点「隐藏」应用到下方设置窗）；右边是规则生效后的列表与收起条状态。

方案 A：只留现有「隐藏会话」一组（通配符 + 折叠的静默启动说明）

  • 改动最轻：不拆新分组、不加「隐藏临时目录」开关，只把「所在目录」升级为支持 * 通配符，并在卡片末行放一个可展开的 FUYU_AGENT_STATUS=off 说明。
  • 零存储迁移：复用 fuyu-agent-session-filters 的 { kind: "folder" | "prompt", value }，含 * 时按路径通配（仍含子目录）。
  • 取舍：脚本作者找 FUYU_AGENT_STATUS=off 需要多点一次展开；遇到别的临时目录脚本时，要先在岛上点一次「隐藏类似会话…」。

方案 B：拆成「隐藏会话」+「静默启动」两组，配临时目录开关与行菜单面板推荐

  • 职责清楚：「隐藏会话」面向用户在岛上事后过滤（含默认关闭的「隐藏系统临时目录里的会话」快捷开关 + 通配符规则）；「静默启动」面向脚本/插件作者从源头跳过钩子，设置搜索也能直接搜到 FUYU_AGENT_STATUS。
  • 两端都能治本：改不了第三方插件源码时，开「隐藏系统临时目录」或点「隐藏类似会话…」立即生效；自己维护的 agy-title 加上 FUYU_AGENT_STATUS=off 后连钩子进程都直接退出。
  • 取舍：「会话列表」页底部多一组代码块卡片（约 150px 高）；临时目录开关默认关，避免用户在 /tmp/demo 手开调试会话时以为钩子坏了。

方案 C：岛上主动提示高频临时会话 + 规则实时命中数，「静默启动」放去连接页

  • 防误杀 + 免翻菜单：每条规则旁显示「命中 N 条」（点开能看藏了哪些会话），输入框实时提示将匹配几条（输单个 * 时提醒会藏掉全部会话）；岛上短时间出现 ≥3 条相似临时目录会话时自动给一行轻提示。
  • 按受众分放：把开发者用的「静默启动」放进「Agent → 连接与扩展」（与回复状态标记、编辑器扩展同页），「外观 → 会话列表」底下只留一行链接跳过去（点窗口里的链接或左侧栏可切换看两页）。
  • 取舍：多一套相似临时会话检测与规则命中计数状态，实现复杂度比方案 B 高一档。
