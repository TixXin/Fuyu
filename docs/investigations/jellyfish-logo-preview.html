2. 任务栏上的小尺寸

3. 岛上的状态灯

默认是实际大小（24 像素高，和收起条上一样）。A 和 C 靠核的颜色加触手姿态区分：运行时三根触手依次收缩，对应悬岛的三个点；等你时触手偏向一边、核变黄闪烁；失败时伞面压扁、触手散开、核变红；完成时触手收短并打勾。B 照原稿靠眼睛区分，等你和失败时整只变色。

4. 放在收起条上

实际大小。用上面的「收起条上的状态」切换。

5. Mac 菜单栏的单色图

菜单栏图标是单色模板图，16 像素高，只剩剪影。
