1. 互动台

左边是放大 8 倍的 B，右边是实际大小的收起条。两边跟着上面的「状态」一起变。

把鼠标移过来试试。

  • 鼠标靠近：眼睛看向鼠标；4 秒没动就自己四处看。
  • 按下：闭眼，松开睁开。不缩放（动效约定：按下不缩放）。
  • 点击：打开 Agent 页，和现在点状态灯一样。
  • 拖动右边的收起条：触手往反方向拖尾，松手回正。
  • 来新消息：眼睛朝消息那边看一眼再回来。

2. 五种状态

不只靠颜色：每种状态的颜色、眼睛、姿态三样都不同，色弱或只用余光也分得开。空闲和运行中同色，靠触手动不动来分。每张卡片上面是放大的样子，下面三个是实际大小：深色岛、浅色岛，以及系统开了「减少动画」时（不动）。

  • 曲线和时长都用动效约定里的档位：过渡用 --motion-ease，进场用 --motion-ease-out，循环用 --motion-ease-in-out；时长是 120 / 160 / 240 / 420ms 四档。
  • 循环只给状态：只有运行中、等你有持续的循环。空闲只有眨眼和 10 秒一次的游动，和现在悬岛的呼吸、宠物的眨眼是同一档。
  • 不回弹：完成的上浮、失败的晃动都不冲过头。
  • 只动 transform、opacity 和颜色，不触发排版；岛收起到边缘或隐藏时暂停（现有的 data-paused）。
  • 多个会话时显示哪个状态，规则不变，仍按现在的优先级取最要紧的一个。

6. 图标和岛放在一起

图标是蓝紫色。岛上的 B 有两种本色可选，用上面的「岛上的身体颜色」切换：米白、深色眼睛和现有的中心图案一致，但只靠形状和图标呼应；淡紫、白眼睛和图标同一个配色，深色、浅色主题都不用换色。等你、失败、完成时两种都换成状态色。

7. 落地前要定的事

  • 状态灯的设置项：在「悬岛 / 圆点」之外加「水母」并设为新默认，还是直接替换悬岛？已经选了悬岛或圆点的老用户保持原样。中心图案里同样加一项「水母」。
  • 身体颜色：米白配深色眼睛（和现有图案一致），还是淡紫配白眼睛（和图标同一个配色）。
  • 贴边把手：12 像素宽放不下眼睛，只剩一个小伞形。保留圆点更清楚，建议把手不换。
  • 图标的制作：原稿重画成矢量后，替换 src-tauri/icons/ 的全部尺寸、Mac 菜单栏的模板图、README 里的小岛图和关于页；小尺寸简化版一起出。
  • 撞脸检查：凭印象，Phantom 钱包的图标是紫底、白色幽灵、两只椭圆眼，和原稿接近，定稿前查一下。
