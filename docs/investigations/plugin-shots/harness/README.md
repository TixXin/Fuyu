# 没有岛上页面的官方插件：截图脚本

`fuyu-plugin shots` 只会截岛上页面和收起条。`ecdict`（离线词典）和 `todo-digest`（待办摘要）没有岛上页面，它们的截图用这里的脚本截：把浮屿自己的窗口组件在浏览器里渲染出来，数据由插件自己的宿主代码算出来，再用无头 Chrome 以 2 倍像素截元素。E77.6 用它截了 6 张图。

## 文件

| 文件 | 作用 |
|---|---|
| `shoot.mjs` | 入口。在 Node 里跑两个插件的宿主代码得到数据，把下面的页面临时放进 `tests/regression/`，起 vite、开无头 Chrome、截图、关掉，最后把放进去的文件全部删掉 |
| `shot-ecdict.html` / `.tsx` | 快捷翻译窗口（`src/windows/translation/TranslationWindow.tsx`） |
| `shot-todo-digest-settings.html` / `.tsx` | 插件详情对话框的「设置」页（`src/windows/settings/PluginDetailModal.tsx`），里面是插件自己的设置组件 `plugins/v3/official/todo-digest/src/settings.tsx` |
| `shot-todo-digest-notice.html` / `.tsx` | 岛上的新消息弹层（`IslandShell` + `MessageArrivalsPanel`） |

页面里的 `../../src/…`、`../../plugins/…` 是按 `tests/regression/` 的位置写的，放在这里不能直接打开；`shoot.mjs` 会自己复制过去。页面用到的 `./shot-data.json` 也是 `shoot.mjs` 每次现写的，不在仓库里。

## 怎么重拍

在仓库根目录：

```text
node docs/investigations/plugin-shots/harness/shoot.mjs
```

- 默认写到 `plugins/v3/official/<插件>/screenshots/<文件名>`，覆盖原图。
- 只拍一部分：后面跟要匹配的词，例如 `ecdict`、`todo-digest/notice`。
- 先看效果不覆盖：`--out <目录>`，图写成 `<目录>/<插件>-<文件名>`。
- 需要本机有 Chrome 或 Edge，Node 要能直接运行 `.ts`（本仓库用的版本可以）。全程约半分钟。
- `tests/regression/` 里已经有 `shot-` 开头的文件时脚本拒绝运行；跑完后 `git status --short tests/regression | grep shot-` 应该没有输出。
- 同样的代码和数据，重拍出的图和上一次逐字节相同；图变了说明界面或插件的输出变了。

要换示例内容，改 `shoot.mjs` 顶部：`SHOTS`（每张图的页面、参数、视口）、`TODOS` 和 `NOTE`（待办和当天笔记）、`WRITTEN_AT` 和 `SHOT_AT`（写入时间、截图时的时间）。词典要查的词写在 `SHOTS` 的 `query.word` 里，只能用 `assets/ecdict.json` 里有的词（约 1.17 万条，生僻词没有）。

## 每张图是什么

### ecdict

三张都是快捷翻译窗口，深色，简体中文，翻译服务一栏显示「离线词典 · offline」。

| 图 | 内容 | 视口 |
|---|---|---|
| `lookup.png`（1560×760，市场卡片封面） | 查 `float`：音标和各词性释义，宽窗口的左右两栏 | 800×400 |
| `inflection.png`（1000×1240） | 查 `wrote`：先还原成原形 `write` 再给释义 | 520×640 |
| `reverse.png`（1000×1240） | 输入「岛屿」：反查出 `island`、`isle` | 520×640 |

数据怎么来的：`shoot.mjs` 导入 `plugins/v3/official/ecdict/src/host.ts`，执行插件的 `apply`，拿到它交给 `translatorEngines.register` 的引擎（名字、默认模型、`translate` 函数），再用这个 `translate` 查三个词。释义文字、「原形」那一行、反查的排版都是插件自己的函数读真实词表 `assets/ecdict.json` 得到的，一个字没有手写。

页面怎么用这份数据：把引擎的名字和查到的结果登记到窗口里的翻译引擎表（`registerTranslationEngine`），把翻译设置里的服务选成它，模拟剪贴板里有这个词（窗口打开时自动填进原文框），点「翻译」。截图前页面会核对：服务一栏以「离线词典」开头、没有报错、译文和插件算出的结果一字不差。

### todo-digest

| 图 | 内容 | 视口 |
|---|---|---|
| `preview.png`（1436×619，市场卡片封面） | 设置页最上面一块：「今天 7 条待办，还有 5 条没完成」、「写入摘要」按钮、将要写进笔记的预览、「上次写入：18:02」，下面带一行设置 | 800×900 |
| `settings.png`（1440×1490） | 整个插件详情对话框：标题、页签和全部设置项 | 800×900 |
| `notice.png`（832×260） | 写完后岛上弹出的提示：「待办摘要已写入 / 已把 5 条未完成待办写进今日笔记」 | 900×360 |

数据怎么来的：`shoot.mjs` 导入 `plugins/v3/official/todo-digest/src/host.ts`，执行插件的 `apply`，给它一个假的待办服务（7 条示例待办，5 条没完成，当天笔记里有一句话）和一个只记录不显示的消息服务，把时钟固定在 18:02，然后依次调用插件登记的 `state` 和 `writeDigest`。得到的两样东西原样交给页面：

- `writeDigest` 返回的状态（待办、设置的默认值、上次写入时间）：设置页的 `host.call("state")` 返回它。预览里的文字是插件的设置组件自己用这份状态排出来的，页面的时钟固定在 18:30，所以预览第一行是 `[18:30]`。
- 插件交给消息服务的那条提示（标题、正文、时长）：提示页把它原样交给窗口里真的 `messages/v1`，走岛屿本来的路径弹出来。

`preview.png` 和 `settings.png` 是同一个页面，前者只截对话框正文从顶部到第一行设置为止（下边界按页面里两行设置的位置算，不是写死的高度），后者截整个对话框。

## 和真机截图的差别

都是浮屿自己的组件渲染的，没有改组件，也没有手画。差别在组件外面那一圈：

- **没有桌面背景和系统窗口阴影**：截的是窗口或岛本身的元素，四角透明。
- **离线词典的引擎是页面登记的**：真机上是宿主里的插件登记引擎，窗口再去读；页面里直接登记到窗口的引擎表，名字和结果来自插件。这条路径在真机上有没有打通没有验证过，见下面「没验证的」。
- **翻译窗口的大小**：真机默认 480×640，竖版两张用 520×640 的视口（窗口本体 500 宽），为了凑够 1000 物理像素；`lookup.png` 用 800×400，窗口宽到 760 以上才是这种左右两栏，真机上要自己拖宽。
- **快捷键的写法**：右上角显示成 `⌃⇧F`，因为截图的 Chrome 跑在 macOS 上；Windows 上是 `Ctrl+Shift+F`。
- **插件详情对话框是单独渲染的**：真机上它盖在设置窗口上面，后面是变暗的插件页；这里后面是纯色。对话框宽 720，和真机一样。真机的设置窗口默认高 860，对话框最高约 740，比 `settings.png` 里矮几个像素，最后一行要滚一点才露全；这里视口高 900，一次显示完。
- **岛是默认外观**：深色、经典样式、不贴边、没有刘海；用户换了主题或在刘海屏上会不一样。提示那一行左边是拼图图标，真机也是：这个插件发提示时没有带自己的图标。
- **`notice.png` 宽 832 物理像素**：岛的弹层本身只有 400 宽，2 倍就是这么大，没有为了凑 1000 像素去拉宽它。
- **截图前把输入框的焦点去掉了**，所以原文框没有光标和聚焦描边。
- **版本号会过期**：`settings.png` 的标题下面有 `v1.1.0`，插件升版本后要重拍。

## 没验证的

读代码时发现一件事，这次没有在真机上确认，也没有改：窗口里的 `translator/v1` 由 `src/features/translation/plugin/services.ts` 在窗口本地提供，引擎列表读的是窗口自己的引擎表；而 `@fuyu/ecdict` 是在宿主（Node）里通过 `translator.engines` 登记的，`src/` 里没有地方把宿主的引擎同步到窗口的表里。照这样，真机上「离线词典」可能不会出现在翻译服务下拉框里，选了也会被 `normalizeTranslationSettings` 改回默认服务。把这三张图当作「引擎出现在窗口里之后的样子」；发版前在真机上装上插件看一眼设置 → 翻译 → 翻译服务。
