收起条改成标签和两栏（C156.5）

设置 → 岛屿布局 →「收起条」这一边，从清单（上移下移、换边）改成和「展开」一样的标签式：上面是收起条预览，下面「在收起条上 / 可以放上去」两栏，有样式的项目在最下面用缩略图卡片选。存储不变，仍是 fuyu-collapsed-items（zone 左 / 右，shelf 小面板，hidden 拿下来）。

要你定的是左侧、中间、右侧、「+N」小面板这几个位置在标签上怎么表达，下面三种可以切换着试：拖动标签、点 ＋ / ×、选中后按 Alt+方向键，上面的收起条跟着变。拖下面的「收起条最宽」能看到放不下的项目怎么收进「+N」。

样式

和展开那边的「大小」一样，选中的项目自动切到它的标签
用量环、剩余待办数没有样式可选（用量环在 AI Agent 页勾选显示哪几家），不在这里出现。

三种表达方式的取舍

  • A 分区：「在收起条上」里分成左侧、中间、右侧、小面板四格，拖到哪格就放哪。一眼看清每个项目在哪，最好懂；占的高度最多，窄窗口下四格竖着排。中间格只收中心图案和剩余待办数，左右的项目拖不进去。
  • B 一排：按收起条的样子排成一排，中间是黑色的「摘要」块，拖过它就换到另一侧，最右边隔开的是小面板。和收起条长得最像、最省地方；但「换边」要靠拖过摘要，键盘用户得多按几下 Alt+←/→。
  • C 菜单：一排标签按收起条上的顺序排，每个标签带一个小字「左 / 中 / 右 / +N」，点标签弹菜单换位置、前后挪、拿下来。最紧凑，也最像现在的右键菜单；但看不出整体布局，要一个个点开看。
  • 推荐 A：这一页本来就有上面的预览，多占的高度可以接受；拖动、点击和键盘都能完成换边，C 的菜单可以作为标签的右键菜单一起加上（三种方式不冲突）。
  • 放不下的规则不变（C139.2 / 设计记录「谁留下」）：按清单顺序先放，放不下的整项收进「+N」；标签上标「收进 +N」提醒你哪几个现在看不到。
