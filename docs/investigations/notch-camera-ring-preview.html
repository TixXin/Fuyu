摄像头刘海内描边

刘海模式下，岛是黑的，摄像头刘海也是黑的，两块连成一片，看不出刘海在哪。这页在岛里面沿着摄像头刘海的轮廓画一圈：从刘海左上角的小弧出来，沿左边、底边、右边绕一圈，再回到屏幕顶边。所有效果都在岛里面，不会画到桌面上。真刘海那块没有像素，所以只画在刘海外沿；实验台的模拟刘海也照这个画。左边两张卡是设置的样子，收起的岛和展开的面板各一组。

模拟状态

摄像头、麦克风开着时用系统隐私灯的颜色（绿、橙）；新消息用来源软件的颜色；Agent 等你时用 Agent 的橙色快闪。
「播放中」给「进度」和「律动」两种样式用。

全部样式

用左边「收起的岛」那组的颜色、粗细、间距、强度画，状态按「播放中」。点「岛」「面板」直接套用。

要你定的

  1. 收起时底边怎么办。收起的岛和刘海一样高，刘海底边就是岛的底边，一整圈画不下。两种办法：只画两侧，像一对括号把刘海括起来，岛的大小不变；岛加高几像素，整圈都画出来，岛比刘海高出「间距 + 粗细 + 2」像素（在左边卡片的「收起底边」里切换着看）。我倾向做成选项，默认「只画两侧」。有消息下拉的时候岛本来就比刘海高，两种都能画整圈。
  2. 留哪几种样式。九种：关、发丝、辉光、扫描、滴落、进度、律动、刻度、极光。我倾向全留：「进度」和「律动」跟着播放走，没在播放时退成「发丝」。嫌多就先砍「刻度」和「极光」。
  3. 默认值。我倾向两组样式都默认「关」，和外框那项一样。
  4. 摄像头、麦克风占用时亮不亮。摄像头就在刘海里，开着时刘海一圈亮绿光，开麦克风亮橙光，和系统隐私灯同色。我倾向这一项单独开关、默认开，样式是「关」时也亮。现有的摄像头 / 麦克风弹窗提示照旧，两者互不影响。
  5. 设置放哪、叫什么。另一个会话正在做岛和面板外轮廓的边框（「刘海边框」）。我倾向外观 → 显示里放一个「刘海」组，下面两小节：「外框」（那个会话做的）和「摄像头一圈」（这个），只在 Mac 或实验台模拟刘海时显示。
  6. 和外框一起开的时候。两圈同时亮会花。我倾向不拦，由你自己选；跟随状态时只让内描边亮，外框保持原样。
  7. 省电。跟外框一样：岛隐藏、全屏、贴边收起时停止动画；系统开了减少动态效果时停在静止的样子，扫描和滴落退成静止的辉光。
