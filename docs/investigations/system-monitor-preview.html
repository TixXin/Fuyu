1. 宽面板（两栏）

现在的第 3 版 1.0.0

一块块卡片；只有处理器、每核、内存、运行时间。

第 2 版 1.3.1（只支持 Windows）

不画卡片。CPU 和 GPU 各一个环、曲线、核心柱 / 引擎；内存；网速；电池；右边最占资源的程序。

计划的第 3 版 1.1.0 · Windows 补回

版式照第 2 版；数据由插件宿主读（Windows 上常驻一个 PowerShell 助手，页面关掉 60 秒后退出）。

计划的第 3 版 1.1.0 · Mac（Apple 芯片） 新

没有 CPU 温度、GPU 温度和功耗、GPU 各引擎（要 root）；GPU 只有占用和已用内存；程序没有图标，显示首字；按钮打开活动监视器。
