侧边竖向岛预览（C54.1 第 3 步）

岛吸在屏幕左右边时立起来，变成一条竖着排图标的窄岛；文字类内容从旁边往屏幕里弹出横向气泡；闲置后缩回把手；点开横版面板从侧边滑出。左右两个岛一起演示，下面的按钮同时作用于两个。配色、圆角、反向圆弧、动画曲线取自岛的真实参数（深色岛 #030303，浅色岛 #f2f2f5，主题色 #74d6ff / #0a7fd1，贴边圆角 8px，宽度 550ms 回弹，高度 500ms ease-out，内容只淡入淡出）。用 Chrome / Edge 139+ 打开才看得到方圆角。

推荐 B：侧边本来就是「不想被打扰」的位置，能不点开就看到数量最有用；36px 和 44px 的遮挡差别不大。音乐封面对听歌多的人有用，可以作为 B 的选项（「音乐显示封面」），不单独做一种造型。

交互约定（预览里能试的）

  • 竖向岛是侧边的收起态：贴边一侧直边，两个贴边角做反向圆弧（同「贴边圆角」），朝内一侧圆角；高度随内容，上限约 300px（随「折叠岛屿大小」缩放）。顺序 Agent → 未读消息 → 邮件 → 音乐 → 待办 → 计时器 → 用量 → 摄像头 / 麦克风 → 文件中转，放不下的从后往前不显示（切到「全开」看）。文字一律不竖排。
  • 气泡：消息预览、音量 / 亮度、设备提示、Agent 审批从对应图标那一行往屏幕里弹，横向、和岛同色；显示期间对应图标亮起一层浅底。审批气泡不自动消失，点允许 / 拒绝才收；其余按顶边的时长（消息 4 秒、设备 3 秒、音量 1.5 秒）。歌词不弹。
  • 闲置收起：竖向岛缩成把手（现在的 12×72）或更窄的细条；鼠标碰到那条边（左右最外 6px）、或来新消息时滑回竖向岛。收起时音量和设备提示直接丢掉，消息预览按「收起到边缘时，收到新消息自动露出」处理。
  • 展开：外壳从竖向岛长成 560×420 的横版面板，只动外壳，面板内容淡入（F14）。面板竖直方向对齐竖向岛，碰到屏幕上沿或任务栏就往里收（把「沿边位置」拉到最下试）。点面板外面收起回竖向岛。
  • Alt 拖动：沿边上下移，记住 0–1 的位置；往屏幕里拖超过 16px，竖向岛变回横向胶囊跟着鼠标走。拖着胶囊靠近左、右、上边 16px 内时，那条边上出现主题色提示线和落点虚框，松手吸上去。

要你拍板的

  • 造型：A / B / C（推荐 B，C 的封面做成 B 的一个开关）。
  • 气泡：离岛 8px 的独立小卡，还是连着岛长出来（推荐连着，更像岛在伸手；独立卡片在浅色桌面上更清楚）。
  • 闲置收起成什么：保留现在的 12×72 把手（有 Agent 色点和未读点），还是 5px 细条（推荐把手，细条在 4K 屏上太难碰）。
  • 面板竖直对齐：对齐竖向岛的中线还是顶（推荐中线，岛在屏幕中间时面板上下都留空间）。
  • 放不下时：直接不显示，还是最底下一个「+N」（推荐 +N，点它展开）。
