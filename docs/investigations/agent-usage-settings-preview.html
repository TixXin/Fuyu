方案 B 第二版：电脑上有哪些 Agent，就显示哪些额度

你选了 B（所见即所改）。这一版把「显示哪家」从固定的 Claude Code / Codex 换成跟着这台电脑走：接入了哪些 Agent、其中哪些读得到额度，就列哪些。下面可以切换几种电脑看看效果，窗口里的东西都能点。

  • 列哪些：设置 → Agent → 「接入哪些 Agent」里开着、钩子装好了的，再加上读得到额度的。现在读得到的有 Claude Code、Codex、Antigravity（按模型）、Cursor（本月和 Auto），WorkBuddy、DeepSeek Harness 读到的是积分和余额，没有百分比，就写数字；GLM、Kimi 是套餐，填了 Key 才出现。
  • 读不到额度的（Grok CLI、GitHub Copilot CLI、CodeBuddy 等）不占一行，只在下面用一行小字写出来，免得以为是漏了。
  • 新接入一家时默认就显示；在这里点掉的才隐藏（记的是「隐藏了哪些」，所以以后新装的 Agent 不会被漏掉）。
  • 额度一列一列对齐：5 小时、7 天，然后是「其他」（按模型、按月这类各家自己的）。点列名隐藏整列，点图标隐藏那一家。
