要点（详细见任务 C76 备注里的「交互方案」）

  • 和现有两种模式的关系：「展开方式」从两项变三项：点击（默认）/ 悬停 / 悬停预览。悬停预览 = 点击模式 + 悬停时先出预览；它和「悬停直接展开」互斥，不叠加。
  • 预览层：收起条那一行原样留在上面（状态灯、环、会话数、音量提示照常），摘要文字淡出；下面长出一行 48px 的卡片区。岛从 38×（约 320）长到 86×400，圆角跟着变大一点。
  • 出现 / 消失：光标停满「悬停延迟」（复用现有设置，默认 300ms）出来，移开 200ms 缩回；按下鼠标、按住 Alt、消息一行预览或横幅显示中都不出；缩回后要移开再回来才会再出。
  • 进入展开：点空白或卡片（卡片直接打开对应页面）、在预览上向下滚一格；向上滚一格缩回收起条。继续停留自动展开默认关。
  • 滚轮切页：独立开关，默认关。只在顶部图标栏一行滚算切页，内容区永远交给页面自己滚；累计满一格切一页，切完 450ms 内的滚动全吞掉（触控板惯性），到头不循环。
