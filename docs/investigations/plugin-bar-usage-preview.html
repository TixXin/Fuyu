插件页的收起条占用一览（E77.3）

12 个官方插件里 8 个要占收起条，用户看不到谁占了多宽、为什么有的没显示。插件页加一块小图回答三个问题：现在谁在收起条上、各占多宽、谁没显示以及为什么。点一项能调它的先后、换到另一侧，或者不让它上收起条。

数字从哪来：岛按内容量出每个插件项的宽度（docs/plugins/services-and-slots.md 的 island.collapsed/v1），收起条最宽 520px，放不下时插件项在右端被裁掉。设置窗口向岛要一份当前的量法结果，所以图上是真实宽度，不是估的。下面的数据是示意。

做法 A：按比例的收起条小图 + 列表推荐

上面一条就是收起条本身，按真实比例画：灰色是浮屿自己的内容（状态灯、文字、内置项），彩色是各插件项，位置和宽度都是量出来的；被裁掉的画斜纹。下面的列表按从左到右的顺序列出每一项，没显示的排在最后并写明原因。点图上的一段或列表的一行，展开操作。

做法 B：预算条

不画位置，只画「520px 的额度被谁用掉了」：一条从 0 到上限的条，浮屿自己的内容加各插件项依次堆上去，超出上限的那段画红。一眼能看出超没超，但看不出谁在左谁在右，也看不出被裁的是哪一个（实际被裁的是最右边的项，不是堆在最后的项）。

推荐 A。任务要的是「按现在的顺序画出每个插件占的位置和宽度」，只有按比例的小图同时给出位置、宽度和被裁的是谁；列表兼作图例和操作入口。按 A 实现，细节：

  • 放在已装插件列表下面、推荐插件上面，标题「收起条上的插件」；没有任何插件往收起条放东西时整块不出现。
  • 标题右侧一句总数：「3 个插件共占 184 px，收起条现在 412 px，最宽 520 px」；有被裁的换成警告色的「有 1 项放不下」。
  • 没显示的原因分四种写清：你把它从收起条上拿掉了；放不下，右端被裁掉 N px；插件现在没有要显示的内容；插件关着。
  • 点一项展开操作：往前、往后、换到左侧 / 右侧、不在收起条上显示（写的是外观页「收起条项目」用的同一份布局）、打开这个插件的设置。
  • 岛展开着或还没连上时，图用最近一次量到的结果并注明；一次都没量到就只列出声明了收起条的插件。
