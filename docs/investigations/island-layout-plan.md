起因（用户，2026-11-20）：

- 「收起条上的内容，DIY 设置入口太多了：插件里可以设置，外观收起条项目里也可以设置。」

状态：**已定，拆成任务 [C156](/docs/tasks/0-archive/C/C156.md)**（#1131，子任务 C156.1–C156.4 / #1132–#1135）。用户 2026-11-20 对四个问题都答「都要」（见「已定」）。预览页：[island-layout-preview.html](island-layout-preview.html)。前一轮的收起条方案见 [island-items-plan.md](island-items-plan.md)（C139），本方案在它上面接着做，不推翻已经做好的清单、右键菜单和「+N」。

所以用户的感受是对的：同一件事（这个东西在岛上显示不显示、放哪、长什么样）有 4 到 6 个入口，而且「开不开功能」「放在哪」「长什么样」三件事混在一起。

## 原则

**功能页只管功能本身，岛上的事都在「岛屿布局」里管。**

- 功能页、插件设置：功能开不开、数据从哪来、账号、提醒这类。
- 岛屿布局：显示不显示、放哪（左 / 右 / 文字位 / 小面板 / 面板里）、顺序、样式、大小。
- 快捷入口（右键菜单、岛上编辑模式）改的是岛屿布局的同一份数据，不另存。

## 一、收起条入口收拢

### 1. 新的一级设置页「岛屿布局」

从「外观」里拿出来，侧栏单独一项，分两节：**收起条**、**展开页面**。外观 → 收起条里的「+N」开关和刘海两侧最宽一起搬过来。

### 2. 收起条一节

- 顶部一条和真岛一样大的**收起条预览**，按当前布局画出来；点预览上的一项，下面清单滚到这一行并展开。
- 清单就是现在的「收起条上的项目」：左侧、文字位、右侧、小面板、不显示五组，行能上移 / 下移、换组（预览页里演示拖动，做的时候先保留上下移按钮）。
- **文字位**加入清单：临时提示、会议、歌词、Agent 标题、待办。现在是写死的先后和歌词 / Agent 二选一，改成可排序、可单独隐藏。这一条由 C139.4 做（C139 方案的 D 项），C156.1 不等它，先建好页面，C139.4 直接把文字位做在新页面里。临时提示和消息预览仍然最优先，不参与排序。
- **每一行能展开，里面是它的样式**，从各功能页搬过来：
  - 状态灯：悬岛 / 圆点
  - 会话环：像素格 / 分段环 / 状态条 / 信号格，显示会话数
  - 用量环：哪几个 Agent 上岛
  - 中心图案：图案、宠物、大小
  - 待办：「剩余 N 个待办」
  - 组件（见第二部分）：尺寸
- 原位置删掉，留一行只读链接：「在岛上：右侧第 3 个 · 调整 ›」，点了打开岛屿布局并定位到这一行。插件详情的「显示在岛上」开关也换成这行链接。
- 右键菜单保留，底部「排列…」改成打开岛屿布局。

### 3. 第三方插件的样式

插件设置里的某个字段可以声明为岛上样式（设置 schema 多一个 `placement: "island"` 一类的标记，名字做的时候定），它就画在岛屿布局那一行里，不在插件设置页。先只给内置插件用，第 5 阶段再开放。

### 4. 存储

不加新 key。位置还在 `fuyu-collapsed-items`；样式还在各自原来的设置里（`agentLightStyle`、插件设置等），只是编辑的地方换了。文字位的顺序是 `fuyu-collapsed-items` 里多出来的几个 id（`zone: "text"`），旧版本读到不认识的 zone 时按默认处理，做的时候在 `contracts.md` 写清。

## 二、自定义面板

> 2026-11-20 C156.3 合入后改：用户嫌设置太复杂，设置页改成「收起条 / 展开」切换加标签（预览 [island-widgets-settings-preview.html](island-widgets-settings-preview.html)，决定记在 [collapsed-bar.md](../design/collapsed-bar.md)「收起条 / 展开切换和自定义面板」）。下面第 3–6 节按新做法改过，原来的画布、组件库搜索、拖到收起条预览上的做法不再用。

### 1. 概念

- **组件**：一个功能的一块视图，声明自己支持哪几档尺寸。
- **自定义面板**：用户新建的一页，有名字和图标，在顶部页面栏里和待办、音乐这些页面并排，里面摆组件。
- **收起条也是组件的一个位置**：组件的 `bar` 尺寸就是收起条项目。所以一个组件可以同时在收起条上、在面板里。

### 2. 尺寸

| 尺寸 | 网格占位 | 大致内容 |
|---|---|---|
| `bar` | 收起条上一项，高 24 | 现在的收起条项目：环、图标、读数 |
| 小 | 1×1（约 120×120） | 一个数字或一个状态：用量环、天气、世界时钟一座城 |
| 中 | 2×1 | 一行列表或一组按钮：正在播放、下一个会议、快捷启动 |
| 大 | 2×2 | 列表：今天的待办、Agent 会话、最近剪贴板 |
| 宽 | 4×1 | 一整行：歌词、系统监控的曲线 |

组件只需要支持其中几档，不支持的尺寸在选择器里不出现。

### 3. 网格和自由（已定 A）

- **网格（默认）**：4 列，格子 120×120、间距 8，岛宽 560 时正好；岛更宽时格子不放大，左右居中。用户不摆位置：组件按顺序从左上往右下自动排，每个放进第一个放得下的格子，加、拿掉、换大小、换顺序都重新排。高度最多 4 行，超出时面板内滚动。
- **自由（「自己摆」）**：每个面板单独打开。组件按 8px 细网格吸附，可以任意位置、任意宽高（不小于这个尺寸档的最小值），可以重叠，后放的在上面。存的仍是格子坐标（单位 8px），所以两种模式能互相切换：自由切回网格时按组件位置（先上后下、先左后右）定顺序，再自动排一遍。岛上编辑模式和设置页都能拖：设置页的画布只在「自己摆」的面板出现，网格面板仍是标签式（用户 2026-11-20 定）。
- 自由模式下组件的宽高由用户定，组件按容器大小自己排版（容器查询），不再只看尺寸档。

### 4. 两个编辑的地方（已定 B）

- **设置 → 岛屿布局（切到「展开」）**：上面是展开岛的预览（选中的页面、面板里组件的位置和大小）；下面「展开页面」一排标签（排序、隐藏、新建面板），选中自定义面板时是「面板里的组件」（名字、图标、删除；左栏已加的组件标签可拖动换顺序、× 拿掉，右栏「可以添加」按功能分组点 ＋）和「大小」（缩略图卡片）。没有画布、没有搜索。
- **岛上编辑模式**：自定义面板右上角一个「编辑」按钮（或在面板空白处长按 0.5 秒）。进入后：
  - 组件轻微晃动、左上角出现「−」，右下角出现拉伸角；
  - 拖组件移动它，**这时拖动不拖岛**（编辑模式里关掉拖岛的手势，这是之前拒绝在岛上拖动排序的原因，现在用模式隔开）；
  - 面板底部出一条「+ 添加组件」，点开是设置里「可以添加」那份清单；网格面板里拖组件是换顺序，点组件在它支持的大小里循环换（用户 2026-11-20 定），自由面板里拖是移位置；
  - 点「完成」、按 Esc、或点岛外退出。编辑模式里岛不会自动收起、不会悬停切页。
- 两处改的是同一份数据，设置窗口和岛通过 `storage` 事件互相跟随（和 `fuyu-collapsed-items` 一样）。

### 5. 收起条上的组件（已定 C）

- 有 `bar` 尺寸的组件能放上收起条，在设置的「收起条」那一页管（C156.3 第一版是组件库里的「条」按钮，重做设置时去掉了；收起条那一页改成标签加「在收起条上 / 可以放上去」两栏，单独是 C156.5）。
- 收起条上已有的内置项目（用量环、会话环、天气等）都变成组件的 `bar` 尺寸，所以它们也能放进面板，用更大的尺寸显示。
- 插件接口：新插槽 `island.widget/v1`，一项声明 `sizes: ["bar", "s", "m", "l", "w"]` 的子集，组件拿到 `size` 和容器宽高。现有 `island.collapsed/v1` 保留，宿主把它当成只有 `bar` 尺寸的组件，旧插件不用改。

### 6. 展开页面一节

- 列出所有页面：内置页面、插件页面、自定义面板，能排序、隐藏（隐藏不等于关功能，功能照常在后台跑）。这顺手解决「页面顺序不能调」。
- 「+ 新建面板」：点了直接建好并选中，名字「新面板」，名字和图标在下面改。模板（「工作台」：待办 + 会议 + Agent；「娱乐」：正在播放 + 歌词 + 天气）在 C156.4 做：空面板里放这两个按钮，不点就是空白（用户 2026-11-20 定）。
- 默认没有自定义面板，老用户升级后看不出变化。

### 7. 存储（新 key，做的时候写进 contracts.md）

- `fuyu-island-pages`：`{ version: 1, order: [页面 id], hidden: [页面 id] }`。没有这个 key 时是现在的顺序。
- `fuyu-custom-panels`：`{ version: 1, panels: [{ id, name, icon, mode: "grid" | "free", items: [{ widget, size, x, y, w, h }] }] }`，`x/y/w/h` 单位 8px。
- 两个都进同步白名单（`src-tauri/src/sync/settings_whitelist.json`）和设置备份。

## 分步（已定 D：都做）

1. **收拢入口**：建「岛屿布局」页，收起条一节（预览、清单、样式搬家、文字位排序），各处原位置换成链接。
2. **展开页面排序和隐藏**：`fuyu-island-pages`。
3. **组件和自定义面板**：`island.widget/v1` 插槽（先只给内置插件），把现有收起条项目改成组件的 `bar` 尺寸，每个内置功能出一两个大尺寸组件，网格模式，设置里编辑。
4. **补全**：自由模式、岛上编辑模式、面板模板，`island.widget/v1` 开放给第三方插件。

每一步单独成任务：C156.1 →  C156.2 → C156.3 → C156.4，上一步合入再开下一步。第 3 步工作量最大，主要花在每个组件的大尺寸设计上。

## 风险

- **岛上编辑和拖岛**：用模式隔开，进编辑模式要有明显的样子（晃动、底部完成按钮），否则用户会以为岛坏了拖不动。
- **自由模式难看**：重叠、留白不齐。所以默认网格，自由是每个面板单独打开的。
- **岛的高度**：面板 4 行时岛高约 520，在小屏上会盖住很多。超出屏幕高度 60% 时面板内滚动。
- **刘海屏**：自定义面板展开后和其他页面一样，不受刘海影响；收起条上的组件仍然走「+N」规则。
- **样式搬家影响老用户的习惯**：原位置留链接一段时间（两个版本），再删。
