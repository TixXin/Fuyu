A

分层聚焦流（Focused Split Feed）

推荐默认

保留最顺手的单列阅读动线，用「顶栏筛选 + 极简微额度 + 活跃/已完成明确分层 + 两行规整结构」彻底消除杂乱。

核心改法

  • 顶栏合一：左侧放状态筛选（全部 / 需处理 / 运行中 / 已完成），右侧放超轻「图标+数字+底色水位线」微额度条，点一下展开完整明细，不再用 5 颗厚重圆胶囊压在列表头上。
  • 强分层：需处理/运行中给轻底色卡 + 左侧语义竖线，固定两行（标题行 + 单行微命令条）；已完成收进底部静默区，极简 34px 单行且支持一键折叠。
  • 去噪提纯：项目名做成柔和微标签与标题分离；模型退出灰框改为极淡纯文字；水母拥有独立 22px 槽位，再也不贴字。

适合谁

  • 想要最平滑升级、同时兼顾 Mac 刘海宽岛和 Windows 常规岛宽的默认主力布局。
试一试：点顶栏状态筛选、点右上角额度条看浮窗、点「▸ 2 子任务」展开、悬停行右侧试归档与撤销。
B

双栏工作台（Master-Detail Workbench）

宽岛体验最佳

像消息页的三栏思路一样善用 800px 宽岛：左栏极简索引高速扫视，右栏实时看完整命令、提问、子任务与快捷按钮。

核心改法

  • 左栏彻底瘦身：只保留「状态灯 + 标题 + 项目微字 + 图标/时间」，所有行等高整齐，扫 10 个会话毫不费眼。
  • 右栏即实时视窗：选中会话立即展示完整命令行（不再截断省略号）、你刚才的提问、模型/权限/路径、子 Agent 进度，底部直接放「跳到窗口」「打开目录」「归档」。
  • 宽窄自适应：800px 展示双栏；切到 580 / 440 窄岛自动退化成单栏列表，点击进入详情页。

取舍

  • 只看一眼就想跳转时，比单列多一次「先选中再看详情」的心理分区（但默认自动选中最紧急会话）。
试一试：点击左栏任意会话切换右侧实时面板；把顶部「岛宽」切到 580 / 440 看自动退化为单栏+返回。
C

智能双列网格（Bento Grid）

消灭宽岛右侧大片空白：需处理任务横跨置顶，运行中排 2 列活态卡片，已完成排 2 列紧凑胶囊，一屏装下 6–8 条零滚动。

核心改法

  • 紧急项横幅置顶：「等你确认 / 出错」独占顶部整行，给足命令预览和「立即处理」按钮，不可能漏看。
  • 双列齐整：每个活跃卡片内部固定「状态+项目+时间 / 标题 / 微终端条+模型」三段，视线在卡片内垂直扫完，告别 800px 左右横跳。
  • 高信息密度：已完成会话双列静默排布，5–8 个会话常常一屏全览，不用滚轮。

取舍

  • 标题非常长时双列卡片会比单列更早触发省略号（悬停可看全文）。
试一试：切换顶栏「高并发 9条」感受双列一屏容纳量，再切到「窄岛 440」看自动回退单列。
D

项目指挥台（Project-Grouped Deck）

去掉每行重复的 Fuyu · / Fuxi · 前缀，按项目文件夹收纳成表格对齐块，同一仓库并行多个 Agent 时极度清爽。

核心改法

  • 消除重复前缀：截图里 4 条都在 Fuyu 里，归组后标题瞬间干净一截，组头顺带显示活跃数和「打开文件夹」入口。
  • 锋利的四列对齐：状态列 | 标题与实时动态 | 模型与来源 | 时间/操作，像 IDE 面板一样垂直严丝合缝。
  • 项目心智优先：同时盯 2–3 个仓库做并行开发时，一眼看清每个项目卡在哪一步。

取舍

  • 如果大部分会话散落在不同目录（每个目录只有 1 条），分组头会多占一些垂直空间。
试一试：点击组头右侧「打开目录」或点行内交互，切「高并发 9条」看多仓库分组效果。
E

极简启动器清单（Linear / Raycast 风格）

彻底做减法：拿掉所有胶囊框和卡片边框，纯靠字重、等宽列与灰度层级呼吸，配合键盘高亮行与底栏提示。

核心改法

  • 零胶囊美学：顶部额度压成 28px 无边框细刻度轨；命令名不再套蓝底灰块，改为极简终端前缀 › run_command；模型改为最淡的等宽文字。
  • 渐进展开：未选中行极致克制；点击或用 ↑↓ 选中的行高亮并自动展开「你的提问」与快捷动作，不把所有细节一次性倒在眼前。
  • 原生 Mac 质感：底栏极淡快捷键提示，整体视觉重心稳、最耐看。

取舍

  • 视觉非常克制，重度依赖大色块/边框发光的用户可能会觉得状态区分偏素。
试一试：点击列表不同行看渐进展开的「你的提问」与底栏路径联动，也可点击额度细轨查看详情。
