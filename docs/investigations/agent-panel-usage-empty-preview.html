Agent 页：额度显示设置 + 空状态

上半部分是「显示哪些额度」的三种设置做法，左边的设置可以直接点，右边的岛会跟着变；下半部分是「没有会话」时的六种画面。每块右上角点「选这个」，最底下会汇总成一句话，复制回来给我就行。

一、额度显示的设置

现在只有一个「显示额度」总开关，显示哪家、哪个窗口都定死了。下面三种做法共用同一份假数据：Claude Code 5 小时 42%、7 天 16%、Opus 7 天 63%；Codex 5 小时 8%、7 天 16%。

A · 分项勾选数据都有

设置里加一组「额度」，哪家、哪些窗口、重置时间、样式分开选。最灵活，设置项最多。

样式切到「进度条」「圆环」看看；只勾一个窗口时一行会很短，右边放重置时间。

B · 一个下拉选模式数据都有

把组合收成几个常用模式，加上每家一个开关。设置页只多两行，大多数人不用想。

「只看最紧的」：每家只显示用得最多的那一项，旁边写是哪个窗口，一行最短。

C · 在岛上点额度行直接改数据都有

右键（或点住）额度行弹出小菜单，勾了立刻生效；设置页里放同一组选项，两边是同一份设置。改的地方就在看的地方。

菜单里的勾选能点。没有会话时菜单也能开（额度行还在）。

二、没有会话时的画面

都按真实岛的大小画，额度行按上面「默认」显示。标「要加记录」的需要多存一点历史，其余用现有数据就能做。

1 · 水母打盹现有数据

岛的水母闭眼漂着、冒 Zzz 和小气泡。文案轻一点：「都歇着呢」。开会话时它醒过来、眼睛睁开，列表接着出来。

2 · 待命台现有数据

每家一张小卡，写清钩子接好没有。空着的时候最常见的疑问是「是没会话，还是没接上」，这里一眼就能看出来；没接的那家直接给「去接入」。

3 · 上一段现有数据

不是真的空，是被「隐藏已结束 / 时间范围」筛掉了：灰着显示上一个会话，给「显示已结束的 3 个」「看 24 小时内」两个按钮。真没有会话时退回成一句话。

4 · 额度当主角现有数据

没会话可看时，页面最有用的就是额度：上面那行放大成圆环，带重置倒计时，「没有进行中的会话」退到底下一行小字。关掉额度时退回成 1 或 6。

5 · 今日潮汐要加记录

一条 0–24 点的波浪，Agent 在跑的时段鼓起来，颜色分 Claude / Codex。下面写今天跑了几个会话、一共多久、最后一个多久前结束。需要把每个会话的起止时间多存一天。

6 · 极简水平线现有数据

一个线描小水母浮在一条水平线上，一行字。最安静，不抢眼，适合常开在 Agent 页的人。
