交互

  • 先看后定：悬停或键盘移到候选上，页头立刻换给你看，旁边写「预览中 · 点一下才会换」；移开就回去。点一下才保存，不需要「确定」按钮。
  • 打开就在对的标签：页面现在用的是 emoji，打开就落在 Emoji 标签；当前来源的标签上有个小点。
  • 最近使用：所有页面共用最近 8 个，换来换去不用重新搜。等于免费的「撤销」。
  • 键盘：任意处按 / 聚焦搜索，Esc 清空，方向键在格子里走，回车选中。
  • 搜不到时给出路：「试试英文」「用 emoji」「上传图片」三个按钮，不留死胡同。
  • 图片三种进法：拖进来、点选文件、粘贴（截图、复制的图片、图标网站「Copy SVG」得到的代码都认）。从浏览器拖图片过来时下载一份存本地，以后不联网。
  • 删图片：「我的图片」里点 × 直接删，底部提示「已删除 · 撤销」5 秒；用着它的页面回到默认。

布局

  • 原来 50 个按钮全铺开，占一整屏；现在一张卡片，面板固定最小高度，切换标签时卡片不跳。
  • 全部图标放在 250px 高的滚动区里，推荐和最近在它上面，不用滚就够大多数人。
  • 预览条右边两块放大图：深色岛和浅色岛各一块。16px 下看不出图片糊不糊、在浅色主题下是否看不清，放大图专门解决这个。
  • 窄窗口（试「窄窗口」按钮）：格子自动减列，分段按钮不换行，图片编辑区上下排。
  • 「Fuyu」页仍然把「Fuyu 文字」和「水母」放在推荐最前面。

动效（都用 motion.md 的档位）

  • 页头换图标：旧的 120ms 淡出，新的 160ms 进场。图标可以从 0.82 放大到原大（无文字）；文字和 emoji 只淡入，不缩放，遵守「文字不动位置」。
  • 选中框、悬停底色：120ms 默认曲线；切换来源标签：面板内容 160ms 淡入，不滑动。
  • 拖文件进来：虚线框 120ms 变成强调色；导入后编辑区 240ms 淡入。
  • 不加错开出场、按下缩放、循环动画。减少动画时只剩淡入淡出（试顶部按钮）。

实现要点

  • 存储：lucide:rocket、emoji:🐙、text:工（可带 ;bold）、image:<id>；没有前缀的旧值照旧当图标名读，老用户不用迁移。记进 contracts.md。
  • 图标：设置窗口打开搜索时才懒加载整套 lucide（单独一个 chunk）；岛只按名字加载用到的那几个，岛的包不变大。中文关键词自己维护一份常用词表，其余靠英文名和 lucide 的 tags。
  • 图片：导入时按裁剪结果统一转成 96×96 PNG，存进 localStorage 的 fuyu-page-icons（跟着设置备份和同步走，记进 data-storage.md）；SVG 先过 dompurify。「跟随主题」用 CSS mask 当单色剪影，颜色跟岛上文字走。
  • 文字：按字形簇计数（Intl.Segmenter），中文最多 2 个、其他最多 3 个；量出宽度超过 30px 时提醒「页头会变宽」。
  • emoji 在 Windows 和 Mac 上长得不一样（系统字体），预览里写明。

没采用

  • 填图标网址：没网就空白、链接失效就没了、岛会去访问第三方。改成「拖进来/粘贴时下载一份」，网址只用一次。
  • 在应用里直接搜 Iconify：要联网、要处理他们的接口和许可；先给出常用网站链接，配合粘贴 SVG，体验已经接近。以后真要做，也是选中后下载存本地。
  • 所有来源混在一个大网格里：几千个候选没有层次，找不到东西。

需要你定

  1. 文字上限：中文 2 个、英文 3 个，可以吗？
  2. Emoji 默认用原色，还是默认「跟随主题」的单色？（预览里默认原色）
  3. 图片统一存 96px 的 PNG（包括 SVG），还是 SVG 保留矢量？PNG 简单、统一，96px 在 2 倍屏上也够清楚。
  4. 「最近使用」要不要？要的话 8 个够不够？
  5. 图片导入的「去哪找图标」放哪几个网站：Lucide、Tabler、Iconify、Phosphor？
