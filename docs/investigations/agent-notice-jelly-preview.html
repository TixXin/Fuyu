Agent 通知里的水母

现在三种通知开头都是 Agent 的品牌图标加状态色。选了「状态灯样式 → 水母」以后，收起条和会话列表已经是水母，通知还不是。这页把卡片、紧凑、两翼三种通知各摆几个方案，水母都是真实的像素画法，按状态播放；选「圆点」时通知保持现状，不在这页里。

像素画风
岛
动画

1 · 卡片（默认样式，图标 26px）

卡片地方最大，水母可以当主角，品牌缩成右下角的角标。

2 · 紧凑（图标 16px）

16px 时水母只剩 11×8 格，再加角标会糊成一团，所以给两种：角标版和把品牌图标挪到状态后面的版。

3 · 刘海两翼（顶条 16px，Mac 刘海旁边）

两翼的顶条贴着刘海，左边一个图标、右边状态。多个会话同时来时左边是一叠图标。
