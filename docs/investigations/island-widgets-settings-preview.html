岛本身一直是黑色，和真岛默认一样；设置窗口跟着深浅色。

和现在那版比，改了什么

现在（dd15a8f7a）这一版
页面列表一行一行，旁边编辑按钮，点开才是面板编辑器「顶部页面」一排标签，就是岛顶部那排按钮的顺序；点哪个，上面的岛就显示哪页。面板标签下面直接能改名字和图标
画布按格子拖，压到别的组件往下挪，方向键移动没有画布。上面的岛就是成品；组件顺序在「面板里」那一栏拖标签换，系统自动从左上往右下排
组件库每行一排「条 / 小 / 中 / 大 / 宽」按钮「可以添加」里每个组件一个标签，点 ＋ 用它最常用的大小加进来；想换大小在最下面点缩略图
收起条和展开页面是页面上分开的两大块舞台下的「收起条 / 展开」切换，下面两栏跟着换成收起条的内容

要你定的几件事

  1. 收起条要不要并进同一个舞台？现在岛屿布局页上半部分是收起条（C156.1 做的：预览 + 左中右三栏 + 样式）。这版把它做成舞台的「收起条」页签，下面两栏变成「在收起条上 / 可以放上去」。建议并进来，左中右位置收进标签的右键或长按，图标样式放到最下面那排缩略图（和面板的大小选择同一个位置）。
  2. 自由拖放还要不要？自动排版在大部分情况下够用，但没法留空、没法把小组件放右下角。建议这版不做，C156.4 再加一个「自己摆」的高级开关。
  3. 一开始有没有面板？现在默认没有，要点「新建面板」。建议仍默认没有，但「顶部页面」那排最后一直有一个虚线的「＋ 新建面板」，点了直接建好并选中，名字叫「我的面板」。
  4. 样式（皮肤）：参考图里每个组件有好几种外观。我们现在只有大小，所以最下面那排缩略图先只放大小；以后组件有了不同外观，也放在这一排。

没变的

  • 存储格式 fuyu-custom-panels 不变：自动排出来的坐标照样写进 x / y / w / h，以后加自由拖放时直接接得上。
  • 顶部页面的顺序和隐藏仍记在 fuyu-island-pages，Alt+数字照这个顺序。
  • 功能关着时组件不出现在「可以添加」里，面板里已有的那一格在岛上空着，标签变灰写「功能已关」。
