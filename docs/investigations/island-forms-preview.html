C65（issue #316）第 1 波：只给你挑样子，不改代码。画面按 1:1 逻辑像素画屏幕上半截（1200 宽）：折叠 300×38、展开 560×490（默认面板宽高）、岛屿圆角默认 16（折叠底角约 12）、贴边圆角默认 8、贴边收起露出 10px，都取自现在的代码和 docs/design/island.md。圆角用 corner-shape: squircle，请用 Edge / Chrome 139+ 打开（和 Windows 上的岛同一个内核）。点岛展开 / 收起；点上面的「形态」看切换过渡。带 ★ 的是推荐值。

已和其他主 agent 约好的前提：形态只在顶边生效，吸到底边、侧边时忽略；「悬空药丸」就是现在拖离顶边后四角圆的造型，不另做一套；Mac 的「刘海」就是 G1.11 的真刘海贴合，Windows 画一个假刘海。

要你定的点

#要定的选项推荐理由
1药丸离顶距离6 / 10 / 14px10px6 看起来像没贴好的贴顶；14 在 1080p 上离得太远，和下面的窗口标题栏挤在一起。10 一眼能看出是"浮着"的。Mac 上从菜单栏下沿往下算。
2药丸阴影有 / 无有（0 8px 24px，深色壁纸 35%、浅色 18%）深色壁纸上几乎看不出，浅色壁纸上没有阴影浅色岛会糊进背景。展开态已经有阴影，折叠态跟着有更统一。
3药丸贴边收起缩进顶边露 10px / 原地缩成短条缩进顶边露 10px和贴顶共用一套：鼠标碰顶边滑出、来消息滑出都不用改。原地短条要另做一块点击区，还会挡住下面窗口。
4Windows 假刘海的宽 × 高宽 200 / 240 / 280，高 28 / 32 / 36240 × 32比贴顶的 300×38 明显窄、矮一圈，又放得下左右各 2–3 个图标；32 和 MacBook 的刘海一样高。随「折叠岛屿大小」缩放。
5刘海上角弧度0 / 6 / 106，固定，下角 14和 Mac 真刘海（G1.11）一致。0 像一块贴上去的黑板；10 在 32 高的刘海上太软。「贴边圆角」滑块只管贴顶，不管刘海。
6刘海里放什么左右两翼 / 图标居中一排 / 什么都不放左右两翼和 Mac 真刘海同一套布局（左：Agent 灯、待办；右：音乐、未读），一份代码。中间空的一段就是"刘海"的样子；全空则看不到 Agent 状态和未读。
7刘海贴边收起（Windows）同宽露 6px / 缩成半宽细条 / 完全藏起同宽，露 6px和贴顶的收起同一个做法（窗口往上滑），只是露出的高度从 10 改成 6；完全藏起后用户找不到岛在哪。Mac 照 G1.11：缩进真刘海里。
8刘海的颜色强制纯黑 / 跟随岛主题折叠、收起强制纯黑；展开跟主题浅色、玻璃的"刘海"不像刘海（切到浅色岛对比一下）。展开后照 Mac 的规则：深色岛顶部一条纯黑往下过渡，浅色岛不变黑。
9Mac 有真刘海时选贴顶 / 药丸自动让到菜单栏下 / 照菜单栏设置自动让到菜单栏下压在菜单栏上时摄像头正好挡住岛的中间（切到「照菜单栏设置」看）。没有刘海的屏上照「菜单栏」设置。
10形态切换的过渡跟随「开合动画」 / 单独一套跟随「开合动画」就是这页的动画：宽 550ms 回弹、高 500ms、圆角 450ms；切换时保持当前状态（展开着就展开着变形）。选「无动画」时直接跳。
11设置放哪外观 → 尺寸与位置 / 位置外观 → 尺寸与位置，最上面「形态」三选一，默认贴顶，随样式预设保存它是外观，和「圆角样式」并列；预设本来就保存圆角、圆角样式。吸到底边 / 侧边时这一项变灰，提示"只在顶边生效"。

其他说明

  • Windows 上的刘海展开后标签栏照常排，不让出中间一段（没有摄像头）；Mac 上照 G1.11 把标签栏分到刘海两边，切到「Mac」能看到。
  • Mac 刘海形态的尺寸跟真刘海走（这里按 14 寸 MacBook Pro 约 185×32 画，两翼各 64），上面「刘海宽 / 高」只管 Windows。
  • 收到消息、短提示时刘海怎么往下长一行，沿用 G1.11 已做的规则，这页不重复画。
