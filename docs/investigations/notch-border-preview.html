刘海边框

Mac 刘海模式（真刘海，或实验台「模拟刘海」）下，岛和刘海连成一整块黑，现在没有描边。这页给它加一圈边：顺着轮廓走，从左边反向弧的尖进屏幕顶边出来，绕过底边，再从右边弧尖回到屏幕里。左边两张卡就是设置里的样子，岛屿和面板各一组，面板可以「同岛屿」。上面两块屏幕是实际大小（可放大看细节），最下面是所有样式的对照。

模拟状态 看「跟随状态」的效果

新消息时岛下面多一行；Agent 等你时边框按状态色闪；完成时绿光扫一下再回到原样。

全部样式

用左边岛屿那组的颜色、粗细和强度画。点「岛屿」「面板」直接套用。

要你定的

  1. 留哪几种样式。七种：关、发丝、辉光、环游、汇流、极光、下沿光。我倾向全留，都是同一套画法换参数，多一种只多几行 CSS；嫌多就砍掉「下沿光」。
  2. 默认值。我倾向岛屿和面板都默认「关」，老用户升级后长相不变；想让人看到这个功能，可以岛屿默认「发丝」（几乎看不出，只是让岛和刘海之间有个边界）。
  3. 「跟随状态」默认开不开。开着时新消息用来源软件的颜色、Agent 等你用橙色闪、完成用绿色扫一下，样式是「关」时也会亮这一下。我倾向默认开，它是这功能最有用的部分：眼角扫一下就知道是谁。
  4. 外发光有没有地方画。辉光、极光、下沿光有一部分画在岛外面，岛窗口在刘海模式下比岛宽多少要在真机上量；不够时要给窗口留几像素透明边（点击判定不变），或者这几种只画内侧。实现时先看，不需要你定，结果会写进任务。
  5. 只做刘海模式，还是普通贴顶的岛也能用。普通贴顶的岛已经有一圈细描边（液态玻璃是油膜边），我倾向这次只做刘海模式，之后要的话把设置从「刘海边框」改名成「边框」再放开。
  6. 设置放哪。外观 → 显示，「刘海两侧最宽」下面一组「刘海边框」，只在 Mac 上显示（实验台模拟刘海时在 Windows 上也显示，方便试）。项目就是左边两张卡。
  7. 省电。环游、汇流、极光会一直动：岛隐藏、全屏、贴边收起时停；系统开了「减少动态效果」时停在静止的样子（环游、汇流退成静止的辉光）；电池供电时要不要也停，你说。
