## 关于这个版本

这是 0.3.8 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **录屏**（Windows）：按 `Ctrl+Shift+6`（数字行和小键盘都行），框选区域、点一个窗口，或按 `F` 录整个屏幕，3 秒后开始录。岛上显示时长，可以暂停，再按一次快捷键停止。默认录成带系统声音的 MP4，选区域前按 `G` 改成 GIF。录好的文件在「视频」下的「浮屿录屏」文件夹，浮屿自己的窗口不会被录进去。设置 → 截图 → 录屏 里可以改默认格式、30 / 60 帧、画质，以及录不录系统声音和麦克风。
- **设置窗口改版**：
  - 打开设置先看到新的「概览」页：岛上轮流演示每个已开启的功能，下面是常用设置和一面功能墙，每个功能一张卡片，带开关。
  - 关掉的功能不再出现在左边菜单里；「外观」和「AI 代理」各合成一项，原来的页面变成页内标签，菜单从 25 项减到 17 项。搜索照样能找到所有设置。
  - 「通用」「行为」「外观」「快捷键」和各功能页重新排版：每个功能页顶部是图标、说明和总开关，长页面拆成标签；滑块一行放下，快捷键显示成键帽。
  - 「关于」页的顶部是一片夜里的海，更新状态写在海上的岛上，点一下岛会跳起来打个招呼；版本那一组改成状态卡片，当前状态和该点的按钮一眼能看到。
- **插件页改版**：已安装的插件和插件市场都是两列卡片，提醒（有更新、缺运行环境、要授权等）显示成卡片上的彩条；插件的设置在弹出的对话框里打开，不再整页跳走。已安装页顶部是插件的图标架和统计，市场顶部有「最受欢迎」推荐。
- **插件列表页能用键盘**：插件打开带搜索框的列表页时，光标直接在搜索框里，`↑` `↓` 选一行，`Enter` 打开，`Esc` 清空。
- **修复**：
  - 插件配置文件损坏时，不再悄悄清空插件的开关、授权和设置：原文件先另存一份，插件页会说明放在哪里。
  - 一个插件自动更新失败，不再挡住其他插件的更新。

## About this release

This is the third beta of 0.3.8. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Screen recording** (Windows): press `Ctrl+Shift+6` (number row or numpad), drag an area, click a window or press `F` for the whole screen, and recording starts after 3 seconds. The island shows the time and can pause; press the shortcut again to stop. It records MP4 with system sound by default; press `G` before choosing the area for a GIF instead. Files go to the Fuyu Recordings folder under Videos, and Fuyu's own windows are left out. Settings → Screenshots → Recording sets the default format, 30 or 60 fps, quality, and whether to record system sound and the microphone.
- **A redesigned Settings window**:
  - Settings now opens on a new Overview page: an island on top plays each feature you have on, with common settings and a wall of feature cards below, each with its own switch.
  - Features that are off no longer appear in the menu, and Appearance and AI Agent are one item each with their pages as tabs, taking the menu from 25 items to 17. Search still finds every setting.
  - General, Behavior, Appearance, Shortcuts and the feature pages are laid out again: each feature page opens with its icon, a line on what it does and its main switch, long pages are split into tabs, sliders fit on one row and shortcuts show as key caps.
  - The About page opens on a night sea with the update status written on a floating island; click the island and it hops and says hello. The Version group is a status card with the current state and the one button you need.
- **Redesigned plugin pages**: installed plugins and the market are two columns of cards, with notes (update available, missing runtime, needs approval and so on) as coloured strips; a plugin's settings open in a dialog instead of replacing the page. The Installed tab opens with a shelf of your plugins and their counts, and the market has a Most liked spotlight.
- **Plugin list pages work from the keyboard**: when a plugin opens a list page with a search box, the box has focus, `↑` `↓` pick a row, `Enter` opens it and `Esc` clears it.
- **Fixes**:
  - A damaged plugin settings file no longer silently wipes plugin switches, permissions and settings: the original is kept aside and the Plugins page says where.
  - One plugin's failed auto-update no longer stops the others.
