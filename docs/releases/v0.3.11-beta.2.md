这是 0.3.11 的第二个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **子 Agent 与子会话默认展开（新，默认关闭）**：在 设置 → AI 代理 中新增「子 Agent / 子会话默认展开」选项，开启后 Claude Code 的子 Agent 列表与 Claude 桌面版的子会话出现时会自动展开。手动展开或收起过的行保持原样。
- **本机接口设置与未开启提示**：本机接口迁移至新版内置插件管理，设置项移至 设置 → 通用 → 本机接口，可一键复制或重新生成访问令牌（令牌不在界面明文显示以保证安全）；当某项内置功能（如待办、笔记、剪贴板）关闭时，请求对应接口会明确返回 503 提示功能已在浮屿中关闭。
- **内置截图与录屏插件化**：截图与录屏功能完成内置插件化改造，快捷键和选区窗口作为后台服务按需常驻，可在 设置 → 插件 里查看与启闭。
- **流光与 AI 标志待机性能优化**：小岛折叠空闲时，AI 代理标志动画改由硬件合成器层接管渲染，消除每秒多达 60 次的主线程布局计算；流光动效默认仅在小岛展开时流动，进一步降低待机能耗。
- **系统监控插件后台能耗降低**：在启用「在后台也记录图表」时，「系统监控」插件将后台采样间隔由 1 秒放宽至 5 秒并保留最近 1 分钟历史，使后台闲置时的 CPU 占用从 27% 降至约 6%。
- **修复**：
  - 修复设置窗口关闭后再打开时，关闭按钮可能残留悬停红点高亮状态的问题。
  - 修复在部分屏幕缩放比例下，展开岛达到最大宽度时顶部两侧圆角被窗口边缘裁切的问题。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.2/Fuyu_0.3.11-beta.2_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.2/Fuyu_0.3.11-beta.2_aarch64.dmg)

This is the second beta of 0.3.11. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Expand subagents and child sessions by default (new, off by default)**: Under Settings → AI Agent, a new "Expand subagents and child sessions" setting automatically opens subagent lists under Claude Code sessions and Claude desktop child sessions as rows appear. Rows you manually toggle remain as you left them.
- **Local API settings and switch handling**: The local API is now managed as a built-in plugin, with its configuration moved to Settings → General → Local API, where you can copy or regenerate the access token without exposing it in plaintext; requests targeting disabled features (such as todos, notes, or clipboard) cleanly return HTTP 503 indicating that the feature is turned off.
- **Screenshot and screen recording pluginization**: Screenshots and screen recordings are now managed under the built-in screenshot plugin with background shortcuts and selection windows, controllable in Settings → Plugins.
- **Idle animation and performance improvements**: The agent mark animation on the collapsed idle island is now handled on composited layers, eliminating up to 60 main-thread layout recalculations per second; the glass flow effect now defaults to running only while expanded to reduce idle power consumption.
- **System Monitor background CPU reduction**: When background chart recording is enabled, the System Monitor plugin now samples every 5 seconds and retains 1 minute of history, reducing idle background CPU usage from ~27% to ~6%.
- **Fixes**:
  - The close button on the Settings window no longer retains its hovered or focused red state after reopening the window.
  - The top rounded corners of the fully expanded island are no longer clipped by the window edge under certain display scaling factors.
