## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_aarch64.dmg)

0.3.14 正式版，包含 v0.3.13 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### 岛屿形态与主题

- **12 套完整风格内置主题**：重做内置主题，提供 12 套覆盖材质、深浅双色、字体、圆角与液态玻璃参数的完整预设，在 设置 → 主题 中一键切换；旧版本已选外观升级后保持原貌。
- **屏幕左右「侧边翼」独立入口（新，默认关闭）**：在 设置 → 侧边翼 中可视化拖拽，将待办、剪贴板、文件中转、日历等页面分流到屏幕左侧或右侧独立抽屉；支持上下拖动边缘把手调位、自动展开与丝滑贴边动效、液态玻璃与窄抽屉适配、多屏热插拔贴边，以及触控板滑动和滚轮切页防连跳。
- **悬停预览展开与翻页优化**：在 设置 → 行为 → 展开与收起 新增「悬停预览」展开方式，鼠标悬停时先滑出按优先级排序的轻量信息卡片（紧急事项置顶、支持轮播与可选倒计时自动展开，点击直达对应页面，向下滚轮展开、向上收起）；展开面板支持按 `Tab` / `Shift+Tab` 切页，新增「页头滚轮切页」开关（默认关闭）；默认展开尺寸调整为 800 × 320，换页默认改用淡入过渡。
- **自定义字体样式、全局字号与本地字体导入**：在 设置 → 主题 → 质感与形状 中可切换内置字体样式（默认、像素、圆润、衬线、等宽）、调节全局字号（85%–125%），或导入本地 `.ttf` / `.otf` / `.woff` / `.woff2` 字体文件，跨主岛、侧边翼与设置窗口实时生效。
- **新版安装引导与版本更新引导**：安装引导收束为清爽的 5 步快速体验加进阶配置中心，支持真岛实时演示 7 种岛屿形态、侧边翼「一键分流」与全套 AI Agent 通知卡片；版本更新引导升级为带主题筛选与「真岛试看」的展示页，交流群二维码支持点击放大，并可在 设置 → 关于 → 帮助 中随时重看。
- **（Mac）刘海模式顶栏收纳与指示灯调整**：展开面板顶栏放不下的页面改收进「··· +N」菜单，不再在窄缝里横滚；录音或录屏时收起态岛屿不再亮起刘海边框，仅在展开面板保留。
- **主岛不接收拖入时穿透外部拖拽**：关闭「文件中转」或关闭「拖入文件时自动展开」且未停留在文件中转页时，外部文件拖拽经过主岛会自动穿透，避免误放或挡住下层窗口。

### 效率工具与硬件

- **跨设备局域网直连同步与剪贴板互传**：在 设置 → 同步 新增「局域网」方式，同一网络里的两台电脑自动发现并用 6 位配对码完成加密配对直接同步，可选开启剪贴板文字互传（默认关闭，需双方开启）。
- **（Windows）Windows 11 任务栏歌词条**：在 设置 → 音乐 开启「在任务栏显示歌词」后，播放时在任务栏托盘左侧显示封面、当前逐字歌词与播放控制按钮，点击打开岛上音乐页且不抢焦点；岛也吸附到任务栏时自动错开不重叠。
- **待办截止日、已顺延天数与截止日提醒**：待办旗子菜单新增「截止日…」月历选择器，行尾按临近程度显示截止徽标与「已顺延 N 天」（顺延超过 1 天显示，可在 设置 → 待办 → 任务 中开关），修正顺延待办按创建时间排序的顺序，并在 设置 → 待办 → 提醒 新增「截止日提醒」（默认前一天）及 Markdown 导出 `(截止 MM-DD)`。（注意：旧版本读写待办数据时不会保留截止日与顺延起始日，开启跨设备同步的多台电脑请一起升级。）
- **延时截图、窗口透明阴影导出与更快选区启动**：新增 3 / 5 / 10 秒延时截图（右键岛上或托盘 / 菜单栏截图按钮，或设置独立快捷键触发，岛上倒计时横幅可随时取消）；选中整个窗口截图时可切换「透明背景与阴影」导出带圆角与柔和投影的 PNG，窗口被部分遮挡也能完整截取；按下截图快捷键后，冻结画面、选区提示与放大镜更快就绪。
- **笔记本电池详情、24 小时曲线与罗技外设电量**：内置电池组件新增充放电剩余时间估算、容量健康度与循环次数、可交互 24 小时电量曲线，以及可选收起条电量芯片（在 设置 → 岛屿布局 中开启，台式机自动隐藏）；外设电量新增支持罗技 Unifying / Bolt / Lightspeed 接收器连接的鼠标与键盘，并支持低电量提醒。
- **计时器页四套可切换布局**：重新设计岛上计时器页，提供左右双栏（默认）、双模式大表盘、速启卡片网格与时间中枢四套布局，可在岛上或 设置 → 计时与提示 → 计时与休息 中随时切换。
- **日历国际节日、多地区节假日与农历倒数日**：日历新增常见国际节日标注（可在 设置 → 日历 中开关），支持一键订阅 13 个国家/地区的官方节假日日历且多地区共存；倒数日与纪念日支持公历/农历切换与闰月，自动按农历跨年计算最近公历日期。
- **大写锁定提示完善**：新增展开态大写锁定胶囊与输入框尾 `⇪` 指示、贴边隐藏时滑出提醒与露边变黄、刘海两翼角标不再被收进「+N」、开启开关时自动演示一次；（Windows）新增密码输入框持续提醒与可选 Num Lock 提示。

### AI Agent

- **Agent 会话页焕新，新增五套可切换布局**：默认为「分层聚焦」，另有「双栏工作台」「双列卡片」「项目指挥台」「极简清单」，可在 Agent 页顶栏随时切换，也在 设置 → AI Agent → 会话列表 提供实时岛屿预览；顶部额度栏新增「极简细条」样式。
- **Claude、Cursor 与 WorkBuddy 额度监控增强**：只用 Claude 桌面端时，Agent 页和用量环里 Claude 的额度也会自动更新（后台由本机 Claude Code 自行查询，不弹钥匙串授权）；（Windows）登录 Cursor 后也能在用量环看到本月用量；WorkBuddy 悬停卡片新增显示当前套餐并说明剩余额度查看位置；Antigravity 离线或额度读取失败时在顶部显示灰胶囊并说明原因。
- **会话通知直达与待审批直达**：点击 Antigravity 2.0 桌面版或 Claude 桌面版会话通知会直接切到对应对话并收起通知；AI Agent 有待处理审批或提问时，悬停或点击展开岛屿直接进入审批卡片页；移除 Antigravity 的岛上命令审批拦截，避免 TURBO 模式和只读命令被逐条打断（保留状态灯、会话列表、用量环与对话跳转）。
- **（Mac）全屏应用下的 AI Agent 系统通知**：全屏应用让岛贴边隐藏时，AI 代理等待确认或出错会发出 macOS 系统通知，点击通知直接打开岛的 Agent 页。

### 插件、设置与性能

- **新官方插件「自选股」与「文件搜索」（插件市场安装）**：「自选股」（1.3.0）在岛上看 A 股、港股、美股行情与日内分时图，提供左图右表等 5 套可切换布局、分时悬停查价、收起条轮播与休市免联网；「文件搜索」（1.1.0）按 `Ctrl+Alt+F`（Mac 上 `⌃⌥F`）按文件名搜索电脑上的文件（Windows 用 Everything，Mac 用 Spotlight），回车打开或直达所在文件夹。
- **多款官方插件焕新（插件市场独立更新）**：天气（1.5.0）新增 5 个免费免 Key 天气源自动切换、国内县区搜索、多城市切换、极端天气提醒与日出日落 / 紫外线 / 空气质量；天气、自选股、文件搜索、倒数日（1.3.0）、GitHub Issues（1.2.0）与闹钟（1.2.0）统一新增首次安装示例数据、页内快捷设置入口并重做岛页界面。
- **统一「网络代理」设置**：在 设置 → 通用 → 网络代理 中可选跟随系统、手动配置 HTTP/SOCKS5 代理（含认证与免代理列表）或直连，打通插件市场、日历、邮箱、应用更新、翻译与全部插件联网，改完立即生效并支持连通性测试。
- **设置体验与本机接口页重做**：版本更新后新增设置项会标注 NEW，支持一键筛选「本版新增」或全部标为已读；在设置窗口按 `Esc` 可直接关闭（有搜索词、弹窗或录快捷键时先退出当前操作）；设置 → 扩展 → 本机接口 重做为顶部状态总控卡与两列开放能力卡片，未开启时下方选项保持展示并呈灰色不可点击状态。
- **插件安装与安全加固**：恢复网页点击插件市场一键安装链接唤起浮屿并弹出签名核验确认；被市场撤销停用的插件在作者发布安全修复版后可自动更新恢复（新增权限时提示确认）；插件支持实时跟随浮屿界面语言，并进一步隔离插件窗口凭据与官方命名空间校验。
- **深度内存与资源优化**：按需懒加载主岛内置展开页、收缩贴边与关闭超高面板后的舞台高度、缩短副窗口闲置释放时长并限制插件宿主内存上限；（Windows）隐藏的副窗口默认启用低内存模式、托盘隐藏主岛时同步挂起渲染可见态，并将系统 OCR 移至短命子进程，主进程闲置内存显著下降。

### 修复

- （Mac）启动浮屿时不再弹出读取 Claude Code 登录信息的钥匙串授权窗口；仅在手动打开「直接向 Anthropic 查询」时询问一次。
- （Mac）关闭剪贴板预热或闲置释放后呼出剪贴板不再抢走焦点，关闭剪贴板时不再导致岛屿抢走键盘焦点、回车粘贴失败或再次呼出闪退；自动粘贴成功后岛上显示「已粘贴」提示。
- 左右侧边翼翻页箭头不再被撑满整行并重叠成“×”，现固定停留在抽屉左右边缘；（Mac）鼠标移到左右侧翼上立即显示悬停效果，无需先点击。
- （Windows）岛放在任务栏上时，展开面板与内容悬浮提示的阴影不再压暗下面的透明岛屿与任务栏。
- （Windows）图形进程反复崩溃导致透明岛不显示、打开设置约 3 秒黑屏且重装无法恢复：1 分钟内连崩 3 次会自动清理图形缓存并切入兼容软渲染重启，不稳定时托盘自动退回原生菜单（含「兼容渲染重启」），并在 设置 → 通用 → 数据 中提供兼容软渲染开关与清理图形缓存入口。
- 升级后此前已安装的官方市场插件不再出现启动失败，启动和刷新市场时会自动按已验签索引迁移恢复。
- WorkBuddy 会话进程追踪与多窗口按目录匹配更准确，（Windows）最小化或隐藏到托盘的窗口点击「跳到窗口」现在能正常恢复。
- 升级到 Antigravity 2.35+ 后 Agent 页顶部重新显示 Antigravity 额度；（Mac）Claude Code 额度过期后会自动走系统代理补查，失败时在「已过期」悬停卡片说明原因。
- （Windows）开着浮屿关机或注销时不再弹出 `node.exe 0xc0000142` 错误，查询开机自启时也不再受子进程输出干扰。
- 从网页点击插件市场一键安装链接打开设置窗口时，能立即读取最新插件列表。
- （Mac）刘海模式下点击「··· +N」菜单靠下项目时面板不再误收起或菜单悬空，收起条右侧异步插件内容不再持续闪烁或不收进「+N」。
- （Mac）液态玻璃开启「透出窗口」时，贴边岛屿圆角与顶部弧线外不再偶尔露出直角背景块。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.14/Fuyu_0.3.14_aarch64.dmg)

The 0.3.14 release, with everything since v0.3.13. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

### Island, themes & appearance

- **12 complete built-in style themes**: replaced the old color swatches with 12 complete presets combining material, dual-tone dark/light colors, typography, corners, and liquid glass parameters under Settings → Theme; existing customized looks stay intact after updating.
- **Independent screen-edge Side Docks (new, off by default)**: drag pages such as Todos, Clipboard, File Shelf, and Calendar into left or right edge drawers under Settings → Side docks, with draggable edge handles, fluid unfolding, liquid glass and narrow-drawer layout support across built-in and plugin pages, display hotplug re-anchoring, and inertia-safe trackpad/wheel switching.
- **Hover preview expand mode and smoother page switching**: choose "Hover preview" under Settings → Behavior → Opening and closing to reveal a priority-ordered preview card before expanding (urgent items pinned, rotating with optional countdown auto-expand, click to jump straight to the page, scroll down to expand or up to close); press `Tab` / `Shift+Tab` to switch pages in the open panel, toggle optional header wheel switching (off by default), enjoy fade transitions by default, and a new 800 × 320 default expanded size.
- **Custom font styles, global scaling, and local font import**: pick built-in font styles (System, Pixel, Rounded, Serif, Mono), scale global text size (85%–125%), or import local `.ttf` / `.otf` / `.woff` / `.woff2` fonts under Settings → Theme → Look and shape, applied live across every window.
- **Redesigned welcome and What's New guides**: streamlined 5-step first-run tour with an expandable setup hub, live island demos across 7 island forms, one-click Side Dock split preview, and real AI Agent notice cards; upgraded What's New into a filterable showcase with live island try-outs, a zoomable community QR card, and replay under Settings → About → Help.
- **(Mac) Notch header overflow menu and recording glow**: panel tabs that do not fit beside the notch now fold into a `··· +N` menu instead of horizontal scrolling; camera and mic glow now appears only on the expanded panel, not the collapsed bar.
- **Pass through external drags when file drop is off**: when File Shelf is disabled or "Open when files are dragged in" is off outside the shelf page, external drags pass straight through the island to underlying windows or the desktop.

### Productivity & devices

- **LAN direct sync and optional clipboard sharing**: Settings → Sync adds a "LAN" mode to discover nearby computers on the same network, pair with a 6-digit code over an encrypted direct link, and optionally share copied text (off by default, requires both sides enabled).
- **(Windows) Windows 11 taskbar lyrics strip**: turn on "Show lyrics on taskbar" under Settings → Music to place the cover art, live word-by-word lyric line, and playback controls next to the Windows 11 system tray; click to open the island Music page without stealing focus, automatically staying clear of a taskbar-docked island.
- **Todo deadlines, carried-over days, and deadline reminders**: set or clear deadlines from the task flag menu calendar picker, see urgency badges and "Carried Nd" (after more than one day, toggleable under Settings → Tasks), fix created-time sorting for carried-over tasks, export `(截止 MM-DD)` in Markdown, and configure deadline reminders under Settings → Tasks → Reminders (default Day before). (Note: older Fuyu versions drop deadline and carry-over fields when saving todos; upgrade synced devices together.)
- **Delayed screenshots, shadowed window export, and faster overlay startup**: capture after a 3 / 5 / 10 s countdown (right-click the island or tray/menu bar screenshot button, or assign a shortcut, cancelable from the island countdown banner); toggle transparent background with rounded corners and soft shadow when capturing a full window (even if occluded); frozen frames, selection hints, and the magnifier now open noticeably faster.
- **Laptop battery details, 24-hour curve, and Logitech receiver battery**: the built-in Battery widget adds remaining/charge-time estimates, health and cycle count, an interactive 24-hour curve, and an optional collapsed bar chip (under Settings → Island layout; hidden on desktops); peripheral battery monitoring now reads mice and keyboards on Logitech Unifying, Bolt, and Lightspeed receivers with low-battery alerts.
- **Four switchable timer layouts**: redesigned the island Timer page with Split studio (default), Dual dial, Preset grid, and Time hub layouts, switchable right on the island or under Settings → Timer & alerts.
- **International festivals, multi-region holiday calendars, and lunar countdowns**: show well-known international festivals in Calendar (toggleable under Settings → Calendar) and subscribe to official holiday calendars for 13 countries/regions side by side; Countdown & Anniversaries now supports lunar dates, leap months, and automatic next-solar-date calculation.
- **Complete Caps Lock alerts**: adds an expanded panel capsule and input-tail `⇪` indicator, tucked slide-out with yellow lip highlight, notch `+N` exemption, and settings preview demo; (Windows) adds continuous password-field warnings and optional Num Lock alerts.

### AI Agent

- **Redesigned Agent sessions page with five layouts**: switch between Focused (default), Split, Bento, Projects, and Minimal from the Agent header, or preview them live in Settings → AI Agent → Session list; the top usage bar also adds a Minimal strip style.
- **Better Claude, Cursor, and WorkBuddy usage tracking**: Claude usage on the Agent page and usage rings now keeps updating even when you only use the Claude desktop app (checked via your local Claude Code with no Keychain prompt); (Windows) Cursor usage rings now work when signed in to Cursor; the WorkBuddy hover card now displays your plan and notes where remaining credits live; Antigravity shows a muted chip with the reason when offline or failing to fetch quota.
- **Direct jump to conversations and pending approvals**: clicking an Antigravity 2.0 or Claude desktop session notice now opens that exact conversation and closes the notice; expanding the island while an AI Agent approval or question is waiting opens the approval view directly; removed island command approval interception for Antigravity so TURBO mode and read-only commands are not interrupted one by one (keeping status lights, sessions, usage, and conversation switching).
- **(Mac) System notifications for fullscreen AI agent alerts**: when a fullscreen app tucks the island away, macOS system notifications alert you if an AI agent needs approval or fails; click to open the Agent page.

### Plugins, settings & performance
