## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_aarch64.dmg)

0.3.9 正式版，包含 v0.3.8 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **岛可以吸附到底边和左右两侧**：设置 → 位置 →「吸附到」可以选底边、左侧或右侧，也可以直接把岛拖到屏幕边上，拖动时会画出提示线。贴在底边时面板往上展开，新消息从上方弹出。贴在左右两侧时，岛立成一列，每行一个图标带数字（Agent、未读、邮件、音乐、待办等），消息和音量提示从岛旁边伸出来，闲置时收成一根把手。「侧边时音乐显示封面」可以在同一页打开（默认关闭）。
- **剪贴板管理视图**：剪贴板窗口标题栏上的「展开成管理视图」把窗口放大到屏幕中间，可以多选（Ctrl / ⌘ 加选、Shift 选一段、Ctrl+A / ⌘A 全选），一次删掉多条，10 秒内能撤销。历史条数上限从 200 提到 500。
- **复制后岛上出卡片**：在剪贴板窗口或岛上的剪贴板页复制一条后，岛上会弹出一张卡片，显示刚复制的内容；鼠标停在上面时不收起，自动粘贴时不弹。显示几秒在 设置 → 剪贴板 →「岛上的复制卡片」里改，也可以关掉。
- **剪贴板收藏置顶和固定键**：剪贴板窗口的「全部」里，收藏的条目排在最上面，用一条分隔线隔开（设置 → 剪贴板 →「收藏的条目置顶」可以关掉）；数字键 1–9 跳过置顶的条目，打开后按 Enter 仍然粘贴最近一条。在操作面板里「设固定键…」给一条按一个字母，之后 `Alt+字母`（Mac 上 `⌥+字母`）直接粘贴它。置顶的条目可以拖动排序，也可以用 `Alt+↑↓`（Mac 上 `⌥↑↓`）移动。
- **收藏网页链接**：在任何程序里复制网址，收起的岛上会弹出「已复制链接」的卡片，点「收藏」就存下来；岛上剪贴板页多了「收藏」一栏，点一下在浏览器里打开，可以拖动排序和删除。剪贴板列表里链接的 ⋯ 菜单里也有「收藏」。
- **剪贴板隐私**：密码管理器清空剪贴板时，浮屿也删掉刚记下的那一条（收藏的不删，默认打开）；打了码的条目可以设成过一段时间自动删除（默认关闭）；单条文字默认最多保存 1 MB，超出的部分截掉并标「已截断」。操作面板里可以一次删掉最近 15 分钟、1 小时或今天复制的条目，收藏的不删，6 秒内可以撤销。
- **（Mac）剪贴板认出来源和接力**：来源按复制它的程序记录，不再总是记成前台程序；从 iPhone 等设备接力过来的内容显示为「其他设备」，不想记录可以在 设置 → 剪贴板 里关掉「记录其他设备复制的内容」。
- **（Mac）跟随鼠标或前台窗口换屏**：设置 → 位置 →「显示在」选跟随鼠标或跟随前台窗口，现在在 Mac 上也起作用。插拔显示器、改分辨率、程序坞换位置后，岛会自己重新摆好。
- **Agent 页更好读**：模型、推理强度和权限模式合成一个小标签，所在程序的图标显示成角标，窄窗口下时间不再被挤出去；用量排成表格。会话排序变化、新会话出现、会话结束和状态变化都有简短的动画。用量过时时只说一句多久之前、为什么旧，已经重置过的时段不再显示旧的百分比。
- **更多 AI Agent**：Agent 页现在也列出 opencode 的会话，opencode 2.x 后台服务在跑时，等你确认和岛上审批也能用。WorkBuddy、Antigravity、DeepSeek Harness 在「安装/修复」后有和 Claude Code 一样的钩子：开始、结束、等你和岛上审批（DeepSeek Harness 只能在岛上拒绝）。SSH 远程主机上也能看到 Antigravity 和 DeepSeek Harness 的会话。这几家的会话卡片也会显示各自记录里有的模型、推理强度、权限模式、待办、当前工具和上下文用量。回复标记改为写进各家的全局提示词文件末尾。设置 → AI Agent →「显示哪些 Agent」每家都有一个开关。
- **会话列表默认看 24 小时**：设置 → AI Agent → 会话列表 里「列出多久内的会话」默认从 2 小时改成 24 小时；以前选过的不变。
- **歌词**：
  - 前奏时显示（新）：设置 → 歌词 →「前奏时显示」，第一句歌词之前收起的岛显示待办（原来的样子）、歌名或一个音符。
  - 跟随封面颜色（新，默认关闭）：在 设置 → 歌词 里打开后，收起岛的波形、卡拉 OK 高亮和音乐页的光晕用当前歌曲封面的颜色，换歌时渐变。
  - 逐字歌词更多：本地歌词文件夹支持 `.ttml` 逐字歌词；网易云的歌曲会先从社区歌词库找逐字歌词，找不到再用逐行歌词。
- **隐藏托盘 / 菜单栏图标**：设置 → 通用 里新增「在托盘显示图标」（Mac 上叫「在菜单栏显示图标」），默认打开。关掉后，再次打开浮屿会直接弹出这一页。「退出岛屿」也放到了通用页最下面。
- **音乐来源可以移除**：设置 里的每个音乐来源都能「移除来源」，60 天没出现过的来源会自动清掉。
- **同时进行多个待办**：开始一个待办不再把别的「进行中」顶掉，可以几个一起进行；完成后自动退出进行中。收起条显示最近开始的那个。
- **岛上的日期选择**：给待办选日期时，弹出的是岛上的日历，不再是系统日期框（Mac 上原来是一张远离岛的白卡片）。今天、选中的日子、过去的日子和别的月份分得清；有「今天」「明天」「下周一」快捷选项，方向键、PageUp / PageDown、Enter、Esc 都能用。
- **剪贴板的空格预览挪到旁边**：按空格预览时，预览出现在剪贴板窗口旁边的独立小窗里（右边放不下就放左边），带滑入和切换动画，不再盖住列表。图片预览出得更快、更清楚。
- **剪贴板的两个打开方式放在一起**：设置 → 剪贴板 里「用 Win+V 打开」和自己的快捷键排成一组；开着 Win+V 时，自己的快捷键叫「备用快捷键」，在 Win+V 被远程桌面、游戏或管理员窗口拦住时用。两个都关时会提示只能从岛上或托盘打开。（Windows）
- **剪贴板键盘操作更顺**：选中的一行多了删除按钮；搜索框为空时左右键切换筛选；点了标题栏或回到固定的窗口后，方向键、数字键、空格和 Del 照样能用。
- **不再抢键盘焦点**：鼠标停在展开的岛上不再把键盘从你正在打字的窗口拿走；想要原来那样悬停就能按翻页键，到 设置 → 快捷键 → 岛上 → 页面切换 打开「悬停时接管键盘」（新，默认关闭）。Windows 上，点收起的岛（消息预览、音乐按钮、Agent 环）也不再抢焦点，开机启动时同样不抢；点开面板后收起时，焦点还给原来的窗口。
- **按钮提示统一**：所有窗口的按钮提示换成浮屿自己的样式，停 1.5 秒出现，截图工具栏里 0.2 秒就出现。
- **邮箱同步失败说清楚原因**：同步失败时，提示后面带上卡在哪一步和服务器的原话，方便排查（例如网易邮箱的「Unsafe Login」）。
- **分别保持深色**：设置 → 外观 里原来的「收起时保持深色」改成「保持深色」一行三个按钮：岛屿、面板、独立窗口（翻译和剪贴板窗口），可以分别选。只在配色是浅色时起作用；设置窗口始终跟随配色。升级后原来的选择不变。
- **剪贴板窗口有标题栏**：窗口顶部多了一条标题栏，按住就能拖动窗口。标题栏上的图钉可以固定窗口：固定后切到别的程序、粘贴之后都不关闭（Windows 上还会记住窗口位置）。窗口里的按钮提示出得更快。
- **修复**：
  - 收起条上的歌词被消息、Agent 等你、会议提醒打断后会回来；会议提醒和歌词轮流显示，不再一直占着。
  - 暂停、继续或播放器重发进度时，歌词不再跳回上一句或卡住不动。
  - 钉钉日历：用预填的地址连接时不再报 405 错误。
  - Claude 桌面版里的 Claude Code 会话，标题和最后一句提问不再显示系统插入的提示文字。
  - （Mac）按空格预览时剪贴板窗口不再被关掉；固定的剪贴板窗口会记住位置；没开「辅助功能」时，顺序粘贴不再跳过第一条。
  - （Mac）四指切换桌面时岛不再消失再出现，一直待在刘海处。
  - （Mac）拖动岛时不再乱跳；拖到菜单栏附近按岛的真实上沿吸附；拖回屏幕正中顶部会回到默认位置。
  - 剪贴板按空格预览复制的图片文件（例如 PixPin 截图、从微信或访达复制的图片）时显示图片本身，不再只显示路径。
  - （Windows）刚开机时按 Win+V 打不开剪贴板、岛偶尔自己隐藏、截图偶尔报窗口已存在，这几个问题修好了。
  - 微信提醒：从手机给正在打开的聊天发消息，岛上不再把你自己的消息当成新消息提醒。
  - 升级后会话环等内置插件有时一直显示为关闭，现在会自动重试加载。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.9/Fuyu_0.3.9_aarch64.dmg)

The 0.3.9 release, with everything since v0.3.8. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Dock the island to the bottom or either side**: Settings → Position → Dock to now offers the bottom edge and the left or right side, or drag the island to a screen edge; a line shows where it will dock. At the bottom, the panel opens upward and new messages pop up above. On the left or right, the island stands up as a column with one icon and count per row (agents, unread, mail, music, todos and more), messages and volume hints grow out beside it, and it tucks into a small handle when idle. "Show album art on the side" is on the same page (off by default).
- **A manage view for the clipboard**: "Expand into the manager" on the clipboard window's title bar opens a large window in the middle of the screen where you can select many entries (Ctrl / ⌘ to add one, Shift for a range, Ctrl+A / ⌘A for all) and delete them together, with 10 seconds to undo. History now keeps up to 500 entries instead of 200.
- **A card for what you just copied**: copying an entry from the clipboard window or the island's clipboard page pops a card on the island showing what was copied; it stays while the pointer is on it and does not appear when the entry is pasted for you. Change how long it shows, or turn it off, under Settings → Clipboard → "Copy card on the island".
- **Pinned favorites and pin keys in the clipboard**: in the clipboard window's All list, favorites sit at the top under a divider (turn it off with Settings → Clipboard → "Pin favorites to the top"); the 1–9 keys skip them, so opening the window and pressing Enter still pastes your last copy. "Set pin key…" in the action panel gives an entry a letter, and `Alt+letter` (`⌥+letter` on a Mac) pastes it. Drag pinned entries to reorder them, or move them with `Alt+↑↓` (`⌥↑↓` on a Mac).
- **Bookmark links**: copy a web address in any app and the collapsed island offers a "Link copied" card with a Bookmark button. Saved links live under the new Bookmarks chip on the island's clipboard page: click to open in the browser, drag to reorder, or delete. Link rows in the clipboard list have Bookmark in their ⋯ menu too.
- **Clipboard privacy**: when a password manager clears the clipboard, Fuyu forgets the entry it just recorded (favorites kept; on by default); masked entries can be deleted automatically after a while (off by default); text is capped at 1 MB per entry by default and marked "Truncated" beyond that. The action panel can delete everything copied in the last 15 minutes, hour or today, favorites kept, with 6 seconds to undo.
- **(Mac) Clipboard sources and Handoff**: entries record the app that actually copied them instead of whatever was in front, and content handed off from an iPhone or another device shows as "Other device"; you can stop recording it with Settings → Clipboard → "Record content copied on other devices".
- **(Mac) Follow the cursor or front window across displays**: Settings → Position → "Show on" with Follow cursor or Follow front window now works on a Mac, and the island re-places itself when displays are plugged in or out, the resolution changes or the Dock moves.
- **An easier-to-read Agent page**: model, reasoning effort and permission mode share one pill, the host app shows as a badge on the agent icon, and the time no longer gets pushed out in narrow windows; usage is laid out as a table. Reordering, new sessions, finished sessions and status changes animate briefly. Stale usage says once how old it is and why, and windows that have reset since are no longer shown with their old percentage.
- **More AI agents**: the Agent page now lists opencode sessions, and while the opencode 2.x background service runs, its waiting state and approvals on the island work too. After Install/repair, WorkBuddy, Antigravity and DeepSeek Harness get the same hooks as Claude Code: start, finish, waiting and approval on the island (DeepSeek Harness can only be denied from the island). Antigravity and DeepSeek Harness sessions on SSH remote hosts show up as well, and their session cards show the model, reasoning effort, permission mode, todos, current tool and context use where each agent records them. The reply marker now goes at the end of each agent's global prompt file. Settings → AI Agent → "Agents shown" has a switch for every agent.
- **The session list covers 24 hours by default**: under Settings → AI Agent → Session list, the default time window is now 24 hours instead of 2; a value you chose before is kept.
- **Lyrics**:
  - Before the first line (new): under Settings → Lyrics, choose what the collapsed island shows before the first line: the todo (as before), the song title or a note.
  - Match album art (new, off by default): turn it on in Settings → Lyrics to colour the collapsed island's waveform, the karaoke highlight and the music page glow from the current song's cover, fading between songs.
  - More word-by-word lyrics: the local lyrics folder takes `.ttml` word-timed files, and NetEase Cloud Music songs first look for word-by-word lyrics in a community library before falling back to line-by-line lyrics.
- **Hide the tray / menu bar icon**: Settings → General has a new "Show icon in the system tray" switch ("Show icon in the menu bar" on a Mac), on by default. With it off, opening Fuyu again brings up that page. Quit is now also at the bottom of the General page.
- **Remove music sources**: each music source in Settings can be removed with "Remove source", and sources not seen for 60 days are cleared on their own.
- **Several todos in progress at once**: starting a todo no longer stops the one already in progress, so several can run together; finishing one takes it out of progress. The collapsed island shows the one started most recently.
- **A date picker on the island**: picking a date for a todo opens a calendar on the island instead of the system date box (on a Mac that was a white card far from the island). Today, the chosen day, past days and other months are easy to tell apart; Today, Tomorrow and Next Monday are one click, and the arrow keys, PageUp / PageDown, Enter and Esc work.
- **Clipboard space preview moves alongside**: pressing space now opens the preview in its own small window next to the clipboard window (on the left when the right has no room), sliding in and crossfading between entries, instead of covering the list. Image previews load faster and sharper.
- **Both ways to open the clipboard in one group**: in Settings → Clipboard, "Open with Win+V" and your own shortcut now sit together. With Win+V on, your shortcut is the "Backup shortcut", for when Win+V is caught by Remote Desktop, a game or an administrator window. With both off, a note says the clipboard opens only from the island or the tray. (Windows)
- **Smoother clipboard keys**: the selected row has a delete button; with an empty search box, left and right switch the filters; arrows, number keys, space and Del keep working after you click the title bar or come back to a pinned window.
- **No more stolen keyboard focus**: resting the cursor on the expanded island no longer takes the keyboard from the window you are typing in. To get the page keys on hover back, turn on "Take the keyboard on hover" under Settings → Shortcuts → On the island → Page switching (new, off by default). On Windows, clicking the collapsed island (a message preview, the music buttons, the agent ring) and starting at login no longer take focus either; when a panel you opened by clicking collapses, focus goes back to the window you were in.
- **One tooltip style everywhere**: every window now uses Fuyu's own tooltips, shown after 1.5 seconds, or 0.2 seconds in the screenshot toolbars.
- **Mailbox sync errors say why**: when a sync fails, the message now names the step it stopped at and what the server said (for example NetEase's "Unsafe Login").
- **Keep parts dark separately**: in Settings → Appearance, "Stay dark when collapsed" is now a "Keep dark" row with three buttons: Island, Panel and Other windows (the translation and clipboard windows), each chosen on its own. They only matter while the colors are light; the settings window always follows the colors. Your current choice is kept after updating.
- **A title bar for the clipboard window**: drag the window by its new title bar. The pin on it keeps the window open when you switch to another app and after pasting (on Windows it also remembers where the window was). Tooltips in the window show sooner.
- **Fixes**:
  - Collapsed-island lyrics come back after a message, an agent waiting for you or a meeting reminder; meeting reminders now take turns with the lyrics instead of holding the bar.
  - Lyrics no longer jump back a line or freeze when you pause, resume or the player resends its position.
  - DingTalk calendar: connecting with the prefilled address no longer fails with a 405 error.
  - Claude Code sessions run from the Claude desktop app no longer show text the app inserts as their title or last prompt.
  - (Mac) Pressing space to preview no longer closes the clipboard window; a pinned clipboard window remembers where it was; without Accessibility access, sequence paste no longer skips the first entry.
  - (Mac) Swiping between desktops with four fingers no longer makes the island vanish and reappear; it stays on the notch.
  - (Mac) Dragging the island no longer jumps, it snaps to the top by its real top edge near the menu bar, and dragging it back to the top centre returns it to the default position.
  - The clipboard space preview shows a copied image file (a PixPin screenshot, an image copied from WeChat or Finder) as the image instead of its path.
  - (Windows) Win+V right after startup opens the clipboard again, the island no longer hides itself now and then, and screenshots no longer sometimes fail with a window that already exists.
  - WeChat alerts: a message you send from your phone to the chat open on your PC is no longer shown as a new message.
  - After updating, built-in plugins such as the session ring sometimes stayed off; they now retry loading.
