这是 0.3.8 的第四个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **内置插件：计时器**（新，默认关闭，在 设置 → 插件 里打开）：岛上多一个「计时器」页，输入 `10`、`10m`、`1h30m`、`90s`、`1:30` 或「10 分钟」就开始倒计时，也可以开秒表；最多同时 12 个，每个都能暂停、继续、取消。收起条上显示最快到点的那个倒计时。时间到时岛上提醒并播放提示音，可以再延 5 分钟。关掉浮屿再打开，倒计时照常按真实时间走。新建计时器的快捷键默认是 `Ctrl+Alt+K`（Mac 上 `⌃⌥K`）。
- **截图历史改版**：按天分组，缩略图铺满格子，每张标着时间，鼠标移上去显示操作。开着剪贴板时，截图历史并进剪贴板页，用「截图」筛选查看；没开剪贴板时仍是单独一页。
- **插件卡片更整齐**：同一行的卡片一样高，内存、按需启动这类信息合成一行，只有最要紧的提醒显示成彩条；缺少 Node.js 或 PowerShell 7 时列表上方只提示一次，不再每张卡片都有一个按钮。市场卡片和已安装卡片用同样的布局，权限列表改成点开的浮层。
- **修复**：
  - （Mac）高分辨率屏幕上截图时，移动鼠标不再卡顿。
  - （Mac）插件卡片能显示 CPU 占用；从访达打开浮屿时，也能找到用 nvm、fnm、volta 等装的 Node.js。
  - 已安装但本机没记下作者密钥的插件，不再被自动更新到它第一个带签名的版本，改为提示更新，由你手动确认。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.8-beta.4/Fuyu_0.3.8-beta.4_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.8-beta.4/Fuyu_0.3.8-beta.4_aarch64.dmg)

This is the fourth beta of 0.3.8. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Built-in plugin: Timer** (new, off by default; turn it on in Settings → Plugins): a Timer page on the island. Type `10`, `10m`, `1h30m`, `90s` or `1:30` to start a countdown, or start a stopwatch; up to 12 at once, each can be paused, resumed or cancelled. The collapsed bar shows the countdown ending soonest. When time is up the island shows a notice and plays a sound, with five more minutes on offer. Countdowns keep real time when Fuyu is closed and reopened. The default shortcut for a new timer is `Ctrl+Alt+K` (`⌃⌥K` on a Mac).
- **Redesigned screenshot history**: grouped by day, thumbnails fill their tiles, each shows its time, and actions appear on hover. With the clipboard on, screenshot history moves into the clipboard page under a Screenshots filter; with it off, it stays its own page.
- **Tidier plugin cards**: cards in a row are the same height, facts such as memory and on demand share one line, and only the most urgent notice shows as a strip. A missing Node.js or PowerShell 7 is one banner above the list instead of a button on every card. Market cards use the same layout as installed ones, and the permission list opens as a popover.
- **Fixes**:
  - (Mac) Moving the pointer while taking a screenshot no longer stutters on high-resolution screens.
  - (Mac) Plugin cards show CPU use, and Fuyu opened from Finder finds Node.js installed with nvm, fnm, volta and similar tools.
  - An installed plugin whose author key this computer has not remembered is no longer auto-updated to its first signed version; it is offered as an update for you to confirm.
