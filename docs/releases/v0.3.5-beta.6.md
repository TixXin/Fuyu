## 关于这个版本

这是 0.3.5 的第六个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **截图（新，默认关闭）**：在 设置 → 截图 里打开后，`Ctrl+Shift+1` 冻结所有屏幕框选区域，`Ctrl+Shift+7` 截取整个屏幕（数字行和小键盘都可以）。鼠标停在窗口或控件上会自动描出它的边框，点一下就选中，滚轮可以逐级扩大到外层窗口和整个屏幕；跟随鼠标的十字参考线默认打开。放大镜显示坐标、尺寸和颜色（按 C 复制颜色），`Enter` 或双击复制到剪贴板，`Esc` 或右键退出。不同缩放比例的多块屏幕各自对齐。
- **剪贴板窗口更好用**：`Ctrl+K` 或右键打开操作面板；`Ctrl+T` 粘贴转换后的文本（合并成一行的命令、大小写、JSON、URL、去追踪参数、全半角、简繁等）；`Ctrl+E` 编辑后再粘贴；空格预览；`Del` 删除可以撤销；可以暂停记录（底栏、面板或托盘）。能认出链接、颜色和 JSON，证件号、卡号和密钥一样打码。
- **剪贴板里的 AI 改写（新）**：`Ctrl+I` 用快捷翻译的服务和模型给条目做总结、润色、改语法或翻译，答案边生成边显示，第二次按 `Enter` 粘贴。设置 → 剪贴板 → AI 提示词 里可以加自己的提示词。
- **统一的主题色**：音乐、日历、剪贴板、文件中转等页面不再各用各的颜色，岛和各个窗口都跟随 设置 → 主题 → 强调色。
- **微信提醒列表**：微信页像 QQ 页一样列出本次运行以来的每条提醒（最多 20 条，只在内存里），点一行打开那个聊天。只有「有新提醒」、读不到内容时会说明原因（微信在托盘里、免打扰等）。开了免打扰的群，只有微信标出「有人@我」时才提醒。
- **点 SSH 电脑上的 Agent 会话**能跳到连着它的 VS Code Remote-SSH 窗口。
- **翻译**：翻译有了自己的窗口，岛顶部不再放翻译按钮，用快捷键或托盘的「快捷翻译」打开，`Esc` 关闭。
- **设置**：AI 代理的会话设置拆成「岛上」和「会话列表」两页。设置 → 关于 多了官网 [fuyu.tix.xin](https://fuyu.tix.xin) 的链接。
- **插件**：插件的收起条项目可以画成竖着的小电池（`statusBatteries`）。待办进度环 1.1.0 在收起条上多了小环和「完成数/总数」，页面重画；系统监控 1.2.2 打开页面后更快出数字。
- **修复**：
  - 收起条的音乐波形只在有声音时显示。
  - 缩放不是 1 时，贴顶圆角旁不再漏出 1 像素的缝，岛拖到另一块屏幕后也一样。
  - 打开截图时屏幕不再闪一下。
  - 剪贴板和文件中转列表滚动后，两行的条目不再变矮。
  - 链接预览不再访问本机和局域网地址。

## About this release

This is the sixth beta of 0.3.5. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Screenshots (new, off by default)**: turn them on under Settings → Screenshot. `Ctrl+Shift+1` freezes every monitor for a region selection and `Ctrl+Shift+7` takes the whole monitor (number row or numpad). Resting the pointer on a window or control outlines it and a click selects it; the wheel steps out to its parent windows and the whole monitor. Guide lines follow the pointer, on by default. A magnifier shows coordinates, size and colour (C copies the colour); `Enter` or a double click copies to the clipboard, `Esc` or a right click leaves. Monitors at different scales each line up.
- **A handier clipboard window**: `Ctrl+K` or a right click opens an actions panel; `Ctrl+T` pastes transformed text (commands joined into one line, case, JSON, URLs, tracking removed, full/half width, Simplified/Traditional Chinese and more); `Ctrl+E` edits before pasting; Space previews; `Del` deletes with undo; recording can pause (footer, panel or tray). Links, colours and JSON are recognised, and card and ID numbers are masked like keys.
- **AI rewrites in the clipboard (new)**: `Ctrl+I` summarizes, polishes, fixes grammar or translates an entry with the quick translation's service and model, the answer streaming in; a second `Enter` pastes it. Add your own prompts under Settings → Clipboard → AI prompts.
- **One accent colour**: music, calendar, clipboard, file shelf and the other pages no longer each use their own colour; the island and its windows follow Settings → Theme → Accent.
- **WeChat reminder list**: like the QQ page, the WeChat page lists each reminder of this run (up to 20, kept in memory only); click one to open that chat. A reminder that only says "new message" says why (WeChat in the tray, a muted chat and so on). A muted group reminds you only when WeChat marks it "someone @-mentioned me".
- **Clicking an Agent session on an SSH computer** now brings up the VS Code Remote-SSH window connected to it.
- **Translation**: with translation in its own window, the island's header drops its translate button; open it with the shortcut or Quick Translate in the tray, and close it with `Esc`.
- **Settings**: the AI Agent session settings split into On the island and Session list. Settings → About links the website, [fuyu.tix.xin](https://fuyu.tix.xin).
- **Plugins**: a plugin's bar item can draw upright mini batteries (`statusBatteries`). The todo ring 1.1.0 adds a small ring with done/total on the collapsed bar and a redrawn page; the system monitor 1.2.2 shows its figures sooner after the page opens.
- **Fixes**:
  - The collapsed bar's music waveform shows only while sound plays.
  - At a scale other than 1, no 1px slit shows beside the top fillet, also after the island moves to another screen.
  - The screen no longer flashes when a screenshot opens.
  - Two-line rows in the clipboard and file shelf lists keep their height after scrolling.
  - Link previews no longer reach this computer or the local network.
