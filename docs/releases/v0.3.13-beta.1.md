## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.13-beta.1/Fuyu_0.3.13-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.13-beta.1/Fuyu_0.3.13-beta.1_aarch64.dmg)

This is the first beta of 0.3.13. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- The strip a tucked island leaves showing can now be narrower and shorter, and the island waits a moment before sliding out (150 ms by default, 0 for instant), so browser tabs under it stay clickable.
