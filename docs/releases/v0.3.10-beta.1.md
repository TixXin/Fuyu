这是 0.3.10 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **修复 Agent 页导致的崩溃（Windows）**：0.3.9 的 Agent 页列表动效在新版 WebView2 上会让岛的页面崩掉，停在一个报错页。列表动效改成淡入、淡出加轻微平移，不再触发崩溃；万一页面以后还崩，岛会自动重新加载，不用手动刷新。
- **更新更稳**：
  - 下载更新和插件时，GitHub 连不上会自动换国内镜像重试；网易云 InfLink-rs 插件的一键安装也一样，失败时说明原因。
  - 安装更新前自动备份数据（设置、待办、剪贴板历史、插件数据等），出问题可以在 设置 → 关于 里恢复。
  - （Mac）更新装好后岛会自己重启，不再一直停在「正在重启」；15 秒还没重启时会给一个「立即重启」按钮。从 0.3.9 及更早版本更新时还需要手动重启一次。
  - 设置 → 关于 →「更新日志」可以翻看历史版本的更新说明，离线也能看。
- **有未读消息时岛不收起**：设置 → 行为 → 贴边收起 里新增「有未读消息时不收起」（默认打开），未读的微信提醒、QQ 通知和邮件会让岛保持展开；音乐设置页也能开「播放时不收起」。
- **鼠标、键盘电量**：蓝牙鼠标、键盘和（Mac）触控板连上时岛上显示电量，低于 20% 和 10% 各提醒一次。
- **磨砂配色**：内置灰白、透白磨砂、暖白磨砂三套配色，岛上的文字颜色可以单独设。
- **设置**：功能的开关只放在概览页的功能卡片上，各功能页不再重复一个开关；概览卡片的对齐和功能计数也修了。
- **AI Agent**：
  - opencode 1.x 通过插件也能显示「等你」并在岛上审批。
  - Codex 会话改从它自己的数据库读取，旧会话、存储迁移后的会话都能列出来；Claude 桌面版的会话用桌面版里的标题。
  - SSH 远程：回复标记写进各家的提示词文件；Antigravity CLI 的远程命令可以在岛上审批。
  - （Mac）能认出正在运行的 WorkBuddy AI。
- **插件**：插件页显示插件宿主占用的内存；插件可以读到浅色、深色主题的颜色变量，在浅色岛上也看得清。
- **修复**：
  - 只是预览过的邮件不算已读，「未读时不收起」不会因此失效。
  - 窗口加载后几秒还没显示出来时会自动重新加载。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.1/Fuyu_0.3.10-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.1/Fuyu_0.3.10-beta.1_aarch64.dmg)

This is the first beta of 0.3.10. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Fixed a crash caused by the Agent page (Windows)**: in 0.3.9 the Agent page's list animations crashed the island's page on recent WebView2, leaving an error page. The rows now fade and shift slightly instead, which no longer crashes; if the page ever crashes again, the island reloads it on its own.
- **Steadier updates**:
  - When GitHub can't be reached, update and plugin downloads retry through mirrors. The NetEase InfLink-rs one-click install does the same and explains failures.
  - Your data (settings, todos, clipboard history, plugin data and more) is backed up before an update installs, and can be restored from Settings → About.
  - (Mac) The island restarts on its own after an update installs instead of staying on "restarting"; if it hasn't restarted after 15 seconds you get a Restart now button. Updating from 0.3.9 or earlier still needs one manual restart.
  - Settings → About → Release notes lets you read the notes of past versions, offline too.
- **The island stays out while messages are unread**: Settings → Behavior → Tuck to edge has a new "stay out while messages are unread" (on by default) for pending WeChat reminders, QQ notifications and unread mail. The music page also has "stay out while music plays".
- **Mouse and keyboard battery**: Bluetooth mice, keyboards and (Mac) trackpads show their battery on the island when they connect, with one warning each at 20% and 10%.
- **Frosted color schemes**: three built-in schemes (gray-white, clear frosted, warm frosted), and the island's text color can be set on its own.
- **Settings**: features are turned on and off only on the overview's feature cards; the feature pages no longer repeat the switch. Card alignment and the feature count are fixed.
- **AI agents**:
  - opencode 1.x shows waiting and can be approved on the island through a plugin.
  - Codex sessions are read from Codex's own database, so older sessions and sessions after its storage migration are listed; Claude desktop sessions use the desktop app's titles.
  - SSH remote: the reply marker goes into each agent's prompt file, and remote Antigravity CLI commands can be approved on the island.
  - (Mac) A running WorkBuddy AI is recognised.
- **Plugins**: the plugin page shows the plugin host's memory; plugins get light and dark theme variables, so they read well on the light island.
- **Fixes**:
  - Previewing a mail doesn't count as reading it, so "stay out while unread" keeps working.
  - A window that hasn't shown up a few seconds after loading reloads itself.
