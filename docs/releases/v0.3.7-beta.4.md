## 关于这个版本

这是 0.3.7 的第四个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **待办的项目会一直留着**：项目现在是一份保存下来的列表，里面的待办做完了项目也不会消失。待办页的筛选固定有「全部」「临时」、每个项目和「+」；输入框旁边可以选新待办加到哪个项目，输入 `#名字` 仍然优先，并且会新建项目。在 设置 → 功能 → 待办 → 项目 里可以改名、排序和删除：改名会同时改计划中的待办和归档，删除后它今天和以后的待办回到「临时」。
- **截图设置**：设置 → 功能 → 截图 里，每个快捷键都可以重新录、恢复默认或关掉，和浮屿其他快捷键冲突、被别的程序占用时会在那一行说明；多了一个可选的全局快捷键，用来隐藏或显示所有贴图。「保存位置」可以换成自己的文件夹，「岛上的截图卡片」可以选显示多久或不显示。截图的快捷键也列在 设置 → 快捷键 里。
- **按 PrintScreen 截图**（新，默认关闭）：在 设置 → 功能 → 截图 打开后，单独按 `PrintScreen` 会打开浮屿的截图，不再交给系统截图工具；`Alt+PrintScreen` 等组合键不受影响。
- **更多截图入口**：托盘菜单多了「截图」，展开的岛顶部多了一个剪刀按钮，点它岛会先收起再开始截图。
- **截图卡片放进收起条**：复制或保存后的缩略图卡片现在和岛上其他提示一样显示在收起条里，不再盖住展开的岛的标题栏和按钮；缩略图照样可以拖出去，「放进文件中转」「发给 Agent」在右侧。默认显示 3 秒。
- **Agent 会话显示改过的名字**：在 Claude Code 里用 `/rename` 给会话改名后，岛上优先显示这个名字。
- **插件的状态项可以画饼图**：插件能用一个最多四块的小饼图代替文字，适合显示占比。
- **修复**：
  - 后台发现新版本后，岛不会再卡住、点了没反应并占满一个 CPU 核心（关闭自动更新或下载失败过的情况下最容易出现）。

## About this release

This is the fourth beta of 0.3.7. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Todo projects stay put**: projects are now a saved list, so a project no longer disappears when its tasks are done. The todo page's filter always offers All, Inbox, each project and +, and a choice next to the input picks where a new task goes; typing `#name` still wins and creates the project. Settings → Features → Todos → Projects renames, reorders and removes them: a rename also applies to planned tasks and the archive, and removing a project moves its tasks of today and later to the Inbox.
- **Screenshot settings**: under Settings → Features → Screenshot each shortcut can be recorded again, reset or turned off, and a row says so when its keys clash with another Fuyu shortcut or are taken by another app. There is a new optional global shortcut to hide or show all pins. Save to takes a folder of your own, and Screenshot card on the island sets how long the card shows, or hides it. The screenshot shortcuts are listed under Settings → Shortcuts too.
- **Screenshot with PrintScreen** (new, off by default): turn it on under Settings → Features → Screenshot and `PrintScreen` on its own opens Fuyu's screenshot instead of the Windows snipping tool. `Alt+PrintScreen` and other combinations are left alone.
- **More ways to start a screenshot**: the tray menu has Screenshot, and the open island has a scissors button at the top that closes the island first and then starts.
- **The screenshot card sits in the collapsed bar**: the thumbnail card after a copy or save now shows in the collapsed bar like the island's other notices, and no longer covers the open island's header and buttons. The thumbnail still drags out, with the file shelf and Send to an agent on the right. It shows for 3 seconds by default.
- **Renamed agent sessions**: a Claude Code session renamed with `/rename` shows that name on the island first.
- **Plugin status items can draw a pie**: a plugin can show a small pie of up to four slices instead of text, good for shares of a total.
- **Fixes**:
  - The island no longer freezes, ignoring clicks and using a full CPU core, after it finds a new version in the background (most likely with automatic updates off or after a failed download).
