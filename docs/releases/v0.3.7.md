## 关于这个版本

0.3.7 正式版，包含 v0.3.6 以来的全部改动。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **新手引导（新）**：新装的岛屿第一次启动时，在真实的岛上带你上手：屏幕变暗，只留岛屿周围一圈亮光，依次选语言、外观、要用的功能，再在真的岛上练习打开岛屿、把文件拖上去、按剪贴板快捷键，最后决定是否开机启动。引导期间岛上放一首示例歌曲和一个示例 Agent 会话，结束后把之前的窗口恢复回来。用过的岛屿不会弹出，设置 → 关于 里可以再打开。
- **所有数据放进一个文件夹**：待办、设置、剪贴板历史、插件、AI Agent 状态和每日待办 Markdown 都放在用户文件夹下的 `.fuyu` 里，备份和换电脑都方便。升级后第一次启动会把原来的数据复制过去，原文件夹保留不动；装过的 Claude Code / Codex 钩子自动改到新位置；自己选过的每日待办保存位置不变。设置 → 通用 → 数据文件夹 可以换到别处（比如网盘），重启后生效；同一个文件夹正被另一台电脑上的浮屿使用时，岛会提示并不启动。设置还会另存为数据文件夹里的 `settings.json`，手动改了下次启动生效。
- **截图能做更多事**：
  - 复制时同时放入图片、PNG 和文件，聊天软件、画图和终端都能直接粘贴；`Ctrl+S` 保存到「图片 › 浮屿截图」，按时间命名，保存位置可以改。
  - 按 `T` 把选区钉在屏幕上：可以拖动、滚轮缩放、`Ctrl` + 滚轮调透明度，右键菜单可复制、保存、鼠标穿透、全部隐藏或关闭。
  - 新快捷键：`Ctrl+Shift+2` 选好就复制、不出工具栏；`Ctrl+Shift+3` 识别选区文字并复制，`Ctrl+Shift+4` 识别后直接翻译。识别在本机进行，不联网。
  - 复制或保存后，收起条上显示带缩略图的卡片：可以把图片拖到别处、「放进文件中转」或「发给 Agent」，默认显示 3 秒。
  - 设置 → 功能 → 截图 里每个快捷键都能重新录、恢复默认或关掉，冲突或被占用时会说明；托盘菜单和展开的岛顶部的剪刀按钮也能开始截图。
  - **按 PrintScreen 截图**（新，默认关闭）：在 设置 → 功能 → 截图 打开后，单独按 `PrintScreen` 打开浮屿的截图，`Alt+PrintScreen` 等组合键不受影响。
- **待办按项目整理**：以「#项目名 」开头的待办归到那个项目，今天的待办按项目分组并显示未完成数。项目是一份保存下来的列表，待办做完了也不会消失；顶部可以筛选「全部」「临时」或某个项目，输入框旁可以选新待办加到哪里；设置 → 功能 → 待办 → 项目 里可以改名、排序和删除。导出 Markdown 时写成 `- [ ] [项目名] 标题`。
- **从日历加待办**：日历页今天和以后的日子多了「添加待办」，以后的日子会按计划在那天出现；计划中的待办也显示在当天日程里，月视图在这些日子上加一个点。不写进日历。
- **翻译页重新设计**：直接画在岛上，方向可选自动 / 中→英 / 英→中，右侧显示服务和模型，小圆点表示密钥是否已保存，点它打开翻译设置。原文和译文两栏，岛够宽时并排、窄时上下排列；没有密钥或出错时在译文栏说明原因，并给出「打开设置」「重试」。
- **开合动画**：设置里新增「开合动画」，可选弹性（默认）、平滑、快速、Q 弹和关闭；收起比展开快、不回弹。系统开了"减少动画"时不回弹。
- **按住 Alt 调整大小**：按住 Alt 时，岛屿上能拖的边显示主题色细线，拖动时边缘紧跟鼠标并显示当前尺寸；收起的岛屿两侧也能拖，调整收起时的宽度。
- **一键清除提醒**：新消息弹窗的「全部消息」旁多了一个按钮，一次清掉岛上的所有提醒，不会把微信、QQ 或邮件标为已读。
- **手机推送按电脑设置**：本机和每台 SSH 电脑各有开关，用 cc-connect 时可以选每台电脑的项目和机器人，远程电脑的会话通过它自己的机器人推送并可以接管。
- **Agent 会话显示改过的名字**：在 Claude Code 里用 `/rename` 改名的会话，岛上优先显示这个名字。
- **设置里的按钮会说明做了什么**：插件页的「立即检查」显示检查中和结果，重新加载、打开文件夹、清除数据等按钮点了以后也会提示几秒。
- **浅色主题**：浅色岛上大量看不清的文字修好了，包括错误和提示的颜色、设置里的说明、翻译页、插件页、下拉菜单和翻译窗口。
- **安装包**：桌面和开始菜单的快捷方式改名为「浮屿」，更新时会把旧的 Fuyu 快捷方式改名。
- **插件**：插件的状态项可以画最多四块的饼图；系统监控插件 1.3.0 随面板大小自动排版，新增「布局」设置。插件由插件市场更新。
- **修复**：
  - 后台发现新版本后，岛不会再卡住、点了没反应并占满一个 CPU 核心。
  - 微信里自己发的消息（包括手机上发、同步到电脑的）不再被当成新消息提醒。
  - 切换页面时只淡入，文字和图标不会在落定时跳一下；缩放为 100% 时日历的日期不再挪动。
  - 待办行高按标题实际换行计算，一行的标题不再显得过高。
  - 贴顶收起的岛屿被拖动时不再反复弹进弹出，托盘的「显示」能把收起的岛屿拉出来。
  - 用量圆环在深色和浅色岛上都更清楚。
  - 原生错误提示改为中英文，以及多处并发、写文件和性能问题。

## About this release

The 0.3.7 release, with everything since v0.3.6. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **First-run guide (new)**: a new install shows you around on the real island. The screen dims except for a lit ring around it; you pick a language, a look and the features you want, practise opening the island, dropping a file on it and pressing the clipboard shortcut, and choose whether it starts with Windows. A demo song and a demo Agent session play meanwhile, and your windows come back afterwards. Islands that ran before do not see it; Settings → About opens it again.
- **All your data in one folder**: todos, settings, clipboard history, plugins, AI agent status and the daily todo Markdown now live in `.fuyu` in your user folder. The first start after the update copies your data there and leaves the old folder untouched; installed Claude Code / Codex hooks follow. Settings → General → Data folder moves it elsewhere after a restart. Settings are also saved there as `settings.json`.
- **More from a screenshot**:
  - Copying puts a picture, a PNG and the file on the clipboard; `Ctrl+S` saves to Pictures › Fuyu Screenshots, named by time, and the folder can be changed.
  - `T` pins the selection to the screen: drag it, zoom with the wheel, fade it with `Ctrl` + wheel, and right-click for copy, save, click-through, hide all or close.
  - New shortcuts: `Ctrl+Shift+2` copies as soon as you pick, without the toolbar; `Ctrl+Shift+3` reads the text in a region and copies it, `Ctrl+Shift+4` reads and translates it. Text is read on your computer, offline.
  - After a copy or save, the collapsed bar shows a thumbnail card: drag the image out, put it on the file shelf or send it to an agent. It shows for 3 seconds by default.
  - Under Settings → Features → Screenshot each shortcut can be recorded again, reset or turned off, and a clash or a key taken by another app is explained; the tray menu and a scissors button at the top of the open island start a screenshot too.
  - **Screenshot with PrintScreen** (new, off by default): turn it on under Settings → Features → Screenshot and `PrintScreen` on its own opens Fuyu's screenshot; `Alt+PrintScreen` and other combinations are left alone.
- **Todos by project**: a todo starting with "#name " goes into that project, and today's todos group by project with the count of open ones. Projects are a saved list that stays when its todos are done; the filter offers All, Inbox or one project, a choice by the input picks where a new todo goes, and Settings → Features → Todos → Projects renames, reorders and removes them. The Markdown export writes `- [ ] [name] title`.
- **Todos from the calendar**: today and later days on the calendar page get "Add a todo"; later ones are planned for that day, show among its events, and the month marks those days with a dot. Nothing is written to a calendar.
- **Translation page redesigned**: drawn on the island itself. Pick Auto / ZH → EN / EN → ZH; the service and model sit on the right with a dot for whether the key is saved, and clicking them opens the translation settings. Source and result sit side by side on a wide island and stacked on a narrow one; a missing key or an error is explained with "Open settings" and "Retry".
- **Open and close animation**: a new "Open and close" setting picks Spring (default), Smooth, Fast, Bouncy or none; closing is quicker and never bounces, and nothing bounces with the system's reduce motion.
- **Resizing with Alt**: holding Alt shows thin accent lines on the edges you can drag; while dragging, the edge stays under the pointer and the size shows. The collapsed island's sides set its collapsed width.
- **Clear every reminder**: the new-messages popup has a button beside "All messages" that clears every reminder on the island at once, without marking anything read in WeChat, QQ or mail.
- **Phone push per computer**: this computer and each SSH computer get their own switch; with cc-connect you pick each computer's projects and bots, and a remote computer's sessions go through its own bots, which can take them over.
- **Renamed agent sessions**: a Claude Code session renamed with `/rename` shows that name on the island first.
- **Settings buttons say what they did**: Check now on the Plugins page shows that it is checking and what it found, and reload, open folder and clear data show a short note for a few seconds.
- **Light theme**: much hard-to-read text on a light island is fixed, including error and hint colours, settings hints, the translation page, plugin pages, select menus and the translation window.
- **Installer**: desktop and Start menu shortcuts are named 浮屿; an update renames an old Fuyu shortcut.
- **Plugins**: status items can draw a pie of up to four slices; the system monitor 1.3.0 lays itself out for the panel's size and has a new Layout setting. Plugins update through the plugin market.
- **Fixes**:
  - The island no longer freezes, ignoring clicks and using a full CPU core, after it finds a new version in the background.
  - A WeChat message you sent yourself (also from your phone) is no longer a new-message reminder.
  - Switching pages only fades in, so text and icons no longer jump; at 100% scaling the calendar's dates no longer shift.
  - Todo rows take their height from the lines their titles actually wrap to.
  - A tucked island dragged at the top edge no longer bounces in and out, and the tray's Show brings it out.
  - The usage rings are easier to read on dark and light islands.
  - Native error messages are worded in your language, plus fixes for concurrency, file writes and performance.
