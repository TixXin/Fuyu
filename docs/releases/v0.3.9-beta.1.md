这是 0.3.9 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **分别保持深色**：设置 → 外观 里原来的「收起时保持深色」改成「保持深色」一行三个按钮：岛屿、面板、独立窗口（翻译和剪贴板窗口），可以分别选。只在配色是浅色时起作用；设置窗口始终跟随配色。升级后原来的选择不变。
- **剪贴板窗口有标题栏**：窗口顶部多了一条标题栏，按住就能拖动窗口。标题栏上的图钉可以固定窗口：固定后切到别的程序、粘贴之后都不关闭（Windows 上还会记住窗口位置）。窗口里的按钮提示出得更快。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.9-beta.1/Fuyu_0.3.9-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.9-beta.1/Fuyu_0.3.9-beta.1_aarch64.dmg)

This is the first beta of 0.3.9. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Keep parts dark separately**: in Settings → Appearance, "Stay dark when collapsed" is now a "Keep dark" row with three buttons: Island, Panel and Other windows (the translation and clipboard windows), each chosen on its own. They only matter while the colors are light; the settings window always follows the colors. Your current choice is kept after updating.
- **A title bar for the clipboard window**: drag the window by its new title bar. The pin on it keeps the window open when you switch to another app and after pasting (on Windows it also remembers where the window was). Tooltips in the window show sooner.
