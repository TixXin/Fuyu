0.3.11 正式版，包含 v0.3.10 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### 插件

- **第 3 版插件平台**：正式版默认使用新版平台。浮屿的插件运行在 Node.js 上，电脑上没有可用的 Node.js 时，第一次启动会在后台下载一份（约 30 MB，依次尝试 nodejs.org、npmmirror、腾讯云，下载后校验 SHA-256），只放在浮屿的数据目录里，不影响系统。下载失败时内置功能照常可用，可在 设置 → 插件 里查看原因并重试。内置功能仍在各自的设置页开关，升级不会把原本关闭的功能打开。
- **从第 2 版升级**：浮屿会提示迁移，保留 7 个旧官方插件的设置；插件本身要到市场重新安装，番茄钟记录等插件私有数据不会迁移。网页里的 `fuyu://` 链接暂时不能一键安装，点了只会把浮屿调出来；请到市场搜索，或打开下载好的 `.fuyu` 文件安装。
- **插件市场**：GitHub 连不上时自动换国内镜像，内容仍按签名和 SHA-256 校验；第一次打开会自己读取目录，图标和截图存在本机，不用每次等网络。卡片顶上是带截图的封面，可放大查看，并标出平台兼容性；已安装的收成底部一行。搜索支持拼音、首字母和关键词，设置窗口的搜索框也会列出市场里对得上的插件。
- **套装（新）**：市场把几个搭配使用的插件放成一个套装，确认一次就全部装好，装完后每个插件各自更新、停用和卸载。新手引导结束前也会推荐一个。
- **管理已装的插件**：插件页会标出它在岛上出现的位置，可以直接打开对应页面、改设置或运行命令；还差一步设置的插件（比如天气还没选城市）会标出来，点「去设置」直达；新装的插件会在岛上闪两下，指出它出现在哪。页面上画出哪些插件在收起条上、各占多宽，可以挪位置或拿下来；插件详情里能单独关掉某个插件的「岛上提醒」。市场插件通常在新版本发布满 3 天后自动更新，更新过的会列出来并能看更新了什么；作者密钥、来源或插件能做的事有变化时，不会静默更新。插件命令的快捷键在 设置 → 快捷键 修改。
- **插件跟着备份和同步走**：装了哪些市场插件、开没开、各自的设置，会进设置备份和跨设备同步（密码、令牌这类字段不带）。另一台设备不会自动安装，插件页提示「另一台设备上还装了 N 个插件」，点一下才装。
- **官方插件**：市场里可装应用启动台、离线词典、倒数日、闹钟、世界时钟、番茄钟、待办摘要、待办进度环、换歌提示、天气、GitHub Issues 和系统监控，这一版统一了图标、补齐了截图。番茄钟有了休息、暂停和设置，稍后上架的 1.2.0 会把选了待办的一轮专注记到那条待办的专注时长里；闹钟可以编辑；倒数日支持纪念日、每年重复和提醒；世界时钟可以在岛上增删城市；系统监控新增 GPU、网络、电池、温度和占用最高的程序；天气可选单位和显示内容；GitHub Issues 支持多个仓库、排序和标签筛选；待办摘要可以定时写入。换歌提示 1.2.0 的卡片停留改为 3 秒，播放软件在最前面时不弹，浏览器里的视频默认不弹。插件由市场单独更新，不随浮屿安装包更新。
- **自己写插件**：设置 → 关于 → 插件系统 说明插件怎么运行、能做什么，并备好一段提示词，写下想法、复制给 AI 编程助手，就能让它写一个插件。开发工具 `fuyu-plugin` 2.1.0 新增画图标、出截图和在本地预览市场页面的命令。

### 待办与日历

- **待办清单与专注**：一条待办可以拆成子步骤、展开写备注，并自动记录专注倒计时；倒计时中途结束时只记实际专注的分钟数。标题以时刻开头（如 `15:00 回电话`）可在岛上准点提醒，也可以推迟。
- **提醒更细**：带时刻的待办可以提前 5、10、15 或 30 分钟提醒；已安排的待办到了那天，可以选提醒哪些优先级；新增「每天收尾提醒」（新，默认关闭），到点还有没做完的待办时提醒一次。都在 设置 → 待办 → 提醒；待办设置也分成了「任务」「提醒」「归档与保存」三页。
- **本周小结**：归档页最上面多了一张卡，显示本周完成几件、每天一根小柱，以及专注时长最多的项目；可在 设置 → 待办 关掉。
- **新待办的默认值**：可以设「新待办默认进哪个项目」和「新待办默认优先级」，给每日笔记设一段开头，工作日重复可以选择不跟随节假日。Markdown 导出能分别选要不要带项目、优先级、子步骤、备注和用时。
- **待办整理**：支持按优先级排序、显示已用专注时间、自定跨天归档时间和行内 Markdown；重复待办可以避开节假日，还可用全局快捷键快速添加待办。
- **会议提醒**：岛上横幅可一键入会，也可用全局快捷键加入当前会议。日历会从事件地点和描述识别 Zoom、腾讯会议、飞书会议等链接；可设置会议期间暂停媒体，结束后恢复。
- **日程视图**：日历可按列表看日程，标出已谢绝和空闲的事件；CalDAV 子日历保留原名，可以单独隐藏或改颜色。

### 同步与消息

- **WebDAV 与端到端加密**：可用坚果云、Nextcloud 或群晖 NAS 等 WebDAV 服务跨设备同步；可以开启端到端加密，让同步服务器无法读取内容。剪贴板收藏也可选择同步（默认关闭），会自动过滤识别出的敏感内容。
- **更多聊天提醒（新，默认关闭）**：在 设置 → 消息 → 来源 开启 Telegram、Discord、WhatsApp、TIM、飞书、钉钉或企业微信。Windows 支持通知内容；Mac 读取已安装应用在程序坞上的未读数，需要辅助功能权限。
- **消息设置重新整理**：分成「来源」和「提醒方式」两页。QQ、微信、邮箱和其他聊天应用在一张列表里，每行写明这个来源能读到什么；「看过后从岛上去掉」合成一个开关。提醒方式可以先看预览，再点「在真岛上试一下」。
- **复制和阅读通知**：长按消息或邮件通知可复制正文、链接或验证码。普通收起条上的长消息会先加宽，再换行或滚动；鼠标停在岛上时，预览不会自动消失。

### AI Agent

- **提醒卡片**：在 设置 → AI Agent → 桌面提醒 选择卡片样式、停留时长和点击后的去向。页面顶上实时预览每种提醒，每个事件一行，可以设弹不弹、停多久、试听提示音，还能点「在岛上试一下」让真岛弹一条。多条提醒按紧急程度叠放，悬停可暂停倒计时，待审批的提醒会保留到处理完成。回复支持 Markdown，表格也会画成表格；（Mac）刘海两侧可显示会话图标和状态。
- **会话与审批**：新增 Cursor 编辑器会话和岛上命令审批；DeepSeek Harness、Factory Droid 和 TRAE 也可在岛上审批。点会话可跳到 Cursor、WorkBuddy 或 Claude 桌面版 Code 页里的对应对话；（Mac）还可定位到 Ghostty、iTerm2、WezTerm 或 tmux 的标签页或窗格。
- **用量环与钩子**：用量环新增 Cursor、Antigravity、WorkBuddy 和 DeepSeek Harness，GLM 和 Kimi 的密钥可以直接读取 Claude Code 的设置。AI Agent 首页可以查看、安装、修复或卸载各家的钩子，也可清理远程钩子。Claude Code 子 Agent 和 Claude 桌面版子会话可设为默认展开（默认关闭）。
- **（Mac）远程与手机推送**：开放 SSH 远程会话和 SSH 代理隧道，可在本机下载和托管 cc-connect，并通过飞书扫码配置。

### 小岛与外观

- **液态玻璃**：可一键切换透明、着色或毛玻璃预设。设置中的「玻璃背后」可选实时窗口、仅壁纸或无背景，实时效果不可用时会说明原因。（Mac）支持系统原生毛玻璃，「自动」岛形会根据屏幕有无刘海切换。
- **收起条自己排**：右键收起的小岛，勾选要显示哪些项目。设置 → 外观 → 收起条项目 里也列出了插件的项目和计时器，可以调顺序、换边、隐藏，或收进「+N」小面板，停在或点「+N」查看。（Mac）贴合刘海时放不下的项目自动收进「+N」，「刘海两侧最宽」可以把两侧调宽。
- **小岛可以让出桌面空间**：新增整体透明度、闲置变暗并穿透点击、贴边露出样式和极小的贴边提示；可以设成点击岛外就收起展开的面板。默认用 `Ctrl+Alt+B`（Mac 上 `⌃⌥B`）在前后层切换。贴边时轮廓和油膜边连成一体，主题也可同时提供深浅配色，切换时平滑过渡。
- **更好找的设置**：重新分组常用设置，外观调整可实时预览；「一键换配色」多了一张「默认」，随时回到刚装好时的颜色。「关于」分成概览、更新日志、插件系统、帮助和交流群，主题市场并入主题页面。常驻后台的窗口更少，设置和托盘卡片打开更快；启用系统「减少动态效果」时也保留轻微过渡。
- **出错时自己恢复**：某个窗口出错时会自动重新加载一次；还是不行就显示一个小条，可以重新加载、重启浮屿或查看日志，小岛不会再悄悄消失。出错记录可在 设置 → 通用 → 数据与备份 里打开。

### 其他

- **音乐与歌词**：换歌时弹出的卡片显示专辑封面、播放软件的名字和图标，点一下打开音乐页；网易云音乐、QQ 音乐、酷狗等播放软件的名字跟随界面语言，Mac 上认得更多播放软件。启用中文歌词源后，新增 QQ 音乐和网易云逐字歌词，优先显示逐字版本；（Windows）还可读取酷狗本机歌词缓存。
- **本机接口**：搬到设置侧栏「扩展」下的独立页面，可复制或重新生成访问令牌，并列出开放了哪些功能、现在能不能用；访问未开启的功能时会明确提示。新增「允许弹消息」（新，默认关闭）：打开后脚本和其他程序可以用 `POST /v1/notify` 在岛上弹一条消息，每个来源可以单独关掉。
- **剪贴板与翻译**：剪贴板预览显示完整备注，宽布局更宽；翻译快捷键可以清空，自定义翻译服务不再强制填写 API Key。
- **录屏与卸载（Windows）**：录屏可选择是否把浮屿窗口录进去。卸载时若选择删除数据，也会清理浮屿凭据和应用数据；自定义数据目录里的其他文件不会被一并删除。
- **交流群**：设置 → 关于 → 帮助和交流群 里可以看到微信群的二维码，群码过期后会自动换成新的，不用等更新。
- **性能和修复**：降低窗口隐藏或岛闲置时的后台开销，改善剪贴板长列表和液态玻璃缩放；修复删除剪贴板历史无效、邮件服务偶尔要重启才就绪、内置开关未保存、远程会话更新时消失、插件通知不上岛、插件进程重启后岛上的插件内容不再更新、用快捷键展开小岛后鼠标一离开就收起、Codex 长时间思考被当成已结束、Claude Code 钩子被 Cursor 或旧版 Claude Code 拦住和独立药丸描边溢出等问题；QQ、微信、备份和 SSH 等处的错误提示跟随界面语言。（Mac）修复启动后岛偶尔不显示、托盘卡片闪退及截图带入拖动光标；浮屿的提示音不再抢走系统的「正在播放」，音乐页读不到歌、换歌不提示的情况不再出现。（Windows）WebView2 图形进程崩溃后可自动恢复。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_aarch64.dmg)

The 0.3.11 release, with everything since v0.3.10. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. ## What's New

### Plugins

- **The v3 plugin platform**: The stable release now uses the new platform by default. Fuyu's plugins run on Node.js. If no usable Node.js is found, Fuyu downloads one in the background on first launch (about 30 MB, from nodejs.org, npmmirror or Tencent Cloud, verified by SHA-256) into its own data folder, leaving the system untouched. Built-in features keep working if the download fails; see Settings → Plugins to check why and retry. Built-in features still have switches in their own settings, and upgrading keeps previously disabled features off.
- **Upgrading from v2**: Fuyu shows a migration notice and carries over the settings of seven older official plugins. Reinstall the plugins from the market; private data such as Pomodoro history does not carry over. One-click installs from `fuyu://` links do not work yet: the link only brings Fuyu to the front. Find the plugin in the market or open a downloaded `.fuyu` file instead.
- **Plugin market**: When GitHub cannot be reached, the market falls back to mirrors, and everything is still checked against its signature and SHA-256. The catalog loads by itself the first time, and icons and screenshots are kept on your computer. Cards have a cover with the plugin's screenshot, which you can enlarge, and show platform compatibility; installed plugins fold into one line at the bottom. Search understands keywords, pinyin and initials, and the search box in Settings also lists matching plugins from the market.
- **Bundles (new)**: The market groups plugins that go together into a bundle that installs after a single confirmation. Each plugin then updates, turns off and uninstalls on its own. The first-run guide recommends one before it ends.
- **Managing installed plugins**: The Plugins page shows where each plugin appears on the island and lets you open its page, adjust settings or run commands. Plugins that still need a step (Weather without a city, for example) are marked "Needs setup" with a Set up button, and a newly installed plugin flashes once on the island to show where it landed. A drawing shows which plugins sit on the collapsed bar and how wide each is, and you can move or remove them there. A plugin's detail page can turn off its "Island alerts" alone. Market plugins normally auto-update three days after a release; the page lists what was updated and what changed. Updates are never silent if the signing key, source, or what the plugin can do changes. Settings → Shortcuts lets you change plugin command shortcuts.
- **Plugins follow backups and sync**: Which market plugins are installed, whether they are on, and their settings are part of settings backups and cross-device sync (fields such as passwords and tokens are left out). Nothing installs by itself on the other device: the Plugins page says "N more plugins are installed on another device" and installs them when you click.
- **Official plugins**: The market offers App launcher, Offline dictionary, Day counter, Alarm, World clock, Pomodoro, To-do digest, To-do progress ring, Track change notice, Weather, GitHub Issues and System monitor, now with matching icons and screenshots. Pomodoro gains breaks, pause and settings, and 1.2.0, coming to the market shortly, adds a finished focus round's minutes to the todo you picked; alarms can be edited; Day counter adds anniversaries, yearly repeats and reminders; World clock adds and removes cities on the island; System monitor adds GPU, network, battery, temperature and the busiest programs; Weather lets you pick units and what to show; GitHub Issues follows several repositories with sorting and label filters; To-do digest can write on a schedule. Track change notice 1.2.0 stays for 3 seconds, skips the player when it is the front app, and ignores browser videos by default. Plugins update separately through the market, not through the app installer.
- **Write your own**: Settings → About → Plugin system explains how plugins run and what they can do, and offers a prompt: describe your idea, copy it to an AI coding assistant, and let it write the plugin. The `fuyu-plugin` tool 2.1.0 adds commands to draw an icon, take screenshots and preview the market listing locally.

### Todos and calendar

- **Checklists and focus time**: Break a todo into subtasks, add a note without leaving the island, and log time from a focus countdown; ending one early logs only the minutes you actually spent. Start a title with a time (for example, `15:00 call back`) to get an island reminder you can snooze.
- **Finer reminders**: A todo with a time can remind you 5, 10, 15 or 30 minutes ahead. Choose which priorities get a reminder when a scheduled todo reaches its day. A new end-of-day reminder (new, off by default) tells you once when todos are still open. All under Settings → Todos → Reminders; the todo settings are now three tabs, Tasks, Reminders, and Archive and saving.
- **Week summary**: The archive page opens with a card showing how many todos you finished this week, a bar per day, and the projects with the most focus time. Turn it off under Settings → Todos.
- **Defaults for new tasks**: Set a default project and a default priority for new tasks, give the daily note a starter, and choose whether weekday repeats follow public holidays. The Markdown export lets you include or leave out project, priority, subtasks, notes and elapsed time.
- **More ways to organize todos**: Sort by priority, show time spent focusing, set a custom day rollover, and use inline Markdown. Recurring todos can adjust around holidays, and a global shortcut opens the quick-add panel.
- **Meeting reminders**: Join from the meeting banner on the island or use a global shortcut to open the current meeting link. Calendar recognizes links for Zoom, Tencent Meeting, Feishu, and others in event locations and descriptions. Fuyu can pause media during a meeting and resume it afterward.
- **Agenda view**: Browse events as a list and see which were declined or marked free. CalDAV calendars keep their original names, and each calendar can be hidden or assigned its own color.

### Sync and messages

- **WebDAV and end-to-end encryption**: Sync through WebDAV services such as Nutstore, Nextcloud, and Synology NAS. Turn on end-to-end encryption to keep sync contents unreadable to the server. Clipboard favorites can sync too (off by default), with automatic filtering of detected sensitive content.
- **More chat alerts (new, off by default)**: Turn on Telegram, Discord, WhatsApp, TIM, Feishu, DingTalk, or WeCom under Settings → Messages → Sources. Windows can show notification contents. On Mac, Fuyu reads unread counts from the Dock and needs Accessibility access.
- **Reorganized message settings**: Two pages, Sources and Notice style. QQ, WeChat, mail and the other chat apps share one list, and each row says what that source can read. "Remove once seen" is now a single switch. Preview a notice style, then click "Try it on the island".
- **Read and copy notifications**: Long-press a chat or mail notification to copy text, links, or verification codes. Long previews on the regular collapsed bar expand, then wrap or scroll. Hovering keeps the preview visible.

### AI Agent

- **Notice cards**: Choose a style, how long alerts stay, and what a click opens under Settings → AI Agent → Desktop alerts. The page previews every kind of notice live, with one row per event for its pop-up switch, stay time and sound, and "Try on the island" pops one on the real island. Alerts stack by urgency, hovering pauses the countdown, and approvals stay until handled. Replies can use Markdown, tables included. On Mac, the icon and status can sit on either side of the notch.
- **Sessions and approvals**: View Cursor editor sessions and approve commands on the island. DeepSeek Harness, Factory Droid, and TRAE approvals are also supported. Click a Cursor, WorkBuddy, or Claude desktop Code session to open the corresponding conversation. On Mac, Fuyu can also find the right tab or pane in Ghostty, iTerm2, WezTerm, and tmux.
- **Usage rings and hooks**: Usage rings now cover Cursor, Antigravity, WorkBuddy, and DeepSeek Harness, and GLM and Kimi keys can be read from your Claude Code settings. See hook status, install, repair, or remove hooks from the AI Agent home page, including remote cleanup. You can expand Claude Code subagents and Claude desktop child sessions by default (off by default).
- **(Mac) Remote sessions and phone push**: SSH remote sessions and the SSH proxy tunnel are available, as is downloading and running cc-connect locally with Feishu QR setup.

### Island and appearance

- **Liquid glass**: Pick a clear, tinted, or frosted preset. Behind the glass lets you choose live windows, wallpaper only, or no backdrop, and explains when it falls back. On Mac, Fuyu supports the native glass effect, and Auto switches the island form to fit the screen's notch if it has one.
- **Arrange the collapsed bar**: Right-click the collapsed island to tick which items it shows. Settings → Appearance → Collapsed bar now lists plugin items and the timer too: reorder them, move them to the other side, hide them, or keep them behind "+N", which opens on hover or click. On Mac, items that do not fit beside the notch go behind "+N" by themselves, and "Widest each side of the notch" gives the sides more room.
- **Move the island out of the way**: Adjust its overall opacity, dim it when idle and click through it, or choose how much stays visible when it tucks against an edge. The expanded panel can close when you click outside the island. `Ctrl+Alt+B` (`⌃⌥B` on Mac) moves it between the front and back. The outline and oil-film rim follow one continuous shape at the edge. A theme can now offer both light and dark palettes, with smooth transitions between them.
- **Easier-to-find settings**: Settings are regrouped, with a live appearance preview. The theme sets gain a Default card that brings back the colors of a fresh install. About now has Overview, Changelog, Plugin system, and Help & community tabs, and the theme market has moved into Themes. Fewer windows stay active in the background, Settings and the tray card open faster, and the island keeps a gentle transition with Reduce Motion on.
- **Recovers from errors**: A window that runs into an error reloads itself once. If that does not help, it shows a small bar where you can reload, restart Fuyu or open the log, so the island no longer just disappears. Open the error log from Settings → General → Data and backup.

### Other changes

- **Music and lyrics**: The card that pops up on a track change shows the album cover and the player's name and icon, and a click opens the music page. Players such as NetEase Cloud Music, QQ Music and KuGou are named in the interface language, and more players are recognized on Mac. With Chinese lyric sources enabled, Fuyu can show word-by-word lyrics from QQ Music and NetEase and prefers word-timed results. On Windows, it can also read the local Kugou lyrics cache.
- **Local API**: Now a page of its own under Extensions in the Settings sidebar. Copy or regenerate the token and see what the API opens and whether each part can be used now; requests to a feature that's turned off say so. New "Allow messages" switch (new, off by default): scripts and other programs can pop a message on the island with `POST /v1/notify`, and each source can be muted on its own.
- **Clipboard and translation**: Clipboard previews show full notes and offer more room in wide mode. The translation shortcut can be cleared, and custom translation endpoints no longer require an API key.
- **Recording and uninstall (Windows)**: Choose whether Fuyu windows appear in screen recordings. Choosing to delete data during uninstall also removes Fuyu credentials and app data without removing unrelated files from a custom data folder.
- **Community groups**: Settings → About → Help & community shows the WeChat group's QR code. An expired code is replaced without waiting for an app update.
- **Performance and fixes**: Lower background activity when the island is idle or windows are hidden, smoother long clipboard lists and glass resizing, and fixes for clipboard deletion, mail getting stuck on startup, switches not saving, remote sessions disappearing on updates, plugin alerts not reaching the island, plugin content on the island going stale after the plugin process restarts, the island closing as soon as the pointer leaves after a shortcut opened it, long Codex thinking being treated as finished, Claude Code hooks being blocked by Cursor or older Claude Code, and the floating pill's outline. Error messages from QQ, WeChat, backups, SSH and others now follow the interface language. On Mac, this also fixes a sometimes-missing island at startup, tray-card crashes, and drag cursors in screenshots; Fuyu's own sounds no longer take over the system's Now Playing, which used to leave the music page without a song and track changes without a notice. On Windows, Fuyu can recover from a WebView2 graphics process crash.
