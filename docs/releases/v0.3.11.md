## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_aarch64.dmg)

0.3.11 正式版，包含 v0.3.10 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### 插件

- **第 3 版插件平台**：正式版默认使用新版平台。没有 Node.js 的电脑首次启动时会自动下载约 30 MB；设置 → 插件 会显示进度，失败后可以重试。内置功能仍可在各自的设置页开关，升级不会把原本关闭的功能打开。
- **从第 2 版升级**：浮屿会提示迁移，并保留部分旧官方插件的设置；插件本身要到市场重新安装，番茄钟记录等插件私有数据不会迁移。网页里的 `fuyu://` 链接暂不支持一键安装；可到市场搜索，或打开下载好的 `.fuyu` 文件安装。
- **插件市场与设置**：市场卡片显示缩略图和平台兼容性，可放大查看截图；已装插件会标出它在岛上出现的位置，可以直接打开对应页面、改设置或运行命令。插件命令的快捷键可以在 设置 → 快捷键 修改。市场插件通常在新版本发布满 3 天后自动更新；作者密钥、来源或插件能做的事有变化时，不会静默更新。
- **官方插件**：市场里可装应用启动器、离线英汉词典、倒数日、闹钟、世界时钟，以及第 3 版的番茄钟、待办摘要、待办进度环、换歌提醒、天气、GitHub Issues 和系统监控。插件由市场单独更新，不随 App 安装包更新。

### 待办与日历

- **待办清单与专注**：一条待办可以拆成子步骤、展开写备注，并自动记录专注倒计时。标题以时刻开头（如 `15:00 回电话`）可在岛上准点提醒，也可以推迟。
- **待办整理**：支持按优先级排序、显示已用专注时间、自定跨天归档时间和行内 Markdown；重复待办可以避开节假日，还可用全局快捷键快速添加待办。
- **会议提醒**：岛上横幅可一键入会，也可用全局快捷键加入当前会议。日历会从事件地点和描述识别 Zoom、腾讯会议、飞书会议等链接；可设置会议期间暂停媒体，结束后恢复。
- **日程视图**：日历可按列表看日程，标出已谢绝和空闲的事件；CalDAV 子日历保留原名，可以单独隐藏或改颜色。

### 同步与消息

- **WebDAV 与端到端加密**：可用坚果云、Nextcloud 或群晖 NAS 等 WebDAV 服务跨设备同步；可以开启端到端加密，让同步服务器无法读取内容。剪贴板收藏也可选择同步（默认关闭），会自动过滤识别出的敏感内容。
- **更多聊天提醒（新，默认关闭）**：在 设置 → 消息 → 即时通讯 开启 Telegram、Discord、WhatsApp、TIM、飞书、钉钉或企业微信。Windows 支持通知内容；Mac 读取已安装应用在程序坞上的未读数，需要辅助功能权限。
- **复制和阅读通知**：长按消息或邮件通知可复制正文、链接或验证码。普通收起条上的长消息会先加宽，再换行或滚动；鼠标停在岛上时，预览不会自动消失。

### AI Agent

- **提醒卡片**：在 设置 → AI Agent 的「桌面提醒」里选择卡片样式、停留时长和点击后的去向。多条提醒按紧急程度叠放，悬停可暂停倒计时，待审批的提醒会保留到处理完成。回复支持 Markdown；（Mac）刘海两侧可显示会话图标和状态。
- **会话与审批**：新增 Cursor 编辑器会话和岛上命令审批；DeepSeek Harness、Factory Droid 和 TRAE 也可在岛上审批。点会话可跳到 Cursor、WorkBuddy 或 Claude 桌面版 Code 页里的对应对话；（Mac）还可定位到 Ghostty、iTerm2、WezTerm 或 tmux 的标签页或窗格。
- **用量环与钩子**：用量环新增 Cursor、Antigravity、WorkBuddy 和 DeepSeek Harness。AI Agent 首页可以查看、安装、修复或卸载各家的钩子，也可清理远程钩子。Claude Code 子 Agent 和 Claude 桌面版子会话可设为默认展开（默认关闭）。
- **（Mac）远程与手机推送**：开放 SSH 远程会话和 SSH 代理隧道，可在本机下载和托管 cc-connect，并通过飞书扫码配置。

### 外观与设置

- **液态玻璃**：可一键切换透明、着色或毛玻璃预设。设置中的「玻璃背后」可选实时窗口、仅壁纸或无背景，实时效果不可用时会说明原因。（Mac）支持系统原生毛玻璃，「自动」岛形会根据屏幕有无刘海切换。
- **小岛可以让出桌面空间**：新增整体透明度、闲置变暗并穿透点击、贴边露出样式和极小的贴边提示。默认用 `Ctrl+Alt+B`（Mac 上 `⌃⌥B`）在前后层切换。贴边时轮廓和油膜边连成一体，主题也可同时提供深浅配色，切换时平滑过渡。
- **更好找的设置**：重新分组常用设置，外观调整可实时预览；「关于」分成概览、更新日志和帮助，主题市场并入主题页面。常驻后台的窗口更少，设置和托盘卡片打开更快；启用系统「减少动态效果」时也保留轻微过渡。

### 其他

- **歌词**：启用中文歌词源后，新增 QQ 音乐和网易云逐字歌词，优先显示逐字版本；（Windows）还可读取酷狗本机歌词缓存。
- **剪贴板与翻译**：剪贴板预览显示完整备注，宽布局更宽；翻译快捷键可以清空，自定义翻译服务不再强制填写 API Key。
- **录屏与卸载（Windows）**：录屏可选择是否把浮屿窗口录进去。卸载时若选择删除数据，也会清理浮屿凭据和应用数据；自定义数据目录里的其他文件不会被一并删除。
- **本机接口**：在 设置 → 通用 → 本机接口 可复制或重新生成访问令牌；访问未开启的功能时会明确提示。
- **性能和修复**：降低窗口隐藏或岛闲置时的后台开销，改善剪贴板长列表和液态玻璃缩放；修复删除剪贴板历史无效、邮件服务偶尔要重启才就绪、内置开关未保存、远程会话更新时消失、插件通知不上岛和独立药丸描边溢出等问题。（Mac）修复启动后岛偶尔不显示、托盘卡片闪退及截图带入拖动光标；（Windows）WebView2 图形进程崩溃后可自动恢复。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11/Fuyu_0.3.11_aarch64.dmg)

The 0.3.11 release, with everything since v0.3.10. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

### Plugins

- **The v3 plugin platform**: The stable release now uses the new platform by default. If Node.js isn't installed, Fuyu downloads about 30 MB on first launch. Settings → Plugins shows the progress and lets you retry. Built-in features still have switches in their own settings, and upgrading keeps previously disabled features off.
- **Upgrading from v2**: Fuyu shows a migration notice and carries over settings for some older official plugins. Reinstall the plugins from the market; private data such as Pomodoro history does not carry over. One-click installs from `fuyu://` links are not available yet. Find the plugin in the market or open a downloaded `.fuyu` file instead.
- **Market and plugin settings**: Market cards show thumbnails and platform compatibility, and you can enlarge screenshots. Installed plugins show where they appear on the island. Open their pages, adjust settings, or run commands directly. Settings → Shortcuts lets you change plugin command shortcuts. Market plugins normally auto-update after three days, but not silently if the signing key, source, or what the plugin can do changes.
- **Official plugins**: The market offers App Launcher, the offline English–Chinese dictionary, Day Counter, Alarm, and World Clock, plus v3 versions of Pomodoro, To-do Digest, Todo Ring, Track Change Notice, Weather, GitHub Issues, and System Monitor. Plugins update separately through the market, not through the app installer.

### Todos and calendar

- **Checklists and focus time**: Break a todo into subtasks, add a note without leaving the island, and log time from a focus countdown. Start a title with a time (for example, `15:00 call back`) to get an island reminder you can snooze.
- **More ways to organize todos**: Sort by priority, show time spent focusing, set a custom day rollover, and use inline Markdown. Recurring todos can adjust around holidays, and a global shortcut opens the quick-add panel.
- **Meeting reminders**: Join from the meeting banner on the island or use a global shortcut to open the current meeting link. Calendar recognizes links for Zoom, Tencent Meeting, Feishu, and others in event locations and descriptions. Fuyu can pause media during a meeting and resume it afterward.
- **Agenda view**: Browse events as a list and see which were declined or marked free. CalDAV calendars keep their original names, and each calendar can be hidden or assigned its own color.

### Sync and messages

- **WebDAV and end-to-end encryption**: Sync through WebDAV services such as Nutstore, Nextcloud, and Synology NAS. Turn on end-to-end encryption to keep sync contents unreadable to the server. Clipboard favorites can sync too (off by default), with automatic filtering of detected sensitive content.
- **More chat alerts (new, off by default)**: Turn on Telegram, Discord, WhatsApp, TIM, Feishu, DingTalk, or WeCom under Settings → Messages → Instant messaging. Windows can show notification contents. On Mac, Fuyu reads unread counts from the Dock and needs Accessibility access.
- **Read and copy notifications**: Long-press a chat or mail notification to copy text, links, or verification codes. Long previews on the regular collapsed bar expand, then wrap or scroll. Hovering keeps the preview visible.

### AI Agent

- **Notice cards**: Choose a style, how long alerts stay, and what a click opens under Desktop alerts in Settings → AI Agent. Alerts stack by urgency, hovering pauses the countdown, and approvals stay until handled. Replies can use Markdown. On Mac, the icon and status can sit on either side of the notch.
- **Sessions and approvals**: View Cursor editor sessions and approve commands on the island. DeepSeek Harness, Factory Droid, and TRAE approvals are also supported. Click a Cursor, WorkBuddy, or Claude desktop Code session to open the corresponding conversation. On Mac, Fuyu can also find the right tab or pane in Ghostty, iTerm2, WezTerm, and tmux.
- **Usage rings and hooks**: Usage rings now cover Cursor, Antigravity, WorkBuddy, and DeepSeek Harness. See hook status, install, repair, or remove hooks from the AI Agent home page, including remote cleanup. You can expand Claude Code subagents and Claude desktop child sessions by default (off by default).
- **(Mac) Remote sessions and phone push**: SSH remote sessions and the SSH proxy tunnel are available, as is downloading and running cc-connect locally with Feishu QR setup.

### Appearance and settings

- **Liquid glass**: Pick a clear, tinted, or frosted preset. Behind the glass lets you choose live windows, wallpaper only, or no backdrop, and explains when it falls back. On Mac, Fuyu supports the native glass effect, and Auto switches the island form to fit the screen's notch if it has one.
- **Move the island out of the way**: Adjust its overall opacity, dim it when idle and click through it, or choose how much stays visible when it tucks against an edge. `Ctrl+Alt+B` (`⌃⌥B` on Mac) moves it between the front and back. The outline and oil-film rim follow one continuous shape at the edge. A theme can now offer both light and dark palettes, with smooth transitions between them.
- **Easier-to-find settings**: Settings are regrouped, with a live appearance preview. About now has Overview, Changelog, and Help tabs, and the theme market has moved into Themes. Fewer windows stay active in the background, Settings and the tray card open faster, and the island keeps a gentle transition with Reduce Motion on.

### Other changes

- **Lyrics**: With Chinese lyric sources enabled, Fuyu can show word-by-word lyrics from QQ Music and NetEase and prefers word-timed results. On Windows, it can also read the local Kugou lyrics cache.
- **Clipboard and translation**: Clipboard previews show full notes and offer more room in wide mode. The translation shortcut can be cleared, and custom translation endpoints no longer require an API key.
- **Recording and uninstall (Windows)**: Choose whether Fuyu windows appear in screen recordings. Choosing to delete data during uninstall also removes Fuyu credentials and app data without removing unrelated files from a custom data folder.
- **Local API**: Copy or regenerate the token in Settings → General → Local API. Requests to a feature that's turned off now say so.
- **Performance and fixes**: Lower background activity when the island is idle or windows are hidden, smoother long clipboard lists and glass resizing, and fixes for clipboard deletion, mail getting stuck on startup, switches not saving, remote sessions disappearing on updates, plugin alerts not reaching the island, and the floating pill's outline. On Mac, this also fixes a sometimes-missing island at startup, tray-card crashes, and drag cursors in screenshots. On Windows, Fuyu can recover from a WebView2 graphics process crash.
