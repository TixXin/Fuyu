## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_aarch64.dmg)

0.3.10 正式版，包含 v0.3.9 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **液态玻璃**：岛换上了流动的彩色液态玻璃，颜色取自主题色、正在放的歌的封面，或者自己挑。外观 → 样式 →「液态玻璃」里能调风格、浓度、速度、色块大小和油膜边，也能一键恢复默认。（Windows）玻璃背后默认是磨砂的桌面壁纸，模糊、饱和度和噪点都能调；系统关了透明效果时和 Mac 上一样，照旧用原来的玻璃。
- **岛的形态**：外观 → 尺寸与位置 →「形态」可以选贴顶、悬空药丸或刘海。屏幕没有刘海也能选刘海，岛会模拟一个出来。
- **托盘卡片**：点托盘 / 菜单栏图标（左键右键都行）弹出浮屿自己的卡片，有入口型、状态型、精简型三种，在 设置 → 行为 →「托盘卡片样式」里选。关掉的功能不会出现在卡片上。
- **剪贴板的空格预览能编辑了**：预览可以一直开着、钉住、调大小。图片能缩放拖动、裁剪、旋转和标注，文字能直接改；`Ctrl+S`（Mac 上 `⌘S`）保存到这条记录，几秒内可以撤销，`Ctrl+Shift+S` 另存成一条新的。
- **拖岛时的中线**：拖动岛时屏幕上显示横竖两条中线，靠近四条边的中点会轻轻吸到正中。外观 → 尺寸与位置 里可以关。
- **（Mac）拖岛改用 Control**：按住 Control 拖动岛、按住 Control 保持面板展开，不再用 Option，免得触发系统的窗口平铺。
- **新手引导**：新增「推送到手机」一幕，本机和 SSH 远程电脑都能一步步装好手机推送，远程电脑还可以顺手打开 SSH 代理隧道。选了 AI Agent 时多两步：挑会话卡片的样式，连接 AI 代理。新装默认用卡片样式和粒子效果。
- **语音输入**：按快捷键对着电脑说话，再按一下结束，识别出的文字可以存成待办、追加到今天的每日笔记，或者复制。识别在本机完成，不上传。识别组件和模型不随安装包，在 设置 → 语音输入 里点「下载」才下；开关和其他功能一样放在概览页。
- **待办的优先级和颜色**：待办可以设高、中、低优先级和颜色标签；设了时间的高优先级待办到点时岛上会提醒。
- **休息提醒**：设置 → 行为 →「休息提醒」里可以加久坐、护眼这类定时提醒，名字、图标和间隔都能改，默认关。锁屏或空闲时不计时，到点在岛上提醒，可以推迟 5 分钟或跳过；前台全屏时不打扰。
- **微信、QQ 消息看过就收走**：打开过微信或 QQ 之后，岛上已经看过的那些提醒会自动去掉，之后新来的留着。在消息设置里的「看过后从岛上去掉」可以关掉。
- **AI Agent**：
  - 新接入 GitHub Copilot CLI、Factory Droid、Grok CLI、Kimi Code、MiMo Code、ZCode、TRAE 和 TRAE CN、Qoder、CodeBuddy Code、Qwen Code，在 设置 → AI Agent 里「安装/修复」后就能在岛上看到会话。其中 Copilot CLI、ZCode、Qoder、CodeBuddy Code、Qwen Code、MiMo Code 能在岛上审批，TRAE 能审批命令。这几家大多还没在真机上测过，有问题欢迎反馈。
  - Agent 页：右键一行或点「⋯」可以跳到窗口、在文件夹中显示、复制路径、归档；能用方向键选行、回车跳转；鼠标停在一行上会显示完整标题和最近的提问。
  - Claude Code 会话下面会列出正在跑的子 Agent，点「n 个子 Agent」展开；Claude 桌面版的子会话挂在父会话下面，会话用桌面版里的标题。
  - Codex 会话改从它自己的数据库读取，旧会话、存储迁移后的会话都能列出来。
  - opencode 1.x 通过插件也能显示「等你」并在岛上审批；SSH 远程主机上的 opencode 会话也能列出来了。
  - SSH 远程：回复标记写进各家的提示词文件；Antigravity CLI 的远程命令可以在岛上审批；在远程电脑上也能检测代理，安装、配置和重启 cc-connect，飞书扫码也能在远程完成。
  - 点 Antigravity IDE 2.x 的会话能跳到它的窗口了。
  - 能读到 WorkBuddy AI（国际版）的会话和钩子；（Mac）能认出正在运行的 WorkBuddy AI。
  - 会话列表右边的时间统一写成 1m、2h、3d 这样的短格式。
  - 会话环插件的默认样式改成像素格；选过样式的不受影响。
- **修复 Agent 页导致的崩溃（Windows）**：0.3.9 的 Agent 页列表动效在新版 WebView2 上会让岛的页面崩掉，停在一个报错页。列表动效改成淡入、淡出加轻微平移，不再触发崩溃；万一页面以后还崩，岛会自动重新加载，不用手动刷新。
- **更新更稳**：
  - 下载更新和插件时，GitHub 连不上会自动换国内镜像重试；网易云 InfLink-rs 插件的一键安装也一样，失败时说明原因。
  - 安装更新前自动备份数据（设置、待办、剪贴板历史、插件数据等），出问题可以在 设置 → 关于 里恢复。
  - （Mac）更新装好后岛会自己重启，不再一直停在「正在重启」；15 秒还没重启时会给一个「立即重启」按钮。从 0.3.9 及更早版本更新时还需要手动重启一次。
  - 设置 → 关于 →「更新日志」可以翻看历史版本的更新说明，离线也能看。
- **有未读消息时岛不收起**：设置 → 行为 → 贴边收起 里新增「有未读消息时不收起」（默认打开），未读的微信提醒、QQ 通知和邮件会让岛保持展开；音乐设置页也能开「播放时不收起」。
- **鼠标、键盘电量**：蓝牙鼠标、键盘和（Mac）触控板连上时岛上显示电量，低于 20% 和 10% 各提醒一次。
- **磨砂配色**：内置灰白、透白磨砂、暖白磨砂三套配色，岛上的文字颜色可以单独设。
- **设置**：功能的开关只放在概览页的功能卡片上，各功能页不再重复一个开关；概览卡片的对齐和功能计数也修了。关掉剪贴板、翻译、日历、待办、音乐等功能后，它在后台的监听、快捷键和窗口也一起停掉。
- **剪贴板打开更快**：按 `Win+V`（Windows）或快捷键打开剪贴板时更快，历史多时也不卡。
- **插件**：安装包里带上了新版插件平台，现在还默认关着，不影响使用。插件页显示插件宿主占用的内存；插件可以读到浅色、深色主题的颜色变量，在浅色岛上也看得清。插件设置页里的密钥只显示圆点，只能复制，复制的内容不进剪贴板历史。
- **修复**：
  - （Windows）启动时岛有时显示一下就消失、只能从托盘叫出来。
  - （Mac）鼠标停在岛上就有悬停效果，不用先点一下，也不会抢走前台应用的键盘；启动时岛也不再抢走前台和键盘。
  - （Mac）岛拖进菜单栏或拖出屏幕顶端时会吸回顶边，拖动时也不再被系统平铺成全屏。
  - （Mac）从旧版升级后，有刘海的 Mac 保留贴在刘海两边的样子。
  - （Mac）替换或更新应用后没有重启时，保存邮箱密码等凭据会失败；现在会提示退出后重新打开，报错也不再写成 Windows 凭据管理器。
  - 更新下载或安装失败时，提示「更新安装失败」，不再说成检查失败。
  - 钉钉等拒绝按时间查询的 CalDAV 日历，现在改用另一种方式读出日程。
  - 日历订阅链接、代理地址里的账号密码不会再出现在错误信息里。
  - 只是预览过的邮件不算已读，「未读时不收起」不会因此失效。
  - 窗口加载后几秒还没显示出来时会自动重新加载。
  - 按钮隐藏后，它的提示也会跟着关掉。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.10/Fuyu_0.3.10_aarch64.dmg)

The 0.3.10 release, with everything since v0.3.9. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Liquid glass**: the island now wears flowing, colorful liquid glass, tinted from your theme color, the cover of the song that's playing, or colors you pick. Tune its style, strength, speed, blob size and oil-film edge under Appearance → Style → Liquid glass, or reset it in one click. (Windows) Behind the glass is a frosted copy of your desktop wallpaper by default, with blur, saturation and grain sliders; with system transparency turned off, and on the Mac, the island keeps the old glass.
- **Island form**: Appearance → Size & position → Form chooses between top, floating pill and notch. Notch works on screens without one too: the island draws its own.
- **Tray card**: clicking the tray / menu bar icon (left or right click) opens Fuyu's own card, in three layouts (entry, status, compact) chosen under Settings → Behavior → Tray card style. Features you've turned off don't appear on it.
- **Edit in the clipboard's space preview**: the preview can stay open, be pinned and resized. Images can be zoomed, panned, cropped, rotated and annotated, and text can be edited in place; `Ctrl+S` (Mac: `⌘S`) saves over the entry with a few seconds to undo, and `Ctrl+Shift+S` saves a new entry.
- **Centre lines while dragging**: dragging the island shows the screen's horizontal and vertical centre lines, and near the middle of an edge the island eases to the exact centre. Turn it off under Appearance → Size & position.
- **(Mac) Drag the island with Control**: hold Control to move the island or keep the panel open, instead of Option, which set off the system's window tiling.
- **Onboarding**: a new "push to phone" act walks you through phone push on this computer and on SSH remote computers, with an SSH proxy tunnel switch for remotes. If you pick AI agents, two more steps let you choose the session card style and connect your agents. New installs default to cards with particle effects.
- **Voice input**: press a shortcut, speak, press it again, and save the recognised text as a todo, append it to today's daily note, or copy it. Recognition runs on your computer and nothing is uploaded. The recognition runtime and model are not in the installer; download them under Settings → Voice input. Its switch sits on the overview like the other features.
- **Todo priority and colors**: todos can have a high, medium or low priority and a color tag, and a scheduled high-priority todo is announced on the island when it's due.
- **Break reminders**: Settings → Behavior → Break reminders lets you add timed reminders such as sitting and eye breaks, with their own name, icon and interval (off by default). They don't count while the screen is locked or you're idle, show on the island when due, can be snoozed for 5 minutes or skipped, and stay quiet while a full-screen app is in front.
- **WeChat and QQ reminders clear once seen**: after you open WeChat or QQ, the reminders you've already seen leave the island; newer ones stay. Turn it off with "Remove once seen" in the message settings.
- **AI agents**:
  - New: GitHub Copilot CLI, Factory Droid, Grok CLI, Kimi Code, MiMo Code, ZCode, TRAE and TRAE CN, Qoder, CodeBuddy Code and Qwen Code. Use Install/repair under Settings → AI Agent and their sessions show on the island. Copilot CLI, ZCode, Qoder, CodeBuddy Code, Qwen Code and MiMo Code can be approved on the island, and TRAE's commands can too. Most of these haven't been tested on real installs yet, so feedback is welcome.
  - Agent page: right-click a row or click "⋯" to jump to its window, show it in the folder, copy the path or archive it; arrow keys pick a row and Enter jumps; hovering a row shows its full title and latest prompt.
  - Claude Code sessions list their running subagents; click "n subagents" to expand. Claude desktop child sessions sit under their parent session, and desktop sessions use the desktop app's titles.
  - Codex sessions are read from Codex's own database, so older sessions and sessions after its storage migration are listed.
  - opencode 1.x shows waiting and can be approved on the island through a plugin, and opencode sessions on SSH remote hosts are listed.
  - SSH remote: the reply marker goes into each agent's prompt file; remote Antigravity CLI commands can be approved on the island; agents can be detected and cc-connect installed, configured and restarted on remote computers, including the Feishu QR setup.
  - Clicking an Antigravity IDE 2.x session jumps to its window.
  - WorkBuddy AI (the international edition) sessions and hooks are read; (Mac) a running WorkBuddy AI is recognised.
  - Session ages in the list read 1m, 2h, 3d in every language.
  - The session ring plugin now defaults to the pixel grid style; a style you picked is kept.
- **Fixed a crash caused by the Agent page (Windows)**: in 0.3.9 the Agent page's list animations crashed the island's page on recent WebView2, leaving an error page. The rows now fade and shift slightly instead, which no longer crashes; if the page ever crashes again, the island reloads it on its own.
- **Steadier updates**:
  - When GitHub can't be reached, update and plugin downloads retry through mirrors. The NetEase InfLink-rs one-click install does the same and explains failures.
  - Your data (settings, todos, clipboard history, plugin data and more) is backed up before an update installs, and can be restored from Settings → About.
  - (Mac) The island restarts on its own after an update installs instead of staying on "restarting"; if it hasn't restarted after 15 seconds you get a Restart now button. Updating from 0.3.9 or earlier still needs one manual restart.
  - Settings → About → Release notes lets you read the notes of past versions, offline too.
- **The island stays out while messages are unread**: Settings → Behavior → Tuck to edge has a new "stay out while messages are unread" (on by default) for pending WeChat reminders, QQ notifications and unread mail. The music page also has "stay out while music plays".
- **Mouse and keyboard battery**: Bluetooth mice, keyboards and (Mac) trackpads show their battery on the island when they connect, with one warning each at 20% and 10%.
- **Frosted color schemes**: three built-in schemes (gray-white, clear frosted, warm frosted), and the island's text color can be set on its own.
- **Settings**: features are turned on and off only on the overview's feature cards; the feature pages no longer repeat the switch. Card alignment and the feature count are fixed. Turning off a feature such as the clipboard, translation, calendar, todos or music also stops its background listeners, shortcuts and windows.
- **Faster clipboard**: the clipboard opens faster from `Win+V` (Windows) or its shortcut, even with a long history.
- **Plugins**: the installer now carries the new plugin platform, still off by default, so nothing changes yet. The plugin page shows the plugin host's memory; plugins get light and dark theme variables, so they read well on the light island. Secrets on the plugin settings page show as dots and can only be copied, and the copy stays out of clipboard history.
- **Fixes**:
  - (Windows) The island sometimes appeared at startup and then vanished until it was shown from the tray.
  - (Mac) Hovering the island shows hover effects without a click first and without taking the keyboard from the app in front; the island no longer takes the foreground and keyboard at launch either.
  - (Mac) An island dragged into the menu bar or past the top of the screen snaps back to the top edge, and dragging no longer tiles it full screen.
  - (Mac) After upgrading from an older version, Macs with a notch keep the island around the notch.
  - (Mac) Saving a credential such as a mail password failed when the app had been replaced or updated without a restart; it now asks you to quit and reopen, and no longer mentions the Windows Credential Manager.
  - A failed update download or install says "Update install failed" instead of calling it a failed check.
  - CalDAV calendars that refuse time-ranged queries, such as DingTalk, now have their events read another way.
  - Calendar subscription links and the user name and password in a proxy address no longer show up in error messages.
  - Previewing a mail doesn't count as reading it, so "stay out while unread" keeps working.
  - A window that hasn't shown up a few seconds after loading reloads itself.
  - A button's tooltip closes when the button is hidden.
