这是 0.3.15 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **首页图标、页签改名与「更多」菜单**：第一个页签默认换成「首页」图标；每个页签都能在 设置 → 岛屿布局 里改名；页签放不下时先收成图标，再放不下就收进「更多」菜单，不用再悬停或滚轮去找。
- **全局展开/收起快捷键**：同一个组合键开关面板（默认不设），并新增「记住上次退出时的面板页面」开关。
- **（Windows）免安装便携版**：fuyu.exe 旁边放一个空的 fuyu-portable.txt，数据就存在程序旁边的 data 文件夹，拷到 U 盘或别的盘也能直接用。
- **公司网络代理**：网络代理「跟随系统」现在认自动配置脚本（PAC）和自动检测（WPAD），设置里能看到实际用的代理；邮箱连不上时会说明是代理、端口、证书还是网络的问题。
- **打开插件文件夹**：设置 → 插件 的「更多」菜单里可以直接打开插件所在的文件夹。
- **AI Agent**：脚本启动代理时带上 `FUYU_AGENT_STATUS=off` 即可完全静默；隐藏会话的目录规则支持 `*` 通配，会话菜单可一键隐藏同类临时目录的会话。
- **新装默认弹横幅**：新装后收到消息默认在岛下方弹横幅，不再直接展开整个面板；已有设置不变。
- **侧边翼**：抽屉右上角的收起按钮换成朝边缘的收起图标，并加上悬停提示。
- **修复**：
  - （Windows）开着「扫光」时，展开面板里有一条黑线来回扫过。
  - AI Agent 页双列卡片内容被截断，双栏工作台等布局排版错乱。
  - （Mac）日历的钥匙串授权每 15 分钟反复弹出，现在每次启动最多问一次。
  - 收起条没有文字、缩放大于 1 倍时被误收进「+N」，拉宽卡在约 260px。
  - 开着代理时 GitHub Issues 插件报 HTTP 403，刷新失败时缓存列表也不显示。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.15-beta.1/Fuyu_0.3.15-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.15-beta.1/Fuyu_0.3.15-beta.1_aarch64.dmg)

This is the first beta of 0.3.15. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Home tab, tab names and a More menu**: the first tab is now a Home icon; every tab can be renamed in Settings → Island layout; tabs that do not fit fold to icons first, then into a More menu, so you no longer hover or scroll to find them.
- **Global expand/collapse shortcut**: one key combination opens and closes the panel (unset by default), plus a setting to remember the last panel page.
- **(Windows) Portable mode**: put an empty fuyu-portable.txt next to fuyu.exe and the data stays in the data folder beside it, ready to run from a USB stick or another drive.
- **Company network proxies**: Follow system now understands auto-config scripts (PAC) and WPAD and shows the proxy it actually uses; when mail cannot connect, the error says whether the proxy, the port, the certificate or the network is to blame.
- **Open the plugins folder**: Settings → Plugins → More opens the folder your plugins live in.
- **AI Agent**: agents started with `FUYU_AGENT_STATUS=off` stay silent; folder hide rules accept `*` wildcards, and the session menu can hide sessions from similar temp folders in one click.
- **Banners for new installs**: new installs show new messages as a banner under the island instead of opening the whole panel; existing settings are unchanged.
- **Side dock**: the drawer's collapse button is now an edge collapse icon with a tooltip.
- **Fixes**:
  - (Windows) A dark line swept back and forth across the expanded panel when Sheen was on.
  - AI Agent page cards were clipped, and the split, bento, projects and minimal layouts rendered out of shape.
  - (Mac) The calendar's Keychain prompt repeated every 15 minutes; it now asks at most once per launch.
  - Collapsed bars without text at more than 1x scale were shelved behind +N and stuck around 260px when widened.
  - The GitHub Issues plugin got HTTP 403 behind a proxy and hid its cached list when a refresh failed.
