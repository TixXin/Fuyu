## 关于这个版本

0.3.6 正式版，包含 v0.3.5 以来的全部改动。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **从官网一键装插件**：在 [官网插件页](https://fuyu.tix.xin/plugins/) 点「在浮屿中安装」，浮屿会打开 设置 → 插件市场，并把这个插件放在最上面，你点「安装」确认即可，签名和权限照常检查。链接格式是 `fuyu://market/install/<插件 id>`，插件不在市场里时会说明。

## About this release

The 0.3.6 release, with everything since v0.3.5. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Install plugins from the website**: press "Install in Fuyu" on a [plugin page on the website](https://fuyu.tix.xin/en/plugins/) and Fuyu opens Settings → Plugin market with that plugin at the top; press Install to confirm, with the usual signature and permission checks. The link is `fuyu://market/install/<plugin id>`; if the plugin isn't in the market, the card says so.

## Downloads

- `Fuyu_0.3.6_x64-setup.exe`: Windows x64 EXE installer.
- `*.msi`: Windows x64 MSI installer.
- `SHA256SUMS.txt`: SHA-256 checksums for both installers.
