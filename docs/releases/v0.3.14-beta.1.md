这是 0.3.14 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **Agent 会话页焕新，新增五套可切换布局**：默认为「分层聚焦」，另有「双栏工作台」「双列卡片」「项目指挥台」「极简清单」，可在 Agent 页顶栏随时切换，也在 设置 → AI Agent → 会话列表 提供实时岛屿预览；顶部额度栏新增「极简细条」样式。
- **点击 Antigravity 会话直达对应对话**：在 Agent 页点击 Antigravity 2.0 桌面版会话会直接切到该对话，不再只切到窗口。
- **待审批时展开岛屿直达审批页**：AI Agent 有待处理审批或提问时，悬停或点击展开岛屿直接进入审批卡片页。
- **（Mac）刘海模式顶栏收纳与指示灯调整**：展开面板顶栏放不下的页面改收进「··· +N」菜单，不再在窄缝里横滚；录音或录屏时收起态岛屿不再亮起刘海边框，仅在展开面板保留。
- **默认展开面板尺寸调整**：默认尺寸调整为 800 × 320。
- **Antigravity 离线或异常时说明原因**：离线登录过期或额度读取失败时，Agent 页顶部额度栏显示灰胶囊，并在悬停卡片里说明原因。
- **移除 Antigravity 的岛上命令审批拦截**：避免 TURBO 模式和只读命令被逐条弹窗打断，保留状态灯、会话列表、用量环与对话跳转。
- **天气插件 1.4.0**（插件市场独立更新）：新增 5 个免费免 Key 天气源（中央气象台、Open-Meteo、CMA 模式、MET Norway、wttr.in）支持手动与故障自动切换；支持城市候选搜索（解决国内县区搜不到或错配）、多城市切换、极端天气提醒（默认关闭）、可选日出日落 / 紫外线与空气质量，并优化 7 天温度条、面板小组件与刘海显示，同时修复添加城市输入时卡死的问题。
- **修复**：
  - 升级到 Antigravity 2.35+ 后，Agent 页顶部不显示 Antigravity 额度。
  - （Mac）Claude Code 额度过期后不会走系统代理补查；现在会自动走系统代理补查，失败时在「已过期」悬停卡片里说明原因。
  - （Mac）刘海模式下点击「··· +N」菜单靠下项目时面板误收起、菜单悬空，以及收起条右侧异步插件内容持续闪烁、挤在一起不收进「+N」。
  - （Mac）液态玻璃开启「透出窗口」时，贴边岛屿圆角与顶部弧线外偶尔露出直角背景块。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.1/Fuyu_0.3.14-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.1/Fuyu_0.3.14-beta.1_aarch64.dmg)

This is the first beta of 0.3.14. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Redesigned Agent sessions page with five layouts**: switch between Focused (default), Split, Bento, Projects, and Minimal from the Agent header, or preview them live in Settings → AI Agent → Session list; the top usage bar also adds a Minimal strip style.
- **Jump straight to Antigravity conversations**: clicking an Antigravity 2.0 desktop session now switches directly to that conversation instead of only focusing the window.
- **Open pending approvals on expand**: hovering or clicking to expand the island while an AI Agent approval or question is waiting takes you straight to the approval view.
- **(Mac) Notch header overflow menu and recording glow**: panel tabs that do not fit beside the notch now fold into a `··· +N` menu instead of horizontal scrolling; camera and mic notch glow is now shown only on the expanded panel, not on the collapsed bar.
- **Default expanded panel size**: adjusted to 800 × 320.
- **Explain Antigravity quota errors**: when Antigravity's offline login expires or its quota check fails, the Agent usage bar shows a muted chip with the reason on hover.
- **No more command approval prompts for Antigravity**: removed island command approval interception so TURBO mode and read-only commands are not interrupted one by one, while keeping status lights, sessions, usage and conversation switching.
- **Weather plugin 1.4.0** (updated via the plugin market): adds 5 free no-key weather sources (NMC China, Open-Meteo, CMA model, MET Norway, wttr.in) with manual and automatic failover, dual geocoding for Chinese counties, multi-city switching, opt-in severe alerts, optional sunrise/sunset, UV and AQI, refined 7-day range bars, widgets and notch display, plus a fix for freezing when typing in city search.
- **Fixes**:
  - Antigravity usage disappeared from the Agent page after updating to Antigravity 2.35+.
  - (Mac) Expired Claude Code usage did not re-check through the system proxy; it now uses the system proxy and explains failures on the expired chip hover card.
  - (Mac) Clicking lower items in the notch `··· +N` menu collapsed short expanded panels and left the menu floating, and async plugins on the right wing flickered continuously instead of folding into `+N`.
  - (Mac) Native liquid glass backdrop occasionally leaked a rectangular corner behind docked islands.
