这是 0.3.11 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **测试版默认打开新版插件平台**：从这一版起，测试版不用再设 `FUYU_PLUGINS_V3=1`，启动就用新版插件平台。电脑上没有 Node 时会自动下载，插件页显示进度，失败了可以点「重试」。消息提醒、AI Agent、Claude 用量环、cc-connect 等功能改由新平台的内置插件提供，用法不变；遇到问题欢迎反馈。
- **（Mac）岛的形态多了「自动」**：设置 → 外观 →「岛的形态」新增「自动」，并设为默认：在有刘海的屏幕上贴合刘海，其他屏幕贴顶；换屏幕、合上或打开笔记本时跟着变。
- **液态玻璃预设**：外观 → 样式 →「液态玻璃」可以一键选预设（iOS 26 透明、iOS 26 着色、流彩毛玻璃、iOS 18 毛玻璃、Win11 Mica），调过的参数显示为「自定义」。新手引导选形状的那一步也能直接选实色或液态玻璃。
- **打开更快**：设置窗口关掉后再打开快很多；托盘卡片先用上次的数据显示出来，再刷新，（Windows）第一次点开也不用等。
- **动画**：各处的动画时长和曲线统一了一遍。系统开了「减少动态效果」时，岛的展开收起和淡入淡出保留轻微过渡，不再生硬地跳变。
- **AI Agent**：
  - 设置 → AI Agent 首页直接显示各家钩子的状态和「安装/修复」按钮；（Mac）也能看到连接页。
  - 子 Agent 列表在卡片和紧凑显示方式下也能展开。
  - 会话列表右边的时间列固定宽度、右对齐，不再参差不齐。
- **修复**：
  - 清掉微信提醒后，标签上的红点也一起消失；邮箱标签不再显示多余的「已连接」圆点。
  - （Mac）用截图快捷键时，岛的拖动光标和调整大小的提示不会再被截进图里；现在要单独按住 Control 约 0.2 秒才进入拖动。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.1/Fuyu_0.3.11-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.1/Fuyu_0.3.11-beta.1_aarch64.dmg)

This is the first beta of 0.3.11. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Betas use the new plugin platform by default**: from this beta on, beta builds start the new plugin platform without setting `FUYU_PLUGINS_V3=1`. If Node isn't installed it is downloaded automatically, with progress on the plugins page and a Retry button if it fails. Message reminders, AI agents, the Claude usage rings, cc-connect and more now come from the new platform's built-in plugins and work as before; feedback is welcome.
- **(Mac) An "Auto" island form**: Settings → Appearance → Island form has a new Auto option, now the default: the island hugs the notch on screens that have one and sits at the top elsewhere, following you when you switch screens or open and close the lid.
- **Liquid glass presets**: Appearance → Style → Liquid glass offers presets (iOS 26 clear, iOS 26 tinted, Frosted flow, iOS 18 frosted, Windows 11 Mica); settings you tuned show as Custom. The onboarding shape step also lets you pick solid or liquid glass.
- **Opens faster**: the settings window reopens much faster after you close it, and the tray card shows with its last data and then refreshes; (Windows) the first click no longer waits either.
- **Motion**: animation durations and curves are unified across the app. With Reduce motion on, the island's open/close and fades keep a gentle transition instead of jumping.
- **AI agents**:
  - Settings → AI Agent's home page shows each agent's hook status and an Install/repair button; (Mac) the connection page is available too.
  - The subagent list can be expanded in the card and compact views as well.
  - The time column in the session list has a fixed width and is right-aligned.
- **Fixes**:
  - Clearing WeChat reminders also clears the tab's dot, and mail tabs no longer show an extra connected dot.
  - (Mac) The island's move cursor and resize hints no longer end up in screenshots taken with the shortcut; the island now enters drag only when Control alone is held for about 0.2 s.
