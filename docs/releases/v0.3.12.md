## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_aarch64.dmg)

0.3.12 正式版，包含 v0.3.11 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### Fuyu 页与小组件

- **展开就是 Fuyu 页**：点岛、悬停展开、从贴边或侧边岛打开，都先落在 Fuyu 页；快捷键、消息、Agent 提醒这些指明了页面的照旧去对应的页。Fuyu 页上是一屏一屏的小组件，一屏放不下就翻页，宽度跟着面板变，面板调窄时组件整体缩小。
- **28 个小组件**：今日、番茄钟、打卡、专注统计、习惯、喝水、便签、倒计时、世界时钟、日出日落、年进度、月历、秒表、未读、截图、翻译、系统状态、电池、网络、快速启动、音量亮度等。没摆过的会先放一套默认布局，关掉的功能对应的组件不会出现；没有电池的台式机上默认不放「电池」。
- **外设电量**（新）：「外设电量」组件列出已连接的蓝牙耳机、鼠标、键盘、触控板的电量，同一台设备只出现一次，也可以在收起条上显示电量最低的那个。Mac 上苹果和第三方蓝牙鼠标键盘不用任何权限就能读；第三方耳机等要在组件里点「读取第三方蓝牙设备」授权蓝牙后读取。
- **在岛上摆组件**：点页头的布局按钮进入编辑，长按或直接拖动组件，其他组件实时让开；从底部组件栏拖进来就能添加。「网格」和「自己摆」两种模式，「自己摆」按点阵吸附、对齐旁边的组件，碰到会把它推开。组件还能跨页拖：贴边停一下翻页、拖到页头的缩略图上直接送过去、「全部」看所有页，还有暂存架和方向键翻页；随时可以恢复默认布局。
- **组件出场动效**：展开面板时小组件依次出场，共十一种，默认每次换一种，数字、环形进度和格子会跟着动起来。在 设置 → 行为 → 展开 里可以固定一种或关掉；同一处还能把 Fuyu 页标签换成水母图标（新，默认关闭）。

### 岛屿

- **大写锁定提示**（新，默认关闭）：按 Caps Lock 时收起的小岛闪一下提示开或关，大写开着时留一个小角标，点它就关掉大写。在 设置 → 系统提示 里打开。
- **消息页六种布局**：默认一次一条，还有统一收件箱、三栏、按人叠卡、来源看板、时间轴；所有来源合在一起按时间排，验证码单独放大、一键复制。在 设置 → 消息 里换布局，岛上立刻跟着变。
- **岛屿布局改版**：设置 → 岛屿布局 分成「收起的岛」「展开的面板」「显示与刘海」三个标签。顶部的预览是真岛的实时镜像，刘海、胶囊、任务栏形态都跟着变，点一项能定位到下面的清单；收起条的项目是可拖动的标签，分左、中、右和「+N」几格摆放，可以直接拖预览里的项目，拿下来能撤销。「展开的面板」的预览按真实大小、一页几列两行画，和岛上一样。中心图案改成看图挑选的卡片，每个展开页可以换页头图标。
- **收起条的文字自己排**：岛屿布局 → 显示与刘海 →「文字的先后」里调整会议、歌词、Agent 标题、待办的顺序，也能隐藏某一类；原来的「歌词优先 / Agent 优先」并进了这张列表。
- **收起条放不下时进「+N」**：没有刘海时，放不下的项目收进「+N」，不再被挤掉或裁掉；新装的插件放到项目更少的一侧，安装提示里能看到它在哪并直接去调整。没有待办时，小岛按图标和小组件收窄，不再留一大段空白。
- **各页面默认一样大**：切换页面时面板不再忽大忽小；在岛上单独调过尺寸的页面照旧，设置 → 布局 →「各页面的尺寸」里能逐个恢复默认。岛和面板的最大宽高按屏幕算，不再卡在 800 × 640。
- **新的改尺寸方式**：面板底部有拉环，边缘停一下再拖，下角旋钮整档切换（紧凑 / 默认 / 宽大），右键「调整大小…」可以用方向键微调、Esc 撤销；收起的岛拖两端的小拉环改宽度。Mac 上也能拖边缘调大小。
- **新的开合动画**：默认改成「弹开」，宽度冲出去再回来，更顺；新增「弹动幅度」（轻微 / 常规 / 弹动）。另有「灵动」「利落」「柔弹」「先横后竖」「生长」可选；已经选过别的不变。设置 → 行为 里还能选鼠标靠近收起的岛时怎么反应，默认「碰到弹一下」，也可以关掉。
- **水母标志**：应用图标、托盘 / 菜单栏图标、岛上的状态灯和设置 → 关于都换成了水母。
- **页头**：页签换成滑动的胶囊；右侧按钮挪到页签旁边，去掉了「隐藏」和「重置位置」。岛展开时按 `Ctrl+,`（Mac 上 `⌘,`）打开设置。点展开岛顶栏或内容的空白处就收起。
- **默认圆角 24**，和 Mac 的刘海一样圆；**侧边岛**默认和面板一样高，歌词竖着显示，也显示插件放在收起条上的内容。
- （Windows）**岛保持在最上层**：开着置顶时，不会再被别的置顶窗口（比如点了图钉的微信图片查看器）盖住。

### 刘海（Mac）

- （Mac）**两侧放得更满**：刘海两侧各至少显示两项，放不下时这一侧自动变宽，再借另一边的空位，最后才收进「+N」；世界时钟在两翼只显示时间。收起的岛两端可以拖，改「刘海两侧最宽」。
- （Mac）**文字放哪自己选**：待办、歌词、Agent 标题和会议的文字可以收进「+N」小面板、常驻刘海下面一行、有变化时出现 4 秒或不显示。
- （Mac）**刘海边框和光圈**：外观 → 显示 →「刘海」可以给岛和展开的面板加一圈外框（发丝、辉光、环游、汇流、极光、下沿光六种，默认关），能跟着新消息和 Agent 状态变色；也能给摄像头刘海加一圈光，摄像头、麦克风在用时亮绿 / 橙。展开面板时默认给刘海描一圈细线，可以关掉。带实时预览和「试一下」。
- （Mac）**展开面板不挤**：标签栏不再挤在一起，提醒、翻译、截图按钮挪到刘海右边；把岛拖离刘海后恢复成普通布局。

### Windows 11 任务栏

- （Windows）**岛可以放进任务栏**：Windows 11 上 设置 → 外观 → 位置 →「吸附到」新增「任务栏」，收起的岛放进任务栏，展开时面板从任务栏上方弹出。按住岛左边的竖线可以沿任务栏拖到想要的位置。收起时默认透明，像任务栏按钮一样，也可以改成跟岛的主题一样。任务栏放不下、自动隐藏或有全屏程序时，退回贴在屏幕底边，离开全屏后回到原位。

### 截图与录屏

- **新标注工具**：模糊、直线、聚光灯，都有单键快捷键；画好的标注能选中、移动、改颜色粗细、删除，双击文字可以再改。马赛克的单键改成 `X`，按住 `M` 照旧是测距离。
- **快捷键速查卡**：截图时角落有一张能拖动的速查卡，按 `?` 或 `F1` 收起展开；选好区域后工具栏多了「录屏」和「速查」两个按钮。
- **认二维码、按文字搜**：选区里有二维码时能直接打开或复制；截图历史可以按图里的文字搜索（文字在本机识别）。
- **贴图更好用**：贴图上能直接标注、识别文字、旋转、折叠和恢复。
- **截图送到别处**：截图可以放进今天的笔记，或建成一条带图的待办；发给 Agent 时会带上备注和截图来自哪个窗口、哪个网页。
- （Mac）**能录屏了**：区域录屏，能录系统声音和麦克风，也能录成 GIF，存到「影片」文件夹。
- （Mac）**截图能吸附到控件**：开了辅助功能权限时，也能吸附到按钮、输入框这些控件；按 Esc 直接退出，不用先点一下选区。
- （Windows）**全屏游戏不再截成黑屏**。

### 待办与日历

- **节假日提醒和放假倒计时**：订阅了中国节假日时，前一天 20:00 后岛上提醒一次「明天调休，要上班」或「明天起国庆节放假 · 共 7 天」（默认开启，在 设置 → 日历 → 「调休和放假前一晚提醒」里关闭，需要装计时插件）；日历页今天那行显示离下次放假还有几天。节假日数据保留到明年底。
- **每年重复的待办**：重复方式新增「每年重复」和「每年重复（农历）」，也可以在标题里写 `@每年` / `@农历每年`；农历生日、纪念日每年自动按农历日期提醒。降级回旧版本后，这些待办会变成不重复的单次待办。
- **日期选择器标出节假日**：休息日角上标「休」、调休上班标「班」，周末数字变淡。
- **没加日历也能看月历**：日历页没有添加任何日历时也照常显示月视图（农历、节气、节日）；新增母亲节、父亲节和护士节、宪法日等纪念日。

### AI Agent

- **按 Agent 安装和修复钩子**：设置 → AI Agent →「钩子与代理」里每个 Agent 的卡片单独显示钩子状态，可以单独安装、修复或卸载；关掉开关时可以顺带移除钩子。新增自动安装和自动修复（默认开启）：发现新装的 Agent 或钩子过时会自动处理，并在岛上告诉你。
- **Cursor 审批两边都弹**：Cursor 要运行命令时，编辑器里立刻弹出它自己的提示，岛上的卡片同时保留，点「去 Cursor」跳过去。
- **审批更稳**：Claude Code 的岛上审批不再因为浮屿换了端口就失效；岛没开时 Agent 直接用自己的提示，不卡住；审批卡片不再重复显示状态、把按钮挤掉。

### 设置

- **跨设备同步引导**：还没设置时只显示三步引导；设好后用勾选格子选同步什么，可选的收进折叠里。
- **设置页重新整理**：日历分成「日历」和「提醒」两页，提醒页能直接看到收起条和强提醒横幅的样子；AI Agent 的提醒把每件事的岛上弹出、声音和手机推送合进一张表；贴边隐藏换成实时预览和缩略图，动画移上去就演一次；材质改成能预览的缩略图，两个不透明度并排；剪贴板设置分成粘贴、贴到终端、隐私与性能，冷门项收进「高级」。搜旧的设置名仍能找到所在的页。
- **剪贴板窗口可以不预先准备**：设置 → 剪贴板 新增「启动时预先准备剪贴板窗口」。打开时第一次按快捷键马上出来，代价是一直多占约 40 MB；关掉时第一次打开稍慢、隐藏 10 分钟后释放。Windows 上默认打开，Mac 上默认关闭。

### 其他

- **Apple Music 官方歌词**：设置 → 音乐 → 歌词 新增「Apple Music 官方歌词」，用 Apple Music 播放时先查 Apple 自己的逐字歌词和翻译（需要 Apple Music 订阅，并填上令牌）。
- **消息卡片显示 Markdown**：机器人和 Agent 发来的表格、粗体、链接、代码块按格式显示。
- **检查更新先问官网**：先从浮屿官网检查更新，GitHub 留作后备，国内更快更稳；官网没跟上时也能从 GitHub 拿到最新版本。
- **插件市场**：新增「计算器」（表达式、汇率、单位换算、日期、个税、年龄等）和「图床上传」（把截图传到 S3 兼容的存储并复制链接）；切歌提示 1.3.0 在播放器位于前台时默认也会提示；系统监控 1.1.2 在 Mac 上 GPU 显示「共享 已用 / 总量」。插件由市场单独更新。
- **按钮提示统一 0.4 秒**；设置 → 关于 → 帮助 里的社区群二维码直接显示。
- （Mac）**更顺、更省内存**：120Hz 屏幕上展开收起跟上刷新率，刚收起又打开时不再卡一下；岛不再越用越多地占着应用图标和系统对象（原来可能多占几百 MB），收起时少占约 45 MB 图形内存。
- （Mac）**应用名跟着界面语言**：程序坞和菜单栏里的名字、菜单跟着浮屿的语言；设置窗口开着时有自己的程序坞图标。输入框不再拼写检查和自动更正。
- （Windows）**隐藏的窗口更省内存**：翻译、剪贴板这些窗口收起后不再在后台刷新。

### 修复

- **岛屿突然「消失」**：0.3.11 默认把 `Ctrl+Alt+B`（Mac 上 `⌃⌥B`）设为「岛屿置于窗口后面」，和 VS Code、Cursor、JetBrains 的快捷键冲突。现在这个快捷键默认不设；岛退到后面前会先说一声，再按一次可以取消；托盘 / 菜单栏卡片上能看到岛在后面，点一下就回到最前。之前特意设过的需要重新设一次。
- 岛偶尔在展开、收起时卡一下；面板开合时岛左右晃一下；悬停时收起的岛偶尔左右抖；鼠标停在岛上时点开，开合动画被跳过。
- （Mac）岛闲置一会儿后第一次展开没有动画、直接弹开。
- 改尺寸的手柄碰得到却拖不动；快速拖面板边缘、松手时鼠标刚好在外面，面板会收起；切到更窄的页面时，鼠标没动也被当成移出而收起。
- 开着音乐「封面颜色」时，展开面板的顶边和边框被光晕冲淡；「亮点颜色」只改了预览、没改到岛上的小圆点。
- （Windows）外设电量读不到蓝牙耳机、鼠标和键盘。
- （Windows）岛吸附在任务栏里时，打开全屏程序会先跳到任务栏上方中间闪一下。
- （Windows）插件运行环境下载时反复报「拒绝访问」、只能用管理员身份运行才能过；下载失败时会分清是磁盘还是网络的问题。
- （Windows）Apple Music 的歌手名后面带着专辑名、歌词匹配不上。
- （Mac）截图时选区窗口错位，顶部只显示冻结画面底部一条；贴图和贴图缩放也一起修好。
- （Mac）在剪贴板里选了条目只复制、没粘贴而且没有提示：没有辅助功能权限时，岛上会提示「已复制，未粘贴」，并带一个按钮直接打开「隐私与安全性 → 辅助功能」。
- 「导出设置」和样式预设的导出一直提示「备份文件名无效」。
- 从第 2 版插件升级时，系统监控插件被当成不支持的第三方插件。
- 截图建的待办没带上图片；切歌提示自己关掉时，消息页的来源图标闪一下。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.12/Fuyu_0.3.12_aarch64.dmg)

The 0.3.12 release, with everything since v0.3.11. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. ## What's New

### The Fuyu page and widgets

- **Opening lands on the Fuyu page**: clicking the island, hover-to-open, the tucked edge and the side island all open on the Fuyu page; shortcuts, messages and agent alerts that name a page still go there. The page holds widgets one screen at a time, pages when they don't fit, and follows the panel width, shrinking the widgets when the panel is narrow.
- **28 widgets**: today, pomodoro, streak, focus stats, habits, water, note, countdown, world clock, sunrise and sunset, year progress, month, stopwatch, unread, screenshot, translate, system status, battery, network, quick launch, volume and brightness, and more. Until you arrange it, the page starts with a default set, leaving out widgets for features you turned off, and the Battery widget on desktops without a battery.
- **Device batteries** (new): a widget lists the battery of connected Bluetooth headphones, mice, keyboards and trackpads, each device once; the lowest one can also sit on the collapsed bar. On a Mac, Apple and third-party Bluetooth mice and keyboards need no permission; for third-party headphones and the like, click "Read third-party Bluetooth devices" in the widget and allow Bluetooth access.
- **Arrange widgets on the island**: press the layout button in the header, then hold or just drag a widget and the others make room; drag one in from the dock to add it. Grid and free modes; free mode snaps to a dot grid, lines up with neighbours and pushes them aside. Widgets also move across pages: hold at an edge to flip, drop on a page thumbnail in the header, open All to see every page, park on the tray, or flip with the arrow keys. You can reset to the default layout at any time.
- **Widgets animate in**: when the panel opens, the widgets come in one after another, with eleven entrances shuffled by default. Pick one or turn it off under Settings → Behaviour → Opening, where the Fuyu tab can also show a jellyfish icon (new, off by default).

### The island

- **Caps Lock alert** (new, off by default): pressing Caps Lock flashes on the collapsed island, and while it is on a small badge stays that turns it off with a click. Turn it on under Settings → System alerts.
- **Six message page layouts**: one at a time by default, plus unified inbox, three columns, stacks, source board and timeline, merging every source by time, with verification codes enlarged and one click to copy. Switch under Settings → Messages and the island follows right away.
- **Island layout, rebuilt**: Settings → Island layout has Collapsed island, Expanded panel, and Display and notch tabs. The preview at the top mirrors the real island live in every form (notch, pill, taskbar); click an item to find it in the list. Collapsed-bar items are draggable chips in left, middle, right and +N lanes, can be dragged straight off the preview and removals can be undone. The expanded panel preview is drawn at real size with the island's columns and rows. The centre pattern is picked from picture cards, and each page can get its own tab icon.
- **Order the collapsed bar's text**: Island layout → Display and notch → Text order sets meeting, lyrics, agent title and to-dos, and can hide any of them; the old "lyrics first / agent first" choice is part of this list.
- **Overflow goes behind "+N"**: without a notch, collapsed-bar items that don't fit go behind "+N" instead of being squeezed or cut off; a newly installed plugin goes to the emptier side, and its install notice says where with a link to adjust. With no todos, the collapsed island shrinks to fit its icons and widgets.
- **Every page the same size by default**: the panel no longer changes size when you switch pages. Pages you resized on the island keep their size and can be reset one by one under Settings → Layout → Page sizes. The island and panel can grow as large as the screen allows instead of stopping at 800 × 640.
- **A new way to resize**: a grabber at the bottom of the panel, edges that arm after a short rest, corner knobs that switch whole presets (Compact / Default / Large), and "Resize…" in the right-click menu with arrow-key nudging and Esc to undo; drag the caps at either end of the collapsed island to change its width. Edges work on a Mac too.
- **New open and close motion**: the default is now Pop, with the width overshooting and settling back, plus a Bounce strength setting (Subtle / Regular / Bouncy). Lively, Snappy, Soft spring, Unfold and Grow are also available; a motion you picked before is kept. Settings → Behaviour also sets how the collapsed island reacts to the pointer (Bounce on touch by default, or off).
- **The jellyfish**: the app icon, the tray / menu bar icon, the island's status light and Settings → About now show the jellyfish.
- **Header**: page tabs get a sliding pill; the right-hand buttons moved next to the tabs, and Hide and Reset position are gone. `Ctrl+,` (`⌘,` on Mac) opens Settings while the island is open. A click on empty space in the open island closes it.
- **Corner radius 24 by default**, matching the Mac notch; the **side island** is as tall as the panel by default, with the lyric shown vertically and plugins' collapsed-bar items.
- (Windows) **Island stays on top**: it stays above other always-on-top windows, such as WeChat's pinned image viewer.

### The notch (Mac)

- (Mac) **Fuller notch wings**: each side shows at least two items, widening when needed and borrowing the other side's room before anything goes into "+N"; the world clock shows only the time there. Drag the collapsed island's ends to set the notch side width.
- (Mac) **Choose where text goes**: to-do, lyric, agent title and meeting text can go in the +N panel, stay in a row under the notch, show for 4 seconds when it changes, or stay hidden.
- (Mac) **Notch border and ring**: Appearance → Display → Notch can outline the island and panel in six styles (hairline, glow, orbit, converge, aurora, underglow; off by default) that light up for new messages and agent status, and ring the camera notch with a glow that turns green or orange while the camera or mic is in use. The open panel outlines the notch with a thin line by default, which can be turned off. Live preview and a Try button included.
- (Mac) **Uncrowded panel at the notch**: the tab bar no longer crowds, with the messages, translate and screenshot buttons moved right of the notch; dragging the island away restores the normal tab bar.

### Windows 11 taskbar

- (Windows) **Put the island in the taskbar**: on Windows 11, Settings → Appearance → Position → Dock to has a new Taskbar option. The collapsed island sits in the taskbar and the panel opens just above it. Press the line on the island's left to drag it along the taskbar. While collapsed it is see-through like a taskbar button by default, or it can keep the island theme. With no room, an auto-hidden taskbar or a fullscreen app, it falls back to the bottom edge of the screen and returns after full screen ends.

### Screenshots and recording

- **New annotation tools**: blur, line and spotlight, each with a single-key shortcut. Drawn marks can be selected, moved, restyled and deleted, and double-clicking text edits it again. Mosaic moved to `X`, so holding `M` measures as before.
- **Shortcut cheat sheet**: a draggable card in a corner lists the keys that work right now; `?` or `F1` folds it. Once a region is chosen, the toolbar also has Record and Shortcuts buttons.
- **QR codes and text search**: open or copy a QR code found in the selection, and search the screenshot history by the text in the pictures (read on your computer).
- **Better pins**: annotate, read the text in, rotate, collapse and restore a pin.
- **Send shots onwards**: put a screenshot into today's note or make a todo with it; shots sent to an agent carry your note and the window or web page they came from.
- (Mac) **Screen recording**: record an area with system sound and the microphone, as video or GIF, saved to Movies.
- (Mac) **Snap to controls**: with Accessibility permission, the selection snaps to buttons and fields too; Esc cancels right away without clicking the overlay first.
- (Windows) **Fullscreen games no longer capture as a black screen.**

### Todos and calendar

- **Holiday reminders and a countdown to the next break**: with China's holidays subscribed, the island reminds you once after 20:00 the day before a make-up workday or the first day off (on by default; turn it off under Settings → Calendar → "Remind the evening before make-up workdays and days off"; needs the Timer plugin). Today's line on the calendar page shows how many days until the next break. Holiday data now covers through the end of next year.
- **Yearly todos**: todos can repeat yearly or yearly by the lunar calendar, from the tag menu or by typing `@yearly` / `@农历每年` in the title. If you downgrade to an older version, these todos become one-off todos.
- **Holidays in the date picker**: days off get a small "休", make-up workdays a "班", and weekends are dimmed.
- **Month view without calendars**: the calendar page shows the month (lunar dates, solar terms, festivals) before you add a calendar; Mother's Day, Father's Day and seven Chinese memorial days are added.

### AI Agent

- **Install and repair hooks per agent**: under Settings → AI Agent → Hooks and agents, each agent's card shows its own hook state and can install, repair or remove hooks; turning an agent off can also remove its hooks. New auto install and auto repair (on by default) take care of newly found agents and outdated hooks, and the island tells you which.
- **Cursor asks in both places**: Cursor shows its own prompt right away, while the island card stays up with an Open Cursor button.
- **Steadier approvals**: Claude Code approvals on the island keep working when Fuyu changes its port; with no island running, agents show their own prompt instead of waiting; the approval card no longer repeats the status line and squeezes out the buttons.

### Settings

- **Sync setup guide**: before sync is set up you see three setup steps; afterwards you pick what to sync from checkbox tiles, with optional groups folded away.
- **Settings pages reorganised**: Calendar settings are split into Calendar and Reminders, with a preview of the collapsed countdown and the reminder banner; agent alerts show every event's island pop-up, sound and phone push in one table; tuck-to-edge has a live preview and thumbnails that play on hover; glass styles are picked from thumbnails with the two opacity sliders side by side; clipboard settings are grouped into pasting, terminals and privacy, with rare options under Advanced. Searching an old setting name still finds its page.
- **The clipboard window no longer has to be prepared**: Settings → Clipboard has a new "Prepare the clipboard window at startup". On, the first shortcut press opens it instantly but it keeps about 40 MB; off, the first open is a little slower and the window is freed after 10 minutes hidden. On by default on Windows, off on a Mac.

### Other

- **Apple Music lyrics**: Settings → Music → Lyrics adds "Apple Music lyrics": while Apple Music plays, Fuyu asks Apple for its own word-by-word lyrics and translations first (needs an Apple Music subscription and a token).
- **Markdown in message cards**: tables, bold text, links and code blocks from bots and agents keep their formatting.
- **Updates come from the official site first**, with GitHub as the fallback, faster and steadier in mainland China; when the site lags behind, the newest version still comes from GitHub.
- **Plugin market**: new Calculator (expressions, exchange rates, unit conversion, dates, income tax, age and more) and Image host (uploads screenshots to S3-compatible storage and copies the link); Track change notice 1.3.0 notifies even when the player is in front by default; System monitor 1.1.2 shows shared GPU memory on a Mac. Plugins update from the market on their own.
- **Tooltips after 0.4s everywhere**; community QR codes in Settings → About → Help show right away.
- (Mac) **Smoother and lighter**: on 120 Hz screens opening and closing run at the refresh rate, and reopening right after closing no longer stutters; the island no longer piles up app icons and system objects (which could add up to hundreds of MB) and uses about 45 MB less graphics memory while collapsed.
- (Mac) **The app name follows the language**: the Dock and menu bar name and menus follow Fuyu's language, and the settings window has its own Dock icon. Text fields no longer spell-check or auto-correct.
- (Windows) **Hidden windows use less**: translation, clipboard and similar windows stop refreshing in the background once hidden.

### Fixes

- **The island "vanishing"**: 0.3.11 set `Ctrl+Alt+B` (`⌃⌥B` on Mac) as the default shortcut to send the island behind windows, which clashes with VS Code, Cursor and JetBrains. The shortcut is now unset by default; the island says so before it goes back and pressing again cancels; the tray / menu bar card shows when the island is behind and brings it to the front with one click. If you chose this shortcut on purpose, set it again.
- Occasional stutters when the island opens or closes; the island shaking sideways as the panel opened or closed; the collapsed island jittering on hover; clicking while hovering skipping the open animation.
- (Mac) The island sometimes opened without its animation the first time after sitting idle.
- Resize handles that lit up but couldn't be dragged; the panel collapsing when a quick edge drag ended just outside; switching to a narrower page collapsing the panel when the cursor hadn't moved.
- With album cover colours on, the glow washed out the panel's top edge and outline; the Accent colour setting only changed the preview, not the dot on the island.
- (Windows) The device battery widget showed no Bluetooth headphones, mice or keyboards.
- (Windows) With the island docked in the taskbar, going full screen flashed it in the middle above the taskbar.
- (Windows) Downloading the plugin runtime failed with "access denied" unless Fuyu ran as administrator; a failed download now tells disk problems apart from network ones.
- (Windows) Apple Music showed the album after the artist, so lyrics didn't match.
- (Mac) The screenshot overlay opened misplaced, showing only the bottom strip of the frozen picture; pins and pin zoom are fixed too.
- (Mac) Picking a clipboard entry silently copied without pasting: without Accessibility permission the island now says "Copied, not pasted" with a button that opens Privacy & Security → Accessibility.
- Exporting settings or a style preset failed with "Not a valid backup file name".
- After upgrading from version 2 plugins, System monitor showed up as an unsupported third-party plugin.
- Todos made from a screenshot lost the picture; the messages page's source icons flashed when a track change notice closed on its own.
