这是 0.3.11 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **设置窗口重新分组**：设置的各个分类拆成更细的标签页，例如 通用 下分「启动与托盘」「数据与备份」「本机接口」；新增「计时与提醒」入口，放计时器、休息提醒和系统提示；AI Agent 分成「Agent」「外观」「提醒」「SSH 远程」四项。
- **更多功能改由内置插件提供**：中心图案、SSH 代理隧道、语音输入、主题市场、自动更新和岛上的计时器改成内置插件，可在 设置 → 插件 里单独开关，原来的开关、设置和计时器自动沿用。中心图案的设置移到 设置 → 外观，SSH 代理隧道的设置移到 设置 → SSH 远程。
- **插件页改版**：设置 → 插件 按用途分组，以双栏卡片显示，每个内置插件附一句说明，顶部显示插件的运行状态，点卡片看详情。
- **（Mac）点会话跳到对应的终端和窗口**：Ghostty、iTerm2、WezTerm 和 tmux 里的会话能切到对应的标签页或窗格；已授权辅助功能时，多窗口的编辑器会抬起该项目所在的窗口。只能定位到窗口、定位不到标签页时，会话行上会提示。
- **岛的轮廓连成一体**：贴边时岛两侧的反向圆弧和岛身画成一条连续轮廓，油膜边和液态玻璃描边沿圆弧一路连下来；经典外观半透明时不再透出一条线。
- **更省内存和电量**：截图、贴图等临时窗口关掉后直接释放（Windows）；截图和贴图不再越用越占内存；窗口隐藏时暂停后台定时刷新，岛隐藏或鼠标离得远时降低检测频率。
- **修复**：
  - 更新后邮箱页偶尔显示「邮件服务未就绪」、要重启才能用的问题。
  - 启动后马上改动的内置功能开关和 Agent 审批开关，重启后不再丢失。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.3/Fuyu_0.3.11-beta.3_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.3/Fuyu_0.3.11-beta.3_aarch64.dmg)

This is the third beta of 0.3.11. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Regrouped settings**: Settings categories are split into finer tabs, for example General now has Startup & tray, Data & backup and Local API. A new Timer & alerts entry holds the timer, break reminders and system alerts, and AI Agent is split into Agent, Appearance, Alerts and SSH remote.
- **More features are now built-in plugins**: The center pattern, SSH proxy tunnel, voice input, theme market, updater and island timers are built-in plugins you can switch on or off in Settings → Plugins. Your existing switches, settings and timers carry over. Center pattern settings moved to Settings → Appearance, and SSH proxy tunnel settings to Settings → SSH remote.
- **Redesigned Plugins page**: Settings → Plugins groups plugins by purpose in two-column cards, gives each built-in plugin a one-line summary, shows plugin status at the top, and opens details when you click a card.
- **(Mac) Jump to the right terminal and window**: Sessions in Ghostty, iTerm2, WezTerm and tmux switch to their own tab or pane. With Accessibility access granted, multi-window editors raise the window for that project. When only the window can be found, not the tab, the session row says so.
- **One continuous island outline**: When docked to an edge, the reverse curves on both sides and the island body are drawn as a single outline, so the oil-film rim and liquid glass border run through the curves. The classic look no longer shows a seam when translucent.
- **Less memory and power**: Screenshot, pin and other short-lived windows are freed when closed (Windows); screenshots and pins no longer pile up memory; background refreshes pause while windows are hidden, and checks slow down while the island is hidden or the pointer is far away.
- **Fixes**:
  - After an update, the mail page no longer sometimes says the mail service is not ready until a restart.
  - Built-in feature switches and the Agent approval switch changed right after startup are no longer lost on restart.
