这是 0.3.12 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

### 日历与待办

- **节假日提醒和放假倒计时**：订阅了中国节假日时，前一天 20:00 后岛上提醒一次「明天调休，要上班」或「明天起国庆节放假 · 共 7 天」（默认开启，在 设置 → 日历 → 「调休和放假前一晚提醒」里关闭，需要装计时插件）；日历页今天那行会显示「12 天后放国庆节 · 共 7 天」。节假日数据保留到明年底，往后翻月也能看到「休」「班」。
- **每年重复的待办**：待办的重复方式新增「每年重复」和「每年重复（农历）」，也可以在标题里直接写 `@每年` / `@农历每年`；农历生日、纪念日每年自动按农历日期提醒。降级回旧版本后，这些待办会变成不重复的单次待办。
- **待办日期选择器标出节假日**：选日期时，休息日角上标「休」、调休上班标「班」，周末数字变淡。
- **没加日历也能看月历**：日历页没有添加任何日历时也照常显示月视图（农历、节气、节日），添加日历的引导移到日程栏顶部；新增母亲节、父亲节和护士节、宪法日等纪念日。

### AI Agent

- **按 Agent 安装和修复钩子**：设置 → AI Agent →「钩子与代理」里每个 Agent 的卡片单独显示钩子状态，可以单独安装、修复或卸载；关掉开关时可以选择顺带移除钩子。新增自动安装和自动修复（默认开启）：已经用过钩子的电脑上，发现新装的 Agent 或钩子过时会自动处理，并在岛上告诉你。
- **Cursor 审批两边都弹**：Cursor 要运行命令时，编辑器里立刻弹出它自己的运行 / 跳过提示，岛上的卡片同时保留，点「去 Cursor」跳过去。
- **审批更稳**：Claude Code 的岛上审批不再因为浮屿换了端口就失效，回到终端提示；岛没开时 Agent 直接用自己的提示，不卡住。
- **审批卡片放得下按钮**：岛上的审批卡片不再重复显示状态、按钮被挤掉。

### 其他

- **社区群二维码直接显示**：设置 → 关于 → 帮助 里的社区群读到列表后直接显示二维码，不用再点一下。

### 修复

- **岛屿突然「消失」**：0.3.11 默认把 `Ctrl+Alt+B`（Mac 上 `⌃⌥B`）设为「岛屿置于窗口后面」的快捷键，和 VS Code、Cursor、JetBrains 的快捷键冲突，按了岛就藏到所有窗口后面。现在这个快捷键默认不设；岛要退到后面前会先在岛上说一声，再按一次可以取消；托盘 / 菜单栏卡片上能看到岛在后面，点一下就回到最前。之前特意设过这个快捷键的，需要重新设一次。
- （Windows）插件运行环境下载时反复报「拒绝访问」、只能用管理员身份运行才能过的问题；下载失败时会分清是磁盘（多半是杀毒软件）还是网络的问题。
- （Mac）截图时选区窗口错位，顶部只显示冻结画面底部一条（带程序坞）的问题；贴图和贴图缩放也一起修好。
- （Mac）在剪贴板里选了条目只复制、没粘贴而且没有任何提示的问题：没有辅助功能权限时，岛上会提示「已复制，未粘贴」，并带一个按钮直接打开「隐私与安全性 → 辅助功能」。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.12-beta.1/Fuyu_0.3.12-beta.1_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.12-beta.1/Fuyu_0.3.12-beta.1_aarch64.dmg)

This is the first beta of 0.3.12. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

### Calendar and todos

- **Holiday reminders and a countdown to the next break**: with China's holidays subscribed, the island reminds you once after 20:00 the day before a make-up workday or the first day off (on by default; turn it off under Settings → Calendar → "Remind the evening before make-up workdays and days off"; needs the Timer plugin). Today's line on the calendar page shows how many days until the next break. Holiday data now covers through the end of next year, so days off and make-up workdays show when you page ahead.
- **Yearly todos**: todos can repeat yearly or yearly by the lunar calendar, from the tag menu or by typing `@yearly` / `@农历每年` in the title — handy for lunar birthdays and anniversaries. If you downgrade to an older version, these todos become one-off todos.
- **Holidays in the todo date picker**: days off get a small "休" in the corner, make-up workdays a "班", and weekends are dimmed.
- **Month view without calendars**: the calendar page shows the month (lunar dates, solar terms, festivals) even before you add a calendar, with the add-a-calendar guide at the top of the agenda. Mother's Day, Father's Day and seven Chinese memorial days are added.

### AI Agent

- **Install and repair hooks per agent**: under Settings → AI Agent → Hooks and agents, each agent's card shows its own hook state and can install, repair or remove hooks on its own; turning an agent off can also remove its hooks. New auto install and auto repair (on by default): on a computer that already uses hooks, newly found agents and outdated hooks are taken care of, and the island tells you which.
- **Cursor asks in both places**: Cursor shows its own Run / Skip prompt right away, while the island card stays up with an Open Cursor button.
- **Steadier approvals**: Claude Code approvals on the island no longer stop working and fall back to the terminal when Fuyu changes its port; with no island running, agents show their own prompt instead of waiting.
- **Approval cards fit their buttons**: the island's approval card no longer repeats the status line and squeezes out the buttons.

### Other

- **Community QR codes show right away**: in Settings → About → Help, community groups show their QR code once the list loads, without an extra click.

### Fixes

- **The island "vanishing"**: 0.3.11 set `Ctrl+Alt+B` (`⌃⌥B` on Mac) as the default shortcut to send the island behind windows, which clashes with VS Code, Cursor and JetBrains, so pressing it there hid the island behind everything. The shortcut is now unset by default; the island says so before it goes back and pressing again cancels; the tray / menu bar card shows when the island is behind and brings it to the front with one click. If you chose this shortcut on purpose, set it again.
- (Windows) Downloading the plugin runtime no longer fails with "access denied" on every retry unless Fuyu runs as administrator, and a failed download now tells disk problems (usually antivirus) apart from network ones.
- (Mac) The screenshot overlay no longer opens misplaced, showing only the bottom strip of the frozen picture (with the Dock) at the top; pins and pin zoom are fixed too.
- (Mac) Picking a clipboard entry no longer just copies it silently without pasting: without Accessibility permission the island says "Copied, not pasted" with a button that opens Privacy & Security → Accessibility.
