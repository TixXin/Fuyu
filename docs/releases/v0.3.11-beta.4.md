这是 0.3.11 的第四个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

### 待办

- **子任务清单**：待办支持添加子步骤，以清单形式展示，逐项勾选；全部勾选后可自动完成主待办。
- **行内备注**：每条待办可以展开写备注，不用离开岛屿。
- **专注倒计时联动**：开始一条待办时自动拉起倒计时，到点后把时长累加到该待办的专注记录上。
- **准点提醒**：标题以时刻开头（如 `15:00 回电话`）的待办到点弹出岛屿提醒横幅，支持推迟。
- **更多排序和显示选项**：新增按优先级排序、已用专注时长显示、自定义跨天归档时间、行内 Markdown 语法。
- **节假日感知重复**：重复待办可以识别节假日，自动跳过或调整。
- **全局快捷键**：全局「快速添加待办」热键，随时呼出新建待办面板。

### 日历

- **会议横幅**：即将开始的会议在岛上显示横幅提醒，一键加入会议链接。
- **会议时自动暂停媒体**：进入会议时自动暂停正在播放的音乐，会议结束后恢复。
- **日程视图**：日历新增按日程列表浏览的视图。
- **自动识别会议链接**：从日历事件描述和地点中自动提取 Zoom、腾讯会议、飞书会议等链接。
- **显示谢绝和空闲状态**：已谢绝和标记为空闲的日历事件单独标注。
- **保留 CalDAV 子日历名**：同步 CalDAV 时保留各子日历的原始名称。
- **子日历可见性和颜色**：可以单独隐藏或更改每个子日历的显示颜色。
- **全局「一键加入会议」热键**：当前有正在进行的会议时，全局快捷键直接打开会议链接。

### 跨设备同步

- **WebDAV 同步**：新增 WebDAV 同步方式，支持坚果云、Nextcloud、群晖 NAS 等，密码存在系统钥匙串里；内置限速和设置向导。
- **剪贴板收藏同步**：收藏的剪贴板条目可跨设备同步（默认关闭），内容经哈希去重，敏感内容自动过滤不同步。
- **端到端加密**：同步数据支持可选的端到端加密（Argon2id + XChaCha20-Poly1305），密钥存在系统钥匙串里，服务端无法解密。

### 消息

- **更多 IM 消息上岛**：Telegram、Discord、WhatsApp、TIM、飞书、钉钉和企业微信的通知也能推送到岛上，带品牌图标，支持窗口闪烁合并去重、（Mac）Dock 角标和三级窗口激活；在 设置 → 消息 里按来源单独开关。
- **复制通知内容**：消息和邮件通知支持长按复制文本、链接，以及一键复制验证码。

### AI Agent

- **更多 Agent 岛上审批**：DeepSeek Harness、Factory Droid（PreToolUse）和 TRAE 的操作审批可以直接在岛上按按钮处理；等待审批的会话行亮起流光边框。
- **Agent 额度环扩展**：岛上的用量环新增 Antigravity、WorkBuddy 和 DeepSeek Harness 的剩余额度显示。
- **统一钩子卸载**：18 个 Agent 钩子支持一键卸载和远程清理，在 设置 → AI Agent → Agent 的状态卡片上操作；卸载时和重新安装后自动恢复，脚本缺失时静默退出不报错。

### 外观

- **岛屿透明度**：新增整体透明度滑块，让岛屿半透明悬浮在桌面上。
- **闲置自动变暗**：设定时间无操作后岛屿自动变暗，变暗后鼠标可穿透岛屿点击下方窗口。
- **贴边样式预设**：贴边自动隐藏支持「标准露边」「极简细线」「贴边隐身」三档露出样式。
- **主题配色平滑过渡**：切换主题或配色时，岛身、预览、设置窗口和弹出窗口的颜色平滑过渡。
- **主题市场深浅双配色**：市场上的主题可以同时提供深色和浅色两套配色，跟随系统或手动切换时自动切换。
- **（Mac）原生毛玻璃背景**：岛屿使用系统原生的毛玻璃效果，跟随展开/收起实时同步形状，macOS 26 上使用 NSGlassEffectView 胶囊风格。

### 插件

- **插件市场**：新增 v3 插件市场标签页，可以浏览、安装和卸载插件，安装前有确认对话框。
- **离线词典插件**：新增官方 @fuyu/ecdict 离线英汉词典引擎插件，零配置免密钥，在 设置 → 插件 安装即可用作翻译引擎。
- **倒计时、闹钟、世界时钟插件**：三个新的官方市场插件上架。
- **官方插件 v3 重写**：番茄钟、待办摘要、待办环、正在播放、天气、GitHub Issues 和系统监控全部改用 v3 插件架构重写。
- **v2 插件迁移引导**：首次升级到这一版时弹一次性通知，引导把旧的 v2 插件迁移到 v3。

### 其他

- **设置实时预览**：设置页顶部固定一个小岛预览，改外观和液态玻璃时立刻看到效果。
- **点击离开自动收起**：新增「点击岛外自动关闭展开面板」选项，点击打开岛的用户也能让面板在鼠标离开后自动收起。
- **录屏时显示浮屿窗口**：截图的「录屏」模式新增「录入浮屿窗口」开关，打开后录屏和 OBS、会议等第三方窗口捕获也能看到浮屿。
- **剪贴板预览备注**：预览面板显示条目的完整备注，宽布局下列表加宽。
- **翻译快捷键可清空**：翻译快捷键支持清空，自定义翻译端点不再强制填 API Key。
- **（Mac）cc-connect 本机运行**：在 Mac 上直接下载、托管运行 cc-connect 并完成飞书扫码设置。
- **（Windows）卸载清理**：卸载时清理系统凭据和 Home 目录。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.4/Fuyu_0.3.11-beta.4_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.11-beta.4/Fuyu_0.3.11-beta.4_aarch64.dmg)

This is the fourth beta of 0.3.11. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

### Todos

- **Subtask checklists**: todos now support sub-steps shown as a checklist you can tick off one by one; optionally auto-complete the parent when all sub-steps are done.
- **Inline notes**: expand any todo to write notes without leaving the island.
- **Focus timer binding**: starting a todo automatically launches a countdown timer and logs the focus time to that todo when it ends.
- **Timed reminders**: todos whose title starts with a time (e.g. `15:00 call back`) pop up an island reminder banner at the specified time, with snooze.
- **More sorting and display options**: sort by priority, show elapsed focus time, set a custom day-rollover hour, and use inline Markdown syntax in todo titles.
- **Holiday-aware recurrence**: recurring todos can skip or adjust around holidays.
- **Global quick-add shortcut**: a system-wide hotkey to instantly open a new-todo panel.

### Calendar

- **Meeting banners**: upcoming meetings show a banner on the island with a one-click join button.
- **Auto-pause media during meetings**: music pauses automatically when a meeting starts and resumes when it ends.
- **Agenda view**: a new list-based daily agenda view in the calendar.
- **Auto-detect meeting links**: Zoom, Tencent Meeting, Feishu and other meeting URLs are extracted from event descriptions and locations.
- **Declined and free status**: declined and free-flagged calendar events are visually marked.
- **Preserve CalDAV sub-calendar names**: CalDAV sync now keeps each sub-calendar's original name.
- **Sub-calendar visibility and colour**: each sub-calendar can be hidden or given its own display colour.
- **Global quick-join meeting shortcut**: a system-wide hotkey that opens the current meeting's link directly.

### Cross-device sync

- **WebDAV sync**: a new WebDAV transport for 坚果云, Nextcloud, Synology NAS and others, with secrets stored in the OS keychain, built-in rate limiting and a setup wizard.
- **Clipboard favorites sync**: starred clipboard items can sync across devices (off by default), with hash dedup and automatic filtering of sensitive content.
- **End-to-end encryption**: sync data can optionally be encrypted end-to-end (Argon2id + XChaCha20-Poly1305), with the key stored in the OS keychain so the server cannot decrypt it.

### Messages

- **More IM notifications on the island**: Telegram, Discord, WhatsApp, TIM, Feishu, DingTalk and WeCom notifications can now appear on the island with brand icons, flash-merge dedup, (Mac) Dock badge routing and three-level window activation; each source has its own toggle under Settings → Messages.
- **Copy notification content**: long-press a message or mail notification to copy its text or links, or tap to copy a verification code.

### AI Agent

- **More Agent approvals on the island**: DeepSeek Harness, Factory Droid (PreToolUse) and TRAE operation approvals can be handled directly on the island; sessions awaiting approval show a flowing orbit border.
- **Agent usage rings expanded**: the island usage rings now show remaining balances for Antigravity, WorkBuddy and DeepSeek Harness.
- **Unified hook uninstall**: all 18 agent hooks can be removed in one click with remote cleanup from the status card under Settings → AI Agent → Agent; hooks are automatically restored after reinstall, and missing scripts exit silently.

### Appearance

- **Island transparency**: a new opacity slider lets the island float semi-transparent on the desktop.
- **Idle dimming**: the island dims automatically after a configurable idle period; when dimmed, the pointer passes through it to the window below.
- **Docked style presets**: auto-hide when docked supports three reveal styles: Standard edge, Minimal thin line and Hidden tuck.
- **Smooth theme colour transitions**: switching themes or colour schemes transitions island, preview, settings and popup window colours smoothly.
- **Dual dark and light theme market variants**: market themes can ship both dark and light colour schemes, switching automatically with the system or manually.
- **(Mac) Native glass backdrop**: the island uses the system's native frosted-glass effect, syncing its shape in real time with expand/collapse; on macOS 26 it uses NSGlassEffectView for a capsule look.

### Plugins

- **Plugin market**: a new v3 market tab lets you browse, install and uninstall plugins, with an install confirmation dialog.
- **Offline dictionary plugin**: a new official @fuyu/ecdict offline English–Chinese dictionary engine plugin, zero-config and key-free; install it from Settings → Plugins to use as a translation engine.
- **Countdown, Alarm and World Clock plugins**: three new official market plugins.
- **Official plugins rewritten for v3**: Pomodoro, Todo Digest, Todo Ring, Now Playing, Weather, GitHub Issues and System Monitor are all rewritten on the v3 plugin architecture.
- **v2 plugin migration guide**: a one-time notice on first upgrade guides you to migrate old v2 plugins to v3.

### Other

- **Live island preview in settings**: a small island preview is pinned at the top of settings pages so appearance and liquid glass changes are visible instantly.
- **Click-away auto-collapse**: a new option closes the expanded panel when the pointer leaves, for users who open the island by clicking.
- **Show Fuyu windows in recordings**: a new "Include Fuyu windows" toggle in the screenshot recorder lets screen recordings and third-party window captures (OBS, meetings) see Fuyu windows.
- **Clipboard preview notes**: the preview pane shows full item notes, and the wide layout widens the list.
- **Clear translation shortcut**: translation shortcuts can now be cleared, and custom translation endpoints no longer require an API key.
- **(Mac) Run cc-connect locally**: download, supervise and set up Feishu scanning for cc-connect on Mac.
- **(Windows) Uninstall cleanup**: credentials and the Home directory are cleaned up on uninstall.
- **Crash recovery and logs**: (Windows) WebView2 GPU process crashes are automatically recovered with rate-limited reloads; native panics are logged to crash.log, viewable from Settings → General → Data.
- **Localised error messages**: errors from QQ notifications, WeChat reminders, sound packs, clipboard transfer, backups and SSH now follow the island's display language.

### Performance

- Collapsed island pages hibernate; clipboard panel uses virtualised scrolling.
- Locale dictionaries split by window and loaded on demand; pinyin and search index lazy-loaded.
- Audio peak state decoupled; pointer and scroll event handlers throttled.
- (Windows) Rust static caches bounded; file I/O moved to async threads; reachable drives cached.
- (Windows) WASAPI endpoints cached; GSMTC timeline throttled; fallback media scan short-circuited.
- Preview window and v2 plugin threads created lazily; clipboard thumbnails served directly.
- Highlight, tray switch knob and spotlight animations moved to transform to avoid reflow.
- Background watch threads merged; file shelf deferred.
- Tauri events deduplicated; high-rate UI events throttled.
- Clipboard copy and paste offloaded to a blocking thread pool; compact persistence debounced.
- Settings cross-window sync de-pinged and file writes debounced.

### Fixes

- (Mac) The island no longer sometimes fails to appear on startup until the tray icon is clicked.
- (Mac) Tray card teardown no longer crashes, and preview windows no longer re-swizzle.
- Expanding the island via keyboard shortcut no longer collapses it immediately when the pointer is outside.
- Fixed a startup crash that could occur with split i18n locale dictionaries.
- Plugin webviews no longer flash during panel expand; cold expand mount is deferred for smoother opening.
