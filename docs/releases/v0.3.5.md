## 关于这个版本

0.3.5 正式版，包含 v0.3.4 以来的全部改动（六个测试版的内容，以及之后的截图标注和快捷键设置）。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### 新名字：浮屿 / Fuyu

- 应用改名为 **浮屿**（英文 Fuyu），安装位置、程序名（`fuyu.exe`）和数据目录也换成了新名字。项目地址改为 [TixXin/fuyu](https://github.com/TixXin/fuyu)，插件市场改为 TixXin/fuyu-plugins，旧地址会自动跳转。官网：[fuyu.tix.xin](https://fuyu.tix.xin)。
- 更新后第一次启动会把旧版的数据搬过来：设置、待办、笔记、剪贴板历史、已装的插件、邮箱和翻译等保存的账号、开机自启都会保留，旧版的安装项会自动卸载，只留下一个「Fuyu」。AI 代理状态的 hook 会自动换成新版，`focusd://` 和新的 `fuyu://` 插件链接都能打开。旧的数据文件夹会留着，确认没问题后可以自己删除。
- 从 0.3.5 起应用采用 GPL-3.0-or-later 许可；插件 SDK、脚手架、PowerShell 模块和示例仍是 MIT。

### 截图（新，默认关闭）

- 在 设置 → 截图 里打开后，`Ctrl+Shift+1` 冻结所有屏幕框选区域，`Ctrl+Shift+7` 截取整个屏幕（数字行和小键盘都可以）。鼠标停在窗口或控件上会描出它的边框，点一下就选中，滚轮逐级扩大到外层窗口和整个屏幕；有跟随鼠标的十字参考线和放大镜（坐标、尺寸、颜色，按 C 复制颜色）。
- 选好区域后可以标注：矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克和序号，三种粗细、八种颜色，能撤销和重做。`Enter` 或双击复制到剪贴板，`Esc` 或右键退出。

### 外观与主题

- **浅色和深色**：设置 → 主题 可以选深色、浅色或跟随系统，两套颜色各自可调；浅色的岛可以在收起时保持深色，和屏幕顶部的黑边融在一起。
- **强调色**：默认、跟随 Windows 或自选一个颜色，岛上各个页面和剪贴板、翻译、设置窗口都用同一个强调色。
- **主题市场**：在「主题」旁预览、应用或保存别人分享的主题。应用或导入主题只改样式，不动你的面板尺寸和显示选项。
- **统一的页面**：待办、音乐、日历、剪贴板、Agent、文件中转、消息、翻译和插件页面用同一个面板尺寸（外观里可调 480–800 × 360–640），内容多时在内部滚动；待办、剪贴板、文件中转和 Agent 页一样直接放在岛上。
- **浅色岛屿的液态玻璃**效果单独调过，不再发灰。

### 剪贴板

- 剪贴板窗口重新设计：Tab 在全部、星标、图片、文件、片段和 #标签 之间切换，可选「宽版」布局在右边完整预览选中的条目。
- `Ctrl+K` 或右键打开操作面板；`Ctrl+T` 粘贴转换后的文本（一行命令、大小写、JSON、URL、去追踪参数、全半角、简繁等）；`Ctrl+E` 编辑后粘贴；空格预览；`Del` 删除可以撤销；可以暂停记录。
- **AI 改写**：`Ctrl+I` 用快捷翻译的服务和模型给条目做总结、润色、改语法或翻译，也可以加自己的提示词。
- **图片里的文字**：新复制的图片在本机用 Windows 自带的文字识别读出文字，可以搜索和复制。
- **导入导出**：历史（含图片）和片段存成一个 JSON 文件，导入时只添加还没有的。

### 消息

- **微信提醒能看到是谁、说了什么（默认关）**：设置 → 消息 → 微信提醒 里打开「显示联系人和消息摘要」，微信闪烁时按聊天弹出联系人和最后一条消息，点预览打开那个聊天。微信页列出本次运行的每条提醒；没有内容时说明原因。开了免打扰的群，只有微信标出「有人@我」时才提醒。
- 新消息提示选「横幅」时，微信也会弹卡片。

### AI 代理

- 一键安装 VS Code 扩展：设置 → AI 代理 → 连接 → 编辑器扩展。
- 点 SSH 电脑上的会话，能跳到连着它的 VS Code Remote-SSH 窗口。
- 会话设置拆成「岛上」和「会话列表」两页。

### 其他改进

- **Alt 拖动与缩放**：按住 Alt 拖动移动岛屿；展开时按住 Alt 拖边缘调宽高。
- **收起栏歌词逐字高亮**，颜色、亮度、发光和填充方式可调；修复网易云音乐等暂停后歌词跳回开头的问题。
- **更新**：可以选检查频率和提醒方式，可以在后台下载、空闲时安装；关于页有「诊断信息」，一键复制版本和更新状态。
- **设置**：新增「行为」「主题」页面；各功能的快捷键在它自己的设置页里录制，「快捷键」页变成总览，能查一个组合键被谁占用。窗口拉窄时侧栏收成一列图标。关于页的反馈与社区、版本历史打开官网的对应页面。
- **闲置自动收起**：有进行中的待办、有 AI 会话在等你、正在放音乐时可以不收起。
- **中间图案**在有未完成待办时显示在待办数前面。
- **翻译**有了自己的窗口，用快捷键或托盘的「快捷翻译」打开，`Esc` 关闭。
- 出错提示跟随界面语言；新安装用一套更顺手的默认设置。
- **插件**：插件和开发工具用上新名字，旧名字照常可用；收起条项目可以画竖着的小电池；新建插件自带教 AI 助手写浮屿插件的说明。待办进度环 1.1.0、系统监控 1.2.2。

### 修复

- 缩放不是 1 时贴顶圆角旁漏出的 1 像素缝。
- 剪贴板历史在文件被短暂占用时丢失写入；启动时第一次调整窗口大小失败。
- 鼠标划过页面图标时会打开路过的页面；收起条的音乐波形在没声音时也显示。
- 列表滚动后两行的条目变矮；链接预览会访问本机和局域网地址。

## About this release

The 0.3.5 release, with everything since v0.3.4 (six betas, plus screenshot annotations and the new shortcut settings). Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

### A new name: 浮屿 / Fuyu

- The app is now **Fuyu** (浮屿), and the install folder, the program (`fuyu.exe`) and the data folder carry the new name. The project lives at [TixXin/fuyu](https://github.com/TixXin/fuyu) and the plugin market at TixXin/fuyu-plugins; the old addresses redirect. Website: [fuyu.tix.xin](https://fuyu.tix.xin).
- The first start after updating brings your data across: settings, todos, notes, clipboard history, installed plugins, saved mail and translation accounts, and launch at startup are kept, and the old install is uninstalled so only one "Fuyu" remains. AI agent status hooks are replaced, and both `focusd://` and the new `fuyu://` plugin links open. The old data folders are left in place; delete them once everything looks right.
- From 0.3.5 the app is licensed GPL-3.0-or-later; the plugin SDK, scaffolder, PowerShell module and examples stay MIT.

### Screenshots (new, off by default)

- Turn them on under Settings → Screenshot. `Ctrl+Shift+1` freezes every monitor for a region selection and `Ctrl+Shift+7` takes the whole monitor (number row or numpad). Resting the pointer on a window or control outlines it and a click selects it; the wheel steps out to parent windows and the whole monitor. Guide lines and a magnifier (coordinates, size, colour; C copies the colour) help.
- Annotate the selection: rectangle, ellipse, arrow, pen, highlighter, text, mosaic and numbers, in three thicknesses and eight colours, with undo and redo. `Enter` or a double click copies to the clipboard; `Esc` or a right click leaves.

### Look and themes

- **Light and dark**: Settings → Theme picks dark, light or the system's, each with its own colours; a light island can stay dark while collapsed to blend with the top of the screen.
- **Accent colour**: default, the Windows accent or one of your own, shared by every island page and the clipboard, translation and settings windows.
- **Theme market**: preview, apply or save themes others share. Applying or importing a theme changes only the look, never your panel size or display options.
- **One panel for every page**: todos, music, calendar, clipboard, Agent, file shelf, messages, translation and plugin pages share one panel size (480–800 × 360–640 under Appearance) and scroll inside; todos, clipboard and file shelf sit straight on the island like the Agent page.
- **Liquid glass on a light island** is tuned on its own and no longer looks grey.

### Clipboard

- A redesigned clipboard window: Tab cycles through all, starred, images, files, snippets and #tags, and a Wide layout previews the picked entry in full on the right.
- `Ctrl+K` or a right click opens an actions panel; `Ctrl+T` pastes transformed text (one-line commands, case, JSON, URLs, tracking removed, full/half width, Simplified/Traditional Chinese and more); `Ctrl+E` edits before pasting; Space previews; `Del` deletes with undo; recording can pause.
- **AI rewrites**: `Ctrl+I` summarizes, polishes, fixes grammar or translates an entry with the quick translation's service and model, and you can add your own prompts.
- **Text in images**: newly copied images are read on this computer with Windows' own text recognition, so you can search and copy their text.
- **Import and export** the history (with images) and snippets as one JSON file; importing adds only what is missing.

### Messages

- **See who wrote and what in WeChat (off by default)**: turn on Show contact and message summary under Settings → Messages → WeChat reminders, and a flashing WeChat pops up each chat's contact and last message; click it to open the chat. The WeChat page lists each reminder of this run and says why when one has no content. A muted group reminds you only when WeChat marks it "someone @-mentioned me".
- With banner notices, WeChat gets a card too.

### AI agents

- Install the VS Code extension in one click: Settings → AI Agent → Connection → Editor extension.
- Clicking a session on an SSH computer brings up the VS Code Remote-SSH window connected to it.
- The session settings split into On the island and Session list.

### More improvements

- **Alt to drag and resize**: hold Alt to move the island; while expanded, Alt-drag its edges to resize it.
- **Word-by-word lyric highlighting** on the collapsed bar, with adjustable colour, brightness, glow and fill; lyrics no longer jump back to the start after pausing in players such as NetEase Cloud Music.
- **Updates**: choose how often to check and how to be told, download in the background and install when idle; About has Diagnostics that copies the version and update state.
- **Settings**: new Behavior and Theme pages; each feature records its shortcuts on its own page, and the Shortcuts page becomes an overview that tells you what uses a combination. A narrow window folds the sidebar into icons. About's Feedback and Version history open the website's pages.
- **Idle tucking** can wait while a todo is in progress, an AI session needs you, or music plays.
- **The centre pattern** stays in front of the pending todo count.
- **Translation** has its own window, opened with the shortcut or Quick Translate in the tray and closed with `Esc`.
- Errors follow the interface language; new installs start with more practical defaults.
- **Plugins**: plugins and their tools carry the new name and the old names still work; bar items can draw upright mini batteries; new plugins come with a guide that teaches AI assistants to write Fuyu plugins. Todo ring 1.1.0, system monitor 1.2.2.

### Fixes

- A 1px slit beside the top fillet at scales other than 1.
- Clipboard history writes lost while the file was briefly busy; the island's first resize failing at start.
- Passing over page icons opening the pages on the way; the music waveform showing without sound.
- Two-line rows shrinking after a list scrolled; link previews reaching this computer and the local network.
