## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_aarch64.dmg)

这是 0.3.10 的第二个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **语音输入**：按快捷键对着电脑说话，再按一下结束，识别出的文字可以存成待办、追加到今天的每日笔记，或者复制。识别在本机完成，不上传。识别组件和模型不随安装包，在 设置 → 语音输入 里点「下载」才下；开关和其他功能一样放在概览页。
- **待办的优先级和颜色**：待办可以设高、中、低优先级和颜色标签；设了时间的高优先级待办到点时岛上会提醒。
- **休息提醒**：设置 → 行为 →「休息提醒」里可以加久坐、护眼这类定时提醒，名字、图标和间隔都能改，默认关。锁屏或空闲时不计时，到点在岛上提醒，可以推迟 5 分钟或跳过；前台全屏时不打扰。
- **微信、QQ 消息看过就收走**：打开过微信或 QQ 之后，岛上已经看过的那些提醒会自动去掉，之后新来的留着。在消息设置里的「看过后从岛上去掉」可以关掉。
- **AI Agent**：
  - 新接入 GitHub Copilot CLI、Factory Droid、Grok CLI、Kimi Code、MiMo Code、ZCode、TRAE 和 TRAE CN、Qoder、CodeBuddy Code、Qwen Code，在 设置 → AI Agent 里「安装/修复」后就能在岛上看到会话。其中 Copilot CLI、ZCode、Qoder、CodeBuddy Code、Qwen Code、MiMo Code 能在岛上审批，TRAE 能审批命令。这几家大多还没在真机上测过，有问题欢迎反馈。
  - Agent 页：右键一行或点「⋯」可以跳到窗口、在文件夹中显示、复制路径、归档；能用方向键选行、回车跳转；鼠标停在一行上会显示完整标题和最近的提问。
  - Claude Code 会话下面会列出正在跑的子 Agent，点「n 个子 Agent」展开。
  - SSH 远程主机上的 opencode 会话也能列出来了。
  - 能读到 WorkBuddy AI（国际版）的会话和钩子。
  - 会话环插件的默认样式改成像素格；选过样式的不受影响。
- **插件**：安装包里带上了新版插件平台，现在还默认关着，不影响使用。插件设置页里的密钥只显示圆点，只能复制，复制的内容不进剪贴板历史。
- **修复**：
  - （Windows）启动时岛有时显示一下就消失、只能从托盘叫出来。
  - （Mac）替换或更新应用后没有重启时，保存邮箱密码等凭据会失败；现在会提示退出后重新打开，报错也不再写成 Windows 凭据管理器。
  - 更新下载或安装失败时，提示「更新安装失败」，不再说成检查失败。
  - 钉钉等拒绝按时间查询的 CalDAV 日历，现在改用另一种方式读出日程。
  - 日历订阅链接、代理地址里的账号密码不会再出现在错误信息里。
  - SSH 远程设置页的说明更新：远程的 Claude Code 和 Antigravity CLI 可以在岛上审批。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.10-beta.2/Fuyu_0.3.10-beta.2_aarch64.dmg)

This is the second beta of 0.3.10. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Voice input**: press a shortcut, speak, press it again, and save the recognised text as a todo, append it to today's daily note, or copy it. Recognition runs on your computer and nothing is uploaded. The recognition runtime and model are not in the installer; download them under Settings → Voice input. Its switch sits on the overview like the other features.
- **Todo priority and colors**: todos can have a high, medium or low priority and a color tag, and a scheduled high-priority todo is announced on the island when it's due.
- **Break reminders**: Settings → Behavior → Break reminders lets you add timed reminders such as sitting and eye breaks, with their own name, icon and interval (off by default). They don't count while the screen is locked or you're idle, show on the island when due, can be snoozed for 5 minutes or skipped, and stay quiet while a full-screen app is in front.
- **WeChat and QQ reminders clear once seen**: after you open WeChat or QQ, the reminders you've already seen leave the island; newer ones stay. Turn it off with "Remove once seen" in the message settings.
- **AI agents**:
  - New: GitHub Copilot CLI, Factory Droid, Grok CLI, Kimi Code, MiMo Code, ZCode, TRAE and TRAE CN, Qoder, CodeBuddy Code and Qwen Code. Use Install/repair under Settings → AI Agent and their sessions show on the island. Copilot CLI, ZCode, Qoder, CodeBuddy Code, Qwen Code and MiMo Code can be approved on the island, and TRAE's commands can too. Most of these haven't been tested on real installs yet, so feedback is welcome.
  - Agent page: right-click a row or click "⋯" to jump to its window, show it in the folder, copy the path or archive it; arrow keys pick a row and Enter jumps; hovering a row shows its full title and latest prompt.
  - Claude Code sessions list their running subagents; click "n subagents" to expand.
  - opencode sessions on SSH remote hosts are listed.
  - WorkBuddy AI (the international edition) sessions and hooks are read.
  - The session ring plugin now defaults to the pixel grid style; a style you picked is kept.
- **Plugins**: the installer now carries the new plugin platform, still off by default, so nothing changes yet. Secrets on the plugin settings page show as dots and can only be copied, and the copy stays out of clipboard history.
- **Fixes**:
  - (Windows) The island sometimes appeared at startup and then vanished until it was shown from the tray.
  - (Mac) Saving a credential such as a mail password failed when the app had been replaced or updated without a restart; it now asks you to quit and reopen, and no longer mentions the Windows Credential Manager.
  - A failed update download or install says "Update install failed" instead of calling it a failed check.
  - CalDAV calendars that refuse time-ranged queries, such as DingTalk, now have their events read another way.
  - Calendar subscription links and the user name and password in a proxy address no longer show up in error messages.
  - The SSH remote settings page now says remote Claude Code and Antigravity CLI can be approved on the island.
