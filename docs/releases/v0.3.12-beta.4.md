这是 0.3.12 的第四个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **岛屿布局改版**：设置 → 岛屿布局 顶部的预览改成真岛的实时镜像，岛上显示什么这里就是什么，刘海、胶囊、任务栏形态都跟着变，点一项能定位到下面的清单。收起条的项目改成可拖动的标签，分左、中、右和「+N」几格摆放，可以直接拖预览里的项目，拿下来能撤销；清单里此刻没内容的项目变淡并标「暂无内容」，刘海旁换了边的标「在左侧 / 在右侧」。中心图案改成看图挑选的卡片，展开页还能给每个页面换页头图标，Fuyu 页可选文字或水母。
- **外设电量**（新）：岛上新增「外设电量」组件，列出已连接的蓝牙耳机、鼠标、键盘、触控板的电量；也可以在收起条上显示电量最低的那个。
- **各页面默认一样大**：切换页面时面板不再忽大忽小；在岛上单独调过尺寸的页面照旧，设置 → 布局 →「各页面的尺寸」里能逐个恢复默认。Fuyu 页的宽度跟着面板宽度变，更宽时多显示几列。
- **（Mac）刘海两侧放得更满**：两侧各至少显示两项，一侧不够时靠刘海的项目换过来，放不下时这一侧自动变宽；放不下的项目先让后面更窄的上，再借另一边的空位，最后才收进「+N」；世界时钟在两翼只显示时间。
- **（Mac）刘海模式的展开面板**：标签栏不再挤在一起，提醒、翻译、截图按钮挪到刘海右边；把岛拖离刘海后，标签栏恢复成普通布局。
- **收起的小岛更紧凑**：没有待办时，小岛按上面的图标和小组件收窄，不再留一大段空白。
- **（Windows）岛保持在最上层**：岛开着置顶时，不会再被别的置顶窗口（比如点了图钉的微信图片查看器）盖住。
- **系统监控插件 1.1.2**：Mac 上 GPU 显示「共享 已用 / 总量」。
- **修复**：
  - 展开面板切到更窄的页面时，鼠标没动不会再被当成移出而收起面板。
  - 开着音乐「封面颜色」时，展开面板的顶边和边框不再被光晕冲淡。
  - 设置里的「亮点颜色」现在会改到岛上的小圆点，之前只改了预览。
  - 没有电池的台式机上，默认 Fuyu 页不再放「电池」组件；已放着的电池组件会提示长按可移除。
  - 官网的更新信息没跟上时，检查更新也能从 GitHub 拿到最新版本。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.12-beta.4/Fuyu_0.3.12-beta.4_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.12-beta.4/Fuyu_0.3.12-beta.4_aarch64.dmg)

This is the fourth beta of 0.3.12. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Island layout, rebuilt**: the preview at the top of Settings → Island layout now mirrors the real island live in every form (notch, pill, taskbar); click an item to find it in the list below. Collapsed-bar items are draggable chips in left, middle, right and +N lanes; you can drag items straight off the preview and undo removals. Items with nothing to show right now are dimmed and tagged "Empty now", and items moved across the notch say which side they are on. The center pattern is picked from picture cards, and each expanded page can get its own tab icon, including the word or jellyfish for the Fuyu page.
- **Device batteries** (new): a new widget lists the battery of connected Bluetooth headphones, mice, keyboards and trackpads; the lowest one can also sit on the collapsed bar.
- **Every page the same size by default**: the panel no longer changes size when you switch pages. Pages you resized on the island keep their size and can be reset one by one under Settings → Layout → Page sizes. The Fuyu page widens with the panel and shows more columns.
- **(Mac) Fuller notch wings**: each side of the notch shows at least two items, borrowing the ones next to the notch and widening when needed; items that do not fit let narrower ones through and borrow the other side's room before going into "+N"; the world clock shows only the time there.
- **(Mac) Expanded panel at the notch**: the tab bar no longer crowds, with the messages, translate and screenshot buttons moved right of the notch; dragging the island away from the notch restores the normal tab bar.
- **Tighter collapsed island**: with no todos, it shrinks to fit its icons and widgets instead of leaving a wide gap.
- **(Windows) Island stays on top**: it stays above other always-on-top windows, such as WeChat's pinned image viewer.
- **System monitor 1.1.2**: on a Mac the GPU shows shared memory used out of the total.
- **Fixes**:
  - Switching to a narrower page no longer collapses the panel when the cursor hasn't moved.
  - With album cover colours on, the music page glow no longer washes out the panel's top edge and outline.
  - The Accent colour setting now changes the dot on the island, not just the preview.
  - On desktop PCs without a battery, the default Fuyu page no longer includes the Battery widget, and an existing one suggests long-pressing to remove it.
  - Update checks now find the newest version on GitHub even when the official site has not caught up.
