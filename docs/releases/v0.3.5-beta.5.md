## 关于这个版本

这是 0.3.5 的第五个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **改名完成：浮屿 / Fuyu**：这一版连安装位置、程序名（`fuyu.exe`）和数据目录也换成了新名字，项目地址改为 [TixXin/fuyu](https://github.com/TixXin/fuyu)，插件市场改为 TixXin/fuyu-plugins（旧地址会自动跳转）。更新后第一次启动会把旧版的数据搬过来：设置、待办、笔记、剪贴板历史、已装的插件、邮箱和翻译等保存的账号、开机自启都会保留，旧版的安装项会自动卸载，只留下一个「Fuyu」。AI 代理状态的 hook 会自动换成新版，`focusd://` 和新的 `fuyu://` 插件链接都能打开。旧的数据文件夹会留着，确认没问题后可以自己删除。
- **剪贴板窗口重新设计**：和岛上的列表页一个样式，Tab 在全部、星标、图片、文件、片段和常用 #标签 之间切换，底部有快捷键提示，支持浅色主题。设置里新增「宽版」布局，右边完整显示选中的条目，图片直接预览。
- **一键安装 VS Code 扩展（新）**：设置 → AI 代理 → 连接 → 编辑器扩展 会列出找到的编辑器，没装的点「安装」即可。点会话跳到一个没装扩展的编辑器时，代理页会提示安装，也可以选「不再询问」。
- **新安装的默认设置**：第一次安装时用上一套更顺手的默认值（布局、行为、AI 代理提醒和声音、在岛上审批等）。已经用过的岛屿设置不变。
- **中间图案和待办数一起显示**：有未完成待办时，折叠态中间的图案显示在「还有 N 项待办」前面，不再被挡住。
- **窄的设置窗口**：窗口拉窄时，侧栏收成一列图标，鼠标移上去展开。
- **修复**：设置窗口的底色和「跟随系统」主题现在也跟着浅色、深色切换。

## About this release

This is the fifth beta of 0.3.5. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **The rename is complete: 浮屿 / Fuyu**: this version moves the install folder, the program (`fuyu.exe`) and the data folder to the new name too. The project now lives at [TixXin/fuyu](https://github.com/TixXin/fuyu) and the plugin market at TixXin/fuyu-plugins (the old addresses redirect). The first start after updating brings your data across: settings, todos, notes, clipboard history, installed plugins, saved mail and translation accounts, and launch at startup are all kept, and the old install is uninstalled on its own so only one "Fuyu" remains. AI agent status hooks are replaced with the new ones, and both `focusd://` and the new `fuyu://` plugin links open. The old data folders are left in place; delete them yourself once everything looks right.
- **A redesigned clipboard window**: it now looks like the island's list pages. Tab cycles through all, starred, images, files, snippets and your top #tags, a footer shows the keys, and there is a light theme. A new Wide layout in settings shows the picked entry in full on the right, with images previewed.
- **Install the VS Code extension in one click (new)**: Settings → AI Agent → Connection → Editor extension lists the editors found; press Install on any that lack it. When a click on a session lands in an editor without the extension, the Agent page offers to install it, or to stop asking.
- **New defaults for new installs**: a first install starts with a more practical set of defaults (layout, behavior, agent alerts and sounds, approving on the island and so on). An island you already use keeps its settings.
- **Centre pattern alongside the todo count**: with todos pending, the collapsed island shows its centre pattern in front of "N todos left" instead of hiding it.
- **A narrow settings window**: when the window is narrow, the sidebar folds into a column of icons that opens on hover.
- **Fixes**: the settings window's own background and the System theme now follow light and dark as well.
