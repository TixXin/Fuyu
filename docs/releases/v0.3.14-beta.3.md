## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_aarch64.dmg)

这是 0.3.14 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **悬停预览展开与页头滚轮切页**：在 设置 → 行为 → 展开与收起 新增「悬停预览」展开方式，鼠标悬停时先滑出一层轻量信息卡片（按优先级排序、紧急事项置顶、支持轮播与可选倒计时自动展开，点击直达对应页面，向下滚轮展开、向上收起）；并新增「页头滚轮切页」开关（默认关闭，防触控板惯性连跳）。
- **待办截止日、已顺延天数与截止日提醒**：待办旗子菜单新增「截止日…」月历选择器，行尾按临近程度显示淡色/橙色/红色截止徽标与「已顺延 N 天」（顺延超过 1 天显示，可在 设置 → 待办 → 任务 中开关），修正按创建时间排序对顺延待办的顺序，并在 设置 → 待办 → 提醒 新增「截止日提醒」（不提醒 / 当天 / 前一天，默认前一天）及 Markdown 导出 `(截止 MM-DD)`。（注意：旧版本读写待办数据时不会保留截止日与顺延起始日，开启跨设备同步的多台电脑请一起升级。）
- **延时截图与窗口透明阴影导出**：新增 3 / 5 / 10 秒延时截图（右键岛上截图按钮、托盘/菜单栏卡片右键或设置独立快捷键触发，岛上倒计时横幅可随时取消）；选中整个窗口截图时，工具栏可切换「透明背景与阴影」导出带圆角与柔和投影的 PNG，即使窗口被部分遮挡也能完整截取。
- **笔记本电池详情、24 小时电量曲线与收起条电量**：内置电池组件新增充放电剩余时间估算、电池容量健康度与循环次数、可交互 24 小时电量曲线，以及可选收起条电量芯片（百分比 / 剩余时间模式，在 设置 → 岛屿布局 中开启，台式机自动隐藏）。
- **计时器页四套可切换布局**：重新设计岛上计时器页，新增左右双栏（默认）、双模式大表盘、速启卡片网格与时间中枢四套布局，可在岛上或 设置 → 计时与提示 → 计时与休息 中随时切换。
- **大写锁定提示完善**：新增展开态大写锁定胶囊与输入框尾 `⇪` 指示、贴边隐藏时滑出提醒与露边变黄、刘海两翼角标不再被收进「+N」、开启开关时自动演示一次；（Windows）新增密码输入框持续提醒与可选 Num Lock 提示。
- **（Mac）全屏应用下的 AI Agent 系统通知**：全屏应用让岛贴边隐藏时，AI 代理等待确认或出错会发出 macOS 系统通知，点击通知直接打开岛的 Agent 页。
- **插件体验与安全加固**：恢复 `fuyu://` 插件市场一键安装链接（自动唤起浮屿并弹出带签名核验的安装确认）；被市场撤销停用的插件在作者发布安全修复版后可自动更新恢复（新增能力时提示确认）；插件新增 `ctx.locale` 接口实时跟随浮屿界面语言，插件命令行补回 `fuyu-plugin mcp` 服务，并进一步隔离插件窗口凭据与官方命名空间校验。
- **深度内存与资源优化**：移除 mimalloc 分配器并按需懒加载主岛 10 个内置展开页、收缩贴边与关闭超高面板后的舞台高度、缩短副窗口闲置释放时长并限制插件宿主默认堆上限；（Windows）隐藏的副窗口默认启用 WebView2 低内存模式、托盘隐藏主岛时同步挂起 WebView 可见态、将 WinRT OCR 移至短命子进程，主进程闲置私有内存显著下降。
- **修复**：
  - （Mac）关闭剪贴板预热或闲置释放后，按快捷键打开剪贴板会抢走焦点导致回车无法自动粘贴；自动粘贴成功后岛上现会显示「已粘贴」提示。
  - 修复 WorkBuddy 会话进程追踪、多窗口按目录匹配，以及（Windows）最小化或托盘隐藏窗口点击「跳到窗口」无法恢复的问题。
  - 修复设置窗口打开插件市场一键安装链接时未能立即读取最新插件列表的问题，以及（Windows）查询开机自启时子进程输出干扰。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.3/Fuyu_0.3.14-beta.3_aarch64.dmg)

This is the third beta of 0.3.14. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Hover preview expand mode and header wheel page switching**: choose the new "Hover preview" trigger under Settings → Behavior → Opening and closing to reveal a lightweight preview card before expanding (priority-ordered, urgent-pinned, rotating with optional countdown auto-expand, click to open the target page, scroll down to expand or up to close); plus an optional header mouse-wheel page switcher (off by default, with inertia protection).
- **Todo deadlines, carried-over days, and deadline reminders**: set, change, or clear a deadline from the task flag menu using the calendar picker; unfinished tasks show muted/orange/red deadline badges and "Carried Nd" (when carried over more than one day, toggleable under Settings → Tasks), created-time sorting now honors the original carry-over date, Markdown export appends `(截止 MM-DD)`, and Settings → Tasks → Reminders adds deadline reminders (Never / On the day / Day before, default Day before). (Note: older Fuyu versions drop deadline and carry-over fields when saving todos; upgrade synced devices together.)
- **Delayed screenshots and transparent shadowed window export**: capture after a 3 / 5 / 10 s countdown (right-click the island or tray/menu bar screenshot button or assign a shortcut, cancelable from the island countdown banner); when selecting a full window, toggle transparent background with rounded corners and soft drop shadow in the toolbar, capturing occluded windows cleanly.
- **Laptop battery details, 24-hour curve, and collapsed bar chip**: the built-in Battery widget adds remaining/charge-time estimates, battery health and cycle count, an interactive 24-hour charge curve, and an optional collapsed bar chip (percent or time mode under Settings → Island layout; hidden on desktops).
- **Four switchable timer layouts**: redesigned the island Timer page with Split studio (default), Dual dial, Preset grid, and Time hub layouts, switchable right on the island or under Settings → Timer & alerts.
- **Complete Caps Lock alerts**: adds an expanded panel capsule and input-tail `⇪` indicator, tucked slide-out with yellow lip highlight, notch +N exemption, and settings preview demo; (Windows) adds continuous password-field warnings and optional Num Lock alerts.
- **(Mac) System notifications for fullscreen AI agent alerts**: when a fullscreen app tucks the island away, macOS system notifications alert you if an AI agent needs approval or fails; click to jump straight to the Agent page.
- **Plugin platform improvements and hardening**: restores `fuyu://` market install deep links with signature-verified confirmation; revoked plugins now auto-update and re-enable when a safe fix ships (prompting if new capabilities are added); adds `ctx.locale` to follow Fuyu's UI language, restores `fuyu-plugin mcp`, and tightens per-plugin window token isolation and official scope validation.
- **Deep memory and resource optimizations**: removed mimalloc in favor of the OS allocator, lazy-loaded all 10 built-in island pages, shrunk stage height when tucked or after tall panels close, shortened auxiliary window idle timers, and capped plugin host V8 heap limits; (Windows) enabled WebView2 low-memory mode for hidden auxiliary windows, suspended tray-hidden WebView visibility, and isolated WinRT OCR into a short-lived worker subprocess.
- **Fixes**:
  - (Mac) Fixed cold-opening the clipboard popup (with prewarm off or after idle destroy) stealing focus so pressing Enter could not auto-paste; successful auto-paste now shows a "Pasted" card on the island.
  - Fixed WorkBuddy session process tracking, multi-window workspace matching, and (Windows) restoring minimized or tray-hidden windows when jumping to a session.
  - Fixed market deep-link installs missing the latest plugin snapshot in Settings, and (Windows) silenced `reg` subprocess stdio in the startup check.
