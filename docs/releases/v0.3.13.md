## 关于这个版本

**下载**：[Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_x64-setup.exe) · [Mac（Apple 芯片）](https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_aarch64.dmg)　国内镜像：[Windows](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_x64-setup.exe) · [Mac](https://ghfast.top/https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_aarch64.dmg)

0.3.13 正式版，包含 v0.3.12 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

### 浮屿水母

- **六种像素画风**：扁平、描边、单色、霓虹、大颗粒、精细，在 设置 → 岛屿布局 →「浮屿水母」的「水母画风」里换；鼠标停在画风卡片上能预览各个状态，霓虹在浅色岛上也看得清，岛拖到缩放不同的屏幕上马上重画。（Mac）菜单栏图标跟着变成像素水母，启动时就是像素的。
- **水母会互动了**：点一下面板里的水母它会有反应，空闲时眼睛跟着鼠标；新增「深夜打瞌睡」，打开后晚上 11 点到早上 6 点没有 Agent 在活动时，收起条上的水母会睡觉。
- **多了两个状态**：会话可能中断时变灰、冒出问号，压缩上下文时挤着眼一拉一压；收起条上不再把可能中断画成失败。
- **样式预设记住水母画风**：保存预设时带上当前画风，套用时一起换，导出的主题文件也带着，卡片上画出那种水母；之前存的预设不会改动你选的画风。

### AI Agent

- **通知和会话列表也用水母**：状态灯选水母时，Agent 通知、刘海旁的标题带、会话列表的每一行和卡片、紧凑视图都换成按状态动的小水母（通知带品牌小角标）；看不见的水母会停下，不白占 CPU。
- **刘海下的提醒更好找**：刘海模式下 Agent 标题和会议提醒默认在刘海下面滑出 4 秒，不再收进「+N」被挡住；同时来几条会排队一条条显示；Agent 等你确认时一直停着，处理完才收回。
- **（Windows）全屏时改发系统通知**：全屏应用把岛收起时，Agent 等你确认或出错会发一条系统通知，点了打开 Agent 页；开着勿扰时不发。
- **Claude Code 额度更准**：改读 Claude Code 每次回复交给状态栏的官方数字（原来的状态栏照常显示），已装过钩子的会自动补装；隔得久了自动向 Anthropic 补查一次（可在用量环设置里关掉）；过期的额度显示「已过期」和「修复」按钮，不再整行消失。
- **Agent 页的额度能挑能换**：跟着这台电脑上的 Agent 走（Antigravity、Cursor、GLM / Kimi 套餐都有一行，WorkBuddy 写积分、DeepSeek Harness 写余额）；有一行胶囊、小方块、最紧的领头、水位刻度、表格五种布局，岛上右键就能换；设置在「外观 → 用量与会话环」，在预览岛上点一下就能隐藏某家或某列。
- **没有会话时的 Agent 页**：换成打盹的水母，还有待命台、上一个会话、额度大圆环、今日潮汐和极简几种可选。

### 面板与翻页

- **翻页更顺手**：展开的面板两边有翻页箭头，← → 翻页、↑ 收起，岛有焦点时 ↓ 或回车展开（设置 → 页面切换里可以关）；触控板左右滑也能翻页。
- **换页动效**：面板和设置窗口换页时新页面按方向拉开，侧栏高亮和标签下划线伸缩着挪过去；在 设置 → 行为 → 展开与收起 →「切换动效」里能换成涟漪、光扫、像素溶解等。
- **Fuyu 面板按大小自动排版**：拖窄、拖高时组件重新排成合适的几列几行，组件少时排在顶部；自由布局跟着面板大小放大、能一直放到底部；拖组件时页头缩略图条提示「拖到页上换页」。
- **Fuyu 面板的组件都能用了**：倒数日、习惯、世界时钟、日出日落、喝水目标能直接改；番茄钟能设时长、走完在岛上提醒；计时器一键倒计时，待办能直接添加，月历能点日子看日程，下一个会议能直接加入；快捷启动能加自己的应用，亮度条能拖动调亮度；文件中转、剪贴板、截图、翻译组件都能直接操作。
- **页头图标自己定**：所有 lucide 图标（中英文搜索）、emoji、一两个字，或者拖进来、粘贴的图片和 SVG。
- **其他**：消息页默认三栏（来源、列表、详情），选过布局的不变；岛的右键菜单换成托盘卡片的样式；贴边隐藏露出的那一条可以调窄、调高低，鼠标停一小会儿岛才滑出；设置搜索能搜到岛屿布局里每个项目的样式设置；（Mac）设置窗口的侧栏改成悬浮的毛玻璃卡片。
- **（Windows）任务栏上的岛**：分体模式下任务栏上的条和弹出的面板都有液态玻璃的实时透出；收起时不再有阴影，透明样子下不显示玻璃底和流光边、和任务栏融为一体，并暂停采集省下 CPU 和显卡。

### 修复

- （Windows）系统「文本大小」调大后，岛屿、右键菜单、托盘卡片等窗口的内容被裁掉、新手引导点不了；浮屿的界面大小改用「岛屿大小」调。
- 从较宽的页面（比如 Fuyu 页）切到别的页面后，岛会左右抖一下。
- 刘海模式下 Agent 通知出现时，左边的水母被收进「+N」。
- （Mac）触控板只有第一次左右滑动能翻页；换到宽度不同的页面时幕布缺一块、闪一下。
- 悬停切换页面时在两页之间来回跳；点翻译原文框、卡片里的空处会收起岛。
- 菜单开着时按 Esc 连面板一起收起。
- 番茄钟先显示 25:01；关掉大写锁定的提示停太久像卡住（缩短到 0.9 秒）。
- 浅色岛上翻译页的占位文字太淡。
- 面板组件复制、打开成功后仍提示失败；日历一直停在之前点过的日子；年进度的剩余天数在夏令时地区多一天。
- 调过岛屿大小后，新消息面板被截掉一截、页签高亮错位，Agent 列表重排和通知滚动条拖动不跟手。
- 开着系统代理时，本机运行的翻译模型（如 Ollama）也走代理而连不上；现在直连，没启动时如实提示。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.13/Fuyu_0.3.13_aarch64.dmg)

The 0.3.13 release, with everything since v0.3.12. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

### The Fuyu jellyfish

- **Six pixel looks**: flat, outlined, one colour, neon, chunky and fine, under Settings → Island layout → Fuyu jellyfish → Jellyfish look. Rest the pointer on a look card to preview each state; neon reads well on the light island, and the jellyfish redraws at once on a display with a different scale. (Mac) The menu bar icon becomes a pixel jellyfish too, from the moment Fuyu starts.
- **It reacts now**: click the jellyfish in the panel and it responds, and while idle its eyes follow the pointer. A new "Doze at night" switch lets the bar jellyfish sleep from 11 pm to 6 am while no agent is active.
- **Two more states**: grey with a question mark when a session may have stopped, and squeezing while a session compacts its context; a possibly stopped session is no longer drawn as failed on the bar.
- **Style presets remember the look**: saving a preset stores the current jellyfish look, applying it switches the look too, exported theme files carry it, and the preset card draws that jellyfish. Presets saved earlier leave your choice alone.

### AI agents

- **Jellyfish in notices and the session list**: with the jellyfish status light, Agent notices, the band beside the notch, every row of the session list and the card and compact views show a small jellyfish that follows the state (notices add a brand badge). Jellyfish out of sight stop, so they use no CPU.
- **Notch alerts you can actually see**: in notch mode, Agent titles and meeting reminders now drop below the notch for four seconds by default instead of hiding in "+N". Alerts that arrive together queue up and show one after another, and an agent waiting for your approval stays until you answer.
- **(Windows) A system notification while full screen**: when a full-screen app has tucked the island away, an agent waiting for you or failing shows a system notification that opens the agents page. Do not disturb silences it.
- **More accurate Claude Code usage**: it now comes from the official numbers Claude Code hands its status line after every reply (your own status line keeps showing), installed automatically if you already had the hooks. After a long gap Fuyu checks once with Anthropic (you can turn this off in the usage ring settings). Usage past its reset shows "Expired" with a Fix button instead of vanishing.
- **Pick and arrange the usage on the agent page**: it follows the agents on this computer (Antigravity, Cursor and the GLM / Kimi plans get a row, WorkBuddy shows credits, DeepSeek Harness its balance). Choose chips, tiles, tightest first, a scale or a table, or right-click on the island to switch; settings live in Appearance → Usage & rings, where clicking the preview hides an agent or a column.
- **An empty agent page worth looking at**: a sleeping jellyfish, or standby, last session, big usage rings, today's tide and minimal looks.

### Panel and pages

- **Easier page turning**: the expanded panel has page arrows on both sides; ← → turn pages, ↑ closes it, and ↓ or Enter opens the focused island (switch off in Settings → Page switching). Swipe sideways on the touchpad to turn pages too.
- **Page transitions**: pages in the panel and the settings window open in the direction you move, and the sidebar highlight and tab underline stretch across. Pick ripple, sheen, pixel dissolve and more under Settings → Behaviour → Expand → Page transitions.
- **The Fuyu panel lays itself out**: resizing it rearranges widgets into columns and rows that fit, a few widgets sit together at the top, free layout scales with the panel and reaches the bottom, and the page strip says "Drop on a page" while you drag a widget.
- **Every Fuyu panel widget does something**: countdowns, habits, world clocks, sunrise and the water goal edit in place; the pomodoro length can be set and alerts on the island; the timer starts countdowns in one click, todos add inline, the month calendar shows a day's events, and the next meeting can be joined directly; quick launch holds your own apps, the brightness bar sets screen brightness, and the file shelf, clipboard, screenshot and translate widgets act directly.
- **Your own page header icons**: any lucide icon (search in Chinese or English), an emoji, a short word, or your own image or SVG.
- **Also**: the messages page opens in three panes by default (a layout you picked stays); the island's right-click menu matches the tray card; the strip a tucked island leaves can be narrower and shorter, and the island waits a moment before sliding out; settings search finds the style options of every collapsed-bar item; (Mac) the settings sidebar is a floating frosted-glass card.
- **(Windows) The island on the taskbar**: in split mode both the bar and its panel show the live liquid-glass backdrop; collapsed, it casts no shadow, and the see-through look drops the glass card and glowing rim to blend into the taskbar and pauses the capture to save CPU and GPU.

### Fixes

- (Windows) With the Windows text size above 100%, the island, menus, tray card and other windows were cut off and onboarding could not be clicked; Fuyu now ignores the system text size, use the island size setting instead.
- The island jumped sideways after switching from a wider page (such as the Fuyu page) to another page.
- In notch mode the jellyfish disappeared into "+N" while an Agent notice showed.
- (Mac) Trackpad swipes turned only the first page; switching to a page of a different width left a gap in the curtain.
- Hover page switching bounced between two pages; clicking the translation source box or empty space in a card collapsed the island.
- Esc with a menu open closed the panel too.
- The pomodoro showed 25:01 first; the Caps Lock off alert lingered (now 0.9 s).
- Placeholder text on the translation page was too faint on a light island.
- Panel widgets reported failure after a successful copy or open; the calendar reopened on a day clicked earlier; the year widget's days left was one too high in DST time zones.
- After changing the island size, the new-message panel was cut short, the tab highlight was misplaced, and the agent list reorder and notice scrollbar lagged the pointer.
- With a system proxy on, a translation model on this machine (such as Ollama) went through the proxy and failed; it is now reached directly, and a stopped one is reported as unreachable.
