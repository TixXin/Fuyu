## 关于这个版本

这是 0.3.5 的第四个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **新名字：浮屿 / Fuyu**：界面、窗口标题、托盘提示和说明文档都换成了新名字（英文名 Fuyu）。这一版只改显示的名字，安装位置、数据和设置都不变。
- **更新在后台下载（新）**：设置 → 关于 新增「自动更新」：只提醒、自动下载后手动安装（默认），或自动下载、空闲时安装。下载时会校验签名，按流量计费的网络不下载；下载好后点「立即安装」不用再等进度条。空闲时安装会等到锁屏或 10 分钟没有操作、岛屿没有展开、没有 AI 会话在运行或等你、前台没有全屏程序时才安装并重启岛屿。新安装默认每小时检查一次更新，已经选过频率的不变。
- **强调色（新）**：设置 → 主题 → 浅色和深色 新增「强调色」：默认、跟随 Windows（个性化 → 颜色 里的强调色），或自选一个颜色。
- **浅色岛屿的液态玻璃**：浅色的岛也有专门的液态玻璃效果，不再发灰发浑。
- **新的设置窗口**：去掉了 Windows 标题栏，侧栏变成一张卡片，右上角是 Windows 风格的最小化、最大化和关闭按钮，窗口顶部整条都能拖动；标题行固定在上面，不随页面滚动。岛是浅色时，设置窗口也是浅色。
- **插件开发**：插件和开发工具用上了新名字（`fuyu-plugin.json`、`acquireFuyuApi()`、`--fuyu-*` 主题变量等），旧名字照常可用，已装的插件不受影响。
- **修复**：
  - 鼠标划过岛上的页面图标时，只打开最后停住的那一个。
  - 系统监控插件更新到 1.2.1，打开页面时不再漏掉开头的读数。
  - 待办输入框里的日期按钮不再变形；浅色岛上列表里的强调色文字会加深，看得清。

## About this release

This is the fourth beta of 0.3.5. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **A new name: 浮屿 / Fuyu**: the interface, window titles, tray tooltip and docs carry the new name (Fuyu in English). This version changes only the name you see; the install folder, your data and settings stay as they are.
- **Updates download in the background (new)**: Settings → About gains Automatic updates: remind only, download and install by hand (the default), or download and install when idle. Downloads are checked against their signature and skipped on metered connections; once downloaded, Install now starts right away. Installing when idle waits for a locked screen or 10 minutes without input, the island closed, no AI session running or waiting on you, and no full-screen app in front, then installs and restarts the island. New installs check for updates every hour; a frequency you already chose stays.
- **Accent colour (new)**: Settings → Theme → Light and dark gains Accent: Default, Windows (the accent from Personalization → Colors), or a colour you pick.
- **Liquid glass for a light island**: a light island gets liquid glass of its own instead of turning grey and muddy.
- **A new settings window**: no Windows title bar; the sidebar is a card, Windows-style minimize, maximize and close buttons sit at the top right, and the whole top of the window drags it, with the title row staying put while the page scrolls. When the island is light, so is the settings window.
- **Plugin development**: plugins and the developer tools use the new name (`fuyu-plugin.json`, `acquireFuyuApi()`, `--fuyu-*` theme variables and so on); the old names still work, and installed plugins are unaffected.
- **Fixes**:
  - Moving the pointer across the island's page icons opens only the one it rests on.
  - The System Monitor plugin is updated to 1.2.1 and no longer misses its first readings when its page opens.
  - The date button keeps its shape in the todo field, and accent text in the lists darkens on a light island so it stays readable.
