## 关于这个版本

这是 0.3.7 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **所有数据放进一个文件夹**：待办、设置、剪贴板历史、插件、AI Agent 状态和每日待办 Markdown 现在都放在 `%USERPROFILE%\.fuyu` 里，找起来、备份和换电脑都方便。升级后第一次启动会把原来的数据复制过去，原文件夹保留不动；装过的 Claude Code / Codex 钩子会自动改到新位置；每日待办 Markdown 的默认保存位置换成 `.fuyu\todo`，原来 `文档\FocuSD` 里的文件会复制过去，自己选过的保存位置不变。
- **在设置里更换数据文件夹**：设置 → 通用 → 数据文件夹 可以换到别的文件夹（比如网盘里），空文件夹会复制现有数据过去，已有浮屿数据的文件夹直接使用，重启岛屿后生效。同一个文件夹正被另一台电脑上的浮屿使用时，岛会提示并不启动，避免两边互相覆盖。
- **设置另存一份文件**：设置会同时保存成数据文件夹里的 `settings.json`，格式和「导出设置」的文件一样，可以直接打开、备份；手动改了它，下次启动生效。
- **截图后识别文字和翻译**：`Ctrl+Shift+3` 识别选区里的文字并复制，`Ctrl+Shift+4` 识别后直接翻译；截图工具栏也多了「识别文字」。识别在本机进行，不联网。
- **截图后的小卡片**：复制或保存截图后，岛上会出现一张带缩略图的卡片，可以把图片直接拖到别处、「放进文件中转」，或「发给 Agent」：把图片贴进正在运行的 Claude Code / Codex 会话。
- **截图更快**：大屏幕上复制截图不再卡一下；钉在屏幕上的截图立刻出现，带一个柔和的阴影。
- **设置里的按钮会说明做了什么**：插件页的「立即检查」会显示正在检查和检查结果，重新加载、打开文件夹、清除数据等按钮点了以后也会提示几秒，不会再让人不确定有没有点上。
- **系统监控插件 1.3.0**：随面板大小自动排版，面板高了图表跟着变大、程序列表显示更多行；新设置「布局」可以选自动、两列或一列。由插件市场更新。
- **修复**：
  - 钉住截图时，屏幕不会再停在截图画面上取不消。
  - 钉住的截图整块都能拖动，不只是图片部分。

## About this release

This is the third beta of 0.3.7. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **All your data in one folder**: todos, settings, clipboard history, plugins, AI agent status and the daily todo Markdown now live in `%USERPROFILE%\.fuyu`, easy to find, back up and take to another computer. The first start after the update copies your existing data there and leaves the old folder untouched. Installed Claude Code / Codex hooks are pointed at the new place, and the daily todo Markdown now saves to `.fuyu\todo` by default, with your files from `Documents\FocuSD` copied over; a save folder you picked yourself stays as it is.
- **Choose the data folder in Settings**: Settings → General → Data folder moves it somewhere else, such as a cloud drive. An empty folder gets a copy of your data, a folder that already has Fuyu data is used as it is, and the change takes effect after a restart. If Fuyu on another computer is using the same folder, the island says so and does not start, so the two never overwrite each other.
- **Settings as a file**: your settings are also saved as `settings.json` in the data folder, in the same format as Export settings, so you can open or back it up directly. Edits to it take effect at the next start.
- **Read and translate text in a screenshot**: `Ctrl+Shift+3` reads the text in a region and copies it, and `Ctrl+Shift+4` reads and translates it. The screenshot toolbar has Read text too. Text is read on your computer, offline.
- **A card after each screenshot**: after you copy or save a screenshot, the island shows a card with a thumbnail. Drag the image out, Put on the file shelf, or Send to an agent to paste it into a running Claude Code or Codex session.
- **Faster screenshots**: copying a large screenshot no longer stalls, and a pinned screenshot appears at once with a soft shadow.
- **Settings buttons say what they did**: Check now on the Plugins page shows that it is checking and what it found, and buttons such as reload, open folder and clear data show a short note for a few seconds, so you know the click registered.
- **System monitor plugin 1.3.0**: lays itself out for the panel's size, so a taller panel gets bigger charts and more program rows. A new Layout setting picks automatic, two columns or one. Updates through the plugin market.
- **Fixes**:
  - Pinning a screenshot can no longer leave the screen stuck on the frozen capture.
  - A pinned screenshot drags from anywhere on it, not only the picture.
