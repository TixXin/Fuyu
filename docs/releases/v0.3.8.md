## 关于这个版本

0.3.8 正式版，包含 v0.3.7 以来的全部改动。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **Mac 版**（新）：浮屿第一次有正式的 Mac 版，支持 Apple 芯片、macOS 15 及以上。岛贴在刘海两边，消息和提醒显示在刘海旁；待办、剪贴板、截图和识字、翻译、媒体控制和歌词、Agent 状态和审批、插件都能用。QQ、微信只能读到程序坞上的未读数；录屏暂时只有 Windows 版。第一次打开要放行一次，步骤见上面的安装说明。
- **录屏**（Windows）：按 `Ctrl+Shift+6`（数字行和小键盘都行），框选区域、点一个窗口，或按 `F` 录整个屏幕，3 秒后开始录。岛上显示时长，可以暂停，再按一次快捷键停止。默认录成带系统声音的 MP4，选区域前按 `G` 改成 GIF。录好的文件在「视频」下的「浮屿录屏」文件夹，浮屿自己的窗口不会被录进去。设置 → 截图 → 录屏 里可以改默认格式、帧率、画质，以及录不录系统声音和麦克风。
- **长截图**：截图工具栏里新增长截图按钮（也可以按 `Ctrl+Shift+5`，Mac 上 `⌃⇧5`）。框选要滚动的区域，按空格或点 ▶ 往下滚，也可以自己在框里滚，照样拼进去；滚到底自动停下。`Enter` 完成并复制，`Ctrl+S` 保存，`Esc` 取消。顶部、底部固定的栏只保留一份。
- **截图的其他改进**：
  - 「自动打码」识别选区里的邮箱、手机号、IP 地址和各类密钥，盖上马赛克；点一处可以取消。
  - 截图界面按住 `M` 测量：显示指针所在色块的宽 × 高；按住 `M` 拖动是一把尺子。
  - 按下快捷键后截图界面马上出现，画面在后面截。
  - 截图历史按天分组，缩略图铺满格子；开着剪贴板时并进剪贴板页的「截图」筛选。
- **设置窗口改版**：打开先看到新的「概览」页，岛上轮流演示已开启的功能，下面是功能墙，每个功能一张带开关的卡片。关掉的功能不再出现在菜单里，「外观」和「AI 代理」各合成一项，菜单从 25 项减到 17 项。各页重新排版：功能页顶部是图标、说明和总开关，长页面拆成标签。「关于」页顶部是一片夜海，更新状态写在海上的岛上。
- **插件页改版**：已安装和市场都是整齐的两列卡片，最要紧的提醒显示成彩条；插件设置在对话框里打开；可以搜索，按「运行中」「有更新」「需要处理」筛选；市场有「最受欢迎」推荐。插件打开的列表页能用 `↑` `↓` `Enter` 操作。
- **内置插件：计时器**（新，默认关闭，在 设置 → 插件 里打开）：岛上的「计时器」页，输入 `10m`、`1h30m`、`1:30` 等开始倒计时，也可以开秒表；收起条上显示最快到点的那个，到点提醒，可以再延 5 分钟。新建计时器默认 `Ctrl+Alt+K`（Mac 上 `⌃⌥K`）。
- **插件市场：天气 1.0.0**：岛上的天气页显示当前天气、24 小时和 7 天预报，下雨前一小时提醒。填了城市才联网，不读取定位。
- **Agent 页多了三种会话**：WorkBuddy、Antigravity 和 DeepSeek Harness 的会话也会列出来；会话时间显示在归档按钮的位置，鼠标移上去才换成按钮。
- **剪贴板**：按住空格预览一条、松开就关；复制的图片文件显示缩略图，其他文件按类型显示图标；「链接」改叫「网址」、「片段」改叫「常用语」；开了「读取链接标题和图标」时网址显示网站图标；`Ctrl+1`–`9` 选中并预览那一行。
- **岛可以吸附到屏幕左右两边**（Windows）：把收起的岛拖到屏幕最左或最右边松手，收成一个小把手，仍显示 Agent 状态和未读。
- **邮箱一键全部已读**：消息 → 邮箱的工具栏多了一个按钮，把当前邮箱的未读全部标为已读；新消息面板里的「清除提醒」也会把列出的邮件标为已读。
- **更好上手**：鼠标停在岛上只有图标的按钮上会显示名字；第一次出现 Agent 会话、收到消息、贴边收起时，收起条上轻轻提示一句；新手引导更简短。
- **录快捷键时能录已在用的组合**：设置里录快捷键时，按浮屿自己已经注册的快捷键会被录进去，不再触发功能。
- **修复**：
  - 剪贴板窗口正好显示九行完整的条目，鼠标停在最后一行时列表不再自己往下滚。
  - `Ctrl+Tab`、`Alt+数字` 切换页面的顺序和顶栏图标一致。
  - 自动弹出的 Agent 提醒卡片和新消息面板，鼠标停在上面时最多保持 30 秒。
  - 启动失败的那一次不会再用旧的待办覆盖新的。
  - 插件配置文件损坏时，不再悄悄清空插件的开关和设置，原文件另存一份并在插件页说明。
  - 一个插件自动更新失败，不再挡住其他插件；本机没记下作者密钥的插件，不再被自动更新到第一个带签名的版本。
  - 不贴顶的岛上方两个角现在也是圆角；各个窗口打开更快。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.8/Fuyu_0.3.8_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.8/Fuyu_0.3.8_aarch64.dmg)

The 0.3.8 release, with everything since v0.3.7. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)). The Windows installers are not code-signed; if Windows SmartScreen says "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Fuyu for Mac** (new): the first final release for Mac, on Apple silicon with macOS 15 or later. The island sits beside the notch, with messages and alerts next to it; todos, clipboard, screenshots and text recognition, translation, media controls and lyrics, agent status and approvals, and plugins all work. QQ and WeChat show only the unread counts from the Dock, and screen recording is Windows only for now. The first launch has to be allowed once, as described above.
- **Screen recording** (Windows): press `Ctrl+Shift+6` (number row or numpad), drag an area, click a window or press `F` for the whole screen, and recording starts after 3 seconds. The island shows the time and can pause; press the shortcut again to stop. It records MP4 with system sound by default; press `G` before choosing the area for a GIF. Files go to the Fuyu Recordings folder under Videos, without Fuyu's own windows. Settings → Screenshots → Recording sets the format, frame rate, quality, system sound and microphone.
- **Long screenshots**: a new button on the screenshot toolbar (or `Ctrl+Shift+5`, `⌃⇧5` on a Mac). Pick the area that scrolls, press Space or ▶ to scroll down, or scroll inside the frame yourself; it stops at the end of the page. `Enter` copies, `Ctrl+S` saves, `Esc` cancels. Headers and footers that stay put are kept once.
- **More for screenshots**:
  - Auto-redact covers emails, phone numbers, IP addresses and keys in the selection with a mosaic; click one to remove it.
  - Hold `M` to measure the block under the pointer; drag while holding `M` for a ruler.
  - The screenshot view appears as soon as you press the shortcut.
  - Screenshot history is grouped by day with full thumbnails, and moves into the clipboard page's Screenshots filter when the clipboard is on.
- **A redesigned Settings window**: it opens on a new Overview page where an island plays each feature you have on, above a wall of feature cards with switches. Features that are off leave the menu, and Appearance and AI Agent are one item each, taking the menu from 25 items to 17. Pages are laid out again: each feature page opens with its icon, a short line and its main switch, and long pages are split into tabs. About opens on a night sea with the update status written on a floating island.
- **Redesigned plugin pages**: installed plugins and the market are tidy two-column cards with the most urgent notice as a strip; a plugin's settings open in a dialog; plugins can be searched and filtered by Running, Updates and Needs attention; the market has a Most liked spotlight. List pages opened by plugins work with `↑` `↓` `Enter`.
- **Built-in plugin: Timer** (new, off by default; turn it on in Settings → Plugins): a Timer page on the island. Type `10m`, `1h30m`, `1:30` and the like for a countdown, or start a stopwatch; the collapsed bar shows the one ending soonest, and it rings with five more minutes on offer. New timer: `Ctrl+Alt+K` (`⌃⌥K` on a Mac).
- **In the plugin market: Weather 1.0.0**: current weather, the next 24 hours and 7 days, and a heads-up an hour before rain. It goes online only after you type a city and never reads your location.
- **Three more kinds of sessions on the Agent page**: WorkBuddy, Antigravity and DeepSeek Harness. A session's time sits where the archive button is and turns into the button on hover.
- **Clipboard**: hold Space to peek at an entry and let go to close it; copied image files show a thumbnail and other files an icon for their kind; with "Read link titles and icons" on, links show the site's icon; `Ctrl+1`–`9` selects and previews that row.
- **Dock the island to the left or right edge** (Windows): drop the collapsed island at the far left or right and it folds into a small handle that still shows agent status and unread.
- **Mark a whole mailbox read**: a new button in Messages → Mail marks everything unread in the current mailbox as read; Clear in the new-messages popup also marks the mails it lists as read.
- **Easier to get started**: icon-only buttons on the island show their names on hover; the first agent session, message and tuck each bring a short hint on the collapsed bar; the first-run guide is shorter.
- **Record shortcuts Fuyu already uses**: while recording a shortcut in Settings, pressing one of Fuyu's own shortcuts records it instead of running it.
- **Fixes**:
  - The clipboard window shows exactly nine whole rows, and resting on the last one no longer scrolls the list.
  - `Ctrl+Tab` and `Alt+digit` go through pages in the order of the header icons.
  - Agent alert cards and the new-messages panel that open by themselves stay at most 30 seconds while hovered.
  - A start that fails no longer overwrites newer todos with older ones.
  - A damaged plugin settings file no longer silently wipes plugin switches and settings; the original is kept aside and the Plugins page says where.
  - One plugin's failed auto-update no longer stops the others, and a plugin whose author key this computer has not remembered is no longer auto-updated to its first signed version.
  - An island that is not attached to the top edge has rounded top corners too, and windows open faster.
