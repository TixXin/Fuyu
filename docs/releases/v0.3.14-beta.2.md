这是 0.3.14 的第二个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。已经装了浮屿的，在 设置 → 关于 里更新就行；手动安装时 Windows 直接覆盖安装，Mac 把新的 Fuyu 拖进「应用程序」替换旧的。待办、笔记、设置和已连接的邮箱都会保留。Mac 版第一次打开要在「系统设置 → 隐私与安全性」里点「仍要打开」，步骤见[在 Mac 上安装浮屿](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)。

## 更新内容

- **屏幕左右「侧边翼」独立入口（新，默认关闭）**：在 设置 → 侧边翼 中可视化拖拽，将待办、剪贴板、文件中转、日历等页面分流到屏幕左侧或右侧独立抽屉；支持上下拖动边缘把手调位、自动展开与贴边丝滑开合动效、液态玻璃与内置/插件页窄抽屉适配、多屏热插拔贴边，以及触控板滑动和滚轮切页防连跳。
- **自定义字体样式、全局字号与本地字体导入**：在 设置 → 主题 → 质感与形状 中可切换内置字体样式（默认、像素、圆润、衬线、等宽）、调节全局字体大小（85%–125%），或导入本地字体文件（`.ttf` / `.otf` / `.woff` / `.woff2`），跨主岛、侧边翼与设置窗口实时生效。
- **新版安装引导与版本更新引导**：主线收束为清爽的 5 步快速体验加进阶配置中心，支持真岛实时演示 7 种岛屿形态、侧边翼「一键分流」体验及全套 AI Agent 通知卡片；版本更新引导升级为带主题筛选与「真岛试看」的 Bento 展示页，左下角微信交流群二维码支持点击居中放大（自动避让 Mac 菜单栏与程序坞），并可在 设置 → 关于 → 帮助 中随时重看。
- **统一「网络代理」设置**：在 设置 → 通用 → 网络代理 中可选跟随系统、手动配置 HTTP/SOCKS5 代理（含认证与免代理列表）或直连，打通插件市场、日历、邮箱、应用更新、翻译与全部插件联网，改完立即生效并支持连通性测试。
- **日历国际节日与多国家/地区节假日订阅**：日历新增常见国际节日与世界纪念日标注（可在 设置 → 日历 中开关「显示国际节日」），并支持一键订阅 13 个国家/地区的官方节假日日历且多地区共存。
- **倒数日与纪念日支持农历**：倒数日卡片新增公历/农历切换与闰月支持，自动按农历跨年计算最近公历日期并同时显示公历与农历。
- **设置页「本版新增」提示与 `Esc` 快捷关闭**：版本更新后新增设置项会在设置行、侧栏、标签页与折叠块标注 NEW，支持一键筛选「本版新增」或全部标为已读；在设置窗口按 `Esc` 可直接关闭（有搜索词、弹窗、菜单或录快捷键时先退出当前操作）。
- **主岛不接收拖入时穿透外部拖拽**：关闭「文件中转」或关闭「拖入文件时自动展开」且未停留在文件中转页时，主岛同步禁用原生文件拖入并在外部拖拽经过时自动穿透，避免误放或挡住下层窗口。
- **面板与设置换页默认淡入**：面板换页与设置窗口换页默认改用淡入过渡。
- **修复**：
  - （Windows）WebView2 GPU 进程反复崩溃导致透明灵动岛不显示、打开设置约 3 秒黑屏且重装无法恢复：1 分钟内连崩 3 次会自动清理图形着色器缓存并切入兼容软渲染（WARP）重启，GPU 不稳定时托盘自动退回原生菜单（含「兼容渲染重启」），并在 设置 → 通用 → 数据 中提供兼容软渲染开关与清理图形缓存入口。
  - （Windows）开着浮屿关机或注销时弹出 `node.exe 0xc0000142` 错误。
  - （Windows）岛放在任务栏上时，悬停弹出的面板阴影会压暗下面的任务栏。

## About this release

**Download**: [Windows](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.2/Fuyu_0.3.14-beta.2_x64-setup.exe) · [Mac (Apple silicon)](https://github.com/TixXin/fuyu/releases/download/v0.3.14-beta.2/Fuyu_0.3.14-beta.2_aarch64.dmg)

This is the second beta of 0.3.14. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. If Fuyu is installed, update it from Settings → About. To install by hand, run the Windows installer over your current version, or drag the new Fuyu into Applications on a Mac to replace the old one. Todos, notes, settings and connected mailboxes are kept. The first time you open the Mac app, click "Open Anyway" in System Settings → Privacy & Security ([steps, in Chinese](https://github.com/TixXin/fuyu/blob/main/docs/features/macos-install.md)).

## What's New

- **Independent screen-edge Side Docks (new, off by default)**: drag pages such as Todos, Clipboard, File Shelf, and Calendar into left or right edge drawers under Settings → Side docks, with draggable edge handles, fluid edge unfolding, liquid glass and narrow-drawer layout support across built-in and plugin pages, display hotplug re-anchoring, and inertia-safe trackpad/wheel tab switching.
- **Custom font styles, global scaling, and local font import**: choose built-in font styles (System, Pixel, Rounded, Serif, Mono), scale global text size (85%–125%), or import local `.ttf` / `.otf` / `.woff` / `.woff2` fonts under Settings → Theme → Look and shape, applied live across every window.
- **Redesigned welcome and What's New guides**: streamlined 5-step first-run tour with an extensible setup hub, live island demos covering 7 island forms, one-click Side Dock split preview, and real AI Agent notice cards; upgraded What's New into a filterable Bento showcase with a zoomable WeChat community QR card (adapting to the macOS menu bar and Dock) and replay under Settings → About → Help.
- **Unified Network proxy settings**: choose Follow system, manual HTTP/SOCKS5 proxy (with optional auth and bypass rules), or Direct mode under Settings → General → Network proxy across the plugin market, calendar, mail, updates, translation, and all plugins with live reload and connection testing.
- **International festivals and multi-region holiday calendars**: show well-known international holidays and observances in Calendar (toggleable via Settings → Calendar → Show international festivals) and subscribe to official holiday calendars for 13 countries/regions side by side.
- **Lunar dates for Countdown & Anniversaries**: switch between solar and lunar dates (including leap months and yearly lunar repeat) with automatic next-solar-date preview.
- **What's new setting highlights and `Esc` to close Settings**: newly added settings are badged with NEW across rows, sidebar items, tabs, and collapsed drawers after updates with one-click What's new filtering; press `Esc` in Settings to close the window (dismissing active search, dialogs, menus, or shortcut capture first).
- **Pass through external drags when file drop is off**: when File Shelf is disabled or "Open when files are dragged in" is off outside the shelf page, the island disables native file drops and lets external drags pass straight through to underlying windows or the desktop.
- **Fade transitions by default**: panel and settings page transitions now default to fade.
- **Fixes**:
  - (Windows) Repeated WebView2 GPU process crashes leaving the island invisible and Settings black after ~3 seconds: 3 GPU crashes within a minute now automatically clear GPU shader caches and restart in WARP compatibility rendering, fall back to the native tray menu with "Restart (Compat Render)" when unstable, and expose manual WARP toggle and cache-clear controls under Settings → General → Data.
  - (Windows) Fixed a `node.exe 0xc0000142` error popping up when shutting down or signing out of Windows with Fuyu running.
  - (Windows) Panels opening above the taskbar-docked island no longer cast a shadow that darkens the taskbar below.
