## 关于这个版本

这是 0.3.7 的第一个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **新手引导（新）**：新装的岛屿第一次启动时，会在一张小桌面上分五幕带你上手：岛屿登场打招呼；主题、强调色和圆角直接画在岛上；回答一个问题（写代码 / 工作 / 学习 / 休闲）挑出模块，可以点或拖贴纸增减；三个小任务（打开岛屿、拖一个文件上去、按一下剪贴板快捷键）换星星；最后卡片缩成岛屿，飞到真正的岛上。用过的岛屿不会弹出。
- **待办按项目分组**：待办以「#项目名 」开头就归到那个项目（`#` 后面跟数字的不算）。有了项目后，今天的待办按项目分组、显示未完成数，没有项目的排在最后；顶部可以只看某一个项目，筛选时新加的待办也归进去。计划中的待办到期后保留项目，导出 Markdown 时写成 `- [ ] [项目名] 标题`。没用项目时页面和以前一样。
- **从日历加待办**：日历页的今天和以后的日子多了「添加待办」一行，今天的直接加进今天的列表，以后的日子会按计划在那天出现。计划中的待办也显示在当天的日程里，标题以时间开头的排在那个时间，月视图在这些日子上加一个点。只存在待办里，不写进日历。
- **开合动画**：岛屿展开时宽度带一点弹性，高度和圆角缓出。设置里新增「开合动画」，可选弹性（默认）、平滑、快速、Q 弹和关闭；收起比展开快，也不回弹。系统开了"减少动画"时不回弹。
- **按住 Alt 调整大小**：按住 Alt 时，岛屿上能拖的边会显示主题色的细线，鼠标下面那条会亮起来；拖动时边缘紧跟鼠标，并显示当前尺寸。整个底部圆角都能同时调宽和高。收起的岛屿两侧也能拖，调整收起时的宽度。悬停展开时，按着 Alt 不会打开面板。新消息、Agent 提醒这类弹出卡片只能移动，不能调整大小。
- **一键清除提醒**：新消息弹窗的「全部消息」旁多了一个按钮，一次清掉岛上的所有提醒（弹窗、收起条预览、横幅、QQ 和微信的提醒列表、插件消息）。不会打开任何应用，也不会把微信、QQ 或邮件标为已读。
- **手机推送按电脑设置**：本机和每台 SSH 电脑各有开关，用 cc-connect 时可以选每台电脑上的项目和它的机器人，远程电脑的会话通过它自己的 cc-connect 机器人推送并可以接管；没装 cc-connect 的电脑可以借用本机的机器人（不能接管）。新建机器人的向导可以建 Codex 项目，默认工作文件夹是岛屿自己的一个空文件夹，不再是你的用户目录。
- **安装包**：桌面和开始菜单的快捷方式改名为「浮屿」，更新时会把旧的 Fuyu 快捷方式改名。
- **插件**：系统监控 1.2.3 在岛屿变窄（展开放大调大）时不再藏起曲线和内存百分比，CPU、GPU 栏太窄时曲线挪到数字下面。
- **修复**：
  - 微信里自己发的消息（包括在手机上发、同步到电脑的）不再被当成新消息提醒。
  - 浅色岛屿上，翻译页、插件页、下拉菜单和翻译窗口不再是深色底配深色字。
  - 用量圆环在深色和浅色岛屿上都更清楚，70% 的黄色和 Claude 的橙色能分开。
  - 待办行高按标题实际换行的行数计算，一行的标题不再显得过高。
  - 贴顶收起的岛屿被拖动时，从顶边在鼠标下方滑出，不再反复弹进弹出；托盘的「显示」能把收起的岛屿拉出来。
  - 没单独设置推送的 SSH 电脑照旧通过本机推送；读取远程电脑的 cc-connect 配置时只取名称和类型，机器人令牌不离开那台电脑。
  - 原生错误提示改为中英文，以及多处并发、写文件和性能问题。

## About this release

This is the first beta of 0.3.7. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **First-run guide (new)**: a new install greets you on a small desktop in five acts: the island drops in and says hello; theme, accent and corners show on it at once; one question (code / work / study / leisure) picks the modules, and stickers add or remove them by click or drag; three small tasks (open the island, drop a file on it, press the clipboard shortcut) earn stars; and the card shrinks into an island and flies onto the real one. Islands that ran before do not see it.
- **Todos grouped by project**: start a todo with "#name " to put it in that project (a number after `#` is not one). Once a todo has a project, today's todos group under their projects with the count of open ones, those without one last; a filter row shows one project, and todos added while filtered join it. Planned todos keep their project, and the Markdown export writes `- [ ] [name] title`. Without projects the page is as before.
- **Todos from the calendar**: today and later days on the calendar page get an "Add a todo" row; today's go straight into today's list, later ones are planned for that day. Planned todos also show among that day's events, a title starting with a time at that time, and the month marks those days with a dot. They stay in your todos; nothing is written to a calendar.
- **Open and close animation**: the island's width opens with a little spring, its height and corners ease out. A new "Open and close" setting picks Spring (default), Smooth, Fast, Bouncy or none; closing is quicker and never bounces, and with the system's reduce motion nothing bounces.
- **Resizing with Alt**: holding Alt shows faint accent lines on the edges you can drag, the one under the pointer lit; while dragging, the edge stays under the pointer and the size shows. The whole bottom corner resizes both ways, and the collapsed island's sides set its collapsed width. With hover expand, holding Alt does not open the panel. Popup cards (new messages, Agent alerts) only move, they do not resize.
- **Clear every reminder**: the new-messages popup has a button beside "All messages" that clears every reminder on the island at once (popup, collapsed preview, banner, the QQ and WeChat lists and a plugin's message). It opens no app and marks nothing read in WeChat, QQ or mail.
- **Phone push per computer**: this computer and each SSH computer get their own switch; with cc-connect you pick each computer's projects and their bots, and a remote computer's sessions go through its own cc-connect bots, which can take them over. A computer without cc-connect can borrow this one's bots (no takeover). The new-bot wizard can set up a Codex project, and a new bot's work folder is an empty folder of the island's, not your home folder.
- **Installer**: desktop and Start menu shortcuts are named 浮屿; an update renames an old Fuyu shortcut.
- **Plugins**: the system monitor 1.2.3 keeps its charts and the memory percent on a narrow island (a large expanded scale); a narrow CPU or GPU column puts its chart under the figures.
- **Fixes**:
  - A WeChat message you sent yourself (also from your phone, synced to the PC) is no longer a new-message reminder.
  - On a light island, the translation page, plugin pages, select menus and the translation window no longer show dark text on a dark fill.
  - The usage rings are easier to read on dark and light islands, and the 70% yellow stands apart from Claude's orange.
  - Todo rows take their height from the lines their titles actually wrap to; one-line titles no longer look too tall.
  - A tucked island dragged at the top edge slides out under the pointer instead of bouncing in and out; the tray's Show brings a tucked island out.
  - An SSH computer without its own push setting pushes through this computer as before; reading a remote cc-connect config brings back only names and types, so bot tokens stay on that computer.
  - Native error messages are worded in your language, plus fixes for concurrency, file writes and performance.
