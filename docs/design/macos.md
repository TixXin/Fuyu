# macOS 上的岛

计划和全部决定见 [macos-port-plan.md](../architecture/macos-port-plan.md)「决定」，任务 G1.3、G1.11。调研见 [macos-notch-apps.md](../research/macos-notch-apps.md)、[macos-tauri-window.md](../research/macos-tauri-window.md)。

## 位置（2026-11-13）

- 岛先做**顶部正中**形态，所有屏幕（有刘海、无刘海、外接屏）都一样；和刘海融为一体的形态放到第 2 步（G1.11），作为可选项。（用户确认，M4）
- 顶部正中时**默认压在菜单栏上**；设置里可以改成**贴在菜单栏下面**，不挡应用菜单和状态栏图标。（用户确认，M5）

## 全屏应用（2026-11-13）

- 前台是全屏应用时，岛怎么显示做成设置，两种都能选：**隐藏，有提醒时短暂出现**（默认），或**照常显示**。（用户确认两种都做，M6；默认值按 Agent 推荐）
- 做法：沿用设置 → 行为里的「游戏模式」两个开关，不另加设置。Mac 上默认「游戏时贴边隐藏」开、「游戏勿扰」关：全屏应用占住岛所在的屏幕时岛贴到顶部，来消息时按「有消息时露出」短暂出来再收回；关掉贴边就是照常显示。Windows 上的默认值不变（贴边关、勿扰开）。（Agent 推断，2026-11-13）
- 判断全屏：最前面的普通窗口（不算岛自己）正好盖住整块显示器（连菜单栏一起），就算全屏；最大化的窗口让出菜单栏，不算。

## 设置窗口（2026-11-13）

- 右上角不画 Windows 的最小化、最大化、关闭按钮，用系统自带的红绿灯：标题栏是 Overlay、隐藏标题，红绿灯在侧栏左上角（离左边 18、离上边 22），失焦变灰、绿灯全屏和分屏都是系统行为。（用户确认 1–3 一起做）
- 侧栏贴满窗口左边，不再是浮着的圆角卡片；背景是系统的 Sidebar 半透明材质，跟着窗口深浅色和是否在前台变；右边一条细线和内容区分开。内容区仍是原来的深色 / 浅色底。选中的一行用强调色铺满、白字，不画左边的竖条。窄窗口（< 760px）时侧栏收成图标，标题往右让开红绿灯，悬停展开的侧栏是实底。（Agent 推断，参考「系统设置」）
- 键盘：⌘W 关闭、⌘M 最小化、⌘F 跳到搜索框。
- 用词：开机自启动 → 登录时打开；最小化到「托盘」→「菜单栏」；打开文件夹 / 在文件夹中显示 → 在访达中打开 / 在访达中显示；退出说明里的开始菜单换成「应用程序」文件夹或启动台；Alt 拖动写成 Option。所有快捷键显示成 ⌃⌥⇧⌘ 符号（存的格式不变，`Ctrl` 是 ⌃、`Win` 是 ⌘）。
- 还没改：剪贴板和截图页说明里的 Ctrl+V、资源管理器、PrintScreen、D:\ 路径；数据文件夹的路径仍显示完整路径，不缩成 `~`（那是可以编辑的输入框）。
