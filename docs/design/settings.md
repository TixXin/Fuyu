## 设置窗口

- 设置窗口分左右两栏：左侧分类菜单，右侧只显示当前分类的内容，独立滚动。（用户确认）
- 设置窗口打开时宽 1080、高 860（逻辑像素），正好让右侧内容到达最宽的 860px（侧栏 172 + 内容 860 + 两侧边距 48）；屏幕放不下时按屏幕缩小，不小于 580 × 420。（用户要求 2026-11-07，原为 820 宽）
- 切换分类时，新页面的标题和各张卡片依次上移 6px 淡入（220ms，每张错开 30ms，第四张起不再错开），侧栏选中项左边的高亮条从中间长出来（180ms）；没有退场动画，旧页面直接换掉。系统要求减少动画时直接切换。（用户反馈切换没有过渡；时长与做法为 Agent 推断）
- 侧栏分组：「基础」通用、行为、外观、主题、主题市场、快捷键；「功能」待办、日历、音乐、翻译、剪贴板、文件中转、消息；「AI Agent」会话、提醒、声音、审批、连接、SSH 远程；「扩展」插件、插件市场；分隔线下是关于。（用户确认 2026-11-06，D8；AI Agent 单独一组 2026-11-07，B16：Agent 的设置项越来越多，以后移植 Vibe Island 的功能也放这一组。分类名 `agents`（会话）、`sounds` 不变，岛上和旧链接照样能打开；SSH 读取的远程电脑单独一页 `agentRemote`，侧栏名「SSH 远程」，放在这一组最后，2026-11-07 用户要求）

## 插件市场

- 插件页和市场页的插件都是卡片，放得下时一行两张（每张至少 220px），窗口窄时一行一张（用户确认 2026-11-07，D10）。
- 插件页：最上面一张卡片是「允许运行第三方插件」开关和插件目录（打开、重新加载两个图标按钮），风险说明是卡片下的脚注；下面按「第三方」「内置」分组。点卡片空白处打开插件自己的设置页，开关、按钮、权限展开不触发；主页和卸载是图标按钮，卸载点一下后变成「确认卸载」。

- 页面标题已经是「插件市场」，列表上方不再重复标题，改为一行状态「共 N 个插件 · 索引更新于 HH:MM」，右侧是「刷新」。只显示岛屿缓存的列表时不写时间。（用户确认）

## 不用系统标题栏（C36，2026-11-10）

- 设置窗口去掉 Windows 自带的标题栏（`decorations: false`，保留系统阴影和圆角）。窗口是一整块底板，左侧菜单是浮在上面的独立卡片（宽 212，离窗口边 8px，圆角 12）。（用户确认预览）
- 窗口按钮是 Windows 式的最小化、最大化 / 还原、关闭，在窗口右上角（每个 46 × 32），关闭悬停变红 `#e81123`。mac 式的三个圆点（放在卡片顶部、悬停显色）代码保留在 `WindowControls.tsx`，以后适配 macOS 再用。（用户要求 2026-11-10）
- 卡片里的菜单保持原样：搜索框、可折叠的组（图标加箭头）、组里的页面缩进挂在下面并带引导线、「关于」固定在底部。（用户要求：保留原来的分组和二级缩进）
- 拖动窗口：窗口顶部的边、卡片顶部的空白、右侧整行标题（标题固定在滚动的页面上方，滚动后照样能拖）；左侧菜单滚动时不显示滚动条；双击这些地方最大化或还原。窗口四边照常可以拖动改大小，拖到屏幕边缘贴靠、Win+方向键、Alt+Space 和 Alt+F4 都照旧；没有了系统标题栏，悬停最大化按钮时 Windows 11 的贴靠布局菜单用 Win+Z 打开。
- 设置窗口跟着岛屿的深浅色（C33.6）：配色是浅色，或跟随系统而 Windows 是浅色时，设置窗口也是浅色。底板 `#eceef2`，侧栏卡片和各组卡片、插件卡片白色，文字、细线、开关和按钮用岛屿浅色主题的同一套变量（`.island-light`，半透明白写成 `rgba(var(--overlay-rgb, 255, 255, 255), a)`），提示用的浅绿、浅红、浅黄换成浅色主题的深一档。窗口刚打开的一瞬间仍是深色底（`tauri.conf.json` 的 `backgroundColor`），页面画出来后切到浅色。（用户确认预览）
- 窄窗口（宽度小于 760）：菜单卡片收成 52px 的图标列，搜索框只剩图标，打开的组不占一行，组和组之间一条短线；折叠的组只剩组图标，点它展开。鼠标停在这一列上（约 0.12 秒）或用键盘把焦点移进去时，卡片展开成完整菜单盖在页面上，名字、搜索、折叠都能用；移开就收回，鼠标点完一页也会收回。这样不需要悬停提示。（预览确认；交互为 Agent 推断）
