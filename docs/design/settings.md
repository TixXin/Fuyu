## 设置窗口

- 设置窗口分左右两栏：左侧分类菜单，右侧只显示当前分类的内容，独立滚动。（用户确认）
- 设置窗口打开时宽 1080、高 860（逻辑像素），正好让右侧内容到达最宽的 860px（侧栏 172 + 内容 860 + 两侧边距 48）；屏幕放不下时按屏幕缩小，不小于 580 × 420。（用户要求 2026-11-07，原为 820 宽）
- 切换分类时，新页面的标题和各张卡片依次上移 6px 淡入（220ms，每张错开 30ms，第四张起不再错开），侧栏选中项左边的高亮条从中间长出来（180ms）；没有退场动画，旧页面直接换掉。系统要求减少动画时直接切换。（用户反馈切换没有过渡；时长与做法为 Agent 推断）
- 侧栏分组（2026-11-13 起外观、主题、主题市场合成一项，AI Agent 组合成一项，见下面「侧栏合并、页内分标签」）：「基础」通用、行为、外观、主题、主题市场、快捷键；「功能」待办、日历、音乐、翻译、剪贴板、文件中转、消息；「AI Agent」岛上显示、会话列表、提醒、声音、审批、连接、SSH 远程；「扩展」插件、插件市场；分隔线下是关于。（用户确认 2026-11-06，D8；AI Agent 单独一组 2026-11-07，B16：Agent 的设置项越来越多，以后移植 Vibe Island 的功能也放这一组。分类名 `agents`（会话）、`sounds` 不变，岛上和旧链接照样能打开；SSH 读取的远程电脑单独一页 `agentRemote`，侧栏名「SSH 远程」，放在这一组最后，2026-11-07 用户要求。2026-11-10 用户同意把原来的「会话」页拆成两页：`agents` 改名「岛上显示」，放总开关、收起条上的会话标题和状态灯、显示哪些 Agent；新的 `agentSessions`「会话列表」放 Agent 页的列表、卡片和隐藏规则。原来「会话」一页管着收起条和展开页两件事，太长，状态灯样式也不好找）
- 概览（2026-11-13，用户同意「概览页 + 隐藏没开的功能」这一步；排版和文案为 Agent 推断）：设置窗口默认打开「概览」，它在侧栏最上面、所有组之上，单独一项。页面从上到下：一句话说明岛是什么、怎么用；「常用」组（深色或浅色、界面语言、登录时打开）；「功能」卡片墙，每个功能一张卡片：图标、名字、一句话说明能做什么、右上角开关，开着时右下角有「设置 ›」打开它的页面；消息没有总开关，卡片上是「选择消息来源 ›」；卡片下的脚注说明关掉会怎样、数据保留。最后是「接下来」组：调整岛的样子（外观）、换一套主题（主题市场）、查看所有快捷键、再看一遍新手引导。概览上的行和各自页面里的是同一个设置，不进设置搜索（`data-search="off"`），搜索结果仍指向原来的页面。
- 没开的功能不进侧栏：待办、日历、音乐、翻译、剪贴板、文件中转、截图关着时，侧栏里不列它的页面；AI Agent 关着时整个「AI Agent」组都不显示。功能和页面的对应在 `categories.ts` 的 `FEATURE_PAGES`。例外：正在看的那一页照常列出（在页面里刚关掉、或从岛上点进来时不会突然消失）；搜索时照样能搜到没开的功能。有功能没开时，「功能」组最后多一行灰色的「＋ 开启更多功能」，点它回到概览。（用户同意；做法为 Agent 推断）
