## 翻译界面

- 快捷翻译参考 `https://island.flyliu.org/` 展示的翻译 UI。（用户确认：本次请求）
- 使用炭灰表面、紧凑标题和语言方向栏，原文与译文以细分隔线组织；浅绿色突出译文及翻译主动作，沿用系统字体和 lucide 图标。（Agent 推断，依据参考界面）
- 默认窄窗口上下排列，宽度达到 760px 时并排；长文本分别滚动和换行，设置区域可滚动。（Agent 推断）
- 空态提供剪贴板入口，加载显示处理中，复制后原位显示“已复制”；保留全局快捷键和 Windows 凭据管理器的密钥设置。（Agent 推断）
- 翻译服务可选 DeepSeek（默认）、火山方舟、通义千问、Kimi、硅基流动、OpenAI 或自定义 OpenAI 兼容接口。预设服务的接口地址由原生端固定，自定义地址须为 https（本机可用 http://localhost）；每个服务可改模型名（DeepSeek 留空用 deepseek-flash，其余需按服务商文档填写），密钥按服务分开保存。工具栏显示当前服务名。（上游 issue #15，用户确认）
- 打开翻译窗口且原文为空时自动填入最新文字剪贴板（默认开，可关）；可开启「停稳后自动翻译」（默认关，仅窗口打开时、输入停约半秒后发送，没有密钥不发送）。「翻译选中文字」快捷键（默认 Ctrl+Alt+T）临时复制选中内容并还原剪贴板，不记入剪贴板历史，没选中时翻译剪贴板文字；译文在折叠的岛上显示一行约 8 秒，消息预览优先，点击打开翻译窗口查看全文。岛内不做第二套原文框，不在后台监听剪贴板或选区，不把译文自动写回剪贴板。（用户确认）
- 设置 → 翻译可选「打开位置」：独立窗口（默认）或岛内页面。选岛内页面时，顶栏翻译按钮、翻译快捷键和点击岛上的译文都打开岛屿展开后的翻译页（方向栏、原文、译文、粘贴 / 复制 / 翻译一行操作），与窗口共用服务、密钥、剪贴板填入和自动翻译设置；收起再展开时保留原文。（用户确认）选独立窗口时岛上没有翻译按钮，从翻译快捷键或托盘菜单的「快捷翻译」打开（翻译关闭时这一项变灰）；翻译窗口按 Esc 关闭，输入法选词时的 Esc 不算。（用户要求 2026-11-10）
- 岛内翻译页（2026-11-12 重新设计）：直接放在岛上，不再套一张自己的卡片。顶行是方向三段选择「自动 / 中 → 英 / 英 → 中」，旁边小字说明翻成什么，右侧是服务名和模型（前面的点绿色表示密钥已配置、橙色表示没有，点它打开翻译设置）。原文、译文是两块同岛形状的浅色区域，页面宽 600px 以上左右并排，窄了上下排列；粘贴、清空和「翻译 Enter」在原文框底部，字数在左下，复制在译文框底部。按钮和译文框的底色用主题色（`--color-accent`），不再用写死的浅绿；译文用正文颜色。没有密钥或出错时在译文框里说明，给「去设置」「重试」；翻译中显示三条骨架线。预览页 `docs/investigations/translation-panel-preview.html`。（用户确认：整体方案、左右并排、显示模型名）
- 设置「基础」分组有「快捷键」页，是所有按键的总览，也能直接改：按功能分组（翻译、剪贴板、插件快捷键、页面切换），每组标题右边「设置页 ›」去功能自己的页；功能关闭时这一组不消失，显示「已关闭」和「开启」。Esc 收起、Alt + 拖动（2026-11-10 起，原 Ctrl + 拖动）、翻译框的 Enter / Shift+Enter / Tab、Agent 审批卡片的 Ctrl+Alt+Y / N / T 只读列出。页首「按键查询」：按下任意组合键，说出浮屿里谁在用它并可前往，没人用就说可以拿来设置。注册失败的错误显示在对应行。不做首次引导和 `?` 浮层。（用户确认）
- 每个快捷键也在它功能自己的设置页里录制，不用跳到快捷键页：翻译页最后一组「快捷键」（打开快捷翻译、翻译选中文字），剪贴板页「打开方式」下面一组（开关、按键、Win+V），「行为」页「展开」下面的页面切换，「插件」页的插件快捷键（没有插件命令时不显示）；各组标题右边「全部快捷键 ›」回总览。两处是同一份设置，改哪边都一样；不管在哪页录，查重范围都相同（全局快捷键、插件快捷键、页面切换键）。（用户要求 2026-11-11，取代原来「每个快捷键只有快捷键页一个修改入口」）
