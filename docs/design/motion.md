# 动效约定

全局方向见 [README.md](README.md)。这里是所有窗口通用的动效规矩：哪里可以动、用哪条曲线和多长、减少动画时怎么办。岛自己特有的（开合预设、Q 弹的合格标准、外壳的注册变量、内容层整像素）在 [island.md](island.md)，这里只链过去。

更新：2026-11-16（D85.1）。档位和减少动画的目标是用户按组长给的默认值同意的（2026-11-16）；token 还没进代码，由 D85.2–D85.4 搬迁和合并，之前写死的值照旧存在。

## 哪里可以动

- **可以动**：岛和面板的外壳（宽、高、圆角）、底色和边框颜色、透明度、图标、没有文字的装饰层（玻璃的色块、高光）。（用户反馈，F14）
- **文字不动位置**：带文字的层只淡入淡出，不做位移动画（`top` / `left` / `margin` 滑入）、不做缩放、不过渡 `transform`。位移在最后一帧会让不同字号的文字取整到不同像素行，`transform` 过渡会让合成器拉伸位图、文字发虚。排查见 [island-jitter.md](../investigations/island-jitter.md)。（用户反馈，F14）
- **不常驻 `will-change`**：要提前提升合成层就只给 `opacity`，动画结束后不残留合成层；进场动画用 `animation-fill-mode: backwards`，不用 `forwards` / `both` 把最后一帧一直挂着。（用户反馈，F14）
- 适用：所有窗口的文字、列表行、按钮标签、面板里切换页面（新页面不上滑；可以被遮罩露出来，见下面「换页动效」）。
- 不适用：没有文字的外壳和装饰层（可以缩放、形变、回弹）；匀速滚动的歌词和跑马灯（它们本身就是在移动的内容，见下面「`linear`」）。
- 例外：开合动画选「灵动」时，展开面板的内容层在淡入的同时从 `blur(10px)` 变清楚（照 Nook X）；选「生长」时内容层从 92% 等比例放大到原大小。只在开合那 100–160ms 里动，动完 `filter`、`scale` 都回到 `none`，不残留合成层。用户在预览页里看过后选的（2026-11-20）。

## 底线

思路借自 ui-motion-skill（MIT），文字是自己写的。（Agent 推断，用户按默认值同意 2026-11-16）

1. **打开怎么来，关闭就怎么回去**：收起、关闭沿原路反着走，用同一类曲线，可以比打开快一点（约 0.7 倍），不换成另一种动作。
2. **除了匀速的东西，不用 `linear`**：界面元素的进出、变色、变大小都有加减速。
3. **操作后 100ms 内要有反馈**：按下、悬停、切换开关的第一帧变化在 100ms 内出现；动作本身可以更长，但不能先静止再动。
4. **不加无限循环的装饰动画**：循环只给表示状态的东西（正在加载、Agent 在跑、等你处理），状态结束就停。
5. **遵守减少动画**：见下面「减少动画」。

- 不要：错开出场（列表一行一行依次飞进来）、按下时缩放按钮、面板或卡片从旁边滑入。这些在悬浮岛这种小而常驻的界面上显得拖沓，也违反「文字不动位置」。（用户按默认值同意 2026-11-16）
- 例外：Fuyu 页面小组件的出场动效（2026-11-21，用户看过 [widget-entrance-preview.html](../investigations/widget-entrance-preview.html) 的十二种方案后定「都要，放进设置里，默认轮播」）。面板展开时卡片可以一张接一张出现，底板可以位移、缩放；文字仍然只淡入，动的是垫在下面的替身底板。「对焦」和「翻牌」两种会让文字跟着模糊、翻转，是用户明知如此仍要保留的可选项。不管哪一种，每张卡片的内容最晚在展开后 560ms 内开始出现；编排不进下面的档位，在 `src/lib/theme/widgetEntrancePlan.ts`。「减少动画」、开合动画选「无动画」时不播。细节见 [island.md](island.md)「小组件出场动效」。（用户要求）
- 适用：所有窗口、所有新写的 `transition` 和 `animation`。
- 不适用：岛外壳的回弹和 Q 弹（由「开合动画」设置管，见下面「弹簧」）；截图选区这类跟手的拖动（跟着鼠标走，不加过渡）。

- 例外：面板和设置窗口的换页动效（2026-11-23，用户看过 [page-switch-motion-preview.html](../investigations/page-switch-motion-preview.html) 后定「都按推荐来」，原默认幕布，2026-11-25 起默认改为淡入）。新页面整块用遮罩（`mask`）露出来（幕布、涟漪、像素溶解）或只淡入（淡入、光扫），文字本身不位移、不缩放、不模糊，`tests/unit/page-switch.test.mjs` 检查新页面的帧里只有透明度和遮罩。用 `mask` 不用 `clip-path`：被 `clip-path` 裁掉的地方点不到，换页后马上点、拖（回归页里拖收起条的格子）会落空；`mask` 只管画不管点，`page-switch` 回归页在拉开途中检查点得到。幕布、亮线、光扫、像素的尺寸和位置都写百分比，不按开始那一刻的像素算死：面板换页时外壳常常同时在变宽变窄。像素溶解每段关键帧用 `steps(1, end)`：`mask-size`、`mask-position` 是可重复的列表，长度不同也会插值，不加的话格子会在两帧之间滑动。动的是没有文字的装饰层：幕布边上的亮线、光扫的斜光、侧栏的高亮块和标签的下划线（它们会位移、伸缩）。预览页里会让文字跟着动的五种（顺向滑入、对焦、层叠、翻页、交错上浮）没有放进设置。时长（幕布 340ms、涟漪 360ms、像素 400ms、光扫 520ms、高亮 280–320ms，乘「速度」0.7 / 1 / 1.4）和曲线不进档位，在 `src/lib/theme/pageSwitch.ts`，是预览页里用户看过的值。减少动画时换成淡入、高亮直接跳。（用户确认）
- 例外：像素画风的水母（2026-11-23，C177，用户看过 [jellyfish-pixel-preview.html](../investigations/jellyfish-pixel-preview.html) 后定「都要，设置里切换」）。它画在画布上逐帧换图，120ms 一拍（和 `--motion-fast` 同长），整格位移，没有曲线和过渡，不走时长档位，`pnpm check:motion` 也查不到它。底线照旧：循环只给运行、等你这类正在进行的状态，失败和完成播一次就停，减少动画时显示静止帧。画法见 [logo.md](logo.md)「像素画风」。

## 曲线

3 条通用曲线，CSS 里写 token，不写 `cubic-bezier(...)` 和 `ease` / `ease-out` 这些关键字。（用户按默认值同意，2026-11-16）

| token | 值 | 用在哪 | 合并进来的旧值 |
|---|---|---|---|
| `--motion-ease` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 默认：悬停、颜色、小控件、列表行 | `(.2, .85, .2, 1)`、`(0.2, 0.7, 0.3, 1)`、`(0.2, 0.8, 0.3, 1)`、`(.2, .75, .25, 1)`；关键字 `ease`、`ease-out` |
| `--motion-ease-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 进场：面板、气泡、横幅等从无到有的东西 | `(0.23, 1, 0.32, 1)`、expo 曲线 `(0.16, 1, 0.3, 1)` |
| `--motion-ease-in-out` | `cubic-bezier(0.45, 0, 0.55, 1)` | 来回的循环：呼吸、等待指示 | 关键字 `ease-in-out` |

- TS 里用到曲线的地方（Agent 列表的排序和归档、切页淡入、剪贴板列表）改读 `src/lib/theme/motionTokens.ts`，单元测试保证它和 `tokens.css` 一致（D85.2 加）。（Agent 推断）
- 现在只出现一两次的其他曲线，合并时按「用在哪」归到最近的一条。（Agent 推断）
- 适用：除岛外壳开合以外的所有过渡和动画。
- 不适用：岛外壳的开合曲线（`src/lib/theme/islandMotion.ts` 的预设、`motionCurves.ts` 算出的弹簧 `linear()`），它们是「开合动画」设置的实现，不并入档位。

### `linear` 只给匀速的东西

- 适用：转圈的加载图标、进度条的流动、歌词和跑马灯的滚动、色块的匀速漂移。
- 不适用：任何有起点和终点的界面变化（进出、变色、变大小、展开收起）。

### 弹簧和 Q 弹

- 回弹、冲过头再回来、果冻感只用在**没有文字**的岛外壳上，曲线留在 `src/lib/theme/islandMotion.ts` 和 `motionCurves.ts`，由设置 → 行为 → 展开 →「开合动画」切换。预设、节奏和 Q 弹的合格标准见 [island.md](island.md)「展开、收起的节奏」「开合动画可选」「Q 弹」三条。（用户确认）
- 不适用：面板里的控件、消息横幅、设置窗口，一律不回弹。

## 时长

4 档。（用户按默认值同意，2026-11-16）

| token | 值 | 用在哪 | 合并进来的旧值 |
|---|---|---|---|
| `--motion-fast` | 120ms | 按下、悬停变色、焦点框 | 80、100、120ms |
| `--motion-base` | 160ms | 默认：小控件展开、切换、淡入淡出 | 140、160、180ms |
| `--motion-medium` | 240ms | 面板里的大块、气泡、横幅、列表重排 | 200、220、240、260、280ms |
| `--motion-slow` | 420ms | 跨大距离、窗口级的进出 | 360、420、500、560ms |

- 现在最常见的是 140ms（约 95 处），并进 160ms 后这些会慢 20ms，D85.4 合并时出前后对比页。（Agent 推断）
- 1s 以上的循环动画不进档位，但要守底线第 4 条：只给状态指示用。（Agent 推断）
- 适用：所有 `transition-duration`、`animation-duration`，以及 TS 里等动画结束的定时器（定时器用和 CSS 同一档）。
- 不适用：岛外壳开合（由「开合动画」预设管，见下面「和原生窗口改尺寸的配合」）；拖岛时中线辅助线这类跟着交互节奏定的延迟（如松手后 120ms 淡出，正好落在 `--motion-fast`）。

## 减少动画

系统开了「减少动画 / 减少动态效果」（`prefers-reduced-motion: reduce`）时：

- **目标**（用户按默认值同意，2026-11-16）：保留淡入淡出（沿用元素自己的时长，档位内一般不超过 `--motion-base`），去掉位移、缩放和回弹。岛外壳开合换成不回弹的 ease-out、时长缩短；循环的状态动画停下或换成不动的样子（例如常亮的点代替呼吸）。
- **做法**（D85.6，2026-11-16）：`src/styles/base.css` 在减少动画时把所有元素的 `transition-property` 收成 `opacity`、`visibility` 和颜色类属性，时长和延迟沿用元素自己写的；没写过渡的元素和 `transition: none` 仍然不动。不统一设时长，因为 CSS 取不到元素原来的时长，统一设成 160ms 会让所有没写过渡的元素也开始渐变。位移、缩放、尺寸的过渡一律去掉。（组长同意）
- 岛外壳在 `src/windows/island/IslandShell.css` 的减少动画段里放行 `--island-shell-*`，时长由 `src/lib/theme/islandMotion.ts` 的减少动画分支给：所有预设换成 `--motion-ease-out` 那条曲线，展开不超过 `--motion-medium`、收起不超过 `--motion-base`，内容淡入不超过 `--motion-base`。设置里「开合动画」的预览（`IslandMotionRow.css`）同样放行，和真岛一致。
- 别的元素要在减少动画下保留尺寸过渡（像岛外壳这样没有文字、又必须连续变化的），在自己的文件里写 `@media (prefers-reduced-motion: reduce)` 带 `!important` 的 `transition-property` 放行，`tests/unit/reduced-motion.test.mjs` 检查 base.css 和岛外壳这两处。
- 新写的 `animation`：在同一个文件里加 `@media (prefers-reduced-motion: reduce)`，停掉或改成不动的形式（`src/AGENTS.md`，`tests/unit/reduced-motion.test.mjs` 检查）。
- 适用：所有窗口。
- 不适用：用户主动的跟手操作（拖动、滚动）本来就没有过渡；「开合动画」选「无动画」时外壳本来就直接跳。

## 和原生窗口改尺寸的配合

岛的网页画在一个比岛大的透明原生窗口里，展开时先放大窗口、收起时等外壳缩完再缩窗口。（用户确认，见 [island.md](island.md)）

- **开合在 560ms 内结束**：外壳的高度过渡（不论哪个预设、展开还是收起）都要在 560ms 内结束；原生侧缩窗口前固定等 600ms（`src-tauri/src/island/geometry.rs` 的 `STAGE_SHRINK_DELAY`），超过就会被窗口切掉。加新预设或拉长时长时同时看这两个数。
- **外壳不超过窗口**：岛最宽、最高（含回弹冲出去的部分）都不超过窗口，否则冲出去的那一下被窗口边缘截掉；Q 弹的高度回弹只往回不往外，因为窗口只比岛高 24px。
- **WebKit 的注册变量过渡**：Mac 上的岛跑在 WebKit 里，`transition` 列表里只要有一个 `@property` 注册过的自定义属性，同一元素上普通属性的过渡就不生效。所以外壳的宽、高、圆角都过渡注册变量（`--island-shell-*`），普通属性只读变量。别的元素同时过渡注册变量和普通属性时也照此办，在 Playwright 的 WebKit 里逐帧量过再交。细节见 [island.md](island.md)「外壳的宽、高、圆角都过渡用 `@property` 注册的变量」。
- 适用：岛的开合、换边、竖向岛展开，以及任何会同时改原生窗口大小的动画。
- 不适用：不改窗口大小的面板内动画、设置窗口、剪贴板窗口里的过渡。
