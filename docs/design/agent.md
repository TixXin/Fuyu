## AI Agent 会话标题

- 小岛在待办位置显示"Agent 图标 + 会话标题"，标题单行省略、不撑宽小岛。什么时候显示（设置 → AI Agent → 小岛显示，`agentTitleMode`）：
  - 有变化时（默认）：Codex / Claude Code 开始新会话、一轮跑完、出错时显示 4 秒，等你确认时一直显示到你处理，规则和歌词优先时的临时显示相同（见 [collapsed-bar.md](collapsed-bar.md)）；其余时间留给待办和中心图案，状态看状态灯和会话环。中途关掉的会话不会一直占着标题。插件和本地接口上报的来源只在「运行时一直显示」下出现。（用户确认 2026-11-09：有活动时弹一下就退）
  - 运行时一直显示：有 Agent 在运行就显示，完成后保留 3 秒再恢复待办，失败或可能中断时配黄灯继续显示；多个 Agent 同时运行时只显示最近有动静的一个。
  - 优先级：消息预览 > Agent 标题 > 待办。（用户确认：图标和标题）
- 标题优先用 Agent 自己生成的标题（Claude Code 的 `ai-title`、Codex 的 `session_index.jsonl`），没有时依次退回第一句提问、文件夹名。"AI Agent"设置页"小岛显示"中可关闭，默认开启。Claude Code / Codex 的标题与 Agent 页同源，直接读会话记录，不依赖钩子（用户确认：统一数据来源）；插件和本地接口上报的来源用各自上报的标题。设计与实测见 `docs/architecture/agent/session-title.md`。（Agent 推断，依据同类项目调研）
- 图标使用官网的 Claude、OpenAI 应用图标，16px 圆角 4px，与 QQ / 微信图标同尺寸。（Agent 推断）
- 小岛显示 Agent 标题时，点击（或悬停展开）打开岛上的 Agent 页，不直接跳终端。（用户确认）
- AI Agent 开启时，小岛最右侧的灰色收起圆点换成正在运行的会话数（蓝色数字，含可能中断的会话），点击打开 Agent 页；没有运行中的会话时不显示。收起到边缘改由闲置自动收起或展开后的最小化按钮（最小化方式选"收起到边缘"）完成。AI Agent 关闭时保留原灰点。（用户确认：灰点改成数字、去掉收起）

## Agent 页

- 岛屿展开后的 Agent 页列出最近 24 小时有动静的 Claude Code / Codex 会话，直接读两者的会话记录，不依赖钩子；正在运行的排前面，最多 12 个。时间窗口在设置 → AI Agent → 会话列表 →「列出多久内的会话」里可选 1 / 2 / 6 / 24 小时，默认 24 小时。agent 已经退出的会话默认不列出（「隐藏已退出的会话」，默认开）。（用户确认：默认 24 小时、默认隐藏已退出的会话；2026-11-15 把默认值从 2 小时改成 24 小时，已保存的设置不动）
- 每行：Agent 图标、"项目名 · 标题"、模型胶囊（见下面「会话行排版」）、状态灯与会话环同色（红"等待确认"或失败、黄"等你回复"、绿运行、半透明绿 10 分钟无动静、灰完成；没看过的完成会话灰点发亮；判断见 `sessionLight.ts`，roadmap B11）、最近一条回复（最多两行）、状态与多久前更新。项目名取会话开始时的文件夹。样式与文件中转页一致的深色面板。每行等高（没有回复摘要的行同样高，状态行贴底对齐），面板高度正好放下"设置 → AI Agent → 会话列表 → 展开后显示条数"设定的行数（2–5，默认 3，与剪贴板的显示条数同样做法，不随样式预设保存），更多会话滚动查看。（用户确认：参照剪贴板显示条数）
- 会话行排版（B41，用户确认 2026-11-15）：标题行从左到右是状态灯、"项目名 · 标题"、模型胶囊、状态文字、来源名、Agent 图标、时间。
  - 模型胶囊：模型、推理强度、权限合成一个小胶囊，如 `Opus 5.5 · M · 自动`；推理强度缩写（Low / Medium / High / Xhigh / Max 写成 L / M / H / XH / Max，插件给的别的写法照原样），悬停看全称；跳过确认时权限字是橙色。标题行放不下时（容器查询，标题行窄于 360px）先省推理强度，再窄（280px）省权限。只有进行中的会话显示。
  - 挤的时候标题先缩（最少留约 2.5 个字），状态文字不缩、最多占四成宽；时间固定一列（列表里在归档按钮的位置，弹出提醒里在行尾，至少 44px 宽），不会被挤出去。
  - 图标：Agent 图标为主，宿主程序（终端、编辑器、桌面版 App）的图标做成它右下角 10px 的角标，悬停和读屏说「在 <宿主名> 里运行」；取不到宿主图标（远程主机、没有程序文件、读图标失败）时不显示角标，不再退回通用的方框图标。「来源」设成「名称」时只在 Agent 图标左边写宿主名；设成「图标和名称」时两样都有，有角标而标题行窄于 480px 时省掉名字。卡片视图的来源同样不再退回方框图标。
  - 状态灯有悬停说明和读屏文字，说灯色的含义：等你确认、等你回复、运行中、10 分钟没有动静、已完成、出错了。
  - 状态灯跟着「岛屿布局 → 状态灯 → 样式」（`agentLightStyle`）：选水母时每行是一只小水母（跟着像素样式，动作和收起条上的一样，减少动画时静止），表情按灯色：等你确认或回复黄、运行蓝、出错红、可能中断灰色问号、正在压缩上下文蓝色挤眼（不看阶段，压缩优先）、没看过的完成绿笑；看过的行和看过的完成会话是米白平静的样子。选圆点时是原来的圆点。卡片视图在标题前面也放一只，紧凑视图用水母代替左边的色条。滚出列表、岛收起或窗口隐藏时水母停下。（用户确认 2026-11-23：列表里的水母要动起来，卡片和紧凑也跟着）
  - 正在调用工具的那一行：工具名是加粗的小胶囊（蓝字），参数等宽、更淡、单行；参数长且带路径时省略中间，最后一段路径留在行内（如 `cd /U… /run-regression.mjs agent-sessions`）；悬停看「正在调用 Bash：完整参数」。「你：」那一行是普通灰字，和它区分开。
- 显示方式（设置 → AI Agent → 会话 → 会话卡片 → 显示方式，`agentSessionView`）：列表（默认，上面这种每行）、卡片、紧凑。卡片每个会话一张 62px、按状态灯颜色描边的卡片：第一行标题、权限模式、模型与推理强度、时间、运行位置和 Agent 图标；第二行状态（按灯色）、子 Agent、任务进度、后台任务、正在调用的工具或最新回复，右端是上下文 tokens。紧凑每个会话一行 34px：状态色条、标题、状态、时间和图标。归档、看过与没看过、找不到窗口的提示三种方式一样。参照 PR #5（Louis），在现有页面上重做。卡片光效（`agentCardEffects`，新装默认粒子流苏）：粒子流苏（边框按灯色发光，进行中和等你处理的呼吸，左侧飘一条粒子流苏）与渐变带（从右端铺一层灯色渐变，进行中和等你处理的更亮）只对卡片和紧凑生效；流光边框（`orbit`，B13）在列表、卡片、紧凑三种方式下都只给等你确认的会话加一条绕边框旋转的光带；系统要求减少动画时全部静止。（用户确认 2026-11-07：列表仍默认，卡片作为可选）
- 归档动画（`agentArchiveMotion`）：滑出（默认，向右滑出再收起）或粒子消散（从左到右化成状态颜色的粒子，约 0.5 秒，再收起），三种显示方式都适用，撤销照旧展开回来；系统要求减少动画时直接移除。参照 PR #5 的消散，做成归档的可选效果，不另加 × 按钮。（用户确认 2026-11-07）
- 列表变动动效（B40，力度「克制」，用户确认 2026-11-15）：会话重排时行平移到新位置（200ms，缓动和归档一致）；新会话原位淡入并从上往下展开，下面的行让位；退出或被筛掉的会话淡出并收起，别的行补位；状态点、紧凑色条和卡片状态文字换色过渡；会话变成等你确认或回复时脉冲一次（列表视图圆点放大一次，卡片和紧凑视图外圈扩散一次），新出现的会话和两种「等你」互换时不脉冲。归档中的行、撤销归档、弹出提醒、审批卡片和切换显示方式时不动；系统要求减少动画时全部直接变化。实现见 `useListMotion.ts`，细节在任务 B40。
- "等待确认"：Claude Code 会话停在工具授权或 MCP 输入请求时显示，状态文字同为橙色；等待中的会话计入小岛上的会话数、小岛一直显示它的标题，不会因为等太久变成"可能已中断"。依赖 Claude Code 的 `Notification` 钩子（需要点"安装/修复"），Codex 没有对应钩子。（用户确认：采纳等待授权建议）
- 点击一行，把该会话所在的窗口切到前台：Windows Terminal 按窗口标题里的会话标题匹配，VS Code 类编辑器按标题中的项目文件夹匹配，Codex 会话最后退回 Codex 应用；最小化的窗口先恢复。只能切到窗口，不能定位到其中某个终端标签；找不到时在该行提示"没找到对应的窗口"。（用户确认：简化版跳转）
- 对齐与归档（B17，用户确认 2026-11-07）：会话圆点、用量行和每行最右的图标都对齐到岛屿 20px 的内边距，和顶部栏的状态灯、右上角按钮在同一条线上；只有悬停高亮往外多出 6px。每行在提供方图标右边是归档的位置，它就是这一行最右的元素，离岛屿边缘 20px，和右上角按钮对齐。列表视图里，有「多久前更新」的行平时在这个位置显示时间（右对齐；这一列的宽度取列表里最长的那个时间，所有行一样宽，所以右侧图标仍在同一列；不到一分钟写 `<1m`，不写「刚刚」；状态那里不再重复写时间），鼠标移到这一行上或用键盘选到它时，时间淡出、换成归档图标；运行中只显示已运行多久、没有更新时间的行，归档图标照常一直显示，平时很淡。归档图标鼠标在这一行上时是普通的灰色，指上去变亮（不用红色，归档不是删除）。卡片和紧凑视图不变。（用户确认 2026-11-07：只在悬停时显示会在右侧空出一块，对不齐；2026-11-13 用户确认：空出的位置平时放时间）点了以后这一行先向右滑出淡出、再收起高度，下面的行补上来，播完才离开列表（岛屿高度随行数变，所以之后才变矮）；左下角浮出「已归档 · 撤销」小胶囊（从左边滑入，5 秒后或撤销时滑出，不占列表位置），撤销时这一行反向展开回来。系统要求减少动画时直接出现和消失。
- 会话行的交互（B43，用户确认 2026-11-15：三样都做）：
  - 行菜单：右键一行，或点「⋯」，弹出和剪贴板等列表一样的行菜单：跳到窗口、在文件夹中显示（`cwd`，用 opener 的 `revealItemInDir`，打开上一级文件夹并选中它）、复制路径、复制会话 id、归档、隐藏这个目录的会话（加一条「所在目录」的隐藏规则，和设置里手动加的一样，含子目录、以后的新会话也隐藏）。远程会话（SSH）没有「在文件夹中显示」；没有目录的会话复制路径和按目录隐藏是灰的；不能归档时（弹出提醒等）没有「归档」。复制后、打不开文件夹时在这一行状态处提示 3 秒（「已复制」「打不开这个文件夹」）。
  - 「⋯」的位置：和归档图标同大（20px）、同一行，在它左边。平时不显示，鼠标在这一行上、键盘选中这一行或菜单开着时出现。列表视图里它正好在 Agent 图标的位置：时间淡出换成归档的同时，Agent 图标淡出换成「⋯」，所以不多占宽度，时间那一列和图标之间也不空出一截（悬停卡片里仍写宿主）。卡片和紧凑视图在右侧给这两个按钮留出位置。弹出提醒里没有「⋯」，也不能右键。
  - 键盘：Tab 到列表里的一行后，↑↓ 选上下一行，Home / End 选第一行和最后一行，到头不绕回；Enter 跳到窗口；Delete 或 Backspace 归档并把焦点移到下一行；Shift+F10 或菜单键打开这一行的菜单，菜单里 ↑↓ / Home / End 选项（绕回）、Enter 执行、Esc 关菜单回到「⋯」。带 Ctrl / Alt / ⌘ / Shift 的方向键不拦，留给岛上的切页等快捷键；子 Agent 的展开按钮和「⋯」、归档按钮照旧能 Tab 到。三种显示方式都一样。
  - 悬停卡片：鼠标停在一行上 0.6 秒，在岛下面出卡片（和用量的悬停卡片同一种）：第一行完整的「项目名 · 标题」，然后「你：最近一次提问」（压成一行，最长 240 字）、「目录：路径」（远程写成 `主机:路径`）、「在 <宿主> 里运行」，每行最多折三行。键盘选中一行时也出。菜单开着、弹出提醒和审批卡片显示时不出。三种显示方式都有。
- 入口：展开后左上角的状态灯图标（点击进入 Agent 页，所在页时高亮）、小岛上的会话数、显示 Agent 标题时点击小岛。AI Agent 关闭时没有 Agent 页。（Agent 推断）
- 弹出提醒：会话开始、完成、出错或等待你确认 / 回答时，收起的岛屿（含贴边隐藏）自动展开到 Agent 页，只显示触发的那一个会话（不显示用量；完成或出错时显示 AI 最后的回复，去掉 Markdown 符号，最多 3 行，面板高度按这一行的实际高度），停留 5 秒（3–30 秒可选）后收起；鼠标停在岛上时不收起，在面板里点过就不再自动收起。会话窗口已在前台、游戏模式勿扰、或你正在用展开的岛屿时不弹。"设置 → AI Agent → 弹出提醒"里，会话开始可选每一轮开始 / 只在新会话开始 / 不弹（默认每一轮；2026-11-19 起新装默认不弹、多一个「不显示」，见下面「弹出通知的新设计」），其余三种事件各有开关，默认都开。没有单独的卡片，直接用只含这一个会话的 Agent 页，点这一行即跳到终端；点岛上别处（如 Agent 按钮）、切页或收起后，Agent 页回到完整列表。（用户确认：B6 第 1 期；弹出时只显示那一个会话为用户反馈）弹出提醒和新消息面板一样不显示顶部栏，岛宽 400，只包住这一行；点这一行以外的面板空白处回到 560 宽的完整 Agent 页。审批 / 提问卡片同样不显示页面顶部栏（走弹出态，高度按卡片，Mac 刘海时状态进两翼），但岛宽仍用完整面板宽度以便看命令；两翼已写「等你确认」时卡片标题只留工具名，不再重复状态句。（C11b：完整宽度；2026-11-19：弹出态 + 两翼，去掉与刘海重复的顶栏和标题）

- 七种都能试。这种通知被关掉（预览台显示收起的岛）时按钮不可点，鼠标放上去说明原因。
- 测试通知照真的走：停留、鼠标放上去暂停、叠放、刘海两翼、声音都用当前设置和原来的代码。差别只有三处：不经过「该不该提醒」的判断；不会触发「没处理时再提醒」；等你确认和提问不点的话 30 秒后自己收起（真的会一直等）。
- 等你确认和提问在「在岛上审批」开着时显示成卡片，点任意按钮（或按快捷键）就收，不回复任何 Agent，「到终端」也不切窗口；关着时显示成等你处理的通知，和真的一样。
- 测试通知不进会话列表，所以不算进收起条的会话数、不留在「等你」、不推到手机和机器人；点它不会去找会话窗口。
- 不打断真的：岛上有真的审批或通知时不弹，预览台下面那行说明写「岛上正有真的提醒，等它收起后再试」。测试通知显示期间来了真的，真的顶掉测试。你自己展开着岛、游戏模式勿扰、Agent 功能关着时也不弹，同样在那行说明里写原因；岛没回应（没在运行）时 1.5 秒后提示。
- 上一条测试还没收就再试一条，新的直接换掉旧的，岛不先收起。
- 结果写在预览台下面那行说明里，8 秒后或换一种通知、改一项设置后换回平常的说明。
- 样例的标题和回复由设置窗口带给岛：岛窗口只加载核心文案，没有设置页的样例。事件见 [contracts.md](../architecture/contracts.md) 的 `agent-test-notice`。
