## 待办日期

- 待办输入框右侧有日期按钮（默认"Today"），点开岛里自己画的月历选日期（C61 起不再用系统日期控件：它在 Mac 上是白底卡片，还会飘到桌面别处）；选今天以后的日子时按钮变成主题色，回车后待办进入"已安排"而不出现在今日列表，日期随之复位为今天。（上游 issue #30，用户确认）
- 有已安排待办时，标题旁出现带数量的日历按钮，进入"Upcoming"页按日期分组查看、删除；该页使用归档页的固定高度，不显示输入框。（Agent 推断）
- 到期待办（日期不晚于今天，包括应用关闭期间错过的）在列表代表今天时并入顶部；列表还停在以前某天时先等跨天流程归档旧列表，再并入，避免被归档到旧日期。（Agent 推断）

### 日期选择的月历（C61，2026-11-14）

- 弹出层挂在岛的 stage 里，底色和墨色取岛的，深色岛上再叠一层墨色 8% 托起来，浅色岛跟着变浅；圆角 14、阴影和「⋯」菜单一个样子。（Agent 推断）
- 只放在岛的范围里（岛外的点击会穿透到桌面）：下面放得下就贴在按钮下方右对齐，上面放得下就放上面，都不行就贴在按钮左侧，再不行就压在岛里能放下的位置。展开的待办页通常只有 306 高，所以平时是贴在按钮左侧。（Agent 推断）
- 格子：今天是强调色字加一圈细边；选中的日子实心填色（今天用强调色，以后的日子用和按钮一样的紫）；过去的日子划掉、不能点；不是本月的日子颜色淡一些但能选。按语言决定一周从哪天开始（中文从周一）。（Agent 推断）
- 头部是年月和「上个月 / 下个月」（本月时上个月不可用），底部三个快捷项：今天、明天、下周一。待办的日期只存一天，过去的不能选，所以不做「下周」这种范围。（Agent 推断）
- 键盘：打开后焦点在选中的日子上，方向键按天和按周移动、PageUp / PageDown 换月、Home / End 到这周首尾，回车或空格选中，Esc 关闭并回到按钮，焦点离开或点别处也关闭。（Agent 推断）

## 项目（issue #44，2026-11-12 起）

- 待办可以带一个项目：在输入框里开头写 `#项目名` 加空格（「#论文 写引言」），就归到这个项目；`#` 后面全是数字的不算（「#40 修好」保持原标题）。项目不单独建表，名字最长 20 个字，用过的项目就是现在待办里出现过的。日历页加的待办也认这个写法。（Agent 推断：issue 建议「从已有项目里选或直接输入新的」，先用不占界面的写法）
- 一条带项目的待办都没有时页面和以前完全一样。有项目时输入框下面多一行筛选（「全部」和各个项目），未完成的按项目分组：组标题写项目名和未完成数，组按项目第一次出现的顺序，组内保持原来的顺序，没有项目的放在最后的「未分组」。已完成的仍在折叠里，不分组，标题前带项目小标签。（Agent 推断）
- 选了一个项目时只列它的待办、不分组，输入框的提示写项目名，新加的待办（没有自己写 `#`）归到这个项目。「已安排」页和归档里的待办标题前也带项目小标签。导出的 Markdown 写成 `- [ ] [论文] 写引言`。（Agent 推断）
- 项目颜色和跨组拖动先不做（重命名、删除见下一节）；拖动排序仍按原列表的顺序，组内拖动正常。（issue #44 的最小版本）

### 保存的项目（2026-11-12 起，用户确认）

- 项目改为一张保存的列表（设置 `todoProjects`），不再随待办清空而消失；没选项目的待办叫「临时」，取代「未分组」。今天的列表上筛选条一直在：「全部 / 临时 / 各项目 / +」，`+` 原地变成输入框，回车新建并选中这个项目。没有待办的项目也有 chip；归档里的某天只列那天出现过的项目，没有「临时」和 `+`。
- 输入框里日期按钮左边一直有一个项目按钮（没有项目时写「临时」），写着新待办要去的项目：默认跟筛选走（「全部」时为「临时」），点开可改，不必为了加一条去切换筛选；换筛选时回到跟随。开头写 `#名字` 仍然最优先，名字不在列表里就新建。插件或旧版本留下的、列表里没有的项目，岛一看到就补进列表末尾。
- 设置 → 待办 → 项目：改名、上下移、删除、添加。项目按 id 认，改名和删了再建同名能区分开。改名会同步改今天、已安排和归档里的待办，已存盘的往日 Markdown 按新名字重写（今天的由自动保存写）；删除只把今天和已安排的待办放回「临时」，归档不动。改名和删除只认设置页里的操作：设置被旧备份或别的窗口覆盖、表里少了项目时不动待办，还在用的项目补回表里（C53）。筛选条上的 `+` 在已有 50 个项目时不显示。和 Agent 页按工作目录的会话分组互不联动。（用户确认）
- 「全部」里各组按保存列表的顺序排，列表外的项目跟在后面，「临时」最后。

## 提醒（C140.1，2026-11-19，用户确认方案）

方案和预览：[todo-settings-plan.md](../investigations/todo-settings-plan.md)、[todo-settings-preview.html](../investigations/todo-settings-preview.html)。三种提醒都走岛上共用的提醒卡片（`reminders/v1`），按钮是卡片自带的「推迟」和关闭，没有单独的「看一下」。

- **带时刻的待办**（标题以 `15:00` 这样的时刻开头）：可以提前 5 / 10 / 15 / 30 分钟提醒，默认准点。提前时卡片第二行写还有多久（「10 分钟后」），准点或过了点才看到的不写。一条待办一天只提醒一次：从提前量那一刻到过点 5 分钟之间，第一次查到时提醒。（用户确认）
- **已安排的待办到期**：到了那天、并进今天的列表时提醒，范围可选：不提醒、只高优先级（默认，原来写死的行为）、高和中优先级、全部。高优先级的卡片标题是「高优先级待办今天到期」，其余是「已安排的待办今天到期」。（用户确认；两句标题为 Agent 推断）
- **每天收尾提醒**：默认关，时间默认 18:00。到点时今天还有没做完的待办，就提醒一次「今天还有 N 件没做完」；到点那一刻都做完了，这一天就不再提醒，之后再加待办也不补。到点后 30 分钟内才查到的照常提醒，更晚不补；开关是在提醒时间过了 2 分钟以后才打开的，或应用是那以后才启动的，当天不补。（用户确认默认关；补不补的规则为 Agent 推断）
- 「今天」按待办的逻辑日期算（设置里的「新一天开始时间」），所以凌晨还没翻篇时不会按新的一天再提醒一遍。
- 设置在「设置 → 待办 → 专注联动与提醒」：到点提醒的开关下面缩进「提前提醒」，接着是「到期提醒哪些待办」和「每天收尾提醒」（打开后缩进「提醒时间」）。C140.2 分标签时挪到「提醒」标签。
- 没处理的重复：日历默认把带时刻的待办算进日程，并在开始前 1 分钟弹会前提醒，待办自己到点再提醒一次。这个重复在这一步之前就有，日历经 `todos/v1` 拿待办，不知道待办自己会不会提醒；怎么去重还没定。

## 本周小结（C140.4，2026-11-19，用户确认方案）

方案和预览同上（方案「第 4 步：本周小结」，预览 ④）。归档页列表最上面的一张卡，跟着列表一起滚动。

- **左边**：本周完成的件数（22px 大数字），下面一行「本周完成 · 专注 6h 40m」。**右边**：七根小柱，一天一根，高度按件数相对本周最多的那天算，今天那根是完整的强调色加一圈细边，星期字也更亮；没完成的那天留一条 2px 的灰线，今天之后的几天也是这条线。**下面**：专注时长最多的三个项目，每行是项目名、一条按比例的细条和时长；没有项目的待办合成一行「临时」，第四名以后不列。（用户确认预览）
- **没有专注时长**（没开「开始任务时启动专注倒计时」的人都是这样）：只有件数和小柱，那一行只写「本周完成」，不留项目那几行的位置。本周一件没完成、没有专注时长、归档也是空的时候整张卡不显示；归档里有往周的记录而本周还没完成时照常显示，写 0。（用户确认前半句；显示 0 而不是隐藏为 Agent 推断：周一早上卡片不该时有时无）
- **一周从哪天开始**跟日期月历一样按界面语言定（`firstDayOfWeek`，中文周一），不做设置。（用户确认）
- **数据来源**：不新存东西。今天之前的每一天看归档，今天看当前的列表；归档里有一份今天的副本（手动保存过）时不重复计，以当前列表为准。件数是那天列表里勾掉的条数，和归档每行的「2/3」里的分子是同一个数。（Agent 推断）
- **专注时长怎么加**：待办上的 `focusMinutes` 是累计值，顺延到第二天的待办会带着前一天的数。所以一条待办只计它比前一天多出来的部分：前一个有记录的日子里有同名、同项目、没做完、且分钟数不比它多的待办时，减去那条的分钟数。没做完的待办上的专注时长也算。上周顺延过来的待办因此只算本周新增的。（Agent 推断；顺延时待办会换 id，只能按标题和项目对）
- 时长写「6h 40m」，不到一小时写「40m」，中英文同一种写法；英文那一行是「done this week · 6h 40m focused」。（Agent 推断，照预览）
- 显示与否是归档组件的属性 `showWeekSummary`，默认显示；设置里「归档页显示本周小结」那一行由 C140.2 接上。关掉后归档页只剩每天的列表。
- 没处理的：用官方插件「番茄钟」专注的时间不进 `focusMinutes`（插件对待办只读），只用番茄钟的人在这张卡上看不到专注时长；内置倒计时对同一条待办「开始、结束、再开始」会各记一次。两件事都不在这一步改。

## 页面样式（C16 引入，C28 起只有这一种）

- 待办页只有下面这一种画法。原来的白色纸张（横线笔记本）和「设置 → 待办 → 显示风格」「待办纸张颜色」都已删除，已存设置里的 `todoStyle`、`todoBackgroundColor` 读取时忽略。（用户要求 2026-11-10：彻底移除纸张风格）
- 页面没有自己的底板，直接画在岛上，和 Agent 页一样；文字和浅色底层都用岛屿的墨色（`--island-ink-rgb`），所以浅色岛屿底色上是深字。（Agent 推断）
- 顶部：四个有名字的标签页「今天 N / 笔记 / 已安排 N / 归档」；当前页底色白 9%，今天页的数量在当前页时是强调色小圆标。「已安排」只在有安排的待办或正打开它时出现。右侧在今天页放保存按钮：平时是下载图标，保存中转圈，保存好变绿勾，没设保存位置或失败时变黄色感叹号，读屏说明各自的意思。（Agent 推断）
- 输入框：38px 高，墨色 6% 底、1px 墨色 10% 边、圆角跟内层面板；左边加号，右边日期按钮（今天 / 明天 / 几月几日，选以后的日子时变紫，提示文字写出那天）。（Agent 推断）
- 每一行：平时无底色，悬停或键盘聚焦时墨色 6% 底；18px 圆形勾选框，完成后绿色实心、标题变灰并划掉；标题 14px、500、19px 行高。开始、删除、拖动三个 26px 图标按钮只在悬停或聚焦时出现。正在做的那一行有浅蓝底和左侧 3px 强调色竖条，右边一直显示「■ 进行中」，悬停时变红色「结束」。可以同时有好几件进行中（C62，2026-11-14 起，用户要求），各自点「结束」；收起的岛只显示最近开始的那一件，结束它以后显示下一件最近开始的；第二天开始时全部结束。一行加间距 34px（2026-11-13 用户嫌空，从 46px 收紧）、每多一行标题加 19px，岛屿按行数长高。（Agent 推断）
- 空列表：图标加「今天还很轻 / 在上面输入一件事，回车添加」，不画虚线框。笔记页是一块墨色 6% 底的输入区。已安排沿用按日期分组的列表，换成行的画法，删除按钮悬停才出现。（Agent 推断）
- 归档：只有一个列表，新的在上、按月分组；每天一行写日期和星期、第一件没做完的事、完成进度条和「2/3」。点进去是回看页：返回按钮写日期，右边「完成 2/3」，列表只读。（Agent 推断：一个列表一眼看到哪天做了多少，比卡片和时间线信息多）
- 插件右键菜单和拖动排序照旧（行带 `data-todo-id`，在 `.todo-list` 里）。
