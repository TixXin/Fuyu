## 待办日期

- 待办输入框右侧有日期按钮（默认"Today"），点开系统日历选日期；选今天以后的日子时按钮变成主题色，回车后待办进入"已安排"而不出现在今日列表，日期随之复位为今天。（上游 issue #30，用户确认）
- 有已安排待办时，标题旁出现带数量的日历按钮，进入"Upcoming"页按日期分组查看、删除；该页使用归档页的固定高度，不显示输入框。（Agent 推断）
- 到期待办（日期不晚于今天，包括应用关闭期间错过的）在列表代表今天时并入顶部；列表还停在以前某天时先等跨天流程归档旧列表，再并入，避免被归档到旧日期。（Agent 推断）

## 项目（issue #44，2026-11-12 起）

- 待办可以带一个项目：在输入框里开头写 `#项目名` 加空格（「#论文 写引言」），就归到这个项目；`#` 后面全是数字的不算（「#40 修好」保持原标题）。项目不单独建表，名字最长 20 个字，用过的项目就是现在待办里出现过的。日历页加的待办也认这个写法。（Agent 推断：issue 建议「从已有项目里选或直接输入新的」，先用不占界面的写法）
- 一条带项目的待办都没有时页面和以前完全一样。有项目时输入框下面多一行筛选（「全部」和各个项目），未完成的按项目分组：组标题写项目名和未完成数，组按项目第一次出现的顺序，组内保持原来的顺序，没有项目的放在最后的「未分组」。已完成的仍在折叠里，不分组，标题前带项目小标签。（Agent 推断）
- 选了一个项目时只列它的待办、不分组，输入框的提示写项目名，新加的待办（没有自己写 `#`）归到这个项目。「已安排」页和归档里的待办标题前也带项目小标签。导出的 Markdown 写成 `- [ ] [论文] 写引言`。（Agent 推断）
- 项目颜色和跨组拖动先不做（重命名、删除见下一节）；拖动排序仍按原列表的顺序，组内拖动正常。（issue #44 的最小版本）

### 保存的项目（2026-11-12 起，用户确认）

- 项目改为一张保存的列表（设置 `todoProjects`），不再随待办清空而消失；没选项目的待办叫「临时」，取代「未分组」。今天的列表上筛选条一直在：「全部 / 临时 / 各项目 / +」，`+` 原地变成输入框，回车新建并选中这个项目。没有待办的项目也有 chip；归档里的某天只列那天出现过的项目，没有「临时」和 `+`。
- 输入框里日期按钮左边一直有一个项目按钮（没有项目时写「临时」），写着新待办要去的项目：默认跟筛选走（「全部」时为「临时」），点开可改，不必为了加一条去切换筛选；换筛选时回到跟随。开头写 `#名字` 仍然最优先，名字不在列表里就新建。插件或旧版本留下的、列表里没有的项目，岛一看到就补进列表末尾。
- 设置 → 待办 → 项目：改名、上下移、删除、添加。项目按 id 认，改名和删了再建同名能区分开。改名会同步改今天、已安排和归档里的待办，已存盘的往日 Markdown 按新名字重写（今天的由自动保存写）；删除只把今天和已安排的待办放回「临时」，归档不动。和 Agent 页按工作目录的会话分组互不联动。（用户确认）
- 「全部」里各组按保存列表的顺序排，列表外的项目跟在后面，「临时」最后。

## 页面样式（C16 引入，C28 起只有这一种）

- 待办页只有下面这一种画法。原来的白色纸张（横线笔记本）和「设置 → 待办 → 显示风格」「待办纸张颜色」都已删除，已存设置里的 `todoStyle`、`todoBackgroundColor` 读取时忽略。（用户要求 2026-11-10：彻底移除纸张风格）
- 页面没有自己的底板，直接画在岛上，和 Agent 页一样；文字和浅色底层都用岛屿的墨色（`--island-ink-rgb`），所以浅色岛屿底色上是深字。（Agent 推断）
- 顶部：四个有名字的标签页「今天 N / 笔记 / 已安排 N / 归档」；当前页底色白 9%，今天页的数量在当前页时是强调色小圆标。「已安排」只在有安排的待办或正打开它时出现。右侧在今天页放保存按钮：平时是下载图标，保存中转圈，保存好变绿勾，没设保存位置或失败时变黄色感叹号，读屏说明各自的意思。（Agent 推断）
- 输入框：38px 高，墨色 6% 底、1px 墨色 10% 边、圆角跟内层面板；左边加号，右边日期按钮（今天 / 明天 / 几月几日，选以后的日子时变紫，提示文字写出那天）。（Agent 推断）
- 每一行：平时无底色，悬停或键盘聚焦时墨色 6% 底；18px 圆形勾选框，完成后绿色实心、标题变灰并划掉；标题 14px、500、19px 行高。开始、删除、拖动三个 26px 图标按钮只在悬停或聚焦时出现。正在做的那一行有浅蓝底和左侧 3px 强调色竖条，右边一直显示「■ 进行中」，悬停时变红色「结束」。一行加间距 46px、每多一行标题加 19px，岛屿按行数长高。（Agent 推断）
- 空列表：图标加「今天还很轻 / 在上面输入一件事，回车添加」，不画虚线框。笔记页是一块墨色 6% 底的输入区。已安排沿用按日期分组的列表，换成行的画法，删除按钮悬停才出现。（Agent 推断）
- 归档：只有一个列表，新的在上、按月分组；每天一行写日期和星期、第一件没做完的事、完成进度条和「2/3」。点进去是回看页：返回按钮写日期，右边「完成 2/3」，列表只读。（Agent 推断：一个列表一眼看到哪天做了多少，比卡片和时间线信息多）
- 插件右键菜单和拖动排序照旧（行带 `data-todo-id`，在 `.todo-list` 里）。

## 和剪贴板、文件中转同一套（C34，2026-11-10）

- 顶部的页面切换用列表页共用的胶囊（`src/components/list/IslandList.css`）：今天 / 笔记 / 已安排 / 归档，数量是胶囊里的小圆标，当前页的圆标是待办蓝。（用户确认预览）
- 今天页右上角是「今天完成 2/6」和一条 44px 的细进度条，最右是「⋯」：保存今天的清单为 Markdown、清除已完成（N 件）。保存按钮平时不显示，只在保存中、刚保存好、没设保存位置或失败时出现在「⋯」左边，点它和以前一样保存或去设位置。（用户确认预览）
- 输入框和剪贴板的搜索框同一种样子（墨色 6% 底、圆角 10、聚焦时一圈待办蓝）。
- 做完的待办沉到下面，收在「已完成 N」一栏里，可以折叠，折叠只在这次打开期间有效；没做完的在上面，顺序不变。回看某一天时照原来的顺序列出。（用户确认预览）
