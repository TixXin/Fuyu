# 文件中转

全局方向见 [README.md](README.md)。

## 文件中转

- 单独一页「文件中转」，强调色是主题色（C39 起，原来是薄荷绿）。（用户确认：单独一页）
- 只存路径不复制文件；拖出默认复制、Shift 移动，与资源管理器一致。（用户确认：只存引用）
- 拖入时列表保持原位并变暗，整个面板叠一层带虚线框的主题色覆盖层；空列表时投放区撑满面板。放下后列表回到顶部，新加入的条目高亮约 1 秒；全部是已有文件时标题旁短暂提示「已在列表中」。（用户确认：覆盖层方案）
- 选中条目用主题色底和描边；选中两个以上时标题下方出现一行选择栏。置顶条目在图标外加一圈主题色描边；「已失效」划掉文件名，「无法访问」用琥珀色文字、不划掉，表示文件可能还在。（Agent 推断）
- 折叠态的数量标签是主题色的胶囊，默认关闭。（用户确认：要这个设置项；默认关为 Agent 推断）
- 详见 `docs/features/file-shelf.md`。

## 和剪贴板同一套（C29，2026-11-10）

- 不再画面板和整页虚线框；行、筛选、搜索框、「⋯」和剪贴板页共用 `src/components/list/`，强调色是主题色。（用户确认预览）
- 顶部筛选：全部 / 置顶，右边是数量和「⋯」（清空，点两次确认）；搜索框一直显示。
- 每行：文件图标（按类型带一点颜色，图片显示预览），第一行文件名，第二行「所在文件夹 · 大小」，失效或无法访问用琥珀色写在大小的位置，失效的文件名划掉。置顶的行尾有图钉。点一行选中（Ctrl / Shift 多选），双击打开，拖出去照旧。
- 悬停才出现：置顶、复制、「⋯」（打开、在文件夹中显示、移除）。多选栏是一条主题色底的横条，写「复制」「移除」。
- 空的时候：图标、「把文件拖到岛上暂存」和一句说明。拖进来时出现虚线覆盖层。
