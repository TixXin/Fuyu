# 灵动岛：顶边贴合与视觉规范

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 顶边贴合

- 岛屿贴住显示器顶边时，顶边与屏幕上沿齐平，上方两角向外做反向圆弧，与屏幕边框连成一体，底部两角保持外凸圆角；离开顶边后恢复四角圆角。（用户确认：参考截图）
- 折叠态与展开态都保持这一造型。（用户确认）
- 拖放时距离顶边 16 逻辑像素以内会吸附到顶边；顶部任务栏存在时以任务栏下沿为顶边。反向圆弧半径默认 8px，可在设置"外观"中用"贴顶圆角"滑块调成 0–12px（0 为直角，随样式预设保存），不进入点击区域，鼠标在那里会穿透到桌面。（Agent 推断）
- 多显示器（C1）：设置"位置 → 显示在"可选主显示器（默认，和以前一样）、鼠标所在的显示器、前台窗口所在的显示器。跟随时，收起的岛（含贴边收起）在目标换到另一块屏幕并停留约 0.6 秒后，移到那块屏幕的顶部中间；展开或正在拖动时不移，等收起后再移；前台是岛屿自己时不算换屏。移屏会清掉拖动保存的位置。只有一个岛，不做每屏一个。（用户确认：跟着走）
- 岛屿圆角可在设置"外观 → 尺寸与位置"中调成 16–40px（默认 16px，随样式预设保存；旧版本保存的设置里没有这一项时按 30px 显示），调的是展开态底角；折叠态底角按原 30 / 22 的比例跟随，原生点击区域同步缩放。拖离顶边后四个角一样圆：顶角取同一形态的底角（折叠 22、展开 30 的比例），不再用更小的顶角，悬浮的胶囊上下对称。（用户确认 2026-11-13：离开顶边后上方圆角和下方不一致，看起来像歪了）内层面板（待办、音乐、剪贴板）与岛边缘相距 20px，圆角按同心原则取"岛屿圆角 − 20px"，最小 8px，默认 10px。贴顶描边与侧边描边同宽同样式（液态玻璃为 1px 加向内淡出）。（用户确认）
- 岛屿圆角默认为"方圆"（CSS `corner-shape: squircle`），在"尺寸与位置 → 圆角样式"中可切回"圆角"，随样式预设保存；旧版本的设置也按方圆显示。岛屿外框、继承其圆角的玻璃与描边层、内层面板都用同一形状，原生点击区域按超椭圆 |x|⁴ + |y|⁴ ≤ r⁴ 判断。没有采用苹果的连续曲率圆角：同半径下它与普通圆角相差不到 1px，CSS 无法直接表达，只能整体裁剪，代价是重做阴影和描边。调研与对比页见 `docs/investigations/corner-shape-compare.html`。（用户确认）
- 展开方式可选"点击"（默认）或"鼠标悬停"。悬停时光标在岛上停留满"悬停延迟"（0–1000ms，默认 300ms）才展开；延迟内按下鼠标会取消，拖动和点击不受影响；停在小岛上的消息预览、邮件、音乐按钮上不展开。小岛正在显示 QQ / 微信 / 邮件预览时暂停悬停展开，点击预览照常打开对应应用；预览结束时光标仍停在岛上的，需移开再回来才会悬停展开。（用户确认：悬停与点击预览冲突）悬停模式下，面板无论是悬停还是点击打开、在里面点过什么，只要光标进入过面板再移开，就在"移开后收起延迟"（0–2000ms，默认 400ms）后收起；正在文本框里输入、或鼠标仍按住（如拖出面板的拖动）时暂不收起，结束后照常收起。光标从未进入过的面板（快捷键、设置预览打开）不按此规则收起。失焦收起照旧。（用户确认：点过后不收起不符合预期）悬停不抢占输入焦点。收起时光标仍在岛上的，需移开再回来才会再次悬停展开。光标进出岛形状由原生端判断（事件 `island-hover-changed`），不依赖网页的 mouseleave。（用户确认）
- "收起到边缘时，收到新消息自动露出"（默认开启，在"通用 → 展开与收起"）：岛贴边收起时仍接收 QQ / 微信 / 邮件预览，有新预览时滑出并显示；预览显示期间暂停闲置计时，预览结束后重新完整计时再收回。关闭后保持旧行为：贴边时丢弃预览。（上游 issue #28，用户确认）
- "外观 → 尺寸与位置"中的"最大面板高度"（306–546px，默认 490px，随样式预设保存）限制会滚动的页面：待办随条目增高到此为止后列表开始滚动，剪贴板和消息页也不超过它；音乐、归档等固定布局的页面不受影响。字号不单独设置，由"展开面板大小"整体缩放；面板宽度起初不开放（需要原生窗口宽度随之变化）。（用户确认）新消息和 Agent 的弹出提醒例外：只显示卡片、岛宽 400（见 collapsed-bar.md、agent.md）；窗口本身是固定 820 宽的透明舞台，岛宽由 CSS 决定，Rust 只用 `expandedWidth` 算鼠标命中区域。
- 面板宽高（C25，2026-11-10）："最大面板高度"改名"面板高度"，下面加"面板宽度"（480–800px，默认 560，随样式预设保存；大缩放下以能放进 820 宽的岛窗口为限）。宽度用于普通页面，日历（680）和要求更宽的插件页取两者中较大的。展开时按住 Alt 拖动面板左右边缘（12px 以内）调宽度、拖动底边调高度、拖动底角两者都调，岛保持居中所以左右一起变；拖动高度时面板临时显示到正在设的高度，松开后回到页面自己的高度。按住 Alt 时展开的岛不因鼠标离开或切到别的窗口而收起。移动岛屿从 Ctrl + 拖动改为 Alt + 拖动。（用户确认：Alt 拖动、Alt 改宽高、按住 Alt 不收起、外观加宽高条；拖边缘的方式、宽度范围为 Agent 推断）
- Alt 拖动的提示（2026-11-11）：按住 Alt 把鼠标移到岛上时，能拖动改尺寸的边上淡淡显示主题色（`--color-accent`）细线，光标所在、或正在拖的那段全亮；改宽度时岛保持居中，对侧的线（或对侧下角）半亮。线画在离边框 4px、与岛同心同形状的轮廓上，落在 12px 的拖动范围里；展开面板是左右两边、底边和两个下角（下角为沿圆角的 L 形，两端各伸出 10px），顶边不能拖所以没有线。下角圆角范围内的整段曲线都算同时调宽高，左下角光标为 `nesw-resize`。折叠岛也能按住 Alt 拖左右边缘调宽度，存为外观 → 尺寸里的"折叠岛屿宽度"（在随内容变化的宽度上加减，-60 到 +180px，默认 0）。悬浮展开时，按住 Alt 移上去或在等待展开时按下 Alt，这次都不展开，松开 Alt 也不展开，要移出再移回来。拖动改尺寸时岛屿直接跟手，不走展开收起的缓动；拖动中在面板底部（折叠岛在它下方）显示正在设的尺寸。新消息、Agent 提醒弹出的卡片有自己的尺寸，按住 Alt 只能移动，不显示线条。面板较矮时左右的线缩短，不和下角的线连在一起。线条带一圈主题色柔光，浅色岛上也看得清。预览页 `docs/investigations/alt-resize-hints-preview.html`。（用户确认：全部淡显 + 光标处加亮、折叠岛只调宽度、Alt 时不悬浮展开；线条位置与粗细、宽度范围为 Agent 推断）
- 所有页面统一尺寸（C27，2026-11-10）：每个页面（待办、音乐、日历、剪贴板、Agent、文件中转、消息、翻译、插件页）展开时都是"面板宽度 × 面板高度"，内容多了在页面里滚动，不再按条目数增高；去掉剪贴板和 Agent 页的"展开后显示条数"，日历不再自动加宽到 680，插件清单里的 `width` / `height` 不再改变岛的大小。只有自己弹出的卡片（新消息面板、Agent 提醒和审批卡片）仍按卡片内容的高度。面板高度范围改为 360–640（翻译、音乐页在 360 也放得下），默认仍是 490。（用户确认：所有页面统一用面板宽高；高度范围为 Agent 推断）
- 在设置中拖动"展开面板大小""面板宽度""面板高度""岛屿圆角"时，收起的岛自动展开实时预览，滑块停止 1.5 秒后自动收起；拖动"折叠岛屿大小"时，预览打开的面板立即收起（贴边收起的岛会滑出）以显示小岛。用户自己打开的面板、或预览中在面板里按过的，不会被自动收起。预览不抢占焦点。（用户确认：本次请求）

## 灵动岛视觉规范（2026-11-06）

下列条目除注明"用户确认"外，均为 Agent 推断，依据一轮岛屿界面的设计审阅。圆角形状见上文"顶边贴合"。设置窗口不在这一轮范围内。

- **清晰度**：新用户默认折叠 / 展开缩放都是 1.0（老用户保留已存值）。`.island` 不再常驻 `will-change: transform`，内容层只保留 `will-change: opacity`；缩放仍用 `transform`（不用 `zoom`），因为原生点击区域（`island/passthrough.rs`）按"基准尺寸 × 缩放、顶部居中"计算，`zoom` 会改变布局盒、打断缩放过渡，还会让展开高度测量换算。进场动画用 `backwards` 填充，结束后不残留合成层。
- **字体**：全岛一个字体栈 `--font-ui`（`Segoe UI Variable Text`、`Segoe UI`、`Microsoft YaHei UI`…），写在 `tokens.css`，`base.css` 引用；不再有私有字体栈和 `font-synthesis: weight`（像素字体主题除外）。字重只用 400 / 600，≥15px 的标题可用 700；不用 800 / 900。
- **文字 4 级**：`--text-1/2/3` 与 `--text-placeholder`，同一色相（`--color-text` 的 248,246,240）取 .96 / .68 / .54 / .42。在岛 `#030303` 与内层面板 `#1e1e22` 上分别为 17.5 / 14.2、8.7 / 7.8、5.7 / 5.4、3.8 / 3.8：前三级用于可读文字（≥4.5:1），placeholder 只给输入框占位。岛上中性灰文字一律用这 4 级，主题色（`--color-accent`）不在此列。
- **图标**：岛上 lucide 图标只用 16px（顶栏、折叠条、列表）和 14px（行内、插件页按钮），统一 `strokeWidth={1.5} absoluteStrokeWidth`；品牌图标 16px。
- **颜色语义**：颜色只给数据和状态用，其余黑白灰。黄色只表示"需要注意"（Agent 状态）。
- **一个主题色**（C39，2026-11-10）：各页面、当前页按钮、玻璃面板的色调、剪贴板窗口、翻译窗口、设置窗口只用一个强调色 `--color-accent`，就是「设置 → 主题 → 强调色」选的那个（默认深色 `#74d6ff`、浅色 `#0a7fd1`，可以跟随 Windows 或自选）；原来各页自己的颜色（音乐紫、日历橙、剪贴板粉、文件中转薄荷绿、日期按钮紫）都去掉了。主题色上的文字用 `--color-on-accent`，按主题色的亮度取深字或白字。表示状态的颜色不跟主题色：Agent 状态灯和会话灯、删除的红、完成的绿、日历的「休 / 班」、警告色、SSH 隧道的「已连接」、设备提示的绿和橙、文件类型和插件分类的图标色。（用户要求：每个页面的主题色花里胡哨，统一成设置窗口的蓝色，并且可以设置）会话列表里仍有运行中会话时，状态灯显示蓝色运行，不再出现"绿灯 + 蓝色数字"。
- **顶部栏的页面按钮**：状态灯右边的待办、音乐、日历、剪贴板、文件中转是图标按钮，图标和设置窗口侧栏同一套（`ListTodo`、`Music`、`CalendarDays`、`ClipboardList`、`Inbox`），不再是彩色圆点。没打开的是灰色单色图标、没有底；当前页的图标用主题色，垫一层主题色的淡底。右边的设置、消息、翻译等操作按钮带圆形底，和左边的页面按钮区分开。插件页按钮同样大小。最左边的 Agent 入口也是图标（`Bot`），不再是圆点，但颜色照旧跟着 Agent 状态（空闲、运行、需要注意），打开 Agent 页时垫一层浅底。（用户确认 2026-11-09：圆点看不出是哪一页，改成图标、单色、当前页上色；Agent 的圆点也改成图标）
- **纯色模式是一整块底色**（2026-11-09）：收起的岛和展开的岛一样只画底色，不再叠上下明暗渐变；纯黑的岛（默认）因此能和屏幕黑边、刘海融在一起。焦点描边和内发光只在用键盘切到岛上的按钮时出现（`:focus-visible`），鼠标点过后不再亮起。液态玻璃不变。（用户反馈：纯色模式下有高光渐变）
- **透明度**：经典模式的"透明度"只作用于岛的底色（`--island-fill`），文字和图标保持不透明。有意的变化：以前整岛一起变淡，现在文字和内层面板在透明度 < 100 时保持不透明。已知问题：贴顶时圆弧过渡层（`IslandTopEdge.css` 的 `.island::before`）用 1px 的底色条盖住顶边描边，底色半透明时盖不住，顶边会透出一条略深的线；要修需改经典描边的画法，这一轮没动。

## 收起时的临时提示（2026-11-07）

- 收起的小岛上，消息预览之外的临时提示按这个顺序占用文字位置：设备提示（耳机或蓝牙音频连接 / 断开、蓝牙电量低、插拔电源，3 秒）先于音量 / 亮度提示（1.5 秒），二者都让位于消息预览。展开、贴边收起、游戏免打扰时不显示，期间发生的变化直接丢弃，不补显示。（Agent 推断）
- 设备提示：图标 16px + 一行文字（太长时省略）+ 右侧电量百分比（等宽数字，没有电量不显示）。连接、充电用绿色图标 `#34C759`，断开、拔电源用灰色图标，电量低时图标和百分比用橙色 `#FF9F0A`。只提示耳机、耳麦和蓝牙音频，扬声器和显示器的 HDMI 音频不提示。蓝牙电量降到 20%、10% 各提醒一次，充到 30% 以上后重新计。（Agent 推断）
- 托盘菜单（F13）：跟随岛屿的界面语言（中文 / English），设置里切换语言后立刻跟着变；岛屿启动前先显示中文，和界面的默认语言一致。菜单三项：「显示岛屿 / 隐藏岛屿」（一项，按岛屿当前是否可见显示对应文字）、「设置」、「退出」。（用户确认）
- 展开、收起动画中文字保持清晰（F14）：整岛的缩放过渡作用在 `@property` 注册的 `--island-scale` 上，不直接过渡 `transform`，避免合成器拉伸位图；内容层只淡入淡出，不滑动：`top` 滑入在最后一帧让不同字号的文字取整到不同的像素行，彼此错开 1 像素（[island-jitter.md](../investigations/island-jitter.md) 第三轮），`transform` 滑入又会模糊文字。也不预先 `will-change`。以后给岛上的文字加动画时同样避免位移动画、transform 过渡和常驻 will-change。（用户反馈）面板里切换页面时新页面也只淡入，不再上滑 6px（第五轮，2026-11-12）。（用户反馈）
- 展开、收起动画中文字不抖：外壳按「基准尺寸 × 当前模式的缩放」直接设定宽高和圆角并过渡，没有文字；收起层和展开层各自用固定的 `zoom`（收起缩放、展开缩放），开合过程中不变。缩放本身过渡（不论 `transform` 还是 `zoom`）会让内容每帧按新尺寸重排，取整误差使文字和列表行来回跳。排查见 [island-jitter.md](../investigations/island-jitter.md)。（用户反馈）
- 展开、收起的节奏和官网顶部的岛一样（2026-11-12）：外壳宽度 550ms 带回弹（`cubic-bezier(0.34, 1.36, 0.5, 1)`，冲过约 4% 再回来），高度 500ms、圆角 450ms 用 ease-out（`cubic-bezier(0.22, 1, 0.36, 1)`），展开层在 120ms 后用 250ms 淡入。回弹只作用在没有文字的外壳上，上一条不变；岛最宽不超过窗口，最宽的面板回弹时不被窗口边缘切掉。（用户要求）
- 外壳的宽、高、圆角都过渡用 `@property` 注册的变量（`--island-shell-width`、`--island-shell-height`、`--island-shell-top-corner`、`--island-shell-bottom-corner`），`height`、`border-radius` 只读这些变量（2026-11-13）：WebKit（Mac 上的岛）的 `transition` 列表里只要有一个注册过的自定义属性，同一元素上普通属性的过渡就不生效，表现是 Mac 上展开、收起只有左右的弹性，上下一下跳到终点。在 Playwright 的 WebKit 和 Chromium 里逐帧量过，改后两边曲线一致。以后给外壳加过渡也用注册变量。（用户反馈）
- 开合动画可选（C49，2026-11-12）：设置 → 行为 → 展开 →「开合动画」有弹性（默认，同官网）、平滑（2026-11-12 前的 560ms ease-out）、快速（约 280ms）、Q 弹（果冻，见下一条）、无动画。「弹性」展开、收起都和官网顶部的岛一样（fuyu-site `TopIsland.astro`）：收起也是宽度 550ms 回弹（先缩过头再弹回）、高度 500ms、圆角 450ms，面板内容 250ms 淡出后折叠条再淡入；按官网逐帧量过宽高对齐。平滑、快速收起比展开快（约 400ms）、不回弹。只换外壳的时长和曲线，内容层仍然只淡入淡出（上面 F14 那两条不变）；高度都在 560ms 内结束，原生侧缩窗口前的 600ms 等待不用改。系统开了「减少动画」时，弹性和 Q 弹去掉回弹，其余照常。时长在 `features/appearance/islandMotion.ts`。（用户确认；收起和官网一致是用户反馈）
- Q 弹（2026-11-12，在 [island-motion-lab.html](../investigations/island-motion-lab.html) 里调定）：宽度是欠阻尼弹簧（展开阻尼 0.55、680ms，收起 0.64、600ms），冲出去再轻轻回一下就停；面板宽时冲出去的部分被 820 宽的窗口截住，回摆那一下仍看得到。高度「落地」：到终点后往回弹 6%（收起 5%）再一小下，始终不超过终点（窗口只比岛高 24px），600ms 内结束。圆角有自己的弹簧。折叠条等收起时最窄的那一下过去才淡入。合格标准（800 和 560 两种面板宽都要过）：展开冲出 8–40px、回摆 ≤ 12px、来回 ≤ 2 次、700ms 内停稳、高度回弹 4–18px；收起比折叠条窄 ≤ 45px、来回 ≤ 2 次、650ms 内停稳、高度上弹 ≤ 15px。第一版阻尼 0.32、来回晃五下，用户反馈晃得太厉害。曲线用 CSS `linear()` 由 `features/appearance/motionCurves.ts` 算出。系统「减少动画」时全部换成 ease-out。（用户确认）
- 开合中内容不左右跳（2026-11-12）：外壳左边缘每帧取整到整设备像素，内容层固定在静止时的整像素位置，不再按外壳宽度的 50% 居中。淡入时内容层在单独的合成层里，按外壳的小数宽度居中会每帧差 1/64 像素、整像素来回翻。排查和录屏方法见 [island-jitter.md](../investigations/island-jitter.md) 第四轮。以后改外壳宽度或内容层定位时保持这一点，并在真实窗口里录屏核对（浏览器暂停截图测不出来）。（用户反馈）

## 音乐页（2026-11-09）

- 和 Agent 页同一种做法：内容直接放在岛的底色上，没有自己的卡片、描边和投影；文字颜色跟随岛的底色（`--island-ink-rgb`），只有鼠标悬停的按钮亮起一层浅底。顶部一行是 56px 封面、歌名（大、亮）和「歌手 · 播放器」（小、暗），歌词偏移和音乐设置在这一行最右、悬停才出现；中间是占满整宽的歌词（没有歌词时是波形）；下面是进度条或估算说明；最下面是上一首、下一首两个只有图标的按钮，中间的播放 / 暂停是跟随文字颜色的实心小圆。液态玻璃外观下也不再给音乐页单独画一块玻璃面板。（用户确认 C17）
- 有歌词时，歌词占波形的位置，不再在歌词下面留一条看着像进度条的细波形；没歌词时仍是大波形。（用户要求：全面优化音乐页 UI）
- 歌词三行：上一句、正在唱的、下一句（有翻译时是翻译）。正在唱的那句太长时换成两行完整显示，不再用省略号截断。（Agent 推断）
- 播放器报告进度和时长时，下面是一条带「已播放 / 总长」的细进度条。网易云这类不报告进度的播放器没有进度条，换成一行说明：歌词按切歌时间估算，拖了进度就点正在唱的那句对齐；岛屿没看到这首歌开头时（比如岛屿启动时歌已在放）说「可能没对齐」。播放器是网易云时附一个「装 InfLink-rs 精确同步」的链接。（调研：网易云自带的 SMTC 不报告进度和歌曲 id，见会话 2026-11-09）
- 估算进度时，三行歌词都是按钮，点哪句就把岛屿的计时拨到那句的开头。播放器报告进度时歌词不能点。（Agent 推断）
- 「正在播放」示例插件 1.1.0 起默认不在换歌时发通知：岛屿自己已经显示正在播放，开了「展开面板」或「横幅」新消息提示时它会变成一张多余的消息卡片。（用户要求）

## 插件的列表页面（2026-11-09）

- 用列表模板的插件页面（GitHub Issue、开发任务看板等）和 Agent 页、音乐页同一种做法：不套卡片，行不加底色，靠字号和明暗区分，只有鼠标悬停的行亮起一层浅底；文字颜色跟随岛的底色（`--island-ink-rgb`），外链图标悬停才出现。详情、表单、状态模板暂时保留卡片。（用户要求 E16）

- 悬停切换页面只认光标真的移动：页面宽度不同（系统监控 800、日历 680、其他 560），岛居中变宽时顶部图标会整体平移，图标滑到静止的光标下面不算悬停；切换页面后约 0.45 秒（岛变宽的动画）内也不响应悬停，之后光标要再动一下。点击不受影响。（用户反馈：悬停系统监控图标时页面来回跳）

- 闲置贴边收起时这些情况不收起（C32，issue #29，2026-11-10）：设置 → 行为 →「闲置时贴边隐藏」下面三个开关：有正在进行的待办时（点了「开始」、待办还在且没完成，默认开）、Agent 在等你时（有会话等审批或回答，默认开）、音乐播放中（默认关）。对应的功能关着时不算。这些情况期间闲置计时暂停，都结束后从头计时，和消息预览结束后一样；只是不收起，已经收起的不会因此露出。「有待办」不按「列表不为空」算：列表里总有没做完的事，那样岛就永远不收。（用户确认：两个默认开、音乐默认关）
- 拖动过位置的岛贴边后再出来（鼠标碰到那条边、新消息、托盘「显示」）时，在屏幕顶边滑出，横向位置用拖动时的 x，这样岛正好在鼠标下面；面板关掉回到收起、或再拖一次后，回到拖动时的高度。托盘「显示」会把贴边的岛滑出来。（issue #37，用户选定 2026-11-11）
- 悬停切换要先停稳（C35，2026-11-10）：光标在页面图标上停约 0.12 秒才切换（设置的悬停时间更长时按设置），划过的图标不切换；以前悬停时间为 0（默认）时，从左往右划过去会把经过的每一页都打开一遍，每次都重排页面、改原生窗口大小、重启岛的宽高动画，划到目标时还卡在上一条的 0.45 秒等待里不动。岛还在改宽度时移到的图标不再被丢掉，等岛停稳后若光标仍在那个图标上就切过去。（用户反馈：左上角图标悬停切换卡顿）

## 图标按钮的悬停名称（2026-11-13）

- 岛上只有图标的按钮（顶部页面图标、右上角圆按钮、消息页工具栏、各页里只有图标的按钮），光标停约 0.4 秒后在按钮下方显示它的名称；下方超出岛时改到上方。键盘聚焦（`:focus-visible`）时立即显示；移开、按下、滚动、按 Esc 或岛失焦时收起。样式和用量环的悬停卡片一样（`.island-hover-card`：岛底色、圆角 12、12px 字），会被指针挡住时避到指针旁边。（用户要求 C56：不用原生 `title`，用岛风格）
- 名称取按钮的 `aria-label`（带快捷键的显示成「待办 (Alt+2)」这样，和读屏一致）；按钮写了 `data-tooltip` 时显示它（新消息弹出页的「清除提醒」用它放较长的说明）。带文字的按钮（文字只是数字角标的除外）、写了原生 `title` 的、已经有悬停卡片的（用量环、会话环）不显示。只挂在主窗口的岛上（`IconButtonTooltip`，`src/components/`），设置和剪贴板窗口不变。
- 整块可点的区域不显示悬停名称：收起的岛本身（原来显示「Fuyu，点击展开」）、展开后顶部栏中间收起岛屿的空白处和收起条右端的收起灰点（原来都显示「收起岛屿」）。它们不是图标按钮，光标只是路过或停在岛上，弹出名称是打扰。做法是按钮上写空的 `data-tooltip=""`，`aria-label` 照旧留给读屏。（用户要求 2026-11-13）

## 侧边吸附（C54.1，2026-11-13）

- 拖到显示器左边或右边 16 逻辑像素以内时吸住；只认外侧的边，两块屏幕之间共享的边不吸。侧边任务栏按工作区算，和顶边一样。（Agent 推断）

- 多显示器跟随时保持吸在哪条边和比例位置；跟到的屏幕在那一侧挨着别的屏幕时，退回顶边。（用户确认）
