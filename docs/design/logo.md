# 标志：水母

更新：2026-11-20（应用图标、菜单栏、托盘、岛上、关于页和 README 都已换）

浮屿的标志是一只宽头、四瓣触手、没有光环的小水母（issue #281）。它同时是应用图标、Mac 菜单栏图标，以及岛上收起条左边常驻的「浮屿水母」（开着 Agent 时随状态变色、做动作）。状态、动效和各种尺寸的预览在 `pnpm logo` 打开的 [jellyfish-set-preview.html](../investigations/jellyfish-set-preview.html)。

## 颜色

应用图标（深海）：

| 用处 | 颜色 |
|---|---|
| 底色 | `#03101F` |
| 光斑 | `#00C2FF`（左下）、`#2D5BFF`（右）、`#7A3DFF`（右上）、`#00FFC8`（左上，弱） |
| 水母身体 | 渐变 `#DFF6FF` → `#6CC4FF`，外发光 `#6FD0FF` |
| 眼睛 / 腮红 | `#0E2340` / `#FF7FA5` |

岛上状态灯（身体颜色随状态变，眼睛 `#1D1B22`，腮红 `#FF8FA0`）：

| 状态 | 代码里的 phase | 颜色 |
|---|---|---|
| 空闲 | `idle` | `#F6E3D3` |
| 运行中 | `running` | `#6DB6F4` |
| 压缩上下文 | 会话的 `compacting` | `#6DB6F4`（和运行中一样） |
| 等你 | `waiting` | `#FFCD3C` |
| 出错 | `failed` | `#F2554C` |
| 完成 | `completed` | `#5ED69E` |
| 可能中断 | `stale` | `#A9ADB8`，浅色岛上 `#8F93A0` |

水母组件的状态（`JellyMood`）是 `idle`、`running`、`waiting`、`failed`、`done`、`sleep`、`stale`、`compacting` 八个，矢量和像素画风都画全了。可能中断：灰色，小点眼、平嘴，歪着，右上角弹出一个问号后停住。压缩上下文：挤眼、平嘴，身体拉长、还原、压扁、还原（1.44 秒一轮），拉长时两边有往里挤的箭头（2026-11-23，用户看过像素预览页后要求接进产品）。

图标里的水母是蓝色，岛上空闲时是米白，这是有意的：图标要在深色炫彩底上亮，岛上空闲要安静。

## 像素画风

岛上的水母可以换成六种像素画风（C177，issue #1229），在 设置 → 岛屿布局 →「浮屿水母」的「水母画风」里选，默认仍是矢量。设置项是 `fuyu-settings` 里的 `jellyfishStyle`（`vector`、`flat`、`sticker`、`mono`、`neon`、`chunky`、`fine`），随设置同步。Mac 菜单栏上的图标跟着变（见下面「菜单栏图标」）；应用图标、Windows 托盘图标和 README 不跟着变。造型、状态和逐帧动作的预览在 [jellyfish-pixel-preview.html](../investigations/jellyfish-pixel-preview.html)。

| 画风 | 取值 | 格子 | 上色 |
|---|---|---|---|
| 扁平 | `flat` | 17×12 | 无描边，头顶一点高光，触手压一层暗部 |
| 描边 | `sticker` | 17×12 | 边缘一圈同色系的深色 |
| 单色 | `mono` | 17×12 | 只用身体色，眼睛和嘴镂空，没有腮红 |
| 霓虹 | `neon` | 17×12 | 只画轮廓，里面透一点身体色，外面一圈半透明的光（画成像素，不用模糊） |
| 大颗粒 | `chunky` | 11×8 | 和扁平一样上色，触手是四条小腿 |
| 精细 | `fine` | 33×24 | 圆眼睛，暗部用抖动过渡，边缘压深一档 |

- **一处选、处处变**：收起条状态灯、中心图案的「水母」、Fuyu 页签图标、Agent 空页面、今日小组件都调 `JellyfishMark`，它按画风分流（`src/components/jellyfish/`，像素部分在 `pixel/`）。画风经 `JellyfishStyleContext` 从岛窗口和设置窗口的根上传下来，没提供时是矢量。
- **按物理像素对齐**：每格取整数个物理像素，在原来 58:43 的占位里居中，最宽多出不到 2 像素，岛的宽度计算不变。占位高度除不尽时取最接近的整数倍，最多比占位大四分之一；Windows 缩放 125%、175% 时往小取，24 像素的占位里画成约 19、21 像素高（用户选定：清晰比大小重要）。占位小到放不下自己的格子时换粗一档的格子（精细在 16 像素的图标位上用 17×12 那套）。规则在 `pixel/pixelFit.ts`。
- **颜色**：身体色读的是矢量版同一组变量（`--center-jelly-fill`），浅色岛上空闲换成暖米色并补一圈棕边；单色在浅色岛上整体压深。霓虹在浅色岛上不画外面那圈半透明的光（浅底上只会把轮廓冲淡），轮廓往墨色压 36%（C179）。主题把状态色写成 `oklch()`、`color-mix()` 这类写法也认：`rgb()` 直接解析，别的交给浏览器在 1 像素的画布上算一次并记住。
- **动作**：逐帧，120ms 一拍，整格位移。空闲 5.8 秒眨一次眼、10 秒游一下；运行前倾、四瓣触手依次收起（0.96 秒一轮）；等你歪头跳两下停一下、感叹号跟着闪（2.4 秒一轮）；失败压扁晃两下、怒气符号鼓两下后停；完成上浮两格落回、星星先后弹出后停；睡着闭眼、触手 4.8 秒收放一次；可能中断歪着、小点眼，问号弹出来后停；压缩上下文挤眼，头拉高一格、还原、压扁、还原（1.44 秒一轮），拉高时两边各一个往里的箭头。切状态时颜色分三拍换过去。
- **省电**：所有像素水母共用一个定时器（`pixel/pixelClock.ts`），只在下一帧该变的时刻醒；空闲时几秒才醒一次，失败和完成播完就不再醒。`paused`（贴边收起、展开、窗口隐藏）时停在当前帧，系统要求减少动画时显示静止帧。
- **小尺寸**：Agent 列表里 12 像素、页签图标 16 像素也按同一条规则取格子。只有大颗粒在缩放 100%、12 像素的占位里画成 8 像素高（放大一档是 16 像素，会撑出占位），别的缩放比例下是 11–13 像素。
- **换屏幕**：除了占位大小和窗口大小变化，还监听缩放比例本身（`matchMedia("(resolution: …dppx)")`），岛拖到另一块缩放不同的屏幕上会按新的比例重画。
- **睡着的 z**：Agent 空页面水母旁边飘的 z，像素画风下换成 4×4 格的方块 z（`AgentEmptyState.tsx`），矢量画风不变。
- **设置里的卡片**：平时画空闲的静止帧；鼠标停在卡片上或键盘聚焦时，按 运行、等你、完成、失败、可能中断、压缩上下文 的顺序每 1.6 秒换一个状态并播动作，移开回到空闲。
- **互动**（C179，矢量和像素画风都有）：只在面板里的水母上开（Agent 空页面、今日小组件，`JellyfishMark` 的 `lively`），收起条上的不开，那里的点击是展开小岛。点一下：空闲的开心一下（演「完成」），睡着的惊醒（演「等你」），1.6 秒后回到原样；正在演 Agent 状态的不理。空闲时眼睛朝鼠标挪一格（像素画风挪一格，矢量挪 2.6 个单位，26 像素高的水母上约 1.5 像素、46 像素高的约 2.8 像素），鼠标在水母身上或离开窗口时回正。只听窗口里的鼠标事件，不向系统要全局鼠标位置，鼠标在窗口外时它不知道。系统要求减少动画时两样都不做。判断写在 `src/components/jellyfish/jellyLively.ts`，接线在 `useLivelyJelly.ts`。
- **深夜打瞌睡**（`fuyu-settings` 里的 `jellyfishNightDoze`，默认关，随设置同步）：打开后，本机时间 23 点到 6 点、没有会话在运行、等你、出错、可能中断，也没有刚结束的会话时，收起条上的水母（状态灯和中心图案的「水母」）演「睡着」；有会话动了马上醒。到 23 点和 6 点各用一个定时器切换，不轮询。默认关是因为它让收起条的样子跟着钟点变，用户没要求过；中心图案选的是宠物时睡着按空闲画。
- **跟着预设和主题走**（C179）：样式预设「保存当前」时记下当时的画风，套用这个预设时画风一起换；导出成主题文件、再导入时也带着。主题市场的主题可以在 `appearance` 里写 `jellyfishStyle` 指定画风。没带画风的（这之前存的预设、现有的市场主题、别人没写这个字段的主题文件）套用时不动你选的画风：预设里存的是整份设置，老预设读出来画风会补成默认的矢量，所以画风单独记在预设上，不从那份设置里取。「恢复默认主题」不改画风。带画风的预设，卡片的小岛缩略图上把圆点换成那种画风的水母，名字下面写一行「水母画风：某某」；没带的还是圆点、不写这一行，这样启用前就知道它会不会换画风。字段见 `docs/architecture/contracts.md`。（Agent 推断，用户同意「主题预设带上画风」时没定老预设怎么办）
- **菜单栏图标**（C179，只在 Mac 上）：选了像素画风后，菜单栏上的水母换成像素的，选回矢量换回原来的剪影。菜单栏图标是单色模板图（系统按菜单栏深浅着色），所以只分得出三种样子：扁平、描边、单色、精细都是 17×12 格的剪影、眼睛挖空，每格 3 个物理像素；大颗粒是 11×8 格、每格 4 个物理像素；霓虹是一圈轮廓、里面很淡、眼睛实心，不画腮红。精细的 33×24 格在 36 像素高的图里只能每格 1 像素、画出来只有 24 像素高，所以改用 17×12 格。图是 52×36 像素（26×18 点的两倍），在非 Retina 屏上系统会把它缩小一半，格子边缘会糊。位图由前端的 `pixel/trayMark.ts` 画好交给 Rust（命令 `set_tray_mark`），Rust 把最后一次收到的位图存在数据目录的 `tray-mark.bin`，下次启动建菜单栏图标时直接用它，不会先闪一下矢量剪影；选回矢量时删掉这个文件。文件和设置对不上时（比如设置是从别的电脑同步来的），岛读到设置后会再发一次纠正。
- **Windows 托盘不跟着换**（Agent 评估后没做）：托盘图标在缩放 100% 时是 16 像素见方，17 格宽的水母放不下；Tauri 只收一张图，125%、150% 时由系统缩放，格子落不到整像素上会糊；托盘上现在用的是彩色应用图标，换成水母等于换了托盘上的标识。要做得给每档缩放各画一张并按任务栏所在屏幕的缩放换图，这台 Mac 上也验不了，所以留着没做。
