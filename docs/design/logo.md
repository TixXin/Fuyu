# 标志：水母

更新：2026-11-20（应用图标、菜单栏、托盘、岛上、关于页和 README 都已换）

浮屿的标志是一只宽头、四瓣触手、没有光环的小水母（issue #281）。它同时是应用图标、Mac 菜单栏图标，以及岛上收起条左边常驻的「浮屿水母」（开着 Agent 时随状态变色、做动作）。状态、动效和各种尺寸的预览在 `pnpm logo` 打开的 [jellyfish-set-preview.html](../investigations/jellyfish-set-preview.html)。

## 颜色

应用图标（深海）：

| 用处 | 颜色 |
|---|---|
| 底色 | `#03101F` |
| 光斑 | `#00C2FF`（左下）、`#2D5BFF`（右）、`#7A3DFF`（右上）、`#00FFC8`（左上，弱） |
| 水母身体 | 渐变 `#DFF6FF` → `#6CC4FF`，外发光 `#6FD0FF` |
| 眼睛 / 腮红 | `#0E2340` / `#FF7FA5` |

岛上状态灯（身体颜色随状态变，眼睛 `#1D1B22`，腮红 `#FF8FA0`）：

| 状态 | 代码里的 phase | 颜色 |
|---|---|---|
| 空闲 | `idle` | `#F6E3D3` |
| 运行中 | `running` | `#6DB6F4` |
| 压缩上下文 | 会话的 `compacting` | `#6DB6F4`（和运行中一样） |
| 等你 | `waiting` | `#FFCD3C` |
| 出错 | `failed` | `#F2554C` |
| 完成 | `completed` | `#5ED69E` |
| 可能中断 | `stale` | `#A9ADB8`，浅色岛上 `#8F93A0` |

水母组件的状态（`JellyMood`）是 `idle`、`running`、`waiting`、`failed`、`done`、`sleep`、`stale`、`compacting` 八个，矢量和像素画风都画全了。可能中断：灰色，小点眼、平嘴，歪着，右上角弹出一个问号后停住。压缩上下文：挤眼、平嘴，身体拉长、还原、压扁、还原（1.44 秒一轮），拉长时两边有往里挤的箭头（2026-11-23，用户看过像素预览页后要求接进产品）。

图标里的水母是蓝色，岛上空闲时是米白，这是有意的：图标要在深色炫彩底上亮，岛上空闲要安静。

## 像素画风

岛上的水母可以换成六种像素画风（C177，issue #1229），在 设置 → 岛屿布局 →「浮屿水母」的「水母画风」里选，默认仍是矢量。设置项是 `fuyu-settings` 里的 `jellyfishStyle`（`vector`、`flat`、`sticker`、`mono`、`neon`、`chunky`、`fine`），随设置同步。应用图标、托盘、菜单栏和 README 不跟着变。造型、状态和逐帧动作的预览在 [jellyfish-pixel-preview.html](../investigations/jellyfish-pixel-preview.html)。

| 画风 | 取值 | 格子 | 上色 |
|---|---|---|---|
| 扁平 | `flat` | 17×12 | 无描边，头顶一点高光，触手压一层暗部 |
| 描边 | `sticker` | 17×12 | 边缘一圈同色系的深色 |
| 单色 | `mono` | 17×12 | 只用身体色，眼睛和嘴镂空，没有腮红 |
| 霓虹 | `neon` | 17×12 | 只画轮廓，里面透一点身体色，外面一圈半透明的光（画成像素，不用模糊） |
| 大颗粒 | `chunky` | 11×8 | 和扁平一样上色，触手是四条小腿 |
| 精细 | `fine` | 33×24 | 圆眼睛，暗部用抖动过渡，边缘压深一档 |

- **一处选、处处变**：收起条状态灯、中心图案的「水母」、Fuyu 页签图标、Agent 空页面、今日小组件都调 `JellyfishMark`，它按画风分流（`src/components/jellyfish/`，像素部分在 `pixel/`）。画风经 `JellyfishStyleContext` 从岛窗口和设置窗口的根上传下来，没提供时是矢量。
- **按物理像素对齐**：每格取整数个物理像素，在原来 58:43 的占位里居中，最宽多出不到 2 像素，岛的宽度计算不变。占位高度除不尽时取最接近的整数倍，最多比占位大四分之一；Windows 缩放 125%、175% 时往小取，24 像素的占位里画成约 19、21 像素高（用户选定：清晰比大小重要）。占位小到放不下自己的格子时换粗一档的格子（精细在 16 像素的图标位上用 17×12 那套）。规则在 `pixel/pixelFit.ts`。
- **颜色**：身体色读的是矢量版同一组变量（`--center-jelly-fill`），浅色岛上空闲换成暖米色并补一圈棕边；单色和霓虹在浅色岛上整体压深。
- **动作**：逐帧，120ms 一拍，整格位移。空闲 5.8 秒眨一次眼、10 秒游一下；运行前倾、四瓣触手依次收起（0.96 秒一轮）；等你歪头跳两下停一下、感叹号跟着闪（2.4 秒一轮）；失败压扁晃两下、怒气符号鼓两下后停；完成上浮两格落回、星星先后弹出后停；睡着闭眼、触手 4.8 秒收放一次；可能中断歪着、小点眼，问号弹出来后停；压缩上下文挤眼，头拉高一格、还原、压扁、还原（1.44 秒一轮），拉高时两边各一个往里的箭头。切状态时颜色分三拍换过去。
- **省电**：所有像素水母共用一个定时器（`pixel/pixelClock.ts`），只在下一帧该变的时刻醒；空闲时几秒才醒一次，失败和完成播完就不再醒。`paused`（贴边收起、展开、窗口隐藏）时停在当前帧，系统要求减少动画时显示静止帧。
- **还没做的**：Agent 空页面水母旁边的 z 仍是矢量画的。
