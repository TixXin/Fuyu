## 说明

正式版 0.3.10 收起闲置时，Rust 主进程 `fuyu.exe` 一直占约 17–21% 单核，暂停前端全部动画也不降（2026-11-06 [idle-usage.md](/docs/investigations/idle-usage.md) 量的是 4.9%，那时没装插件、没开 cc-connect 和 SSH 隧道）。按线程看，CPU 平均分在 7 个没有名字的线程上（同一个启动地址，像 Windows 线程池），不是我们用 `Builder::name` 起的线程。

源码里常驻的短间隔轮询只有鼠标穿透循环（`island/passthrough.rs`，12 ms）；快捷键和剪贴板监听是窗口消息驱动，10 ms 的循环只在线程退出时等待用。所以 20% 的大头还要定位。

做法：
1. 用带符号的本地构建（按 [idle-usage.md](/docs/investigations/idle-usage.md) 的测法，单独身份运行，装上同样的插件、隧道、cc-connect）采样，找出线程池里在跑的模块。
2. 按结果放慢或合并：能改成事件驱动的改事件驱动；穿透循环在光标离岛很远时放慢，靠近时保持 12 ms，不影响移入时的反应。

## 验收

- 列出主进程闲置 CPU 的来源和各自占比。
- 改完后收起闲置时主进程 CPU 有前后对比。
- 鼠标移进岛、悬停展开、Alt 拖动的手感不变。
- Rust 单元测试和 `pnpm build:exe` 通过。
