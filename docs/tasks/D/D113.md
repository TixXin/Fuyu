## 说明

消息设置页重做（D111，提交 1343ccb50）只在浏览器回归页里看过，没在真岛和 Windows 上跑过。没测到的几条合在这里，由用户在真机上测。

已经确认的：开发版岛（Mac）经实验台端口收到 `message-sample-requested` 事件，前端错误日志里没有新报错；岛侧读错文案分区的报错在修复后没有再出现。没看到岛的画面，示例消息弹没弹出来要人眼确认。

#### Mac（开发版或含 D111 的构建）

1. 设置 → 消息 → 提醒方式：把「新消息提示」依次选成三种方式，每种都点一次「在真岛上试一下」。应该看到：岛上按当前方式弹出一条「示例消息 / 新消息会像这样出现在岛上」，按钮旁短暂出现「已发到岛上」。
2. 系统设置里关掉浮屿的辅助功能权限，再开设置 → 消息 → 来源。应该看到：汇总条下面只出一条提示（不是每个来源各一条），点它的按钮能打开系统设置的辅助功能页。
3. 从岛上邮箱面板点设置、从新手引导里点邮箱。应该看到：设置窗口落在「来源」，并滚到邮箱那一行。
4. 老数据：升级前把某一个来源的「看过后从岛上去掉」关掉过的数据目录，升级后提醒方式页里合并后的那一个开关是关的；本来都开着的，升级后是开的。

#### Windows（含 D111 的构建）

5. 同第 1 条，「在真岛上试一下」三种方式各试一次。
6. QQ / Telegram 等缺通知权限时：来源页那一行开关左边出现「授权」或「打开 Windows 通知设置」，点了能走通。
7. 微信开着时：微信那一行下面「显示联系人和消息摘要」「隐藏任务栏按钮」两行还在，能切换，切换后行为和重做前一样。
8. 「更多聊天软件」：没装的软件收在折叠里，展开后打开某一个，它留在折叠里不跳走；装了的直接列在外面。
