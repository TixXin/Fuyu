## 说明

展开面板后，面板四周出现一圈阴影，阴影外侧还有一块透出来的半透明黑色区域。群友附的截图只截到面板右侧边缘：面板圆角外有一条深色半透明带。之前修过「任务栏模式下阴影压暗」（#1244），这次是普通展开面板时的边缘问题。

- 类别：问题
- 平台：Windows（同一位群友，用的是液态玻璃「流彩毛玻璃」一类主题，待确认）
- 群里反馈：2026-11-27，1 人提到 3 次（浮汐 FB-38）

待补：

- 完整截图（整个面板加周围桌面）、当前外观主题和材质、系统版本
- 可能和 Windows 液态玻璃透出（#933、#1276）或面板窗口比内容大的透明画布有关，待核实

## 验收

- 默认主题和各液态玻璃主题下，展开面板四周没有多余的黑边或透出的暗色区域，阴影只在设计范围内
- 收起、展开、贴边收起来回切换后边缘仍然干净
