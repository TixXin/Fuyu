## 说明

[D97](/docs/tasks/D/D97.md) 子任务 2，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 中的 **P0-2（主岛折叠态面板休眠）** 与 **P1-2（主岛剪贴板面板虚拟滚动与 FLIP 限流）**：

1. **主岛折叠态（`mode === "collapsed"`）下停止隐藏展开面板的后台空转（P0-2）**：
   - 主岛折叠时 `.island__expanded` 仅设置 `opacity: 0; pointer-events: none;`，而主岛窗口本身始终可见（`document.visibilityState === "visible"`），导致 `useVisibilityInterval` 不会暂停：上次打开音乐页时歌词（200ms）+ 进度条（500ms）每秒空转 7 次；上次打开 Agent 页时每个运行中会话每秒触发重渲染并执行隐藏 DOM 的 FLIP 测量；上次打开剪贴板页时每次复制都重排数百行隐藏节点。
   - 在 [IslandShell.tsx](/src/windows/island/IslandShell.tsx) / [IslandPages.tsx](/src/windows/island/IslandPages.tsx) 中，当主岛处于折叠态且不在展开预备或收起过渡动画期间时，卸载或休眠展开面板子树，确保隐藏态零定时器空转且开合过渡依然丝滑。
2. **主岛剪贴板面板虚拟滚动与 FLIP 限流（P1-2）**：
   - [ClipboardHistoryPanel.tsx](/src/features/clipboard/ClipboardHistoryPanel.tsx) 接入虚拟滚动（复用 `useVirtualRows` 或视口窗口化挂载），避免 500 条历史全量挂载 8,000+ DOM 节点；
   - [ClipboardHistoryItemRow.tsx](/src/features/clipboard/ClipboardHistoryItemRow.tsx) 使用 `React.memo` 包裹并稳定化回调引用，缩略图 `<img>` 增加 `loading="lazy" decoding="async"`；
   - [useClipboardHistoryList.ts](/src/features/clipboard/useClipboardHistoryList.ts) 将同步 `getBoundingClientRect()` FLIP 测量限制在视口可见的前 20 项以内，同步把 `loadPinyin` 收紧为仅含英文字母词时触发。

## 验收

- 主岛处于折叠态且收起动画结束后，展开面板内的定时器（歌词、音乐进度、会话计时器等）与隐藏 DOM FLIP 测量均不运行；再次展开主岛时内容正常渲染且开合动效无闪烁
- 主岛剪贴板面板在数百条记录下仅挂载视口附近的 DOM 节点，`ClipboardHistoryItemRow` 在无关项更新时不重渲染
- `pnpm check`、`pnpm build` 与 `pnpm test:regression` 通过
