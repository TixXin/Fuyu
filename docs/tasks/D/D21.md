## 说明

会话列表一行的预览变了、或者这一行移到最上面，就会被当成新消息；手机发出、电脑同步过来的消息（未读数仍是 0）也会弹提醒，内容是自己刚发的那条。见 issue #40。

## 验收

- 已有的一行预览变了、未读数没有增加时不算新消息；移到顶部但未读数是 0 的也不算
- `new_messages` 有回归用例：before「对方: 在吗」未读 0，now「我: 在」未读 0，返回空
- docs/features/wechat-reminders.md 写清楚判断规则

## 交接

- 2026-11-12 14:12 lane 18：已核实：除了 changed() 只比预览，new_messages() 的 moved_up（移到未置顶最前面）也会把手机发出的消息算进去。难点：moved_up 本来是为未读数不增加的收到消息准备的（多半是微信里正打开着的那个聊天），只看未读数会把它漏掉，退回只显示「有新提醒」。已在 #40 问报告人；等用户/报告人实测微信最小化且停在该聊天时未读数会不会增加，再定是只看未读数，还是另外读 UIA 选中行区分正打开的聊天。
