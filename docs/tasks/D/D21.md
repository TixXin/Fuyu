## 说明

会话列表一行的预览变了、或者这一行移到最上面，就会被当成新消息；手机发出、电脑同步过来的消息（未读数仍是 0）也会弹提醒，内容是自己刚发的那条。见 issue #40。

## 验收

- 已有的一行预览变了、未读数没有增加时不算新消息；移到顶部但未读数是 0 的也不算
- `new_messages` 有回归用例：before「对方: 在吗」未读 0，now「我: 在」未读 0，返回空
- docs/features/wechat-reminders.md 写清楚判断规则
