## 说明

- `fuyu_home()` 按顺序找：环境变量 `FUYU_HOME`，`%APPDATA%\com.tixxin.fuyu\home.json` 里记的路径，`~/.fuyu`。指针文件留在固定位置，不放进家目录。
- 迁移照 `rename_migration` 的结构：复制 `%APPDATA%\com.tixxin.fuyu\` 到家目录（旧目录保留）；待办 Markdown 目录是空的或等于旧默认 `Documents/FocuSD` 时改成 `FUYU_HOME/todo` 并复制 `.md`；重装 Claude Code / Codex 钩子，命令里带上 `FOCUSD_AGENT_STATUS_DIR`；进度记在 `FUYU_HOME/home-migration.json`，每步只做一次。
- 旧位置继续写一份 `local-api.json`（给已发布的 `fuyu-plugin`），新版 CLI 先找家目录。
- 设置里改家目录：新位置是空的就复制，已经有浮屿数据就直接用；重启生效并重装钩子；旧目录不删。
- 家目录里放锁文件，另一台电脑在用时提示并拒绝。
- lane 预览用自己的家目录；`pnpm dev:lane --fresh` 跟着改。
- 远程电脑的钩子核对 `agent_status/remote_setup.rs`。
