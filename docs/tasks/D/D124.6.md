## 说明

补齐 Windows 侧托盘隐藏主岛 `SetIsVisible(false)` 联动与 WinRT OCR 短命子进程隔离，对齐 macOS 内存治理架构，并留下 Windows 真机实测清单。详见 [内存优化方案](/docs/architecture/memory-optimization-plan.md)。

## 验收

- 主岛隐藏到托盘时同步 WebView2 `SetIsVisible(false)`，恢复显示时设为 `true`。
- Windows OCR 经 `--fuyu-ocr` 短命子进程执行，防止 WinRT 模型滞留主进程。
- 双平台编译检查与单元测试通过，Windows 实测项记入实测清单。
