## 说明

岛展开后收回时，没有回弹到原来的长度，停在一个很长的收起条上。群友说这个问题之前就报过，到现在还没修好。附图是收起条：左边水母，中间音符加歌名「【STN快报…」，右边音频跳动条、一个同心圆图标和蓝色未读数「1」，整条比平时长很多。

- 类别：问题
- 平台：未说明
- 群里反馈：2026-11-26，1 人提到 2 次（浮汐 FB-25）

待补：

- 复现步骤：从什么状态展开、怎么收回（移开鼠标 / 点击 / 快捷键）、多久不恢复
- 系统和版本；是不是只在播放音乐、有未读消息时出现

## 验收

- 展开后收回，收起条回到按当前内容算出的宽度，不停在展开过程中的长度
- 有音乐标题、未读数时收起条宽度符合设计，不会一直保持过长
