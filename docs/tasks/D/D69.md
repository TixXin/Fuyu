## 说明

排查记录见 [dev-island-issues.md](/docs/investigations/dev-island-issues.md) 第 2 节。结合当前 `HEAD`（含 `D97.2` 折叠态卸载子树）与 `wry`/`tao` 源码审查，已定位到三处具体根因并待在途 `C77` 释放 `src/windows/island/` 与 `src-tauri/src/island/` 后落地：

1. **隐藏窗口期无效预热 + 首次展开 Frame 0 同步冷挂载尖峰**：`useIslandPreparing` 在 `main` 窗口仍处于 `visible: false`（`SW_HIDE`）时跑完 `isPreparing` 并卸载 `<IslandPages />`，导致首次展开在 Frame 0 同时启动外壳过渡与冷挂载整棵业务面板（实测 GPU 光栅化 177–233ms），吞掉前 120ms `fadeDelay` 并在合成器超时或反色渐变时露出浅色/空白过渡帧。改法：等窗口 `show_ready_island` 可见后再做短暂预光栅化；折叠态收到 `onPointerEnter`/`onPointerDown` 提前预挂载 `<IslandPages />`；快捷键/消息冷展开采用 `1-rAF` 外壳先行，在 `120ms` 面板透明窗口期的第 1 帧再挂载内容。
2. **插件子 WebView2 漏设透明创建选项且导航前提前显示**：[webview_page.rs](/src-tauri/src/win32/webview_page.rs) 创建控制器前未通过 `ICoreWebView2ControllerOptions3::SetDefaultBackgroundColor` 设 `(0,0,0,0)`，且 [webviews.rs](/src-tauri/src/plugin_host/webviews.rs) 在 HTML 导航完成前立即 `SetIsVisible(true)` 露出纯白 `#FFFFFF` 底色。改法：补齐 `Options3` 全透明底色并在首帧导航完成后再显示控制器。
3. **`glass.rs` 遗留死代码强制擦除重绘**：[glass.rs](/src-tauri/src/island/glass.rs) 首次同步仍调用早已废弃的 `clear_acrylic` 与 `SetWindowRgn(hwnd, None, true)`（`bRedraw = true` 同步擦除重绘整个 HWND），直接清理该死代码。

## 验收

- 插件子 WebView2 以全透明默认背景创建且导航就绪后再显示，无纯白底闪现
