## 说明

[D97](/docs/tasks/D/D97.md) 子任务 6，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 中的 **P0-1 剪贴板部分**、**P1-3 v2 插件线程懒启动** 与 **P1-4 剪贴板缩略图协议化**（主岛窗口提前初始化与 `file_shelf` 懒加载已由 [D96](/docs/tasks/D/D96.md) 负责，本任务不改 `lib.rs` 与 `file_shelf/mod.rs`）：

1. **剪贴板预览窗口 `clipboard-preview` 按需懒创建 + 历史文件异步加载（P0-1）**：
   - [background.rs](/src-tauri/src/clipboard_history/background.rs)：不在启动时同步预建 `clipboard-preview` 隐藏窗口（省去 1 个常驻 WebView 进程 ~40–70 MB），改为按空格预览时按需创建、关闭或空闲超时后销毁；`clipboard` 主窗口延后至首帧就绪后后台预热或按需创建；
   - [clipboard_history/mod.rs](/src-tauri/src/clipboard_history/mod.rs)：将 `clipboard-history.json`（可达 2–15 MB）的反序列化移出 `setup()` 主线程，孤儿图片清理只传文件名集合 `HashSet<String>`，消除全量 `items.clone()`。
2. **已冻结的 v2 `plugin_host` 5 个常驻线程按需懒启动（P1-3）**：
   - [plugin_host/mod.rs](/src-tauri/src/plugin_host/mod.rs) 与 [events.rs](/src-tauri/src/plugin_host/events.rs)：未开启第三方插件且无已启用 v2 插件时不启动 `system-events`、`system-idle`、`plugin-hotkeys`、`plugin-lifecycle`、`plugin-updates` 5 个常驻线程；`events::publish` 无活跃订阅者时直接返回，不再每次 `thread::spawn` 短命睡眠线程（遵守 v2 冻结规则，不加新接口）。
3. **剪贴板缩略图接入 `fuyu-clip://` 协议与 IPC 瘦身（P1-4）**：
   - 扩展 [image_protocol.rs](/src-tauri/src/clipboard_history/image_protocol.rs) 支持读取磁盘已有的 `<hash>-thumb.png` 缩略图，兼容旧条目的内联 Base64 缩略图，新条目不再通过 IPC 快照重复传输 MB 级 Base64 字符串（若调整前端图片地址解析，认领时同步把对应前端文件加入 `scope`）。

## 验收

- 应用启动后未按空格预览前不创建 `clipboard-preview` 窗口；按空格预览、切换条目与关闭回收正常
- `setup()` 主线程不再同步反序列化 `clipboard-history.json` 或克隆全量 `items`
- 默认未启用 v2 第三方插件时，5 个 `plugin_host` 后台线程不启动，`events::publish` 零多余线程派生
- 剪贴板缩略图经 `fuyu-clip://` 正常加载且兼容历史数据，`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与 Windows CI（`pnpm mq:try --wait`）通过
