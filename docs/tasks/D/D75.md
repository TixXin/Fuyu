## 说明

D73 留下的实测清单，要在 Windows 那台机器上做。D73 让运行器被杀掉时不留无头 Chrome 和 Vite（Chrome 用 `--remote-debugging-pipe`，Vite 在运行器进程里跑），Mac 上四种信号都测过；Windows 上只有 CI 的 `regression` 跑通（运行 43760071014），强行结束后的情况没测。

1. 跑 `pnpm test:regression`，等它开始打印页面结果。
2. 在任务管理器（或 `Stop-Process`）里结束命令行是 `node scripts/run-regression.mjs` 的 node 进程。
3. 几秒后 `Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*fly-regression*' }` 应该是空的。
4. 再跑一次，中途按 Ctrl-C，同样查一遍；这一次 `%TEMP%\fly-regression-*` 目录也应该被删掉。

## 验收

- 两种结束方式下都没有留下命令行带 `fly-regression` 的 chrome.exe / msedge.exe。
- 有残留就在 issue 里贴进程列表，再改 `scripts/run-regression.mjs`。
