## 说明

把浮屿打成 MSIX 上架 Microsoft Store，做法照 Snow Shot：交一个不签名的 MSIX，由商店签名后分发；官网的 NSIS 安装包照旧保留，两个渠道并存。调研见 [microsoft-store-msix.md](/docs/research/microsoft-store-msix.md)，做法和打包、本地测试、提交步骤见 [microsoft-store.md](/docs/features/microsoft-store.md)。

为什么：从商店装的版本由微软签名，没有 SmartScreen「未知发布者」，也不用证书费。这不替代安装包签名，官网下的 exe 仍走 D114 里的 SignPath。

按顺序做：

1. ~~钩子共享文件挪到 `~\.fuyu`~~：不用做。D30.3 起数据已经在家目录 `%USERPROFILE%\.fuyu`，MSIX 不重定向它，钩子命令也不调用 `fuyu.exe`。
2. **商店渠道的开关**：同一个 `fuyu.exe`，运行时认出自己在 MSIX 包里时关掉内置更新、开机自启改用 `windows.startupTask`、不跑改名迁移。
3. **MSIX 打包脚本**：清单模板、名称资源、MakeAppx / MakePri；本地用自签证书签一份测试副本。
4. **两个版本共存**：共用家目录，家目录的锁让它们不能同时运行；`localStorage` 和应用数据目录不共用。
5. **提交**：Partner Center 保留名字、中英文隐私政策、分级问卷、`runFullTrust` 的用途说明，上传。

## 验收

- 商店版装好后：岛、剪贴板、截图、翻译、媒体、通知、任务栏这些功能正常；AI 代理钩子装好后状态灯能亮
- 设置里开机自启开关在商店版上生效，被系统或策略关掉时界面如实显示
- 商店版没有自更新入口，更新由商店推送
- 安装版行为不变
- `docs/architecture/data-storage.md`、`contracts.md`、`platforms.md` 写明商店版的数据位置和差异
- 在 Microsoft Store 能搜到并安装
