## 说明

把浮屿打成 MSIX 上架 Microsoft Store，做法照 Snow Shot：交一个不签名的 MSIX，由商店签名后分发；官网的 NSIS 安装包照旧保留，两个渠道并存。调研见 [microsoft-store-msix.md](/docs/research/microsoft-store-msix.md)。

为什么：从商店装的版本由微软签名，没有 SmartScreen「未知发布者」，也不用证书费。这不替代安装包签名，官网下的 exe 仍走 D114 里的 SignPath。

按顺序做：

1. **钩子共享文件挪到 `~\.fuyu`**：hook 脚本、`agent-status.json`、运行标记现在在 `%APPDATA%\com.tixxin.fuyu`，MSIX 会把应用新写的 AppData 文件重定向到包的私有目录，外部的 Claude Code 等就读写不到。挪到 `~\.fuyu`（Mac 已经这样），旧位置兼容读取，安装版也一起改。
2. **商店渠道的构建开关**：商店版不带 updater、关掉检查更新入口；开机自启用 MSIX 的 `windows.startupTask`，设置里的开关读写它（安装版仍写注册表 `Fuyu`，契约不变）；不跑改名迁移。
3. **MSIX 打包脚本**：清单模板（`runFullTrust`、`packagedClassicApp`、startupTask、需要的设备能力）、图标资源、MakeAppx / MakePri；本地用自签证书签一份测试副本。
4. **两个版本共存**：商店版和安装版数据不是同一份，做一次导入或明确说明二选一；同时装时单实例和快捷键要互相检测。
5. **提交**：Partner Center 保留名字、中英文隐私政策、分级问卷、`runFullTrust` 的用途说明，上传。

## 验收

- 商店版装好后：岛、剪贴板、截图、翻译、媒体、通知、任务栏这些功能正常；AI 代理钩子装好后状态灯能亮
- 设置里开机自启开关在商店版上生效，被系统或策略关掉时界面如实显示
- 商店版没有自更新入口，更新由商店推送
- 安装版行为不变，旧位置的钩子文件能迁移
- `docs/architecture/data-storage.md`、`contracts.md`、`platforms.md` 写明商店版的数据位置和差异
- 在 Microsoft Store 能搜到并安装

## 备注

- 只有用户本人能做的：注册 Partner Center 账号（个人账号现在是否免费、国内身份验证要求待核实）、保留「浮屿 / Fuyu」名字、确认隐私政策内容。
- MSIX 卸载不能跑 `--uninstall-cleanup`，外部钩子靠设置里的「移除钩子」和钩子命令的存在性守卫兜底。
