## 说明

[D97](/docs/tasks/D/D97.md) 子任务 1，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 第一批前端动效合成器化与按需加载快赢项（P0-3、P0-4、P1-1 局部）：

1. **液态玻璃高光层 `.island__glass::before` 改为 `transform: translate3d`（P0-3）**：
   - [IslandGlass.css](/src/windows/island/IslandGlass.css) 在带有 `filter: blur(20px)` 的伪元素上对 `left` 和 `top` 做 `transition`，鼠标划过岛屿时每帧触发主线程 Layout + 20px 高斯模糊重绘；改为固定 `left: 0; top: 0;` 并通过 `transform: translate3d(...)` 与 `transition: transform` 走合成器线程。
   - 改动动效前须加载 `fuyu-motion` skill 遵守曲线与档位规范。
2. **进度条 / 电量条 / 位置预览改为 `transform` 过渡（P0-3）**：
   - 待办完成进度条（[TodoIslandPage.css](/src/features/todos/island/TodoIslandPage.css)、[TodoIslandHeader.tsx](/src/features/todos/island/TodoIslandHeader.tsx)）与自动更新下载进度条（[UpdatePanel.css](/src/features/updater/UpdatePanel.css)、[UpdatePanel.tsx](/src/features/updater/UpdatePanel.tsx)）：`width` 过渡改为 `transform-origin: left center; transform: scaleX(...)`；
   - 折叠栏插件电池电量条（[PluginStatusChip.css](/src/features/plugin-views/PluginStatusChip.css)、[PluginStatusChip.tsx](/src/features/plugin-views/PluginStatusChip.tsx)）：`height` 过渡改为 `transform-origin: center bottom; transform: scaleY(...)`；
   - 设置页位置偏移预览（[PositionDiagram.css](/src/windows/settings/sections/PositionDiagram.css)）：`margin-top` 过渡改为 `transform: translateY(...)`。
3. **`pinyin-pro`（212.2 KB）按字母搜索词懒加载（P0-4）**：
   - 移除 [ClipboardPopup.tsx](/src/features/clipboard/ClipboardPopup.tsx) 与 [useClipboardManager.ts](/src/features/clipboard/useClipboardManager.ts) 挂载时无条件触发的 `loadPinyin()`，在 [popupQuery.ts](/src/features/clipboard/popupQuery.ts) 提供字母词判断，仅当查询包含英文字母（`/^[a-z]+$/`）时才按需加载拼音库。
4. **设置搜索索引按需加载与 `useIslandNotices` 解耦 `dompurify`（P1-1 局部）**：
   - [SettingsSidebar.tsx](/src/windows/settings/SettingsSidebar.tsx)（注意：开工前先 `git status --short` 确认是否有其他会话未提交改动）移除顶层静态 `import searchIndex from "./searchIndex.json"`（111.5 KB），改为搜索框聚焦或输入非空搜索词时动态加载；
   - [useIslandNotices.ts](/src/features/messages/island/useIslandNotices.ts) 改为从 `../mail/useMail` 导入 `useMail`，切断主岛常驻 runner 对 `MailPanel.tsx` 和 `dompurify` 的静态依赖。

## 验收

- `.island__glass::before` 及上述进度条、电量条、位置预览均使用 `transform` 过渡，不再对 `left`、`top`、`width`、`height`、`margin-top` 做过渡，`pnpm check:motion` 零新增白名单
- 剪贴板窗口初始挂载不加载 `pinyin-pro` chunk，输入英文字母搜索时正常加载并匹配中文拼音
- `SettingsSidebar` 按需动态加载 `searchIndex.json`，`settings-search` 回归页通过
- `pnpm check`、`pnpm build` 与相关回归页通过
