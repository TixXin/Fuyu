## 说明

0.3.14 上钉钉日历又同步不了，界面上没有任何报错。群友截图里日历页显示「还没有日历」和「订阅中国节假日 / 添加工作日历」两个按钮，也就是说之前配好的钉钉日历整个不见了，不只是同步失败。

- 类别：问题
- 平台：未说明
- 群里反馈：2026-11-27，1 人提到（浮汐 FB-42）；同一个人另提了 #1305（希望定期自动更新日历）

初步怀疑：

- 前端 `src/features/calendar/useCalendar.ts` 读日历失败时只写 `console.error`，界面不提示；后端读到的日历源为空时页面就显示「还没有日历」
- 日历源配置或凭据在升级到 0.3.14 时丢了，或者读取失败被当成「没有日历」，待核实
- 和 #369（钉钉 CalDAV 返回 405，0.3.10 已修）是不是同一个原因，待核实
- 后台本来就每 15 分钟自动重新同步一次（`src-tauri/src/calendar/mod.rs` 的 `REFRESH_AFTER`），#1305 想要的定期更新其实已有，群友感觉「不更新」多半就是这里同步失败了

待补：

- Windows 还是 Mac；钉钉日历是怎么加的（CalDAV 账号还是订阅链接）；设置里日历源列表里它还在不在

## 验收

- 找到钉钉日历在 0.3.14 上消失或同步失败的原因并修好，升级后已配好的日历源不丢
- 同步失败时日历页和设置里都有明确提示（哪个日历、什么错误），不再显示成「还没有日历」
- 设置里能看到每个日历上次同步的时间和自动同步间隔，回复 #1305 后一起关闭
