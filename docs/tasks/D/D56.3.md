## 说明

[D56](/docs/tasks/D/D56.md)（#327）子任务，修复主岛开合原生几何调用冗余、外壳 CSS 重排传播与消息到达卡片三段式高度反向抽搐（待在途 `C77` 与 `C102.3` 完成后执行，避免范围冲突）：

1. **开合动画跳过无变化的 Win32 显示器枚举与窗口查询**：
   - [src-tauri/src/island/mod.rs](/src-tauri/src/island/mod.rs) 与 [geometry.rs](/src-tauri/src/island/geometry.rs)：对齐 `DEFAULT_EXPANDED_ISLAND_HEIGHT` 与前端默认 `490.0`；当影响舞台几何的输入字段与上次已同步状态完全一致时跳过 `apply_stage_geometry`，普通开合仅更新穿透与焦点状态。
2. **真岛 `useIslandWindow` 单飞合帧与跨窗口调参跟手模式**：
   - [useIslandWindow.ts](/src/windows/island/useIslandWindow.ts) 与 [IslandResizeHints.css](/src/windows/island/IslandResizeHints.css)：移除 Rust 未使用的 `glassIntensity` / `islandBackgroundColor` 依赖，为 `syncNativeInteraction` 增加 `rAF + inFlight` 单飞合帧；跨窗口连续高频调整尺寸/圆角时临时挂载 `island-resizing` 跟手模式并对齐 `--island-shell-fill`。
3. **外壳 CSS 布局包含与透明窗口冗余 `backdrop-filter` 清理**：
   - [IslandShell.css](/src/windows/island/IslandShell.css)、[IslandGlass.css](/src/windows/island/IslandGlass.css)、[IslandRunners.tsx](/src/windows/island/IslandRunners.tsx)：移除 `.island__expanded` 多余 `height` 过渡并补充 `contain: layout style`，移除透明主岛窗口背后无像素时无效的 `backdrop-filter`，收敛 `IslandRunners` 对无关 `page` 变化的重渲染。
4. **修复消息到达卡片三段式高度抽搐与横幅二次测量**：
   - [useIslandMessagePanel.ts](/src/features/messages/island/useIslandMessagePanel.ts) 先就绪带估算高度的 `popup` 贡献再切展开态，消除 `490px → 28px → 实测高度` 反向抽搐；[MessageBanner.css](/src/features/messages/banner/MessageBanner.css) 按动效规范去掉带文字层的 `scale(0.97)` 与 `both`，使首帧命中框一次测准。

## 验收

- 普通顶边开合不再重复触发显示器枚举与 `set_size` / `set_position`
- 消息卡片弹出一步平滑展开至目标尺寸，无高度反向抽搐
- `pnpm check`、`pnpm build`、相关回归页、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与双端 CI 通过
