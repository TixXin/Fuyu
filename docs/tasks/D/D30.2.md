## 说明

照 `todos.json` 已有的做法：第一次启动时从 localStorage 读出来写成文件；写入排队、用 revision 处理冲突；窗口之间用 Tauri 事件同步，代替现在 `fuyu-settings` 等 key 的 storage 事件。旧 key 继续写，给退回的旧版本用。只搬 `BACKUP_KEYS` 里的设置，窗口之间的一次性请求留在 localStorage（见 D30 备注）。
