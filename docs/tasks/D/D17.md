## 说明

`fly-island` 和 `FocuSD` 都是上游起的名字，本仓库已经独立维护，要换成自己的名字。名字、内部标识和旧数据的迁移一起做，按 [分步计划](/docs/architecture/rename-plan.md) 推进，进度在计划里勾选。

## 验收

- 计划里的 7 步都勾上。
- 仓库（`TixXin/fuyu`）、README、安装包、窗口标题、npm 包（`fuyu-plugin`、`create-fuyu-plugin`）和插件市场（`TixXin/fuyu-plugins`）都用新名字。
- 旧版本的用户经应用内更新到新版后，只剩一个安装项，设置、待办、凭据、插件和 Agent hook 都还在。
- 旧的 npm 包标记为弃用并指向新包。

## 备注

- 2026-11-10 用户定名：浮屿 / Fuyu，英文不带 `-island`。调研推荐的是 Skyholm，用户选了浮屿；定名当天的查重和要接受的几点写在 [调研](/docs/research/project-rename.md) 的「定名」一节。
- 2026-11-10 用户决定内部标识一起改、带迁移。应用标识取 `com.tixxin.fuyu`；插件 id 和插件签名的域串不改，原因写在计划的「保留不改」。

## 结论（2026-11-09）

查了 GitHub 上的同类项目和 89 个候选名：「X Island」、Dynamic / Notch、各种语言的「岛」、中文的「X屿」都已经被同类项目用了，包括「浮屿」。Skyholm、Enisle、Hoverholm 在 GitHub、npm 和 crates.io 上都没有同名项目。详见 [调研](/docs/research/project-rename.md)。
