## 说明

`fly-island` 和 `FocuSD` 都是上游起的名字，本仓库已经独立维护，要换成自己的名字。

等用户确认两件事：

- 用哪个名字。调研推荐 Skyholm（空岛），其次 Enisle（登岛），备选 Hoverholm（悬屿）。用户 2026-11-10 提出的 fuyu-island（浮屿）英文没有重名，但「浮屿」已有两个 Windows 同类项目在用，不建议。
- 内部标识（应用标识、localStorage key、注册表值、凭据服务名、链接协议）是不是一起改。

## 验收

- 名字定下来的当天，在 GitHub、npm 和 crates.io 上再查一次，确认没有新冒出来的同名项目。
- 先在 `docs/architecture/` 写分步计划：哪些标识改、旧数据怎么迁移、已安装的旧版本怎么更新到新名字。
- 仓库、README、安装包、窗口标题、npm 包和插件市场都用新名字。
- 旧版本的用户更新后，设置、待办和凭据都还在。

## 结论（2026-11-09）

查了 GitHub 上的同类项目和 89 个候选名：「X Island」、Dynamic / Notch、各种语言的「岛」、中文的「X屿」都已经被同类项目用了，包括最初想到的「浮屿」。Skyholm、Enisle、Hoverholm 在 GitHub、npm 和 crates.io 上都没有同名项目。详见 [调研](/docs/research/project-rename.md)。
