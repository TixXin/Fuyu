## 说明

[D97](/docs/tasks/D/D97.md) 子任务 5，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 中的 **P0-5（`SESSION_CACHE` 淘汰修复）**、**P2-4（U2–U6 全局缓存上限）** 与 **P2-5（异步命令阻塞 I/O 与盘符探测正缓存）**：

1. **修复 `agent_status` 的 `SESSION_CACHE` 远程/历史会话永不淘汰问题（P0-5 / U1）**：
   - [session_scan.rs](/src-tauri/src/agent_status/session_scan.rs) 当前先调 `forget_missing` 再 `truncate(MAX_SESSIONS)`，且用 `!path.starts_with(home_dir)` 跳过非当前目录，导致未进前 12 名的 24h 内会话与已删除的远程 SSH 镜像目录缓存永不回收；调整清理顺序并增加最后访问时间 TTL 与硬性容量上限（如 128 条）。
2. **补齐 U2–U6 共 5 处全局 `static` 容器的容量上限与过期清理（P2-4）**：
   - [timeline_clock.rs](/src-tauri/src/media_control/timeline_clock.rs)（U2）、[audio_fallback.rs](/src-tauri/src/media_control/audio_fallback.rs)（U3）、[opencode.rs](/src-tauri/src/agent_status/opencode.rs)（U4）、[lifecycle.rs](/src-tauri/src/plugin_host/lifecycle.rs) / [notify.rs](/src-tauri/src/plugin_host/notify.rs) / [reveal.rs](/src-tauri/src/plugin_host/reveal.rs)（U5）、[external.rs](/src-tauri/src/agent_approval/external.rs)（U6）分别补齐过期 `retain` 与硬性容量上限。
3. **异步命令文件 I/O `spawn_blocking` 化与盘符可达性正缓存（P2-5）**：
   - [sound_packs.rs](/src-tauri/src/agent_status/sound_packs.rs) 与 [pets/mod.rs](/src-tauri/src/pets/mod.rs) 的 `async fn` 大文件解压/拷贝放入 `tauri::async_runtime::spawn_blocking`；
   - [availability.rs](/src-tauri/src/file_shelf/availability.rs) 为可达盘符增加 15 秒正缓存 TTL，避免每次查询重复为每个盘符 `thread::spawn` 探测线程。

## 验收

- U1–U6 所有全局静态缓存均具备容量上限与过期清理逻辑，并新增对应单元测试验证超量/过期淘汰
- `sound_packs` 与 `pets` 的阻塞文件操作均在 `spawn_blocking` 中运行；`file_shelf` 盘符探测在 15 秒 TTL 内命中正缓存不重复建线程
- `pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 通过，双端 `clippy` 零告警，Windows CI（`pnpm mq:try --wait`）通过
