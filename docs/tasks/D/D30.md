## 说明

协作者 ShengLin1001 在 #50 提出：数据现在分在 `%APPDATA%\com.tixxin.fuyu`、WebView2 的 localStorage 和 `Documents/FocuSD` 三处，难找、难备份、难迁移。2026-11-12 用户同意方向，分三期（子任务 D30.1–D30.3），每期单独合入。

## 验收

- 应用数据、设置文件、待办 Markdown 都在一个家目录下，默认 `~/.fuyu`，设置里能改
- 老用户升级后自动迁移，不丢数据；退回旧版本仍能用（看到的是迁移那一刻的数据）
- 已安装的 Claude Code / Codex 钩子、已发布的 `fuyu-plugin` 继续能用

## 备注

用户 2026-11-12 定的答案（#50 的 6 个问题）：

1. 默认放 `~/.fuyu`，不放 `%APPDATA%`。
2. WebView2 自己的缓存（EBWebView）留在 `%LOCALAPPDATA%`。
3. 只搬 `BACKUP_KEYS` 里的设置；窗口之间的一次性请求（`fuyu-settings-focus`、`fuyu-position-reset`、`fuyu-panel-preview`、`fuyu-onboarding-welcome`、`fuyu-onboarding-demo` 等）留在 localStorage，它们靠 storage 事件传消息。
4. 不支持两台电脑同时用一个家目录：放锁文件，另一台检测到就提示并拒绝。
5. 退回旧版本只看到迁移那一刻的数据，可以接受，写进说明；不做「旧版本改过就重新导入」。
6. 远程电脑（ssh）的钩子实施时核对 `agent_status/remote_setup.rs`。

issue 里漏掉、要一起处理的：已发布的 `fuyu-plugin` 固定读 `%APPDATA%\com.tixxin.fuyu\local-api.json`（`packages/fuyu-plugin/src/dev.mjs`），旧位置要继续写一份；自己拼数据目录的钩子脚本有 3 个（还有 `fuyu-agent-session.ps1`），它们已经认 `FOCUSD_AGENT_STATUS_DIR` / `FOCUSD_AGENT_STATUS_PATH`，重装钩子时把路径放进命令即可。
