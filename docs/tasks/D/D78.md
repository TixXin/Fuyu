## 说明

D77（#657）起 Windows 上的 manifest 由链接器嵌入（src-tauri/build.rs 的 /MANIFEST:EMBED /MANIFESTINPUT:src-tauri/windows-app-manifest.xml，tauri-build 改用 new_without_app_manifest），测试程序也带上 Common-Controls v6。CI 只证明能链接、测试能跑；D77 在 Mac 上做，正式包效果要在 Windows 真机（tixxin-computer）上看。

## 验收

- D77 前后各 pnpm build:exe，mt.exe -inputresource:fuyu.exe;#1 -out:x.manifest 导出比对：Common-Controls 6.0.0.0 依赖前后都在；DPI 元素前后都没有；改后多出 trustInfo asInvoker 属预期（没加 /MANIFESTUAC:NO）；只有一份 manifest 资源
- 跑起来看：DPI 缩放、多显示器不同缩放下位置和清晰度、选文件夹对话框和更新提示正常不崩
- Windows 本机 pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml 能启动并跑完
