## 说明

收敛 Node 宿主进程的 V8 新生代与老生代上限，防止大内存机器上宿主闲置膨胀，并加单测防止打包内置插件残留运行期 `.ts` 导入触发 `amaro`。详见 [内存优化方案](/docs/architecture/memory-optimization-plan.md)。

## 验收

- `host_args` 默认传入 V8 轻量级内存参数并支持环境变量覆盖。
- Rust 单元测试与脚本单元测试全部通过。
