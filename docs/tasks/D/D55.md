## 说明

用户群反馈歌词偶尔卡住。我们已经用 SMTC 的 LastUpdatedTime 加播放速率推算当前位置（media_control/session.rs 的 read_timeline）。参考 JNTMTMTM/eIsland：每个媒体会话记一个推算时钟，播放器没发布新时间线时从自己上次推算的位置接着推，不退回旧值；暂停时停在推算的位置，并同步暂停歌词动画。怀疑我们在暂停、切歌或播放器长时间不更新时间线时退回了旧位置。先在 Windows 上用网易云、QQ 音乐、Spotify 复现。

## 验收

- 复现并写清卡住的原因
- 暂停、继续、拖动进度、切歌后歌词不跳回、不卡
- Rust 单元测试覆盖位置推算
