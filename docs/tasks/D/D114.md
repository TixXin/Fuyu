## 说明

设置 → 关于加第四个标签「支持」，并把签名的费用和收款渠道定下来。用户 2026-11-19 说先记下来，方向以后再定，还不开工。

1. **「支持」页**：关于页现在是「关于 / 更新日志 / 帮助」三个标签（`src/windows/settings/AboutSettingsPage.tsx`，分区插槽），加一个「支持」。内容依次是：今年的目标、已收到和已支出；钱用在哪（第 2 项的费用和续费日期）；收款方式；打赏的人和金额。
2. **钱用在哪**：
   - 苹果开发者账号（个人）：99 美元 / 年，Developer ID 签名和公证要用（G1.12）。
   - Windows 安装包签名：走免费的 SignPath Foundation（用户 2026-11-19 定）。浮屿是 AGPL-3.0，符合它对开源许可证的要求；发布者会显示成 SignPath Foundation，安装包要由 CI 自动构建出来。申请不过的备选是 Certum 的开源证书（云端，约 49 欧元一张，有效期最长 459 天）。
3. **收款渠道**（没定）：
   - 国内：微信赞赏码和支付宝收款码，名单要手动记；或者爱发电（抽 6%，有接口能读赞助者）。
   - 海外：Stripe 不给大陆个人开户，GitHub Sponsors 和 Buy Me a Coffee 收不到款。可行的是 Open Collective（挂在 Open Source Collective 下，托管方代收、抽约 10%，账目和名单公开、有接口）或 Ko-fi 加 PayPal。
4. **名单数据**：不打进安装包，否则加一个人就要发版。启动后从远端读，读不到时显示随包带的那份；放在哪个地址要另定（国内访问 GitHub raw 不稳）。
5. README 和 `.github/FUNDING.yml` 加入口。

## 验收

- 设置 → 关于 → 支持：能看到目标和收支、两项费用的金额和周期、收款方式、打赏名单；中英文都有，英文界面不显示国内的收款码
- 文案用「打赏 / 赞助」，不用「捐款 / 募捐」；不写「签名后就没有 SmartScreen 警告」这类保证（信誉要靠下载量慢慢攒）
- 断网时这一页照常显示，名单用随包带的那份
- 花出去的钱有公开的账目可查（Open Collective 的账目页，或仓库里的一份文档）
- Windows 安装包带签名的那部分另建任务，这一项只管页面、渠道和账目

## 备注

开工前要用户定的：

- 海外渠道用 Open Collective 还是 Ko-fi 加 PayPal；国内名单纯手动还是加爱发电
- 名单里显示什么：建议只显示对方留的昵称，没留显示「匿名」，金额是否显示由对方选
- 只有用户本人能做的：申请 SignPath、申请 Open Collective、提供两张收款码图片

2026-11-19 查价时没有核实到官方原文的几处，开工前要再查：

- Stripe 不给大陆个人开户、GitHub Sponsors 不支持大陆：查到的支持地区里只看到香港和澳门
