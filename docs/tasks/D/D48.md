## 说明

翻译、剪贴板和截图选区窗口平时都隐藏着，但 WebView 一直占着内存。微软的建议是不活跃的 WebView 设 `MemoryUsageTargetLevel = Low`，一段时间不用的调 `TrySuspend`，要用时 `Resume`；两套做法二选一。Tauri 没有封装，仓库已经依赖的 `webview2-com` 0.39 里有 `ICoreWebView2_19`，可以经 `with_webview` 调用（`unsafe`，放 `src-tauri/src/win32/`）。能省多少没有公开数字，要自己量。

做法：先做 `MemoryUsageTargetLevel`：窗口隐藏时设 Low，显示前改回 Normal。量前后的私有内存和唤起延迟，再决定翻译窗口要不要换成 `TrySuspend`（暂停期间收不到事件，恢复后要补一次状态）。只在 Windows 上做，macOS 不受影响。

来源见[调研](/docs/research/memory-and-performance.md)。

## 验收

- 隐藏的翻译、剪贴板、截图选区窗口在隐藏后进入低内存状态，显示时恢复。
- 有前后对比：隐藏一段时间后的私有内存，和快捷键唤起剪贴板、翻译窗口的延迟；延迟没有明显变差。
- 折叠态、展开态、贴边收起和托盘隐藏下主岛行为不变。
- 数字没有改善时如实记录，并把这项改动撤掉。

## 备注

### 第一步的代码（2026-11-15，Mac 上写，默认关）

- `src-tauri/src/win32/webview_memory.rs`：经 `ICoreWebView2_19::SetMemoryUsageTargetLevel` 设 Low / Normal。
- `src-tauri/src/webview_memory.rs`：只有环境变量 `FUYU_WEBVIEW_LOW_MEMORY=1` 时才生效，没设时一个 WebView2 调用都不做；Mac 上是空实现 `webview_memory_unsupported.rs`。
- 接的地方：翻译窗口（`translation/mod.rs` 的 `toggle_translation_window`、`hide_translation_window`）、剪贴板窗口（`clipboard_history/popup.rs` 的 `toggle`、`hide`）隐藏后设 Low、显示前设 Normal，页面加载完时窗口还隐藏着也设 Low（`lib.rs` 的 `on_page_load`）；截图选区窗口建好时设 Low，开始截图前全部设 Normal，截完 / 取消隐藏后设 Low（`screenshot/session.rs`）。
- 没做 `TrySuspend`，剪贴板预览窗口 `clipboard-preview` 也没接。

### 实测清单（Mac 上测不了：WebView2 只在 Windows 上有）

在 Windows 那台（tixxin-computer）上，用同一个 `pnpm build:exe` 打出的 `src-tauri/target/release/fuyu.exe` 各跑一轮，开关前后对比：

1. **两轮怎么开**：关闭的一轮直接启动；打开的一轮在 PowerShell 里 `$env:FUYU_WEBVIEW_LOW_MEMORY = "1"; & .\src-tauri\target\release\fuyu.exe`（环境变量只对这个进程生效）。每轮启动前先退出正在运行的岛。
2. **准备**：两轮都打开快捷翻译和剪贴板窗口（设置里剪贴板「打开方式」选独立窗口），打开截图模块；启动后各用快捷键唤起一次再收起，截一张图再取消。
3. **私有内存**：收起后等 10 分钟不碰，记下浮屿相关的 `msedgewebview2.exe` 渲染进程（任务管理器「详细信息」加「提交大小」列，或 `Get-Process msedgewebview2 | Select Id, PrivateMemorySize64`）的私有内存总和，以及每个窗口对应的渲染进程（Edge 的 `edge://inspect` 或 Process Explorer 看命令行里的窗口）。两轮各量 3 次取中位数。
4. **唤起延迟**：收起 10 分钟后，按快捷键唤起剪贴板、翻译窗口，各 10 次（每次之间收起再等 1 分钟以上），录屏或用秒表估从按键到内容出现的时间；对比两轮，打开的一轮不能明显变慢（例如中位数多出 100 ms 以上算变慢）。截图快捷键也试几次，选区出现不能变慢、画面不能白一下。
5. **打开开关后功能照旧**：剪贴板窗口收起时复制新内容，再唤起能看到；翻译窗口收起后用划词翻译快捷键唤起能拿到选中文字；截图多显示器各截一次。
6. **主岛不受影响**：打开开关后，折叠态、展开态、贴边收起和托盘隐藏四种状态下主岛的显示、动画、点击照旧（主岛的 WebView 不在名单里，不应该有变化）。
7. **结论**：把两轮的数字写进这里。私有内存没有明显下降（例如少于 10%）或唤起明显变慢，就把这次的代码撤掉（删掉上面列的文件和调用处），如实记录后 `pnpm tasks drop`；有改善再决定是去掉开关默认打开，还是翻译窗口换成 `TrySuspend`。
