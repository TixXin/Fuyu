## 说明

承接在 macOS 开发机完成并合入的 [D99](/docs/tasks/0-archive/D/D99.md)（#814）、[C110](/docs/tasks/0-archive/C/C110.md)（#815）、[D100](/docs/tasks/0-archive/D/D100.md)（#817）、[D101](/docs/tasks/0-archive/D/D101.md)（#818）真机交互实测清单：

1. **快捷键以「岛上页面」打开焦点保持与归还（D99）**：在 Windows 真机将剪贴板与快捷翻译设为「岛上页面」，聚焦外部编辑器且鼠标不在主岛上方时，短按一次全局快捷键立即松手，确认主岛稳定展开并持有焦点、不自动收起；按 `Esc` 或再次按快捷键收起后，焦点正确归还给唤起前的外部窗口。
2. **睡眠唤醒剪贴板连续复制与退出刷盘（D101）**：Windows 真机执行系统睡眠/现代待机再唤醒后，立即按剪贴板快捷键打开窗口并连续点击复制多张大图与长文本条目，确认主消息循环与桌面帧率平稳无卡顿；修改条目长备注后在空格预览窗和独立宽版详情栏查看完整多行备注，立即从托盘退出再重开应用确认最后一次修改未丢失。
3. **WebView2 GPU 进程退出自愈与日志定位（D100）**：在任务管理器手动结束浮屿关联的 `msedgewebview2.exe --type=gpu-process` 进程（或观察睡眠唤醒后），确认透明悬浮岛与剪贴板窗口自动重载恢复不冻结，`~/.fuyu/webview-crashes.log` 追加 `gpu-process-exited ... reloaded` 记录；在「设置 → 通用 → 数据」点击「崩溃诊断日志」可定位最新日志。
4. **翻译热键单条清空与本地免密钥调用（C110）**：在「设置 → 翻译」清空单条快捷键后确认系统全局热键立即释放且重启后保持未设置；连接本机免密钥 Ollama / MTranServer 回环地址（不填 API Key）确认快捷翻译、划词翻译与改写正常返回。
5. **岛上和独立窗口打开翻译页不往下跳（[C123](/docs/tasks/0-archive/C/C123.md)，#902）**：把快捷翻译分别设为「岛上页面」和独立窗口，用快捷键打开翻译，确认页面不往下滚一截、输入框照样拿到焦点、可以直接打字；清空输入后焦点仍留在输入框，页面也不跳。
