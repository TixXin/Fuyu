## 说明

[D97](/docs/tasks/D/D97.md) 子任务 3，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 中的 **P1-1（公共入口包瘦身与窗口级服务按需加载）**：

1. **双语字典按激活语言动态加载 + 拆分 `settings` / `onboarding` 专用大词典**：
   - 目前 [src/i18n/index.ts](/src/i18n/index.ts) 静态导入中英双语全量词典（源码 535.3 KB，其中 `settings` 占 231 KB、`onboarding` 占 22.2 KB），导致所有 10 类窗口共用的入口 chunk `index.js` 高达 668.3 KB。
   - 改为启动时按当前 `locale` 动态加载单语种词典（切换语言时再按需加载另一语种），并将仅设置窗口和引导窗口使用的重型分段按窗口按需加载，显著降低 `main`、`clipboard`、`pin`、`tray-menu`、`drag-grid` 等窗口的 JS 解析与内存开销。
2. **[src/main.tsx](/src/main.tsx) 按窗口类型（`windowKind`）按需加载 `plugin/services.ts`**：
   - 移除顶层无条件 `import.meta.glob("./features/*/plugin/services.ts", { eager: true })`；
   - 在 `loadWindow()` 中按窗口角色仅加载所需的服务模块，避免 `pin`、`drag-grid`、`clipboard-preview`、`tray-menu`、`onboarding` 等轻量窗口启动时执行全部 10 个模块的服务注册及 [plugin-kernel/services.ts](/src/features/plugin-kernel/services.ts) 顶层的 `get_builtin_plugins` IPC 请求。

## 验收

- `pnpm build` 产出的公共入口 `index-*.js` 体积相比基线（668 KB）下降 40% 以上
- `pin`、`drag-grid`、`clipboard-preview`、`tray-menu`、`onboarding` 窗口启动时不再触发无关 `plugin/services.ts` 执行与多余的 `get_builtin_plugins` IPC
- 中英文切换、设置窗口、新手引导及各独立窗口功能与文案完全正常，`pnpm check`、`pnpm build` 与 `pnpm test:regression` 全部通过
