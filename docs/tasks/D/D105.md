## 说明

岛上剪贴板面板的单条「删除剪贴记录」与顶栏「清空剪贴历史」改用 [RowMenu.tsx](/src/components/list/RowMenu.tsx) 承载二次确认后，第二次点击确认无法触发删除或清空：

1. **根因**：
   - [useClipboardConfirmations.ts](/src/features/clipboard/useClipboardConfirmations.ts) 在捕获阶段监听全局 `pointerdown`，当事件路径中不存在 `[data-clipboard-confirm-control='true']` 节点时，立即清空 `confirmDeleteId` 和 `isConfirmingClear`。
   - [RowMenu.tsx](/src/components/list/RowMenu.tsx) 渲染菜单项 `<button className="row-menu__item">` 时未携带确认控件标记，导致用户在菜单内第二次按下鼠标（`pointerdown`）时确认态就被提前重置，随后的 `click` 只能重新进入确认态、菜单保持不关，陷入死循环无法删除。
2. **改法**：
   - 在 `RowMenuItem`（[RowMenu.tsx](/src/components/list/RowMenu.tsx)）支持确认控件标记（或让 [useClipboardConfirmations.ts](/src/features/clipboard/useClipboardConfirmations.ts) 识别处于二次确认流程中的菜单项按钮），并在 [ClipboardHistoryItemRow.tsx](/src/features/clipboard/ClipboardHistoryItemRow.tsx)（单条删除）与 [ClipboardPanelHeader.tsx](/src/features/clipboard/ClipboardPanelHeader.tsx)（清空剪贴历史）接线。
   - 补充单测或回归页断言，覆盖第一次点击进入确认态、第二次点击执行删除/清空、点击菜单外区域取消确认态。

## 验收

- 岛上剪贴板行菜单点击「删除剪贴记录」进入确认态后，再次点击即可删除对应记录并关闭菜单
- 岛上剪贴板顶栏菜单点击「清空剪贴历史」进入确认态后，再次点击即可清空非收藏记录并关闭菜单
- 点击菜单外部或超过 3 秒未点时，确认态正常重置
- `pnpm check`、`pnpm build` 及剪贴板相关回归页通过
