## 说明

0.3.13-beta.2 有用户反馈同一台 Windows 电脑上所有窗口都显示不全（右键菜单、展开面板、Fuyu 面板、托盘卡片被裁，引导的「下一步」点不了）。推断是系统「文本大小」不是 100%：WebView2 的缩放默认是显示器缩放 × 文本大小，浮屿定窗口尺寸只乘了显示器缩放。

在 Windows 上把每个 WebView 的缩放固定成显示器缩放，显示器缩放变化时自己跟上。排查和方案对比见 docs/investigations/windows-text-scale-clipping.md。

## 验收

系统文本大小在 100%、125%、175% 下，岛、右键菜单、托盘卡片、引导、剪贴板、翻译、设置、截图和插件窗口都完整、能点；浮屿开着时改文本大小或显示缩放不出现裁切；100% 下和现在没有差别；Mac 不受影响。
