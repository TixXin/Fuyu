## 说明

仓库和应用已经改名为 Fuyu，但本机文件夹还是 `E:\Projects\fly-island` 和 `E:\Projects\fly-island-lanes`，所以状态栏显示 `fly-island`，会话名也是 `fly-island-xx`。改名会影响：Claude Code 按路径存的记忆和会话历史、每个 lane 的 `.git` 里的绝对路径、`core.hooksPath`、lane 归属记录、pnpm 的 `node_modules` 联接、Rust 编译缓存和桌面快捷方式。脚本 [`scripts/rename-local-folders.mjs`](/scripts/rename-local-folders.mjs) 把这些一次做完；仓库里的脚本已经不依赖文件夹名（lane 文件夹认 `<任意名>-lanes`）。

## 验收

- 用户退出所有会话、`pnpm tauri dev`、岛屿和编辑器后，在 `E:\Projects` 下运行：
  1. `node fly-island\scripts\rename-local-folders.mjs`（演练，只列出要做什么并检查能不能做）
  2. `node fly-island\scripts\rename-local-folders.mjs --apply`
- 脚本做完：两个文件夹改名为 `fuyu`、`fuyu-lanes`；`git worktree repair`；`core.hooksPath` 和 lane 归属记录改成新路径；`~/.claude/projects` 下主工作区和各 lane 的目录复制一份到新名字（旧的保留）；主工作区和各 lane 重新 `pnpm install`。改不了 lane 文件夹时会把主工作区改回原名。
- 之后手动：在 `E:\Projects\fuyu` 跑 `pnpm build:exe`（Rust 全量重编一次，桌面快捷方式改指新路径）；Orca、VS Code、magpie 的工作区路径改成新文件夹；岛上任务看板插件设置里的仓库目录改成新路径。
- 新会话从 `E:\Projects\fuyu` 打开，状态栏显示 `fuyu`，`pnpm lane:list` 正常列出 lane。
- 新会话把 AGENTS.md、docs 和记忆里的 `fly-island-lanes`、`E:\Projects\fly-island` 改成新路径。
