## 说明

方案见 [计划](/docs/architecture/skills-batch1-plan.md) 第 3 节。

## 验收

- --list、--take、--match、--as、-- <整个文件>、--dry-run、-m、-F 都在
- 编号按内容算；这次提交相对 HEAD 的每一行增删都必须是工作区里已有的
- commit-tree 加带旧值核对的 update-ref；HEAD 中途推进时重来，最多 3 次，不冲掉别人的提交
- 提交后对涉及的路径 git reset -q，对齐共用索引；提交说明经 git hook run commit-msg
- 临时仓库里的测试覆盖计划第 3 节列的各种情况，开头去掉 GIT_* 变量
- pre-commit 的提示指向这个命令；workflow.md 补说明；在真实仓库里用它提交一次
