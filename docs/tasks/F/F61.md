## 说明

gate.mjs 的提示说 heavy 不写 CARGO_TARGET_DIR 时默认用 src-tauri/target/agents，但 scripts/heavy/ 里没设它，代理的 Rust 产物落进了用户 dev 的 target/debug。修法：heavy 跑 cargo 的 build/test/check/clippy/run 且没写目录时补成 target/agents 并打一行说明；tauri build、build:exe、release 不受影响；queue.mjs 按补完后的目录分道；核对 gate.mjs 提示和 workflow.md「Rust 构建」措辞；加测试。细节见 #728。
