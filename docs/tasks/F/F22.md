## 说明

`src-tauri/target` 涨到约 360 GB，其中约 195 GB 是 `debug` / `agents` 下的 `incremental`：每个 lane 路径、每次编译参数变化都会新建一份，cargo 从不清理。每个 lane 预览还要从头编全部依赖（每个 9~20 GB）。`crate-type` 带的 `staticlib` / `cdylib` 是 Tauri 模板为移动端留的，每次构建多出约 1 GB 的 `.lib`。

## 验收

- 有清理命令，按时间和新旧删掉不用的 incremental、自家 crate 的旧产物、已删 lane 的预览目录；land 时自动跑一次
- lane 预览共用一个 build-dir，第二个 lane 起不再重编依赖
- `crate-type` 只留 `rlib`，dev profile 减少调试信息
- `cargo test` 和 `pnpm build:exe` 通过
