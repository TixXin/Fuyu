## 说明

Mac 那台机器的内核主机名跟着网络变（没设固定的 HostName），机器名取自 os.hostname()，所以同一台机器用过 tixxindeair 和 tixxindemacbook-air 两个名字，11-13 以来换了 5 次。名字一变，本机会话把自己早先认领的任务当成别人的，land 分支名也跟着变（mq:wait 不写 PR 号时找不到刚开的 PR）。Windows 的主机名是电脑名，不受影响。

做法：机器名只在 scripts/machine-name.mjs 里算，认领和 land 分支名用同一个函数；第一次用到时记在本地 git 配置 fuyu.machine 里，以后照用（Mac 上第一次取 scutil --get LocalHostName，其他系统取 os.hostname()）；同一台机器用过的旧名字记在 fuyu.machineAlias 里，任务的 host 等于本机名或任一别名都算本机，mq:wait 不写 PR 号时按别名再找。
