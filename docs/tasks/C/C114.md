## 说明

依据调研报告 [todos-and-calendar-expansion.md](/docs/research/todos-and-calendar-expansion.md)，对标 Things 3、滴答清单、Todoist、Dato、MeetingBar、Itsycal、Fantastical 与 Notion Calendar，系统补齐浮屿「待办」与「日历」模块的核心效率闭环及设置页可配置项，解决当前待办设置仅 4 个开关、日历设置仅 2 个控件且缺少排序、轻语法、熬夜跨天结算、会议降噪、会前强提醒与跨插件联动的痛点。

分两波共 6 个子任务推进（OAuth 登录授权仍归入既有任务 [C5b](/docs/tasks/C/C5b.md)）：

- **第一波（零文件重叠并发开发）**：
  - [C114.1](/docs/tasks/C/C114.1.md)：待办设置扩充、优先级排序、行内轻语法、进行中用时、完成轻音效与自定义跨天时间（前端 `src/features/todos/`）
  - [C114.2](/docs/tasks/C/C114.2.md)：日历原生解析升级：扩充国内外会议链接库、解析已拒绝与空闲状态并保留子日历名称（Rust `src-tauri/src/calendar/`）
  - [C114.3](/docs/tasks/C/C114.3.md)：日历设置页重设计、倒计时样式定制、会前横幅强提醒、入会停歌与 7 日议程/月历周数（前端 `src/features/calendar/`）
- **第二波（跨插件闭环与高阶能力）**：
  - [C114.4](/docs/tasks/C/C114.4.md)：待办单层子任务（Checklist）、行内备注、番茄专注计时联动（`timers/v1`）与准点提醒（`reminders/v1`）
  - [C114.5](/docs/tasks/C/C114.5.md)：全局「快速添加待办」与「一键加入当前会议」热键及无感焦点归还
  - [C114.6](/docs/tasks/C/C114.6.md)：子日历独立勾选与色标、结合中国节假日调休的重复待办（Recurrence）

## 验收

- 「设置 → 待办」与「设置 → 日历」形成分组清晰、默认克制、高阶完备的配置体系，新增偏好自动纳入设置备份与跨窗口同步
- 待办打通「行内语法极速录入 → 优先级排序 → 进行中计时/番茄联动 → 完成音效 → 自定义跨天归档」闭环
- 日历打通「子日历保留与降噪过滤 → 国内外主流会议全识别 → 收起条定制倒计时 + 会前强提醒横幅 → 一键入会自动停歌」闭环
- 全部子任务单测、回归页、`pnpm check`、`pnpm build` 与双平台 Rust 检查通过，`contracts.md` 与 `searchIndex.json` 同步更新
