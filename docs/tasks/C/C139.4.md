## 说明

收起条中间文字位的先后是写死的：临时提示 > 会议 > 歌词 / Agent（一个开关二选一）> 待办。插件也能往文字位放内容，写死的顺序会遇到和图标一样的问题。

定下来的做法（方案的 D）：做成和图标一样的可排序列表（会议、歌词、Agent 标题、待办、插件的文字），每项能隐藏；临时提示（消息预览、音量亮度、设备提示、翻译）仍然排在最前、不参与排序。现有的「歌词优先 / Agent 优先」开关并进这张列表，老设置迁过来。这会改掉 2026-11-09「不做通用排序」的决定，用户 2026-11-19 同意。

放在 C139.3 之后做，顺序存在同一个 key `fuyu-collapsed-text` 里。

## 验收

- 设置里能排文字位的先后，岛上按它显示；默认顺序和现在一样，老用户看不出变化
- 「歌词优先 / Agent 优先」的老设置迁到新列表，行为不变
- `docs/design/collapsed-bar.md` 更新；单元测试覆盖迁移和排序
