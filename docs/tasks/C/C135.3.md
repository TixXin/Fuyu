## 说明

C135.1 的 DXGI 采集已合入，真机项没人看过。按 issue #1276 的九条在 Windows 真机上逐条验，占用数字记进 C135 备注；全过后 platforms.md 液态玻璃一行 Windows 格改「已支持」并标 C135 完成，发现问题就地开修复任务。

## 验收

- 拖岛经过不同窗口和正在播的视频，玻璃里是岛后面的实时画面，不错位、不拖影
- 展开、收起、换页、消息弹出时背景盖满岛，不露边、不闪；岛自己和拖岛辅助线不出现在玻璃里
- 100% 和 150% 的两块屏之间拖动后对得上；锁屏解锁、弹一次 UAC 后 1–2 秒内恢复
- 全屏游戏或全屏视频时停止采集；Win+Shift+S、本应用截图、OBS 采集里岛仍可见
- 任务管理器对比经典 / 只透壁纸 / 透出窗口，静止桌面和身后放视频的 CPU、GPU 记进 C135 备注；收起闲着时占用不明显上升
- 关掉系统「透明效果」直接退回纯色玻璃；采不到时设置页有灰字说明
- `docs/architecture/platforms.md` 液态玻璃一行 Windows 格改为已支持
