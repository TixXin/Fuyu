## 说明

跨设备同步第一步（父任务 C91，#435）里的设置白名单和外观预设：`BACKUP_KEYS` 每个 key、`fuyu-settings` 每个字段标同步 / 本机 / 只在首次并入时带过去；新加的设置默认只留在本机，并有测试逼新设置做出选择。`write_settings_file` 按白名单给变了的 key 打 HLC；外观预设和 todoProjects 按 id 逐条打时间、留墓碑。用户定：和屏幕大小有关的尺寸不同步，模块总开关只在首次并入时带过去，快捷键不同步。

计划和 scope 见 [cross-device-sync-plan.md](/docs/architecture/cross-device-sync-plan.md)。

## 验收

- 白名单覆盖全部现有设置（测试证明）
- 改一个设置只动这个 key 的时间；单元测试
