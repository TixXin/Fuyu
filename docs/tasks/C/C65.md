## 说明

用户群反馈希望能在药丸、刘海模式之间切换，自由选择外观。现在只有贴顶形态。加形态选择，药丸悬空在屏幕顶部下方，刘海是贴顶带内凹圆角的样子。Mac 真刘海另见 G1.11。要考虑和贴边收起、C54 侧边吸附、多显示器的关系。

## 验收

- 外观里能选三种形态，切换时有过渡
- 折叠、展开、贴边收起三种状态在每种形态下都正常
- 回归页覆盖三种形态
