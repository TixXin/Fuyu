## 说明

在「设置 → 外观 → 样式 → 液态玻璃」最上面加一行「预设」，对应 C97 预览页（docs/investigations/ios-glass-preview.html）的五套：iOS 26 透明、iOS 26 着色、流彩毛玻璃（现在的默认）、iOS 18 毛玻璃、Win11 Mica。只改玻璃相关的设置，不动配色；不另存字段，按当前设置和哪一套一致显示，不一致显示「自定义」。数值在回归页 liquid-glass 的调参页用真实壁纸比过再定，不照抄预览页。C97 剩下的主题市场上架可以直接引用这里的数值。（用户要求 2026-11-16）
