## 说明

按 C101.1–C101.3 留下的清单，在 Windows 和 Mac 的真机上测剪贴板空格预览（PR #648、#649、#651，图片编辑 C101.4 的 d2315fe4）。计划见 [计划](/docs/architecture/clipboard-preview-plan.md)。

用正式构建（`pnpm build:exe` 打出的程序）或开发版逐条测，结果写进任务文件；不对的另提 issue。

#### Windows

留住、图钉、尺寸（C101.1）
1. 预览出现、点档位按钮 / 图钉 / ×、滚轮、拖动时，剪贴板窗口不失焦、不关。
2. 按住空格时鼠标进过预览，松开后预览留住；没进过照旧关；图钉钉住后空格不关，Esc 和 × 能关。
3. 中等、全屏两档的位置和大小：单屏、副屏、100% / 150% 缩放、任务栏在侧边；拖边和角改大小时剪贴板窗口不失焦，重开后记得大小；双击顶栏在全屏和上次大小间切换。
4. 全屏时剪贴板窗口在预览上层，↑↓ 换条预览跟着换；点一下预览后剪贴板窗口仍在上层。
5. 剪贴板窗口里按 F 循环三档，`+` `-` `0` 不会打进搜索框。

图片缩放（C101.2）
6. 滚轮一格的缩放步长合适、以指针为中心。
7. 精确式触控板捏合能缩放，不触发整页缩放。
8. 150% 缩放比例下 1:1 显示为 100%。
9. 拖动平移时剪贴板窗口不失焦。

文字编辑（C101.3）
10. 按 Ctrl+E 或点铅笔，预览拿到键盘，中文输入法能打字，剪贴板窗口不关。
11. Ctrl+S 改这条后焦点回到剪贴板窗口，底栏「已改这条」能撤销，列表标「已编辑」。
12. Ctrl+Enter 只粘贴这次，仍贴到弹出前的程序（剪贴板固定时也一样）。
13. 编辑时点别的程序，两个窗口都关（固定时剪贴板窗口留着）；点剪贴板窗口只退出编辑。
14. 全屏档时剪贴板窗口压在预览上，挡住部分编辑框，看能不能接受。

15. 用 Win+V 打开的剪贴板窗口，以上各条照样成立。

#### Mac

16. 非 key 面板里能不能收到鼠标进出；按住空格时，提示是否变成「松开后保留」。
17. 点预览里的档位按钮、图钉、× 和拖边时，剪贴板窗口仍是 key、不关；第一次点击就生效。
18. 全屏档时剪贴板窗口压在预览上；全屏应用所在的桌面里，中等、全屏两档的位置。
19. 外接屏（缩放不同）上，全屏档跟着剪贴板窗口那块屏；拖边的位移和鼠标对得上。
20. 触控板捏合能缩放；两指滑动是缩放，手感能接受；2x 屏上 1:1 清晰。
21. 预览出现、点档位和图钉时，仍不抢焦点（G1.18）。
22. 编辑时预览成为 key，拼音能打字；结束后剪贴板窗口重新成为 key。

#### 两边都要测

23. 剪贴板窗口里按 `+` `-` `0`，预览跟着缩放；↑↓ 换条后回到「适应」。
24. 宽版右栏双击能看原图，滚轮仍滚动列表、不缩放。

#### 图片编辑（C101.4，两边都测，Mac 上 Ctrl 换成 ⌘）

25. 按 Ctrl+E 或点「编辑图片」进入编辑，预览拿到键盘，剪贴板窗口不关。
26. 框、箭头、文字（用中文输入法）、马赛克、序号都能画；裁剪按回车应用；能左右旋转；Ctrl+Z 先撤标注，再撤裁剪和旋转。
27. Ctrl+S 改这条：缩略图和预览换成新图，标「已编辑」，识别出的文字几秒后更新；6 秒内撤销能变回原图。
28. Ctrl+Shift+S 另存成新的一条。
29. 4K 大图保存的耗时；PNG 超过 10 MB 时提示没存上。
30. 改这条后大约 15 秒，旧的 png 文件被删掉。
31. 编辑时点别的程序，窗口照常关。
32. Mac：带 ICC 色彩配置的图片，编辑后颜色不变。

#### 编辑器配色（C101.6，两边都测）

33. 深色、浅色岛下，文字编辑器（Ctrl/⌘+E）的「改这条」主按钮看得清，文本框有描边；动作面板里选中项的底色和描边正常。

## 验收

- 清单每一条都测过，结果写进本任务的结论
- 不对的另提 issue
