## 说明
竞品里有拦截 Windows 11 Toast 并在岛上弹出的做法（sadeeshasathsara/dynamic-island-on-windows、NotchNook 的 Live Activities），调研见 [dynamic-island-desktop-projects.md](/docs/research/dynamic-island-desktop-projects.md)。浮屿的 QQ 提醒已经用 `UserNotificationListener` 读系统通知（`src-tauri/src/qq_notifications/listener.rs`），只是只认 QQ。把它推广成「用户选哪些应用就显示哪些应用的通知」，钉钉、飞书、企业微信、Teams、Outlook 等一次接上，和消息页的定位一致，成本比再接一个专门的通道低得多。

要先定的：监听要不要从 `qq_notifications` 拆成独立模块（QQ 改成其中一个来源）；应用列表怎么来（读过往通知里出现过的应用，让用户勾选，不手填 AUMID）；消息页怎么分组显示；隐私上只在岛上显示、不落盘还是像 QQ 一样保留最近几条。

## 验收
- 设置里有「其他应用的通知」开关（默认关），打开后列出最近发过通知的应用供勾选
- 勾选的应用发通知时，岛上弹出横幅（应用图标、标题、正文摘要），点击打开对应应用
- QQ 提醒行为不变，回归页和单元测试通过
- 系统没有授予通知读取权限时给出提示和去设置的入口
- 中英文文案；`docs/features/` 写功能说明，`contracts.md`、`platforms.md` 同步（macOS 没有对应 API，标不支持）
