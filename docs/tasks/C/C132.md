## 说明

「贴边隐身」（C111，露出 0px）收起后岛完全看不见，用户会以为软件关了（#864）。希望留一个不占地方的提示：发光的小圆点，或带光晕的小白条，光晕做成可选，以后能加别的效果。

提示不能重新挡住浏览器标签页（见 C117 / #849），要很小并且鼠标穿透；深色、浅色壁纸上都要看得见。

## 验收

- 「设置 → 收起与露出」里，贴边隐身可以选提示样式（至少：无 / 小圆点 / 光晕），中英文文案齐全，跑过 `pnpm settings:index`
- 提示以外的区域照常穿透，唤醒热区不变
- 回归页覆盖三种样式
