## 说明

选区里有二维码时，工具栏或识字结果里给出解码内容：网址可以直接打开或复制，其他文本复制。解码在本机做（Rust 侧找一个纯 Rust、许可证合适的库，或 Windows / macOS 自带的能力），不上传。

## 验收

- 常见二维码（网址、文本、微信名片截图）能识别；没有二维码时不打扰
- 打开网址前显示完整网址
- 单元测试用几张样例图；`cargo test`、`pnpm build:exe`
