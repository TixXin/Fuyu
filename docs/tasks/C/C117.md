## 说明

用户反馈在最大化浏览器（如 Edge / Chrome）顶部操作标签页时，贴边隐藏的小岛存在两处遮挡与误触问题：
1. 收起贴边时露出的边缘条略微遮挡浏览器顶部标签页，且横向宽度与完整收起岛同宽（默认约 300px），覆盖范围过大；
2. 点击关闭标签页（`×`）时鼠标容易擦过顶部露边条，当前一旦进入热区就 `0ms` 立即触发 `onPeek()` 弹出完整小岛，瞬间盖住标签页导致无法点击。

结合已完成的 [C111](/docs/tasks/0-archive/C/C111.md)（标准露边 `10px` / 极简细线 `4px` / 贴边隐身 `0px` 三档预设），进一步补齐贴边隐藏的尺寸自定义与防误触体验：

1. **自定义贴边隐藏露出的宽度与高度**：
   - 在「设置 → 收起与露出」（[TuckSettingsSection.tsx](/src/windows/settings/sections/TuckSettingsSection.tsx)）保留 `C111` 快捷预设的同时，支持自定义贴边收起时的**横向宽度**（例如缩窄为居中短指示条 `80–340px`，两侧区域完全穿透给底层浏览器标签页）与**露出高度**（`0–14px`，为 `0px` 时保留屏幕边缘 `2px` 唤醒热区）。
   - 同步更新 [geometry.rs](/src-tauri/src/island/geometry.rs) 与 `passthrough.rs`（以及前端外壳收起态宽度过渡），确保缩窄后的贴边条只有实际可视/热区矩形拦截悬停，两侧空白区域鼠标点击直达底层窗口标签页。
2. **贴边唤醒防误触悬停延迟（`tuckedHoverDelayMs`）**：
   - 当前 [useTuckedHoverOpen.ts](/src/windows/island/useTuckedHoverOpen.ts) 在 `isTucked` 状态下收到 `inside = true` 即 `0ms` 立刻调用 `onPeek()` 滑出小岛。
   - 新增可调的「鼠标停留在隐藏边缘多久后露出」（默认给轻巧防擦过的短延迟如 `120–150ms`，支持设为 `0ms` 立即或调长），鼠标快速划过/点按标签页关闭按钮移开时取消计时、不误弹小岛。

## 验收

- 「设置 → 收起与露出」可调整贴边隐藏条的宽度、露出高度（与三档预设联动）及悬停露出延迟，支持中英文文案与重置默认值，并更新设置搜索索引（`pnpm settings:index`）
- 最大化浏览器顶栏关闭标签页时，贴边条两侧完全鼠标穿透不挡点击，快速擦过边缘不会误触发小岛滑出遮挡标签页
- 100% / 125% / 150% / 200% DPI 缩放下顶边与底边的几何计算、穿透区与唤醒热区单测覆盖并通过
- 更新 [island.md](/docs/design/island.md)，`pnpm check`、`pnpm build`、回归页、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与双端 CI 全部通过
