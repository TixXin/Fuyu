## 说明

参考 eIsland 的语音转文字。按快捷键说话，识别结果显示在岛上，可编辑后存成待办、每日笔记，或复制。先调研 Windows 自带的语音识别、本地模型（如 Whisper 类）和在线服务的效果、隐私和体积，再定方案。

## 方案（用户定，2026-11-15）

调研见 [voice-input.md](/docs/research/voice-input.md)。两个系统都用本机 SenseVoice-Small int8（sherpa-onnx，Rust 里跑）；模型第一次用时下载（GitHub Release 加国内镜像，校验 SHA-256），不打进安装包；Rust 原生录音（Windows 复用 `win32::audio_capture`，Mac 新写，`Info.plist` 加麦克风说明、`Entitlements.plist` 加 `audio-input`）；快捷键按一下开始、再按一下结束，岛上有停止按钮；不做在线服务；不做自动粘贴到当前输入框。模型只在用时加载、空闲后卸载。
