## 说明

截图的第一到第三版（C41）都已完成，功能面和 Snipaste、Shottr 相当。第四版不再大量加功能，分三组推进，每项是一个子任务：

1. 补短板：独占全屏游戏截成黑屏（C150.1）、冻结画面送进选区窗口太慢（C150.2）；Mac 上的录屏（G1.39）和按控件吸附（G1.40）；已有任务 D48（隐藏的选区窗口让出内存）、G1.32（Mac 上截图带出岛的拖动提示）。
2. 常用的小缺口：标注能选中再改（C150.3）、贴图增强（C150.4）、模糊 / 直线 / 聚光灯（C150.5）、延时截图（C150.6）、二维码（C150.7）、窗口带阴影导出（C150.8）、历史按文字搜（C150.9）。
3. 浮屿独有的：发给 Agent 带指令和来源（C150.10）、放进今日笔记和待办（C150.11）、官方示例图床插件（C150.12）。

建议顺序：第一组先做，第二组先做 C150.3 和 C150.4，第三组放在后面。计划里「不做上传图床、不做成插件」不变：图床走截图卡片的插件动作（`ScreenshotActionSpec`），由插件提供。

## 验收
