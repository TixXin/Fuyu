## 说明

按预览页 [agent-notice-preview.html](/docs/investigations/agent-notice-preview.html) 第 4、6、10 节做多会话的三种叠法（叠放露边、一次一条加 +n、左翼图标堆）和 Mac 刘海时的样子（两翼标题带等），由 C137.4 的设置切换。

## 验收

- 三种叠法都能切换，默认叠放露边，最紧急的在前，悬停展开成列表，点一行换到那条
- Mac 刘海时的样子按设置切换，默认两翼标题带，摄像头那段不放东西
- `notch-island` 和新的叠放回归页、快照更新
- 实测清单（Win、Mac 刘海、浅色、深色、多会话、审批快捷键、三套样式）写进 C137
