## 说明

跨设备同步（调研见 [cross-device-sync.md](/docs/research/cross-device-sync.md)）的同步引擎，第一种方式是「同步文件夹」：用户选一个 OneDrive / iCloud Drive / 坚果云同步盘 / Syncthing / SMB 共享里的目录，浮屿只读写本地文件。

- 远端布局 `fuyu-sync/meta.json` + `devices/<设备 id>/<类别>.json`，每台只写自己的目录，读所有目录后逐条合并（HLC 后写者赢，加上次同步的底稿）
- 第一版数据：待办（含以后的、每日笔记、归档）、常用短语、链接书签、白名单内的设置和外观预设
- 安全阀：第一次并入前自动本地备份；远端清空或大量删除时停下来问；读不了的文件跳过；目录暂时不在（没挂载、刚唤醒）时跳过这一轮；远端格式更新时停止并提示升级
- 写临时文件再改名；忽略冲突副本和各家网盘的临时文件
- 设置页：选文件夹、选同步哪几类、立即同步、上次结果、设备列表；中英文

## 验收

- 两个目录模拟两台设备的合并测试（增、改、删、并发改、首次并入）
- Windows 和 Mac 各用一种网盘实测，列进实测清单
