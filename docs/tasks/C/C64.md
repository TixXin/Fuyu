## 说明

用户群反馈希望显示无线鼠标、耳机等设备的电量。C3 已做蓝牙耳机电量，这里扩到鼠标和键盘：蓝牙低功耗设备走 GATT 电池服务；罗技等用 USB 接收器的设备要 HID++，分两步，先做蓝牙。

## 验收

- 蓝牙鼠标、键盘的电量在岛上能看到，低电量时提醒一次
- 拿不到电量的设备不显示，不报错
- 调研结论写清楚接收器类设备要怎么做
