## 说明

功能零散第 1 轮（计划见 [feature-misc-plan.md](/docs/architecture/feature-misc-plan.md)）里几项在 Mac 开发机上测不了的，合在这里由用户在真机上测。用正式构建（`pnpm build:exe`）或开发版逐条测，结果写进任务文件；不对的另提 issue。

#### C122（#901）微信会话定位重试：Windows

微信提醒走 Windows UIA，Mac 上测不了。

1. 微信刚从托盘唤出、会话列表还在加载时点岛上的提醒，能打开对应会话。
2. 目标会话在列表下面、不在可视区：3 秒内列表自己滚到它（例如新消息把它顶上来）就能打开，否则 3 秒后照旧只唤出微信（不会主动滚列表）。
3. 超时（例如会话已被删除）不卡住，照旧唤出微信。

#### C127（#900）酷狗本地歌词缓存：Windows

在哪台机器：装了酷狗音乐客户端（KuGou8）的 Windows 电脑，用含 C127（`9d9a038b`）的构建。Mac：开发机上没有装酷狗，也没找到 Mac 客户端的歌词缓存目录，C127 只读 Windows 的目录；手头有 Mac 版酷狗的话，看一眼 `~/Library` 下有没有 `.krc` 文件，有就记下路径，另提 issue。

1. 设置 → 音乐 → 歌词：打开「在线查找歌词」和「也查酷狗、QQ 音乐和网易云」。
2. 在酷狗客户端里放一首中文歌（例如周杰伦《晴天》），等它显示出歌词，让它把歌词缓存到本机。确认缓存在：`%SystemDrive%\KuGou\Lyric`，或 `%APPDATA%\KuGou8\KuGou.ini` 里 `LyricPath=` 指的文件夹，里面有形如 `周杰伦 - 晴天-<一串十六进制>-….krc` 的文件。
3. 关掉酷狗，断网（或拔网线 / 关 Wi-Fi），用别的播放器（QQ 音乐、网易云、系统自带播放器）放同一首歌。应该看到：岛的音乐页和收起条照常出歌词，而且是逐字高亮的（证明来自本地 KRC 缓存，没联网）。
4. 放一首酷狗没放过的歌（仍断网）：应该没有歌词（在线来源连不上，可能显示查找失败），岛不卡。
5. 在酷狗设置里把歌词目录改到别的文件夹（会写进 `KuGou.ini` 的 `LyricPath`），重复第 2、3 步：改过的目录也能读到。
6. 关掉「也查酷狗、QQ 音乐和网易云」，重复第 3 步：应该不再读本地缓存（断网时没有歌词）。
7. 确认岛没有改动酷狗的文件：缓存文件夹里的文件数和修改时间不变。

#### C124（#897）收起条长消息的点击区域：Windows 和 Mac

C124 做完后补具体步骤。大致是：长消息让收起条加宽、换行之后，岛的点击区域和看到的大小一致，岛外的桌面照常能点；刘海、贴边收起、底边吸附下也一样。
