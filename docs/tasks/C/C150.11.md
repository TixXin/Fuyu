## 说明

截图卡片的去处现在是拖出、文件中转、发给 Agent 和插件动作。加两个：把图放进今日笔记（笔记要能显示图片）；建一条待办，待办带这张图（点开能看）。如果笔记和待办已经是第 3 版插件，就做成它们注册的截图动作（`ScreenshotActionSpec`），不在截图模块里写死。

## 验收

- 两个去处在卡片上能用，图片文件跟着笔记 / 待办保留，不被截图历史的清理删掉
- 中英文文案；截图卡片回归页更新
- `pnpm check`、`pnpm build`
