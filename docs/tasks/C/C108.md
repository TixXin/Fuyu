## 说明

任务 [C107](/docs/tasks/0-archive/C/C107.md)（#740）在 macOS 开发机上完成了 Windows WASAPI 进程级音频会话识别、窗口标题曲目解析与自定义播放器添加功能的开发与单测验证。需要在 Windows 真机上对实际播放器进程、后台暂停浏览器共存及设置页添加流程做一次真机实测。

## 验收

- 在 Windows 真机打开飞牛音乐桌面版（`xtMusic` / 网页应用）或未装 SMTC 插件的 `foobar2000` 播放歌曲，同时后台保留一个暂停视频的 Edge / Chrome 标签页，确认岛上显示跳动波形、来源显示「飞牛音乐」（或 `foobar2000`）并从窗口标题提取「歌名 - 歌手」匹配在线歌词
- 在「设置 → 音乐 → 来源优先级」点「添加音乐软件」，确认可一键点选正在运行的程序或手动输入 `.exe` 进程名加入列表、参与拖拽排序与移除
