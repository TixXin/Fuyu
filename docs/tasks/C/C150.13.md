## 说明

把岛的面板展开后按截图快捷键，选区能识别并贴住面板的位置，但截出来那块只有壁纸，面板不见了。群友说是「今天」才开始，之前能正常截到展开的面板，像是最近版本带出的回归。

视频（20 秒）里的过程：展开面板（首页卡片），按截图，选区框在面板原来的位置，框里是壁纸和桌面，面板已经消失；截图结束后面板也没回来。

- 类别：问题
- 平台：Windows（任务栏和壁纸看得出，系统版本没说）
- 群里反馈：2026-11-27，同一位群友前后两条（浮汐 FB-36、FB-37）

初步怀疑：

截图开始时岛先收起或被隐藏（失焦收起、窗口隐藏），之后才拍下定格画面，所以选区只拿到之前记下的窗口矩形。最近动过截图时序的提交：`85804b714 perf(screenshot): speed up frozen frame delivery to overlay window (C150.2)`、`ced39706b feat(screenshot): add 3/5/10s delayed screenshot with island countdown (C150.6)`，待核实。

## 验收

- 展开面板后按截图（快捷键和岛上的截图入口都试），定格画面里有面板，选区贴住面板后截出的图完整
- 截图过程中和结束后面板不会自己收起或消失（用户主动点别处除外）
- Windows 和 macOS 都确认
