## 说明

外观里现在有四处能「一键换一套」，各管一部分：外观 → 主题的「内置主题」（灰白、通透、暖白，只改配色和不透明度）、液态玻璃里的「预设」（C104，只改玻璃参数）、「我的预设」、外观最后一个标签页「主题市场」（配色、字体、圆角）。用户（2026-11-18）定：主题是一整套风格，放在外观最前面，让人先从挑好的几套里直接选，再去各处微调。

- 外观 → 主题页最上面是一组带实时预览的卡片：内置主题、我的预设、市场主题放在同一处，最后一张「更多主题」从市场加载
- 「主题市场」标签页并进来，不再单独占一个标签；旧的跳转（概览页的入口、插件设置里的「主题市场」）改成打开主题页并定位到市场那一组
- 主题市场仍是第 3 版内置插件 `theme-market` 提供：它往主题页登记一个区块，而不是登记一个分类
- 选一套就把它的数值复制进设置；之后微调不受升级影响，主题数值以后改了，已经用上的那份不跟着变，卡片显示「自定义」
- 液态玻璃里的预设保留，它只管材质，和整套主题不是一个层级

## 验收

- 外观第一页最上面是主题卡片，内置、我的预设、市场三类在一处，中英文，窄窗口不溢出
- 主题市场的下载、应用、分享在新位置都能用，旧的入口都跳到这里
- 选主题后微调，卡片变成「自定义」；重启、升级后微调还在
- `pnpm settings:index` 重跑，设置搜索能搜到主题和市场
- 相关回归页（设置、主题市场）更新并通过；`pnpm check`、`pnpm build` 通过
