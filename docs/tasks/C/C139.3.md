## 说明

刘海形态下收起条不放常驻文字（待办、歌词、Agent 标题、会议），2026-11-13 定的，原因是两翼太窄。结果是这些内容在刘海屏上只能悬停或展开看。

定下来的做法（方案的 B）：文字类内容在刘海屏上的去处每个项目自己选，默认**只在小面板**（C139.2 的那张卡片上半部分），另外三档：

- 刘海下常驻一行（复用消息预览在用的那一行；会一直盖住下面窗口的标题栏，所以不是默认）
- 有变化时出现 4 秒（Agent 一轮跑完、切歌）
- 不显示（现在的行为）

消息和长提示仍然优先占这一行。存储用新 key `fuyu-collapsed-text`，不往 `fuyu-collapsed-items` 里加新的 `zone` 值（旧版本的校验会把整项丢掉）。

## 验收

- 刘海屏上歌词、Agent 标题、待办能在小面板里看到；每项能改成另外三档，行为和预览页一致
- 没有刘海时行为不变
- `docs/design/macos.md`「刘海」一节更新，`contracts.md` 记下新 key，新 key 进同步和备份；回归页覆盖四档
