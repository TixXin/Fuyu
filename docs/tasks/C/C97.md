## 说明

接着 C87：在流动彩色、高光、形变下面加一层岛正后方那块壁纸的毛玻璃（Rust 读壁纸并缩小，前端按岛的屏幕坐标取样，模糊、提饱和、着色、噪点），新增 glassBackdrop / glassBlur / glassSaturation / glassNoise 进 GLASS_SETTING_KEYS，随主题和预设保存；做完往 TixXin/fuyu-plugins 的 themes.json 加三套主题（iOS 毛玻璃·流彩、iOS 着色玻璃、Mica）。社区产品和 Apple Liquid Glass 的调研见 docs/research/ios-style-glass.md，预览页见 docs/investigations/ios-glass-preview.html。iOS 26 边缘折射这次不做（预览页里在 Chromium 下没调通）。

## 验收

- 旧数据没有新字段时按默认值读，外观不变；主题导出和预设保存都带上新字段，设置里能调
- 换壁纸、拖动、贴边、换屏、展开收起时，玻璃里的画面和背后的壁纸对得上；多显示器各用自己的壁纸
- 取不到壁纸、系统关掉「透明效果」时退回 C87 的 CSS 玻璃；收起闲着时占用不上升
- 「文字保护」按取样处的亮度提高底色浓度；`pnpm test:regression` 通过（含浅色）
- 三套主题上架 `TixXin/fuyu-plugins` 的 `themes.json`
