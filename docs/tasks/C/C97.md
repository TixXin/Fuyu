## 验收

- 旧数据没有新字段时按默认值读，外观不变；主题导出和预设保存都带上新字段，设置里能调
- 换壁纸、拖动、贴边、换屏、展开收起时，玻璃里的画面和背后的壁纸对得上；多显示器各用自己的壁纸
- 取不到壁纸、系统关掉「透明效果」时退回 C87 的 CSS 玻璃；收起闲着时占用不上升
- 「文字保护」按取样处的亮度提高底色浓度；`pnpm test:regression` 通过（含浅色）
- 三套主题上架 `TixXin/fuyu-plugins` 的 `themes.json`
