## 说明

用户群反馈：展开面板页头里全是图标，只有第一个 Fuyu 是英文字，希望页面图标能自定义。

现状：已经有把 Fuyu 标签换成水母图标的开关（设置 → 行为 → 打开 →「Fuyu 标签用图标」，`fuyuTabIcon`，默认关），但用户没找到。各页面图标自定义还没有。

要做：把这个开关放到更容易找到的地方（例如岛屿布局的页面列表里），并决定是否默认用图标；再看能不能在岛屿布局里给每个页面换图标（从内置图标库里选），存储格式写进 contracts.md。

## 验收

- 用户能在岛屿布局附近找到 Fuyu 标签用文字还是图标
- 能给各页面换图标（或在任务里写明不做的原因），重启后保留
- 中英文文案；回归页覆盖页头图标替换
