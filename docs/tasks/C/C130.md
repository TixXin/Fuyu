## 说明

岛开着「始终置顶」，但会被别的也设了置顶的窗口盖住（#882）：微信图片查看器点了「置顶」图钉后盖在岛上；另一例是一个蓝色标题栏、标题以 `Epl…` 开头的窗口。主窗口现在只靠 `tauri.conf.json` 的 `alwaysOnTop: true`，之后没有再把自己提到置顶层最前。

做法：别的置顶窗口出现或到前台时，用 `SetWindowPos(HWND_TOPMOST, SWP_NOACTIVATE)` 把岛重新放到置顶层最前，不抢焦点。全屏让位、截图选区、贴图这些现有规则不变。和 C134（岛挡住东西时让位）要一起考虑，别互相打架。

## 验收

- 微信图片查看器置顶时，岛仍显示在它上面
- 岛不抢键盘焦点，全屏时的让位行为不变
- Windows 真机实测，测不了的留实测清单
