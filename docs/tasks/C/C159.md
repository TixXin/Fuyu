## 说明

状态灯样式和中心图案里的「悬岛」（取值 mark 不变，老设置不用迁移）改画成水母：身体颜色随状态变（空闲米白、运行蓝、等你黄、失败红、完成绿），表情和动作照 jellyfish-set-preview.html 的七种状态（运行划水、等你跳、失败晃一次、完成上浮一次），浅色岛空闲时加描边。设置里的选项名、预览图和文案一起改；mark.svg 换成水母。验收：岛上 24px 看得清各状态；减少动画时不动；pnpm check、pnpm build、回归页通过。
