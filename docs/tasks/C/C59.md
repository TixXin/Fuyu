## 说明
d-island、DynamicWin 都有天气（调研见 [dynamic-island-desktop-projects.md](/docs/research/dynamic-island-desktop-projects.md)）。天气要联网、要知道城市，放进内置会违背浮屿默认不联网的做法，所以做成市场插件，同时当插件生态的一个示范。数据源优先用 Open-Meteo（不要 API key，有中文地名检索）。

## 验收
- 插件设置里按名字搜城市选择，不读系统定位；不配置城市时不联网
- 收起条可选显示图标和温度（默认关）；岛上「天气」页显示当前、今天逐小时和未来 7 天
- 可选「一小时内要下雨时在岛上提醒」，默认关
- 刷新间隔不低于 30 分钟，失败时显示上次结果和更新时间
- 有 README 和 CHANGELOG，按 [lanes.md](/docs/architecture/lanes.md) 的插件发布流程上架市场
