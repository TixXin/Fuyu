## 说明

按预览页 [agent-notice-preview.html](/docs/investigations/agent-notice-preview.html) 的推荐 B 做通知卡片：带状态环的图标、状态句、标题独占一行、消息正文 Markdown 6 行，超出用细的叠加式滚动条在卡片里滚动、悬停展开约 16 行；模型、用时、「你：」进悬停卡。审批和提问卡同一结构，按钮「拒绝 / 到终端 / 允许」，允许用强调色。只有等你确认用橙色（状态字和图标环），等你回复灰蓝，出错红。

## 验收

- 五种状态、审批卡、提问卡都是新结构，浅色和深色岛都对
- 长消息在卡片内滚动，滚动条 3～4px 叠加式、深浅跟岛走、上下渐隐，滚到底不传给岛，减少动画时不淡入淡出
- 窄于 300px 按钮只剩图标，中英文不溢出
- `agent-alert-card`、`agent-approvals` 回归页和快照更新
