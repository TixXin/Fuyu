## 说明

群友说外设（键盘、鼠标、耳机等）的电量还不能显示在岛上。外设电量常驻显示是 C161（#1163）做的，0.3.12 已发布，可能是群友的版本旧、设备没被识别，或者显示入口不好找。

- 类别：建议
- 平台：未说明

待补：

## 验收

- 按群友的设备确认原因：版本旧就告诉他怎么开；设备读不到电量就补上支持，补不了的在界面或文档里说明支持范围
- 外设电量的开启入口在设置里好找
