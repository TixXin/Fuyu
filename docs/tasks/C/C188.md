## 说明

Windows 上企业微信来消息时，岛上只提示「有新消息」，看不到发送人和内容。群友已在企业微信设置里打开「通知显示消息详情」（附了截图）。另一位群友问飞书等其他来源能不能也显示详情。微信已经可以在浮屿设置里打开详情。

- 类别：问题
- 平台：Windows
- 群里反馈：2026-11-25 至 11-26，2 人提到（浮汐 FB-11）

初步怀疑：

- 聊天来源在 `src-tauri/src/im_sources/specs.rs`，企业微信、飞书等走 Windows 通知；岛上不显示详情可能是只取了标题没取正文，或者这些来源默认按隐私模式处理，待核实

## 验收

- 企业微信打开「通知显示消息详情」后，岛上能显示发送人和内容
- 弄清飞书、钉钉、Telegram 等其他来源能不能显示详情，能的照样支持，不能的在设置里写明原因
- 设置里每个来源显示详情的开关和说明一致，中英文都有
