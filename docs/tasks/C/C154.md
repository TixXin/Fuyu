## 说明

在 Windows 11 上，让浮屿的东西能「放进」任务栏，像汽水音乐的任务栏歌词条那样。分两样：

1. **岛屿吸附到任务栏**：设置 → 外观 → 位置与尺寸 →「吸附到」加一个「任务栏」，折叠的岛贴合任务栏高度，摆在任务栏空白处，展开时向上开。
2. **音乐歌词组件吸附到任务栏**：新做一个独立的任务栏音乐组件（封面、歌名歌手、当前一句歌词、上一首 / 暂停 / 下一首），岛留在原来的位置，组件单独放在任务栏上。

### 为什么

用户想要汽水音乐那种任务栏歌词。调研见 [windows-taskbar-embedding.md](/docs/research/windows-taskbar-embedding.md)：汽水音乐并没有 `SetParent` 进任务栏，而是一个顶层透明窗口，所有者（owner）设成 `Shell_TrayWnd`，加 `NOACTIVATE | TOOLWINDOW | TOPMOST`，摆在托盘区左边。我们照这个做，不注入 Explorer。

### 拆分

- C154.1 任务栏宿主：两样都要用的底层（找任务栏、设 owner、算空白区域、跟随任务栏变化、Explorer 重启），并先实测 Explorer 重启时被拥有的窗口会不会被一起销毁
- C154.2 岛屿吸附到任务栏
- C154.3 音乐歌词组件吸附到任务栏

## 验收

三个子任务都完成；Win11 靠左和居中对齐、自动隐藏、全屏应用、Explorer 重启、多显示器下都正常；Win10 和 macOS 不显示这两个选项，platforms.md 写明。
