## 说明

参考 eIsland 的闲置、悬停、展开、全展开四层：光标停在收起的岛上时，先出一个比收起条大一点的预览（当前歌词、时间、下一个日程等轮换），点击或继续停留才展开面板；面板上滚轮切换页面。要先评估和现在的「悬停展开」、悬停切页（C23、C35）怎么共存，做成可选。

## 验收

- 先出交互方案（写进任务备注），和用户确认
- 预览层可选开关，不影响现在的默认行为
- 滚轮切页可选，不和面板内滚动冲突

## 备注

### 交互方案（2026-11-15，用户确认：全部按推荐值）

可点的预览页：[hover-preview-preview.html](/docs/investigations/hover-preview-preview.html)（收起 → 预览 → 展开、滚轮切页、深浅岛、顶边 / 底边、消息预览和音量提示、贴边收起）。下面的推荐值就是预览页里默认选中的那一项。代码里「peek」已经指贴边收起时露出（`isPeeking`），这里一律叫「悬停预览」（`hoverPreview`），免得混。

**一、和现有展开方式怎么组合**

- 「展开方式」从两项变三项：点击（默认）/ 悬停 / 悬停预览（新）。悬停预览 = 点击模式 + 悬停先出预览；和「悬停直接展开」互斥，不叠加（悬停模式下 300ms 就展开，中间再插一层只会更慢）。默认仍是点击，老用户不变。
- 存成 `expandTrigger: "preview"`，只是多一个取值；读到不认识的值按 `"click"` 处理（旧版本降级也安全）。

**二、预览层**

- 形态：收起条那一行原样留在上面（状态灯、用量环、会话数、音乐 / 文件中转按钮，音量和设备提示照常在这一行），摘要文字淡出；下面长出一行 48px 的卡片区。岛从 38 × 收起宽 长到 86 × max(收起宽 + 40, 400)，不超过面板宽；圆角 22 → 24。底边吸附时翻过来：收起条那一行贴下沿，卡片在上面。
- 出现：停满「悬停延迟」（复用现有设置，默认 300ms，悬停预览模式下也显示这个滑块）。不出的情况和现在暂停悬停展开一样：按下鼠标、按住 Alt、消息一行预览或横幅正在显示、游戏免打扰、托盘隐藏；缩回后光标要移开再回来才会再出。
- 消失：光标移开 200ms 缩回收起条（不用「移开后收起延迟」，那是给面板的）。
- 内容：一次一张卡，按优先级排：Agent 等你确认 / 回复 > 15 分钟内的会议 > 正在放歌（封面 + 当前歌词 + 歌名 · 歌手，播放 / 暂停按钮）> 未读（各来源计数 + 最新一条）> 下一个日程 > 待办（进行中的任务或剩余数）> 时间日期农历（兜底，只在别的都没有时出）。紧急的两种（Agent 等你、会议）钉住不轮换；其余每 4 秒轮换一张，右边竖排小圆点，点圆点手动切。
- 点击：点卡片直接打开对应页面（音乐卡 → 音乐页，未读 → 消息页…），点预览空白处展开当前页；卡片上的按钮（播放 / 暂停、加入会议、去处理）只做自己的事，不展开。点击不抢焦点，和点收起条一样；只有展开时才拿焦点。

**三、从预览进入展开**

- 点击（空白或卡片）；在预览上向下滚一格展开，向上滚一格缩回收起条。
- 继续停留自动展开：默认关（选这个模式的人就是不想面板自己弹出来），可选 1 / 1.5 / 2.5 秒；开着时卡片区底部一条 2px 主题色细线走倒计时。

**四、和其他东西的关系**

- 消息一行预览 / 横幅：显示期间不出预览；预览开着时来消息，缩回收起条显示一行预览。「展开面板」模式来消息照旧自己展开。
- 音量 / 亮度 / 设备提示：照常占上面那一行，卡片不动。
- 歌词（D60）：预览开着时收起条上的歌词淡出，只在音乐卡里显示，不重复；D60 的让位规则只管收起条。
- Agent 审批弹出：照旧直接展开到 Agent 页，预览让位。
- 贴边收起：碰到细条先按「贴边时悬停」的设置走（露出收起条或直接展开）；露出后继续停留满延迟再出预览。
- 侧边竖向岛：不出预览（44px 宽放不下卡片，文字类内容那边已经走横向气泡），悬停什么都不做，点击展开。以后真要做，用横向气泡的样子。
- 底边吸附：往上长，见上面。Mac 刘海模式：卡片区从刘海下面长出来，上面那一行照旧分在刘海两侧。
- 拖动：在预览上按下就收回预览再拖；按住 Alt 不出预览。

**五、滚轮切页（独立开关，默认关）**

- 放在设置 → 页面切换，和「悬停切换页面」并列。和展开方式无关，点击模式也能用。
- 在哪滚算切页：只在顶部图标栏那一行（状态灯到右侧圆按钮，约 46px 高）。内容区永远交给页面自己滚，能不能滚都不切页：可滚的页面滚到底时再切会误切，「不能滚时才切」又让同一个手势在不同页面意思不一样。预览页里能试另外两种：「图标栏 + 不能滚的页面」「任意处按住 Shift」。
- 方向：向下 / 向右 = 下一页，向上 / 向左 = 上一页，顺序就是图标栏的顺序；到头不循环。
- 节流：累计 deltaY 满 50px（鼠标一格就够，按行滚的设备按一行 40px 算）切一页；切完 450ms 内的滚动全吞掉（和 `PAGE_SWITCH_SETTLE_MS` 一样，正好等岛改完宽度），吞的期间再有滚动就续 150ms，触控板惯性不会连跳；200ms 没有滚动清零累计。
- 和悬停切页共存：滚轮切页后图标会因岛变宽平移，现有的 `pageHoverMoved` 只认光标真的动，不会被带着误切。
- 岛不拿焦点时滚轮也要能收到：Windows 默认「滚动非活动窗口」是开的，WebView2 能收；实现时在 Windows 上实测一次，Mac 上非激活面板同样要测。

**六、原生端要改的**

- 点击区域：`src-tauri/src/island/state.rs` 的 `IslandMode` 加一个 `Preview`（前端传 `"preview"`），`IslandWindowState` 加 `preview_width`、`preview_height`；`base_size()` 和圆角在 `Preview` 时取预览的尺寸，`cursor_on_island` / `island_rect` 跟着就对了，`passthrough.rs`、`passthrough_macos.rs` 的进出判断和 `island-hover-changed` 不用另写。预览不拿焦点、不开失焦收起监听（和收起一样）。
- 舞台窗口：预览 86px 高，比展开面板小，舞台窗口不用另外变大；要核对收起时舞台窗口是不是按收起高度缩过，缩过就按展开时的尺寸处理。
- 横幅命中（`banner_hit.rs`）：预览期间不出横幅，不用改。
- 底边吸附、刘海：`island_top_in_stage` 已按吸附边算位置，预览沿用；刘海的点击判断（`point_in_notch`）要加 `Preview`。

**七、实现时的拆分（第 3 波）**

1. 原生端 `Preview` 模式和点击区域（Rust 测试覆盖命中）。
2. 前端 `useHoverPreview`（从 `useHoverExpand` 拆出共用的武装 / 暂停逻辑）、预览层组件、卡片挑选（纯函数，`node:test`）。
3. 滚轮切页 `useWheelPageSwitch` + 节流纯函数（单测）。
4. 设置：展开方式第三张卡片、滚轮切页开关、继续停留展开；`pnpm settings:index`；中英文案。
5. 回归页：预览层深浅岛对比度、顶边 / 底边。

### 用户定的点（2026-11-15 用户确认：都按括号里的推荐值）

实现时把定下来的规则写进 `docs/design/island.md`（展开方式那一大条和页面切换那几条旁边），标「用户确认」。

1. 放在哪：「展开方式」第三项（推荐），还是点击模式下的一个子开关？
2. 预览里继续停留自动展开：默认关（推荐），还是默认 1.5 秒？
3. 卡片：轮换、紧急的钉住（推荐），还是固定只显示最要紧的一张？要不要让用户勾选参与的卡片（推荐先不做）？
4. 预览尺寸：86 × 至少 400（推荐），还是更紧凑的 70 高（卡片只一行字）？
5. 滚轮切页范围：只在顶部图标栏（推荐），还是图标栏 + 不能滚的页面，或任意处按住 Shift？
6. 侧边竖向岛不出预览（推荐），还是做成横向气泡式的预览？
