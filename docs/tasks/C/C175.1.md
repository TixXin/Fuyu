## 说明

Fuyu 面板上只能看、点不进去或点了没反馈的组件，补上入口和反馈：

- 月历：点某天看当天日程、能翻月、能打开日历；一周起始日跟随语言设置；补标题行
- 下个会议：有会议链接时能一键加入，点了能打开日历
- Agent 会话：点会话跳过去，等你的会话能直接处理或跳转
- 用量：没配置或没数据时说明原因，显示什么时候重置
- 文件中转：文件能拖出、打开或在文件夹里定位；中转关着时说明是关了
- 计时器：没有计时时能直接开始一个
- 待办：能新建，能打开笔记页；未完成的排在前面
- 剪贴板、截图、翻译：复制成功有提示，失败也提示；截图、剪贴板、翻译能打开完整页面
- 未读消息：大数字和下面各行对得上
- 音量亮度：亮度条不再假装能拖（能调之前看起来就是只读的）
- 媒体：补上一曲、能打开媒体页

## 验收

上面每个组件点了都有反应：要么执行动作并有反馈，要么打开对应页面；没有能点却没反应的地方。中英文文案齐全，窄尺寸不溢出。
