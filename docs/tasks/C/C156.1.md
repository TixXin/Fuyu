## 说明

新建一级设置页「岛屿布局」，收起条一节放：和真岛一样的收起条预览（点一项定位到清单）、现在的「收起条上的项目」清单（左侧 / 文字位 / 右侧 / 小面板 / 不显示）、「+N」开关和刘海两侧最宽。清单每一行能展开，里面是这一项的样式，从各处搬过来：状态灯样式、会话环样式和显示会话数、用量环上岛的 Agent、中心图案、「剩余 N 个待办」。

原位置（AI Agent 页、待办页、插件设置、插件详情的「显示在岛上」、外观 → 收起条）换成一行只读链接「在岛上：右侧第 3 个 · 调整 ›」，保留两个版本后再删。右键菜单底部「排列…」改为打开这一页。

文字位排序由 C139.4 做，这里只是把它搬进新页面，所以等 C139.4。

方案 [island-layout-plan.md](/docs/investigations/island-layout-plan.md)，预览 [island-layout-preview.html](/docs/investigations/island-layout-preview.html)。

## 验收

- 收起条的显示、位置、样式只能在「岛屿布局」里改，别处只有链接
- 点预览上的一项，清单滚到这一行并展开
- 不加新的存储 key，老用户的设置原样保留
- 设置搜索索引（`pnpm settings:index`）和回归页更新
