## 说明

用户 2026-11-19 定：液态玻璃改成实时透出岛后面的窗口，不再只透壁纸，推翻 `docs/design/island.md`「不透出桌面」那条（2026-11-15 的决定）。

现状：设置 `glassBackdrop` 有 `none` / `wallpaper`（默认，C97）/ `native`（C90，只在 Mac 出现，「原生透出（实验）」）。Mac 的 `native` 已经实时透出后面的窗口；Windows 的 `src-tauri/src/island/glass.rs` 只返回 `css-fallback`。

做法（组长计划，用户 2026-11-19 按建议通过）：

- **Windows 采集**：移植上游 fly-island 7d639493（GPL-3.0，我们是它的 fork）的 `win32/desktop_duplication.rs` 和 `island/glass_capture.rs`，前端参照它的 `useGlassCapture.ts`、`glassFrame.ts`（`gh api "repos/flyl1u/fly-island/contents/<路径>?ref=7d63949335f8105c48f42aa2ff216e9c8b50ba57" --jq .content | base64 -d`；做法和实测见同一提交的 `docs/investigations/glass-live-backdrop.md`）。按本仓库规矩改：不写注释、不 `unwrap`、`unsafe` 只在 `win32/`、单文件 ≤ 800 行。岛所在显示器开 DXGI Desktop Duplication，变化帧整屏拷到 GPU 副本，只把岛后面那块经 mip 缩到 1/4 读回，Rust 里模糊、提饱和，经 Tauri `Channel` 发原始字节，前端画进 `IslandGlassLayer` 里玻璃背后那层 canvas，色调、白雾、噪点、流动色块、高光照旧叠在上面。`apply_glass_material` 在 `native` 时启动采集，返回实际状态（透出 / 退回壁纸 / 退回 CSS）。
- **排除自身**：采集期间对 `main` 设 `WCA_EXCLUDED_FROM_DDA`，停时撤销；拖岛时的 `drag-grid` 辅助线窗口也排除。不用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，它会让岛在所有截图和录屏里消失。本应用截图走 GDI `BitBlt`，不受影响。
- **多显示器和 DPI**：区域用物理像素；区域中心换屏时在驱动那块屏的适配器上重建；混合缩放间拖动要对齐。
- **出错**：`DXGI_ERROR_ACCESS_LOST`、锁屏、UAC 安全桌面、分辨率或显示器变化时丢掉 duplication，1 秒后重建，期间保留最后一帧；连续失败（约 5 次）或系统不支持排除属性、没有 D3D11、远程桌面时退回。
- **占用**：只在液态玻璃 + `native` + 岛露出来时采。展开、拖动、开合动画中最多 30 帧/秒，区域有变化才读回；收起闲着最多 5 帧/秒；贴边隐藏、托盘隐藏、闲置变淡到穿透、刘海折叠、全屏应用占满本屏、游戏免打扰时释放 duplication，停在最后一帧；没活时线程阻塞，不轮询。
- **回退链**：透出窗口 → C97 壁纸毛玻璃 → C87 CSS 玻璃（系统关了「透明效果」时直接 CSS）。选了透出窗口但在回退时，选项下一行灰字说明原因（中英文）。
- **设置（用户定）**：「玻璃背后」三档改名为「透出窗口 / 只透壁纸 / 无」（英文 Live windows / Wallpaper only / None），值仍是 `native` / `wallpaper` / `none`，Windows 也显示 `native`；两个平台默认都是 `native`，Mac 去掉「实验」。已存 `wallpaper` 的老设置迁移一次到 `native`（加迁移标记，之后用户再选壁纸就尊重）；迁移和默认值变化写进 `contracts.md`。
- **Mac**：不另做采集，沿用 C90；只受上面文案、默认值、迁移影响。
- **文档同批改**：`docs/design/island.md`（「不透出桌面」改成透出窗口，写明用户 2026-11-19 定；C97 一节改为「回退：只透壁纸」）、`docs/architecture/platforms.md`（两边都支持，Windows 写 DXGI）、`contracts.md`（新命令、默认值、迁移）。

预计改动：`src-tauri/src/win32/desktop_duplication.rs`（新）、`src-tauri/src/island/glass.rs`、`glass_capture.rs`（新，非 Windows 有空实现）、`island/mod.rs`（只加 mod 和命令注册）、`src-tauri/Cargo.toml`（windows crate 的 D3D11 / DXGI feature）、`src/windows/island/`（`IslandGlassLayer.tsx`、`useGlassCapture.ts`、`glassFrame.ts`、`api.ts`、`useIslandWindow.ts`）、`src/lib/settings/glassSettings.ts`、`src/windows/settings/sections/GlassSettingsSection.tsx`、`src/i18n/sections/settings/appearance.ts`、`tests/unit/`、`tests/regression/liquid-glass*`。

**在 Windows 机器上做**（要编译 DXGI、要真机实测）。做完后 Mac 同步，由组长另派会话在 Mac 上复核默认值、文案和迁移。

## 验收

- Windows：拖岛经过不同窗口和正在播的视频时，玻璃里是岛后面的实时画面，没有错位；展开、收起、换页时背景始终盖满岛；岛自己和拖动辅助线不出现在玻璃里
- Windows：多显示器、不同缩放之间拖动对得上；锁屏解锁、UAC 弹窗后恢复；全屏游戏时停止采集
- Windows：Win+Shift+S 和本应用截图里岛仍可见
- Windows：任务管理器对比经典 / 只透壁纸 / 透出窗口三种，在静止桌面和身后放视频时的 CPU、GPU，数字写进备注；收起闲着时占用不明显上升
- 采不到时退回壁纸，壁纸也取不到时退回 CSS 玻璃，设置页有说明
- 设置三档文案中英文都有；新装默认透出窗口；老用户存的 `wallpaper` 迁移一次，之后手选壁纸不再被改
- `docs/design/island.md`、`platforms.md`、`contracts.md` 已改
- Rust 单元测试、`pnpm build:exe`、`pnpm check`、`pnpm build`、`pnpm test:regression` 通过，附 `pnpm mq:try` 的 Windows CI 链接
