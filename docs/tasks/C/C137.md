## 说明

岛顶部弹出的 AI 代理状态通知信息挤：第一行塞了绿点、会话标题、模型胶囊、运行时长和提供方图标，会话标题经常被截断；第二行是用户最后一句话，第三行是工具和命令。用户 2026-11-19 要求从各个方面重新设计，先出预览页挑方向，这一阶段不改实现。

## 验收

- `docs/investigations/agent-notice-preview.html` 并排给出 2～3 套差别明显的方案，各写清取舍
- 覆盖：信息层级、标题截断、五种状态（运行中、等你确认且能直接审批、等你回复、完成、出错）、多会话叠放、多家 harness 图标、长命令和多行文本、浅色和深色岛、Windows 和 Mac 刘海形态、出现更新消失的动效、停留时长和悬停停住、点击去向、窄宽度、中英文
- 用户挑定方向后另写实现计划


## 备注

用户 2026-11-19 说「可以了，按预览页开始吧」，未逐条选的按推荐；同日又说「都要，丰富的设置选项，用户可自己选择设置，默认就按你推荐的来即可」：三套样式都做成设置，默认值按推荐。

- 版式：B 状态优先为主体（默认），A、C 作为可选样式；Mac 刘海用 C 的两翼标题带。
- 颜色：橙色只给等你确认的状态字和图标环；主按钮用 `--color-accent`；等你回复灰蓝；出错红。
- 正文：默认 6 行，Markdown，超出在卡片里滚动，悬停展开全文；运行中命令 3 行；模型、用时、「你：」进悬停卡。
- 滚动条：叠加式 3px 细条，平时隐藏、滚动时出现、停下淡出，颜色跟岛的深浅，上下渐隐，滚动不传给岛，减少动画时不淡入淡出。
- 问题 1（选哪套）：B 为主体 + C 的刘海两翼带 + 开始新一轮不弹，三套都可在设置里切换。
- 问题 3（开始新一轮）：不弹，只在收起条显示标题。
- 问题 5（停留）：等你确认留到处理；等你回复、出错留到看过；完成 5 秒；悬停暂停。
- 问题 6（点击去向）：切到会话窗口，右上角 ↗ 开 Agent 页。
- 问题 7（多会话）：叠放露边，悬停展开成列表。
- 问题 8（审批按钮）：拒绝 / 到终端 / 允许，允许在最右用强调色。

设置项和默认值的完整清单见 `docs/design/agent.md`「弹出通知的新设计」，各条也写进了 `docs/design/island.md`「Agent 通知」。实现拆成 C137.1～C137.3。
