## 说明

ShengLin1001 提的 issue #286。液态玻璃现在只是半透明着色底：`island/glass.rs` 一开始就清掉 acrylic、只返回 `css-fallback`，CSS 的 `backdrop-filter` 模糊不到桌面，除了鼠标光斑是静止的。两个方向：流动彩色（mesh gradient / 极光，可跟主题色或封面取色）、iOS 26 式玻璃（透出并模糊桌面、边缘折射和高光）。先调研（当初关原生 acrylic 的原因、透明异形窗上 Mica / Acrylic、Win10 退化、Mac、CSS / SVG / WebGL 的上限和占用），写进 `docs/research/liquid-glass.md`，再出预览页 `docs/investigations/liquid-glass-preview.html` 给用户挑。计划见岛外观主 agent 的分波计划（第 1 波调研和预览，第 2 波实现）。

## 验收

- 调研文档和带浅色版的预览页，用户挑定方向，写进 `docs/design/island.md`
- `appearanceMode: "liquidGlass"`、`glassIntensity` 兼容，新参数随样式预设保存
- 收起、贴边、游戏免打扰时停动画，遵守 `prefers-reduced-motion`，常驻占用不明显上升
- `pnpm test:regression` 通过（含浅色对比度），顶、底、侧三种吸附边都看过

## 交接

- 2026-11-15 05:16：第 1 波调研和预览页做完：docs/research/liquid-glass.md、docs/investigations/liquid-glass-preview.html。结论：当初关原生 acrylic 是因为 DWM 材质铺满 820×460 的透明舞台、SetWindowRgn 裁不住（v0.2.2 92dea57f 的注释，后来随去注释删掉）；Windows 原生材质第 2 波不碰，Mac 的 NSVisualEffectView / macOS 26 液态玻璃可行但要自己加岛大小的 effect view（刘海形态折叠时仍纯黑），建议另开实验任务。推荐做方向 1 流动彩色，默认 1B 慢流动（色块只动 transform），可选 1C 极光+油膜边，叠上方向 2 里不依赖背后的镜面高光、边缘亮线和弹簧形变；贴边、游戏免打扰、隐藏、减少动态效果时 animation-play-state: paused。色块要按相对亮度压（深色 ≤0.1、浅色 ≥0.62）文字才过 3:1。要用户定：只做方向 1 还是高光+形变也单做子风格；默认 1B 还是 1C；颜色跟主题色还是封面；折叠岛何时流动；浅色岛白底淡彩行不行；Windows/Mac 原生实验要不要建任务；深色岛颜色偏沉能不能接受。Windows 实测清单见调研 §6。
