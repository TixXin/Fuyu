## 说明

用户复制了 GLM 的 API key，想在剪贴板历史里删掉时，删除按钮出现在窗口可见范围之外，点不到（#863，用户群里有录屏）。可能和 #847（行菜单二次确认点击失效）有关，也可能是菜单或按钮被窗口边界裁掉。

另外，系统的「不要记录」标记已经认了（`src-tauri/src/win32/clipboard.rs`），但从网页或终端复制的 key 不带这个标记。要给出结论：长得像密钥的内容（`sk-…`、长 hex / base64 串等）是不记录还是打码显示、默认开还是关、有没有开关。

## 验收

- 剪贴板条目的删除入口在列表底部、窗口边缘等任何位置都能完整显示并点到；录屏里的操作能删掉那条记录
- 对密钥类内容给出结论并实现，中英文文案齐全
- 回归页覆盖最后一行的菜单位置
