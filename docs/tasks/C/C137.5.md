## 说明

Agent 通知重新设计（[C137](/docs/tasks/0-archive/C/C137.md)，#991）已合入 main（PR #1015、#1020），回归页只在 Mac 浏览器和 Windows CI 里跑过，真岛、Windows 桌面和 Mac 真刘海都没上手测。这一项是给用户（或另一台机器）照着测的清单：

1. Windows 深浅色岛：三套样式（状态优先 / 精简两行 / 两翼）各弹一次运行中、等你确认、等你回复、完成、出错，看颜色和截断
2. 多会话：同时让 3 个会话进入等你确认 / 出错 / 等你回复，分别把「多个会话同时来」切成叠放露边、一次一条 +n、左翼图标堆，看最紧急的在前、悬停展开列表、点一行换到那条、移开收起、岛高度跟着变
3. Mac 真刘海：刘海样子切两翼标题带（左翼图标和状态环、右翼状态字、摄像头那段空着）和卡片在刘海下面
4. 审批：等你确认时 Y/N/T 快捷键和按钮顺序设置照常，两翼标题带下审批卡也在刘海下面
5. 长消息：卡片内滚动、细滚动条、上下渐隐，滚到底岛不切页不收起
6. 减少动画：列表和滚动条不淡入淡出
7. 设置页 AI Agent → 提醒的 16 项逐个改，通知跟着变；恢复默认
