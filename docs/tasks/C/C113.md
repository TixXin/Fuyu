## 验收

- Windows 真机旧版 `todos.json`（v1）、`clipboard-links.json`（v1）启动后正常展示，修改单条后升级为 v2 且其余条目 `updatedAt` 不变；`%APPDATA%\com.tixxin.fuyu\sync-device.json` 独立于 `.fuyu` 家目录；QQ 通知、微信提醒开关与 PrtSc 接管不进入 `settings-sync-meta.json`
- Windows 与 Mac 真机分别在「设置 → 通用 → 跨设备同步」选择同一个 OneDrive / iCloud Drive / 坚果云同步盘 / Syncthing / SMB 子目录，验证首轮本地备份、按条 HLC 合并、设备列表、「在文件夹中显示」与「可选同步」分组
- 休眠唤醒、SMB 未挂载或 OneDrive 占位文件离线（`0x8007016A`）时跳过本轮且不误判为远端清空
