## 说明

`src/features/translation/TranslationPanel.tsx` 聚焦输入框用的是普通 `focus()`，在岛上的翻译页里打开时页面可能往下滚一截。上游 fly-island 的 3d8779fe 改成 `focus({ preventScroll: true })`。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

## 验收

- 岛上和独立窗口里打开翻译，页面都不跳动，输入框照样获得焦点
- 可以和 D104 的真机验收一起看
