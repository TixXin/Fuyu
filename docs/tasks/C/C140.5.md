## 说明

做 C140.4 时查出来的三件事，用户 2026-11-19 要求都解决。1) 内置专注倒计时：待办结束或做完时停掉倒计时，按已专注的整分钟数记，删掉时只停不记；到点时待办不在进行中的不记。2) 顺延到第二天的待办专注时长从 0 开始，本周小结改回逐天相加。3) todos/v1 的 update 多收 addFocusMinutes（Rust 和岛上两条路），官方插件番茄钟一轮专注到点时记到选中的待办上；待办上多记「上次记专注时长的时刻」focusedAt，一次最多记从那一刻到现在经过的分钟数，两边同时计时不重复。番茄钟上架到市场、@fuyu/plugin-services 发 npm 不在这一步。
