## 说明

源自 [fly-island-issue-76.md](/docs/research/fly-island-issue-76.md)（对应第 1 项与第 4 项第一阶段）：

1. **翻译单条全局快捷键支持置空关闭**：
   - 目前翻译模块虽可通过插件总开关整体停用，但开启翻译后，「打开快捷翻译」（默认 `Ctrl+Shift+F`）和「翻译选中文字」（默认 `Ctrl+Alt+T`）两条全局热键均强制绑定，[TranslationShortcutRows.tsx](/src/features/translation/TranslationShortcutRows.tsx) 无清空按钮，[storage.ts](/src/features/translation/storage.ts) 将空值强制回退为默认值，[src-tauri/src/translation/mod.rs](/src-tauri/src/translation/mod.rs) 对空字符串报错 `shortcut.invalid`，启动时 `None` 也会回退注册默认热键。
   - 对齐仓库内截图（[ScreenshotShortcutRows.tsx](/src/features/screenshot/ScreenshotShortcutRows.tsx)）、语音输入、计时器的交互范式：在每条翻译快捷键录制按钮旁提供 `<X />` 清空按钮，允许保存空字符串 `""` 表示单独关闭该热键（显示未设置/已关闭，底层调用 `change_hotkey(None)` / `change_selection_hotkey(None)` 注销且启动时不回退默认值），不关闭翻译功能本身。
2. **本机回环 `custom` 自定义翻译接口支持免 API Key 调用**：
   - 目前 [src-tauri/src/translation/request.rs](/src-tauri/src/translation/request.rs) 与前端自动翻译检查对所有内置提供商一律强制要求系统凭据库存在 API Key，导致本机运行 Ollama 或 MTranServer（`http://localhost:...` / `http://127.0.0.1:...`）的免密钥服务无法直接使用。
   - 当 `provider === "custom"` 且目标地址为本机回环地址（`localhost`、`127.0.0.1`、`[::1]`）时，允许未保存 API Key 直接发起请求（密钥为空时不附带 `Authorization` 头），前端 `hasSecret` / 自动翻译与设置页提示同步放行。

## 验收

- 「设置 → 翻译」与「设置 → 快捷键」中的两条翻译快捷键均可独立点击清除置空，置空后释放系统全局热键且重启应用后保持关闭，点击「恢复默认」可恢复默认热键
- 自定义翻译接口填写本机回环地址且不填 API Key 时，快捷翻译、自动翻译与改写均可正常发送请求，远端 `https://` 自定义接口在未填密钥时仍给出缺密钥提示
- 更新 [translation.md](/docs/features/translation.md) 与 [contracts.md](/docs/architecture/contracts.md)，补充前后端单元测试，`pnpm check`、`pnpm build`、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与 Windows CI 通过
