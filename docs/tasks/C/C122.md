## 说明

`src-tauri/src/wechat_reminders/chats.rs` 的 `open()` 只等 300 毫秒试一次，会话列表还没渲染好或者那一行不在可视区时就会失败，微信停在上一个会话。上游 fly-island 的 b30fa8bf 最多重试 3 秒，两次采样的位置一致才点。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

## 验收

- 微信刚唤出、列表还在加载时，点提醒也能打开对应的会话
- 超时后照旧打开微信，不卡住
- Windows 真机实测
