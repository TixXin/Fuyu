## 说明

Mac 上按住 Option 拖岛会触发系统左右平铺。Mac 上「修饰键 + 拖动」移动岛屿、按住修饰键时展开面板不收起，改用 Control；Windows 仍是 Alt。要改：src-tauri/src/macos/input.rs（加 Control 判断）、island/mod.rs 的 alt_key_down（macOS 分支，改成平台中性的名字）、island/passthrough_macos.rs 的 move_armed / held；前端 src/windows/island/useModifierWindowDrag.ts 在 Mac 上看 ctrlKey，开始拖动后吞掉紧跟的 contextmenu（Ctrl+点击在 Mac 上是右键）；文案 settings/shortcuts.ts（altDragMac 等改 ⌃ Control）。Mac 上没有拖边缘改尺寸（modifier.rs 只在 Windows），快捷键页 Mac 那行改成「按住 ⌃ Control 时展开的面板不收起」，layout.ts 两条尺寸说明在 Mac 上去掉拖边缘半句。文档：docs/design/island.md、docs/architecture/platforms.md。不加选修饰键的设置项。需在真机验证 window.start_dragging 对带 Control 的按下仍能拖，不行改成 Rust 侧跟手移动。

## 验收

- Mac：按住 ⌃ 移到岛上出现可拖手势，⌃ + 拖动移动岛，不弹右键菜单、不触发系统平铺；按住 ⌃ 时展开的面板不收起；按住 ⌥ 不再有效果
- Windows 行为、文案不变
- 快捷键页、尺寸说明在 Mac 上不再提拖边缘改尺寸，中英文都对
- pnpm check、pnpm build、cargo test、pnpm build:exe、pnpm test:regression settings 通过
