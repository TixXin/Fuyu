## 说明

C144（#1086）在 Mac 上做完，代理不跑真岛，下面这些都没在真岛上测过。另外请群里遇到「岛消失」的用户确认：岛不见时再按一次 `Ctrl+Alt+B` 是否回来；没回来的要他们数据目录里的 `frontend-errors.log` 另查。

## 验收

- Windows 上从 0.3.11 升级后，在 VS Code 里按 `Ctrl+Alt+B` 右侧栏照常开关、岛不动；设置 → 快捷键 → 全局 → 岛屿 显示「未设置」
- 设一个键后按下：岛上出现「岛退到窗口下面，再按 X 回来」，约 1 秒后退到窗口下面；提示期间再按一次岛不退；退下去后再按一次马上回到最前
- 岛在下层时点托盘图标：卡片的岛按钮写「在窗口下面」，点一下岛回到最前，卡片不关
- 岛在下层时用原生菜单或再次启动浮屿显示岛，岛回到最前
- Mac 上重复第 2、3 条（菜单栏图标）
- 岛展开或贴边时按键：不出提示，约 1.2 秒后照常退下去
