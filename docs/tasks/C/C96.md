## 说明

用户提到有人在局域网里 Mac + Windows 混用。第一版靠同步文件夹（Syncthing、NAS 共享）和 NAS 的 WebDAV 覆盖；这项是以后单做的局域网直连，定位「局域网剪贴板互传，并能立即触发同步」，设计见 [cross-device-sync.md](/docs/research/cross-device-sync.md)「三、局域网」。

- 自签证书（rcgen），设备 id 取公钥 SHA-256；mDNS `_fuyu._tcp`（mdns-sd）加手填 IP
- 6 位配对码 + SPAKE2 绑定双方证书指纹（或核对校验串）；双向 TLS 1.3 只认配对时的指纹
- 传同一套按设备的记录（按序号拉增量）；可选剪贴板实时推送，敏感条目不推
- Windows 防火墙弹窗、公用网络、AP 隔离的提示；Mac 本地网络权限（`NSLocalNetworkUsageDescription`、`NSBonjourServices`）

排在同步引擎之后，并且要等 Mac 有正式签名的包（G1.12）才能验收本地网络权限。

## 验收

- Windows ↔ Mac 在家用路由器上互相发现、配对、传输；休眠唤醒后重连
- 拒绝防火墙 / 本地网络权限后的提示
