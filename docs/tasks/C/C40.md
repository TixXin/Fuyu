## 说明

用户要在浮屿里内置截图。先全网调研：截图软件应该具备什么功能，优秀的截图软件有哪些先进、独特的做法，以及 Windows 上用 Rust / Tauri 怎么实现；再和用户定第一版做什么，拆成实现任务。

## 验收

- 调研文档写好并合入（[screenshot-tools.md](/docs/research/screenshot-tools.md)）。
- 用户定下第一版、第二版和不做的范围。
- 按定下的范围建实现任务。

## 备注

- 2026-11-10 用户同意先调研再定范围。还没定的两件事：录屏 / GIF 要不要做；做成内置模块还是内置插件（调研建议内置模块，可以在设置里关掉）。

## 结论（2026-11-10）

基础功能已是共识，用户最在意的进阶功能是贴图、长截图、本地 OCR 和自动打码。浮屿能做出别人没有的，是截图之后的去处：岛上预览、进文件中转和剪贴板历史、OCR 交给翻译、一键发给 Agent 会话。技术难点在多显示器和混合 DPI。建议的第一版、第二版和不做的范围见 [调研](/docs/research/screenshot-tools.md) 的「建议的范围」，等用户定。
