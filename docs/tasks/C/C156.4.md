## 说明

C156.3 合入后，用户嫌设置太复杂，设置页按 [island-widgets-settings-preview.html](/docs/investigations/island-widgets-settings-preview.html) 重做了（「收起条 / 展开」切换、页面和组件都是标签、面板按组件顺序自动排、缩略图选大小，单色；见 [collapsed-bar.md](/docs/design/collapsed-bar.md)「收起条 / 展开切换和自定义面板」）。网格模式里用户不再摆位置，下面几条按这个改过。

- **自由排版**：每个面板能切到「自己摆」，组件按 8px 吸附，任意位置、任意宽高，可以重叠，组件按容器大小排版。网格（默认）仍是按顺序自动排。自由切回网格时，按组件当前位置（先上后下、先左后右）定顺序，再自动排一遍；网格切到自由时从自动排出的位置开始。设置页不再加回画布：设置里只有开关，岛上的预览照样画出组件的位置。
- **岛上编辑模式**：面板右上角「编辑」或空白处长按 0.5 秒进入。组件轻微晃动，拖动不拖岛，「−」拿掉，底部「+ 添加组件」（和设置里「可以添加」同一份清单），「完成」/ Esc / 点岛外退出；编辑时岛不自动收起、不悬停切页。网格面板里拖组件是换顺序（放到哪个组件前面），自由面板里是移到那个位置，右下角有拉伸角。
- **面板模板**：工作台（待办 + 下一个会议 + Agent 会话）、娱乐（正在播放 + 歌词 + 天气）。入口见下面「要用户定」第 2 条。
- **组件开放给第三方插件**：`island.widget/v1` 去掉 `builtinOnly`；`meta` 多一个 `icon`（设置页的标签和预览要用）。设置窗口不加载插件代码，所以岛要把第三方组件的 id、名字、图标、尺寸报给设置（和插件页面一样走 `plugin-bar-usage-report`），设置的「可以添加」里按插件分组、标「插件」。更新插件开发文档，市场里至少一个示例（天气、世界时钟、系统监控、快捷启动这些官方插件，C156.3 因为插槽只收内置而没做）。

方案 [island-layout-plan.md](/docs/investigations/island-layout-plan.md)，预览 [island-layout-preview.html](/docs/investigations/island-layout-preview.html)（第一版，设置页部分已被上面的新预览取代）。

**要用户定（开工前问）**

1. 自由排版放在哪里改：只在岛上编辑模式里拖，还是设置页也加回一块能拖的画布？（设置简化之后，加回画布等于把复杂度带回来）
2. 模板从哪里选：新建面板时先弹一步选模板，还是新建后空面板里直接给「工作台 / 娱乐」两个按钮，不选就是空白？
3. 收起条那一页还是原来的清单（左中右、上下移、换边、开关）。要不要也改成和展开一样的标签加「在收起条上 / 可以放上去」两栏？改的话放进这个任务，还是单独开一个？
4. 网格面板在岛上编辑时能不能直接换大小（比如点组件循环换小 / 中 / 大），还是只在设置里用缩略图换？

## 验收

- 岛上能完成面板的全部编辑（加、拿掉、换顺序，自由面板里还能移动和拉伸），拖组件时岛不动
- 网格和自由来回切，组件和大小不丢；切回网格后按位置定顺序重新排
- 设置页保持现在的标签式做法，不加回拖格子的画布（除非用户在「要用户定」第 1 条选了画布）
- 第三方插件能注册组件，设置的「可以添加」里看得到、带图标；市场插件里至少一个示例
