## 说明

外观选「液态玻璃」时，岛展开后左右两侧顶部的倒角（贴着屏幕上沿往外翻的小圆弧）被截掉一部分；纯色外观正常。用户 2026-11-16 报告，在 B68 那个会话里只建任务、不修。

先查液态玻璃的几层底子（壁纸毛玻璃 `src/windows/island/IslandGlassWallpaper.css` 的 `::before`、流彩层、油膜边 `.island__glass-rim`）是不是按岛本体的矩形裁剪，没给两侧倒角留位置；展开态的尺寸、缩放是否跟上了 `--island-top-fillet`。回归页 `liquid-glass` 调参页加 `?expanded=1` 能直接看。

## 验收

- [ ] 展开、收起时两侧倒角完整，和纯色外观形状一致；深色、浅色，贴顶、不贴顶都看过
- [ ] `liquid-glass` 回归页加一条检查
