## 说明

用户群反馈：音乐设置里开了「封面颜色」后，展开面板没有顶边（截图在 Windows，半透明背景加壁纸）。

推测原因：封面颜色在音乐页上加了一层光晕 `.cover-color .music-player::before`（`src/features/media/MusicPlayerPanel.css`），`inset: -36px -28px auto` 往上越出 36px、两侧各 28px，盖到页头和面板上沿，把面板顶部的描边和高光冲淡了。要先在 Windows 上复现确认，再把光晕限制在面板内部、不压过外框。

## 验收

- 开着封面颜色时，展开面板的顶边、圆角描边和关掉时一样清楚
- 光晕效果仍在（只是不越过面板边框和页头）
- 深色、浅色、液态玻璃、半透明背景下都检查过；Windows 真机确认
