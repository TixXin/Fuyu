## 说明

[C93](/docs/tasks/0-archive/C/C93.md)（issue #437）已完成跨设备同步 WebDAV 传输后端、系统凭据应用密码存储、请求预算与退避保护，以及设置页表单、「测试连接」与配置指南，并在本机通过回环模拟 WebDAV 服务端完成了双机合并及各类异常测试。

由于开发环境没有真实坚果云与 Nextcloud / 群晖 WebDAV 账号，需使用真实账号在两台设备（Windows 与 Mac）上完成真机验收。

## 验收

- 坚果云真账号双机同步：在坚果云网页端生成第三方应用密码并建好同步目录（如 `https://dav.jianguoyun.com/dav/我的坚果云/fuyu/`），两台电脑在「设置 → 通用 → 跨设备同步」切到 WebDAV 点「测试连接」通过后保存启用，核对待办新增/修改/删除、短语与书签双向合并正常，`sync-config.json` 不含密码明文
- Nextcloud 或群晖 WebDAV 真机同步：指向真实 Nextcloud（`https://域名/remote.php/dav/files/<用户名>/Fuyu/`）或群晖 WebDAV Server（HTTPS 5006 / 局域网 HTTP 5005），验证「测试连接」与双机合并正常
- 异常提示核对：故意填错应用密码点「测试连接」确认显示第三方应用密码引导提示；断开网络后点「立即同步」确认显示「暂无法连接 WebDAV 服务器」且不丢本机数据
