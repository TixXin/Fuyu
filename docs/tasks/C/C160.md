## 说明

用户群反馈：没有待办的时候，收起条缩到最窄还是很长一条（只有天气和倒数日两个小标签，岛却有两百多像素宽）。

收起条的宽度已经按内容算，但有一条写死的下限：`MIN_COLLAPSED_ISLAND_WIDTH = 280`（`src/windows/island/layout.ts`），设置里的宽度微调最多再减 60，所以最窄也有 220px。要改成没有文字行时按实际内容（收起项、左右的图标）算宽度，像灵动岛一样内容少就窄。

要一起检查：贴边收起、刘海模式、消息弹出（通知宽度另算）、展开和收起之间的宽度动画、窗口居中对齐（`alignCollapsedIslandWidth` 的像素对齐也用这个下限）、宽度微调设置的意义和范围。

## 验收

- 没有待办、只有一两个收起项时，岛的宽度贴着内容，比现在明显窄
- 有待办或通知时的宽度和现在一样
- 宽度微调设置仍然有效，范围合理
- 贴边收起、刘海模式、展开收起动画没有跳动或错位
