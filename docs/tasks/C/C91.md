## 说明

跨设备同步（调研见 [cross-device-sync.md](/docs/research/cross-device-sync.md)）的第一步：先让数据能按条合并。现在待办、短语、书签、预设都是整份覆盖，没有一类同时有 id、修改时间和删除记录。

- 稳定的设备 id（不能因为复制了数据目录就两台同 id）
- 待办、以后的待办、todoProjects、常用短语、链接书签、外观预设：每条加 `updatedAt`（混合逻辑时钟 HLC），只在内容真的变了时更新；删除留记录（墓碑或上次同步的 id 集合）；每日笔记加整篇的修改时间
- 设置的「可同步项」白名单：新加的设置默认只留在本机
- `todos.json` 格式升版本、兼容旧文件（对外契约，同步改 contracts.md）

## 验收

- 旧数据升级后行为不变，单元测试覆盖 HLC 比较和墓碑
- 白名单列出 `BACKUP_KEYS` 和 `fuyu-settings` 每一项是否同步（报告第一节）
