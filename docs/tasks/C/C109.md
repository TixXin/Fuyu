## 说明

调研与方案见 [notification-text-copy.md](/docs/research/notification-text-copy.md)。打通从收到消息/邮件通知到复制文本、链接与验证码的完整链路：

- **基础复制能力（P0）**：
  - 邮件阅读页（[MailPanel.tsx](/src/features/messages/mail/MailPanel.tsx)、[MailPanel.css](/src/features/messages/mail/MailPanel.css)）为标题 `.qq-mail-reader__subject` 与发件人 `.qq-mail-reader__meta` 放开 `user-select: text`；工具栏增加「复制正文」按钮；正文内超链接左键保持由默认浏览器打开，右键（无文本选区时）弹出轻量「复制链接地址」菜单。
  - QQ 通知列表（[QQNotifications.tsx](/src/features/messages/qq-notifications/QQNotifications.tsx)）每条右侧提供独立的「复制内容」图标按钮（点击仅复制并给已复制反馈，不拉起 QQ）；新消息横幅（[MessageBanner.tsx](/src/features/messages/banner/MessageBanner.tsx)）与到达面板（[MessageArrivalsPanel.tsx](/src/features/messages/arrivals/MessageArrivalsPanel.tsx)）支持右键复制消息文本。
  - 原生侧在 `mail` 模块提供不受悬浮窗口焦点限制的跨平台文本复制命令 `copy_message_text`（基于 `arboard::Clipboard`）；前端补齐 macOS 非激活面板下选中只读文本按 `Cmd+C` 的复制兜底，并在 [useHoverFocus.ts](/src/windows/island/useHoverFocus.ts) 中当岛内存在非空文本选区时保持焦点，避免拖选后光标滑出岛外导致 `Ctrl+C` 失效。
- **智能验证码提取与一键复制（P1）**：
  - 实现纯函数验证码提取器（中英文触发词门控 + URL/日期/时间/手机号/金额等干扰项剔除 + 触发词最近距离消歧），同时服务邮箱与 QQ 通知。
  - 识别到验证码时，复用横幅与到达面板现成的 `actions` 按钮槽位渲染 `复制 <验证码>`，邮件阅读页标题下方显示紧凑验证码复制条；新到达未读邮件若标题未直接含码但命中验证线索词，按需只读预取一次正文并写入阅读缓存。
  - 在「设置 → 消息」（[MessagesSettingsPage.tsx](/src/features/messages/MessagesSettingsPage.tsx)）新增「识别验证码并显示复制按钮」开关（默认开启，存于内置插件 `messages` 配置 `otpCopy`），更新设置搜索索引与文档。

## 验收

- 邮件阅读页主题、发件人、正文均可自由框选复制；工具栏可一键复制纯文本正文；正文超链接右键可复制链接地址，左键仍由默认浏览器打开
- QQ 通知列表项右侧有独立复制按钮（点击仅复制文本并显示已复制状态，不触发 `openQQ`）；横幅与到达面板支持右键复制消息文本
- 双端岛内存在非空文本选区时移出岛外不立即释放焦点；macOS 下选中只读文本按 `Cmd+C` 可正常写入剪贴板
- 验证码提取器覆盖中英文模板、字母数字混合码及 HTML/URL/日期/电话/金额干扰消歧，无触发词的普通消息零误报；横幅、到达面板与邮件阅读页支持一键复制验证码
- 「设置 → 消息」开关可控制验证码识别与按钮显示（默认开）；深浅色岛对比度、`pnpm check`、`pnpm build`、`pnpm test:regression`、`cargo test` 与双端 clippy 全部通过，同步更新 [contracts.md](/docs/architecture/contracts.md)、[mail.md](/docs/features/mail.md) 与 [qq-notifications.md](/docs/features/qq-notifications.md)
