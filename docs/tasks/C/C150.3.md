## 说明

现在标注画完只能撤销，不能改。加一个选择状态：不在画的时候点中已有的标注就选中它，显示控制点；能拖动、拖控制点改大小或箭头端点、在工具栏换颜色和粗细、`Delete` 删除；文字标注双击再编辑。每次修改进撤销 / 重做。逻辑放 `src/features/screenshot/annotations.ts` 旁边，界面在 `src/windows/screenshot/`。

## 验收

- 矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克、序号都能选中、移动、删除；能改样式的都能改
- 撤销 / 重做覆盖这些修改
- 单元测试（命中测试、修改后的数据）；截图工具栏的回归页更新；`pnpm check`、`pnpm build`
