## 说明

跨设备同步引擎（父任务 C92，#436）的后端：远端布局 `fuyu-sync/meta.json` + `devices/<设备 id>/<类别>.json`，后端接口（列目录 / 读 / 写 / 删）和同步文件夹实现，按条 HLC 合并加上次同步的底稿，安全阀（首次并入前备份、大量删除时刹车、目录不在时跳过、远端版本更新时停止），合并结果写回各数据并让设置在运行中生效。用户定：本地改动 5 秒防抖后推送，每 5 分钟拉一次，启动和打开同步页时各拉一次。

计划和 scope 见 [cross-device-sync-plan.md](/docs/architecture/cross-device-sync-plan.md)。

## 验收

- 两个临时目录模拟两台设备：增、改、删、并发改、每日笔记冲突、首次并入、大量删除刹车、目录不在、远端版本更新
