## 说明

源自 [fly-island-issue-76.md](/docs/research/fly-island-issue-76.md)（对应第 2 项）：目前顶边（贴顶、悬空药丸）与底边吸附在闲置贴边收起（`is_tucked = true`）时，窗口固定露出 `10px`（[src-tauri/src/island/geometry.rs](/src-tauri/src/island/geometry.rs) `TUCKED_VISIBLE_EDGE_HEIGHT = 10.0`），在浅色壁纸或全屏阅读界面顶栏上仍偏宽显眼。

参考 BoringNotch（无刘海零高度悬停热区）与 TieZ（细边缘指示条），不做繁琐的像素级自由编辑器，在「设置 → 收起与露出」（[TuckSettingsSection.tsx](/src/windows/settings/sections/TuckSettingsSection.tsx)）新增轻量三档预设：

1. **标准露边（`edge`，默认 `10px`）**：保持现行外观与反向圆弧过渡，零行为变化；
2. **极简细线（`line`，露出 `4px`）**：收起后仅留一条柔和细边指示位置，显著降低视觉存在感；
3. **贴边隐身（`hidden`，可视 `0px` + 屏幕边缘 `2px` 透明悬停唤醒热区）**：收起后完全退出可视区，鼠标推至屏幕吸附边缘热区时照常触发露出或展开，收到新消息自动露出（`revealOnMessage`）照常工作。

前后端几何计算（`geometry.rs`、`passthrough.rs` 鼠标穿透与悬停热区）、设置备份与多语言文案、设置搜索索引（`pnpm settings:index`）同步更新。依赖 [D97.1](/docs/tasks/D/D97.1.md) 完成后执行以避免 `IslandShell.css` 冲突。

## 验收

- 「设置 → 收起与露出」可切换三档贴边露出样式，默认值为「标准露边」，升级用户外观不变
- 顶边与底边在「极简细线」和「贴边隐身」档位下收起位置、鼠标穿透区与边缘悬停唤醒热区在 100% / 125% / 150% / 200% DPI 缩放下均准确命中（补充 `geometry` / `passthrough` 单元测试）
- 更新设置搜索索引（`pnpm settings:index`）与 [island.md](/docs/design/island.md)，`pnpm check`、`pnpm build`、回归页、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与 Windows CI 全部通过
