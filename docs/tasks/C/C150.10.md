## 说明

现在发给 Agent 只是切到会话终端、贴 PNG 路径。改成发之前可以在卡片上写一句话（例如「这个按钮没对齐，修一下」），和路径一起贴；同时附上截图来源：截图开始时前台窗口的进程名、窗口标题，浏览器里能取到的话加网址。来源默认附上，设置里能关。截图会话开始时记下来源，后面 C150.12 的插件动作上下文也用它。

## 验收

- 卡片上能输入一句话再发，回车发送；不写也能直接发
- Claude Code、Codex 里看到的是指令、来源和图片路径
- 来源取不到时只发路径；中英文文案
- `pnpm check`、`pnpm build`、`cargo test`、`pnpm build:exe`；截图卡片回归页更新
