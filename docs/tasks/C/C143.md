## 说明

用户群反馈（2026-11-19）：聊天软件里的 Agent / 机器人（例子是 hermes-agent 发的「WebDev 前 20 有变动」榜单）发来的是 Markdown 消息，在聊天软件里是一张四列表格，带加粗标题和链接；到了岛上的消息卡片里，整条变成一段挤在一起的纯文本，表格的行列全丢了，没法读。

现状：

- 消息页的即时通讯卡片（`src/features/messages/im-sources/ImNotificationPanel.tsx`）把正文直接放进 `<p>`，按纯文本显示；QQ、微信、邮件卡片、新消息横幅和到达面板也是纯文本。
- 仓库里已经有一个不依赖第三方库的 Markdown 组件（`src/components/markdown/`），支持标题、列表、引用、代码、链接和表格，Agent 状态通知（`src/features/agent-status/notice/NoticeMessage.tsx`）和插件市场在用。
- 反馈截图里岛上那段文字已经没有 `|`、`**` 这些 Markdown 符号，说明聊天软件发系统通知时很可能已经把格式压平了。所以这项要先弄清楚到岛上的原文是什么，再决定怎么显示。

要做的：

1. 向反馈的用户确认是哪款聊天软件、哪个平台（Windows / macOS），拿一条同样的消息，看系统通知里到岛上的原文（有没有换行、有没有 Markdown 符号）。
2. 原文带 Markdown 符号的：消息卡片、横幅、到达面板的正文用现有的 `Markdown` 组件渲染，表格在窄卡片里可以横向滚动，不撑破卡片。
3. 原文已被压平的：写清楚能做到哪一步（保留换行、识别链接），做不到还原表格的在备注里记下原因。
4. 复制按钮照旧复制原文，不复制渲染后的文字；验证码识别不受影响。
5. 收起条的单行预览去掉 Markdown 符号，只显示文字。

## 验收

- 一条带表格、加粗、链接的 Markdown 消息到岛上后，消息页卡片里按格式显示，表格有行列，链接能点开
- 窄卡片里表格不溢出、不把卡片撑宽
- 普通聊天消息（含 `*`、`_`、`#` 这类字符的日常文字）显示和现在一样，不被误当成格式
- 复制得到的是原文；横幅和到达面板的一键复制验证码照常
- 原文被聊天软件压平的情况，备注里写明结论和原因
- 中英文界面、深浅色下都正常；相关回归页更新
