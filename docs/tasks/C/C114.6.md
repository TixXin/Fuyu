## 说明

[C114](/docs/tasks/C/C114.md) 第二波子任务，补齐多子日历精细管理与懂中国法定调休的周期性重复待办：

1. **子日历独立开关与色标**：在 [C114.2](/docs/tasks/C/C114.2.md) 子日历识别基础上，扩充 `calendar-sources.json` 与 `CalendarSourcesSection`，支持展开 CalDAV 账号勾选要显示的子日历、设置子日历色点，以及单独指定某子日历「仅在面板展示、不参与会前倒计时」。
2. **懂中国调休的重复待办（Recurrence）**：`TodoItem` 支持可选轻量循环规则（每天 / 法定工作日 / 每周几 / 每月几号 / 完成后 N 天）；选择「法定工作日」时联动内置法定节假日调休表（[holidays.ts](/src/features/calendar/holidays.ts) 抽至共享 `utils/` 或 `lib/`），周六日调休「班」照常生成、法定长假「休」自动跳过。

## 验收

- CalDAV 多子日历可在设置页独立开关显隐、倒计时参与状态与色点，日程行展示对应日历色标
- 「法定工作日」重复待办在周末补班日正常生成、法定节假日自动跳过，普通每日/每周/每月循环跨天生成准确
- 遵守模块分层边界（`tests/unit/feature-boundaries.test.mjs` 通过），前后端测试全部通过
