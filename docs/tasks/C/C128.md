## 说明

C126 在 Mac 上写完了「游戏模式下露边条点穿、不被顶沿唤出、进入时归还焦点」，Windows 只过了 CI，要在 Windows 真机（tixxin-computer）上实测。改动见 [C126](/docs/tasks/0-archive/C/C126.md)。

## 验收

- 打开游戏模式（勿扰 + 自动贴边），开全屏游戏或全屏视频：碰屏幕顶沿岛不探出、不展开；点露边条点到的是游戏，游戏不失焦
- 先点一下岛让它拿焦点，再进全屏游戏：焦点回到游戏
- 退出全屏：岛叫回，悬停、点击、探出恢复原样
- 折叠、展开（进入游戏时应收起）、贴边收起、托盘隐藏（隐藏时不冒出来，退出后仍隐藏）四种状态各过一遍
- 游戏中用快捷键 / 托盘叫出岛能正常用；再贴边后又点穿
- 只开勿扰、不开自动贴边：没贴边的岛照旧可点
