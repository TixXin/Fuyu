## 说明

[C114](/docs/tasks/C/C114.md) 第一波子任务（纯前端日历侧，详见 [todos-and-calendar-expansion.md](/docs/research/todos-and-calendar-expansion.md) 第五节）：全面充实「设置 → 日历」，并补齐会前强提醒横幅、入会自动暂停音乐、日程降噪过滤与 7 日议程 / 月历周数视图。

1. **日历偏好模型与跨窗口同步（`fuyu-calendar-prefs`）**：
   - 将 [calendarSettings.ts](/src/lib/settings/calendarSettings.ts) 的 `CALENDAR_REMIND_MINUTES` 扩充为 `[0, 5, 10, 15, 30, 60]`。
   - 在 `src/features/calendar/` 新增 `calendarPrefs.ts` 与 `useCalendarPrefs.ts`（存储于 `localStorage` 的 `fuyu-calendar-prefs`，支持跨窗口实时同步与容错默认值）。
2. **「设置 → 日历」分组重设计（[CalendarSettingsPage.tsx](/src/features/calendar/CalendarSettingsPage.tsx)）**：
   - **小岛倒计时显示**：会前倒计时提前量（含 60 分钟档）、倒计时范围（全部非全天日程 / 仅含视频会议链接的日程）、收起条显示格式（`标题 · 10 分钟后` / `14:00 标题 · 10m` / `紧凑：仅图标与剩余时间`）、显示会议标题（防窥开关）、会议开始后保留时长（开始即隐藏 / 开始后 5 分钟默认 / 开始后 15 分钟 / 直至会议结束并显示剩余分钟）。
   - **会前强提醒与入会动作**：会前弹出岛屿强提醒横幅（默认开，可选准点 / 会前 1 分钟默认 / 3 分钟 / 5 分钟，通过窗口服务 `reminders/v1` 弹出带「加入」操作按钮的会议提醒卡，遵循 `calendarShowTitle` 脱敏且同一场会议只提醒一次）、点击「加入」会议时自动暂停媒体播放（默认开，通过窗口服务 `media/v1` 在播放态下自动调用暂停）。
   - **日历面板与过滤规则**：默认日程视图（近两日默认 / 未来 7 天议程，面板页头亦提供快捷切换）、降噪过滤开关（隐藏已拒绝日程 `declined`、空闲日程 `free` 不参与倒计时、在列表中折叠全天日程）、月历显示周数（ISO 第 N 周）、每周起始日（跟随语言 / 周一 / 周日）、以时间开头的待办并入日程开关（默认开，显式说明该联动特性）。
   - **日历源与私有会议域名**：在已添加日历区支持手动立即刷新，并提供可选「自定义企业视频会议域名」输入（前端对 `https://<domain>/...` 补齐会议链接识别）。
3. **面板与月历视图升级（[CalendarPanel.tsx](/src/features/calendar/CalendarPanel.tsx)、[CalendarMonth.tsx](/src/features/calendar/CalendarMonth.tsx)、[MeetingLine.tsx](/src/features/calendar/MeetingLine.tsx)）**：落地 2 日/7 日议程切换、全天日程折叠、周数列、周起始日切换与收起条多格式渲染，补齐中英文文案与 `tests/unit/calendar-prefs-and-upcoming.test.mjs` 单元测试。

## 验收

- 「设置 → 日历」呈现清晰的四大功能分组与日历源管理，默认行为与升级前保持兼容
- 收起条倒计时支持范围过滤、三种文案格式与四种开会后保留策略（含显示剩余结束分钟）
- 会前到达设定提前量时通过 `reminders/v1` 弹出带「加入」按钮的岛屿横幅（每场会不重复弹）；点「加入」时若音乐正在播放则经 `media/v1` 自动暂停
- 日历面板支持「近两日 / 未来 7 天」切换、折叠全天日程、过滤已拒绝日程，月历支持显示周数与切换周一/周日开头
