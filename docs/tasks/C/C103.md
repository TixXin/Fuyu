## 说明

用户在 C98 验收后要的：拖动岛（直接拖、修饰键拖）时，在岛中心所在显示器的工作区上显示九宫格虚线（横竖各两条三等分线，主题色 --color-accent 淡虚线），松手消失，换屏跟随。岛窗口是 820 宽的舞台，盖不住整屏，需要新的透明、鼠标穿透、不抢焦点、压在岛下面的全屏窗口（例如 label drag-grid，第一次拖动时创建，之后隐藏常驻；Mac 上和岛一样能在所有桌面和全屏应用上显示）。网格线不吸附。只有顶部、底部、左、右四条边的中间有轻微吸附（约 12px 内）：岛贴着顶边或底边时水平居中，贴着左右边时竖直居中，方便居中放下；吸住时给一个看得出的提示（例如中线的一小段加亮）。Mac 上拖动中就跟手吸（C98 后岛自己移动窗口，drag_follow_macos.rs）；Windows 拖动由系统接管，松手时在 snap_after_drag 里对齐。外观 → 尺寸与位置加开关「拖动时显示九宫格辅助线」，默认开（只管线，不管中间吸附），中英文，跑 pnpm settings:index。新窗口要同步 AGENTS.md 窗口表、contracts.md、overview.md、tauri.conf.json / capabilities；设计写进 docs/design/island.md，platforms.md 加一行。

## 验收

- 拖动时当前屏工作区出现九宫格虚线，不挡鼠标、不抢焦点，换屏跟随，松手消失；深浅色都看得清
- 贴顶 / 贴底时靠近正中会轻微吸到水平居中，贴左右时靠近中间会吸到竖直居中；离远了不吸；原有贴边吸附和提示线照旧
- 关掉开关后不再出现网格，中间吸附照旧
- Windows、macOS 都能用，拖动不卡
- pnpm check、pnpm build、cargo test、pnpm build:exe、pnpm test:regression 通过
