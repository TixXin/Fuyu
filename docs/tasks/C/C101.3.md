## 说明

按 [计划](/docs/architecture/clipboard-preview-plan.md) 里的 P3 做：Ctrl+S 改这条（带 6 秒撤销），Ctrl+Shift+S 另存，Ctrl+Enter 只粘贴这次；剪贴板窗口的 Ctrl+E 编辑器同步改键位。编辑时预览拿焦点，剪贴板窗口那段时间不因失焦关掉，结束后焦点还回去。

## 验收

- Rust 单测覆盖改文字后的字段重算和撤销
- 回归页覆盖编辑态，快照随提交带上
- Mac 上预览不会一出现就抢焦点（G1.18 的问题不回来）
- `contracts.md`、`docs/design/clipboard.md`「编辑后粘贴」更新

## 备注

- UI 外观总控 2026-11-15 提醒：Mac 上键位用 ⌘（⌘S 改这条、⌘⇧S 另存、⌘↵ 只粘贴这次），文案和快捷键说明按平台显示，Windows 才写 Ctrl。
- 进入编辑后，F（循环尺寸）、`+` `-` `0`（缩放）、空格（关预览）都不再拦截，要能正常打字；Esc 先退出编辑，不直接关预览。
