## 说明

[C109](/docs/tasks/0-archive/C/C109.md) 跟进实测（依赖真实邮箱授权码与已登录开启系统通知的 QQ 客户端）：

- **Windows 真机（邮箱 + QQ 系统通知）**：发送含验证码的新邮件（验证码在标题、验证码仅在正文各一封）与含验证码的新 QQ 通知，核对新消息横幅和自动展开面板出现 `复制 <验证码>` 按钮，点击后系统剪贴板写入验证码、提醒收起、不误唤起客户端；QQ 通知列表项右侧悬停「复制内容」按钮仅复制正文、不唤起 QQ；右键横幅/到达卡片可复制消息文本。
- **macOS 与 Windows 邮件阅读页**：在 macOS（`Accessory` 非激活面板）和 Windows 打开真实邮件阅读页，框选标题、发件人地址与正文段落，确认鼠标略微移出岛边缘时选区与焦点不丢失，按 `⌘C` / `Ctrl+C` 可在外部编辑器正常粘贴；工具栏「复制正文」复制净化纯文本；未框选文字时右键正文超链接弹出「复制链接地址」并可写入剪贴板；在「设置 → 消息」关闭「识别通知中的验证码」后阅读页验证码胶囊条与新消息横幅验证码按钮隐藏。

## 验收

- Windows 真机真实邮箱与 QQ 系统通知的横幅、到达面板、列表页复制与一键复制验证码正常
- macOS 与 Windows 真机邮件阅读页的标题/发件人/正文选区快捷键复制、移出保焦、工具栏复制正文、右键复制链接与设置开关正常
