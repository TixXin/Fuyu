## 说明

用户群反馈希望岛上能看到外设电量。现在蓝牙耳机（C3）和蓝牙鼠标、键盘、触控板（C64）的电量只在设备连上和电量低时弹一次提示，平时看不到。

要加一个常驻的显示：岛上的小组件（和本机电池组件 `BATTERY_WIDGET` 同一组）列出已连接外设的名字、类型图标和电量；可以选择放到收起条上做收起项。数据复用 `device_events` 已有的读数，后端要能按需给出当前所有外设的电量（现在只在事件发生时推送）。罗技接收器的设备等 C88（#420）做完后自动出现在这里。

## 验收

- 岛上有外设电量小组件，列出已连接、能读到电量的外设，电量变化时会更新
- 没有外设或都读不到电量时显示空状态，不报错
- 可以放到收起条上，只显示最低的那个或图标加百分比，窄宽度下不溢出
- 中英文文案；Windows、macOS 都实测
