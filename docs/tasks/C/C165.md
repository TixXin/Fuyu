## 说明

用户群截图里，台式机的默认 Fuyu 页放了「电池」组件，显示「这台电脑没有电池」，白占一格。

要做：生成默认 Fuyu 页布局时，本机没有电池就不放电池组件（用别的组件补位）；已经放了的不自动删，但没有电池时组件给出更有用的内容或提示可以移除。

## 验收

- 没有电池的电脑上新生成的默认 Fuyu 页没有电池组件，格子被别的组件补上
- 有电池的笔记本上和现在一样
- 已经自定义过的布局不被改动
