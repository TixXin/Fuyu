## 说明

用户在 Mac 开发版上反馈（经功能总控转来）：高亮颜色选了「自定义 #FFFFFF」，设置页预览是白色，收起的岛上正在唱的歌词却是红色；当时开着「跟随封面颜色」。

原因（组长 2026-11-19 看代码）：`src/lib/settings/lyricsSettings.ts` 的 `karaokeLook` 在开着「跟随封面颜色」时把高亮色写成 `var(--cover-accent, <选的颜色>)`，岛上有封面色就盖过自定义色；设置页预览里没有 `--cover-accent`，所以显示自定义色。界面没说明谁优先。和 C127、C4c 无关。另要排除设置改了岛没收到（跨窗口同步）。计划见 [feature-misc-plan.md](/docs/architecture/feature-misc-plan.md) 第 3 轮。

## 验收

- 按用户定的优先级改 `karaokeLook`，设置页说明和预览与岛上一致，中英文案齐全
- 改设置后岛上即时生效
- 单元测试覆盖跟随封面开关和三种颜色的组合

## 交接

- 2026-11-19 04:38：用户 2026-11-19 定（组长转）：自定义优先。高亮颜色选「自定义」时一律用自定义色；「跟随封面颜色」只在高亮颜色选「文字色」或「主题色」时接管歌词高亮，波形和音乐页光晕照旧跟封面。设置页写明这条规则，预览和岛上一致。用户原话：自定义优先，用户可以自己设置又丰富的设置选项。
