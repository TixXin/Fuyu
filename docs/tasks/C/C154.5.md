## 说明

和汽水音乐的任务栏歌词条一样，岛在任务栏里时可以沿任务栏左右拖到想放的位置：
- 展开方式是「点击」时，鼠标放上去岛最左边出现一条竖线；是「悬停展开」时，按住拖动键（Alt）才出现
- 按住竖线横着拖，拖的过程中用虚线框标出松手后会落在哪；虚线框只落在空白处，不落到任务按钮、托盘或其他任务栏组件上
- 松手后记住位置（存在 `fuyu-position` 的任务栏位置里，契约写进 contracts.md）；默认紧挨托盘；空白处放不下时挪到最近的空位
- 其他第三方任务栏组件（如汽水音乐）当成障碍物避开

## 验收

- 点击 / 悬停两种展开方式下竖线出现的时机对
- 拖动时虚线框跟着鼠标在空白处吸附，松手后岛落在虚线框处，重启后位置不变
- 空白区域计算的单元测试覆盖第三方组件和记住的位置
