## 说明

截图里：用量两行字小、偏灰、挤，「可能已过时」每行重复；右侧模型、权限、两个图标、时间挤在标题行，时间被截；宿主图标取不到时退回像日历的方框；状态点含义不清；工具调用行看不出是「正在调用」。用户选定：模型·推理强度·权限合成一个胶囊，放不下先省推理强度再省权限，时间固定一列；宿主做 Agent 图标右下角的角标，取不到不显示；用量行列对齐成表格、提对比度，过时改成一个时钟图标加悬停说明；状态点加说明；工具行区分工具名和参数。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。
