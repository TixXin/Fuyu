## 说明

核查上游 `flyl1u/fly-island#80` 与本仓库实现后确认：浮屿在卸载时未清理写入 18 家外部 AI 代理配置目录的钩子、外部插件与提示词回复标记，且勾选 `Delete the application data` 时漏删了迁出的家目录 `%USERPROFILE%\.fuyu`；一旦 `.fuyu` 被删除，又会引发 15 家命令钩子报脚本缺失错误、DSH 挂载报错以及 `opencode` / `MiMo Code` / `pi` 插件自动重建 `.fuyu`。

按全网调研与用户确认的三项产品决策（真正卸载时默认卸掉外部钩子并留恢复标记、勾选删除数据时顺带删编辑器扩展、Windows 卸载器只清本机不阻塞连 SSH），拆分为三项子任务推进：

- `B73.1`：18 家 AI 钩子与外部配置的统一反安装、Fail-Open 守卫及 SSH 远端移除（Rust `agent_status` 核心层）
- `B73.2`：设置页「移除钩子」交互、前端类型化 IPC、多语言文案与回归页
- `B73.3`：Windows NSIS 卸载前自调用、凭据与家目录安全清理及文档收口

## 验收

- 应用内可一键移除已安装的本地及 SSH 远程 AI 钩子，保留用户自己的其他 hooks 与配置
- Windows 真正卸载（非 `/UPDATE`、非 `/REINSTALL`）时自动移除本机 18 家外部钩子、插件与回复标记；未勾选删除数据时记录 `uninstalled-hooks.json` 供日后重装自动恢复
- 勾选 `Delete the application data` 时清理正式版系统凭据、`tixxin.fuyu` 编辑器扩展，并安全删除默认 `~/.fuyu`（自定义家目录仅按受管文件白名单清理，绝不递归全删用户目录）
- 钩子命令具备脚本缺失静默 `exit 0` 守卫，外部 JS 插件在 `FUYU_DIR` 不存在时不重建顶层目录
