## 说明

在 Agent 页「用量」那里把用量环相关的开关全关掉后，用量环的入口也一起消失，之后再也打不开、没法重新开启。

- 类别：问题
- 平台：未说明
- 群里反馈：2026-11-26，1 人提到（浮汐 FB-21）

初步怀疑：

- 用量环的设置入口跟着用量环的开关走，全部关掉后入口被一起藏起来，待核实

## 验收

- 用量环的开关全关后，仍能在 Agent 页或设置里找到入口重新打开
- 回归页覆盖「全关后再打开」这条路径
