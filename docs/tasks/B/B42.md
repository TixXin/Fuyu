## 说明

现在只显示「2 个子 Agent」这个数字。Claude Code 的子 Agent 记录在 `<会话>`/subagents/agent-*.jsonl，没读。做法（用户选定）：Rust 读子 Agent 的描述、状态、当前工具、开始时间；父行的「n 个子 Agent」变成可点的小按钮，点开在父行下缩进列出，默认收起，跑完自动消失。顺带调研 Claude 桌面版开的子会话能不能拿到父会话，拿不到就另开 issue。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。

## 验收

- 子 Agent 能展开收起，键盘可达，减少动画时不动
- Rust 模块带脱敏样本的测试
- cargo test、pnpm build:exe、pnpm check、pnpm build、pnpm test:regression 通过
