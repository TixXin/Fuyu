## 说明

用户群反馈希望 Agent 页支持豆包。先调研豆包有哪些能当 harness 接入的形态（豆包桌面版、Trae / Trae CLI 等），各自的会话文件、钩子、审批和用量，结果补进 docs/research/agent-harnesses.md；再按 `fuyu-agent-harness` skill 的清单接入能接的那一种。

## 验收

- 调研写清楚每种形态能拿到什么（会话列表、运行状态、等你、审批、用量）
- 至少一种形态在 Agent 页显示会话并亮灯，带品牌图标
- 平台支持表和功能文档同步更新

## 结论

第 1 步调研做完（2026-11-15），见 [agent-harnesses.md「豆包」](/docs/research/agent-harnesses.md#豆包2026-11-15-追加)：豆包桌面版是云端对话的 Chromium 外壳、数据在沙盒容器里读不了，不接；推荐接 TRAE / TRAE CN（IDE），用它的 Claude Code 格式钩子攒会话，能做三态、等你和岛上审批（「允许」受 TRAE 自身确认模式限制），约 1.5–2 天。TRAE CLI 2.0 只给企业旗舰版，放第二步。
