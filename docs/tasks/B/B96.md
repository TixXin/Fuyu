## 说明

B74 Windows 实测（2026-11-27）第 2 条不过：退出浮屿、删掉 `%USERPROFILE%\.fuyu\fuyu-agent-*.{cmd,ps1}` 后 `claude -p … --include-hook-events`，Claude Code 的 5 个浮屿钩子全部 `exit_code=127, outcome=error`（bash 报 No such file，PowerShell 报 -File 文件不存在，中文报错在 Claude 里还是 GBK 乱码）。`src-tauri/src/agent_status/claude_hooks.rs` 的 Windows 版 `claude_code_running_command` / `claude_code_powershell_command` 没有存在性守卫，Mac/Linux 版有 `[ -f … ] && exec … || exit 0`。Codex、Cursor、Gemini/Antigravity、Grok、Copilot（PowerShell 那条）都有守卫，实测静默返回 0。浮屿运行时约 1 分钟内会自动写回脚本，所以只影响浮屿已卸载或家目录被删、配置还在的情况。

改法：Windows 上 Claude Code 经 Git Bash 执行钩子，两种命令都包一层 `[ -f "<脚本>" ] && <原命令> || exit 0`，并确认没有 Git Bash 时的执行方式；识别受管条目的逻辑要同时认新旧写法，「自动更新旧版钩子」能把旧命令换掉。

## 验收

- Windows 上删掉钩子脚本后 `claude -p "hi" --output-format stream-json --verbose --include-hook-events` 里所有浮屿钩子 `exit_code=0`、无 stderr
- 脚本在时状态灯、审批、会话照常工作
- 旧写法的钩子在升级后被自动换成新写法，移除钩子时新旧写法都能删干净
