## 说明

开发版点「安装/修复」时替正式版装：脚本写进正式版的数据目录，Claude Code 审批钩子用正式版 agent-approval.json 的端口和 token，钩子状态也按正式版判断，开发版里同样提示没装或过时。用户 2026-11-16 要求（之前开发版只读、不装，正式版没装过钩子的机器只开开发版就什么都看不到）。验收：开发版首页卡片有「安装/修复」，点后和正式版点的结果一样（正式版看是最新）；单元测试覆盖开发版取正式版的端口和 token；Mac 上用开发版实测一次。
