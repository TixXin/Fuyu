## 说明

现在点一行就是跳窗口，悬停时显示归档，别的都没有。做三样（用户选定全做）：右键或 ⋯ 打开现成的 RowMenu（跳到窗口、打开文件夹、复制路径 / 会话 id、归档、按目录隐藏，写进已有的「隐藏会话」规则）；键盘 ↑↓ 选行、Enter 跳转、Delete 归档；悬停卡片显示完整标题、最近提问和路径。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。

## 验收

- 三种显示方式都能用，中英文文案齐
- 回归页覆盖菜单和键盘
- pnpm check、pnpm build、pnpm test:regression 通过
