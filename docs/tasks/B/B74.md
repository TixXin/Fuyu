## 说明

汇总 `B73`（`B73.1`、`B73.2`、`B73.3`）在自动化单测与 CI 中无法直接覆盖的 Windows NSIS 安装/卸载向导、Windows 凭据管理器与真实 SSH 远端联调实测项。背景与方案见 [agent-hooks-uninstall-cleanup.md](/docs/research/agent-hooks-uninstall-cleanup.md)。

## 验收

- 正式版（Windows / Mac）装有任一 AI 钩子时，「设置 → AI Agent → AI Agent 状态灯」显示「移除钩子」（开发版与全部未安装时不显示）；点击后移除本机及已启用 SSH 远端的浮屿钩子并保留用户自有配置，移除按钮随刷新自动隐藏
- Windows 真机安装钩子后手动删除 `%USERPROFILE%\.fuyu\fuyu-agent-*.{cmd,ps1}`，在 Claude Code、Codex、GitHub Copilot CLI（PowerShell）触发提问或工具调用静默返回 `0` 且零报错；删空 `.fuyu` 后运行装有旧插件的 `opencode` / `pi` / `DSH` 不再重建 `.fuyu`
- Windows 装好钩子与回复标记后双击新版 NSIS 安装包选默认「先卸载旧版本再安装」，确认 `/REINSTALL` 下外部钩子、回复标记与家目录数据完好保留
- Windows 运行 `uninstall.exe` 不勾选 `Delete the application data`，确认 19 家外部钩子与回复标记已移除且写出 `%USERPROFILE%\.fuyu\uninstalled-hooks.json`；重装启动后自动恢复并删除该标记文件
- Windows 运行 `uninstall.exe` 勾选 `Delete the application data`，确认正式版 `com.tixxin.fuyu` 凭据（不含 `lane-*`）、编辑器扩展 `tixxin.fuyu-*` 及默认 `%USERPROFILE%\.fuyu` 已清除；自定义 `home.json` 目录仅删浮屿受管项，完好保留用户自有文件
