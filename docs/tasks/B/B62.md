## 说明

在新手引导的「把它捏成你喜欢的样子」（`shape`，`src/windows/onboarding/ShapeAct.tsx`）这一幕加「纯色 / 液态玻璃」选项，选了马上作用在真岛上。液态玻璃用 C97 的默认参数（玻璃背后：桌面壁纸，强度 25%），细节留给「设置 → 外观 → 样式」，引导里写一句去哪里调。系统关掉透明效果或读不到壁纸（Mac）时照常显示选项，说明里写清楚这时是纯色玻璃。液态玻璃只能在设置里找到，新用户不知道有它。（用户要求 2026-11-16）

## 验收

- [ ] `shape` 这一幕多一个「纯色 / 液态玻璃」选项，中英文文案，窄窗口不溢出
- [ ] 选了马上改真岛外观，退回纯色也马上生效；跳过引导时外观不变
- [ ] 透明效果关闭、读不到壁纸时有说明
- [ ] 回归页覆盖：切换后岛上出现 / 去掉液态玻璃层
