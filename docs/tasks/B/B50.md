## 说明

Agent 页里 Claude 桌面版开出来的子会话（主 agent 用 start_session 派出去的）现在和父会话平级、各占一行，多个主 agent 同时派会话时列表很长，也看不出谁是谁开的。把它们挂到父会话下面：父行下面一个「▸ n 个子会话」按钮，点开缩进列出，做法和 B42 的子 Agent 列表一致，默认收起，子会话不再单独占一行。

数据：`~/Library/Application Support/Claude/claude-code-sessions/<账号>/<组织>/local_<id>.json` 里 `cliSessionId` 是会话记录 id，`spawnedFrom.sessionId` 是父会话的 `local_` id，父会话文件里的 `cliSessionId` 对上它的会话记录（[B42](/docs/tasks/0-archive/B/B42.md) 备注里的调研，2026-11-15）。`claude_desktop.rs` 已经读这些文件，没读 `spawnedFrom`。要注意：子会话等你确认、出错、跑完没看时，收起状态下父行要看得出来；`depth` ≥ 2 的怎么显示；父会话已归档或不在时间窗里时子会话照常单独显示；Windows 上文件位置（应在 `%APPDATA%\Claude\claude-code-sessions\`）先核实。和 B43 都改 `AgentSessionRow.tsx`、`AgentSessionsPanel.tsx`，排在它后面。

## 验收

- Rust 读 `spawnedFrom`，给会话带上父会话 id，带脱敏样本的测试
- 子会话挂在父行下，能展开收起，键盘可达，减少动画时不动；子会话需要处理时父行有提示
- Mac 和 Windows 都核实过文件位置
- cargo test、pnpm build:exe、pnpm check、pnpm build、pnpm test:regression 通过
