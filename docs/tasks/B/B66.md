## 说明

B42 只给列表视图做了「▸ n 个子 Agent」按钮，卡片和紧凑视图只显示数量。卡片和紧凑视图下也在卡片下面放同一个按钮和列表（按钮不能嵌在卡片按钮里），有按钮时卡片不重复写数量，展开时下面的卡片平移；岛上弹出的提醒卡片不放。（用户要求 2026-11-16）

## 验收

- [ ] 卡片、紧凑视图下有子 Agent 时出现按钮，点开列出子 Agent，再点收起
- [ ] 有按钮时卡片不重复写子 Agent 数；子 Agent 全部跑完按钮消失
- [ ] 窄窗口不撑出横向滚动，展开时下面的卡片平移
- [ ] 回归页 `agent-sessions` 覆盖卡片视图的展开收起
- [ ] `docs/design/agent.md` 的 B42 那条改成卡片和紧凑视图也能展开
