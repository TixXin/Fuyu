## 说明

方案见 [agent-hooks-uninstall-cleanup.md](/docs/research/agent-hooks-uninstall-cleanup.md) 第 2 步。

为设置 → AI Agent → AI Agent 状态灯卡片补上「移除钩子」次级操作入口（与 `B73.1` 约定的 Tauri 命令 `uninstall_agent_status_hooks` 对接，返回 `{ removedAt: number; remotes: RemoteSetupResult[] }`）：

1. 在 `src/features/agent-status/api.ts` 增加 `AgentHooksUninstallResult` 与 `uninstallAgentStatusHooks()`。
2. 在 `src/features/agent-status/status.ts` 增加纯判断函数 `hasInstalledAgentHooks(state: AgentHooksState | null): boolean`（任一代理状态为 `current` 或 `outdated` 时返回 `true`），并配 `node:test` 单元测试。
3. 在 `useAgentStatusSettings.ts` 与 `AgentHooksSettingsSection.tsx` 增加卸载状态流与「移除钩子 / Remove hooks」次级按钮（仅在 `hasInstalledAgentHooks(agentHooksState) && !devBuild` 时显示，安装或移除进行中禁用两颗按钮，完成后刷新 `agentHooksState` 与 `agentStatus` 并展示已移除提示及远端主机结果）。
4. 补齐 `src/i18n/sections/settings/agent.ts` 中英文文案与 `tests/regression/settingsMocks.ts` 中的命令 mock。

## 验收

- 装有任意代理钩子且非开发版时，AI Agent 状态灯卡片「安装/修复」旁显示「移除钩子」按钮；全部未安装或开发版时不显示
- 点击「移除钩子」调用 `uninstall_agent_status_hooks`，刷新状态灯与钩子状态，正确展示完成或错误提示及远端主机结果
- 中英文文案齐全，窄窗口下按钮排布不溢出，无写死颜色或动效违规
- 新增前端单测、`pnpm check`、`pnpm build` 及设置页浏览器回归测试通过
