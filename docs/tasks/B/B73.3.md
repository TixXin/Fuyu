## 说明

方案见 [agent-hooks-uninstall-cleanup.md](/docs/research/agent-hooks-uninstall-cleanup.md) 第 3 步。依赖 `B73.1` 提供的 `agent_status::cleanup_for_app_uninstall`。

1. 新增 `src-tauri/src/uninstall_cleanup.rs`，并在 `src-tauri/src/lib.rs` 的 `run()` 最顶部（任何单实例锁、`home_dir::init`、WebView 创建之前）拦截 `--uninstall-cleanup [--delete-data]`，无窗口同步执行后直接 `std::process::exit(0)`：
   - 解析真实家目录（按 `FUYU_HOME` → `%APPDATA%\com.tixxin.fuyu\home.json` → `%USERPROFILE%\.fuyu`），调用 `agent_status::cleanup_for_app_uninstall(&home, delete_data)` 清理本机 18 家外部钩子/插件与本机回复标记；
   - `delete_data` 为真时：清理正式版 `com.tixxin.fuyu` 命名空间下的系统凭据（不动 `lane-*` 开发版与其他软件凭据），并执行带安全门禁的家目录删除——默认 `.fuyu` 目录经路径校验（非根、非 `%USERPROFILE%` / `%APPDATA%`、末级名为 `.fuyu`）后递归删除；用户通过 `home.json` 或环境变量指定的自定义目录**绝不整目录递归删除**，仅按浮屿受管文件与子目录白名单逐项删除，空目录再尝试非递归移除。
2. 修改 `src-tauri/windows/installer.nsi`（保持纯 ASCII 并带 `; Fuyu:` 标记）：
   - 在 `PageLeaveReinstall` 覆盖安装/升级卸载分支向 `uninstall.exe` 追加 `/REINSTALL`，在 `un.onInit` 解析 `ReinstallMode`；
   - 在 `Section Uninstall` 的 `CheckIfAppIsRunning` 之后、`Delete "$INSTDIR\${MAINBINARYNAME}.exe"` 之前，当 `$UpdateMode <> 1` 且 `$ReinstallMode <> 1` 时，按 `$DeleteAppDataCheckboxState` 调用 `ExecWait '"$INSTDIR\${MAINBINARYNAME}.exe" --uninstall-cleanup [--delete-data]'`；补充 `tests/scripts/nsis-template.test.mjs` 断言。
3. 同步更新 [agent-status-hooks.md](/docs/features/agent-status-hooks.md)、[harnesses.md](/docs/architecture/agent/harnesses.md)、[contracts.md](/docs/architecture/contracts.md)、[data-storage.md](/docs/architecture/data-storage.md)、[platforms.md](/docs/architecture/platforms.md) 及 `.claude/skills/fuyu-agent-harness/SKILL.md`（修改 skill 前先加载 `fuyu-skill-writing`），并跑通 `pnpm mq:try --wait` Windows CI。

## 验收

- `--uninstall-cleanup` 与 `--uninstall-cleanup --delete-data` 单测覆盖：保留数据卸载、删除默认 `.fuyu`、自定义家目录只删受管白名单不伤用户其他文件、正式版凭据匹配清理
- `installer.nsi` 正确区分 `/UPDATE`、`/REINSTALL` 与真正卸载，调用顺序在 `CheckIfAppIsRunning` 后、删二进制前，`tests/scripts/nsis-template.test.mjs` 通过
- 架构与功能文档、`fuyu-agent-harness` skill 同步更新，`pnpm check`、`cargo test`、双平台 `clippy` 与 `pnpm mq:try` Windows CI 全部通过
