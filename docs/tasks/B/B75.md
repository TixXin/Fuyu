## 说明

用户询问「WorkBuddy 的剩余用量在哪个位置显示」（使用的是 WorkBuddy **体验版**套餐）。

排查 [B25](/docs/tasks/0-archive/B/B25.md) 已落地的 WorkBuddy 用量实现（[workbuddy.rs](/src-tauri/src/claude_usage/workbuddy.rs)、[usageRing.ts](/src/features/claude-usage/usageRing.ts)）：
1. 当前 WorkBuddy 仅归在 `HOVER_USAGE_PROVIDERS`（默认关闭，不画收起条进度圆环），且只从本地 `~/.workbuddy/projects/**/*.jsonl` 会话日志累加「今日 / 7 天 / 累计**已用积分**」，没有**套餐总额度与剩余用量**；在体验版套餐或部分新版模型（如 `DeepSeek V4 Pro`）下还可能出现 `credit = 0` 或无积分字段。
2. 用户期望直观看到当前套餐（含**体验版**、专业版等）的**剩余用量 / 总额度**及重置/到期时间，并在岛上清晰找到入口。

按 `.claude/skills/fuyu-agent-harness/SKILL.md` 推进：
1. **调研核实 WorkBuddy 套餐与剩余额度数据源**（先写入 [agent-harnesses.md](/docs/research/agent-harnesses.md)）：
   - 核查 WorkBuddy 国内版（`~/.workbuddy`、`<AppData>/WorkBuddy`）与 WorkBuddy AI（`~/.workbuddy-ai`、`<AppData>/WorkBuddy AI`）本地存储的账号状态缓存、配置文件或官方客户端配额查询接口，明确**体验版（Trial / Free）**与付费套餐返回的字段结构（总积分/总次数、剩余额度、已用比例、到期或周期重置时间）。
   - 严守安全边界：登录凭据仅在 Rust 进程内存只读使用（静态缓存键仅存哈希指纹），不出 Rust 进程、不写日志、不落前端存储。
2. **接入剩余用量展示与进度圆环**：
   - 当能够获取套餐总额度与剩余用量时，支持在收起条渲染 WorkBuddy 用量进度圆环（兼容「显示剩余百分比」模式），并在悬停卡片与 Agent 页用量条中展示套餐名称（如「体验版」）、剩余 / 总额度与重置或到期时间。
   - 未登录或离线拿不到套餐总额度时，平滑回退展示本地会话统计（今日 / 7 天已用积分与 token 数），并在「设置 → AI 代理 → 用量」清楚标注开启位置与数据说明。
