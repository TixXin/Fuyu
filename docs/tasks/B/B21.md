## 说明

岛上的会话标题现在只读 Claude Code 记录里的 `ai-title`（src-tauri/src/agent_status/sessions.rs），它基本只在会话开头生成一次，不随对话更新。2026-11-11 查过：没有官方功能或维护中的插件能持续更新标题（sesh 只起一次名，已归档；社区需求 anthropics/claude-code #34365、#58763 还开着）。用户要求先记成待办。

## 验收

- 用户用 `/rename` 起的名字在岛上和 Agent 页显示，优先于其他标题（先核实 /rename 写进会话记录的字段）。
- 新开关（默认关）：岛屿每隔几轮或会话状态变化时，取最近几条消息，用小模型生成一个短标题，只在浮屿里显示，不改 Claude Code 自己的标题。
- 优先级：/rename 的名字 > 岛屿生成的标题 > ai-title。
- 设置里说明会多花 token、会把会话内容交给模型。
