## 说明

让 Antigravity、WorkBuddy、DeepSeek Harness 和 Claude Code / Codex 走同一套钩子：点「安装/修复」装好开始、结束、等待、审批的钩子，设置页的钩子状态也列出这三家。DSH 要用户在 `cordis.yml` 挂上 `@deepseek-ai/dsh-hooks-claude-code` 桥接插件，安装时检测并提示；桥接的 `PreToolUse` 只认 `deny` / `ask`，岛上只能拒绝。各家事件对照见 issue #175 和 [agent-harnesses.md](/docs/research/agent-harnesses.md)。

## 验收

- 三家真机点一次「安装/修复」后，运行中 / 完成 / 等你和 Claude Code 一样亮
- WorkBuddy、Antigravity 能在岛上允许或拒绝一次工具调用；DSH 能在岛上拒绝
- DSH 没挂桥接时有明确提示
