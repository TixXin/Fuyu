## 说明

B30 让 opencode 2.x 的会话在岛上显示「等你」并能在岛上审批，靠的是后台服务的 `service.json` 和 HTTP 接口。opencode 1.x 没有后台服务，`opencode --standalone` 的私有服务不写 `service.json`，这两种都拿不到待批请求。1.x 要做得写一个 1.x 插件（`event` + `permission.ask` 钩子）写事件文件、挂起等岛的结果，接口和 2.x 不兼容。调研见 [agent-harnesses.md](/docs/research/agent-harnesses.md)「opencode」一节。

## 验收

- 1.x 的会话能显示「等你」，能在岛上允许 / 拒绝；或者决定不做，在 `docs/architecture/agent/harnesses.md` 写明原因
- `--standalone` 能支持就支持，不能就在文档里写明
