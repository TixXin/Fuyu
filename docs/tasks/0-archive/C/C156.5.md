## 说明

岛屿布局设置页的「展开」那一边已改成标签式（d2a183025，预览 [island-widgets-settings-preview.html](/docs/investigations/island-widgets-settings-preview.html)）。「收起条」那一边还是原来的清单（左中右分组、上移下移、换边、开关）。用户 2026-11-20 定：也改成标签加「在收起条上 / 可以放上去」两栏，单独开任务。

- 两栏：每个项目一个标签（图标、名字），点 ＋ 放上去，点 × 拿下来，拖动或 Alt+方向键换顺序；上面的收起条预览跟着变。
- 左侧、右侧、中间和「+N」小面板这些位置在标签上怎么表达（分组、右键菜单还是长按），做之前先出预览页给用户看。
- 有样式的项目（状态灯、会话环、用量环、中心图案、剩余待办数）的样式，和展开那边的「大小」一样，放到下面用缩略图卡片选。
- 存储不变，仍是 `fuyu-collapsed-items`；功能页里的「调整 ›」链接和预览上点一项照样定位到它。标签和拖动可以复用 `src/windows/settings/island-layout/` 里的 `useChipReorder`、`.layout-chip` 样式。

预览页 [collapsed-bar-chips-preview.html](/docs/investigations/collapsed-bar-chips-preview.html)：用户 2026-11-22 定了 A 分区（左侧、中间、右侧横排，小面板在下面一条），第一版的 C 菜单并进来当右键菜单。第二版补了交互细节，页面底部「这一版定下的交互」是清单，等用户确认后照它做；水母用 `docs/assets/logo/jellyfish.svg` 的真形状。

方案 [island-layout-plan.md](/docs/investigations/island-layout-plan.md)，设计记录 [collapsed-bar.md](/docs/design/collapsed-bar.md)「收起条 / 展开切换和自定义面板」。
