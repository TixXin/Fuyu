## 说明

岛的外形现在是拼的：本体圆角矩形加盒子外面的两块反向弧（`::before` / `::after`），接缝靠盖条、遮罩和 `clip-path` 补。油膜边、液态玻璃的描边只围着本体走，左右竖线通到屏幕顶，和反向弧上另画的描边错开、断开；经典外观半透明时盖条透出一条线。改成一条 CSS `clip-path: shape()` 轮廓，描边是轮廓和它往里缩一个描边宽度的路径相减得到的环。预览页 [island-one-outline-preview.html](/docs/investigations/island-one-outline-preview.html)。

## 验收

- 贴顶、贴底、贴侧边时，描边从侧边顺着反向弧连到屏幕边、在弧尖渐隐，没有接缝和重线；液态玻璃、油膜边、经典都一样
- 经典外观透明度低于 100 时，顶边不再透出线
- 展开收起、贴边和悬空切换时，轮廓跟着动画走，没有闪烁或错位
- 不支持 `shape()` 时（旧 Mac WebView）用 `@supports` 退回现在的拼法，外观不变
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过
