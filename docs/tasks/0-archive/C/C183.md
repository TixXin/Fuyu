## 说明

来源：微信用户群反馈 `FB-10`。支持用户自定义字体样式、字体大小，以及导入本地字体文件（`.ttf` / `.otf` / `.woff` / `.woff2`）。

## 验收

- 设置 → 主题 → 质感与形状中可选择内置字体样式（默认、像素、圆润、衬线、等宽）、调节字体大小（85%–125%，可重置）以及导入、启用、打开目录或删除本地字体；上方岛屿实时预览同步更新。
- Rust 侧 `custom_fonts` 将字体存入家目录 `fonts/`，校验扩展名、文件头魔数与 32 MB 上限，并纳入升级前备份与卸载受管清单；跨窗口通过 `FontFace` 与 `custom-fonts-changed` 事件实时加载和回退。
- `fontScale` 默认 100% 时渲染零偏差；通过 Vite CSS 插件缩放字面量字号，不撑破窗口外框也不影响拖拽坐标。
- `fontFamily` / `fontScale` / `customFontId` 兼容旧配置、预设和跨设备同步白名单；中英文文案、错误码与设置搜索索引齐全。
