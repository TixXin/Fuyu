## 说明

消息页现在只有 QQ 和微信两个来源。用户要求再接 Telegram、Discord、WhatsApp、TIM（简洁版 QQ）、飞书、钉钉、企业微信七个（企业微信是用户 2026-11-16 补的），做到和 QQ、微信同一级：自己的图标和开关、来消息时岛上提醒、点开跳到对应应用、看过后自动去掉（C66 的做法）。

Windows 上复用 `qq_notifications/listener.rs` 的 `UserNotificationListener` 读系统通知，按应用过滤；TIM 和 QQ 的通知形式相近，可以先复用 QQ 的解析；企业微信和微信是两个程序（`WXWork.exe`），不能当成微信，要单独认，通知形式和 `wechat_reminders` 的处理能不能复用要实测。Mac 上系统没有读其他应用通知的接口，和 QQ、微信一样用辅助功能读程序坞角标（`macos/dock_badges.rs`），只给未读数。

和 [C57](/docs/tasks/C/C57.md)（任意应用的系统通知上岛，用户勾选应用）有重叠：两者都要把监听从 `qq_notifications` 抽成公共的一层，规划时先做这一层，或者两个任务一起排。插件平台第 3 版正在把内置功能迁成插件（[v3-progress.md](/docs/architecture/plugins/v3-progress.md)），新来源按那边的结构写，开工前和插件系统总控对一下。

## 验收

- 设置里七个应用各有开关；默认关，或检测到装了才默认开（组长定）
- Windows：来消息时岛上弹出提醒（应用图标、发件人、正文摘要），点击打开对应应用，看过后自动去掉
- macOS：显示未读数，数字变多时提醒
- QQ、微信行为不变，回归页和单元测试通过
- 中英文文案；`docs/features/` 写功能说明，`platforms.md`、`contracts.md` 同步
