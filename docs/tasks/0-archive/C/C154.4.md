## 说明

岛吸附在 Win11 任务栏里时，用一套任务栏专用的透明外观：不画黑色胶囊，透出任务栏本身，看起来像任务栏的一部分（汽水音乐的歌词条就是这样）。
- 不改用户保存的主题：岛放进任务栏时临时换外观，离开任务栏自动回到原主题；只换岛，设置窗口等不变
- 文字颜色跟系统任务栏的深浅色（`SystemUsesLightTheme`），不跟岛的深浅色
- 悬停时加一层很淡的底色，和任务栏按钮的悬停一样
- 设置 → 外观 → 位置与尺寸加一行「任务栏上的外观：透明（默认）/ 跟随岛屿主题」，只在选了任务栏时显示；中英文文案、设置搜索索引

## 验收

- 选「任务栏」后岛变透明、文字在深浅色任务栏上都看得清；改回别的吸附边恢复原主题
- 选「跟随岛屿主题」时和 C154.2 一样
- 回归页覆盖透明外观的深浅两种任务栏
