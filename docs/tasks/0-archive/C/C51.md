## 说明

用户 2026-11-12 觉得迷你桌面上画的岛和真岛不一样，要求改成全屏遮罩、在真岛上演示，并做演示模式和岛弹出面板的欢迎消息。说明见 [新手引导](/docs/features/onboarding.md)。

## 验收

- 遮罩压暗屏幕，亮圈跟着真岛（展开、收起、贴边、换屏都跟上）
- 只有卡片接住鼠标，能碰到真岛，能从桌面拖文件到岛上
- 引导开着时岛上有演示歌曲和演示 Agent 会话，关掉就消失
- 打开时岛弹出「你好啊，我在这儿」，点「开始使用」后弹出「浮屿已就绪」
- Esc、跳过、× 都能退出；中英文、深色浅色都不溢出
