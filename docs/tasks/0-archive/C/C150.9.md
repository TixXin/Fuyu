## 说明

截图存进历史时在后台用本机识字（Windows 自带 / Vision）取出文字，记在图旁边；岛上「截图历史」页加搜索框，按文字过滤，命中的词在缩略图上标出来。识字失败或关掉时不影响历史本身。

## 验收

- 存进历史后几秒内能搜到图里的文字，中英文都行
- 删除截图时一起删文字；保留天数照旧
- 单元测试（搜索和索引）；截图历史回归页更新；`pnpm check`、`pnpm build`、`cargo test`

## 提交

- `feat(screenshot): search the screenshot history by the text in the pictures`

## 备注

- 文字存在 `screenshots/<名字>.words.json`（行 → 词，位置是相对原图宽高的 0–1），识字串行、在后台线程，识完发 `screenshot-history-changed`；空结果也写文件，避免重复识。
- 搜索在前端做（`historySearch.ts`）：去掉空白、忽略大小写和全角，同一行里跨词匹配；缩略图是 16:10 `cover` 裁切，标记框按原图宽高换算到裁切后的位置。
- 设置 → 截图 加了「识别历史截图里的文字」（`historyText`，默认开，跟着同步）。
- 实测清单（本机只跑了单元测试和回归页，真岛识字要装好的岛）：1) Mac 真岛：截一张有中英文的图，几秒内「截图」页能搜到并标出词；2) Windows 真岛同上（Windows OCR 要装中文语言包才认中文）；3) 删掉一张、改保留天数后 `screenshots/` 里不留多余的 `.words.json`；4) 关掉开关后新截图不再生成文字文件。
