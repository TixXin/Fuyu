## 备注

- 日历 tab 的顺序：已添加的日历、日历面板（默认视图、每周起始日、月历周数、折叠全天日程）、哪些日程不算（隐藏已拒绝、空闲不参与倒计时、以时间开头的待办并入日程），快捷键那组仍在这个 tab，放在最后（原来跟在面板组后面，来源组挪到最前后只能放最后）。`calendar` 和别名 `calendarSources` 都落在这个 tab。
- 提醒 tab：演示组（演示框、收起条显示格式的 3 格缩略图、显示会议标题）、小岛倒计时（提前多久，开着时再显示范围和开始后保留）、会前强提醒（开关和提前量一行，强提醒关着时提前量的下拉灰掉；调休和放假前一晚；加入时暂停媒体；自定义会议域名收进「高级」折叠）。
- 演示直接用岛上的 `MeetingLine` 和 `MeetingBannerNotice` 画，加入按钮和关闭按钮借岛上的 class 画成不能点的样子，不调用 `joinCalendarMeeting`。示例会议固定是 14:00 的「产品周会」，倒计时取 10 分钟和「会前倒计时」里较小的那个；横幅按当前提前量写。
- 演示框只在点「演示强提醒」后动：外壳底层横向展开、文字淡入，4.2 秒后自己回到收起条；页面刚打开时不动。减少动态效果时没有动画，直接换成横幅再换回来。缩略图是静止的三种收起条，不需要动。
- 「显示会议标题」原来只在倒计时开着时出现，现在常驻在演示组里：它也管横幅。「强提醒提前量」不再是单独一行，它的说法写进了开关行的说明，设置搜索还能搜到。
- 存储没动：`IslandSettings` 的 `calendarRemindMinutes`、`calendarShowTitle`，`fuyu-calendar-prefs` 的各字段、取值和默认值都照旧；回归页断言了选「紧凑」照旧写进 `countdownFormat`。
- 没跑 `pnpm settings:index`（统筹会话最后统一做），在那之前 `settings-search` 回归页挂是预期的。
