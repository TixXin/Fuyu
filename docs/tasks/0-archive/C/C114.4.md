## 说明

[C114](/docs/tasks/C/C114.md) 第二波子任务，在 [C114.1](/docs/tasks/0-archive/C/C114.1.md) 基础上打通待办结构化拆解与 `timers/v1` / `reminders/v1` 跨插件联动：

1. **单层子任务（Checklist）与简短备注**：`TodoItem`（前后端 `types.ts` 与 `src-tauri/src/todos/model.rs`）向后兼容地新增可选 `subtasks?: { id: string; title: string; completed: boolean }[]`、`note?: string`、`focusMinutes?: number`；主行折叠态仅显示轻巧的 `2/4` 进度微标，点开可在行下编辑子步骤与一行备注，可选「子任务全部勾选后自动完成主待办」，Markdown 导出自动写成缩进 `  - [ ]`。
2. **专注番茄钟联动（`timers/v1`）**：在「设置 → 待办」开启「开始任务时启动专注倒计时（默认 25 分钟可调）」后，点击待办的「开始」自动调用 `timers/v1` 启动专注倒计时，计时结束累加 `focusMinutes`。
3. **带时刻待办准点提醒（`reminders/v1`）**：对今日标题含 `HH:mm` 行首时间的未完成待办，支持到点经 `reminders/v1` 弹出岛屿提醒横幅（提供「完成」「推迟 10 分钟」动作）。

## 验收

- 旧版 `todos.json` 无迁移报错；新增子任务与备注后持久化、归档与 Markdown 缩进导出均正确
- 开启专注联动后点击待办「开始」能拉起内置 `timer` 倒计时并在设置页妥善提示未启用 `timer` 的引导
- 带 `HH:mm` 的今日待办到点触发一次 `reminders/v1` 提醒，回归页、前端单测与 Rust `todos` 测试全部通过
