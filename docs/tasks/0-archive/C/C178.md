## 交接

- 2026-11-23 06:40 页头图标自定义方案：实测清单（本机只在 headless Chrome 回归页里看过，真 WebView 和真岛没看）：1) Windows WebView2 和 Mac WKWebView 的设置窗口里把 PNG/SVG 拖进「图片」区能导入，拖到别处不会把窗口导航走（settings 窗口 dragDropEnabled 改成了 false）；2) 截图后 Ctrl/Cmd+V 粘贴、复制 SVG 代码粘贴能导入；3) 真岛页头 emoji（原色和单色）、文字、单色图片在深浅色岛上的大小和对齐；4) 两台设备开着「收起的岛」同步组时图片跟过去。
