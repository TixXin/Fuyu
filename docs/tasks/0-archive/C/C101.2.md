## 说明

按 [计划](/docs/architecture/clipboard-preview-plan.md) 里的 P2 做：滚轮以指针为中心缩放，拖动平移，双击切换适应 / 100%，加缩放条，键盘 + - 0 由剪贴板窗口转发。

## 备注

- 结构：缩放计算在 `src/features/clipboard/imageZoom.ts`（纯函数），交互在 `useImageZoom.ts`，组件 `ClipboardImageViewer.tsx` 取代了 `ClipboardPreviewImage.tsx`。`ClipboardPopupPreview` 加了可选 prop `imageZoom`：预览窗口传它（滚轮、捏合、拖动、双击、缩放条、`+` `-` `0`）；宽版右栏和管理页不传，只有双击和拖动。适应时不加任何变换，DOM 和以前一样。
- 100% 指一个图片像素对一个屏幕物理像素（按 `devicePixelRatio` 换算）；适应会把小图放大铺满（和以前的 `object-fit: contain` 一致），所以最小只缩到 min(适应, 100%)，最大 800%。
- 捏合：WebView2 发带 Ctrl 的 wheel，WKWebView 发 `gesturechange`，两种都接。
- 验证：`pnpm test:regression clipboard-image-viewer` 23 项通过（快照随提交）；`clipboard-preview` 46 项通过、快照不变；`clipboard-popup` 失败在「Ctrl+E 编辑，Ctrl+S 另存为新记录」，是 C101.3 正在改的键位，不是本任务。`pnpm check` 停在 `check:tests-types`：`tests/regression/tray-menu.tsx` 两处类型错误（别的会话没提交的文件）；其余各步单独跑都通过，单元测试 1440 通过 0 失败。`pnpm build` 通过。
