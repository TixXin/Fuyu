## 说明

在 `src-tauri/src/win32/` 加任务栏宿主：
- 找当前显示器的任务栏（`Shell_TrayWnd` / `Shell_SecondaryTrayWnd`），读矩形、对齐方式（`TaskbarAl`，读不到时看开始按钮位置）、是否自动隐藏
- 把一个窗口的所有者设成任务栏（`SetWindowLongPtrW(GWLP_HWNDPARENT)`），加 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`；能还原
- 用 UI Automation 取任务按钮组、开始按钮、小组件按钮、托盘区，算出能放东西的空白区域（靠左：任务按钮右边到托盘区；居中：按钮组两侧较宽的一边）
- 跟随任务栏变化（位置、自动隐藏、对齐、图标数量、DPI、显示器），`SetWinEventHook` 加慢轮询兜底；收到 `TaskbarCreated` 后重新挂上
- 全屏应用在前台时让开

### 先实测

Explorer 正常重启和 `taskkill /f` 时，所有者是任务栏的跨进程窗口会不会被一起销毁。会的话改成只置顶、不设所有者的退路方案，把结论写进调研文档。
