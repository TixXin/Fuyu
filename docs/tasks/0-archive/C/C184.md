## 说明

响应群反馈 FB-7：内置倒数日小组件与官方 `@fuyu/countdown` 倒数日/纪念日插件同步支持农历日期与公历/农历切换：
- 内置小组件支持公历/农历切换、数字农历（如 `08-15`、`闰6-15`、`2026-08-15`）与中文农历（如 `八月十五`、`正月初一`、`除夕`、`闰六月初五`），自动按农历跨年计算并实时预览公历日期。
- 官方 `@fuyu/countdown` 插件（升级至 `1.2.0`）新增公历/农历切换与农历年/月（含闰月）/日选择器，支持实时公历预览、农历每年重复、纪念日天数与周年数计算，无损兼容旧公历数据。
