[C114](/docs/tasks/C/C114.md) 第一波子任务（纯前端待办侧，详见 [todos-and-calendar-expansion.md](/docs/research/todos-and-calendar-expansion.md) 第四节）：在不改动 `todos.json` 存储契约的前提下，补齐待办高频效率能力并将「设置 → 待办」充实为结构清晰的分组卡片。

1. **待办偏好存储与跨窗口同步（`fuyu-todo-prefs`）**：
   - 在 `src/features/todos/` 新增 `todoPrefs.ts` 与 `useTodoPrefs.ts`（读写 `localStorage` 的 `fuyu-todo-prefs`，监听 `storage` 与窗口内 `CustomEvent` 实时同步，损坏或旧字段平滑回退默认值）。
2. **「设置 → 待办」分组扩充（[TodosSettingsPage.tsx](/src/features/todos/TodosSettingsPage.tsx)、[TodoSettingsSection.tsx](/src/features/todos/TodoSettingsSection.tsx)）**：
   - **小岛显示与排序**：保留空闲剩余数、多任务流动及秒数、允许拖拽排序；新增「显示进行中已用时长」（默认开，读取 `TodoItem.startedAt` 在列表行与收起条显示如 `18m` / `1h 05m`）与「列表排序方式」（手动顺序默认 / 优先级优先高→低 / 创建时间新→旧）。
   - **快速录入与轻语法**：新增「行内快捷语法识别」（默认开：回车提交时自动识别并从标题剥离 `!1`/`!2`/`!3`、`p1`–`p3`、`！1`–`！3` 优先级，以及 `@今天`、`@明天`、`@后天`、`@下周一`..`@下周日`、`@MM-DD` 计划日期，兼容既有 `#项目` 前缀）与「新建待办插入位置」（列表底部默认 / 列表顶部）。
   - **反馈与跨天结算**：新增「勾选完成时播放轻音效」（默认开，Web Audio 合成短促克制的勾选音效并提供设置页试听按钮）、「新一天开始时间」（`00:00` 默认 / `02:00` / `03:00` / `04:00` / `05:00` / `06:00`，在 [useTodoRollover.ts](/src/features/todos/useTodoRollover.ts) 按逻辑日期翻篇，避免熬夜过零点误归档）、「已完成任务显示方式」（底部折叠栏默认 / 保持原位划掉 / 完成后从今日列表隐藏，仍计入完成进度与归档）、「Markdown 导出附带信息」（可选写出优先级标记与专注分钟数）、「应用内归档保留时长」（永久保留默认 / 90 天 / 180 天 / 1 年，不影响磁盘已导出的 `.md`）。
3. **文案与测试**：补齐中英文文案（`src/i18n/sections/todo.ts`、`todoIsland.ts`、`settings/todo.ts`）与 `tests/unit/todo-prefs-and-syntax.test.mjs` 单元测试。
