## 说明

参考 eIsland：外观里可调整个岛的透明度；一段时间没操作自动降低透明度，光标靠近或有新消息时恢复；闲置变淡时鼠标点击穿透到下面的窗口。和贴边收起是两种不挡视线的方式，可以同时开。

## 验收

- 外观里有透明度和「闲置变淡」（时长、变淡程度）设置
- 变淡时点击穿透，光标靠近或有提醒时立刻恢复
- 折叠、展开、贴边收起和托盘隐藏下行为正确
