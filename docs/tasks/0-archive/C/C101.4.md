## 备注

### 调研（2026-11-16，c101-4）

截图的标注能不能复用：

- `src/features/screenshot/annotations.ts`（工具、颜色、粗细、开始 / 延伸 / 撤销重做的纯函数）和 `drawAnnotations.ts`（把标注画到 canvas，马赛克要传底图）都不依赖截图的状态，坐标是图片像素，`scale` 只决定线宽，可以原样用。
- `src/windows/screenshot/useAnnotations.ts`（工具、样式、历史、草稿、文字输入的状态）和 `AnnotationTextInput.tsx` 也能直接用：样式存在截图的 `fuyu-screenshot-annotation-style`，两边共用一套颜色和粗细正合适。`ScreenshotToolbar.tsx` 和截图的复制、钉住、长截图绑在一起，不复用，剪贴板这边写一个小工具栏（同一组 lucide 图标）。
- 不能从 `src/features/clipboard/` 直接 import：feature 之间禁止互相 import（`tests/unit/feature-boundaries.test.mjs`，白名单只减不增）。所以编辑器放在 `src/windows/clipboard/`（窗口层可以组合多个 feature），剪贴板自己的纯函数（裁剪、旋转、坐标换算）放 `src/features/clipboard/imageEdit.ts`。截图那边的文件不改。
- 读原图进 canvas：`fuyu-clip://` 和页面不同源，画进去会污染 canvas、读不出像素。不给图片协议加 CORS（插件页面也在 webview 里），而是加命令 `read_clipboard_history_image` 用 `tauri::ipc::Response` 把 PNG 原样交给前端。
- 图片地址按条目 id 缓存一天（`immutable`），替换后同一个 id 会显示旧图：前端地址加 `?v=<hash>`，Rust 只看路径，不用改 `image_protocol.rs`。

Rust 要碰的：

- 新文件 `clipboard_history/edit_image.rs`：命令 `save_clipboard_history_image`（原始请求体是 RGBA，请求头 `x-id`、`x-width`、`x-height`、`x-mode`=`replace`|`new`，照截图 `screenshot_finish` 的做法）和 `read_clipboard_history_image`；哈希照抓取时的算法（宽高 + 像素），文件用 `service.persist_image` 写成新名字（`<hash>.png` / `-thumb.png`），所以替换时旧文件还在，撤销直接指回旧文件；撤销窗口过后（后台线程等 `UNDO_WINDOW_MS` 加几秒）旧文件没人引用了才删，撤销时删新文件；替换后清掉 `ocrText`，开了文字识别就重新识别（结果写回前先确认这条还是那张图，防止撤销后被写错）。`new` 走 `insert_capture`，和抓到一张新图一样（去重、识别都照旧）。
- `edit.rs`：撤销沿用 `LAST_EDIT` 和 `undo_clipboard_history_edit`，`with_content_of` 多恢复 `image`、`ocrText`，`apply_undo` 返回被撤掉的内容，好删新文件；不另写一套撤销。
- `service.rs`：只把 `read_image_text` 改成 `pub(super)`。`mod.rs`：`tauri_commands!` 加两条、`mod edit_image;`。`store.rs`、`file_image.rs`、`image_protocol.rs` 不用改。
- 只编辑「图片」类条目；复制的图片文件（`Files` + `fileImage`）是用户磁盘上的文件，不替换，第一版也不给编辑入口。

前端：进编辑和焦点交接用 C101.3 那套（`{ type: "edit" }` 命令、`set_clipboard_preview_editing`，把 `ClipboardPreviewEditor` 里的焦点交接抽成 hook 两边共用），改好后照旧发 `{ type: "edited" }` 给剪贴板窗口显示撤销。裁剪、旋转直接作用到底图（有标注时先把标注画进底图），撤销栈里放底图快照；Ctrl/⌘+Z 先撤标注再撤裁剪旋转。

## 交接

- 2026-11-16 01:07 c101-4：实测清单（本机是 Mac，代理不跑 tauri dev；Windows 要另一台机器）：两边 1) 预览里 Ctrl/⌘+E 或点「编辑图片」进编辑器，预览拿到键盘，剪贴板窗口不关 2) 画框、箭头、文字（中文输入法能打字）、马赛克、序号；裁剪拖出范围回车应用；左右旋转；Ctrl/⌘+Z 先撤标注再撤裁剪旋转 3) Ctrl/⌘+S 改这条：列表缩略图和预览都换成新图、标「已编辑」，识别出的文字过几秒更新；底栏 6 秒内撤销后变回原图 4) Ctrl/⌘+Shift+S 另存一条：顶上多一条新图，原来的不动 5) 大图（4K 截图）保存不卡太久，超过 10 MB PNG 时提示没保存上 6) 改这条后 15 秒左右 clipboard-images 目录里旧的 png 被删，撤销过的那次删的是新的 7) 编辑时点别的程序：两个窗口照常关；全屏档下编辑区够大。Mac 8) 有 ICC 色彩配置的图片编辑后颜色不变
