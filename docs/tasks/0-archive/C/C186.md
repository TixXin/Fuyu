## 说明

来源：微信用户群反馈 `FB-5`。关闭「文件中转」插件或关闭「拖入文件时自动展开」且未停留在文件中转页时，主岛（与侧边翼）不再拦截外部文件拖入，同步关闭 Windows WebView2 原生 `AllowExternalDrop` 并在外部拖拽经过主岛时自动启用鼠标穿透，让拖拽直接落到下层窗口或桌面；桌面图标区域无法按顶部药丸局部挖空的技术限制在群内一并说明。

## 验收

- `shouldAcceptFileDrop` 在文件中转关闭、或关闭 `shelfExpandOnDrop` 且未处于文件中转展开页时返回 `false`，前端同步调用 `set_island_file_drop_accepted`（卸载时置 `false`）。
- Windows 侧 `win32/webview_drop.rs` 调用 `ICoreWebView2Controller4::SetAllowExternalDrop` 实时同步原生外部拖放开关，主岛启动页面加载时同步初始状态。
- `ExternalDragGuard` 在双平台主岛鼠标穿透循环中识别「岛外按下并拖过主岛」，当主岛不接收拖入时启用鼠标穿透并抑制悬停，不影响岛内点击、拖岛、缩放与拖出。
- 通过 `tests/unit/file-shelf.test.mjs`、`drag_passthrough` 单测与双平台 clippy。
