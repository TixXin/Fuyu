## 说明

在 src-tauri/src/macos/ 加一个只有岛大小、按岛形状遮罩的 NSVisualEffectView（macOS 26 用 NSGlassEffectView），展开收起跟着改 frame；刘海形态折叠时仍纯黑（G1.11），macOS 26 以下和「降低透明度」时退化。调研见 docs/research/liquid-glass.md §3；来自 C87 用户决定（2026-11-15）。

## 备注

- macOS 27.2（Build `26B123`）`macos_native_glass_probe --release` 实测：基线透明 `NSPanel` 静止 `9.63 MB` / `0.02%` CPU；`NSVisualEffectView` 九宫格遮罩静止 `12.55 MB`（`+2.92 MB`）/ `0.01%` CPU、60fps 开合 `16.24 MB` / `0.26%` CPU；`NSGlassEffectView` 悬空胶囊静止 `16.38 MB` / `0.02%` CPU、60fps 开合 `16.39 MB` / `0.20%` CPU；九宫格遮罩冷生成耗时 `626 µs`（`136×76 px`，`965 B` PNG）。详见 `docs/investigations/macos-native-glass.md`。
- 实测清单（需人工或旧系统真机目视核验）：1) 在真岛切到「液态玻璃 → 玻璃背后 → 原生透出（实验）」，核对贴顶、悬空药丸、四边吸附、刘海折叠纯黑与展开过渡的视觉效果；2) 系统辅助功能开启「降低透明度」后核对自动退回纯色玻璃；3) macOS 15 及以下机器核对无 `NSGlassEffectView` 时自动走 `NSVisualEffectView` 退路。
