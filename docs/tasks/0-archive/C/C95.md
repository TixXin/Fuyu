## 说明

跨设备同步（调研见 [cross-device-sync.md](/docs/research/cross-device-sync.md)）里剪贴板收藏的同步，默认关。

- 只同步收藏的文字条目，按内容 hash 去重（两台复制同一段字 id 不同）
- 收藏 / 取消收藏要带时间；`pinKey` 全局唯一，合并后有重复时要裁决
- 敏感、被打码、带 Windows 排除格式的条目不上传，也不被远端覆盖
- 图片以后再说（按内容另存 blob、限大小）
