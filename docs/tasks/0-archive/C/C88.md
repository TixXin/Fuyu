## 说明

C64 做了蓝牙鼠标、键盘的电量。用罗技 Unifying / Bolt / Lightspeed USB 接收器的鼠标键盘不走蓝牙，系统读不到电量，要用罗技的 HID++ 2.0 协议经接收器的厂商自定义 HID 接口（usage page 0xFF00）直接问设备：先用根功能 0x0000 查到 UNIFIED_BATTERY（0x1004）或 BATTERY_STATUS（0x1000）的功能序号，再读电量。两个系统都用 HID 接口（Rust 的 `hidapi`），不用装驱动；Mac 上要确认是否需要「输入监控」权限。读数接到 `device_events/peripherals.rs` 的外设提醒上。调研见 https://github.com/TixXin/fuyu/blob/main/docs/research/peripheral-battery.md

## 验收

- 接收器上的罗技鼠标、键盘连上时岛上提示带电量，低于 20%、10% 各提醒一次，和蓝牙外设同一套提醒
- 没有接收器、设备不支持电量功能、或读失败时不显示、不报错，不影响罗技 Options+ / G HUB 同时运行
- Windows、macOS 都实测（至少一个 Unifying 或 Bolt 接收器）
