## 说明

- 快捷启动组件：除了终端、文件、计算器、设置四项，能加自己的应用（选一个程序），能删、能排序
- 音量亮度组件：亮度能拖动调节（Windows 用 WMI / DDC，Mac 用内建屏的亮度接口），不支持的屏幕说明原因

## 验收

快捷启动能加、删、打开自己选的应用，重启后保留；支持的屏幕上亮度能拖动调节，不支持的说明原因。两个平台的情况写进 platforms.md。
