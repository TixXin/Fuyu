## 说明

- 新插槽 `island.widget/v1`：一项声明支持的尺寸（`bar` / 小 1×1 / 中 2×1 / 大 2×2 / 宽 4×1），组件拿到尺寸和容器宽高。现有 `island.collapsed/v1` 保留，宿主把它当成只有 `bar` 尺寸的组件。先只给内置插件。
- 内置功能各出一两个组件：今天的待办、下一个会议、正在播放、歌词、Agent 会话、用量环、天气、世界时钟、系统监控、最近剪贴板、快捷启动。
- 自定义面板：在「岛屿布局 → 展开页面」新建，起名、选图标，4 列网格（格子 120、间距 8），压到别的组件时往下挤，最多 4 行，再多在面板里滚动。在设置里编辑：中间按实际大小画的面板，右边按功能分组的组件库，点尺寸加入；点「条」加到收起条上。
- 新 key `fuyu-custom-panels`。默认没有自定义面板，老用户看不出变化。

方案 [island-layout-plan.md](/docs/architecture/history/island-layout-plan.md)，预览 [island-layout-preview.html](/docs/investigations/island-layout-preview.html)。

## 验收

- 能新建、改名、删除面板，加、拖、删组件，岛上实时跟随
- 收起条上的内置项目也能以大尺寸放进面板
- `contracts.md` 写新 key 和新插槽，进同步白名单和设置备份；插件类型声明更新
