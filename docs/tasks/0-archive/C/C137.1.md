## 说明

按预览页 [agent-notice-preview.html](/docs/investigations/agent-notice-preview.html) 做通知卡片的三套样式，由 C137.4 的「通知样式」设置切换，默认 B。卡片还读消息行数、命令行数、Markdown、元信息位置、滚动条、审批按钮顺序、显示快捷键这几项。审批和提问卡在三套样式里结构一致。颜色固定：只有等你确认用橙色（状态字和图标环），主按钮用强调色，等你回复灰蓝，出错红。

## 验收

- 三套样式下五种状态、审批卡、提问卡都对，浅色和深色岛都对
- 长消息按设置的行数显示，超出在卡片内滚动；叠加式滚动条 3～4px、深浅跟岛走、上下渐隐，滚到底不传给岛，减少动画时不淡入淡出；悬停展开全文
- 窄于 300px 时按预览页的规则收按钮，中英文不溢出
- `agent-alert-card`、`agent-approvals` 回归页覆盖三套样式，快照更新
