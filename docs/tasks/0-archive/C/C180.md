## 说明

把笔记本电池的详细信息放到岛上：放电剩余时间（优先用系统估时，没有时用实测功率）、充电时的充满预计（实测功率；驱动给了功率和容量时第一次读数就能估）、当前 / 满充 / 设计容量和健康度、最近一段时间的电量曲线（可悬停、方向键查看采样点，设置里可关），收起态一格电量或剩余时间（设置里选）。

现状：只有「电量 + 是否接电」，来自 `src/features/system-widgets/`（电池小组件，Rust 在 `src-tauri/src/system_widgets/`、Mac 在 `src-tauri/src/macos/power.rs`）和官方插件 `plugins/v3/official/system-monitor/`。开工先定是扩展它们还是另做一个电池插件，理由写进本文件。

**架构决定（2026-11-25）**：直接扩展内置 `system-widgets` 电池小组件（增加 `m` 卡片规格展示详细容量/健康度/交互式电量曲线，并补充收起条电池芯片与对应设置），不另建独立市场插件。理由：① `system-widgets` 已具备跨平台系统电源采样、桌面机自动隐藏（`batteryPresence.ts`）和 `island.widget/v1` / `island.collapsed/v1` 接缝；② 避免重复轮询电源接口或要求用户再装一层插件；③ 保持对原有 `get_system_stats` 契约的向后兼容。

思路参考自 @QXiaoLingShang 在 [flyl1u/fly-island#126](https://github.com/flyl1u/fly-island/pull/126) 的电池插件，作者 2026-11-23 在 PR 下同意我们参考。上游是第 2 版结构（往岛壳里接了约 30 个文件），按 v3 插件重新实现，不搬分支。可参考的点：`GetSystemPowerStatus` 标志位未知时不当成没电池、`GetPwrCapabilities` 排除 UPS 和短时电池、WinRT `AggregateBattery` 读容量和功率；实测功率要排除间隔过大、拔插电源、适配器功率不够这几种情况。他的版本在岛隐藏时也每 10 秒采样，采样不落盘，这两点不照搬。

## 验收

- 笔记本上能看到剩余时间、充满预计、容量和健康度、电量曲线；台式机上不出现电池入口
- 驱动读不到容量详情时退回只显示电量
- 文案中英文；深浅色、窄窗口都看过
- Windows 和 macOS 的支持情况写进 `docs/architecture/platforms.md`
