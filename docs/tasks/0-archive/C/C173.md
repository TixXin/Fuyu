## 说明

设置 → 计时与提醒 → 系统提示里加「大写锁定」。用户在 [预览页](/docs/investigations/caps-lock-preview.html) 里选了图标 G「箭头加锁」，其余按预览页的推荐。

## 验收

- 开了这一项，按 Caps Lock，收起的岛（贴顶、悬空、底边、刘海、侧边岛）弹 1.5 秒「大写锁定已开启 / 已关闭」，关闭是灰色。
- 先后：消息预览 > 大写锁定 > 设备提示 > 音量亮度。
- 大写开着时收起条上有黄色角标，是「岛屿布局」里的一项；点角标关掉大写。
- 子选项：提示方式（只一闪 / 只角标 / 一闪 + 角标，默认一闪 + 角标）、关掉大写时也提示（默认开）、点角标关掉大写（默认开）。
- 整项默认关；关着时 Rust 不轮询。
- 刚启动、睡眠回来时状态变了不弹，只更新角标。
- 中英文案、设置搜索、契约（事件、命令）、platforms.md。
