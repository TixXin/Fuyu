## 说明

收起条上的内容现在有 6 个地方能改：外观 → 收起条上的项目、右键菜单、插件详情的「显示在岛上」、AI Agent 页（状态灯、会话环的样式）、待办 / 音乐 / 插件设置里的岛上样式、外观 → 收起条（「+N」、刘海两侧最宽）。功能开不开、放在哪、长什么样三件事混在一起，用户不知道该去哪改。展开的岛也只有固定页面，不能自己搭一页想看的内容。

用户 2026-11-20 定的方向：

- **功能页只管功能本身，岛上的事都在新的设置页「岛屿布局」里管。**右键菜单和岛上编辑模式是它的快捷方式，改的是同一份数据。
- **加自定义面板**：组件有 条 / 小 / 中 / 大 / 宽 几档尺寸，面板支持网格和自由两种排版，设置里和岛上都能编辑；收起条项目就是组件的「条」尺寸。

方案 [island-layout-plan.md](/docs/investigations/island-layout-plan.md)，预览 [island-layout-preview.html](/docs/investigations/island-layout-preview.html)。

分四步，每步单独能用，各有子任务：

1. **C156.1 「岛屿布局」设置页**：收起条的显示、位置、样式只在这里改，各处原位置换成链接
2. **C156.2 展开页面能排序、隐藏**
3. **C156.3 组件插槽和自定义面板**：网格排版，在设置里编辑，内置功能各出一两个组件
4. **C156.4 自由排版、岛上编辑模式、面板模板**，组件插槽开放给第三方插件

## 验收

- C156.1 到 C156.4 全部结束
- `docs/design/` 记下新的约定，`contracts.md` 记下新的存储 key
