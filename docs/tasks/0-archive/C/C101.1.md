## 说明

## 备注

### 给 C101.2、C101.3 的命令通道

- 事件 `clipboard-preview-command`，剪贴板窗口（`clipboard`）用 `emitTo("clipboard-preview", …)` 发给预览窗口。载荷是 `src/features/clipboard/previewCommands.ts` 里的联合类型 `ClipboardPreviewCommand`，现在只有 `{ type: "zoom", zoom: "in" | "out" | "reset" }`。
- 加命令只改 `previewCommands.ts`：往 `ClipboardPreviewCommand` 里加一种，在 `previewCommandForKey(event)` 里把按键映射过去（预览开着、剪贴板窗口在 look 模式时，`useSpacePeek.lookKey` 先问它，返回非空就 `preventDefault` 并发出去）。现在映射了 `+` / `=` → in、`-` → out、`0` → reset，带 Ctrl / ⌘ / Alt 的不映射。C101.3 要的 Ctrl+E 进编辑，在这里加一条带修饰键的映射，不用动 `ClipboardPopup.tsx`。
- 预览窗口这边用 `useClipboardPreviewCommand(handler, enabled?)`（`src/features/clipboard/useClipboardPreviewCommand.ts`）收，P1 里还没有人用；图片查看器、编辑器各自在组件里调用它。
- 反方向：预览窗口发给剪贴板窗口的是 `clipboard-preview-report`（`{ type: "pointer", inside }` / `{ type: "pinned", pinned }` / `{ type: "close" }`），由 `useSpacePeek` 收。C101.3 进编辑时要让剪贴板窗口失焦不关，可以在这里加一种 report。

### 给 E36.3.34 迁移用：窗口配置和 `clipboard_history` 入口改了什么

- `tauri.conf.json`、`capabilities/` 都没改：`clipboard-preview` 窗口照旧启动时创建、`focus: false`、`focusable: false`、`resizable: false`（拖边改大小是前端画拖拽区、经 Rust `set_size` / `set_position`，不靠系统的可调大小）。
- `clipboard_history/mod.rs`：多了 `pub(crate) mod preview_size;`；`ClipboardHistorySettings` 多一个 `#[serde(flatten, default)] preview: preview_size::PreviewSettings`（字段 `previewSize`、`previewWidth`、`previewHeight`，`normalized()` 里一起规范化）；`tauri_commands!` 多三条：`preview_window::set_clipboard_preview_size`、`preview_window::resize_clipboard_preview`、`preview_window::clipboard_preview_has_pointer`。
- `clipboard_history/preview_window.rs`：摆放改用 `island/screen.rs`（Mac 上按点算），显示后 Windows 调 `win32::window::place_below`（新加的安全封装，`SetWindowPos` 插到剪贴板窗口下面）、Mac 把预览面板的 level 设成 `MainMenu + 3`（剪贴板窗口是 `+4`）；新事件 `clipboard-preview-layout`。`macos/island_panel.rs` 没动。
- 迁成插件时这三条命令和三个事件（`-layout`、`-report`、`-command`）跟着预览窗口走；设置字段在 `clipboard-history.json` 里，格式见 `contracts.md`。

### 实测清单（本机是 Mac，Windows 只能在另一台机器上测；Mac 上要用户跑开发版，代理不跑 `pnpm tauri dev`）

Windows：

1. 预览出现、点击（档位按钮、图钉、×）、滚轮、拖动时剪贴板窗口不失焦、不关。
2. 按住空格时鼠标进过预览，松开后预览留住；没进过照旧关；松开时指针停在预览上也留住；图钉钉住后空格不关，Esc 和 × 能关。
3. 中等、全屏两档的位置和大小：单屏、副屏、不同缩放比例（100% / 150%）、任务栏在侧边；拖四条边和四个角改大小时剪贴板窗口不失焦，松手后变成自定义档，重开后记得大小；双击顶栏在全屏和上次大小之间切换。
4. 全屏时剪贴板窗口在预览上层，↑↓ 换条预览跟着换；点一下预览后剪贴板窗口仍在上层。
5. 剪贴板窗口里按 F 循环三档，`+` `-` `0` 不会打进搜索框。
6. Win+V 打开的剪贴板窗口同样适用以上几条。

Mac：

1. 非 key 面板里鼠标进出（`pointerenter`）收不收得到；收不到时松开那一下靠 `clipboard_preview_has_pointer` 也能留住，但「按住时提示松开后保留」不会出现。
2. 点预览里的档位按钮、图钉、×，以及拖边时剪贴板窗口仍是 key、不关；第一次点击就生效（不是只把面板点到前面）。
3. 全屏档时剪贴板窗口压在预览上面；全屏应用所在的桌面里中等、全屏两档的位置。
4. 外接屏（缩放不同）上全屏档跟着剪贴板窗口那块屏，拖边的位移和鼠标对得上。
