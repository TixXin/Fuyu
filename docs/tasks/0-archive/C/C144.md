## 说明

0.3.11 发布后群里三位用户反馈岛「莫名其妙消失」，托盘还能用，重启才回来。读代码的结论（还没让遇到问题的用户验证）：C134 的全局快捷键「切换岛的上下层」默认开着，键是 `Ctrl+Alt+B`，在 VS Code / Cursor（开关右侧栏）和 JetBrains（跳到实现）里都是常用键；按到后岛退到所有窗口下面，岛和托盘卡片都没有提示，上下层只在内存里，重启才回到最前。

做法：

1. `islandLayerShortcut` 默认改成空（不设）。新加 `islandLayerShortcutChosen`（布尔）：在设置里设过键才是 true，不是 true 时存着的键不算数，这样 0.3.11 存下的默认值升级后被清掉。
2. 岛退到下层前，岛上先显示一行提示，约 1.2 秒后才真正退下去；回到最前不等。
3. 托盘卡片的岛按钮在岛退到下层时显示「在窗口下面」，点一下回到最前；任何「显示岛」的入口都把岛拉回最前。
4. 改 `docs/design/island.md` 里「常见 IDE 默认不用这个键」的判断，更新 `contracts.md`。

## 验收

- 新装、从 0.3.11 升级后，浮屿不再占用 `Ctrl+Alt+B`
- 在设置里设了键的，按下后岛上先出现提示再退下去，再按一次马上回到最前
- 岛在下层时托盘卡片看得出来，点一下回到最前
- Windows 真机测不了的留实测清单
