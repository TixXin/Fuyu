## 说明

[C114](/docs/tasks/C/C114.md) 第一波子任务（Rust 原生日历侧，详见 [todos-and-calendar-expansion.md](/docs/research/todos-and-calendar-expansion.md) 第五节）：升级 `src-tauri/src/calendar/` 的链接提取、iCalendar 属性解析与 CalDAV 子日历元数据保留。

1. **扩充视频会议链接识别（[meeting_link.rs](/src-tauri/src/calendar/meeting_link.rs)）**：
   - 在既有 9 类规则基础上补齐高频漏网链接：腾讯会议短链 `meeting.tencent.com/s/` 与 `wemeet.tencent.com/`、企业微信会议 `meeting.wecom.work/` 与 `work.weixin.qq.com/webapp/tm/`、飞书/Lark `meetings.feishu.cn/` / `meetings.larksuite.com/` / `applink.feishu.cn/client/vc/`、华为云会议 `meeting.huaweicloud.com/`、Zoom 个人会议室与分享链 `zoom.us/my/` / `zoom.us/s/` / `zoom.com.cn/my/` / `zoom.com.cn/s/`、Jitsi Meet `meet.jit.si/`。
   - 严格保持仅匹配 `https://` 且要求有效路径段，避免将产品首页误判为入会链接。
2. **解析日程参与状态与忙闲透明度（[ics.rs](/src-tauri/src/calendar/ics.rs)）**：
   - `CalendarEvent` 新增带默认序列化的布尔字段 `declined: bool` 与 `free: bool`（同步派生测试态 `ts_rs::TS`）。
   - 解析 `TRANSP:TRANSPARENT` 标记 `free = true`；解析 `ATTENDEE` 参数中的 `PARTSTAT=DECLINED`（当传入当前账号标识/邮箱匹配对应参会人，或单参会人邀请已拒绝时标记 `declined = true`）。
3. **保留 CalDAV 子日历真实名称（[caldav.rs](/src-tauri/src/calendar/caldav.rs)、[mod.rs](/src-tauri/src/calendar/mod.rs)）**：
   - 在 `PROPFIND` 发现子日历集合时解析 `<D:displayname>`；事件合并时优先保留有意义的子日历显示名（为空时回退 `source.name`），不再把账号下所有子日历事件一律覆写为顶层 `source.name`。
4. **类型生成与双平台验证**：运行 `node scripts/plugins-v3/gen-rust-types.mjs` 同步生成类型，补齐 `ics/tests.rs`、`meeting_link.rs`、`caldav_tests.rs` 单元测试，通过本机测试、clippy、Windows 交叉 clippy 与 `pnpm mq:try --wait` Windows CI。
