## 说明

用户 2026-11-12 要求做安装后的设置引导，并且要单独的窗口。说明见 [新手引导](/docs/features/onboarding.md)。

## 验收

- 新装第一次启动时，岛出现后打开引导窗口；升级上来的用户不打开
- 四步：欢迎（语言、外观）、功能开关、用法（展开方式、贴边、Win+V、开机启动）、完成（去设置的入口）
- 每一项改了马上生效，跳过或关掉窗口时已选的保留
- 设置 → 关于里能再打开
- 中英文、深色浅色都不溢出
