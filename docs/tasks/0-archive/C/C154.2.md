## 说明

设置 → 外观 → 位置与尺寸 →「吸附到」加「任务栏」（只在 Windows 11 显示）：
- `Edge` 加 `Taskbar`，前端 `IslandDockEdge` 加 `"taskbar"`；旧版本读到新值要退回默认（对外契约，写进 contracts.md）
- 折叠的岛贴合任务栏高度，放进 C154.1 算出的空白区域；空间不够先缩窄，再不够退回底边吸附并提示
- 展开向上开，复用底边吸附的舞台定位
- 位置示意图画出任务栏里的岛；中英文文案；设置搜索索引

## 验收

- 选「任务栏」后岛在任务栏空白处，点任务栏不会盖住岛，岛不抢焦点
- 展开 / 收起、拖走后吸附回别的边都正常
- 自动隐藏、全屏、Explorer 重启、换显示器后岛位置正确
- Win10 / macOS 不显示这个选项；platforms.md 更新

调研见 [windows-taskbar-embedding.md](/docs/research/windows-taskbar-embedding.md)。

## 备注

- 展开时舞台不动（往上挪会让悬停展开在任务栏内外来回跳），展开时岛提到其他任务栏组件之上。
- 用户 2026-11-20 定的后续：任务栏专用透明外观（C154.4）、左侧拖动线条和虚线框（C154.5）、任务栏那条不动、面板在上方弹出（C154.6）。
- 实测清单（本机只有一块屏、任务栏靠左）：自动隐藏、全屏、居中任务栏、副屏、任务栏放不下时退回底边并在设置里显示提示。
