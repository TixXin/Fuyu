## 说明

跨设备同步（调研见 [cross-device-sync.md](/docs/research/cross-device-sync.md)）加 WebDAV 方式，和同步文件夹共用同一个引擎。用户群最早要的就是这个。

- 用已有的 reqwest 实现 PROPFIND（Depth: 1）/ GET / PUT / DELETE / MKCOL
- 坚果云：750 条分页、`Accept-Encoding: identity`、ETag 不带引号（群晖要带，两种都兼容）、LOCK 403 不用锁、503 退避；请求预算 600 次 / 30 分钟，防抖推送 + 定时拉取
- 地址、用户名存设置，应用密码进凭据管理器 / 钥匙串，不同步
- 设置页加 WebDAV 表单和「测试连接」，帮助里写坚果云应用密码、Nextcloud、群晖的设置方法

## 验收

- 用真坚果云账号和 Nextcloud（或群晖）各测一遍两台设备同步
- 断网、密码错、超频率时的提示
