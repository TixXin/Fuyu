## 说明

在日历页选中的那天下面加一个输入行：今天直接加进今天的列表，以后的日期调用现有的 scheduleTodo；计划好的待办也显示在日历上，和 ICS 事件区分。不写回 ICS/CalDAV。见 issue #43。

## 验收

- 选中今天或以后的日期能加待办，过去的日期没有输入行
- 日历上能看到计划的待办；到那天进入当天待办列表
- 和待办页「即将到来」用同一份数据
