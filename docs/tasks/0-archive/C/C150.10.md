## 说明

现在发给 Agent 只是切到会话终端、贴 PNG 路径。改成发之前可以在卡片上写一句话（例如「这个按钮没对齐，修一下」），和路径一起贴；同时附上截图来源：截图开始时前台窗口的进程名、窗口标题，浏览器里能取到的话加网址。来源默认附上，设置里能关。截图会话开始时记下来源，后面 C150.12 的插件动作上下文也用它。

## 验收

- 卡片上能输入一句话再发，回车发送；不写也能直接发
- Claude Code、Codex 里看到的是指令、来源和图片路径
- 来源取不到时只发路径；中英文文案
- `pnpm check`、`pnpm build`、`cargo test`、`pnpm build:exe`；截图卡片回归页更新

## 提交

- `feat(screenshot): send a note and where the shot came from to the agent`

## 备注

- 来源在 `screenshot/source.rs`（整理、等待最多 600 ms），各平台读前台窗口在 `screenshot/front_window.rs`、`front_window_macos.rs`，Windows 读地址栏在 `win32/browser_url.rs`；`session.rs` 只加了一行 `super::source::remember()`。
- 卡片：点「发给 Agent」先出一行输入框，回车发送（空着也行）、Esc 收起；贴的文字是指令、「来源：应用 — 标题」、网址、带引号的路径；没有指令也没有来源时和原来一样只贴路径。
- 设置 → 截图 加了「发给 Agent 时附上来源」（`agentSource`，默认开）。
- 验证时别的会话正在改的 `lyrics/mod.rs` 让 Rust 测试编译不过，Rust 测试在那边能编译后补跑；Mac 和 Windows 交叉 clippy（含测试代码）都过了。
- 实测清单（要真岛和 Agent 会话）：1) Mac：在 Safari 里按截图快捷键，发给 Claude Code，终端里看到指令、「来源：Safari — 标题」、网址和路径；Chrome 多半只有标题；没给辅助功能授权时只有应用名；2) Windows：Chrome、Edge、Firefox 里截图，地址栏网址能带上；3) 从岛上按钮或托盘开始截图时不带来源（前台是浮屿）；4) Codex 里同样能收到；5) 关掉设置后只发指令和路径。
