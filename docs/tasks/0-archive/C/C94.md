## 说明

跨设备同步（调研见 [cross-device-sync.md](/docs/research/cross-device-sync.md)）的端到端加密，用户定：可选、默认关，打开时明确提醒「忘了口令数据就找不回来」。

- 口令经 Argon2id（64 MiB、3 轮）派生密钥，包住随机数据密钥，放进 `meta.json`；改口令只需重新包一次
- 数据 XChaCha20-Poly1305，AAD 绑定远端路径和格式版本
- 解开的数据密钥存钥匙串，口令不存；密钥校验值用来提示口令错误
- 导出恢复密钥；重置远端（用还留着密钥的这台重新上传）

## 验收

- 加解密、口令错误、改口令、恢复密钥的单元测试
- 开关加密时远端整体迁移不丢数据
