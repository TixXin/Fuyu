## 说明

参考 eIsland（调研见 docs/research/eisland.md）：第一句歌词开始之前，收起的岛和音乐页显示歌名或一个音符，而不是提前把第一句亮出来。我们现在前奏时收起的岛显示待办，加一个选项。

## 验收

- 前奏时可选显示歌名、音符或待办（现在的行为）
- 第一句开始时平滑切到歌词
- 回归页覆盖前奏状态
