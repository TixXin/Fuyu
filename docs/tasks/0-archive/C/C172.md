## 说明

Fuyu 面板编辑时拖着组件换页不方便（issue #1195）。照预览页 [panel-drag-paging-preview.html](/docs/investigations/panel-drag-paging-preview.html) 做进岛里：拖动时滚动补偿、编辑态分页和分隔线、贴边停留翻页（圆环、甩动、探出、新的一页）、页头页码点长成缩略图（真刘海时在组件栏）、停在缩略图上跳页、在缩略图上松手送过去（「去看看 · 撤销」）、被挤走的标橙、「全部」总览（停留或空格）、暂存架、← / → / 数字 / Esc、提示行。设计记录在 docs/design/island.md「跨页拖动」。

## 验收

- 网格模式拖组件到左右边停一下会翻页，最后一页再往右多出新的一页，松手后那一页留着。
- 拖起来时页头的点变成缩略图；停在缩略图上跳页，在缩略图上松手组件去那一页、当前页不动，组件栏能「去看看」和「撤销」。
- 「全部」和空格打开所有页，指到哪放哪。
- 暂存架能放能取，退出编辑时架上的回到面板。
- Esc 取消这次拖动；← / → / 数字翻页。
- 旧版本存的布局照常显示；`pageBreak` 写进 contracts.md。
