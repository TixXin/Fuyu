## 说明

收起条上的通知（`CollapsedMessageContent.css`）现在是单行省略，长的微信、QQ 消息读不全。上游 fly-island 的 fbbcb22c、e3b04ba5：按实际排版量是否被截断，先加宽，到上限后换行并可滚动，鼠标停在岛上时通知不消失。原生侧要同步点击区域的尺寸。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

## 验收

- 短消息外观不变
- 长消息先加宽，到上限后换行，超出部分可以滚动
- 鼠标停在岛上时通知不自动消失
- 回归页覆盖短、长、超长三种消息
