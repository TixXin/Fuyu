## 备注

- 贴边隐藏页分三组：「隐藏后的样子」（实时预览、露出样式缩略图条、贴边隐身时的隐身记号条、记号颜色色块、记号呼吸）、「什么时候收起」（闲置隐藏、闲置多久、「这些时候不收起」四个胶囊、细调里只剩再次隐藏和等待）、「露出」（鼠标碰到隐藏的岛、新消息露出、最小化按钮放最后）。预览里的小岛只画外形不放字，露边 10px、细线 4px 照 Rust 的 `TUCKED_VISIBLE_*_HEIGHT`；「试一下」演指针碰顶边、岛滑出来（选了「展开面板」时变大）、按「再次隐藏前等待」收回去。记号呼吸只在指着预览、或刚改过记号的 8 秒里演，平时不循环。缩略图和预览的墙纸用浅一点的蓝，深色的岛才看得清。
- 行名缩短后旧名写进说明，设置搜索还能搜到：「隐身记号」的说明以「隐身提示」开头，「记号颜色」以「提示颜色」开头，「记号呼吸」以「提示呼吸」开头，「弹开的回弹」以「弹动幅度」开头；四个「不收起」的意思写进「这些时候不收起」的说明。
- 动效：曲线和悬停各一条缩略图条；缩略图只在指针或键盘焦点在那格上时演一次（`useThumbPointer` 在条外包一层、按 `data-thumb` 认指着哪格，因为共用组件把选中那格也算 live；贴边隐藏的两条也这样，记号呼吸只在指着那格时演），选中但没指着的停着；系统减少动态效果时不演。曲线缩略图用 `islandMotionVariables` / `islandMotionTiming` 的真参数开合一次；悬停缩略图用 `islandHoverShape` 和 `advanceHoverSpring`，模拟指针从下方靠近、碰到、离开。悬停原来的「把鼠标移到这里试试」框去掉了，缩略图代替。
- 「弹开的回弹」照方案只在曲线选「弹开」时显示；这个值同时管悬停「碰到弹一下」，曲线不是弹开时它照旧生效、只是没地方改，说明里写了。
- 设置键、取值、默认值都没改；`searchIndex.json` 没重生成（统筹会话最后统一跑），在那之前 `settings-search` 回归页挂是预期的。
