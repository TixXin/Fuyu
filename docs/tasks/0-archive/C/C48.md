## 验收

- 五幕都在迷你桌面的岛上看到效果：落岛动画、外观实时变化、身份和贴纸装功能、三个小任务亮星星
- 练习里的剪贴板快捷键是真的，按下后真的弹出剪贴板，引导里那颗星亮起
- 「开始使用」让窗口飞到真岛上并关闭，真岛显示「浮屿已就绪」
- 减少动画时没有动画，照样能走完；键盘能走完
- 中英文、深色浅色都不溢出
