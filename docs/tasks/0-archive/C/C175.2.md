## 说明

Fuyu 面板"日常"组的组件把内容写死了，改成能在组件里就地修改：

- 倒数日：自己填名称和日期（保留春节、元旦作为默认）
- 习惯：能改名，能增减（上限几项按尺寸）
- 世界时钟：能换城市
- 日出日落：按系统时区对应的城市取纬度，不再写死 31°
- 番茄钟：到点在岛上提醒；面板没开也按时结算
- 数据仍存在 `fuyu-daily-widgets`，老数据照常读取

## 验收

以上都能在组件上直接改、刷新后保留；老版本存下的数据不丢；番茄钟面板关着时到点也会提醒。
