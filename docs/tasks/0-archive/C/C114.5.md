## 说明

[C114](/docs/tasks/C/C114.md) 第二波子任务，对标 Things 3 Quick Entry 与 Dato / Notion Calendar 一键入会热键，补齐待办与日历的桌面全局键盘流入口：

1. **全局「快速添加待办」快捷键**：接入设置页与全局热键页（默认留空供用户按需绑定，提供推荐键提示）；按下后唤醒并展开悬浮岛切至待办页、聚焦输入框；通过热键唤起并回车添加后自动收起岛屿并归还先前前台窗口焦点。
2. **全局「一键加入当前会议」快捷键**：绑定后在存在当前倒计时或刚开场会议且含 `meetingLink` 时，无需展开岛屿即可一键打开会议链接（并遵循 `C114.3` 的入会自动暂停音乐设置）。
