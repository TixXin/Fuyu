## 说明

参考 eIsland 的链接识别和链接收藏：复制了链接时岛上弹一条（可关），一键收藏；收藏页能打开、拖动排序、删除，显示网站图标；可设黑名单和识别规则。可以作为剪贴板的一项功能，复用剪贴板已有的链接识别。

## 验收

- 复制链接后可选弹出收藏提示，黑名单里的网站不弹
- 有链接收藏页，支持打开、排序、删除
- 收藏数据有导入导出
