## 说明

用户群反馈希望加 WebDAV 同步，同步设置、待办、剪贴板等。之前「跨设备同步」（C24.10）没做。先调研再决定：除了 WebDAV 还有哪些方式（S3 兼容存储、GitHub Gist、局域网直连、自建服务、网盘目录等）；别的开源工具怎么做同步（剪贴板管理器、Joplin、Obsidian 插件等）；冲突合并、端到端加密、图片体积、凭据存放；第一版同步哪些。

## 结论（2026-11-15）

见 [cross-device-sync.md](/docs/research/cross-device-sync.md)。第一版做「同步文件夹」和 WebDAV（坚果云优先），远端每台设备只写自己的文件、按条用 HLC 后写者赢合并；同步待办、常用短语、链接书签和白名单内的设置与预设，凭据和剪贴板历史不同步；端到端加密可选、默认关；局域网先靠 Syncthing / NAS，直连以后单做。拆成 C91–C96（#435–#440）。
