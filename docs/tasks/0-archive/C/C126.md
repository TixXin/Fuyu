## 说明

游戏模式现在只在前端关掉悬停展开（`useGameMode.ts`、`useIslandHover.ts`），原生的点击区域没处理，全屏游戏里鼠标碰到屏幕顶沿仍会误点到岛。上游 fly-island 的 636a4d45 在原生侧让露边条在游戏模式下点穿，并处理焦点归还。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

## 验收

- 游戏模式下鼠标碰到岛的露边条不会唤出岛，点击穿透到游戏
- 退出游戏模式后恢复原来的行为
- Windows 真机实测，测不了的留实测清单
