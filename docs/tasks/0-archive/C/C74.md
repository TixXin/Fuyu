## 说明

参考 eIsland：从当前歌曲的封面取主色，给收起岛上的波形、歌词高亮和音乐页的光晕上色，可选。取色在前端做，换歌时渐变过渡；颜色太暗或太亮时调到在深浅色岛上都可读。

## 验收

- 音乐设置里有「跟随封面颜色」开关，默认关
- 深色、浅色岛上取出的颜色都可读（对比度检查通过）
- 没有封面时回到强调色
