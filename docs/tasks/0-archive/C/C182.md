## 说明

在顶部主岛之外新增屏幕左右侧独立入口（侧边翼 / Side Docks），支持 `fuyu-island-pages.placement` 页面分流、`fuyu-side-docks` 高度自定义设置（默认外框圆角 14px、二层抽屉自动展开）、Rust `side_dock` 独立悬浮窗口与外侧边防误触，以及设置页可视化拖拽编排台。方案见 [side-docks-plan.md](/docs/architecture/side-docks-plan.md)，交互预览见 [side-docks-preview.html](/docs/investigations/side-docks-preview.html)。

## 验收

- `fuyu-island-pages` 支持可选 `placement` 且向后兼容，禁用侧安全回退顶岛
- `fuyu-side-docks` 支持圆角/尺寸/自动展开/外观/多屏自定义并接入备份与同步白名单
- Rust `side_dock` 按需创建与定位 `side-left` / `side-right`，避开双屏拼接边并含单测
- 侧边翼窗口复用 `island.page/v1` 插槽，主岛自动分流隐藏移走页面并同侧互斥
- 设置 → 侧边翼独立一级菜单（带 NEW 徽章）提供空间拖拽分流、交互式显示器调把手与宽高、视觉选择卡与精细参数
