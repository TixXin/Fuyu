## 备注

- **「没设置」怎么判断**：`activeSyncBackend(status) === "off"`（没选文件夹、也没启用 WebDAV），和状态卡、加密组原来用的 `isSyncActive` 是同一个判断。`useSyncSettings` 加了 `loaded`：第一次拿到状态之前页面什么都不画，免得已经设好的人先闪一下引导。
- **引导**：第 1 步（同步方式）总是打勾，因为总有一个选中的方式；第 2 步总是当前步（描边，`aria-current="step"`），文件夹时是「选择文件夹…」，WebDAV 时步骤下面直接是原来的 WebDAV 表单（`SyncWebdavSection` 原样用）。第 2 步一做完页面就换成设好后的样子，所以第 3 步「要不要端到端加密」做成本页记住的意愿开关：打开的话，设好后加密那组直接展开「开启加密」的表单（`SyncEncryptionSection` 加了 `startOpen`），不另做第三步的流程，口令、恢复密钥和「找不回来」的提醒都还是加密组那一套。引导里看得到操作出错（`actionError`、`status.error`）；帮助组照常在下面。
- **设好后**：状态卡第一行之外加一行事实：上次同步 · N 台设备 · 文件夹或 WebDAV 地址 · 已加密 / 没加密；「立即同步」改成主按钮，旁边「更换…」展开原来的「同步方式」组（换文件夹、换 WebDAV、在文件夹中显示、停止同步都在里面），停止同步后回到引导。确认删除时「更换…」也在，方便按提示换目录。
- **格子**：每格是勾选框、名字、一行短说明（新文案 `categories.items.*.hint`，放不下省略）、状态徽标，完整说明在悬停提示（`title`）里；关着的格子也显示「已关闭」徽标（照预览）。出错时错误信息整行写在格子下面（`role="alert"`）。两列用 `minmax(max(220px, 50%), 1fr)`，容器窄到放不下两格 220px 时自动变一列。格子沿用 `settings-row` / `settings-row__title` / `settings-row__description` 的类名，设置搜索能收进索引、搜到后能定位高亮。组标题从「同步内容」改成「同步什么」（英文本来就是 What to sync）。
- **可选同步**：整组收进 `SettingsAdvanced`，折叠标题写「都没开（共 7 项）」/「已开 N 项（共 7 项）」，组标题「可选同步」和每行的说明不变。
- **没动的**：`toggleCategory`、`toggleOptionalGroup`、确认删除、WebDAV 保存、停止同步的调用和存储、Rust 侧都没动；`SYNC_SECURITY_SECTIONS` 的渲染从 `SyncBackendSection` 挪到页面里（加密组不再跟着「更换…」折起来）。
- **给统筹会话**：设置搜索索引由统筹会话统一重生成。`settingsMocks.ts` 里同步是没设置的状态，照现在的 mock 重生成，索引里只会有引导的三步，「同步什么」六格、可选同步七行、加密组都会掉出索引；要留住它们，`settings-search` 的 `on` 状态需要让 `get_sync_status` 返回一个设好的状态（比如 `backend: "folder"`、`folder` 有值），这个文件不在本任务范围里，没改。
