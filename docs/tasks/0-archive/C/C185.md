## 说明

响应群反馈 FB-8：
1. 日历对接内置国际节日与常见世界纪念日（含复活节、感恩节等浮动节日），支持中英文双语名称；中文界面下优先级低于中国传统节日/节气/国内纪念日，英文界面也可在月历与当日副标题显示，并在设置「日历面板」提供「显示国际节日」开关（默认开启）。
2. 扩展节假日订阅能力，支持一键订阅 13 个国家/地区官方 iCloud 节假日 `.ics`（中国大陆、香港、台湾、澳门、美国、英国、日本、韩国、新加坡、加拿大、澳大利亚、德国、法国），支持多地区共存与按地区准确识别已订阅状态。
