## 说明

岛上的消息页按来源分标签，空的时候只有一只企鹅和「暂无消息」。用户从预览页的六个方案里选了「全都要」：六种布局都做，用户可以换，默认「一次一条」，各处细节一起补。

## 验收

- 消息页有六种布局：一次一条（默认）、统一收件箱、三栏、按人叠卡、来源看板、时间轴；在消息页右上角的布局按钮和设置 → 消息里都能换，换完立刻生效、重启还在
- 所有来源合成一份按时间排的列表；聊天的「已读」只记在岛上并写明，邮件的已读是真的标已读；「全部已读」不会清空聊天提醒
- 一次一条：Enter / C / S / 空格四个键，进度算上这一轮看过的，读邮件返回后还在原来那张卡
- 验证码单独放大，「复制」只复制验证码
- 来源关着、缺权限、要重新授权、出错时，顶上一行说清楚并带按钮；全都看完显示「都看完了」
- 350px 窄面板下六种布局都不横向溢出，三栏变成列表和详情来回切；深浅色都能看
- 原来按来源分的页面（写邮件、切换邮箱、权限）从「⋯ → 详情与设置」还能进

## 备注

- 布局存在消息插件配置 `layout`（`plugins.yml`），不在 `fuyu-settings`：岛上的布局按钮和设置窗口都要写，插件配置两边都能写，备份也已经桥接；issue 里原先写的 `messageLayout` 进 `fuyu-settings` 作废
- 聊天来源只有「清空全部」，没有逐条已读，所以单条「已读」记在 `fuyu-message-handled`（最多 500 个，只留还在列表里的）
- 一次一条不再跟着上次打开的来源标签走，总从最新一条开始：跟着标签走时进度会显示「2 / 8」，看不懂
