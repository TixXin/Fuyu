## 说明

刘海模式（真刘海 `on` 和实验台模拟 `simulated`）下，给收起的岛（含刘海下面那一行）和展开的面板各加一条可选的外轮廓边框，照 [预览页](/docs/investigations/notch-border-preview.html)（f2b786175）做。

- 七种样式：关、发丝、辉光、环游、汇流、极光、下沿光；颜色（强调色、白、紫、粉、薄荷、自定义）、粗细 0.5–3px、强度、动效开关、跟随状态变色。
- 岛屿和面板分开设，面板有「同岛屿」。**默认全关**（样式关、跟随状态关），升级后看不出变化（用户定）。
- 设置在外观 → 显示的「刘海边框」组，在「刘海两侧最宽」下面，只在 Mac 或实验台模拟刘海时出现；组单独成块，C167 的「摄像头刘海内描边」可以挨着放。
- 跟随状态：新消息用来源软件的颜色亮，Agent 等你时橙色闪，完成时绿色扫一圈；样式是「关」时也亮。摄像头、麦克风归 C167 的内描边，边框不跟。

## 备注

- 外发光的地方：舞台窗口最小 820×460，展开时高度另加 24px、宽度至少是面板加两侧反向弧再加 4px（`src-tauri/src/island/geometry.rs` 的 `stage_width_for`）。收起时四周都够；展开时底下有 24px，面板拉到最宽时两侧只剩约 2px，外发光在两边会被窗口切掉一点。能接受，没改窗口大小。
