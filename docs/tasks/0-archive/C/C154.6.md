## 说明

吸附在任务栏时改展开方式：任务栏里那条岛原地不动、继续显示，完整面板单独出现在任务栏正上方。做法：拆成两个窗口（用户 2026-11-20 定）：
- 任务栏里只放一个和收起的岛一样大的小窗口（窗口所有者是任务栏），不再是 820 宽的透明舞台，和旁边的任务栏组件之间不再空一大截
- 展开时在任务栏上方另开面板窗口，显示岛的页面；收起时关掉或隐藏
- 新窗口 label 属于对外契约，写进 contracts.md、capabilities
- 开合动画重新做，按 docs/design/motion.md

## 验收

- 悬停 / 点击展开时任务栏里那条不动，面板从任务栏上方弹出，不卡、不来回跳
- 面板和任务栏组件不互相遮挡；任务栏里的岛和汽水音乐等组件紧挨着
- 自动隐藏、全屏、Explorer 重启、换显示器时面板和小窗口都正确

## 结论

方案用户 2026-11-21 定：占位窗口做法。

先写的「`main` 留在任务栏、另开 `island-panel` 网页窗口」做不成：岛的各页面读的是 `main` 里 runners 的内存状态（`mediaIsland`、`todoApi` 这类 runner store，里面有函数），传不到另一个网页；面板里再跑一份 runners 会让 Agent 钩子安装、`todos.changed`、快捷键、消息横幅这些副作用翻倍。所以改成：

- **任务栏里的占位窗口**：一个原生小窗口（`win32/taskbar_slot.rs`，不是网页，透明、鼠标穿透、不抢焦点），和收起的岛一样大，所有者是任务栏，由任务栏宿主每次刷新摆到槽位上；任务栏藏起、全屏、没位置时隐藏。我们自己的排位只把直接挂在任务栏上的窗口当障碍物，旁边的组件挨着的是它。
- **岛挂在占位窗口下面**：`main` 的所有者设成占位窗口，不再直接挂在任务栏上；被拥有的窗口一定在所有者上面，岛照样压在任务栏之上。没有新的网页窗口，也就没有新的窗口 label。
- **展开时收起条不动，面板在上方**：吸附任务栏、展开时，`main` 里收起的那条留在任务栏里，面板在同一个窗口里出现在任务栏正上方；舞台窗口展开时不挪、不改大小。命中测试按「收起条 + 面板 + 中间的空隙」算。
- 不吸附任务栏、或任务栏藏起来退回底边时，照旧原地展开。

拆窗口时保留拖岛的路径（e4605e2d6）：`drag_island` 拖起时调 `taskbar::lift` 解除挂靠，用 `taskbar::TaskbarDrop` 判断能否放回任务栏，落点由 `taskbar_host::drop_at`（`preview.rs`）算，辅助线窗口的虚线框模式会把自己和岛提到任务栏上面。任务栏里的小窗口拖动也要走这条路。
