## 说明

现在截图走 GDI `BitBlt`，独占全屏的游戏和部分硬件加速画面会截成黑屏（screenshot-plan.md「风险」里记过）。录屏已经有一套 Windows Graphics Capture 管线（`src-tauri/src/recording/`），截图在检测到前台是全屏独占窗口、或 GDI 截出的画面整块纯黑时，改用 WGC 取一帧显示器画面。

## 验收

- 全屏独占的游戏（或 D3D 全屏的测试程序）里按截图快捷键，冻结画面不是黑屏
- 普通桌面截图仍走原来的路，耗时不变
- Rust 单元测试覆盖「纯黑判断」和回退选择；`cargo test`、`pnpm build:exe`
