## 说明

新做一个独立的任务栏音乐组件，像汽水音乐的任务栏歌词条：封面、歌名 - 歌手、当前一句歌词（有逐字就逐字高亮），上一首 / 暂停 / 下一首。岛留在原位置，组件单独放在任务栏上。
- 新窗口（label 待定，例如 `taskbar-lyrics`，属于对外契约），用 C154.1 挂到任务栏空白处
- 数据复用岛的媒体状态和歌词（`src/features/media`），不另开轮询
- 设置 → 音乐 加「在任务栏显示歌词」开关和显示内容选项；不在播放时隐藏或只显示图标
- 岛也吸附在任务栏时两者排在一起，不重叠
- 点组件打开岛的音乐页

## 验收

- 开关打开后播放时任务栏出现组件，歌词跟着走，按钮能控制播放
- 和任务栏图标、托盘区、吸附到任务栏的岛不重叠
- 自动隐藏、全屏、Explorer 重启后正常；中英文文案、深浅色都对
- Win10 / macOS 不显示；platforms.md 更新

调研见 [windows-taskbar-embedding.md](/docs/research/windows-taskbar-embedding.md)。
