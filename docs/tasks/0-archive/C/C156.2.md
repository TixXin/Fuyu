## 说明

「岛屿布局」加「展开页面」一节：列出全部页面（内置、插件、以后的自定义面板），能排序、隐藏。隐藏只是不在顶部页面栏出现，不关功能，功能照常在后台跑。新 key `fuyu-island-pages`（`{ version: 1, order, hidden }`），没有这个 key 时是现在的顺序。

方案 [island-layout-plan.md](/docs/investigations/island-layout-plan.md)，预览 [island-layout-preview.html](/docs/investigations/island-layout-preview.html)。

- 隐藏的页面不出现，功能不停
