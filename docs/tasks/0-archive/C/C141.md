## 说明

用户 2026-11-19 定：本机接口在设置里单独开一页。

现状：它是「通用」页顶部的第四个标签（页名 `generalApi`），内容是 `src/features/local-api/LocalApiSettings.tsx` 的一组：地址、访问令牌、允许修改、重新生成令牌。接下来本机接口要加弹消息（C142）和更多能力，开关和来源列表在一个标签里放不下。

做法（除「单独一页」外都是 Agent 推断，做的时候写进 `docs/design/settings.md` 并标明）：

- **侧栏**：「扩展」组里、「插件」「插件市场」下面加一项「本机接口」。这一项一直在，不随内置插件 `local-api` 开关隐藏：用户 2026-11-19 看了开发版后定，菜单项和接口的开关是分开的（第一版做成关着时不列，已改）。接口关着时页面上只有一张带开关的卡片。
- **页名不变**：继续用 `generalApi`，只是从「通用」的标签升成侧栏的一项。岛上和旧链接、设置搜索、插件页里的「设置」入口照旧打开它；「通用」页去掉这个标签。
- **页面内容**，从上到下三组：
  1. 连接：地址、访问令牌（复制、重新生成），照搬现有的行。
  2. 权限：现有的「允许修改」；给 C142 的「允许弹消息」留位置。下面列出现在开放的能力（待办和笔记、AI Agent 状态、剪贴板历史），各自能不能用：对应的功能关着、或它自己的开关没开时写明原因，能点过去的给链接。
  3. 试一下：一段能直接复制的示例（Windows 给 PowerShell，Mac 给 curl），和文档链接。示例里不带令牌，读 `local-api.json`。
- 同一批改：中英文文案、`pnpm settings:index`、回归页 `settings` 和 `settings-feature-off`（连快照）、[local-api.md](/docs/features/local-api.md) 的「开启」步骤、`docs/design/settings.md`。

预计改动：`src/features/local-api/`、`src/features/plugin-kernel/settingsCategories.ts`、`src/windows/settings/GeneralSettingsPage.tsx`、`src/windows/settings/pluginDisplay.ts`、`src/i18n/sections/settings/localApi.ts`、`src/windows/settings/searchIndex.json`、`tests/regression/settings.tsx`、`tests/regression/settings-feature-off.tsx`。不动 Rust。

## 验收

- 侧栏「扩展」组有「本机接口」一项，接口关着时也在；「通用」页不再有这个标签
- 旧的 `generalApi` 链接、设置搜索、插件页的「设置」都打开新页
- 地址复制、令牌复制、重新生成令牌、允许修改和以前一样能用
- 能力列表在待办、AI Agent、剪贴板关着或没授权时显示对应的原因
- 中英文都有，窄窗口（580 宽）里不溢出
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过
