## 说明

用户群反馈：音乐播放器排序界面里删不掉已经不用的播放器。给列表里的每一项加删除，或自动清掉很久没出现过的播放器。

## 验收

- 排序页每一项可以删除，删掉的播放器再出现时重新加回
- 不影响现有的排序数据

## 提交

- `feat(media): any music source can be removed, unseen ones expire after 60 days`
