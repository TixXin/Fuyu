## 说明

`src/features/clipboard/ClipboardPopupPanels.css` 里 `.clipboard-editor__primary` 写的是 `background: rgb(var(--pop-accent))`。剪贴板窗口里 `--pop-accent` 本身就是完整的颜色，套上 `rgb()` 后不生效，所以文字编辑器的「改这条」主按钮几乎看不见，文本框描边也一样。C101.4 发现，只在图片编辑器里局部覆盖了。

## 验收

- 主按钮和文本框描边在剪贴板窗口、岛上、空格预览三处都正常，深色、浅色都对
- 同一个文件里别的 `rgb(var(--pop-accent))` 也查过
- `pnpm test:regression clipboard` 过，快照随提交带上

## 提交

- `fix(clipboard): use the accent colour as-is in the editor and panels (C101.6)`
