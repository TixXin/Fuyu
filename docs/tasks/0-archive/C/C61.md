## 说明

待办输入框右侧的日期按钮原来用系统的 `<input type="date">`：Mac 上是白底卡片，弹到桌面中间偏右离按钮很远，过去的日子和非本月的日子同一种浅灰，翻月只有三个小图标。改成岛里自己画的月历：跟着岛的底色和浅色岛，放在岛的范围里贴着按钮；今天、选中、过去、非本月各有样式；键盘能选；底部快捷项今天 / 明天 / 下周一。约定写在 `docs/design/todos.md`「日期选择的月历」。

## 验收

- 深色岛和浅色岛下月历都和岛一个风格，Mac 和 Windows 上都贴着按钮、不出岛。
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过，回归页 `todo-date-picker` 覆盖定位、样式区分、键盘和快捷项。
