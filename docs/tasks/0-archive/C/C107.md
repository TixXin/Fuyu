## 说明

针对 #740 反馈「小众音乐软件不会上岛，现在用的是飞牛音乐桌面版」：

1. **WASAPI 进程级音频会话识别**：在 `src-tauri/src/win32/audio.rs` 增加 `IAudioSessionManager2` / `IAudioSessionEnumerator` / `IAudioSessionControl2` 枚举，识别当前正在发声或处于活动音频会话的进程（跳过系统音效、浮屿自身及已有 SMTC 会话的进程，并支持 WebView2 / Electron 子进程回溯主进程）。
2. **窗口标题曲目解析与国内外播放器适配**：内置飞牛音乐桌面版（`xtMusic`、`fnmusic`、`feiniu`、`飞牛音乐`）及国内外主流与小众音乐播放器（音流 Stream Music、Feishin、Supersonic、Sonixd、Plexamp、Navidrome、Roon、Audirvana、foobar2000、MusicBee、AIMP、Winamp、WACUP、Dopamine、洛雪音乐 LX Music、YesPlayMusic、MusicFree、Listen 1、汽水音乐、千千音乐、咪咕音乐、波点音乐、椒盐音乐、方格音乐、Cider、Spotube、Nuclear、Qobuz 等）的识别规则；对无 SMTC 会话（或 SMTC 缺少歌手字段）的播放器，从主窗口标题拆出「歌名 - 歌手」，驱动现有的在线歌词查找、无进度轴自计时与多媒体键控制。
3. **修复后台暂停 SMTC 会话压制音频波形**：当选中的 SMTC 会话处于暂停且无其他播放器发声时才抑制峰值，若无 SMTC 的音乐进程正在发声，优先切到该音乐进程上岛。
4. **设置页支持手动添加音乐软件**：在「设置 → 音乐 → 来源优先级」支持从正在运行的程序中选择或输入 `.exe` 名称添加自定义音乐软件，任何冷门或自制播放器都能直接上岛。

## 验收

- 飞牛音乐桌面版及内置名单中的国内外无 SMTC 播放器播放音乐时可自动识别上岛，从窗口标题解析歌名与歌手并显示波形与歌词
- 后台存在暂停的浏览器或其他 SMTC 会话时，不会吞掉正在发声的无 SMTC 音乐软件
- 设置 → 音乐 → 来源优先级支持手动添加和移除自定义播放器进程
- Rust 单元测试、Windows 交叉 clippy 与前端 `pnpm check` 通过
