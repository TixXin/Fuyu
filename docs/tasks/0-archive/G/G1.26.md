## 说明

更新在下载或安装阶段出错时（例如 `updater_install` 返回 `failed to unpack ...`），设置 → 关于页的状态标题和顶部小岛都写「检查更新失败」。G1.25（#423）端到端测试时发现。

做法：`UpdateSnapshot` 加 `errorKind`（`check` / `install` / `null`），`fail(error, check)` 写入，开始检查、下载、安装时清掉；前端 `UpdatePanel` 和 `AboutHero` 按它选「检查更新失败」或「安装更新失败」，安装失败时按钮写「重新检查」（待装的更新已被取走，要重新检查再下载）。字段缺失按检查失败处理。

## 验收

- 安装失败时关于页标题和小岛写「安装更新失败」，按钮「重新检查」；检查失败仍写「检查更新失败」、按钮「重试」；中英文都有。
- Rust 单元测试、`pnpm check`、`pnpm build`、`pnpm test:regression update` 通过。
