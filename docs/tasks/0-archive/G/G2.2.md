## 说明

[G2](/docs/tasks/G/G2.md) 子任务 2，修复 macOS 主岛显示路径抢走全屏焦点的问题，补充 Rust 侧启动兜底显示，并彻底消除主岛与托盘显隐状态同步竞态：

1. **平台化 `island::show_island`（[mod.rs](/src-tauri/src/island/mod.rs)、[focus.rs](/src-tauri/src/island/focus.rs)、[focus_macos.rs](/src-tauri/src/island/focus_macos.rs)、[focus_unsupported.rs](/src-tauri/src/island/focus_unsupported.rs)）**：
   - `island::show_island` 不再在所有平台直接调 `window.show()` + `window.set_focus()`（macOS 上 `tao` 的 `set_focus` 会调 `[NSApp activateIgnoringOtherApps: YES]` 踢走全屏应用焦点）；
   - Windows 与 unsupported 在各自的 `focus` 模块保持 `window.show()` + `window.set_focus()`；macOS 在 [focus_macos.rs](/src-tauri/src/island/focus_macos.rs) 中改走主线程 `island_panel::show_panel_without_key` + `island_panel::make_island_key`（不激活整个 `NSApp`，同时记录 `PREVIOUS_APP` 以便失焦归还）。
2. **主岛启动超时兜底显示（[mod.rs](/src-tauri/src/island/mod.rs)、[watch.rs](/src-tauri/src/island/watch.rs)）**：
   - 维护用户主动隐藏标记（`hide_island` 置 `true`，`show_island` / `show_island_without_focus` 置 `false`）；
   - 在已有的 `island-watch` 线程（不新建额外常驻线程）增加一次性启动兜底截止时间（开发构建 6s、正式构建 3s）：到期若主岛仍不可见且未被用户主动隐藏，自动调用 `show_island_without_focus` 兜底显示，确保前端因重载或异常未走到 `show_ready_island` 时也不会启动即隐身。
3. **收口主岛与托盘显隐状态同步（[mod.rs](/src-tauri/src/island/mod.rs)、[tray.rs](/src-tauri/src/tray.rs)）**：
   - `minimize_island`、`show_ready_island`、`hide_island`、`show_island`、`show_island_without_focus` 均在主线程完成窗口显隐变更后同步触发 `tray::refresh_now`，并统一 `tray::toggle_island` / `tray::toggle_island_from_card` 的刷新时序，消除跨通道异步排队导致 `is_visible()` 读到旧值把托盘卡片或原生菜单状态刷回去的竞态。

## 验收

- macOS 上 `island::show_island` 通过 `island_panel` 显示并设为 key panel，不再调用 `window.set_focus()` 抢占前台应用激活态
- `island-watch` 包含一次性启动兜底显示截止时间，且用户主动隐藏后不会误触发兜底显示（纯调度/判断逻辑有单元测试覆盖）
- 从岛内最小化、启动首次显示、托盘卡片开关、原生托盘菜单各入口切换显隐后，托盘状态与菜单文案均在主线程显隐生效后一致刷新
- `pnpm heavy -- cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml`、`pnpm build:exe`、`pnpm check:size` 与 `pnpm check:tasks` 通过
