## 说明

录屏在 Mac 上还没开始，命令返回 `platform.unsupported`，设置里的录屏组和快捷键都不显示（platforms.md「录屏」）。按 Windows 的分法做：`SCStream` 按选区或整屏取帧，硬件 H.264 经 `AVAssetWriter` 写 MP4；系统声音用 `SCStream` 的音频输出，麦克风用 `AVAudioEngine`；GIF 复用 gifski 那一路；排除浮屿自己的窗口用 `SCContentFilter`。界面（倒计时、岛上的计时、暂停、停止）和 Windows 共用。

## 验收

- Mac 上 ⌃⇧6 能选区域或整屏录成 MP4，带系统声音，麦克风按设置；能出 GIF
- 默认不录进浮屿自己的窗口
- 设置里的录屏组和快捷键在 Mac 上显示；platforms.md 改对应行
- `cargo test`、`pnpm build:exe`；真机实测清单写进备注
