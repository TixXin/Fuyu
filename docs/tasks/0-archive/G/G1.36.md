## 说明

Mac 上放着歌时，浮屿自己一响提示音（Agent 的开始、完成、等你确认，计时器到点），系统的「正在播放」就被浮屿占走：来源变成 `com.apple.WebKit.GPU`、歌名是「Fuyu」，之后一段时间音乐页读不到歌名，换歌提示也不弹。E66.13 排查时发现，用户 2026-11-19 说建任务修。

原因：提示音在岛的 WebView 里用音频元素播放，WebKit 把会出声的音频元素登记成「正在播放」，不看长短。改成 Web Audio，放完后挂起音频上下文；音频上下文启动不了时退回音频元素。

## 验收

- Mac 上放着歌时响提示音，系统的「正在播放」仍是播放器
- 提示音照常能听到，音量设置照常生效
- Windows 上提示音照常（进实测清单）
