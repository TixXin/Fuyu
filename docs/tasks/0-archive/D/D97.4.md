## 说明

[D97](/docs/tasks/D/D97.md) 子任务 4，落实 [fuyu-performance-audit-v2.md](/docs/research/fuyu-performance-audit-v2.md) 中的 **P2-1（`audioPeak` 高频状态解耦）**、**P2-2（`islandContributions` 引用稳定化与 selector）** 与 **P2-3（高频指针/滚动事件 `rAF` 合帧）**：

1. **`audioPeak`（500ms）从 `MediaState` 顶层拆出为独立轻量订阅（P2-1）**：
   - [useAudioLevel.ts](/src/features/media/useAudioLevel.ts) 与 [runners.tsx](/src/features/media/plugin/runners.tsx) 将每 500ms 变化的音频峰值拆为独立外部 store，仅由折叠栏/音乐页实际渲染波形的组件订阅，避免每 0.5 秒刷穿 `MediaRunner`、歌词计算与整个音乐面板；展开音乐页显示歌词视图且无波形展示时暂停 `getAudioLevel` 轮询。
2. **`islandContributions` 子对象引用复用与 selector 支持（P2-2）**：
   - [islandContributions.ts](/src/features/plugin-kernel/islandContributions.ts) 在聚合时对键值未变的 `style.vars` 与各槽位数组复用旧引用，并在 [useIslandContributions.ts](/src/features/plugin-kernel/useIslandContributions.ts) 支持 selector 订阅，消除单点贡献变化引发全岛 18 处消费者连带重渲染。
3. **8 处高频 `pointermove` / `scroll` 补齐 `requestAnimationFrame` 合帧与布局缓存（P2-3）**：
   - 在 [ScreenshotOverlay.tsx](/src/windows/screenshot/ScreenshotOverlay.tsx)、[ClipboardImageEditor.tsx](/src/windows/clipboard/ClipboardImageEditor.tsx)、[usePopupPins.ts](/src/features/clipboard/usePopupPins.ts)、[IslandHoverCard.tsx](/src/components/IslandHoverCard.tsx)、[SettingsTabs.tsx](/src/windows/settings/SettingsTabs.tsx)、[useWallpaperBackdrop.ts](/src/windows/island/useWallpaperBackdrop.ts) 中，于拖拽/指针进入时缓存容器 `DOMRect` 并用 `requestAnimationFrame` 合帧坐标更新；
   - 在 [useVirtualRows.ts](/src/features/clipboard/useVirtualRows.ts) 中仅当可见起止行号 `(start, end)` 实际变化时才触发状态更新。

## 验收

- 音乐播放期间 `audioPeak` 更新不再引起 `MediaRunner` 与歌词组件重渲染
- 单个插件贡献变化时，无关字段的 `useIslandContributed` 订阅方不重渲染，并有单元测试覆盖引用稳定性
- 截图选区/标注拖拽、悬停光效与虚拟列表滚动均具备 `rAF` 合帧或行区间去重，拖拽移动中不逐帧调用 `getBoundingClientRect()`
- `pnpm check`、`pnpm build` 与 `pnpm test:regression` 通过
