## 说明

缩短非主岛副窗口的隐藏滞留时长，并补齐多屏全屏透明截图选区窗口的 60 秒空闲销毁机制，避免隐藏 WebView 进程长时间占内存。详见 [内存优化方案](/docs/architecture/memory-optimization-plan.md)。

## 验收

- 翻译与非预热剪贴板窗口空闲销毁缩至 3 分钟；托盘卡片与预览缩至 2 分钟内。
- 多屏 `screenshot-<n>` 选区窗口在截图结束后 60 秒自动销毁，新截图启动时可取消并按需重建。
- Rust 单元测试覆盖空闲回收状态与代际防竞态。
