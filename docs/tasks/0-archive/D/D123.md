## 说明

来源：微信用户群反馈 `FB-3` 与同用户 `FB-4`（Win11 25H2 下 WebView2 GPU 进程反复崩溃导致透明灵动岛不显示、打开设置约 3 秒变黑屏且重装无效）。补齐启动期 WARP 兼容软渲染（`--use-angle=warp`，保留透明窗口 DirectComposition 合成）、损坏 GPU 着色器缓存自清理、运行期多窗口 GPU 崩溃脉冲合并与 3 次连崩自动切换重启、原生托盘菜单兜底以及设置页「数据与诊断」控制入口。

## 验收

- `webview_gpu.rs` 在 `lib.rs` 创建 WebView2 之前读取 `<家目录>/webview-gpu.json`（及 `FUYU_GPU_MODE` / `--software-rendering` / `--gpu-mode=`），兼容模式下安全拼接 `--use-angle=warp`，带一次性清缓存标记时仅清理 `EBWebView` GPU 着色器缓存目录且保留 `Local Storage`。
- `webview_recovery.rs` 合并 1.5 秒内不同窗口的并发 `GPU_PROCESS_EXITED` 脉冲；硬件模式下 60 秒内 3 次独立 GPU 崩溃自动落盘切 `warp` 并安全重启一次，已在 `warp` 模式下不循环重启。
- GPU 不稳定时托盘点击与岛右键自动退回原生精简菜单；Windows 原生菜单补充「兼容渲染重启」兜底项。
- 设置 → 通用 → 数据页在 Windows 下展示兼容软渲染开关、自动切入原因提示与清理图形缓存并重启入口；更新 `data-storage.md`、`uninstall_cleanup.rs` 与设置索引，通过定向测试、回归页与双平台 clippy。
