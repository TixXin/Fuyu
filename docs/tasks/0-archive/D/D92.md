## 说明

在 `5713333f` 和 `4d00b60e` 将 `screenshot-N` 选区窗口改为截图结束直接 `destroy()` 并移除 `screenshot-ended` 事件后，前端 `useScreenshotFrame.ts` 原本在 `listenScreenshotEnded` 中清空 canvas 宽高和 GPU 纹理的逻辑不再被触发；同时长截图 `long.rs` 滚动循环在每次抓帧稳定与拼接时对整帧 RGBA `Vec<u8>` 做了多次冗余 `.clone()`。

## 验收

- `useScreenshotFrame.ts` 在 effect cleanup（组件卸载或会话切换）中清空 canvas 并将宽高置 0，不依赖已移除的 `screenshot-ended` 事件。
- `long.rs` 用布尔标志 `tried` 替代整帧 `Vec<u8>` 副本，并在画面稳定时直接将捕获的 `frame` 移入 `stitcher.push(frame)`，消除滚动拼接循环中的冗余深拷贝。
- `pnpm build` 与 `cargo test` 通过。
