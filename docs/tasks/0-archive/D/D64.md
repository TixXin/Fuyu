## 验收

- 新增 GitHub 能识别的行为准则文件，并写明社区参与者应遵守的基本规范。

- 新增无障碍说明文件，准确描述项目当前的无障碍支持与已知限制。
- 三个文件放在 GitHub 可识别的位置，仓库首页显示对应标签。
