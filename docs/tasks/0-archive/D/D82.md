## 说明

计划和排查结论见 docs/investigations/clipboard-winv-lag.md 的「设置窗口和托盘卡片打开也慢」一节里的 D82。设 FUYU_WINDOW_TRACE=1 时把各段耗时写进数据目录的 window-open-trace.log（格式在本任务里定，D83 照用）；关设置窗口改成隐藏、不销毁，真正退出的路径照常关；前端第一次渲染完就请求显示，兜底从 2 秒降到约 600 毫秒。用户定的：常驻可以，设置窗口不预建。

## 备注

日志格式（D83 照用）：

- 只在岛启动时设了 `FUYU_WINDOW_TRACE=1` 才写，写进数据目录的 `window-open-trace.log`，超过 256 KB 清空重写。
- 每次打开一行：`<时间> <窗口 label>#<n> <kind> <段>=<毫秒> … total=<毫秒> [via=<谁显示的>]`。各段是离上一段（第一段离请求打开）的毫秒数，一位小数；`<n>` 是这次运行里的序号，各窗口共用。
- 设置窗口：`settings#3 create built=412.3 ready=380.0 show=5.2 total=797.5 via=frontend`（`via` 是 `frontend` 或 `fallback`），隐藏后再开 `settings#4 reuse show=2.0 total=2.0`。
- 代码在 `src-tauri/src/settings_window/open_trace.rs`，`pub(crate)`：`WindowTrace::begin(label, kind)`、`mark(段)`、`finish(&app, via)`；没设环境变量时都是空操作。托盘卡片直接用它，`kind` 和段名自己定。
