## 说明

窗口里的界面出错时，给用户一个看得见、能恢复的兜底，并把错误记到数据目录里。岛上的插槽项各有错误边界，但窗口外壳和翻译、剪贴板、截图、贴图、托盘卡片、新手引导这些窗口没有：`src/main.tsx` 是唯一的根，任何一处渲染抛错都会卸掉整棵树，岛是透明窗口，于是整个不见；前端错误只打到控制台，正式版里看不到。

1. 窗口级错误边界：出错后先自动重载一次；一分钟内再出错显示兜底界面（岛上是收起条大小的提示加「重新加载」，其他窗口是卡片加「重新加载」「关闭」，拖岛辅助线窗口只记录不显示）。
2. 边界之外的错误（根上的未捕获错误、启动失败）走同一套判断。
3. 新命令 `report_frontend_error` 写数据目录的 `frontend-errors.log`（时间、版本、窗口、类型、截断的消息和调用栈，超过 64 KB 删前一半）：渲染错误、未捕获异常、未处理的 Promise 拒绝、被撤掉的插槽项；设置里的「崩溃日志」能定位到它。
4. 开发版仍等下一次代码改动再重载，只是也显示兜底界面。

## 验收

- 外壳渲染抛错：第一次自动重载；紧接着再出错显示兜底界面，按钮可用，中英文都有
- `frontend-errors.log` 按格式写入并封顶，卸载清理带上它
- 重载判断、错误摘要有单元测试；兜底界面有回归页；日志行格式有 Rust 单元测试
- `data-storage.md`、`contracts.md` 和两份 `AGENTS.md` 的目录说明同步更新
