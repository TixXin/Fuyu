## 备注

### 实现时和方案不一样的地方

- 快捷键页的「按键查询」仍是两个标签最上面的一行，没有挪到标签行右边；标签名后面没有数量和冲突红点。
- 位置示意图固定画一大一小两块屏幕（主显示器、另一块），不读真实的显示器数量：前端没有列出显示器的命令。
- 紧凑滑块行、内嵌子项块、键帽是改在共用组件里的，所以其它设置页（待办、音乐、AI Agent 等）的滑块、缩进行和快捷键录入也一起变了。
- 「最小化按钮」放在「贴边隐藏」组的最后一行，没有单独成组。
- 「样式预设」保留原名。
- 页内标签沿用外观页的做法：每个标签是一个页名（新增 `behaviorTuck`、`behaviorAlerts`、`shortcutsIsland`），`behavior`、`shortcuts` 仍能打开，各是第一个标签。
- 验收里没达到的：行为 › 贴边隐藏在「闲置时贴边隐藏」打开时约 1.25 屏；外观两个标签仍约 1.7 屏（预览占 150px，收起条项目列表长）。

### 方案

范围：通用、行为、外观、快捷键。四个问题都解决：页面太长分组太散、太平全是开关列表、控件和交互不顺手、设置项放错了页。

**不变的东西**：每个设置项的含义、默认值、`localStorage` key 和数据格式、页名（`general`、`behavior`、`theme`、`appearance`、`shortcuts`）、岛上和旧链接打开的页面。只动排版、控件和设置项放在哪一页。

#### 现状

1080 × 860 的窗口，一屏约 780px。

| 页面 | 分组数 | 页面高度 | 主要问题 |
|---|---|---|---|
| 通用 | 5 | 约 1.3 屏 | 位置、数据文件夹、备份各有一段长脚注；数据拆成两组 |
| 行为 | 8 | 1663px，两屏多 | 8 个组一路排下去；三个系统提示各占一组、每组只有一个开关；页面切换快捷键和快捷键页重复 |
| 外观 › 样式 | 5 | 1428px | 「调整哪一套」离它管的颜色组隔了一组；预设是长列表 |
| 外观 › 尺寸与内容 | 3 | 1325px | 5 个整行滑块占掉一屏 |
| 快捷键 | 8 + 查询 | 1597px | 能改的全局快捷键和不能改的岛上按键混在一起排 |

#### 四页共用的控件改动

1. **紧凑滑块行**：现在每个滑块占两行（标题一行、整行宽的滑块一行）。改成一行：左边标题，右边 180px 的滑块加数值胶囊，恢复默认的按钮还在数值旁边。时间滑块在 0 时写「立即」，不写「0 秒」。窗口窄于 720 时回到两行。
2. **子项放进内嵌块**：某个开关打开后才有用的几行，放进一个浅色的内嵌块（左边一条细线连到开关那一行），开关关掉时整块收起。现在只是左边多缩 20px，看不出从属关系。
3. **说明收短**：每行说明最多一行；组下面的长脚注只留第一句，其余收进「了解更多」，点开才显示。
4. **快捷键显示成键帽**：`⌃` `⇧` `F` 一个键一个小方块，代替现在带键盘图标的灰色胶囊。点键帽开始录入；恢复默认和清除在悬停时出现；冲突直接在这一行下面用红字写「和 XX 冲突」。
5. **带小图的选择卡**：两三个选项、而且选项有画面感的（展开方式、配色、外观模式）用它，其余仍用分段选择。
6. **页内标签**：行为页和快捷键页像外观页那样在标题下面分标签，每个标签不超过一屏。

#### 通用

```text

│ 登录时打开                           [开关] │
│ 界面语言                        简体中文 ⌄ │
└─────────────────────────────────────────────┘
┌ 位置 ───────────────────────────────────────┐
│ ┌───────────────┐  显示在        主显示器 ⌄│
│ │  ▭   ▭[岛]    │  菜单栏     压在菜单栏上 ⌄│
│ │  屏幕示意图   │  顶部距离     ──●── 0 px │
│ └───────────────┘  回到默认位置       复位  │
└─────────────────────────────────────────────┘
  按住 Option 拖动岛屿可以移动它。  了解更多
┌ 数据 ───────────────────────────────────────┐
│ 数据文件夹   ~/…/com.tixxin.fuyu   打开 更换│
│ 导出设置                             导出… │

```

- 「位置」组左边画一张屏幕示意图：有几块显示器画几块，岛画在选中的那块顶部；改「显示在」「顶部距离」时示意图跟着变。
- 「数据文件夹」和「备份与恢复」合成「数据」一组；两段长脚注各留一句。
- 「最小化按钮」（隐藏到托盘还是贴边）挪到行为页的「贴边隐藏」标签：它说的是岛怎么反应，不是应用级设置。
- macOS 上的「系统权限」组保持原样，排在「位置」后面。

#### 行为

8 个组分成 3 个标签，每个标签一屏以内。

```text
行为
 展开与收起    贴边隐藏    系统提示
 ──────────
┌ 展开方式 ───────────────────────────────────┐
│ ┌──────────────┐ ┌──────────────┐           │
│ │  点一下展开  │ │ 悬停就展开 ✓ │  ← 选择卡，带小岛示意
│ └──────────────┘ └──────────────┘           │
│ ┊ 悬停多久后展开              ──●── 立即   │  ← 内嵌子项块
│ ┊ 移开后多久收起              ──●── 立即   │
│ 悬停切换页面                         [开关] │
│ ┊ 悬停多久后切换              ──●── 立即   │
└─────────────────────────────────────────────┘
┌ 开合动画 ───────────────────────────────────┐
│ 曲线                      弹性（同官网） ⌄ │
│ [ 预览区，和现在一样 ]                   ▷ │
└─────────────────────────────────────────────┘
  页面切换快捷键 ›
```

- **展开与收起**：展开方式、两个延时、悬停切换页面、开合动画。
- **贴边隐藏**：
  - 「闲置时贴边隐藏」和它的 6 个子项；
  - 「露出」（鼠标移到隐藏的岛上、有新消息时露出）；
  - 「最小化按钮」（从通用挪来）；
  - 「全屏和游戏」组（游戏勿扰、游戏时贴边隐藏，原「游戏模式」）。
  - 标签顶部画一个贴在屏幕顶边、只露一条边的小岛。
- **系统提示**：音量与亮度、耳机与充电、摄像头和麦克风，现在是三个组、每组一个开关，合成一组「在小岛上提示」三行，每行前面一个图标。
- **页面切换快捷键**从行为页去掉，只留在快捷键页；「展开与收起」标签最下面留一行链接跳过去。

#### 外观

标签不变（样式、尺寸与内容、主题市场），顶部的岛屿预览不变。

**样式**（5 组变 4 组）

- 「配色」三个选项改成三张带小岛缩略图的选择卡：深色、浅色、跟随系统。
- 「调整哪一套」和「恢复这套的默认颜色」挪进「颜色」组的标题行，它管的就是下面这几个颜色。
- 「颜色」组的三个颜色（岛屿背景、任务字样、亮点）排成一行三个色块，下面一行亮点亮度。
- 「风格」和「圆角」合成「质感与形状」一组：外观模式、字体、不透明度、圆角样式、两个圆角滑块，滑块用紧凑行。
- 「样式预设」从列表行改成卡片，和主题市场的卡片一样带小岛缩略图，一行两到三张。

**尺寸与内容**

- 「尺寸」拆成「折叠岛屿」（大小、宽度）和「展开面板」（大小、宽度、高度）两个小组，用紧凑滑块行。
- 「显示内容」「收起条上的项目」不变。

#### 快捷键

```text
快捷键
 全局（7）    岛上（12）                 [ 按一组键，查是谁在用 ]
 ────────
┌ 翻译 ─────────────────────────── 设置页 › ┐
│ 打开快捷翻译                    ⌃ ⇧ F     │
│ 翻译选中文字                    ⌃ ⌥ T     │
└─────────────────────────────────────────────┘
┌ 剪贴板 … ┐   ┌ 截图 … ┐   ┌ 插件 … ┐
```

- 分两个标签：
  - **全局**：在任何程序里都能按、可以改。翻译、剪贴板、截图、插件。
  - **岛上**：鼠标在岛上或岛有焦点时才生效。页面切换、岛上操作、翻译输入框、审批卡片。
- 标签名后面带数量，有冲突时标签上一个红点。
- 「按键查询」从单独一张卡片改成标签行右边的一个输入框样子的按钮。
- 「岛上」标签里不能改的按键（岛上操作、翻译输入框、审批卡片）排成两列的速查表：左边动作、右边键帽，没有按钮的样子。能改的（页面切换的三个）仍是可录入的行，排在最上面。
- 功能关着的组（比如截图关着时）收成一行「截图已关闭 · 开启」，和现在一样。

#### 设置搜索

行为页和快捷键页分了标签后，搜索结果的路径变成「行为 › 贴边隐藏 › 分组 › 设置」，点了直接打开那个标签，和外观、AI Agent 现在的做法一样。挪了页的设置（最小化按钮、页面切换快捷键）搜索结果指向新位置。

#### 实现顺序

每一步一个提交，都能单独验证。

1. 共用控件：紧凑滑块行、内嵌子项块、键帽、选择卡、「了解更多」脚注
2. 行为页：标签、合并系统提示、挪走页面切换
3. 快捷键页：两个标签、速查表
4. 通用页：屏幕示意图、数据合并、最小化按钮挪走
5. 外观页：配色卡、颜色组、预设卡片、尺寸分组
6. `docs/design/settings.md`、搜索索引、回归页

#### 要你定的

#### 验收

- 1080 × 860 的窗口里：通用一屏放完；行为和快捷键每个标签不超过一屏；外观两个标签各不超过 1.5 屏。
- 每个设置改了以后存进去的值和现在一样；旧的页名和岛上的入口照常打开对应的页或标签。
- 580 宽的窗口里控件不溢出；浅色设置窗口对比度检查通过。
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过。
