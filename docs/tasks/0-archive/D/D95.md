## 说明

按照性能审查报告（[fuyu-performance-audit.md](/docs/research/fuyu-performance-audit.md) M6）与动效规范（[motion.md](/docs/design/motion.md)「文字不动位置」），将无文字组件的 `left` / `top` 定位过渡迁移到 GPU 合成层 `transform`：

1. [IslandGlass.css](/src/windows/island/IslandGlass.css) 的 `.island__glass-highlight`：由 `left: var(--glass-pointer-x)` + `transition: left` 改为 `left: 0` + `transform: translateX(calc(var(--glass-pointer-x) * 100 / 42 - 50%))` + `transition: transform`。
2. [TrayCardParts.css](/src/windows/tray-menu/TrayCardParts.css) 的 `.tray-card__knob`：主区与底部开关圆点由 `left: 16px` / `left: 14px` 与 `transition: left` 改为 `transform: translateX(14px)` / `translateX(12px)` 与 `transition: transform`。
3. [Spotlight.css](/src/windows/onboarding/Spotlight.css) 与 [Spotlight.tsx](/src/windows/onboarding/Spotlight.tsx) 的 `.onboarding-spotlight`：将 `left`、`top` 替换为 `--spot-x`、`--spot-y` 驱动的 `transform: translate3d(var(--spot-x, 0px), var(--spot-y, 0px), 0)` 与 `transition: transform`，保留 `width`、`height`、`border-radius` 以保持边框与圆角形态不变。

## 验收

- 3 处无文字组件在 `getComputedStyle` 中均以 `transform` 替代 `left` / `top` 过渡，且几何位置与开关视觉位置和修改前一致。
- `pnpm check:motion`、`pnpm lint`、`pnpm check:size`、`pnpm check:colors`、`pnpm check:tasks`、`pnpm test`、`pnpm vite build` 及 `liquid-glass`、`tray-menu`、`onboarding`、`onboarding-push` 回归测试全部通过。
