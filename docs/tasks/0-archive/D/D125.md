## 说明

Windows 11 真机剖析确认 `libmimalloc-sys 0.1.49` 内置的 `mimalloc v3.3.2` 在 ~89 线程的浮屿主进程中保留多个 64 MiB arena 且默认关闭 `page_commit_on_demand`，导致仅 ~18 MB 的真实 Rust 活跃内存被放大到 150–161 MB 私有提交。移除 `mimalloc` 全局分配器并回退到系统原生分配器（Windows NT LFH / macOS libmalloc）。

## 验收

- `src-tauri/src/main.rs`、`Cargo.toml`、`Cargo.lock` 不再依赖 `mimalloc`。
- Windows 11 真机实测 `fuyu.exe` 空闲私有内存从 150–161 MB 降至 22–24 MB（-85%），空配置从 89.8 MB 降至 18.8 MB（-79%），安装包体积减少 1.8 MB。
- 全量校验与 Windows/macOS CI 通过。
