## 说明

针对 #257（D49）排查 Rust 侧 `emit` 频率，消除状态未变化时的冗余事件广播：

1. **同步引擎（`src-tauri/src/sync/engine.rs`）**：`Engine::update` 仅在修改后的 `SyncStatus` 与当前值不等时才调用 `app.emit("sync-status-changed", ...)`；`notify_local_change()` 在 `SyncPhase::Off`（未配置同步目录）时不发送 `Wake::Changed` 唤醒同步线程。
2. **内置插件开关与配置（`src-tauri/src/plugin_kernel/builtins.rs`）**：`set_builtin_plugin_enabled` 与 `set_builtin_plugin_config` 仅在开关集合或配置值实际发生变化时才调用 `app.emit("plugins-v3:builtins-changed", &plugins)`。
3. **剪贴板链接书签（`src-tauri/src/clipboard_history/links.rs`）**：`update` 在闭包未改变 `ClipboardLinks`（`next == *state`）时直接返回，不重复写盘、不发 `clipboard-links-changed` 事件、不触发同步唤醒。

## 验收

- 上述三处在状态未改变时不再发送冗余 `emit` 事件。
- 事件名与负载结构保持不变，`cargo test` 与 `pnpm check:size` 通过。
