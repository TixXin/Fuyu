## 说明

issue #37：岛在副屏上贴边后一直出不来，点那条边、托盘「显示」都没用。在双屏上复现（2026-11-11）：用 Alt 拖过位置的岛贴边后，鼠标碰到顶边那条，岛滑回拖动时的高度（不是顶边），鼠标落在岛和顶边之间的缝里，岛于是收回、又被碰到、再滑出，弹几次后停在拖动处、窗口穿透鼠标。和是不是副屏无关；跟随鼠标换屏的路径正常。托盘「显示」只管窗口显示隐藏，贴边的岛窗口本来就可见，所以拉不出来。

改法（用户选 A）：原生端新增 `out_at_top`，岛从贴边出来时在顶边滑出、x 用拖动的位置，面板关掉回到收起、再贴边或再拖动时结束，回到拖动的高度（`geometry.rs` 的 `out_at_top_after`、`shown_custom_position`）。托盘「显示」遇到贴边的岛时发 `island-reveal-requested`，主窗口把它滑出来。
