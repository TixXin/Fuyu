## 说明

参考 eIsland 升级前的独立备份。安装更新前把应用数据（localStorage 导出、应用数据目录里的文件）备份一份并校验，保留最近几份；升级后数据读取出错时提示从备份恢复。

## 验收

- 每次安装更新前自动备份并校验，保留最近 3 份
- 设置里能看到备份并手动恢复
- 备份不含凭据管理器里的密码
