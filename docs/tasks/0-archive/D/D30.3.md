## 说明

做成什么样见 [家目录](/docs/features/data-home.md)。设置里改家目录和锁文件拆到 D30.4。

## 验收

- 新装的数据在 `~/.fuyu`；老用户升级后数据复制到 `~/.fuyu`，旧目录保留
- 装过的 Claude Code / Codex 钩子升级后指向家目录，Agent 状态照常
- 每日待办 Markdown 的默认目录换到 `~/.fuyu/todo`，旧的 `.md` 复制过去；自己选过的目录不动
- 已发布的 `fuyu-plugin` 还能连上本地接口
- lane 预览不受影响

## 提交

- `feat(data): keep the island's files in a home folder, ~/.fuyu by default`

## 备注

- 和最初的方案不同：钩子没有在命令里带 `FOCUSD_AGENT_STATUS_DIR`，而是让脚本默认用自己所在的文件夹（审批脚本本来就这样），配置里的命令格式不用变，重装一次钩子即可。
- 远程电脑（ssh）的钩子本来就用远程机器自己的 `~/.fuyu`，不受影响。
- 需要在真机上验证：一个有旧数据、装过钩子的岛升级后，`~/.fuyu` 里的数据齐全、Agent 状态正常、待办 Markdown 目录换过去。
