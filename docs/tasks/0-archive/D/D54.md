## 说明

用户反馈看不到各版本更新了什么。现在只有待安装的那个版本能看到更新说明，关于页加「版本历史」，能翻看已发布各版本的说明（读 GitHub Releases 或打包进去的 docs/releases/），跟随界面语言。

## 验收

- 离线时有合适的提示
