## 说明

扩展 `src-tauri/src/island/geometry.rs` 现有延迟收缩逻辑，让主岛在收起静默态将透明物理舞台从 `820×460` 收缩至安全紧凑包围盒，展开或需要大画布前瞬间扩回，大幅压低 GPU 显存/共享内存。详见 [内存优化方案](/docs/architecture/memory-optimization-plan.md)。

## 验收

- 收起态静默后物理舞台安全收缩，展开/拖拽/弹条/增长前瞬间扩回。
- 折叠态、展开态、贴边收起、刘海、底部与侧边停靠位置与点击穿透零偏移。
- Rust 单元测试覆盖全部几何与缩放边界。
