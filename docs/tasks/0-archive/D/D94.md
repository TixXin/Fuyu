## 说明

排查主岛液态玻璃合成开销（来源：[fuyu-performance-audit.md](/docs/research/fuyu-performance-audit.md) M2）：

1. 壁纸背板模式下 `IslandGlassWallpaper.css` 仅关闭了 `.editor-panel` 的 `backdrop-filter`，主壳 `.stage .island.island--appearance-liquidGlass[data-glass-wallpaper]` 仍在执行实时桌面模糊。
2. 刘海折叠态（`:root[data-island-notch] .island--collapsed`）已是纯黑 `#000` 背景且 `.island__glass` 透明度为 0，但主壳仍开启 `backdrop-filter`，且 `.island__glass::before`（`filter: blur(20px)`）和 `.island__glass-highlight` 仍在绘制。
3. 窗口隐藏（`document.hidden`）只附加 `island--glass-paused` 暂停关键帧动画，未关闭 `backdrop-filter` 和玻璃图层；贴边收起（`.island--tucked`）时 `.island__glass::before` 与 `.island__glass-highlight` 仍在绘制。
4. `IslandApp.css`、`IslandGlassLight.css`、`IslandGlassWallpaper.css` 中面向 `.island--appearance-liquidGlass ... .editor-panel` 的规则已无对应 DOM（`.editor-panel` 仅存在于设置窗口）。

## 验收

- 壁纸背板模式下主壳禁用 `backdrop-filter`，刘海折叠态禁用 `backdrop-filter` 并隐藏高光/光斑模糊图层。
- 窗口隐藏时 `glassClassNames` 附加 `island--glass-hidden`，禁用 `backdrop-filter` 并隐藏 `.island__glass`；贴边收起时隐藏 `.island__glass::before` 与 `.island__glass-highlight`。
- 移除主岛样式中失效的 `.island--appearance-liquidGlass ... .editor-panel` 死规则。
- `tests/unit/glass-palette.test.mjs` 补充测试，`pnpm check`、`pnpm build` 与 `pnpm test:regression` 通过。
