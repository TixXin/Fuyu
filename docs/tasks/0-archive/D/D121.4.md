## 说明

发版时 CI 上的 Windows 预构建 11 分钟、macOS 6 分钟，pnpm release 有 5 分多钟在等它。release 构建 workflow 加 Rust 编译缓存，Windows 降到 7 分钟以内。

## 备注

- 2026-11-22 不做：用户定不做：剩下的办法要花钱（更大的 runner）或让测试版和正式版编译方式不同（2026-11-22）

## 交接

- 2026-11-22 12:41 键盘大写提示发版：放回，实测：Windows 预构建 Build 一步 533–568 秒，其中前端 30 秒、打 NSIS+MSI 约 47 秒，其余约 8 分钟是编译浮屿自己这个 crate 加 thin LTO 链接；Rust 依赖缓存（Swatinem/rust-cache）已经有且命中。关掉 Defender 实时扫描后 539 秒，对照 533 秒，没有效果，已撤回。剩下的办法都要用户定：GitHub 付费的更大 Windows runner、release 改用 lld 链接（要验证产物）、或减少 thin LTO / codegen-units 的取舍（影响安装包大小和性能）。
