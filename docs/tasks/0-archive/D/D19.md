## 说明

PR #36 把贴顶圆角的半径取整到物理像素（`--island-device-pixel`），但这个值只在算 stage 样式时读一次 `devicePixelRatio`。岛拖到缩放比例不同的屏幕上后它停在旧值，缝可能又出来。现在 `useDevicePixelRatio` 监听 `(resolution: <dpr>dppx)` 的变化，stage 样式跟着更新。
