## 说明

源自 [fly-island-issue-76.md](/docs/research/fly-island-issue-76.md)（对应 6-5 主线程阻塞隐患与 6-1 预览窗长备注遗漏）。为避免与当前正在改剪贴板模块的会话冲突，本任务依赖 [D97.6](/docs/tasks/D/D97.6.md)、[D15b](/docs/tasks/D/D15b.md) 与 [D97.1](/docs/tasks/D/D97.1.md) 完成后执行：

1. **点击复制与粘贴命令彻底脱离 Win32 UI 主线程**：
   - [src-tauri/src/clipboard_history/mod.rs](/src-tauri/src/clipboard_history/mod.rs) 中的 `copy_clipboard_history_item` 与 `copy_clipboard_history_item_as` 目前仍是同步 `pub fn`，直接在 Win32 主消息循环线程上串行执行磁盘 PNG 解码、最多 `8 × 35ms = 280ms` 的 `OpenClipboard` 重试睡眠以及大 JSON 同步写盘；`paste_clipboard_history_item` 也未包 `spawn_blocking`。
   - 将上述命令全部改为 `async fn` 并使用 `tauri::async_runtime::spawn_blocking` 在阻塞线程池执行剪贴板读写与图片解码。
2. **历史 JSON 异步防抖落盘与紧凑序列化**：
   - 点击复制仅调整条目顺序时，在内存中更新状态并立即释放 `state.lock()` 返回快照，将磁盘写入交给后台防抖合并队列（并在退出或显式导入导出时立即刷盘），同时把 `serde_json::to_string_pretty` 换为紧凑序列化（读取完全兼容），消除系统刚从睡眠唤醒磁盘慢时持锁卡死主线程的路径。
3. **剪贴板预览区补齐完整备注显示与宽版分栏微调**：
   - 在 [ClipboardPopupPreview.tsx](/src/features/clipboard/ClipboardPopupPreview.tsx) 底部元数据区 `<dl className="clipboard-popup__pane-meta">` 中渲染非空的 `item.note` 正文（支持多行自动折行），解决列表单行截断后按空格打开大预览窗仍看不到完整长备注的问题；
   - 调整 [ClipboardPopup.css](/src/features/clipboard/ClipboardPopup.css) 宽版（640px）左侧列表宽度（现为固定 `330px`，比标准窄版 `380px` 更窄），保证切到宽版时列表备注可用宽度不退化。

## 验收

- `copy_clipboard_history_item`、`copy_clipboard_history_item_as`、`paste_clipboard_history_item` 均不在主线程或 Tokio 核心异步线程直接执行同步阻塞 I/O
- 历史记录高频更新按防抖合并异步写盘且退出时不丢最后一次变更，紧凑 JSON 与旧版历史文件双向兼容
- 空格预览窗口与独立剪贴板宽版右侧详情栏完整展示条目长备注，宽版左侧列表宽度不窄于标准版列表可视区
- `pnpm check`、`pnpm build`、相关回归页、`pnpm heavy -- cargo test --manifest-path src-tauri/Cargo.toml` 与 Windows CI 全部通过
