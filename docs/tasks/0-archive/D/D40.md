## 备注

### 实现时和方案不一样的地方

- 歌词预览原来就有（「岛上的歌词样式」组第一行，循环播放一句），没有新做，也没有固定在标签顶部。
- 功能页头下面的状态行只有剪贴板有（「按 … 打开」）；消息页头右边写已开几个来源。其它页没有做「已记录 128 条」这类统计。
- 功能关着时收起其余设置：原来多数页已经这样，这次补上了待办页，并在页头下面加了一句说明。
- 消息的三个来源仍是三组，不是独立的卡片：每组的开关行前面加了图标，开着时说明里写当前状态，长脚注收成「了解更多」。
- 剪贴板的弹出位置仍是分段选择，没有改成选择卡。
- 录屏的快捷键留在「截图」标签的快捷键组里，没有挪到「录屏」标签；Mac 上没有「录屏」标签。
- 待办的「待办清单保存路径」和文件中转没有改结构，只换了页头。
- 截图页在回归页的假数据里打不开（平台不支持），没有看过界面；消息页约 1.3 屏。

### 方案

范围：待办、日历、音乐、翻译、剪贴板、文件中转、截图、消息。沿用「基础」四页已经做好的控件（紧凑滑块、内嵌子项块、键帽、选择卡、「了解更多」脚注、页内标签）。

**不变的东西**：每个设置项的含义、默认值、存储 key 和格式；现有页名（`todos`、`music`、`clipboard` 等）和岛上、旧链接打开的页面。

#### 现状

1080 × 860 的窗口，一屏约 800px。

| 页面 | 分组 | 页面高度 | 主要问题 |
|---|---|---|---|
| 待办 | 4 | 一屏内 | 第一组没有标题，只有一个「启用待办」开关 |
| 日历 | 4 | 一屏内 | 「已添加的日历」和「添加日历」是两个组 |
| 音乐 | 5 | 1680px，两屏 | 歌词来源 7 行、歌词样式 8 行一路排下去，改样式看不到效果 |
| 翻译 | 5 | 934px | 打开位置、翻译方式各一两行，各占一组 |
| 剪贴板 | 7 | 2088px，两屏半 | 打开方式 8 行、历史 10 行，还有常用语、提示词、导入导出 |
| 文件中转 | 3 | 一屏内 | 同待办 |
| 截图 | 5 | 一屏多 | 截图和录屏的设置排在一页 |
| 消息 | 5 | 1017px | QQ、微信、邮箱三组各带一段很长的脚注；「添加邮箱」单独一组 |

八页共同的问题：每页第一组都是一个没有标题的卡片，里面只有「启用 XX」一个开关，看不出这页是干什么的。

#### 八页共用的改动

1. **功能页头**。代替现在那个没有标题的开关卡片：左边是功能图标（放在强调色的小方块里），中间是功能名和一句「它能做什么」，右边是总开关。开着时页头下面一行小字写当前状态，例如「已记录 128 条」「2 个邮箱」「快捷键 ⌃⇧V」；关着时页头变灰。消息页没有总开关，页头右边写「已开 2 个来源」。
2. **功能关着时收起其余设置**。只剩页头和一句「开启后可以在这里设置」，不再把一整页用不上的开关摆出来。数据保留的说明仍在。
3. **长页面分标签**（音乐、剪贴板、截图），每个标签一屏左右。做法和外观、行为一样：每个标签是一个页名，原来的页名打开第一个标签。
4. **有画面感的选项用选择卡**：消息的提示方式（一行预览 / 横幅 / 展开面板）、剪贴板的弹出位置（鼠标旁 / 屏幕中间）、翻译打开在（独立窗口 / 岛上）。
5. **长脚注收成「了解更多」**，子项用内嵌块，滑块用紧凑行。这些控件已经有了，主要是把还在用旧写法的地方换过去。

#### 各页

##### 待办

页头 + 三组，一屏内。

- 「任务」：四个开关不变，「多任务流动」的停留时间作为它的内嵌子项。
- 「项目」不变。
- 「待办清单保存路径」改名「保存」，路径和「保存」按钮排在一行，下面的说明收短。

##### 日历

页头 + 两组。

- 「小岛显示」不变。
- 「已添加的日历」和「添加日历」合成「日历」一组：上面是已添加的列表（没有时一行空状态），最下面一行「＋ 添加日历」，点了在原位展开选择类型和填写的表单，添加完收起。

##### 音乐（分三个标签）

- **岛上显示**：页头、在收起的岛上显示音乐波形、在收起的岛上显示当前歌词、同时有 Agent 在运行时、来源优先级。
- **歌词来源**：本地歌词文件夹、在线查找歌词（下面内嵌「也查酷狗和网易云」）、网易云精确同步、歌词提前或推后。
- **歌词样式**：标签顶部固定一条**歌词预览**，用当前设置画一句正在唱的歌词（逐字高亮、变亮方式、高亮颜色、没唱到的字、发光都反映在上面，自动循环播放）；下面是这 8 个样式设置。现在改样式要去放歌才看得到。

##### 翻译

页头 + 三组，一屏内。

- 「使用」：翻译打开在（选择卡）、打开时填入剪贴板、停稳后自动翻译（原「打开位置」「翻译方式」合并）。
- 「翻译服务」：服务、模型、API 密钥，不变。
- 「快捷键」：不变。

##### 剪贴板（分四个标签）

- **打开与粘贴**：页头、快捷键打开、弹出位置（选择卡）、窗口宽度、选中后自动粘贴、两个终端相关的开关、共享屏幕时隐藏、读取链接标题和图标，以及快捷键组。
- **记录什么**：记录图片（内嵌「识别图片里的文字」）、记录复制的文件、保留格式、不记录密码密钥、不记录这些程序复制的内容、允许本地接口读取、最大历史条数、自动清理。
- **常用语与提示词**：现在的「常用语」「AI 提示词」两组。
- **导入导出**：导出、导入。

##### 文件中转

页头 + 两组，不动结构，只换控件（最多保留条数用紧凑行，脚注收短）。

##### 截图（分两个标签）

- **截图**：页头、快捷键（含 PrintScreen）、截图时、截完之后。
- **录屏**：默认格式、帧率、画质、录系统声音、录麦克风，以及录屏的快捷键。

##### 消息

- 页头：没有总开关，右边写已开几个来源。
- 「新消息提示」：提示方式改成三张选择卡，每张画出岛上的样子（一行预览、岛下方的横幅、自动展开的面板）；面板停留时间是「展开面板」的内嵌子项；现在 124 字的脚注收成一句加「了解更多」。
- 来源改成三张**来源卡**（QQ、微信、邮箱），每张：品牌色图标、名字、一句状态（「正在接收」「需要辅助功能权限」「2 个邮箱，1 个要重新授权」）、开关；长说明收进「了解更多」。
- 邮箱卡开着时下面列出账号，最后一行是「＋ 添加邮箱」，点了在原位展开表单；不再有单独的「添加邮箱」组。

#### 实现顺序

每一步一个提交。

1. 功能页头组件，功能关着时收起其余设置（八页一起换）
2. 剪贴板（四个标签、弹出位置选择卡）
3. 音乐（三个标签、歌词预览）
4. 消息（提示方式选择卡、来源卡、添加邮箱收进卡片）
5. 翻译、截图、日历、待办、文件中转
6. `docs/design/settings.md`、搜索索引、回归页
