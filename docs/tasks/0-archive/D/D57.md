## 说明

参考 eIsland：它把安装包同时放在国内对象存储和 GitHub，更新弹窗显示当前更新源。我们的更新包、插件和 InfLink-rs 都只从 GitHub 下，国内用户下载慢或失败（见 D53）。加一个国内镜像源，下载失败时自动换源，签名校验不变。

## 验收

- 发布流程同时上传到国内镜像，latest.json 格式不变或兼容旧版
- 更新和插件下载先试主源，失败自动换镜像
- 关于页显示这次用的下载源

## 提交

- `feat(updater): fall back to GitHub mirrors for update and plugin downloads`

## 交接

- 2026-11-15 06:12 download-mirrors：实测清单（Mac 上测不了国内网络和 Windows 安装）：1) Windows、国内网络不开代理，设置 → 关于 → 检查更新 → 下载，面板显示「本次下载源」，装完版本正确；2) 屏蔽 github.com / objects.githubusercontent.com 后下载自动换到 ghfast.top 或 gh-proxy.com；3) 插件市场在国内网络下能刷出列表、装上一个插件。第一条验收（发布时上传国内镜像）这轮不做，见 D63（#419）。
