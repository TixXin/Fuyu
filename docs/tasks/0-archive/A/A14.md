## 说明

1. macOS 的 `window_focus.rs` 目前只调 `NSRunningApplication` 激活整个应用且候选标题为空字符串，同一编辑器或应用开多个项目窗口时无法挑出并置顶目标项目窗口，缺少进程链时也无法按标题/文件夹匹配。在已获 macOS「辅助功能」授权时，用 `AXUIElement` 读取候选应用的 `AXWindows` 与 `AXTitle`，复用 `window_of_process_chain → preferred_window → best_window` 评分管线选中并 `AXRaise` 目标窗口，未授权时静默回退为整应用激活。
2. `window_focus.rs` 的 `EDITORS` 补齐 `trae cn`、`zed` 与 JetBrains 系列编辑器；`AgentSessionRow.css` 和 `AgentSessionCard.css` 的 `<button>` 补上 `font: inherit`，消除独立回归页在 macOS 下按钮与外层容器 `"99m"` 字宽不一致的问题。

## 验收

- [x] macOS 已授辅助功能权限时，同一应用多项目窗口（及无进程链时按文件夹/标题匹配）能选中并置顶目标窗口；未授权时不弹窗、保持整应用激活回退
- [x] `EDITORS` 覆盖 `trae cn`、`zed` 与 JetBrains 系列编辑器并有单元测试覆盖
