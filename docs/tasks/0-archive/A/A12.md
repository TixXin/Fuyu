## 说明

岛屿面板点击 agent 会话时，部分宿主只能激活应用窗口，无法切到具体的 tab 或会话。已支持精准切换的：Orca、WezTerm、Windows Terminal（UIA）、macOS Terminal / iTerm2（AppleScript）、VS Code 系编辑器（URI + 浮屿扩展）。本任务逐步适配更多可适配的宿主。

### 可做（宿主提供了 API）

| 宿主 | 切换机制 | 备注 |
|---|---|---|
| Ghostty（macOS） | AppleScript `tell application "Ghostty"` 遍历 windows/tabs，按 TTY 选 tab | 和 Terminal/iTerm2 同一套路，`terminal_tabs.rs` 加一个分支 |
| Ghostty（Windows） | 待调研：Ghostty 2.0+ 是否暴露 Win32 tab 或 IPC | 目前 Windows 版较新，观察 |
| Alacritty + tmux/zellij | 检测 tmux/zellij 会话，`tmux select-window -t` 切 pane | Alacritty 自身无 tab，但终端复用器有 |
| Codex Desktop | 关注 deep link / IPC 更新 | 目前无 API，Codex 更新后接入 |
| Antigravity Desktop/IDE | 关注 `antigravity://` URI 是否支持 `?conversation=<id>` | 目前无 conversation 级 deep link |

### 受限（宿主不提供 API）

以下宿主目前无法从外部切到具体 tab/会话，需等上游支持：

- **Antigravity Desktop/IDE**：没有 conversation 级 deep link URI
- **Codex Desktop**：独立 Electron 应用，没有外部 IPC
- **Claude Code TUI**：一个实例就是一个 session，无需切；已能切到所在终端 tab

### 体验优化

当 `focus_agent_window` 只能聚焦到应用窗口但切不到具体会话时，在会话卡片上给出提示（tooltip 或小标记），让用户知道需要手动切换。
