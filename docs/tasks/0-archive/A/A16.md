## 说明

Windows 上 WorkBuddy 开着时，点它的会话或右键「跳到窗口」都提示「没有找到对应的窗口」（#862）。真机实测能跳的目前只有 Claude Code 和 Antigravity，WorkBuddy 的窗口匹配没测过。先查 WorkBuddy 的程序名、窗口类和进程链（`src-tauri/src/agent_status/focus.rs`、`window_focus.rs`），对照 A10 处理 Antigravity 改名的做法。做之前先加载 `fuyu-agent-harness` skill。

## 验收

- WorkBuddy 开着时，点会话或右键「跳到窗口」能把它切到前台
- 确实找不到时，提示说明原因（没开、最小化到托盘）
- `docs/architecture/platforms.md` 的 WorkBuddy 行写明跳转的实测情况；测不了的留实测清单
