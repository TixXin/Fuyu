## 说明

响应 `#745`，包含两部分：

1. **内置接入 `pi`（`@earendil-works/pi-coding-agent` 及桌面端 `PiDeck` / `PiCove`）**：
   - 会话列表：扫描 `~/.pi/agent/sessions/<编码目录>/<ISO>_<id>.jsonl`（支持 `PI_CODING_AGENT_DIR`），解析 `session` 头（`id`、`cwd`、`timestamp`）、`session_info`（自定义标题 `name`）、`model_change`、`thinking_level_change`、`compaction` 以及 `message`（用户提问、助手回复、`toolCall` / `toolResult`、token `usage`、回复状态标记），支持 SSH 远程镜像拉取。
   - 状态灯、等你与岛上审批：「安装/修复」在 `~/.pi/agent`（或 `PI_CODING_AGENT_DIR`）存在时写入 `~/.pi/agent/extensions/fuyu-island.js`，监听 `session_start`、`agent_start`、`agent_end`、`tool_call`、`session_shutdown`，驱动状态灯（`agent-pi-running.flag` / `agent-status.json`）、保存等你通知（`agent-notifications/pi-*.json`）并通过 `/pi/permission` 支持岛上审批（返回 `{ block: true, reason }` 或放行）。
   - 回复标记与窗口跳转：回复标记写 `~/.pi/agent/AGENTS.md`；点击会话支持跳到 `PiDeck` / `PiCove` 桌面窗口或对应终端。
2. **通用第三方 Agent 接入**：
   - 状态灯与脚本放开任意合法第三方 provider id（`[a-z][a-zA-Z0-9_-]{0,31}`）：`fuyu-agent-running`、`fuyu-agent-status`、`agent-<id>-running.flag` 及 `agent-status.json` 中的非内置字段自动归入 `snapshot.others` 驱动状态灯。
   - 通用第三方会话目录扫描：支持在 `<fuyu-home>/agent-third-party/`（或 `agent-status.json` / `thirdPartyAgents` 配置）下按 `<provider>/` 扫描 Claude / pi 兼容 JSONL 或会话描述 JSON，连同 `external.rs`（`PUT /v1/agent-status/{source}`）上报的第三方会话一起出现在 Agent 页会话列表中（带通用图标与自定义名称），无需修改浮屿源码即可对接新 Agent。

## 验收

- `pi`（id `pi`）接入 `HARNESSES` 与前端 `AGENTS`：会话列表、状态灯、扩展安装/修复、等你、岛上审批、回复标记、SSH 远程镜像、PiDeck/终端窗口跳转全部就绪并通过单测。
- 通用第三方 Agent 支持：向 `fuyu-agent-running` / `fuyu-agent-status` 或 `agent-status.json` 写入任意合法 provider id 可点亮状态灯；向 `<fuyu-home>/agent-third-party/<provider>/` 放入 JSONL / JSON 会话或通过 `PUT /v1/agent-status/{source}` 上报非远程会话可在 Agent 页会话列表中显示。
