## 说明

用户反馈：「这个会话环有 bug，关了后一会后又重新显示了」。Mac 开发版（DEV）。

- 设置 → AI Agent → 外观 →「用量与会话环」里把会话环关掉；过一会儿再看，开关又是开着的（样式「信号格」，「显示会话数」关），岛的收起条上又出现信号格。
- 用户没有手动再打开过。

先查开关状态被谁写回去：迁移、默认值重置、插件设置同步、AI Agent 插件重新加载时覆盖；以及会话环和 AI Agent 插件会话列表之间的联动。

## 验收

- 关掉会话环后，重开设置、重新加载插件、重启岛，开关都保持关闭，岛上不再出现会话环
- 有单测或回归页覆盖「关掉后不被写回」
