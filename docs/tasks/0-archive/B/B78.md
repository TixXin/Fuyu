## 说明

我们已经接了 Cursor 的会话，用量环还没有 Cursor 的额度。上游 fly-island 的 1e278b32（插件名叫 grok-bot，实际查的是 Cursor）摸通了取登录 Token 和带 checksum 请求头查额度的方法，可以对照。做之前先加载 `fuyu-agent-harness` skill。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

- 没装或没登录时不报错、不显示
- Windows 和 macOS 各实测一次，测不了的留实测清单
