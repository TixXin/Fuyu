## 说明

我们已经接了 Cursor 的会话，用量环还没有 Cursor 的额度。上游 fly-island 的 1e278b32（插件名叫 grok-bot，实际查的是 Cursor）摸通了取登录 Token 和带 checksum 请求头查额度的方法，可以对照。做之前先加载 `fuyu-agent-harness` skill。 来源见 [上游改动调研](/docs/research/upstream-recent-changes.md)。

## 验收

- 装了 Cursor 并登录时，用量环显示 Cursor 的额度
- 没装或没登录时不报错、不显示
- Windows 和 macOS 各实测一次，测不了的留实测清单

## 交接

- 2026-11-18 23:57 b78：实测清单（本机 Mac 用 Cursor 的登录调 GetCurrentPeriodUsage 回了 401，进一步看 Token 格式被权限拦下；Windows 没机器）：1) Mac：Cursor 开着并登录，设置 → AI Agent → 用量环勾上 Cursor，岛上出现粉色环，悬停显示 Cursor · <套餐> / 本月 N% · 重置时间；2) Mac：退出 Cursor 登录或删掉 Cursor 后环消失、不弹错；3) Windows 同 1)、2)（%APPDATA%\Cursor）；4) 接口回 401 时确认是 Token 过期（Cursor 开着会自己刷新）还是 Token 格式不对，必要时改 cursor.rs 的 clean_token
- 2026-11-19 b78：401 的原因找到了：新版 Cursor 在 macOS 上把 Token 存成 `cursor-safe-storage:v1:` 加 Safe Storage 密文。照 CodexBar 和 burnbar 的做法用钥匙串 `Cursor Safe Storage` 的密码解密，去掉 checksum（调研见 [cursor-usage-api.md](/docs/research/cursor-usage-api.md)）。本机 Mac 真接口回 200：Premium、本月 37.4%（被忽略的测试 `live_cursor_usage`，带 `--ignored` 跑）。实测清单剩：1) Mac 上在岛上看粉色环和悬停卡片，第一次会弹钥匙串授权；2) 退出登录后环消失；3) Windows 同上，看 Token 是明文还是加密的（加密的现在当没登录，不显示；解密另建 B86 / #1013）
