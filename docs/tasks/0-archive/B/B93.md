## 说明

全屏应用把岛收到边上（游戏模式「贴边」开、「勿扰」关）时，Agent 等你确认或出错，Windows 上改发一条系统通知（2026-11-23，命令 `agent_notify`，前端 `src/features/agent-status/useFullscreenAgentAlerts.ts`）。Mac 上还没有发系统通知的能力，全屏时这类提醒看不到。

## 验收

- Mac 上 `agent_notify` 用 `UNUserNotificationCenter` 发通知，第一次发时请求通知授权；开发版不是 .app 包时取不到通知中心，先判断，不能崩。
- 点通知打开岛的 Agent 页（发 `agent-notification-opened`，和 Windows 一样）。
- `docs/architecture/platforms.md`「全屏时 Agent 改发系统通知」一行改成已支持，`contracts.md` 里 `agent_notify` 那条去掉「只在 Windows」。
