## 说明

把 Factory 的 Droid CLI（命令 `droid`）接进 Agent 页。调研见 [global-coding-agents.md](/docs/research/global-coding-agents.md) 的 Droid 一节。

核实（2026-11-15；本机没装 CLI；格式出自 Factory 官方文档和第三方 sessionr 的读法）：

- 会话在 `~/.factory/sessions/<项目路径，/ 换成 ->/<uuid>.jsonl`，旁边的 `<uuid>.settings.json` 有 `model`、`reasoningEffort` 和用量。`FACTORY_HOME` 可以改目录。
- 记录：`session_start`（`id`、`title` 或 `sessionTitle`、`cwd`）；`message`（`timestamp`、`message.role`、`message.content` 是 Anthropic 风格的 `text` / `tool_use` / `tool_result` 块，注入的提问带 `visibility: "hidden"`）；另有 `todo_state`、`compaction_state`。
- 钩子：`~/.factory/hooks.json` 里事件名直接是顶层键（`settings.json` 里则在 `hooks` 键下），每项 `{matcher, hooks:[{type:"command", command, timeout}]}`，超时默认 60 秒。事件有 `PreToolUse`、`PostToolUse`、`UserPromptSubmit`、`Notification`、`Stop`、`SubagentStop`、`PreCompact`、`SessionStart`、`SessionEnd`，没有 `PermissionRequest`、`StopFailure`。stdin 是 Claude 兼容格式，`Notification` 的 `notification_type` 有 `permission_prompt`、`idle_prompt`。Droid 启动时读一次钩子，装完要重开会话。
- 全局提示词文件：`~/.factory/AGENTS.md`。

做法：会话读取在 `droid.rs`，把 `message` 记录转成 Claude 的样子交给现有的 `parse_claude_tail`（没有 `tool_use` 的助手消息算一轮结束）。钩子在 `droid_hooks.rs`：有 `~/.factory/hooks.json` 时写进它的顶层，没有时写 `settings.json` 的 `hooks` 键（官方文档：只有没有 `hooks.json` 时才读 `settings.json` 里的钩子，新建 `hooks.json` 会让用户写在 `settings.json` 的钩子失效），条目用 claude_compat 声明生成，去掉 Droid 没有的 `StopFailure`。没有 `PermissionRequest`，岛上不做允许 / 拒绝，「等你」靠 `Notification` 的 `permission_prompt`。用量环不做。
