## 说明

用户要求国内几家之后再调研海外的 AI 编程代理，逐家查清会话文件、钩子、等你、岛上审批、用量，能不能复用 Claude Code 兼容层或 opencode 适配，给出接入顺序。

## 验收

- 每家写清形态、会话文件、钩子、等你、审批、用量、可复用的适配、工作量，标明按文档还是实测
- 给出推荐接入顺序和要用户定的问题

## 提交

- `docs(research): overseas coding agents and how they could join the Agent page (B51)`

## 结论

调研见 [global-coding-agents.md](/docs/research/global-coding-agents.md)。海外钩子趋同，Grok CLI、Droid 能直接套 Claude Code 兼容层，Copilot CLI 只差回包格式；推荐顺序：先做兼容层的回包格式和去重（Grok、Copilot 都会读 `.claude/settings.json`），再 Grok、Copilot CLI、Droid、Cursor、Amp、Kiro、Goose。要用户定的问题在文档开头。
