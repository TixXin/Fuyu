## 备注

- 用量环已在第 3 版内置插件 `claude-usage`（[src-tauri/src/claude_usage/mod.rs](/src-tauri/src/claude_usage/mod.rs)、[src/features/claude-usage/plugin/island.tsx](/src/features/claude-usage/plugin/island.tsx)）上落地，无需触碰已冻结的旧 `plugin_host/builtin.rs`；三家开关（`antigravity`、`workbuddy`、`dsh`）默认均为 `false`。另本任务对 [harnesses.md](/docs/architecture/agent/harnesses.md)、[agent-status-hooks.md](/docs/features/agent-status-hooks.md)、[agent-harnesses.md](/docs/research/agent-harnesses.md) 的同步改动已被同工作区提交 `2e5c55bb` 一并带入。
- 本机 macOS（Antigravity 2.32.2、WorkBuddy AI、DSH `~/.dsh`）真实账号实测（`live_antigravity_workbuddy_and_dsh_usage`）：
  - **Antigravity**：经 `sysctl(CTL_KERN, KERN_PROCARGS2)` + `lsof` 发现运行中 `language_server_macos_arm`，明文环回 HTTP 调 `RetrieveUserQuotaSummary` + `GetUserStatus` 返回 `plan=Some("Pro")`、`five_hour=64.2%`、`seven_day=16.9%`、`models=[("3p5h", 5.0%), ("3p7d", 3.0%)]`；另实测 Cloud Code 回退（`daily-cloudcode-pa.googleapis.com` 的 `retrieveUserQuotaSummary` 只回 `3p-*` 时自动补调 `fetchAvailableModels` 拿到 Gemini 5 小时配额）。内部接口返回不可识别结构时置 `endpointChanged` 提示「接口失效」，不显示 `0%`。
  - **WorkBuddy**：只读扫描 `~/.workbuddy-ai/projects/**/*.jsonl`（兼容 `~/.workbuddy` 与 `$WORKBUDDY_CONFIG_DIR`），返回 `sessions=1`、`total_tokens=32790`、`credit=0.0`，不联网、不进百分比圆环，仅在悬停卡片显示今日 / 近 7 天 / 累计已用积分。
  - **DeepSeek Harness**：只读发现活跃存储 `~/.dsh`，校验 `cordis*.yml` 未覆盖官方默认地址后在内存中读 `.credentials.yaml`（静态缓存键仅存 SHA-256 指纹），调 `GET https://api.deepseek.com/user/balance` 返回 `source="dshApi"`、`available=true`、`CNY total="63.88"`，不进圆环，仅在悬停卡片显示钱包余额。
- Windows 真机待实测项已同步写入 [agent-harness-manual-tests.md](/docs/investigations/agent-harness-manual-tests.md)（#179）。
