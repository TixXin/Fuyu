## 备注

2026-11-17 在 macOS 上用 `codex-cli 0.169.0` 实测完成：
- 挂起等待期间终端不显示审批框（底栏显示 `Running hooks ◦ 1`），返回空 `{}` 后约 29ms 终端弹出 `Would you like to run the following command?`，按 `y` 照常执行。
- 返回 `allow` 直接放行执行、不出终端审批框；返回 `deny` 加 `message` 直接拦截并在终端显示 `Blocked by hook` 与拒绝原因、同时传回模型。
- 挂起时按 Esc 立即中断会话，HTTP 端点约 2ms 读到连接断开；沙箱自动放行的命令不触发 `PermissionRequest`；新装钩子首次启动需确认信任。详见 `docs/architecture/agent/island-interaction-notes.md`。
