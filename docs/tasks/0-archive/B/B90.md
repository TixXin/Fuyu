## 说明

Agent 页只有一个「显示额度」总开关，显示哪家、哪个窗口、重置时间都定死了；没有会话时只有两行字。用户 2026-11-23 看过[预览页](/docs/investigations/agent-panel-usage-empty-preview.html)后定：三种额度设置做法都要（分项勾选、只看最紧的、岛上菜单），六种空状态都能选，默认分项勾选和水母打盹。

## 验收

- 设置页能选显示哪家、哪些额度、只看最紧的、重置时间、样式，岛上额度行右键或按钮打开同样的菜单，立刻生效；旧设置升级后显示和以前一样。
- 「没有会话时显示」六种画面都能选，默认水母打盹；新动画有减少动画的处理。
- 「今日潮汐」的本地记录写进 contracts.md；同步白名单带上新设置。
- 中英文文案齐全。
- 第二轮（用户看过[设置预览](/docs/investigations/agent-usage-settings-preview.html)选了「所见即所改」）：额度行跟着这台电脑开着、读得到额度的 Agent 走（Antigravity、Cursor、GLM / Kimi 套餐、WorkBuddy 积分、DeepSeek Harness 余额也有），读不到的列成一行小字；设置挪到「外观 → 用量与会话环」，是带预览岛的所见即所改；空状态在「会话列表」里用轮播挑。
