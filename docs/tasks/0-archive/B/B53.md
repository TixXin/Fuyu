## 说明

把智谱 ZCode（桌面版 + `zcode` CLI）接进 Agent 页：会话列表、状态灯、等你、岛上审批、回复标记。调研见 [china-coding-agents.md](/docs/research/china-coding-agents.md) 的 ZCode 一节。

## 验收

- 「安装/修复」把钩子装进 `~/.zcode/cli/config.json`，设置页状态灯卡片里有 ZCode
- Agent 页列出 ZCode 会话（标题、目录、模型、最近提问和回复、三态），带品牌图标
- 等授权时岛上显示「等你」，能在岛上允许 / 拒绝
- 本机没装 ZCode 的部分列进实测清单

## 提交

- `feat(agent-status): ZCode on the island through its hooks and session database (B53)`

## 结论

按 ZCode main 分支源码和官方文档写，本机没装，未实测。

- 会话库 `~/.zcode/cli/db/db.sqlite` 是 opencode 第一版的表，复用 `opencode.rs` 的读取器；读取器按列是否存在跳过已删除、`*_child` 子会话，`title_source = default` 的占位标题当没有标题，多认 `modelId`，缓存按库路径分开存。
- 钩子装在 `~/.zcode/cli/config.json` 的 `hooks.events` 下（Claude Code 的分组格式），并把 `hooks.enabled` 设成 true；UserPromptSubmit、PreToolUse 亮灯，Stop 完成，PermissionRequest 存「等你」并走岛上审批（Claude Code 的 `decision.behavior` 回包）。
- 回复标记写 `~/.zcode/AGENTS.md`。跳转只有通用的终端窗口匹配；用量环、远程 SSH 没做。
