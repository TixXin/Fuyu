## 说明

GLM（智谱）用量环要用户把 API key 手动粘贴到设置里，才能查额度。用户为此复制 key，key 被记进了剪贴板历史（见 #863，剪贴板那部分由 C133 修）。


查 GLM / Kimi 用量时，先从用户已经配好的地方读 key，不用再复制粘贴：

- Claude Code 的 `~/.claude/settings.json`（及项目级 settings）里 `env.ANTHROPIC_BASE_URL` 指向 `open.bigmodel.cn` / `api.z.ai`（Kimi：`api.kimi.com` / `api.moonshot.cn`）时，用同一份 `env.ANTHROPIC_AUTH_TOKEN` / `ANTHROPIC_API_KEY`
- 其他常见位置可酌情加（cc-switch 等切换工具的配置、环境变量），先调研再定
- 读到的 key 只留在 Rust，不回前端，不写日志；手动填的 key 优先
- 设置里显示「已从 Claude Code 配置读取」，不再要求粘贴

## 验收

- 用 GLM 跑 Claude Code 的用户打开用量环就能看到 GLM 额度，不需要复制 key
- 读取失败或没配时，照旧提示手动填写

来源：#863 用户反馈。参考 B78（Cursor 用量环）和 `src-tauri/src/claude_usage/plan.rs`。
