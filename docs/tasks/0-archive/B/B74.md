## 说明

汇总 `B73`（`B73.1`、`B73.2`、`B73.3`）在自动化单测与 CI 中无法直接覆盖的 Windows NSIS 安装/卸载向导、Windows 凭据管理器与真实 SSH 远端联调实测项。背景与方案见 [agent-hooks-uninstall-cleanup.md](/docs/research/agent-hooks-uninstall-cleanup.md)。

## 验收

- 正式版（Windows / Mac）装有任一 AI 钩子时，「设置 → AI Agent → AI Agent 状态灯」显示「移除钩子」（开发版与全部未安装时不显示）；点击后移除本机及已启用 SSH 远端的浮屿钩子并保留用户自有配置，移除按钮随刷新自动隐藏
- Windows 真机安装钩子后手动删除 `%USERPROFILE%\.fuyu\fuyu-agent-*.{cmd,ps1}`，在 Claude Code、Codex、GitHub Copilot CLI（PowerShell）触发提问或工具调用静默返回 `0` 且零报错；删空 `.fuyu` 后运行装有旧插件的 `opencode` / `pi` / `DSH` 不再重建 `.fuyu`
- Windows 装好钩子与回复标记后双击新版 NSIS 安装包选默认「先卸载旧版本再安装」，确认 `/REINSTALL` 下外部钩子、回复标记与家目录数据完好保留
- Windows 运行 `uninstall.exe` 不勾选 `Delete the application data`，确认 19 家外部钩子与回复标记已移除且写出 `%USERPROFILE%\.fuyu\uninstalled-hooks.json`；重装启动后自动恢复并删除该标记文件
- Windows 运行 `uninstall.exe` 勾选 `Delete the application data`，确认正式版 `com.tixxin.fuyu` 凭据（不含 `lane-*`）、编辑器扩展 `tixxin.fuyu-*` 及默认 `%USERPROFILE%\.fuyu` 已清除；自定义 `home.json` 目录仅删浮屿受管项，完好保留用户自有文件

## 备注

2026-11-27 AI 在 Windows 真机（`tixxin-computer`，0.3.15-beta.1，Claude Code 2.1.330）上实测，测前备份了家目录、应用数据和凭据，测完全部还原：

1. 移除按钮：过，但验收写法已过时。B89 起「设置 → Agent → 钩子与代理 → 移除全部钩子」在正式版里常驻，不随安装状态隐藏。点「全部移除 → 确认」后提示「已从各家 AI Agent 配置中移除浮屿钩子与脚本」，各家配置里的浮屿条目、四个脚本和 Claude 的 `statusLine` 都删掉，`~/.claude/settings.json` 里用户自己的 `env`、`model` 等保留；「全部重装」后 19/19 家恢复，配置与之前逐字节一致。本机没有启用的 SSH 远端，远端部分没测。
2. 删掉脚本后静默返回 0：**不过**，另开 B96（#1301）。退出浮屿、删掉 `fuyu-agent-*.{cmd,ps1}` 后 `claude -p … --include-hook-events`，Claude Code 的 5 个钩子全部 `exit_code=127, outcome=error`：Windows 版 Claude 钩子命令没有存在性守卫。Codex、Cursor、Gemini/Antigravity、Grok、Copilot（PowerShell 那条）带守卫，实测 `exit=0`、无输出（Cursor 审批返回 `{"permission":"ask"}`）。另：浮屿运行时删掉的脚本约 1 分钟内会被自动写回。opencode / pi / DSH 本机不在 PATH 上，没测「不重建 `.fuyu`」。
3. NSIS 重装保留：过。同版本安装包只有「Add/Reinstall」，不经卸载器，所以改测两个方向：用 0.3.12-beta.2 安装包降级（默认「Uninstall before installing」），实际命令 `uninstall.exe /REINSTALL _?=…`（0.3.15 的卸载器）；再用 0.3.15-beta.1 安装包升级回去（0.3.12 的卸载器同样带 `/REINSTALL`）。两次卸载后各家钩子配置、四个脚本、状态栏脚本、7 份回复标记、todos、settings、clipboard-history 哈希都不变。
4. 不勾删除数据卸载：过。19 家钩子、`statusLine`、回复标记全部移除，写出 `uninstalled-hooks.json`（`{"hooks": true, "replyMarker": true}`），家目录数据保留；重装启动约 20 秒后钩子、标记、`statusLine` 逐字节恢复，标记文件被删。小问题：回复标记关掉或卸载时，原本不存在、由浮屿新建的 `CLAUDE.md`、`AGENTS.md`、`GEMINI.md` 等留下 0 字节空文件。
5. 勾删除数据卸载：过（默认家目录）。`~/.fuyu`、`%APPDATA%\com.tixxin.fuyu`、`%LOCALAPPDATA%\com.tixxin.fuyu` 删除；放进去的假扩展 `~/.vscode/extensions/tixxin.fuyu-terminal-0.0.1-aitest` 删除、对照目录保留；正式版凭据 `…com.tixxin.fuyu.qq-mail`、`…com.tixxin.fuyu.calendar`、测试用 `device-key.com.tixxin.fuyu.bark` 删除，`lane-*`、旧名 `com.focusd.island.*` 和无关条目保留。自定义 `home.json` 目录的情况没测。小问题：安装目录 `%LOCALAPPDATA%\Fuyu` 卸载后残留历次升级留下的旧哈希 `plugins-v3/host/chunk-*.mjs`（卸载器只删当前版本资源清单）。

还没测：SSH 远端移除、opencode / pi / DSH 不重建 `.fuyu`、自定义 `home.json` 目录只删受管项。
