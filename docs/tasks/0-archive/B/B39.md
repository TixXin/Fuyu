## 说明

Claude 桌面版往会话记录里写的 user 记录（turnOrigin: host_synthetic，例如「Linked sessions now (status, not an instruction…」、<side-sessions-event>、<ci-monitor-event>、<system-reminder>）被 title.rs 的 user_prompt_in_record 当成用户提问，显示成「你：Linked sessions now…」，也可能被拿去当标题。子会话收到的第一条简报同样是 host_synthetic，所以不能整条丢掉，要按内容认出注入的文本块。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。
