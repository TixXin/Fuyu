## 说明

把小米 MiMo Code（终端 CLI，opencode 的分支）接进 Agent 页：会话列表、三态、等你、岛上审批、回复标记。调研见 [china-coding-agents.md](/docs/research/china-coding-agents.md) 的 MiMo 一节。

## 验收

- Agent 页列出 MiMo Code 会话，带品牌图标
- 「安装/修复」装上它的插件，等你和岛上审批能用
- 本机没装的部分列进实测清单

## 提交

- `feat(agent-status): MiMo Code on the island through the opencode plugin and its session database (B54)`

## 结论

按 XiaomiMiMo/MiMo-Code 源码写，本机没装，未实测。

- 目录和 opencode 同一套规则，名字是 `mimocode`（`~/.local/share/mimocode/mimocode.db`、`~/.config/mimocode/`，`MIMOCODE_HOME`、`MIMOCODE_DB` 可改），Windows、macOS 也一样。
- 会话复用 `opencode.rs` 的读取器；读取器在 `message` 有 `agent_id` 列时只看 `main` 的消息，`title_source = fallback` 的占位标题当没有标题。
- 插件复用岛的 opencode 插件，装进 `~/.config/mimocode/plugin/`，审批路由换成 `/mimo/permission`，岛上允许 / 拒绝和「等你」都走插件。
- 没有状态灯（没有命令钩子）、用量环、远程 SSH；非默认发布渠道的库 `mimocode-<渠道>.db` 不读。
