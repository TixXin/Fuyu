## 说明

设置 → Agent →「钩子与代理」改成每家 Agent 单独安装、修复，再加自动配置的设置。交互预览：[agent-hooks-per-item-preview.html](/docs/investigations/agent-hooks-per-item-preview.html)。

方案：

- Rust：`install_agent_hooks(providers)` 先写共用脚本，再逐家装，每家的结果单独返回；`uninstall_agent_hooks(provider)` 只移除这一家。全局的 `install_agent_status_hooks` 留给「全部安装」「全部重装」（含 SSH 远程、回复标记），改为装完所有家再一起报错。
- 卡片右侧：钩子状态（绿勾 / 修复 / 安装）、`⋯` 菜单（重装、清除状态、这家的注意事项）、开关。关掉装了钩子的一家时问「只关闭」还是「关闭并移除钩子」；打开没装钩子的一家顺手装上。
- 顶部汇总只在有旧版钩子、脚本旧了、或一家都没装时出现，按钮只修有问题的几家。
- 底部「钩子设置」：自动配置新 Agent、自动更新旧版钩子（`agentHooksAutoInstall` / `agentHooksAutoUpdate`，默认开，不同步）、全部重装、全部移除。
- 岛上 20 秒后检查一次，之后每 10 分钟一次：至少一家装过钩子才动，只动开关开着的；装好后弹一条岛上提示；同一状态试过一次不再试；开发版不自动装。
