## 说明

现在只显示「2 个子 Agent」这个数字。Claude Code 的子 Agent 记录在 `<会话>`/subagents/agent-*.jsonl，没读。做法（用户选定）：Rust 读子 Agent 的描述、状态、当前工具、开始时间；父行的「n 个子 Agent」变成可点的小按钮，点开在父行下缩进列出，默认收起，跑完自动消失。顺带调研 Claude 桌面版开的子会话能不能拿到父会话，拿不到就另开 issue。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。

## 验收

- 子 Agent 能展开收起，键盘可达，减少动画时不动
- Rust 模块带脱敏样本的测试
- cargo test、pnpm build:exe、pnpm check、pnpm build、pnpm test:regression 通过

## 备注

- **数据从哪来**（Claude Code 2.1.325 本机样本）：`~/.claude/projects/<项目>/<会话 id>/subagents/` 里每个子 Agent 三个文件：`agent-<id>.jsonl`（对话记录，`isSidechain: true`）、`agent-<id>.meta.json`（`description`、`agentType`、`toolUseId`、`spawnDepth`、`requestShape`、`model` 等）、`agent-<id>.prefix.json`。查 Claude Code 二进制确认：`finished: true` 只在跑完时写上，被用户停掉写 `stoppedByUser: true`，所以没有这两项就是还在跑。进程崩了不会写 `finished`，所以记录 30 分钟没更新的也当成已经退出。
- **做法**：`agent_status/subagents.rs` 在 `list_agent_sessions` 返回前给每个会话套一层（`ListedSession`，`serde(flatten)`），只对本机、没退出、`subagents > 0` 或 `backgroundTasks > 0` 的 Claude Code 会话读目录：每个 `meta.json` 最多读 16 KB，还在跑的才读记录尾部 128 KB（拿当前工具）和第一行（拿开始时间），按文件修改时间和长度缓存，没变就不重读。新字段 `subagentList` 为空时不输出；原来的 `subagents` 数量不变，前端和插件照旧能用。没改 `AgentSessionSummary`，所以别的模块构造摘要的地方都不用动。
- **后台子 Agent**：放到后台跑的子 Agent 在父会话里马上收到「Async agent launched」，原来就算进「后台任务」、不算进 `subagents`，现在它们会出现在子 Agent 列表里（标「后台」），「n 个后台任务」里仍然算一份，没去重。
- **卡片和紧凑视图**：只显示数量（`AgentSessionCard.tsx` 不在这次范围里，卡片高度固定 62 / 34px），没做展开。
- **远程会话**：`remoteHost` 的会话不读子 Agent（远程镜像只拉了父会话记录），列表里只有原来的数量。要做的话 `remote_fetch.rs` 得把 `subagents/*.meta.json` 和记录尾部一起拉过来。
- **其他几家**（按 `fuyu-agent-harness` 的要求，只说明不做）：Codex 有子 Agent，是单独的线程，`session_meta.payload.source.subagent.thread_spawn` 里有 `parent_thread_id` 和 `depth`（本机样本，`sessions.rs` 的 `parse_codex_meta` 和 `codex_threads.rs` 现在把它们滤掉不列），以后可以按父线程挂到父会话下面。opencode 的 task 工具开的是带 `parentID` 的子会话（按文档，未实测）。WorkBuddy / CodeBuddy 会话格式像 Claude Code，有没有 `subagents/` 目录没核实。Antigravity、DSH、Qoder、Qwen 没查到子 Agent 的本地记录。
- **Claude 桌面版子会话能不能找到父会话（调研结论，2026-11-15，Mac 本机）**：能。`~/Library/Application Support/Claude/claude-code-sessions/<账号>/<组织>/local_<id>.json` 每个桌面会话一份，里面 `cliSessionId` 是 `~/.claude/projects/` 里的会话记录 id，`spawnedFrom.sessionId` 是开它的父会话的 `local_` id（还有 `spawnedFrom.title`、`name`、`sideSession`），`startChain.firstSessionId` / `startChain.depth` 是最上层的会话和层数。父会话的 `local_<id>.json` 里又有它自己的 `cliSessionId`，所以两步就能把子会话对到父会话的会话记录。本机 97 份里 73 份带 `spawnedFrom`。证据：这个会话自己的文件里 `cliSessionId = f7395b96…`，`spawnedFrom.sessionId = local_2e33e948…`（B42 的主 agent），`startChain.depth = 2`。B46 正在写的 `claude_desktop.rs` 已经读这些文件（取 `cliSessionId`），没读 `spawnedFrom`。Windows 上应在 `%APPDATA%\Claude\claude-code-sessions\`，没核实。归组没在这个任务里做，要做另开任务。
- **实测清单**（真机 `pnpm tauri dev`，本机没跑）：
  - Claude Code 会话里让它开 2 个前台子 Agent、1 个后台子 Agent：父行下面出现「▸ 3 个子 Agent」，点开列出三行，后台那个标「后台」，工具随子 Agent 调用变化，用时每秒走
  - 子 Agent 一个个跑完：列表里一个个消失，全部跑完按钮消失；停掉一个子 Agent 也会消失
  - 展开收起时下面的会话平移、不跳；系统设置「减少动态效果」打开后不动、箭头不转
  - Tab 能选到按钮，空格 / 回车展开收起，读屏念「展开 n 个子 Agent」
  - 卡片、紧凑视图只显示数量，不出按钮
  - 窄宽（400 弹出提醒宽）下子 Agent 行不撑出横向滚动
  - Windows 上同样走一遍（子 Agent 目录在 `%USERPROFILE%\.claude\projects\…`）
