## 说明

现在只有归档有动画，新会话出现、重排、状态变化都是瞬间跳变。做一个 FLIP 的 useListMotion：重排时行平移过去（约 200ms），新行淡入展开，离开的行收起，状态点换色过渡，变成「等你」时圆点脉冲一次；和归档动画不冲突；系统要求减少动画时全部关掉。用户选了克制的力度。 总计划和每个任务的 scope 见 [agent-page-plan.md](/docs/design/agent-page-plan.md)。

## 验收

- 三种显示方式（列表、卡片、紧凑）都有动效，减少动画时无动画
- 新回归页 agent-list-motion 检查重排后位置和减少动画
- pnpm check、pnpm build、pnpm test:regression 通过

## 备注

设计说明（主 agent 收口时合并进 `docs/design/agent.md`）：

- `useListMotion.ts`（FLIP）：只在列表的 key 顺序或成员变了的那次渲染里量一次各行位置（`getBoundingClientRect`，读的是上一次提交的 DOM），提交后再量一次新位置，差值用 WAAPI 平移 200ms，缓动 `cubic-bezier(0.2, 0.7, 0.3, 1)`，和归档一致。平时重渲染不测量。行按 `data-session-key` 认，分组标题行带 `data-session-key="group:<key>"`。
- 新行：原位淡入，`clip-path` 从上往下展开（200ms）；下面的行由 FLIP 往下让，所以不改高度，免得和平移叠加。
- 离开的行（会话退出、被筛掉）：渲染时克隆一份，提交后作为 `li.agent-motion-ghost` 绝对定位放回旧位置，淡出并从下往上收起（180ms）后移除；影子 `aria-hidden`、`inert`、没有 `data-session-key`。别的行同时平移补位。测试里按 DOM 顺序取 `.agent-session` 的，要排除 `.agent-motion-ghost` 或等 200ms。
- 状态点、紧凑色条、卡片状态文字换色过渡 240ms；`sessionLight` 从别的状态变成 `needs` / `yourTurn` 时，行上加 `agent-motion-pulse`，列表视图圆点放大一次，卡片和紧凑视图卡片外圈扩散一次（640ms），播完去掉。新出现的会话不脉冲，`needs` ↔ `yourTurn` 之间互换不脉冲。
- 和归档：`useArchiveMotion` 归档时给行打 `data-motion="archiving"`，FLIP 和影子都跳过它；撤销归档那次提交整个跳过 FLIP，只有归档自己的展开动画。弹出提醒（`reveal`）、审批卡片显示时不动；切换显示方式（列表 / 卡片 / 紧凑）那次不动。
- 减少动画：JS 里查 `prefers-reduced-motion`，整套不动；CSS 的脉冲在同文件 `@media (prefers-reduced-motion: reduce)` 里关掉；换色 `transition` 由 `base.css` 统一归零。

顺带发现（不是本任务改的）：归档收起结束后，`useArchiveMotion` 在 `requestAnimationFrame` 里 `cancel()` 动画，回归页里这一帧比 React 移除这行早，行会恢复原高一帧；真机上可能闪一下，值得观察。

实测清单（Mac 回归页测不了流畅度，要在 `pnpm tauri dev` 的真岛上看）：

- [ ] 会话按状态重排时，行平移顺滑，展开岛时不掉帧（对照 `docs/investigations/expansion-performance.md`）
- [ ] 新会话出现、会话退出时淡入 / 收起，滚动到中间时影子位置对得上
- [ ] 变成「等你」时圆点 / 卡片脉冲一次，不反复闪
- [ ] 归档（滑出、粒子消散两种）和撤销时没有重复动、没有闪
- [ ] 卡片视图开「粒子流苏」时脉冲和呼吸动画不打架
- [ ] Windows 系统设置里关掉动画效果后，列表全部瞬间变化
