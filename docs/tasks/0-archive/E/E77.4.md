## 说明

给写插件的人（先是我们自己）的五件事，按这个顺序做，每件单独提交：

1. **至少一张截图**：官方插件必须有至少一张截图（没有自己界面的截它起作用的地方，例如词典截翻译窗口里的查词结果），写进 `docs/plugins/official-quality.md`，测试拦住；第三方插件 `check` 时只警告。
2. **图标命令**：`fuyu-plugin icon --glyph <lucide 名> --color <#rrggbb>` 按官方插件标准「图标」一节的骨架写出 `assets/icon.svg`，并提示主色有没有和已有官方插件撞。
3. **截图命令**：不凭空画图，截真界面。把插件的岛上页面、收起条、设置分节放进固定尺寸的岛外壳，喂插件自己提供的一份示例数据，用无界面浏览器截图（回归页已有这套机制，`scripts/regression/`）；同时合成一张市场封面（截图放在主色浅底上）。示例数据怎么约定先写方案。先支持岛上页面和收起条。
4. **把官方标准做成检查**：说明超过市场卡片两行、写了实现方式（「基于…」「免 API Key」这类）、名字在清单 / 岛页标题 / 设置分节 / README 不一致，`check` 给出警告（官方插件套件里当错误）。
5. **本地预览**：`fuyu-plugin preview` 在本地渲染出这个插件在市场卡片和详情页里的样子，作者不用等上架才发现图标糊了、说明被截断。

## 验收
