## 说明

B1：v0.3.10 只迁移了计时器，`off_without_grant` 在 fcf96486（E36.6.5）里随 `v2_builtins.rs` 删了，现在 `plugins.yml` 没记的内置插件一律当开着。从 v0.3.10 或更早升上来的用户和新装用户，用量环、cc-connect、会话环、本机接口、SSH 隧道、中心图案会变成开着，旧配置也丢了。v0.3.11-beta.1–beta.4 还带着完整迁移表，beta 用户有 `v2-migrated.json` 标记，必须跳过。

改法：从 `fcf96486^:src-tauri/src/plugin_kernel/v2_builtins.rs` 拿回迁移表（含旧 `local-api.json`），在 `builtins::init` 里跑一次；`src/features/builtins.json` 给这六个标默认关，第一次迁移时显式写成关闭（不能改成「没写就当关」）。顺带改对 `data-storage.md` 本机接口那一行（M3）。

## 验收

- Rust 单元测试：从 v0.3.10 升上来有授权（保持开关、搬旧配置）、没授权（六个都关）、新装（六个都关、计时器照旧）、已经是 beta（有标记，不动）
- Rust 单元测试、`pnpm build:exe`、`pnpm check` 通过，附 `pnpm mq:try` 的 Windows run
