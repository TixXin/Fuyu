## 说明

计划「关键设计」第 2 条，纯搬迁。`src/windows/island/slots/` 里各功能的注册搬到 `src/features/<领域>/plugin/island.tsx`，窗口用 `import.meta.glob(..., { eager: true })` 收集；新加 `island.notice/v1`、`island.runner/v1`，把 `islandNotice.tsx` 的提示、外壳里直接 import 的会议行、设备弹窗、音量弹窗、歌词，以及 `IslandApp.tsx` 里的接线 hook 改成插槽项；外壳要读的功能状态改成元数据。拥有者暂时仍是 `builtin`。

计划见 [v3-phase3-plan.md](/docs/architecture/plugins/v3-phase3-plan.md)。

- 回归页 DOM 快照全部不变
- `v3-boundary.md`「插槽」一节加上新插槽

## 备注

**范围按组长 2026-11-15 的决定切过**：摸底后，「外壳只 import `plugin-kernel` 和 `lib` / `components`」这一条连同外壳布局读功能状态的部分拆到 E36.3.51（#619）；本任务只做纯搬迁。做了的：
- `slots/` 里各功能的展开页、页头按钮（消息、翻译、截图）、收起条项（邮件、更新、设备占用、文件中转、音乐、用量环、计时、会话数、中心图案）、刘海提醒（设备、额度、音量亮度）搬进各功能的 `plugin/island.tsx`，页面元数据在 `plugin/page.ts`；外壳由 `windows/island/slots/builtins.ts` glob 收集，顺序全写成显式 `order`（页面 10–100）。
- 新插槽 `island.notice/v1`（录屏、语音、计时响铃、截图、复制、提醒卡片放进功能，第一次提示留在外壳）和 `island.runner/v1`（`timer` 的休息提醒、`local-api` 的实验台动作、`translation` 的开关下发和岛内快捷键）。
- 剪贴板页嵌截图历史改成页面元数据 `fold`，不再由剪贴板 import 截图。
- 功能里不 import 外壳：句柄用 `plugin-kernel` 的 `defineSlot`，props 写成功能自己那几个字段；外壳把打开设置、带快捷键的标签、页是否开着、监听岛悬停放进上下文。边界测试把 `plugin-kernel` 当平台层放行（0dc091f0）。
- 功能边界白名单没有能删的条目（本任务没有动功能之间的 import），也没有新增。

验证：`pnpm check`（1393 个单元测试通过）、`pnpm build`、`pnpm test:regression`（57 页全过，113 份 DOM 快照全部没变，没有用 `--update-snapshots`）。第一次整跑时 `claude-usage`、`bottom-island` 在别的会话跑 Rust 测试的负载下超时，单独重跑和最后一次整跑都通过。

### A 做完后外壳还剩的 import（E36.3.51 从这里开工）

E36.3.25 之后，`src/windows/island/` 里还有 46 个文件、约 219 处 import 功能目录（不算 `plugin-kernel`）。按要怎么去掉分三类：

**1. 外壳拿功能状态算布局（E36.3.51 的主体）**：要定通用的贡献元数据，功能经 runner 交结果，外壳只认元数据。
- `IslandApp.tsx`（agent-status、calendar、clipboard、media、messages、screenshot、timer、todos、translation）：收起条文字（待办 + Agent 标题 + 歌词优先级 + 横幅 + 翻译速览）、收起宽度、贴边保持、封面取色、悬停领头页、弹出高度（Agent 卡、消息到达面板）、刘海下拉、各功能 hook 的调用和结果下传。
- `IslandShell.tsx`、`IslandCollapsedBar.tsx`（会议行、歌词、Agent 标题和图标、设备/音量/额度弹窗、消息预览、更新提醒）、`IslandSideColumn.tsx`、`IslandSideBubble.tsx`、`IslandSideHandle.tsx`、`NotchPopupBand.tsx`、`NotchMessage.tsx`、`IslandHeader.tsx`（Agent 状态图标、`MessageSource`）。
- 布局计算：`layout.ts`（Agent 页高度）、`useCollapsedTodo.ts`、`useTuckHold.ts`、`useIslandGlass.ts`（中心图案）、`useCollapsedSlots.tsx`（中心图案、会话环、计时、用量的上下文）、`useAgentIndicator.ts`。

**2. 给插槽项的 props 包 / 来源包，由外壳调功能 hook 拼出来**：功能自己出状态（runner + 功能自己的 store）后，这些 hook 搬进各功能的 `runners.tsx`，插槽项直接读。
- 展开页的 props 包：`IslandPages.tsx`（`IslandPagesProps` 的类型）。
- 提示的来源包：`islandNotice.tsx`（录屏、截图、复制卡片、计时响铃的类型，`useIslandReminder` 的调用）、`useIslandVoiceInput.tsx`（语音提示，含 voice-input → device-use 的跨功能调用）。
- 提醒和收起条的上下文类型：`slots/alerts.tsx`、`slots/collapsed.tsx`、`slots/header.tsx`（设置按钮的更新圆点 `useUpdateReminder`、`MessageSource`）。
- 各功能 hook 的接线：`useIslandNotices.ts`、`useIslandAgents.ts`、`useIslandAgentAlerts.ts`、`useIslandBanner.ts`、`useIslandMessagePanel.ts`、`useLatestMessagePreview.ts`、`useMessageView.ts`、`useIslandLyrics.ts`、`useIslandTodos.ts`（todos + agent-status + local-api + updater）、`useIslandShelf.ts` / `useFileShelfDrop.ts`、`useIslandScreenshot.ts`（截图按钮的回调 + 截图设置下发）、`useIslandTranslation.ts`（打开翻译的两个回调）、`useIslandKeyboard.ts`（剪贴板快捷键和页面快捷键在同一个 keydown 里，拆开要定先后）、`useIslandFeatures.ts` / `features.ts`（`MessageSource`、计时插件开关）、`useOnboardingDemo.ts`。
- 要先有服务的：`useIslandAutoUpdate.ts`（updater 要 agent-status 的空闲、锁屏和会话状态）。
- `TodosGate.tsx`：`main.tsx` 在岛渲染前等待待办存储迁移，可以做成待办插件的启动闸门。

**3. 第 2 版插件系统（冻结，不迁，随第 2 版一起删）**：`usePluginPages.ts`、`usePluginOpenView.ts`、`usePluginKeybindings.ts`、`usePluginHostEvents.ts`、`useFirstRunGuide.ts`、`PluginPageButtons.tsx`，以及 `IslandApp`、`IslandShell`、`IslandCollapsedBar`、`IslandPages`、`useIslandNotices`、`useIslandBanner`、`useIslandMessagePanel`、`useLatestMessagePreview`、`useCollapsedSlots` 里对 `plugins`、`plugin-views` 的 import。
