## 说明

[方案](/docs/architecture/plugins/v3-everything-plugin.md)「分阶段」的第 3 阶段，预计 4–6 周。`features/` 下每个领域变成一个插件：宿主部分注册服务，界面部分往插槽注册。先拿计时器、翻译打样，再逐个迁；开工时按功能拆子任务。

要做的：

- 开始前回头评估一次 rutis
- 服务的类型包
- 给 Rust 函数加标记，自动生成给宿主的入口和 TypeScript 类型；Rust 能力的提供者插件
- 功能之间只通过服务和事件互相调用
- 设置的插件页列出全部内置插件，能单独关掉
- 每个功能迁完后先在测试通道默认开

开工前读 [进度](/docs/architecture/plugins/v3-progress.md) 和 [流程](/docs/architecture/plugins/v3-workflow.md)；开工时把上面拆成步骤写进下面的验收，做完一步勾一步。
