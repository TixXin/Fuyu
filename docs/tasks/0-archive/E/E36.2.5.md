## 说明

IslandPages 的页面和 features.ts 的 BUILTIN_PAGE_ORDER、快捷键顺序、页头圆点名单改由 island.page/v1 的页面项提供；IslandFeatures 固定类型改成按页面 id 的开关表，单独一个提交。

分步计划见 [v3-phase2-plan.md](/docs/architecture/plugins/v3-phase2-plan.md)。

## 验收

- features.ts 里没有写死的页面列表
- 单元测试不改断言，回归页和 DOM 快照一致

## 提交

- `refactor(island): expanded pages register in island.page/v1, features.ts reads the registry (E36.2.5)`
- `refactor(island): IslandFeatures becomes a switch table keyed by page id (E36.2.5)`

## 备注

- 页面项的元数据（`icon`、`shortcutOrder`、`headerDot`、`enabled`、`fallback`）放在不含组件的 `src/windows/island/slots/pageSlot.ts`，组件和注册在 `slots/pages.tsx`：单元测试用 `node:test` 跑，Node 加载不了 `.tsx`。三个单元测试（含 `agent-session-list.test.mjs`，它也调 `resolveIslandPage`）只多一行 `import "./islandPageSlot.mjs"`，这个辅助文件用同一份元数据配空组件注册，断言没动。
- `features.ts` 的页面顺序、快捷键顺序、启用和回退都按注册表算；第 2 版插件页在快捷键顺序里排在最后一个页头圆点页之后（和页头上 `PluginPageButtons` 跟在圆点后面一致）。`HEADER_DOT_PAGES` 和 `HeaderDotPage` 还在导出（由元数据算出，类型仍是那 7 个页），给 `IslandHeader.tsx` 用到 E36.2.6。
- 注册靠 `IslandPages.tsx` 顶上的副作用 import。单独渲染 `IslandShell` 的回归页夹具 `lyrics-handoff-checks.tsx` 不经 `IslandApp`，页头算不出快捷键（`music-lyrics` 的快照少了「(Alt+1)」），所以它也加了这一行 import。E36.2.6 让页头直接读注册表后也要注意这一点。
- `IslandFeatures` 改成 `Record<BuiltinPage | MessageSource, boolean>` 加 `clipboardScreenshots?`、`pluginPages?`。`calendar`、`screenshots`、`timer` 从可缺省变成必填（应用里 `useIslandFeatures` 本来每项都给）；8 个回归页夹具手写的对象补了这三项 `false`（原来缺省即 undefined，同样是关）。全可缺省的写法会让 `IslandApp.tsx`、`IslandShell.tsx` 编不过，所以没用。
- 第二个提交只动类型：`features.ts`、`pageSlot.ts` 去掉类型后的 JS 和第一个提交逐字相同（`node:module` 的 `stripTypeScriptTypes` 比对）。
- 验证（两个提交各跑一次）：`pnpm check` 通过（第一次跑时 `check:tasks` 停在别的会话的 `docs/tasks/D/D73.md`，那次单独补跑了 `pnpm test`；第二次整串通过，单元测试 1353 个、0 失败、15 跳过）；`pnpm build` 通过；回归页 53 页过 52 页、104 个快照一字不变。没过的 `timer.html` 是计时器小条的数字（快照 `##:##`、实际 `05:00`），出自 D73 会话正在改的快照规则，和展开页无关。D73 正在改 `scripts/run-regression.mjs`（工作区里的版本缺 `settledSnapshot` 导出、跑不起来），回归页用的是已提交的运行器拷到临时目录跑的。
