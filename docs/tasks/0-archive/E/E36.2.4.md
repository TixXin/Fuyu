## 备注

- 两个插槽加了元数据 `shown(context)`（主 agent 2026-11-15 同意，和 `island.page/v1` 的 `enabled`、`island.alert/v1` 的 `active` 同类，只加不改，不出 `/v2`）。原因：邮件、更新、文件中转、音乐、会话数、4 个用量环、计时器、中心图案都是有内容（或插件开着）才出现，出不出现决定传给 `arrangeCollapsedItems` 的 id 列表和相邻量表是否合进同一个 `.island__gauge-slot`；组件返回 null 会改 DOM（例：计时器在、会话数不在时，会话数被排进用量环和计时器之间，一个量表框拆成两个）。
- 第 2 版插件状态不进注册表：它的 id 是第 2 版插件动态给的，注册表里只能放静态的项；按 `PLUGIN_STATUS_ORDER`（35）插在「更新」（30）和「设备占用」（40）之间，和以前的 push 位置一样。第 6 阶段随第 2 版一起删。
- `gauges` 照旧由 `useCollapsedSlots` 产出（用量环、计时器在注册表里，`useCollapsedSlots` 按 `shown`、`hideable` 挑出来、按 `width` 算 `sideWidth`）：侧栏（`IslandShell` 的 `useSideColumnRows`）和回归页 `collapsed-slots`、`claude-usage` 都直接用 `CollapsedSlots.gauges`；收起条在第一个 `group: "gauges"` 的位置放 `slots.gauges`。所以一个插槽有两种 props：`group: "gauges"` 的项拿 `useCollapsedSlots` 那边的上下文（`CollapsedGaugeContext`），其余的拿收起条的上下文（`CollapsedBarContext`），在 `slots/collapsed.tsx` 里用两个 `defineSlot` 分开写类型。
- 验证（2026-11-15，Mac）：`pnpm check`（1347 项单元测试）、`pnpm build` 通过；`pnpm test:regression` 53 页全过，105 份 DOM 快照一字不变，没用 `--update-snapshots`。搬迁提交单独跑过一次回归，收起条相关的页和快照都一致（当时 `music-lyrics` 页头的 `(Alt+N)` 不一致，是 E36.2.5 正在改、还没提交的 `features.ts` 造成的，它跟上后这次全过）。
