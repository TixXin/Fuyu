## 说明

对照 `docs/architecture/plugins/v3-everything-plugin.md` 清单 `fuyu.config` 要求，支持插件通过 JSON Schema 自动生成设置表单并持久化到插件数据目录。

## 验收

- `sources.mjs` 解析清单 `fuyu.config` 指向的 JSON Schema 文件；宿主提供 `ctx.config`（`get`、`set`、`onChange`）与 `plugin-config/v1` 服务（`list`、`get`、`set`、`reset`、`changed`），读写 `<dataDir>/<id>/config.json` 并按 schema 默认值与约束校验。
- 插件详情弹窗对带 schema 的插件自动渲染布尔开关、枚举下拉、数值与文本输入表单及恢复默认按钮。
- 单测、`pnpm check` 与 `pnpm build` 通过。
