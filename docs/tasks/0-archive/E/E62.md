## 说明

官网插件市场换成了新索引 `index.v3.json` 里的 12 个 `@fuyu/*` 官方插件，但没放插件说明。`plugins/v3/official/*/README.md` 原来是写给开发者的（服务、插槽名），还写着「第 3 版」「plugin platform v3」。改成写给普通用户的说明：做什么、装好后在岛上哪里出现、怎么用、有哪些设置、联网或启动程序等能力；开发者内容放最后一节。中文在前、英文在后，不写版本字样。

核实过：README 会被打进插件包（`packages/plugin-cli/src/files.mjs` 总是带 README），市场详情页已装时读本机包里的 README，没装时按索引里该版本的提交号读 GitHub 上的文件。所以改仓库里的 README 不影响已发布包的签名和哈希，但要重新发布插件，市场详情里才看得到新 README；官网可以直接读仓库 main 上的文件。

## 验收

- 12 份 README 都改成面向用户的说明，没有「第 3 版」「v3」字样
- `pnpm check` 通过
