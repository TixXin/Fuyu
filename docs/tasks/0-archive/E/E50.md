## 说明

对照 `docs/architecture/plugins/v3-everything-plugin.md` 清单 `fuyu.commands` 要求，补齐第 3 版插件命令注册、未声明核对、双平台全局快捷键同步以及设置窗口快捷键页的录制与冲突管理。

## 验收

- 宿主提供 `ctx.commands.register(id, handler)` 与 `commands/v1` 服务（`list`、`run`、`setKeybinding`、`changed`），未运行插件也能从清单列出命令与默认快捷键，注册未声明命令时记入 `undeclared.commands`。
- Rust 内核通过 `pluginKernel.syncHotkeys` 同步全局快捷键（Windows `WM_HOTKEY` / macOS `global_hotkey`），按键触发回调宿主执行命令，宿主停止时清理热键。
- 设置窗口快捷键页展示第 3 版插件命令快捷键，支持录制、冲突提示、清空与恢复默认。
- 单测、`pnpm check`、`pnpm build` 与 `cargo test` 通过。
