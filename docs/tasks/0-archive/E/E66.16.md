## 说明

E66.12 做了换歌提示的新卡片后还有几处没跟上，用户 2026-11-19 说都做，详情见 issue #1048。

1. 没有刘海的岛看不到播放软件的名字：把名字接在歌手后面。
2. 「收起条一行」的提示方式没有跟上：图标用封面，点了打开音乐页。
3. 其他插件的提示标题带用插件自己的图标。
4. 岛屿实验台的「插件通知」按钮点了没反应：修好并加「换歌提示」按钮。

## 验收

- 没刘海的岛上，换歌卡片的第二行是「歌手 · 播放软件名」；有刘海时不重复写
- 收起条一行的换歌提示图标是封面或软件图标，点了打开音乐页
- 只有一条插件提示时，标题带的图标是那个插件自己的图标；拿不到时才是铃铛
- 实验台的「插件通知」「换歌提示」按钮能让开发版的岛弹出对应的提示
- 回归页和单元测试覆盖

## 备注

- 「有标题带时不重复写」是用 CSS 做的：功能读不到岛有没有刘海，名字总是渲染，标题带在时隐藏。
- 插件图标的地址要宿主把清单里的 `fuyu.icon` 报给窗口，所以改了 `packages/plugin-base` 的状态（多一个 `icon`）。
- 实验台按钮修好后在真岛上试过一次能送达；之后真岛一直被别的会话的 Agent 提示占着，没截到新卡片。
