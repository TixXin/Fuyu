## 说明

IslandHeader 的圆点按钮改用页面项的数据，右侧按钮经 island.header/v1 注册，纯搬迁。

分步计划见 [v3-phase2-plan.md](/docs/architecture/plugins/v3-phase2-plan.md)。

## 验收

- PAGE_ICONS、HEADER_DOT_PAGES 的用法去掉
- 回归页和 DOM 快照一致

## 提交

- `refactor(island): the header's page dots come from the page items, HEADER_DOT_PAGES and PAGE_ICONS are gone (E36.2.6)`

## 备注

- 右边 6 个按钮（设置、消息、翻译、截图、复位、最小化）原样搬进 `src/windows/island/slots/header.tsx`，按现在从左到右注册到 `island.header/v1`（`order` 10–60，留出空隙给以后的插件项）。显示条件写成元数据 `enabled`，传进去的是右侧按钮要用的那包 props（`IslandHeaderContext`），不只是 `features`：翻译、截图按钮看的是 `onOpenTranslator`、`onScreenshot` 有没有给。`IslandHeader.tsx` 在 `pageActions` 后面用 `SlotView` 渲染，内置项不加包裹层。更新提醒的 `useUpdateReminder` 跟着设置按钮搬进它的组件，是同一个外部 store 的订阅。
- 圆点按钮用 `useSlotEntries(pageSlot)` 读页面项，`features.ts` 新的 `headerDotPages(items, features)` 挑 `headerDot` 为真、`enabled(features)` 为真的项按 `shortcutOrder` 排，图标用页面项的 `icon`。`PAGE_ICONS`、`HEADER_DOT_PAGES` 删了，`island-window` 单元测试改用 `headerDotPages`，多断言了一条关掉音乐、计时器后圆点少这两个。圆点的文字仍按页 id 查翻译（页面项没有标题字段）。
- 页头和 `features.ts` 一样依赖 `IslandPages.tsx` 顶上注册页面项的副作用 import；没让 `IslandHeader` 自己 import `slots/pages`，那会把各页面的组件和样式提前带进来、改变 CSS 顺序。
- 验证（两个提交各跑一次）：`pnpm check` 整串通过（单元测试 1353 个、0 失败、15 跳过）；`pnpm build` 通过；回归页 53 页全过、105 个快照一字不变（`bottom-island`、`notch-island`、`side-island`、`message-panel`、`music-lyrics` 等 10 页的快照里有页头的按钮和圆点）；`vite build` 产出的 14 个 CSS 文件和改动前逐字节相同。
- 真岛上看页头各按钮、圆点、关掉功能后按钮消失，记在 [v3-progress.md](/docs/architecture/plugins/v3-progress.md)「待人工验收」。
