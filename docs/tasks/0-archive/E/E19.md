## 说明

统一做法：操作成功后在触发它的那一行短暂显示结果，4 秒后消失（`src/components/settings/useFlash.ts`）；失败照旧显示错误；本身已经有明显变化的操作（开关、卸载、撤销权限、列表增删）不加提示。

## 验收

- 插件页「立即检查」：检查期间按钮显示「正在检查…」，结束后显示「已是最新（刚刚检查）」或「找到 N 个更新」。
- 插件页的重新加载、打开插件目录、内存上限、插件命令、清除数据，成功后在各自那一行显示结果。
- 设置窗口其他页同类按钮已检查，能改的已改，其余记在备注里。

## 提交

- `feat(settings): say what a click did when nothing else shows it: plugin update check, reload, folder, memory, command, clear data, and four more settings buttons`

## 备注

设置窗口其他页的检查结果（2026-11-12）：

改了的：

- AI 代理 → 远程电脑「立即刷新」：刷新期间显示「正在刷新…」并禁用，成功后显示「已刷新」。
- 通用 → 位置「复位」：点后显示「已复位」。这个操作只是通知岛屿，设置窗口这边不会失败。
- 插件 → 开发者，已加载插件的「重新加载」：成功后那个插件的按钮显示「已重新加载」。
- 翻译 → 服务密钥：替换已有密钥后显示「新密钥已保存」（原来前后都是「已保存」，看不出变化）；删除后显示「密钥已删除」。

没改的：

- AI 代理 → 提醒 → 手机推送（cc-connect）里「没有项目 / 没有会话」行的刷新：刷新后列表通常还是空的，看不出刷新过。本机的列表本来每 5 秒自动重读；刷新按钮同时走本机和远程两条读取路径，要把成功与否一路传回来，改动比别处大，以后按同一做法加「已刷新」。
- 插件详情页 cc-connect 小节的刷新图标：数据变了能看出来，没变就看不出；属于 cc-connect 功能，同上。
- 提示音「试听」：成功时能听到；失败只写进控制台（`sounds/player.ts`），以后可以把失败显示出来。
- 关于 →「退出」：成功时程序直接退出；失败只写进控制台，很少见，不改。
- 其余异步按钮（钩子安装、编辑器扩展安装、推送测试、音效包导入、预设和剪贴板的导入导出、设置备份、保存路径、日历、Inflink、更新诊断、检查更新、cc-connect 配置、主题市场、邮箱连接）已经有状态或结果提示，不用改。
