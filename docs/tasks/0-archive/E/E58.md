## 说明

来自 E36.6，见 v3-progress 决定记录 2026-11-19。这件事归插件开发总控管。

`docs/plugins/` 下第 2 版的插件作者文档（`README.md`、`runtime.md`、`api.md`、`publish.md`、`vscode.md`、`changelog.md` 等）从 2026-11-18 起顶上加了「已下线、只留作参考」，正文没动。官网的插件文档页、根目录 `README.md`（以及 `docs/readme/` 下各语言版本）的插件段、`docs/README.md` 还链着这些文档。要把入口换到第 3 版的 `docs/plugins/v3/`（现在已挪成 [docs/plugins/](/docs/plugins/README.md)），官网的插件文档也同步换掉，第 2 版文档归档或删除。第 2 版已经删了（E36.6.5、E36.6.6），第 3 版从 E54 起默认开启，新作者照着第 2 版文档写出来的插件装不上。

2026-11-19 并进 E60（插件页和插件市场页重设计，#911）：用户定了只有一套插件系统，就叫「插件」，面向用户和插件作者的文档里不再写「第 3 版」「v3」；架构历史文档 `docs/architecture/plugins/v3-*.md` 保留原样。所以这里不是「换成第 3 版」，而是把现在的文档当作唯一的插件文档：`docs/plugins/v3/` 里的内容挪成 `docs/plugins/` 的正文（改链接），第 2 版文档归档或删除；`docs/features/` 等功能文档里提到「插件（第 3 版）」「Plugins (v3)」的地方改成「插件」。

## 验收

- `README.md`（中文、英文）的插件段和 `docs/README.md` 指向第 3 版文档
- 官网的插件文档换成第 3 版，不再教第 2 版的写法
- `docs/plugins/`、`docs/features/`、`README.md`（含 `docs/readme/` 各语言）、`docs/README.md` 里不再出现「第 3 版」「v3」这类字样（架构历史文档、发布说明、归档文档除外）
- `docs/plugins/` 里第 2 版的文档归档或删除，仓库里不再有指向它们的入口链接（发布说明和归档文档除外）

## 备注

- 做法：`docs/plugins/v3/*.md` 用 `git mv` 挪成 `docs/plugins/*.md`（单独一个提交），第 2 版的十篇作者文档直接删除，不另建归档目录；要看旧文档，[迁移那篇](/docs/plugins/migrate-from-v2.md) 链到删除前的最后一版（`82c16e4027`）。正文里旧系统一律叫「旧版插件」，环境变量 `FUYU_PLUGINS_V3`、目录 `plugins-v3/`、市场文件 `index.v3.json` 这些真实名字照写。顺手把已过时的说法改掉：命令行和脚手架已经在 npm 上（2.0.0），市场 CI 已合入（fuyu-plugins#25），`fuyu-plugin dev` 已有（cli.md 补了 `dev` 一节）。
- 官网不在本仓库：在私有仓库 `TixXin/fuyu-site`，`src/data/docs.ts` 的 `DOC_FILES` 构建时从本仓库 `docs/plugins/` 按固定文件名取文档（`README`、`quickstart`、`manifest`、`ui`、`runtime`、`permissions`、`publish`、`api`、`changelog`、`vscode`）。本任务合入 `main` 后，那 8 篇不存在了，服务器上的自动构建会失败（`fetch.ts` 取不到就让构建失败），线上停在旧的第 2 版文档。要在 fuyu-site 把 `DOC_FILES` 换成 `README`、`package`、`cli`、`services-and-slots`、`publish`、`market-rules`、`review`、`migrate-from-v2`，并检查页面上写死的 SDK 链接（`plugins/sdk/`、`plugins/schema/`、`plugins/examples/` 都已删除）。交给 E60 组长安排。
- 范围外还指着旧路径、要别的会话改的：`docs/architecture/contracts.md`（链 `../plugins/v3/services-and-slots.md`）、`docs/architecture/plugins/sdk-release.md`（链已删的 `../../plugins/changelog.md`）、`docs/architecture/data-storage.md`（插件一行链 `docs/plugins/README.md` 讲的是第 2 版的数据）、`scripts/plugins-v3/pack-npm-sdk.mjs`（npm 包的文档地址和 `homepage` 写 `docs/plugins/v3`，下次发 npm 前改成 `docs/plugins`）、`scripts/land-check.mjs` 的 `CHECKED_DOCS`（`docs/plugins/api.md` 已删）、`packages/create-plugin` 的 README 和 `description` 还写 v3。
