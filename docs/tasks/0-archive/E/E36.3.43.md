## 验收

- 按计划「每个功能任务都按这个标准算做完」的 8 条：插件清单里有它、通用的三层「关掉」检查都过；插槽项都在 `src/features/<领域>/plugin/`、拥有者是它的 id；后台登记进开关表、关掉就真停；旧开关迁进 `plugins.yml` 并兼容旧值；不 import 别的功能；回归页快照不变或写明为什么变；插件页能开关；两个系统的待人工验收列好

## 备注

- 功能关掉时的统一规则：路由转给哪个内置插件，那个插件关着就回 503（待办 `todos`、Agent 状态 `agents`、剪贴板 `clipboard`），写在 `local-api.md`「功能关着时」和 `contracts.md`。这改掉了 E36.3.38 写的「待办关掉后接口仍可用」。
- 岛上接 `local-api-request` 的桥搬到不是插件的 `features/island-bridge/`（单独的纯搬迁提交）：第 2 版插件的待办调用和岛屿实验台也用它，关掉本机接口不能撤；`windows/island` 不准用 `import.meta.env`，放不进外壳。
- `agents/v1` 没有写的方法，`/v1/agent-status/*` 在 Rust 里照旧直接写，挡在 `agents` 开关后面；要不要给 `agents/v1` 加 `report`、`clear` 留到第三方插件真要时再定。
- 验证（2026-11-16，Mac）：`pnpm check` 通过（单元测试 1527 项）；`pnpm build`、`pnpm build:exe` 通过；Rust 单元测试 1107 项全过；Mac clippy `--all-targets`、Windows 交叉 clippy `--lib --tests` 0 告警；`pnpm test:regression` 除 `agent-sessions`（「⋯」盖 Agent 图标的像素检查）和 `clipboard-popup`（虚拟列表占位高 6353→6355px）外全过，这两页不碰本机接口；`builtins-off` 查 `local-api` 通过；`plugins-v3.html` 快照有意改了本机接口那行说明。
