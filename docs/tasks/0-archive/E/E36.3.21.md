## 说明

issue #551 写了全文。内置插件的宿主部分（`src/features/*/host/`）和基座的宿主（`packages/plugin-base/src/host/`）跑在 Node 里，规则（`src/AGENTS.md`、[v3-builtins.md](/docs/architecture/plugins/v3-builtins.md)「内置插件的宿主部分怎么写」）是不能 import 浏览器的东西和 `@tauri-apps/api`。现在只靠人看着：`pnpm lint` 是 `eslint src`，`no-restricted-imports` 只配在 `src/**/*.{ts,tsx}` 上，`host/` 里的 `.mjs` 不受限制；`packages/` 不在 lint 范围里。违反了要到宿主加载时才报错，开发时不设 `FUYU_PLUGINS_V3=1` 就发现不了。

要做的：

1. 给这两处加 `no-restricted-imports`：禁止 `@tauri-apps/*`、`react`、`react-dom`、`lucide-react`、`dompurify` 和 `src/` 里碰浏览器的模块；也可以反过来只放行本领域的纯函数、`@fuyu/*`、`node:*`。选哪种写进交接。
2. 加 `no-restricted-globals`：`window`、`document`、`localStorage`。
3. `pnpm lint` 或 `pnpm check` 覆盖这些 `.mjs` 和 `packages/plugin-base/src/host/`。
4. `v3-builtins.md` 后续表里 lint 那行改成已做；`src/AGENTS.md` 的 `host/` 说明加一句（先加载 `fuyu-skill-writing`）。

## 验收

- 在 `src/features/timer/host/` 里 import `@tauri-apps/api/core` 或用 `window`，`pnpm lint` 报错；现有代码 0 告警
- 有测试证明规则生效（例如 `tests/scripts/` 里对故意违规的样例跑 ESLint）

## 提交

## 备注

- 选的是禁止名单（`eslint.config.js` 末尾那段，说明在 `v3-builtins.md`「内置插件的宿主部分怎么写」）：放行名单要列每个领域的纯函数文件，E36.3.23 这类新加 `host/` 入口时都得改配置。
- 已知限制：lint 只看宿主文件自己的 import，它 import 的纯函数文件（如 `timers.ts`）再往下 import 了什么查不到，那一层靠打包和加载时的报错。
- 验证：`pnpm build` 通过；`pnpm check` 前面各步都过，单元测试 1374 个里 2 个失败，都在别的会话没提交的玻璃效果文件里（`src/windows/island/IslandGlassFlow.css`、`src/features/appearance/IslandPreview.css`：`light-island-colors`、`reduced-motion`），与本任务无关。
