## 说明

第 3 版默认打开之前必须完成。宿主脚本和内置插件现在不在安装包里：Rust 在开发版和 build:exe 里都从仓库路径加载 packages/plugin-base/src/host/main.mjs（plugin_kernel/mod.rs）。按 v3-node-runtime.md「让正式构建带上它」接线：prepare-release-config.mjs 生成的 tauri.release.conf.json 和 tauri.bundle-macos.conf.json 加 bundle.resources（宿主文件夹和 E36.3.6 的内置插件产物），三条发版构建路径在打安装包前跑 bundle-host.mjs；不加进 tauri.conf.json。Rust 正式版按 resource_dir() 找宿主和内置插件，开发版和 build:exe 仍走仓库路径。发版冒烟测试检查宿主文件。Node 运行时按决定 16 不随包、用电脑上的或下载（node_for_host 已接上），这里只核对签名公证后的 Mac app 和 Windows 安装版能用下载来的 Node。碰发版脚本，要完整打安装包验证。

分步计划：[v3-phase3-foundation-plan.md](/docs/architecture/plugins/v3-phase3-foundation-plan.md)。设计：[v3-node-runtime.md](/docs/architecture/plugins/v3-node-runtime.md)。

## 验收

- [ ] 两个系统打出的安装包里有宿主和内置插件
- [x] 装好的 app 开 FUYU_PLUGINS_V3=1 时从资源目录起宿主，加载内置插件和一个已安装的插件，仓库不在场也能跑
- [ ] 电脑上没有合适的 Node 时，下载的 Node 能被装好的 app 用起来（Mac 签名公证版、Windows 安装版各一次）
- [x] 开发版和 pnpm build:exe 不受影响
- [x] 发版冒烟测试检查宿主文件
