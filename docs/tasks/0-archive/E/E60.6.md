## 说明

依赖 E60.2（市场页，它在改设置窗口插件相关的文件）。起因同 E60.5：用户装了官方插件后找不到插件的设置，正在播放的命令只能靠快捷键触发。

- 官方插件的 `settings.section/v1` 都挂在分类 `pluginsV3` 下，但设置窗口没有任何地方渲染这个分组；插件行上的齿轮打开的详情弹窗「设置」标签只有 `PluginSchemaForm`（`PluginDetailModal.tsx`、`PluginDetailTabs.tsx`）。
- 齿轮直接进插件自己的设置：按插件 id 过滤后用 `SlotView` 渲染该插件注册的 `settings.section/v1`，和 `PluginSchemaForm` 并存。放在详情弹窗的「设置」标签里，还是插件页的子页，按 E60 的重设计定（`docs/design/settings.md`）。插件把 section 挂在哪个 category 下都能找到它（按插件 id 归属，不靠 category）。
- 详情弹窗「命令与快捷键」标签加「运行」按钮，调 `commandsClient.run`；运行失败给出提示。
- 回归页加第三方插件注册设置分组、命令运行的用例。

## 验收

- 装了带 `settings.section/v1` 的插件后，齿轮能进到它自己的设置并能改
- 命令标签能直接运行命令
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过
- 用户在开发版上：世界时钟齿轮进到它的设置；正在播放能从命令标签运行（另记待人工验收）
