## 说明

Rust 的 rpc.rs 现在把宿主发来的请求一律当通知，宿主调 Rust 只会等到超时。改成：请求交给登记的处理函数，在工作线程里跑，带超时和并发上限，回答或回错误；Rust 推给宿主的事件用通知 event；流式结果用调用 id 加进度通知；ready 报 protocol 2。宿主侧 ctx.rust.call / ctx.rust.on，受管，插件停用时撤掉。先手写两三个方法的分发表，宏留给 E36.3.4。plugin_kernel 和 supervisor.rs 等 E36.2.11 合入后再动。

分步计划：[v3-phase3-foundation-plan.md](/docs/architecture/plugins/v3-phase3-foundation-plan.md)。
