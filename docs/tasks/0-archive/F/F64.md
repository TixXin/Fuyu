## 说明

Mac 上常常同时开十几个代理会话，各自编译、跑 cargo test、开无头 Chrome 跑回归页，笔记本很卡。`pnpm heavy` 加远程模式：配置了远程 Windows 机器后，经过 heavy 的命令把工作区打成提交推过去，在远程的固定副本里排队执行，输出和退出码原样传回，远程改的文件打补丁拉回；连不上时退回本机。

## 验收

- Mac 上 `pnpm heavy -- cargo test …`、`pnpm test:regression <页>`、`pnpm test:changed` 实际在 Windows 上执行，结果和本机一致。
- 没提交的改动包括在内；远程改的文件（快照、生成文件）回到 Mac 工作区。
- 多个会话同时发起时分到不同副本或排队，互不覆盖。
- 远程连不上时自动退回本机。
- 文档写明配置、关闭办法和 Mac 专属代码靠什么检查。
