## 说明

delete_branch_on_merge 只删合入的 PR 的分支；手动关的被取代 land PR（#608、#640、#645、#652、#664）和 mq:try 的 try/ 分支没人删。做法见 #697：land 开新 PR 后关掉本机前缀、head 已被新 PR 包含的旧 land PR 并删分支，正文写「取代 #N」；mq:try --wait 后删这次的 try 分支，新增 mq:try --clean；workflow.md「排障」加手动关 land PR 用 --delete-branch。
