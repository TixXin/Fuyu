## 说明

Mac 那台机器的内核主机名跟着网络变（没设固定的 HostName），机器名取自 os.hostname()，所以同一台机器用过 tixxindeair 和 tixxindemacbook-air 两个名字，11-13 以来换了 5 次。名字一变，本机会话把自己早先认领的任务当成别人的，land 分支名也跟着变（mq:wait 不写 PR 号时找不到刚开的 PR）。Windows 的主机名是电脑名，不受影响。

做法：机器名只在 scripts/machine-name.mjs 里算，认领和 land 分支名用同一个函数；第一次用到时记在本地 git 配置 fuyu.machine 里，以后照用（Mac 上第一次取 scutil --get LocalHostName，其他系统取 os.hostname()）；同一台机器用过的旧名字记在 fuyu.machineAlias 里，任务的 host 等于本机名或任一别名都算本机，mq:wait 不写 PR 号时按别名再找。

## 验收

- 这台 Mac 换网络后机器名不变：`fuyu.machine` 已写下 `tixxindemacbook-air`，系统报别的主机名时仍返回它（单元测试和本机实测）
- 旧名字下的认领仍算本机的：B29、B47 的 `host` 是 `tixxindeair`，加了别名后 `claimState` 判为本机
- `node --test tests/scripts/tasks.test.mjs tests/scripts/mq.test.mjs tests/scripts/machine-name.test.mjs`、`pnpm check`、`pnpm build` 通过

## 备注

- 原因：这台 Mac 没设固定的 HostName，内核主机名由系统在每次网络变化时重新决定。系统日志里 11-15 06:30:52 换网络后主机名被设成 `TixxindeMacBook-Air.local`，落在两个名字交替的那段时间里。另一个网络上是 DHCP 还是反向解析给出 `TixxindeAir`，没查到（日志已不在）。
- 固定下来而不是每次读 `scutil --get LocalHostName`：改电脑名或局域网重名（系统自动加 `-2`）时 LocalHostName 也会变。
- 这台 Mac 的本地配置已经设好：`fuyu.machine = tixxindemacbook-air`，`fuyu.machineAlias = tixxindeair`。配置在 `.git/config` 里，发版目录 `../Fuyu-release` 是同一个仓库的 worktree，读到的是同一份。
- Windows 上没实测。Windows 走 `os.hostname()`，名字和以前一样（`tixxin-computer`），只由单元测试里的 win32 用例覆盖。Windows 那台拉到这次改动后第一次跑 `pnpm tasks` 的认领或 `pnpm mq:land` 时会写下 `fuyu.machine`，到时 `git config fuyu.machine` 应是 `tixxin-computer`。
- `scripts/mq/landLock.mjs` 锁文件里的 `host` 仍是 `os.hostname()`，只作记录，不参与判断，没动。
- land 没有为别名做处理：名字固定后不再变，改动时旧名字下没有开着的 PR。
