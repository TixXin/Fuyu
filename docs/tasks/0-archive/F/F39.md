开发版（`pnpm tauri dev`）和安装的正式版要能同时开着、一眼分得清、互不损坏数据。F38 的 `pnpm dev:side` 解决了能同时开，2026-11-14 核实后还剩这些问题：两个岛长得一样；开发版会检查更新并可能覆盖正式版；凭据共用；快捷键、Win+V、审批端口、本地接口端口谁先启动归谁；提醒可能各弹一次。
