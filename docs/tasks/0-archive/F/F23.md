## 说明

WorktreeCreate 钩子只拿文件夹不存在的编号，每次 /clear、重启或新会话都新建一个 lane，2026-11-12 积到 27 个。回收靠钩子记下的 `claude.exe`，但大多数 lane 没有这条记录（启动方式不同时找不到这个父进程），land 时永远不删。改成先复用空闲的 lane。

## 验收

- 新会话、/clear 后、重启后都复用空闲的 lane，lane 数量大致等于同时开的会话数
- 有未提交文件、未合入提交，或有进程在里面的 lane 不会被复用
- 补丁升级时丢掉 lane 池会被测试发现

## 提交

- `build(lanes): reuse idle lanes instead of creating a new one per session`
