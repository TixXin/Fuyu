## 说明

PR #640 的 Windows CI 上，Rust 测试程序一启动就报 0xc0000139：日历服务（E36.3.30，8d3d998c）用了 `#[host_service(..., inject(app))]`，静态登记把 `AppHandle` 留进测试程序，链进了 tauri 运行时和窗口相关的 DLL。Windows 上没有 manifest 的测试程序起不来，Mac 上照常，本机发现不了。c811bcbf 已改用 `crate::home_dir::current()`。插件系统总控 2026-11-16 定：宏在编译时就挡住，不靠 CI。

宏在 `src-tauri/crates/plugin-base-macros/`。遇到 `inject(app)` 时用 `compile_error!` 报错，报错信息指向 [v3-services.md](/docs/architecture/plugins/v3-services.md) 的替代写法；别处还有 `inject(app)` 的一起改掉；文档里的示例和参数说明改成新写法；加一个编译失败的测试（trybuild 或宏 crate 现有的测试办法）。

## 验收

- 写了 `inject(app)` 的服务编译不过，报错信息说明替代写法
- 编译失败的测试在 CI 的 Windows 和 Mac 上都过
- `v3-services.md` 改好
