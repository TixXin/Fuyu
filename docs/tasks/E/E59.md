## 说明

来自 E36.6，见 v3-progress 决定记录 2026-11-19。这件事归插件开发总控管。

第 2 版 SDK `fuyu-plugin` 0.7.0 自带 `fuyu-plugin mcp`：一个走 stdin/stdout 的 MCP 服务，让 Claude Code、Cursor 读写岛屿的本地接口。E36.6.6 删掉了 `packages/fuyu-plugin`，而 npm 上 `fuyu-plugin` 2.x 是第 3 版的命令行（`packages/plugin-cli`），里面没有 `mcp`，所以 [local-api.md](/docs/features/local-api.md) 暂时写成 `npx -y fuyu-plugin@0.7.0 mcp`（2026-11-18 核实 npm 上的 0.7.0 带 `src/mcp.mjs`）。0.7.0 已经没人维护。要把 `mcp` 搬进 `packages/plugin-cli`，工具清单按本地接口现在的样子核对一遍，发新版后把文档改回 `npx -y fuyu-plugin mcp`。

## 验收

- 第 3 版命令行能用 `npx fuyu-plugin mcp` 启动 MCP 服务，工具覆盖本地接口现有的读写
- `packages/plugin-cli` 里有它的测试
- `docs/features/local-api.md` 改回不带版本号的命令
- `pnpm check` 通过
