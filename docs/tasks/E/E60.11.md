## 说明

用户 2026-11-19：「插件市场的权限应该去掉，现在没有权限系统」。截图里市场卡片底部写着「不联网 · 3 项权限」。发版前要做。

浮屿现在没有插件权限系统：第三方插件不隔离，窗口的 CSP 放行任意 http/https，清单里的 network 白名单也不执行（`docs/investigations/plugin-release-readiness.md` S1）。界面上写「N 项权限」，等于给了用户一个做不到的保证。

- 界面上不再出现「权限」：去掉市场卡片上的「N 项权限」（`PluginMarketCard.tsx`），去掉市场详情的「权限」标签（`PluginMarketDetailTabs.tsx`、`PluginMarketPermissions.tsx`），去掉插件页详情的「权限」标签（`PluginDetailModal.tsx`）。
- 「联网 / 不联网」标签保留（用户 2026-11-19：「联网标签留着」），不在本任务范围。
- 清单里对用户还有用的信息，如实放进详情的「概览」，标题用「它会做什么」一类，不暗示浮屿会拦：会替换哪个内置功能（`replaces`）、会连哪些域名、要用哪些 Node 能力。
- 安装确认（`PluginInstallConfirmModal.tsx`）如果只剩这些，简化成一句话或者去掉，按设计定，先改 `docs/design/settings.md` 再动代码。
- 文案在 `src/i18n/sections/settings/pluginMarket.ts`、`pluginPage.ts`；不用的文案键删掉。
- 文档：`docs/design/settings.md`，以及 `docs/plugins/` 里提到「权限」的地方（README、package、cli、publish、review、migrate-from-v2）。清单字段名（`permissions` 之类）是给开发者的契约，不改名，只把说法改成「声明」而不是「权限」。
- 和 E63.8（被撤销插件的界面，可能碰 `InstalledPluginRow.tsx`）可能重叠，开工前和正式版前插件修复组长对一下文件。

## 验收

- 设置窗口的插件市场、插件页、安装确认里，中英文都不再出现「权限」/ permission；「联网 / 不联网」标签照旧
- 详情「概览」如实列出替换的内置功能、连接的域名、用到的 Node 能力，没有的就不显示
- 设计文档和插件文档同步；回归页快照更新
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过
