## 说明

B2：`market/v1` 不检查调用方，`uninstall` 传 `@x/..` 能删掉整个 `packages/`，勾了删数据还会删整个 `data/`（`packages/plugin-cli/src/installer.mjs` 的包名正则）。

改法：包名两段拒绝只由点组成的名字；卸载只接受已装列表里的 id；卸载、从文件安装、手动安装开关等改磁盘的方法只接受设置窗口发来的调用。

## 验收

- 单元测试：`@x/..`、`@x/.`、未安装的 id、非设置窗口和插件的调用都被拒；设置窗口里卸载、从文件安装、改手动安装开关照常
- `pnpm check`、`pnpm build` 通过，附 `pnpm mq:try` 的 Windows run
