## 说明

重新设计设置窗口里的「插件」页和「插件市场」页。用户 2026-11-19 的要求：现在的插件页设计得不好；内置模块不该出现在插件页里；界面和文档里不再出现「第 3 版」「v3」这类字样（第 2 版已经删了，只有一套插件系统，就叫「插件」）；两页的布局都重做，细节要顾到。

用户看过预览页 [`docs/investigations/plugin-pages-preview.html`](https://github.com/TixXin/fuyu/blob/main/docs/investigations/plugin-pages-preview.html) 后同意按推荐做：

1. 插件市场回到侧栏「扩展」下单独一页（和 11-07 的 D10 一致），插件页不再有标签。
2. 运行诊断（插件进程、内存、CPU、全部模块的运行表、二分排查）平时不显示：出问题时插件页顶上出提示条，点进「插件 › 运行诊断」子页；⋯ 菜单里常驻入口。
3. 已装插件一行一个，不再两列卡片。
4. 代码里的内部名字（组件、CSS class、文案文件）在最后单独一个 refactor 提交里改；对外契约不改（设置分类 key `pluginsV3`、数据目录 `plugins-v3/`、环境变量 `FUYU_PLUGINS_V3*`）。
5. 架构历史文档（`docs/architecture/plugins/v3-*.md`）里的「第 3 版」保留，只改面向用户和插件作者的文档。
6. 插件页底部一行脚注：自带功能不算插件，在「概览」里开关。
7. 插件行上加「重启」（停用再启用）和「查看日志」（详情里看完整的最近出错，可复制）。
8. 「从文件安装」从折叠区挪到市场页头的按钮。
