## 说明

插件平台第 3 版第 5 阶段（#295）的地基：第 3 版插件的清单和 `.fuyu` 安装包格式，做成新包 `packages/plugin-manifest`（`@fuyu/plugin-manifest`）。第 3 阶段的 E36.3.9（宿主按清单加载插件）要用它，所以先把校验函数的接口单独合入。

- 清单（`package.json` 的 `fuyu` 键）的 JSON Schema 和校验函数：必填项、名字规则（第三方必须 `@<仓库所有者>/<名字>`，`@fuyu/*` 留给官方）、`engines.fuyu`、未知字段告警
- `.fuyu` 包的读写：确定性 zip（排序、固定时间戳、文本统一 LF）、20 MB 上限、禁止 `.node`、可执行程序、`node_modules`、符号链接和 `..` 路径
- 包的摘要（按文件路径和各自 SHA-256 算，签名文件不计入）和包内的签名文件格式（作者签名、市场签名）及校验
- 浮屿专有的名字（`fuyu` 键、`.fuyu` 后缀）做成可配置的
- 格式写进 `docs/architecture/plugins/v3-package.md`

## 验收

- 校验函数的接口（类型声明加最小实现）先单独合入，通知第 3 阶段地基
- 单元测试覆盖每条规则和一组坏包
- `pnpm check` + `pnpm build` 通过
