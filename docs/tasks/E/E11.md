## 说明

E10 修好了 PowerShell 插件 SDK 等待消息的超时（Windows PowerShell 5.1 的 `[Console]::In.ReadLineAsync()` 是同步阻塞的，改成 `StreamReader` 包住 `[Console]::OpenStandardInput()`），只发布了系统监控 1.0.2。还没换上的：

- `plugins/examples/` 下 github-issues、now-playing、pomodoro、todo-digest、todo-ring 的 `lib/focusd.ps1`：它们是旧版库，不能整份覆盖，只改 `Read-FocusdLine` 和顶部读取器（同 E10 提交里系统监控那几行）。改了内容要升 `version`，`pnpm plugins:index` 才肯打包；再到 `TixXin/focusd-plugins` 改包地址。
- npm 包 `fly-island-plugin` / `create-fly-island-plugin`（带 PowerShell 模板的 SDK）和 PowerShell 模块 `FlyIsland.Plugin` 发新版。

用户 2026-11-09 决定：先等系统监控 1.0.2 在用户机器上确认，再发这些。
