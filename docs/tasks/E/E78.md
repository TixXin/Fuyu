## 说明

开源基座 [`TixXin/tauri-cordis`](https://github.com/TixXin/tauri-cordis) 发到 0.2.0 了，但仓库的门面还是一张规格表，和浮屿之间没有互相引用。2026-11-19 的现状：0 star，没有 topics 和 Discussions，6 个 npm 包没有 `keywords`；README 没有示例代码，快速开始要克隆仓库且看不到窗口；没有回答和 `tauri-plugin-*` 的关系、为什么带 Node、安全模型；`docs/guarantees.md` 是中文的，路径还是浮屿仓库的；没有 `CONTRIBUTING`、`CHANGELOG`、`SECURITY.md`；浮屿的中英文 README 没提到 Cordis 和 tauri-cordis。

两边读者不同（浮屿是用户，tauri-cordis 是开发者）：tauri-cordis 在首屏引用浮屿当作真实案例，浮屿在「插件」一节和致谢里引用 tauri-cordis，不放首屏。

## 验收

- tauri-cordis：README 重写（英文加简体中文），npm 包的 README 单独写；概念、接入、写插件、安全模型、稳定性几份文档；保证清单出英文版并改对路径；`CONTRIBUTING`、`CHANGELOG`、`SECURITY.md`、issue 模板；带窗口的 Tauri 示例应用；topics、`keywords`、Discussions。
- 浮屿：README（中、英）和插件文档入口链接 tauri-cordis；`fuyu-plugins` 的 README 和官网插件页各一个链接。
- 对外发声只起草，发不发由用户定。
