## 说明

源自 [fly-island-issue-76.md](/docs/research/fly-island-issue-76.md)（对应第 4 项）：低频查单词的新用户不想为了查个别英文词汇先折腾云厂商大模型 API Key，而必应/谷歌网页免 Key 接口属于非官方逆向接口，不宜内置进宿主核心。

基于 [E36.4.2](/docs/tasks/0-archive/E/E36.4.2.md) 已落地的 `ctx.translatorEngines.register`（`translator/v1`）接缝，在 `plugins/v3/official/ecdict/` 新增 MIT 许可的官方插件 `@fuyu/ecdict`（数据源基于开源 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可，须在插件 `README.md`、`LICENSE` 与仓库 [THIRD_PARTY_NOTICES.md](/THIRD_PARTY_NOTICES.md) 保留声明）：

1. 通过 `ctx.translatorEngines.register` 注册免密钥引擎 `ecdict`（`hasSecret: true`，中英文名称「ECDICT 离线词典 / ECDICT Offline Dictionary」），启用后直接出现在「设置 → 翻译 → 翻译服务」下拉框中，零配置开箱即用。
2. 内置经过体积精简的常用英汉核心词表（控制在轻量包体积内，含音标、词性释义与基础词形变化映射如复数/过去式/进行时还原），离线毫秒级查询：
   - 输入英文单词或短语时返回音标、词性与中文释义、常见词形还原说明；
   - 输入简短中文词组时支持反向匹配对应英文词条；
   - 输入整段长句超出词典收录时，返回清晰友好的中英文提示（引导长句翻译切换到大模型或翻译服务插件）。
3. 插件停用时自动注销 `ecdict` 引擎，符合官方 v3 插件打包与校验规范（`fuyu-plugin build --official`、`fuyu-plugin check --official --market`）。

## 验收

- `plugins/v3/official/ecdict` 通过 `pnpm build`、`fuyu-plugin check --official --market`、类型检查与插件测试
- 注册引擎 `ecdict` 无需配置任何 API Key 即可完成英查中（含大小写不敏感与基础词形还原）、简明中查英及未命中提示，停用插件后引擎自动移除
- 补齐单元测试与第三方开源许可声明（[THIRD_PARTY_NOTICES.md](/THIRD_PARTY_NOTICES.md)），无网络权限声明（纯本地离线运行）
