## 说明

依赖 E60.5、E60.6。归插件开发总控管（`plugins/v3/official/`）。

E60.5 给 `island.page/v1` 加了标题字段、E60.6 让设置窗口按插件 id 渲染插件自己的设置后，官方插件跟着补上：岛页面带中英文标题（需要时给出切页顺序），设置分组换成合适的 category（或保留，看 E60.6 的做法），收起项给出宽度，给常用命令（例如正在播放的 `show`）考虑默认快捷键。改完重新打包、签名、上架到 `index.v3.json`（照插件开发总控的发布流程）。

分工（2026-11-19 和插件开发总控商定）：代码由 E60 组长派会话做，上架由插件开发总控做。会话的范围是 `plugins/v3/official/` 里要补字段的插件（世界时钟、系统监控、正在播放，以及其他注册了岛页面或设置分节的），每个插件 `version` 加一档、写 changelog，跑插件自己的测试和官方插件套件测试（E36.6.3 那个），提交后报全局合入。不用签名：`@fuyu/*` 不带作者签名，CI 校验提交号在 TixXin/fuyu 的 main 上。做完在本任务「备注」列出改了哪些插件、新版本号、功能提交号，并告诉插件开发总控；合入后它在 TixXin/fuyu-plugins 开 PR 给 `plugins/v3/official/<名字>.json` 的 `versions` 加行，检查通过、批准合入后 Publish v3 构建并签名 `index.v3.json`。
