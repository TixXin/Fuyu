## 说明

系统监控插件打开「后台记录曲线」后，监控页关着时也每秒读一次 CPU、GPU 和网速，保留最近 5 分钟。实测这时插件的 PowerShell 进程一直占约 14% 单核。用户希望后台记录轻一些：每 5 秒读一次，曲线只带最近 1 分钟。这个开关默认就是关的，不变。

做法：后台（页面关着）每 5 秒读一次，只留最近 1 分钟；页面打开时照旧每秒刷新。页面打开时发过去的历史按秒展开，曲线的时间轴不变形。同步改设置说明、README、CHANGELOG，版本号升到 1.3.1。

## 验收

- 后台记录时插件进程的 CPU 有前后对比。
- 打开监控页时曲线带着最近 1 分钟，之后每秒接着画。
- 设置说明和 README 的中英文都改了。
- 需要打包签名。
