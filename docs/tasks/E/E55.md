## 说明

将第 3 版插件 CLI、服务类型、模拟宿主与项目脚手架打包并通过 GitHub Actions OIDC Trusted Publishing 发布为 `fuyu-plugin@2.0.0` 与 `create-fuyu-plugin@2.0.0`，让外部作者无需克隆浮屿仓库即可通过 `npm create fuyu-plugin@latest` 开发、测试、打包并上架第 3 版插件；同时更新市场工具链并通知第三方插件作者迁移。

## 验收

- `scripts/plugins-v3/pack-npm-sdk.mjs` 生成自包含、零 `workspace:*` 依赖的 `fuyu-plugin` 与 `create-fuyu-plugin` 2.0.0 发布包，附带完整 `.d.mts` 类型声明，独立临时目录脚手架 + `tsc` + `eslint` + `fuyu-plugin check` + `fuyu-plugin pack` 端到端单测通过。
- `bundle.mjs` 支持 `fuyu-plugin/services`（含市场裸构建回退解析），窗口与宿主代码均可正常使用。
- `.github/workflows/publish-sdk.yml` 推送 `sdk-v2.0.0` 标签后成功通过 npm Trusted Publishing 发布 `fuyu-plugin@2.0.0` 与 `create-fuyu-plugin@2.0.0`。
- `TixXin/fuyu-plugins` 更新 `market/v3/tools.json`，并向 `ShengLin1001` 发送第 3 版迁移说明。
