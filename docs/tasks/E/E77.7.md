## 说明

1. 装完一个插件，用户不知道它出现在哪。安装成功后让岛把新出现的位置（收起条那一格或新页面的页头按钮）亮一下。
2. 换歌提示这类高频提醒需要能单独关：插件页每个会发岛上提醒的插件有一个「岛上提醒」开关，关掉后它的提醒不弹，别的插件不受影响。

这两件都要改岛和消息的接线，和进行中的 E66.12、E66.13 是同一批文件，等它们结束再做。

## 验收

- 装完带岛上界面的插件，岛上对应位置有一次不打扰的提示动画，开了「减少动画」时不动
- 每个会发提醒的插件能单独静音，重启后记得住
- 回归页有断言

## 备注

- 建议的范围（认领时写进 `--scope`）：src/windows/island/, src/features/messages/island/, src/features/plugin-kernel/
- **第一件（单独静音）已做完**，提交 `feat(plugins): mute a plugin's island alerts from its detail page (E77.7)`。拦的位置是岛窗口消息插件的 `src/features/messages/plugin/services.ts`（岛窗口里的 `messages/v1` `notify` 和宿主转来的通知都经过这里）；名单存 `localStorage` 的 `fuyu-plugin-notice-mutes`，岛每次收到通知时读，所以不用事件。开关在插件详情的「概览」里，那一行的「岛上提醒」标签在静音时显示成「提醒已静音」。
- 第一件已知的限制：静音按通知上的 `pluginId` 匹配，插件没写时它是 `source`；官方插件都写了自己的包名。第三方插件用了别的 `source` 又不写 `pluginId` 的，开关关了也拦不住。要补的话在宿主的 `src/features/messages/host/index.mjs` 用调用方的身份（服务方法的第二个参数 `{ plugin }`）盖掉自报的 `pluginId`，但这会改 `messages/v1` 的 `action` 事件里的 `source`，是契约变化，没在这次做。
- 第一件的实测清单（本机没有真岛：代理不跑 `pnpm tauri dev`）：
  1. 开着「换歌提示」插件播歌并切歌，确认岛上弹换歌提示；设置 → 插件 → 换歌提示 → 详情「概览」，关掉「岛上提醒」，不关设置窗口直接再切歌：岛上不再弹，已装列表那一行的标签变成「提醒已静音」。
  2. 保持静音，让另一个会发提醒的插件发一条（闹钟到点，或番茄钟一轮结束）：照常弹。
  3. 退出浮屿再打开，切歌：仍然不弹；详情里的开关仍是关的。
  4. 打开开关，再切歌：马上又弹。
  5. 静音时在换歌提示的命令里点「立即提示当前歌曲」：不弹，也不报错。
  6. 设置 → 数据与备份导出设置，导出的文件里有 `fuyu-plugin-notice-mutes`；恢复这份备份后静音还在。

  1. 触发：`src/windows/settings/usePluginInstallFlow.tsx` 的 `confirm` 成功、且不是更新（`kind !== "update"`）时，设置窗口发一个新的 Tauri 事件 `island-plugin-spotlight`（`emitTo("main", …)`，载荷 `{ pluginId }`）。事件名和载荷校验放新文件 `src/features/plugin-kernel/islandSpotlight.ts`，照 `islandPageRequest.ts` 的写法；`requestIslandPluginSpotlight` / `listenIslandPluginSpotlight` 加在 `src/features/plugin-kernel/api.ts`；事件写进 `contracts.md` 的事件表。
  2. 岛上的状态：`islandSpotlight.ts` 里一个小 store（`useSyncExternalStore`），记 `{ pluginId, until }`。收到事件时这个插件的界面文件多半还没加载完，所以先记成「待亮」，15 秒内等到它的 `island.collapsed/v1` 项或 `island.page/v1` 页面登记出来再亮，过期丢掉，亮过一次就清。岛收起着亮收起条那一格，展开着亮页头按钮；两处都没有的插件（只有设置、只发提醒）不亮。
  3. 加在哪：收起条那一格在 `src/features/plugin-kernel/SlotView.tsx` 的 `wrap`（外部项外面的 `<div class="plugin-slot" data-slot>`）上加 `data-owner` 和 `data-spotlight`，不用改 `collapsedBarItems.tsx`；页头按钮在 `src/windows/island/IslandHeader.tsx` 的 `dot-button--plugin`（已有 `data-page`），拥有者对上时加 `dot-button--spotlight`。C139.2 加了收起条放不下时的「+N」：新插件那一格被收进「+N」时要改成亮「+N」按钮，这一处要在它的 `CollapsedMore.tsx` 上加，所以必须等它提交。
  4. 动画（先加载 `fuyu-motion` skill）：只动没有文字的装饰层，不位移、不缩放。`::after` 伪元素画一圈强调色描边加柔光，`opacity` 0 → 1 → 0 闪两下，一下 `var(--motion-slow)`、曲线 `var(--motion-ease-in-out)`，`animation-iteration-count: 2`、`animation-fill-mode: backwards`，不循环；`animationend` 时清掉 `data-spotlight`。样式写在 `src/features/plugin-kernel/PluginSlot.css` 和 `src/windows/island/IslandHeader.css`，各自在同一个文件里加 `@media (prefers-reduced-motion: reduce)` 把这个 `animation` 关掉（不闪、也不留描边）。
  5. 不打扰：不展开岛、不抢焦点、不弹提醒；岛贴边收起或隐藏着时不唤出，等不到就过期作废。
  6. 测试：待亮的匹配和过期是纯函数，单测；`collapsed-slots` 或 `plugin-slot` 回归页断言收到事件后那一格有 `data-spotlight`、动画结束后没有、减少动画时始终没有；`plugin-page` 回归页断言装完发了 `emit:island-plugin-spotlight`、更新不发。真岛上亮一下的样子要进实测清单。
