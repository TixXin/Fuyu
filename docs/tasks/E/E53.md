## 说明

对照 `docs/architecture/plugins/v3-everything-plugin.md`「下线什么：插件自己的窗口（E34，实验）→ 用新接口重做成服务 `ctx.windows`」，在 `fuyu.experimental: ["windows/v1"]` 实验门禁下提供跨平台独立插件窗口能力。

## 验收

- 宿主提供 `ctx.windows`（`create`、`update`、`show`、`hide`、`focus`、`close`、`list`、`onEvent`，要求内置插件或声明 `fuyu.experimental: ["windows/v1"]`）与 `plugin-windows/v1` 规则管理服务；新增实验插槽 `plugin.window/v1`。
- Rust 内核 `pluginKernel.windowOpen` / `windowControl` / `windowList` 管理独立插件窗口，强制单插件上限 8、全局上限 24，插件停用或宿主停止时自动销毁全部窗口。
- 前端 `?window=plugin-window` 入口为 `overlay` 窗口绘制宿主受控护栏标题条（显示插件名与关闭按钮），并注入 `SLOT_THEME` 主题变量；插件详情弹窗提供「不允许置顶 / 不允许点击穿透 / 隐藏全部窗口」三项开关。
- 单测、`pnpm check`、`pnpm build` 与 `cargo test` 通过。
