## 说明

计划「关键设计」第 2 条，纯搬迁。`src/windows/island/slots/` 里各功能的注册搬到 `src/features/<领域>/plugin/island.tsx`，窗口用 `import.meta.glob(..., { eager: true })` 收集；新加 `island.notice/v1`、`island.runner/v1`，把 `islandNotice.tsx` 的提示、外壳里直接 import 的会议行、设备弹窗、音量弹窗、歌词，以及 `IslandApp.tsx` 里的接线 hook 改成插槽项；外壳要读的功能状态改成元数据。拥有者暂时仍是 `builtin`。

计划见 [v3-phase3-plan.md](/docs/architecture/plugins/v3-phase3-plan.md)。

- `v3-boundary.md`「插槽」一节加上新插槽
