## 说明

按用户 2026-11-19 同意的预览 [预览页](/docs/investigations/plugin-pages-preview.html) 重做设置窗口的「插件」页。

- 插件页只列用户装的插件（官方市场、第三方、本地导入），22 个内置模块完全不出现；一行一个，行上有开关、⚙（打开详情的「设置」）、⋯ 菜单、状态提示条（出错、需授权、换钥、被撤销、等依赖等），出错的行有「重启」（停用再启用）和「查看日志」。
- 工具栏：搜索已装插件，筛选「全部 / 已启用 / 已停用 / 需处理」；右上角「浏览插件市场」。空状态引导去市场。
- 详情弹窗 5 个标签：概览、设置（`PluginSchemaForm`）、命令与快捷键（读 commands/v1，「改」跳快捷键页）、权限（含窗口权限守卫）、运行情况（用量、完整的最近出错，可复制）；底栏卸载两步确认。
- 运行诊断：平时不显示；出问题时（任一插件出错或被暂停、插件进程没连上、安全模式、运行环境下载失败）页顶出提示条，点进「插件 › 运行诊断」子页（宿主状态、全部模块含内置的运行表、二分排查）；⋯ 菜单常驻入口。设置搜索能搜到子页。
- 运行环境（Node）下载中 / 失败、安全模式改成页顶提示条；旧插件迁移卡挪到页顶、可折叠，去掉版本字样和内部 id。
- 页底脚注：自带功能不算插件，在「概览」里开关，点了跳过去。
- 侧栏名「插件（第 3 版）」改成「插件」，搜索词去掉「第 3 版 / v3」；插件市场拆成侧栏「扩展」下单独一页（这一步只搬，市场内容由 E60.2 重做），插件页和市场页互相跳转；双击 `.fuyu` 的事件 `plugin-package-open` 改为打开市场页。分类 key `pluginsV3` 不变（`fuyu-settings-focus` 和旧链接照样能打开）。
- 界面文案里所有用户能看到的「第 3 版」「v3」「宿主」「plugins-v3」「FUYU_PLUGINS_V3」等内部字样换成人话（含 `sessionRing.ts` 里的「设置 → 插件（第 3 版）」）。
- 先认领并提交 11-18 留下的未认领改动（市场卡片「需要更新浮屿 / 不支持当前系统」、搜索清除按钮等，用户 2026-11-19 同意并入），再做重设计。
