## 说明

第 4 阶段第 1 批。`agents/v1` 支持插件贡献外部会话列表、窗口聚焦器与额度来源；会话环、用量环与 Agent 页无感汇总。

计划见 [v3-phase4-plan.md](/docs/architecture/plugins/v3-phase4-plan.md)。

## 验收

- 支持插件向 `agents/v1` 注册外部 Agent 会话提供者与自定义 `focus` 处理器，停用插件后会话自动撤除
- 支持插件贡献自定义额度数据，汇总进 `agents/v1.usage()`
- 单元测试验证外部插件贡献的会话与额度能被 Agent 页、会话环、用量环与截图「发给 Agent」消费
