## 说明

应用自带一份内置插件清单，宿主把它和数据目录的 plugins.yml 合起来：内置的默认开、kind 由清单定，plugins.yml 只记开关和配置。内置插件宿主部分写在 src/features/<功能>/host/（TypeScript），构建时打成 .mjs 随安装包带上，开发版从源码加载、能热重载。Rust 拉宿主时多传内置目录（排在 E36.3.3 之后）。界面上的开关等插槽。

分步计划：[v3-phase3-foundation-plan.md](/docs/architecture/plugins/v3-phase3-foundation-plan.md)。

## 验收

- [ ] 关掉一个内置插件后它的服务、定时器、监听器、界面文件全撤
- [ ] 用户写的条目不能把第三方插件冒充成 builtin
- [ ] 正式构建的产物里有内置插件，pnpm build 前后时间记进任务
- [ ] 前端和 Rust 的验证都通过
