## 说明

方案里试用的第 0 步。做一个最小的沙箱 iframe 试用页（sandbox=allow-scripts，不给 allow-same-origin），在 Windows 和 Mac 的设置窗口里各打开一次，逐项试：看不看得到 window.__TAURI_INTERNALS__、window.ipc、chrome.webview、webkit.messageHandlers；能不能调通 Tauri 命令；能不能连宿主的 WebSocket；fetch、图片、WebRTC、表单、导航；死循环时设置窗口卡不卡。结果写进 docs/investigations/，结论补进 docs/research/plugin-bundles-and-try-before-install.md：都碰不到就照方案 (b) 另建实现任务（先官方、作者选择加入），任何一项能碰到就退回只看截图。两台机器都要测。

**要在真机上做**（2026-11-19）：代理不跑 `pnpm tauri dev`，下面的清单给用户或有真机的会话照着做，Windows 和 Mac 各做一遍。E77.6 的示例数据合入之前也能做，这一步不需要它。

## 备注

### 真机验证清单

不用写代码：用开发者工具造一个沙箱 iframe，再把控制台切到它里面执行探测脚本。控制台里执行的脚本不受页面的 CSP 限制，所以测的是「这个框架里的脚本够得到什么」，正是试用页的情况。

**准备**

1. `pnpm tauri dev` 启动开发版，打开设置窗口，在窗口里右键 → 检查（Windows 也可以按 F12），打开控制台。
2. 在控制台（上下文是顶层页面）执行，造出两个沙箱框架，并记下宿主的端口：

   ```js
   const mk = (id, attrs) => { const f = document.createElement("iframe"); f.id = id; f.setAttribute("sandbox", "allow-scripts"); Object.assign(f, attrs); f.style.cssText = "position:fixed;right:8px;bottom:8px;width:220px;height:80px;z-index:99999;background:#fff"; document.body.append(f); };
   mk("probe-srcdoc", { srcdoc: "<p>probe A</p>" });
   const pluginFile = performance.getEntriesByType("resource").map((e) => e.name).find((n) => n.includes("fuyu-plugin"));
   if (pluginFile) mk("probe-protocol", { src: pluginFile }); else console.warn("没找到 fuyu-plugin 协议的文件：先装一个市场插件，重开设置窗口再来");
   console.log("B 框架的地址：", pluginFile);
   window.__TAURI_INTERNALS__.invoke("get_plugin_host_connection").then((c) => console.log("宿主连接（只记端口，不要贴出令牌）：", c));
   ```

   框架 A 是 `srcdoc`（地址 `about:srcdoc`），框架 B 的地址在 `fuyu-plugin` 协议上，和以后试用页的地址是同一种。两个都要测：Tauri 判断能不能调命令时看的可能是地址而不是来源。

**探测**（A、B 各做一遍）

3. 把控制台的执行上下文切到那个框架（Chromium 的开发者工具在控制台左上角的下拉框，Safari 的检查器在控制台右下角），执行下面的脚本，把 `PORT` 换成第 2 步看到的端口：

   ```js
   (async () => {
     const PORT = 0;
     const out = {};
     const see = (name, get) => { try { out[name] = String(get()); } catch (e) { out[name] = "抛错：" + e.message; } };
     const wait = (name, promise) => Promise.race([promise, new Promise((r) => setTimeout(() => r("5 秒没结果"), 5000))]).then((v) => { out[name] = String(v); }, (e) => { out[name] = "失败：" + (e && e.message || e); });
     see("地址", () => location.href);
     see("来源", () => self.origin);
     see("__TAURI_INTERNALS__", () => typeof window.__TAURI_INTERNALS__);
     see("__TAURI__", () => typeof window.__TAURI__);
     see("window.ipc", () => typeof window.ipc);
     see("chrome.webview", () => typeof (window.chrome && window.chrome.webview));
     see("webkit.messageHandlers.ipc", () => typeof (window.webkit && window.webkit.messageHandlers && window.webkit.messageHandlers.ipc));
     see("parent.document", () => typeof parent.document);
     see("localStorage", () => localStorage.length);
     see("document.cookie", () => document.cookie.length);
     await wait("调命令 get_builtin_plugins", (async () => "调通了，返回 " + JSON.stringify(await window.__TAURI_INTERNALS__.invoke("get_builtin_plugins")).length + " 个字符")());
     await wait("连宿主 WebSocket", new Promise((resolve) => { const ws = new WebSocket("ws://127.0.0.1:" + PORT); ws.onopen = () => resolve("连上了"); ws.onerror = () => resolve("连不上"); ws.onclose = (e) => resolve("被关闭 " + e.code); }));
     await wait("fetch 外网", fetch("https://api.github.com/zen").then((r) => "拿到了 " + r.status));
     await wait("fetch 本机 80 端口", fetch("http://127.0.0.1/").then((r) => "拿到了 " + r.status));
     await wait("加载外网图片", new Promise((resolve) => { const img = new Image(); img.onload = () => resolve("加载了"); img.onerror = () => resolve("没加载"); img.src = "https://github.com/favicon.ico?" + Date.now(); }));
     see("RTCPeerConnection", () => typeof RTCPeerConnection);
     see("window.open", () => window.open("https://example.com") ? "打开了" : "没打开");
     console.table(out);
   })();
   ```

4. 把表格抄进结果文档。要看的是这几行：
   - 「调命令」是「调通了」→ **不过关**，试用页能调浮屿的命令。
   - 「连宿主 WebSocket」是「连上了」→ 再看它不带令牌能不能发方法；能就不过关。
   - `parent.document`、`localStorage` 不是抛错 → 不过关（沙箱没生效）。
   - 「fetch 外网」「加载外网图片」拿得到 → 试用页能往外发东西，试用包要靠回应头里的 CSP 再挡一道，记下来。
5. 还在框架的上下文里，逐条执行，每条单独记：
   - `top.location = "https://example.com"`：应该抛错；设置窗口被带走就是不过关（重开设置窗口继续）。
   - `location.href = "https://example.com"`：框架自己走掉是预期的，记一下能不能走。
   - 最后做 `while (true) {}`：看设置窗口还能不能点、能不能关，岛本身卡不卡；记下怎么恢复的（关窗口还是要杀进程）。

**结果怎么定**

- 两个系统上 A、B 都调不通命令、碰不到父页面和本地存储：照方案 (b) 继续，另建实现任务；外网请求和死循环的结果决定试用包的 CSP 和要不要放进单独的窗口。
- 任何一个框架调通了命令：不做能点的试用，退回只看截图；把是哪个系统、哪个框架写清楚。
- 只有 B 调通：试用页不能放在 `fuyu-plugin` 协议上，记下来，另想地址（或者停）。

以后每次升级 Tauri 重做一遍第 2 到第 4 步。
