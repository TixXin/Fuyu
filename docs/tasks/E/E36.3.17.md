## 说明

`defineService`、`isServiceDefinition` 和服务名、方法名的规则（`SERVICE_NAME`、`MEMBER_NAME`、保留字、默认超时）现在在 `@fuyu/plugin-services` 里，和浮屿自己的服务声明、Rust 生成的类型放在一起。挪进 plugin-base 的不带 Cordis 的子路径 `@fuyu/plugin-base/services`（常量直接从同包 `protocol` 取；不能放主入口，主入口带 Cordis，窗口代码一引就把 Cordis 打进去），宿主共享这个子路径（加进 E36.3.16 的 `HOST_SHARED_MODULES`）；`@fuyu/plugin-services` 转出保持兼容，删掉重复的常量和 `packages/plugin-base/test/services.test.mjs` 里那条相等测试。

为什么：定义服务属于插件接口这一层；名字规则宿主也要用，只该有一份；plugin-services 只留浮屿的服务清单。第 5 阶段对第三方开放后再挪就得长期留兼容转发，所以最晚在第三方接口冻结前做。

开工前：改 plugin-base 的 `exports` 要经理同意，对外接口会变也要第 5 阶段那边同意（主 agent 去问），两边都同意后再认领。

分步计划：[v3-phase3-foundation-plan.md](/docs/architecture/plugins/v3-phase3-foundation-plan.md)。

- [ ] `@fuyu/plugin-services` 照旧能 import 这些名字（转出）
