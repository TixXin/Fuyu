## 说明

E36.6.6（#791）收口第 2 版时留下的一项旧名兼容。`packages/plugin-cli/src/keys.mjs` 在新位置 `~/.fuyu-plugin/signing.key` 不存在时还读改名前的 `~/.fly-island-plugin/signing.key`，也认旧环境变量 `FLY_ISLAND_PLUGIN_SIGNING_KEY`，DPAPI 子进程的变量还叫 `FLY_ISLAND_DPAPI_INPUT`；`packages/plugin-cli/test/sign.test.mjs` 测着它。

插件作者签名私钥只在 Windows 那台机器上，用户还没确认那台的私钥已经挪到新位置；没挪就删，下次在那台机器上签第 3 版插件会找不到私钥。所以等用户确认再做。

## 验收

- 用户确认 Windows 那台的私钥已经在 `~/.fuyu-plugin/`（或那台从没用过旧位置）
- `keys.mjs` 和测试里不再有 `.fly-island-plugin`、`FLY_ISLAND_*`；`docs/investigations/old-names-cleanup.md` E 类那一行标为已做
- `pnpm check` 通过
