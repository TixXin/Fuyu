## 说明

计划「关键设计」第 1、3 条和第 0 批。Rust 在 `plugin_kernel/` 加内置插件的开关表：读写数据目录的 `plugins-v3/plugins.yml`（内置插件只记 `disabled`），命令 `get_builtin_plugins` / `set_builtin_plugin_enabled`，事件 `builtin-plugins-changed`，写完让在跑的宿主重读；后台登记的接口（`start` / `stop` / `running`）和按 `builtins.json` 逐个开关的通用测试。`builtins.json` 一次列全 22 个内置插件（`updater` 是 `essential`），每个领域放一个空的宿主入口。窗口里读开关的 hook 和事件，插槽注册表按拥有者的开关过滤；设置的插件页列出全部内置插件、能开关，宿主没开时也能用；插件名的中英文一次加全。

计划见 [v3-phase3-plan.md](/docs/architecture/plugins/v3-phase3-plan.md)。

## 验收

- 关掉一个内置插件后它的插槽项消失、Rust 登记的后台停掉，再打开能恢复
- `FUYU_PLUGINS_V3` 没开时开关照样生效
- 通用的 Rust 测试和宿主测试在计时器、翻译两个样板上跑通
- `contracts.md`、`data-storage.md` 记上新命令、事件和 `plugins.yml` 的用法
