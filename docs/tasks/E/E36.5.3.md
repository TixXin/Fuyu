## 说明

插件平台第 3 版第 5 阶段（#295）的地基：逐版审核用的分析器，新包 `packages/plugin-review`（`@fuyu/plugin-review`）。市场 CI 在每个版本的 PR 上跑它，作者也能在本地跑。

- 输入两个版本的源码目录和构建产物，输出差异摘要：`nodeApis`、联网域名、依赖变化（读锁文件）、敏感模式（子进程、`eval` / `Function` / `vm`、非字面量的动态 `import()`、写插件目录以外的文件）、混淆迹象、二进制文件
- 给出绿 / 黄 / 红三档和每条的理由，JSON 和 Markdown（能直接贴进 PR 评论）两种输出
- 测试夹具：干净的 1.0、靠更新下毒的 1.1（子进程 + 没声明的域名 + 拼接的字符串）、靠依赖升级下毒的 1.2

## 验收

- 夹具都判对：1.0 → 1.1、1.0 → 1.2 都不是绿；改文案的小更新是绿
- `pnpm check` + `pnpm build` 通过
