## 说明

PowerShell 助手、nvidia-smi、GPU 计数器、程序图标在 Mac 上验不了。合入并上架后在 Windows 开发版装 1.1.0：各项有读数；页面关掉 60 秒后 PowerShell 进程退出；收起条温度偏高变色。发现问题回到 E64.1 修。

**首次出数要多久（2026-11-19 用户在 Windows 开发版的截图）**：第一张截图网速显示「—」、「最占 CPU 的程序」是骨架屏；第二张一切正常（网速、程序 8 行、GPU 四个引擎、温度都有），所以多半是刚打开还没取到第一批数，不当 bug 查。要做的：量一下首次打开到网速、程序列表出数要几秒；超过两三秒就在骨架屏上写「正在读取」，或者先出第一批数（改插件宿主 `src/host/win/` 或 `src/ui/`，版本升修订号）。要在 Windows 机器上做。
