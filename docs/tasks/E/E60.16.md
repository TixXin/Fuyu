## 说明

官方插件「应用启动台」（E66.5）要能打开自己的岛页面、收起岛。接口由插件系统总控 2026-11-19 定下，已经告诉官方插件完善组长。不挡发版，做法照 E60.12（`ctx.settings.open()`）。

排在 E60.14 之后：要复用它做的「让岛切到插件页面」入口（`island-open-plugin-page` 事件、`src/features/plugin-kernel/islandPageRequest.ts`、`src/windows/island/usePluginPageRequests.ts`），改的文件也有重叠；和 E60.15 错开文件。

- `ctx.island.open(page?)`：窗口代码和宿主代码都能调。宿主要先 inject `"island"`，从宿主转到岛窗口的路径由做的会话定，可以参考 E60.12 的 settings.open。调用后岛展开，切到本插件注册的 `island.page/v1`。
  - `page` 只能是本插件自己的页面 id，不传就用它注册的第一个页面；传别的插件的页面 id 报错。插件 id 由加载器或宿主填，插件自己传不了。
  - 本插件没有注册岛页面时，返回明确的错误。
  - 岛贴边隐藏或缩到托盘时，先唤出再切页。收起、展开、贴边、托盘四种状态都要考虑。
- `ctx.island.collapse()`：先只给窗口代码。只有当前打开的是本插件自己的页面时才收起；不是的话什么也不做，返回 `false`，免得插件收掉用户正在看的别的页面。宿主要不要也给，评估后把结论写进本任务。
- `island-open-plugin-page` 事件可以复用，但不直接暴露给插件。
- 一起改：类型声明（`packages/plugin-base` 的 `*.d.mts`，写 JSDoc）、`docs/plugins/` 的接口文档和更新记录（`docs/plugins/changelog.md`）。`fuyu-plugin check` 要认 inject `"island"`，照 E60.12 认 `"settings"` 的做法。

## 验收

- 插件调 `ctx.island.open()` 或 `open("<自己的页面>")`，岛展开并切到那一页；贴边或在托盘时先唤出
- 传别的插件的页面 id 会报错；没有岛页面的插件调用时返回明确的错误
- 当前不是本插件的页面时，`collapse()` 返回 `false`，岛不动；是本插件的页面时收起
- 单元测试或回归页覆盖上面几条，至少包括：打开别人的页面报错、不在本插件页面时 collapse 不生效
- 接口文档、更新记录、类型声明同步更新
- `pnpm check`、`pnpm build`、`pnpm test:regression` 通过；改了 Rust 或 api.ts 时，再跑 Rust 测试和 `pnpm build:exe`，并附 `mq:try` 的 Windows CI 结果
- 做完告诉插件系统总控和官方插件完善组长
