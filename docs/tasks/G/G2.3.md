## 说明

[G2](/docs/tasks/G/G2.md) 子任务 3，收敛 [vite.config.ts](/vite.config.ts) 开发服务器的文件监听范围，防止多会话并行修改插件配置或回归快照时反复触发主岛清缓存整页重载：

1. **收敛 `server.watch.ignored`（[vite.config.ts](/vite.config.ts)、`scripts/vite/`）**：
   - 当前 [vite.config.ts](/vite.config.ts) 仅忽略了 `**/src-tauri/**`；多会话并行写 `plugins/v3/official/*/tsconfig.json` 或 `tests/regression/snapshots/*.html` 时，Vite 会清缓存强制整页重载，打断隐藏中正在加载上千个 ESM 模块的主岛并导致挂载卡死；
   - 在 `scripts/vite/` 抽离监听忽略规则并在 `vite.config.ts` 的 `server.watch.ignored` 中忽略 `**/src-tauri/**`、`**/plugins/**`、`**/tests/regression/snapshots/**`、`**/docs/**`、`**/video/**`、`**/.claude/**`，同时保留 `src/**` 与 `tests/regression/*.{html,tsx}` 回归页本身的正常热更新。
2. **脚本单测覆盖（`tests/scripts/vite-watch.test.mjs`）**：
   - 编写 `node:test` 单元测试，验证插件 `tsconfig.json`、回归快照 HTML、文档与 `src-tauri` 均被忽略，而 `src/` 与回归入口页不被误忽略（遵守仓库代码和脚本不写注释规则）。

## 验收

- `vite.config.ts` 忽略 `plugins/`、`tests/regression/snapshots/`、`docs/`、`video/`、`.claude/` 与 `src-tauri/`，不影响 `src/` 与回归页热更新
- 新增 `tests/scripts/vite-watch.test.mjs` 单元测试通过
- `pnpm check` 与 `pnpm build` 通过
