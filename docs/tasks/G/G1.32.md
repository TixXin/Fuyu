## 说明

Mac 上按 Control+Shift+1 截岛屿面板时，岛的拖动提示（移动光标、边缘的调整大小提示）被一起截进去。原因：`src-tauri/src/island/passthrough_macos.rs` 只看 Control 有没有按下（`macos/input.rs` 的 `is_control_key_down`），鼠标在岛上又按着 Control 就发 `island-move-armed-changed`；截图快捷键正好带 Control。Windows 拖岛用 Alt，不受影响。用户 2026-11-16 在 Fuyu-[总控] 功能里报的，交给 Mac 适配。

做法：
1. 只有单独按住 Control（没按 Shift、Option、Command）才进入「准备拖动」，按住约 0.2 秒后才显示提示；按住 Control 让面板保持展开（`ISLAND_HOLD_CHANGED_EVENT`）照同样规则。
2. 截图开始前收掉岛上临时的提示（拖动提示、按钮悬浮提示）。截图归 Fuyu-[总控] 功能，改截图模块前打个招呼。
3. 设置 → 位置的 `moveHint` / `moveHintMac`（`src/i18n/sections/settings/position.ts`）写的是 Windows 按 Ctrl、Mac 按 Option，实际是 Alt 和 Control，中英文改对。

## 验收

- Mac 上鼠标停在岛上按 Control+Shift+1 截图，图里没有拖动提示和移动光标
- 单独按住 Control 照常显示提示、能拖岛；Control+右键拖动照常
- 带 Control 的其他组合键按下时岛上不闪提示
- 设置里拖岛的说明在两个平台上都和实际按键一致，中英文
- Windows 行为不变
