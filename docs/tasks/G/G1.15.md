## 说明

Windows 用独立的 WebView2 页面（plugin_host/webviews.rs、win32/webview_page.rs），Mac 上还是「暂不支持」。两条路：Tauri 的子 webview 会让插件页面拿到岛屿的 Tauri 命令通道，不能用；用 objc2-web-kit 自己建 WKWebView 加到岛窗口上（自定义 URL scheme 供文件、脚本消息通道、导航限制、复用 webviews.rs 的 INIT_SCRIPT 和 CSP），代码量大、要真机看效果。先研究用到这个功能的插件有多少、WKWebView 方案的细节，再决定做不做。

## 结论（2026-11-14）

研究写在 [macos-webview.md](/docs/architecture/plugins/macos-webview.md)。能做：自己建 WKWebView，需要的 WebKit 接口都有，安全边界能做到和 Windows 一样，`webviews.rs` 里平台无关的部分可以直接复用。约 500–600 行代码，加一轮真机验收。做出来后 Mac 上直接多出来的只有待办进度环和天气两个页面，第三方插件都没用。建议先不做，等有第三方插件要用、Mac 用户明显增多或者官方要出新的网页插件时再开工；要让进度环在 Mac 上有页面，先考虑给状态模板加环形进度。做不做等用户定。
