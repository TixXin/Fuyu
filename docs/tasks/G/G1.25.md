## 说明

Mac 上应用内更新装完后，tauri updater 只替换 .app 不退出，我们没调用重启，界面一直停在「正在重启」。修法：install 成功后在非 Windows 上 request_restart；设置页「完成」持续不重启时给手动重启按钮。验收见 issue #423。
