## 说明

Mac 上应用内更新装完后，tauri updater 只替换 .app 不退出，我们没调用重启，界面一直停在「正在重启」。修法：install 成功后在非 Windows 上 request_restart；设置页「完成」持续不重启时给手动重启按钮。验收见 issue #423。

## 交接

- 2026-11-15 06:17 mac-update-restart：原因已确认：tauri-plugin-updater 在 Mac 上 install() 只替换 .app 就返回（Windows 上是 exit(0) 交给安装器），我们没调重启。本机证据：/Applications/Fuyu.app 05:23 已换成 0.3.9，进程到 06:03 才重开。改动已在工作区：update_channel.rs 的 restart_after_install（1.5 秒后 request_restart）、useRestartStalled.ts + UpdatePanel.tsx 的 15 秒兜底按钮、project.ts 三条文案、platforms.md / updater.md。兜底界面已在 update-reminder 回归页手动验证。还没做：cargo test、build:exe、带修复的测试包端到端（用户让所有会话排队，等放行）；端到端要有人点设置 → 安装（没有桌面控制工具）。注意：从 v0.3.9 及以前升级到带修复的版本仍要手动重启一次。测试材料：scratchpad/upd（临时密钥、overlay.json 改标识为 com.tixxin.fuyu.updtest、本地 latest.json）。
