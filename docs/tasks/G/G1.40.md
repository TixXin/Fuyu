## 说明

Mac 上截图只能吸附到整个窗口（`CGWindowListCopyWindowInfo`），Windows 上能吸附到控件（UI Automation）。有「辅助功能」授权时，用 `AXUIElementCopyElementAtPosition` 和元素的 `AXFrame` 取鼠标下的控件和它的上层，滚轮换层级，和 Windows 一样；没授权就照旧只到窗口。截图开始时取好或按需取，不能让选区窗口卡顿。

## 验收

- 有授权时在访达、Safari、VS Code 里悬停能高亮到控件，滚轮换层级
- 没授权时行为不变，不弹授权提示
- platforms.md 截图那行更新；`cargo test`、`pnpm build:exe`
