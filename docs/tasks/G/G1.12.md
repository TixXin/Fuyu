## 说明

只有用户本人能做。步骤见 [macos-distribution.md](/docs/research/macos-distribution.md)「用户本人必须做的事」。

### 购买流程（个人账号，99 美元 / 年；2026-11-13 整理）

1. Apple ID 开好双重认证，姓名、地址、电话用真实信息（苹果会核实）；账号和证书都挂在这个 ID 上，之后别换。
2. 在 iPhone 或 Mac 上装「Apple Developer」App，在 App 里注册，选「个人」。中国大陆通常要在 App 里扫身份证实名、用 App Store 的支付方式付款，比网页报名顺。网页入口：<https://developer.apple.com/programs/enroll/>。
3. 付费、等审核（快的当天，慢的几天，可能要补材料）。人民币价格常见说法 688 元，以付款页为准。
4. 建证书（只有账号持有人能建）：「钥匙串访问 → 证书助理 → 从证书颁发机构请求证书」存成 CSR → 开发者网站 Certificates →「+」→ **Developer ID Application** → 上传 CSR → 下载 `.cer` 双击装进钥匙串 → 在「我的证书」里确认下面挂着私钥 → 导出 `.p12` 并设密码。
5. App Store Connect → 用户和访问 → 集成 → 密钥，新建 API key，记下 Issuer ID、Key ID，下载 `.p8`。
6. 交给代理：Team ID、证书全名（`Developer ID Application: 名字 (TEAMID)`）。`.p12`（base64）、导出密码、`.p8`、Issuer ID、Key ID 由用户放进仓库 Secrets，不发在对话里、不提交进仓库。之后由 G1.13 接签名、公证和发布。

### 容易踩的坑

- 证书类型选 **Developer ID Application**；Apple Development、Mac App Distribution 签出来的包对外发布用不了。
- 私钥只在生成 CSR 的那台 Mac 上；拿到证书立刻导出 `.p12` 备份。丢了只能新建，一个账号最多 5 张。
- 不要随手吊销 Developer ID 证书：吊销后，用它签过的已发布版本也可能被系统拦下。到期前换新证书即可，只有私钥泄露才吊销。
- `.p8` 只能下载一次。
- 个人账号的开发者名是真名；要显示组织名得办组织账号（要邓白氏编码），以后转要找苹果支持。
- 留意自动续费：过期后不能再签名、公证新版本，已公证的旧版本还能用；国内信用卡偶尔扣款失败。
- 别用别人的 Apple ID 代办：建证书、改账号都要账号持有人本人。
- 从本机临时签名换成正式证书后，辅助功能、屏幕录制、自动化授权要重新勾一次，之后跨版本保留。
- 公证要求包里所有代码都签名：内置的 `MediaRemoteAdapter.framework` 打包时由 Tauri 用正式证书重签，第一次公证时核对。
- 费用减免只给非营利、教育机构和政府，个人项目申请不了。

### 一个账号能发布多少软件

不限数量，99 美元覆盖名下所有 Mac 应用。有限制的是：Developer ID Application 证书最多 5 张（一张可签任意多个应用）；公证有论坛转述的「每天 75 次」，范围不明，按次发版碰不到。来源：[Apple 账号帮助](https://developer.apple.com/help/account/certificates/create-developer-id-certificates/)、[论坛 706413](https://developer.apple.com/forums/thread/706413)、[论坛 783347](https://developer.apple.com/forums/thread/783347)。

### 不买账号能不能给别人用

能打包、能下载使用，但：第一次打开要在「系统设置 → 隐私与安全性」点「仍要打开」并输管理员密码（macOS 15 起按住 Control 打开绕不过）；进不了官方 Homebrew；临时签名每次重编身份都变，更新后辅助功能等授权会悄悄失效。折中是固定用钥匙串里的自签名证书签名，授权能跨版本保留，但别人第一次打开仍要「仍要打开」。详见 [macos-distribution.md](/docs/research/macos-distribution.md) 第 2 节。

未核实：人民币价格、大陆实名与 App 内付款的具体方式、审核时长、证书有效期，以办理时苹果页面为准。
