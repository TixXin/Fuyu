## 说明

#646：Windows 上的 Antigravity IDE（报告里写 2.7.0）里的会话岛上能看到，点会话却提示「没有找到对应窗口」。跳转时 Antigravity 按程序名 `antigravity` 找窗口（`src-tauri/src/agent_status/focus.rs` 的 `prefer_app`、`antigravity::APP`），新版改了可执行文件名或窗口标题的话可能对不上；先看报告人的 `agent-focus.log` 再定。

## 验收

- 用报告人的 `agent-focus.log` 或在装了 Antigravity IDE 2.x 的 Windows 上复现，确认没找到窗口的那一步
- 修好后 Antigravity IDE 2.x 的会话能跳到它的窗口，旧版 Antigravity 不受影响
- 回复并关闭 #646
