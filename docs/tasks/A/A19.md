## 说明

A16（找窗口、从托盘唤出）和 A17（`workbuddy://` / `workbuddy-ai://chat/<会话 id>` 打开指定对话）都是在 Mac 上做的，Windows 和 WorkBuddy 国内版这台机器测不了，需要在 Windows 上照下面测一遍，结果记进任务文件，有问题另开任务。

前提：Windows 上装 WorkBuddy（国内版或 WorkBuddy AI），开两条以上会话；用带 A17 的浮屿；`agent-focus.log` 在浮屿数据目录里。

1. WorkBuddy 窗口开着时，在 Agent 页点一条不是当前显示的会话：WorkBuddy 切到前台并切到那一条，行内不出现「已切到窗口，请选会话」（log 里有 `app-link=sent`）
2. 关窗口收进托盘后再点另一条会话：窗口被唤出、切到前台、停在那一条
3. WorkBuddy 完全退出后点会话：WorkBuddy 启动并打开那一条（冷启动可能要几秒）
4. 右键「跳到窗口」同第 1 条
5. 国内版和 WorkBuddy AI 在 Windows 上的 exe 名都是 `WorkBuddy.exe`；国内版的链接协议是 `workbuddy://`（注册表 `HKCU\Software\Classes\workbuddy`）
6. 国内版的 Mac 版（如果有）：点会话能打开那一条
7. Mac 上 WorkBuddy AI 收起窗口后，在岛上点会话能把窗口拿出来并停在那一条

## 验收

- 上面七条在任务文件里逐条记下结果（做不到的写现象和 `agent-focus.log` 的那几行）
