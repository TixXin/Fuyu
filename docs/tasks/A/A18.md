## 说明

A17 让点 WorkBuddy 会话直接打开那条对话（`workbuddy-ai://chat/<会话 id>`）。顺带看了 Antigravity 和 Cursor，两家都有自己的链接协议，可能也能打开指定会话，但还没查实：

1. Cursor 3.30：`cursor://anysphere.cursor-deeplink/agent`（以及 `/background-agent`）会打开或聚焦 Agents 窗口，并把整个链接转给 Agents 窗口里的路由。要查 Agents 窗口（`workbench.glass.main.js`）认哪些参数，能不能按本地 composer id 选中会话，和我们读的 Cursor 会话 id 怎么对应。
2. Antigravity 2.33：主进程把任何 `antigravity://` 链接经 `deep-link` 消息交给窗口里的界面处理，界面不在安装包里（运行时加载），要开着应用实测哪些路径能打开指定对话，和我们读的对话 id 怎么对应。
3. 有办法的那家：点会话先唤出窗口，再打开那条会话，去掉行内「只切到窗口」的提示；没办法的写进调研文档。

调研见 `docs/research/workbuddy-open-session.md` 的「其他图形界面代理」一节。

## 验收

- 两家各有查实的结论写进调研文档
- 有办法的那家在 Mac 上点会话能切到那一条
