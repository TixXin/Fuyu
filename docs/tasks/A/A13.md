## 说明

A12（`f30e478a`，#751）合入后，在真机岛上核对新增的终端标签/分屏切换与仅窗口级切换反馈（开发过程未在后台无人值守触发 macOS「自动化」系统授权弹窗，且本机未装 `tmux`）。

## 验收

- [ ] macOS 上在 Ghostty 开多个标签或分屏跑 Claude Code / Codex，点击岛上会话并在系统首次弹出的「自动化」授权点允许后，确认能切到对应标签页与分屏（`~/.fuyu/agent-focus.log` 记 `mac-tab=selected`）
- [ ] 点击 Claude Desktop（Code 页）、Antigravity Desktop/IDE 或 Codex Desktop 的会话，确认窗口调到前台且会话行内出现 3 秒「已切到窗口，请选会话」提示，悬停卡片带有「点击只切到窗口，需手动选会话」说明
- [ ] 装有 `tmux` 的 Mac 上在 Alacritty 或 Ghostty 里经 `tmux` 跑会话，点击确认能激活外层终端并切到对应 `tmux` window/pane（日志记 `tmux=selected`）
