## 说明

用户：「agent 回话还不支持 claude 桌面版跳转到指定会话，查下其他开源项目上怎么做的」。现在在 Agent 页点 Claude 桌面版的会话或在岛上回话，只能把 Claude 桌面版调到前台，不能打开那条会话。

1. 调研其他开源项目（Agent 状态灯、菜单栏工具、Claude 桌面版相关工具）怎么跳到 Claude 桌面版的指定会话，写成 `docs/research/claude-desktop-open-session.md`。
2. 线索：Claude 桌面版的会话有 `claude://claude.ai/epitaxy/local_<sessionId>` 这种链接。先确认钩子里拿到的 `session_id`、`claude_desktop.rs` 读到的会话记录，和链接里的 id 能不能对上。
3. 有可靠做法就实现：点会话 / 回话时先发链接，再照旧切窗口；参照 A17（WorkBuddy）、A18（Cursor）的 deep link 写法，id 拼进链接前校验。没有就在 research 里写清结论。
4. 按 `fuyu-agent-harness` 走；`platforms.md` 写清实测情况，Windows 测不了留实测清单并进 A19。

## 验收

- Mac 上 Claude 桌面版开着两条以上 Code 会话时，在 Agent 页点其中一条，Claude 桌面版切到那一条
- 有 `docs/research/claude-desktop-open-session.md` 调研结论
