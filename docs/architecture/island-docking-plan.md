# 岛屿吸附到左右侧和任务栏（方案）

任务：C54（C54.1 左右侧抽屉，C54.2 任务栏模式）。交互已经定下（2026-11-13，用户确认五条都按推荐），约定在 [design/island.md](../design/island.md)「侧边吸附」「任务栏模式」；下面的交互小节是当时的方案原文，以 design/island.md 为准。

## 现状

- 吸附只有顶边：`src-tauri/src/island/top_edge.rs` 只比较 Y，离顶边 16 逻辑像素以内就贴上去，状态是一个布尔值 `top_attached`，事件 `island-top-attachment-changed` 的载荷也是布尔值。
- 贴边收起只往上缩：`geometry.rs` 用 `TUCKED_VISIBLE_EDGE_HEIGHT`（10px）算 `tucked_y`，只露出底下一条。
- 岛窗口是固定 820 宽的透明舞台，岛在里面水平居中，展开时往下长；原生点击区域（`passthrough.rs`）按"顶部居中"计算。
- 多显示器跟随（`follow.rs`）把收起的岛移到目标屏幕的顶部正中，拖动保存的位置（`fuyu-position`）随之清掉。
- 前端的顶边造型（反向圆弧、`IslandTopEdge.css`）和 `windows/island/topEdge.ts` 也只认顶边。

## 一、左右侧：侧边抽屉

### 交互

1. **吸附**：拖到显示器左边或右边 16 逻辑像素以内时吸住。只认**外侧**的边：两块屏幕之间共享的那条边不吸，免得岛卡在两屏中间。顶部任务栏、侧边任务栏都按工作区算，和现在顶边的规则一样。
2. **折叠态是把手，不把胶囊竖过来**：岛上的内容（歌词、横幅、会话行）都是横排的，竖着排看不了。吸在侧边时折叠成一条竖向把手，宽约 12px、高约 72px，贴边的一侧是直边，朝屏幕内的一侧是圆角；把手上只显示 Agent 状态的颜色和未读角标（一个点或数字）。
3. **展开**：点击（或开了悬停展开时悬停）把手，现在的横版面板从侧边滑出，贴着那一侧；面板里的页面不改。面板的垂直位置跟着把手，靠近屏幕上下边时往里收，保证整块面板在工作区内。
4. **把手的位置**：在侧边上按住 Alt 拖动只沿这条边上下移，记住相对位置（0–1，换屏、改分辨率后还在原来的比例上）；拖离侧边超过 16px 就脱离吸附，变回自由的岛。
5. **贴边收起**：侧边本身就是收起的形态，不再另有"贴边收起"；"一段时间不用自动收起"在侧边时就是收回成把手。
6. **收起时的临时内容**（消息预览、音量 / 亮度、设备提示、歌词）：把手旁边弹出一个横向小气泡（朝屏幕内），显示完收回；开了"收起到边缘时，收到新消息自动露出"的，消息预览走这个气泡。歌词这种一直在变的不弹，只在顶边模式显示。
7. **造型**：贴边的一侧和屏幕边齐平，两个贴边角向外做反向圆弧，和顶边的贴顶圆角同一套参数（"贴顶圆角"滑块改名"贴边圆角"，作用于所有吸附边）。
8. **多显示器跟随**：跟随换屏时保持吸在哪条边、在边上的比例位置；跟随到的屏幕在那一侧有相邻屏幕时，退回顶边。
9. **设置**：设置 → 位置里加"吸附到"：顶边（默认）、左侧、右侧，和拖动吸附是同一个状态，两边改哪个都同步。

### 实现

- **原生侧**：`top_edge.rs` 推广成 `edge.rs`，状态从 `top_attached: bool` 换成 `attached_edge: Option<Edge>`（`Top` / `Left` / `Right`），加上沿边的比例位置。舞台窗口在侧边时换成竖向舞台（宽度为面板宽度加阴影余量，高度为面板高度加余量），岛贴住舞台的一侧；`passthrough.rs` 的点击区域、`modifier.rs` 的 Alt 拖边判断按吸附边换算。`geometry.rs` 的 `resolve_stage_position` 按边算位置，收起偏移从"往上"变成"往吸附边方向"。
- **前端**：`topEdge.ts` 和贴顶造型改成按边（CSS 用 `data-edge` 选择）；折叠态加把手组件，展开动画在侧边时改成横向滑入，内容层仍然只淡入淡出（不违反 design/island.md 里 F14 那几条）。
- **对外契约**（同一个提交里前后端一起改，写进 contracts.md）：
  - `fuyu-position` 加可选字段 `edge`（`top` / `left` / `right`）和 `along`（0–1）；旧数据没有这两项时按现在的规则读，等同顶边。
  - 事件 `island-top-attachment-changed` 保留（载荷仍是"是否贴顶"，给旧插件和现有前端用），新增 `island-edge-changed`（载荷 `"top" | "left" | "right" | null`）。
- **平台**：macOS 先只做 Windows，`platforms.md` 加一行；Mac 上左右侧没有刘海和菜单栏的冲突，以后可以照搬。
- **步骤**：① 原生侧吸附边状态和竖向舞台（零界面变化，先只支持 `Top`，确认顶边行为不变）；② 左右侧吸附、把手和展开；③ 临时气泡、设置项、多显示器跟随。每步一个提交。

## 二、任务栏模式（实验）

### 为什么不嵌进任务栏

- Windows 11 去掉了 DeskBand 接口，没有官方的办法往任务栏里放东西。
- 用 `SetParent` 把窗口挂到 `Shell_TrayWnd` 下面（TrafficMonitor 这类软件的做法）依赖任务栏未公开的内部结构。Win11 的任务栏是 XAML 重写的，系统更新、explorer 重启、DPI 变化、多屏任务栏都可能让它失效或错位，作为常驻功能维护成本太高。

所以做成**覆盖式**：岛还是自己的置顶窗口，只是摆在任务栏的空白区域上面，看起来在任务栏里。

### 交互

1. **入口**：设置 → 位置 → 吸附到 → "任务栏（实验）"；不靠拖动进入，避免和任务栏图标抢拖动。
2. **形态**：高度等于任务栏高度减上下边距（任务栏 48px 时岛约 36px），一行内容：Agent 状态灯 + 当前最重要的一条（正在跑的会话、歌词或歌名、未读数，按现在收起条的优先级）。
3. **位置**：在任务栏的左侧空白区或右侧（托盘左边）二选一，默认左侧（Win11 图标默认居中，左侧通常空着；左侧开着小组件时往右让）。任务栏图标靠左对齐时自动改到右侧。
4. **展开**：点击后面板从任务栏**往上**展开，贴着任务栏上沿，水平位置对齐岛；面板里的页面不改。
5. **跟随任务栏**：用 `SHAppBarMessage(ABM_GETTASKBARPOS)` 取任务栏位置，监听 `WM_SETTINGCHANGE` / `WM_DISPLAYCHANGE` / explorer 重启（`TaskbarCreated` 消息）后重新定位；任务栏在顶部或侧边（ExplorerPatcher 等）时退回顶边模式并提示。
6. **层级**：任务栏也是置顶窗口，点它时可能盖住岛。任务栏获得前台时把岛重新提到它上面（`SetWindowPos(HWND_TOPMOST)`，已有的 `shell_hook.rs` 能收到前台变化）；任务栏自动隐藏、全屏应用时岛跟着隐藏，任务栏出现时再出现。
7. **多显示器**：只放在主任务栏上；副屏任务栏以后再说。

### 实现

- 新模块 `src-tauri/src/island/taskbar_dock.rs`，Win32 调用放 `win32/taskbar.rs`（`ABM_GETTASKBARPOS`、`TaskbarCreated`、找托盘和小组件的位置）；macOS 不支持，`platforms.md` 写明。
- 复用第一部分的"吸附边"状态，`Edge` 加 `Taskbar`；`fuyu-position` 的 `edge` 多一个 `taskbar` 值。
- 先做验证页：在几种任务栏设置下（图标居中 / 靠左、自动隐藏、125% / 150% 缩放、副屏）截图记录，结果写进 `docs/investigations/taskbar-dock.md`，再决定是否从"实验"转正。

## 顺序

先做 C54.1（左右侧），它把"吸附边"这一层抽出来；再做 C54.2（任务栏），复用这一层。两部分的交互定下来之后，各自搬进 design/island.md 的新小节"侧边吸附"和"任务栏模式"。

## 已确认（2026-11-13）

用户确认五条都按推荐：左右侧用把手 + 横版面板滑出；侧边收起时歌词不弹，消息、音量、设备提示用气泡；跟随换屏到那一侧有相邻屏幕时退回顶边；任务栏模式覆盖式、标实验、只从设置进入；任务栏模式默认左侧空白区。
