# 数据存放位置

2026-11-12 起（D30.3，#50）浮屿的文件放在家目录：`FUYU_HOME`，或 `%APPDATA%\com.tixxin.fuyu\home.json` 指向的文件夹，默认 `%USERPROFILE%\.fuyu`；升级时把旧的应用数据目录复制过去，旧目录保留，见 [家目录](../features/data-home.md)。Windows 卸载（B73.3，2026-11-18 起）在删 `%APPDATA%\com.tixxin.fuyu` 前先运行 `fuyu.exe --uninstall-cleanup`：未勾选「删除应用数据」时保留家目录，只清理外部 19 家 AI 钩子与回复标记并在家目录记 `uninstalled-hooks.json`（`{ hooks, replyMarker }`）供重装启动时自动恢复；勾选「删除应用数据」（`--delete-data`）时额外清理正式版 `com.tixxin.fuyu` 凭据（不动 `lane-*`），且仅当家目录是真实的默认 `%USERPROFILE%\.fuyu`（非软链）时整目录删除，通过 `home.json` 或 `FUYU_HOME` 指定的自定义目录只按受管文件与子目录白名单逐项删除、目录变空才非递归移除，不碰用户自己的其他文件。下表里的「应用数据目录」都指家目录。之前的应用数据目录是 `%APPDATA%\com.tixxin.fuyu`，WebView2 的数据（含 `localStorage`）在 `%LOCALAPPDATA%\com.tixxin.fuyu\EBWebView`。2026-11-10 改名（D17）前两者用的是旧标识；新版第一次启动时把旧目录复制过来，旧目录保留，见 [改名兼容](contracts.md#改名兼容d17)。

macOS 上（G1.4，2026-11-13 起）：家目录同样是 `FUYU_HOME`、指针文件或默认的 `~/.fuyu`；应用数据目录（指针文件 `home.json` 所在处）是 `~/Library/Application Support/com.tixxin.fuyu`；锁文件 `fuyu.lock` 的 `computer` 取 `scutil --get ComputerName`。WebView 的数据（含 `localStorage`）在 `~/Library/WebKit/com.tixxin.fuyu`；没打包的调试版按进程名存在 `~/Library/WebKit/fuyu`，lane 预览在 `~/Library/WebKit/fuyu-lane-<N>`。凭据在登录钥匙串里，服务名和用户名与 Windows 相同。
