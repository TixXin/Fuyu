# 收起条上的项目：统一排序、分左右、可隐藏（C12，issue #17）

## 现状（2026-11-09，`9f1e3a7`）

收起条（`src/windows/island/IslandCollapsedBar.tsx`）从左到右写死：

| 位置 | 内容 | 来源 |
|---|---|---|

| 中间 | 摘要文字或中心图案（`slots.center`） | 内置 / 内置插件 `focusd.center-pattern` |
| 右侧 | 新邮件、更新提醒 | 内置 |

临时出现的内容（消息预览、音量亮度、设备提醒、用量提醒、会议加入按钮、插件通知按钮）占摘要的位置或紧跟其后。

宽度（`useCollapsedTodo.ts` + `layout.ts`）：按摘要文字估算 280–340px，再加 `sideWidth`（用量环）和没有摘要时的 `centerWidth`。右侧其余图标不加宽度，占用的是摘要的空间。

## 目标

- 每个常驻图标是一个**上岛项目**，有固定 id，在 外观 → 收起条 统一排列：左右两区，每区可放多个，可上移 / 下移、换区、隐藏（状态灯也能隐藏）。
- 一个插件可以提供多个项目：用量环每家一项（`usage:claude`、`usage:codex` …），市场插件的每个状态项一项（`plugin:<插件 id>/<状态项 id>`）。
- 默认顺序等于现在的布局，老用户升级后看不出变化。
- 位置只在这一处调；插件不需要知道自己在哪。
- 临时内容不参与排序，规则不变。
- 收起按钮（AI Agent 关闭时最右的那个）不参与排序，始终在最右，保证收起条总有一个收起的地方。

## 数据

新 localStorage key `fuyu-collapsed-items`（写进 contracts.md）：

```json
{ "version": 1, "items": [{ "id": "status-light", "zone": "left" }, { "id": "music", "zone": "right", "hidden": true }] }
```

- 只记录用户排过的项目。读的时候和当前可用的项目合并：记录里有的按记录的区和顺序；没记录的（新装的插件、新加的内置项目）按默认位置插入；记录里有、现在不可用的（插件被关掉）保留在记录里但不显示，插件重新打开时回到原位。
- 合并、移动、换区、隐藏都是纯函数（`features/appearance/collapsedItems.ts`），单元测试覆盖。

## 宽度

每个项目声明自己额外需要的宽度（多数是 0，用量环是现在的 `CLAUDE_USAGE_GAUGE_WIDTH`）。收起条宽度 = 按摘要估算的宽度 + 显示中的项目的额外宽度之和，和项目在哪一区无关，所以默认布局下宽度不变。隐藏的项目不计宽度。
