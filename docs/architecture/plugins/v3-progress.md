## 谁能改哪一节

这份文档会被几个会话、两台机器同时用到。为了不改到同一行：

| 节 | 谁改 | 什么时候 |
|---|---|---|
| 当前状态、阶段 | 负责当前阶段的会话 | 阶段开头和结尾各一次；中途的进度不记在这里 |
| 开工前的准备 | 做那一项的会话 | 做完时 |
| 基线和实测 | 在哪台机器上测的就由那台机器上的会话改，一个系统一行 | 测完时 |
| 待人工验收 | 列验收项的会话加行；用户看过后由当时的会话勾掉 | |
| 等你定的事、决定记录 | 和用户对话的那个会话 | 用户定了之后 |
| 风险的现状 | 负责当前阶段的会话 | 阶段结尾 |

- **每一步的进度不记在这里**：记在各自认领的任务文件里（步骤写在任务的「验收」，交接写在「交接」）。看全局用 `pnpm tasks show E36`。
- 子代理不改这份文档。
- 和代码改动放在同一个提交里。只写事实：日期、提交号、数字。
- 一个阶段结束后，这里只留一行结果；它的细节在任务文件里，随任务归档。
